# 250 篇顶会论文写作手册

本手册把 250 篇 ICLR/ICML 2026 Outstanding、Oral、Spotlight 论文的统计结果转换成论文设计动作。需要逐节整数预算、9 句摘要、10 页正文配置、17 页附录架构和完整完稿标准时，直接使用 [`iclr-full-paper-blueprint.md`](iclr-full-paper-blueprint.md)。完整统计、案例页码和逐篇证据见 [`statistical_analysis_250.md`](../reports/statistical_analysis_250.md)。

## 1. 先建立一条证据主线

正文围绕一条主线展开：

```text
研究对象 → 关键缺口 → 核心洞见 → 方法组件 → 形式化对象
→ 可观测预测 → 实验 → 结果 → 消融 → 结论
```

为每项贡献建立一行 claim map：

| 主张 | 方法对象 | 公式或保证 | 预测 | 实验 | 结果 | 消融 | 结论 | 附录证据 |
|---|---|---|---|---|---|---|---|---|
| C1 |  |  |  |  |  |  |  |  |

250 篇中，30.8% 形成完整十节点闭环。高质量写作的优化方向是让每个贡献从引言连续贯穿到结论，而非增加孤立章节。

## 2. 按证据职责分配正文

下表采用逐篇正文占比的四分位区间。每个区间独立反映该模块的常见规模，实际组合跟随论文类型。

| 模块 | 起稿区间 | 主要职责 |
|---|---:|---|
| 引言 | 12%–17% | 建立对象、缺口、洞见、贡献和结果预告 |
| 相关工作 | 6%–11% | 分类、最近邻差异、继承关系和方法缺口 |
| 方法 | 18%–29% | 定义组件、对象、变换、执行接口和预测 |
| 理论 | 0%–16% | 假设、定理、保证、复杂度和可观测推论 |
| 实验设计 | 7%–12% | 数据、任务、基线、指标、分母、预算和控制 |
| 结果 | 12%–22% | 回答主张、展示异质性、成本与失败面 |
| 消融 | 0%–9% | 识别组件职责、机制、替代解释和敏感性 |
| 结论 | 2%–3.5% | 按贡献顺序回收证据和影响 |
| Limitations | 0%–3% | 给出适用范围、代价、失败条件和部署边界 |

方法、结果、引言的会议等权均值合计 55.68%。正文首先保证这三个模块形成完整可读链，再扩展理论、鲁棒性和附加结果。

## 3. 摘要按功能推进

摘要的高频骨架为：

```text
对象与范围 → 问题与缺口 → 核心洞见 → 方法
→ 实验设置或理论 → 结果 → 影响
```

建议写成 7–9 句：

1. 定义研究对象与任务范围。
2. 指出现有方法的具体失败。
3. 给出一句可复述的核心洞见。
4. 说明方法如何实现该洞见。
5. 交代任务、数据、模型或理论设置。
6. 给出最重要的结果方向。
7. 写出比较对象、决策量和代表数字。
8. 回收到能力、理论或实践影响。
9. 在适用时写明关键边界或代价。

98.0% 的摘要包含方法，98.0% 至少包含一种结果，55.6% 包含定量结果。数字优先承载性能、成功率、速度、内存、计算量、覆盖率或复杂度中最能改变判断的一项。

## 4. 引言形成因果推进

引言采用以下动作序列：

```text
context → problem → failure_of_prior_work → missing_insight
→ core_idea → method_preview → result_preview → contribution_list
```

每段包含四个接口：

```text
上一段留下的问题
→ 本段的判断或对象
→ 支撑判断的证据、公式或例子
→ 下一段需要回答的问题
```

贡献列表承担全文索引。每项贡献写出一个对象、一个方法组件和一个结果入口，并与方法小节、结果小节和结论保持同序。

## 5. 相关工作建立最近邻坐标系

Related Work 的中位数为 507 词，正文占比中位数为 8.42%。每个文献簇按四步组织：

```text
分类轴 → 最近邻工作 → 明确比较维度 → 本文改变的维度
```

有效比较维度包括 objective、assumption、scope、oracle、data access、computational cost 和 evaluation target。段落结尾把缺口交给下一节的一个方法组件，使文献讨论直接参与论证。

## 6. 方法章节让图、公式和算法共用一套对象

每个方法组件采用五步推进：

```text
定义组件 → 给出对象和公式 → 解释机制
→ 写出可观测预测 → 指向对应实验
```

三种表达各自承担明确职责：

- 方法图：输入、状态、组件边界、数据流和输出；
- 公式：定义、目标、变换、约束和保证；
- 伪代码：初始化、循环、更新、分支、终止和输出。

图中节点、公式变量和算法状态使用同一命名。方法模块平均每篇包含 1.21 幅图、0.39 个算法对象和 5.52 个展示公式。

## 7. 理论连接预测与实验

理论段落按以下顺序展开：

```text
假设 → 形式对象 → 定理或命题 → proof idea
→ 可观测预测 → 实验接口 → 结果解释
```

正文保留定理陈述、假设、结论和预测；附录承载完整证明、技术引理和扩展条件。理论模块平均每篇包含 5.97 个展示公式，92.0% 的证明对象位于附录。

## 8. 实验设计使用协议表

一张实验协议表集中呈现设计字段：

| 字段 | 写作内容 |
|---|---|
| 研究问题 | RQ、假设、预测和失败判定 |
| 数据 | 来源、规模、划分、筛选、标签和分母 |
| 任务 | 环境、协议、输入输出和评测范围 |
| 模型 | 架构、骨干、版本和适配方式 |
| 基线 | 最近邻、强基线、资源匹配和比较条件 |
| 指标 | 方向、聚合单位、权重和决策意义 |
| 重复 | seed、run、trial 和重复单位 |
| 预算 | 训练、推理、token、query、时间和成本 |
| 超参数 | 选择规则、搜索空间和最终配置 |
| 运行环境 | 硬件、软件、精度和运行时 |
| 控制 | 匹配、干预、泄漏与污染控制 |
| 人类评测 | 参与者、标注协议、一致性和聚合 |

实验顺序与贡献顺序一致：主结果回答能力，组件干预回答机制，鲁棒性回答分布变化，失败面板回答适用范围，成本表回答落地代价。

## 9. 结果图表各司其职

- 表格承载精确数值、跨任务比较、基线排名和资源成本；
- 图形承载结构、趋势、分布、Pareto、伸缩和失败面；
- 结果模块平均每篇包含 2.34 幅图和 2.09 张表；
- 消融模块平均每篇包含 1.67 幅图和 0.90 张表；
- 图注写明对象、分母、聚合单位、误差定义和阅读结论；
- 正文展示项目特定的 estimand、任务异质性、失败数量和机制分解；
- 附录展开逐任务矩阵、重采样分析、敏感性和完整分布。

结果段按 claim 编号组织。每段先写判断，再给数值和图表，随后解释机制、异质性和代价。

## 10. 消融回答机制问题

优先选择能够区分机制的消融：

1. 删除一个方法组件；
2. 用最近邻机制替换该组件；
3. 改变理论中的关键条件；
4. 展示任务、模型和规模异质性；
5. 给出失败切片和计算代价；
6. 把结果回收到原始 prediction。

超参数扫描用于展示稳定区间；组件干预用于确认因果职责。两类结果在标题和结论中分别命名。

## 11. 正文与附录形成调用关系

正文保留决策接口：

- 研究问题、核心主张和范围；
- 方法对象、关键公式、算法接口和定理结论；
- 数据、任务、基线、指标、分母和预算；
- 主结果、机制消融、失败面与成本；
- 结论和精确附录指针。

附录承载核查材料：

- 完整证明、推导、算法变体和复杂度细节；
- 数据处理、完整配置、硬件、版本和随机种子；
- 全结果矩阵、鲁棒性、追加消融和失败全集；
- 人类评测协议、问卷、案例网格和复现命令。

附录/正文页数比的中位数为 1.40，词数比中位数为 0.84。正文平均调用附录 10.48 次。每次调用写明对象与用途，例如「Appendix C 给出 finite-sample guarantee 的完整证明」。

## 12. 用词匹配证据角色

| 动词 | 适合承载的证据 |
|---|---|
| `propose` / `introduce` | 新方法、对象、系统或数据集 |
| `show` / `establish` | 证明、直接推导或明确实证 |
| `find` / `observe` | 经验发现、趋势和异质性 |
| `demonstrate` | 跨任务、模型或设置的验证 |
| `however` | 前一结论后的边界、反例或机制转折 |
| `in contrast` | 同一比较维度上的最近邻差异 |

`novel`、`significantly` 和 `state-of-the-art` 与具体对象、数值和比较条件同时出现。结果与动词形成可定位的证据关系。

## 13. 写作顺序

1. 建立 claim map。
2. 建立实验协议表。
3. 设计主结果、机制消融、失败面和成本图表。
4. 写方法对象、公式、算法和 prediction。
5. 写实验、结果和消融。
6. 组织证明、配置、全结果和复现附录。
7. 回写相关工作和引言。
8. 写摘要和结论。
9. 检查术语、符号、图表顺序和附录调用。
10. 逐项核对 claim closure。

## 14. 完稿检查表

- [ ] 每项贡献连接方法组件、prediction、结果和结论。
- [ ] Related Work 写出分类轴、最近邻和明确差异。
- [ ] 方法图、公式和算法使用一致命名。
- [ ] 实验协议表给出数据、基线、指标、分母、重复和预算。
- [ ] 主结果展示决定结论的数值与任务范围。
- [ ] 消融回答组件职责或替代解释。
- [ ] 失败、成本和适用范围进入正文决策链。
- [ ] 附录各章均由正文精确调用。
- [ ] 结论按贡献顺序回收全文证据。
