## 5. 视觉叙事闭环与最终判断

- **视觉叙事**：Figure 1 先把固定 key 的 failure 拆成 query stealth/robustness 问题，再由 Tables 1–3 把“有效性—prominent robustness—targeted robustness”压成统一 FSR 网格，Figure 2 补 stealth。附录以 Table 4/5、Figures 3–9 展开 quality、攻击、query accumulation、domain、δ、regularizer、leakage，再以 Figures 10–12 展示 token/multi-key/harmful domain 的能力边界，Table 9 回收资源成本。
- **最有价值对象**：Figure 1（方法接口）、Table 2（主 deployment matrix）、Table 3（targeted failure/robustness）、Figure 3/6（“单次信号弱化→多次 query 恢复”的机制）、Table 4（目标域质量代价）和 Figure 9（stealth domain boundary）。
- **最可复用模式**：统一 FSR 表头与绿/粉 cell encoding；用 log query axis 和显式 `α=1e−3` threshold 把 statistical power 画成可读曲线；将目标域 success 与非目标域 leakage/quality 作为配对证据；用颜色之外的 marker/line style 表示多因素时保持同一语义。
- **主要失败模式**：大矩阵和长 legend 在缩放后密度高；大多数曲线无 error bar/band，Figure 8 band 也未定义；Figure 10–12 的短 caption 不足以独立解释 panel、样本量和参考线；颜色-only series 在灰度下弱；正文/图例的 δ 范围和 benchmark 计数存在可见不一致；主结果措辞应限定到列示模型、攻击集合、domain secrecy 和 query budget。
- **一句话视觉策略**：用一张三 lane 概念图定义“语义域触发＋扩散统计信号”，用统一的 FSR 矩阵和 log-query/ROC 曲线逐级证明有效性、鲁棒性、隐蔽性与边界，再把质量、泄漏、扩展能力和成本留在附录做反向约束。
