## 全局纸张视觉系统

- **版式**：Letter、双栏 proceedings；Figure 1/3 和 Table 5/7/9 使用跨栏或大横向空间，主结果 Table 2/3/4 放在左/右栏中，Figure 4–6 共享 p.8 的紧凑消融/定性区块。
- **字体**：正文与 caption 主要是 Nimbus Roman/Computer Modern 系列；图内统计轴和散点使用嵌入的 Computer Modern/DejaVu Sans/Times New Roman 混合字形。图表内最小文字约 5–6 pt，常见文字约 8–9 pt；这是 PDF 对象与 180 dpi 渲染的综合估计。
- **颜色**：统计图使用蓝/红或绿/蓝对照；结构渲染主要使用红色蛋白骨架与灰色 masked residues，Figure 7 使用蓝–紫–红的 attention heatmap；Figure 1/8 还使用多色 CATH 分类。颜色承载类别、split、mask 状态或 attention 强度，许多对象没有完整的形状/纹理替代编码，因此整体灰度安全性有限。
- **表格**：Table 1–4、6–8 采用少量横线的 booktabs-like 结构；Table 2/3 用 bold 与 underline 标 best/second-best；Table 5/9 用灰色底标 default row。所有结果表都是点估计，没有误差条、seed 离散量或置信区间列。
- **caption**：常见模式是斜体对象编号 + bold 标题，再接 setup、encoding 或一句 finding。Figure 7 的 panel label 与 caption 有重复/遗漏，Figure 9 的 caption 对 70%/90% 的五列关系解释不够精确，是局部 caption 系统缺口。

- **设计与 grammar**：左侧以两幅红色 protein structure 作为输入，经黑色「Hierarchical CATH Prediction」箭头指向中部 TEDBench/CATH 多层 radial label space；右侧按纵向虚线分成长尾曲线、样本分割和功能例子。不存在单一坐标系；长尾小图的 x 为 topology label 顺序、y 为 samples，split bar 为组成比例。没有统一 legend，但 radial 图带 CATH 层级/类别说明，split bar 带四个比例标签；多处直接标注。渲染为 mixed（嵌入 raster 结构图 + 向量文字/线条/图形）。
- **编码**：颜色区分 CATH 层级/类别、train/val/test/experimental split 与 protein illustration；文字给出 label、样本数和功能角色；径向位置表达 hierarchy，折线高度表达 long-tail count，箭头表达预测方向。约 5 个视觉模块、约 6 个 legend/说明项和大量 radial labels，复杂度高。

- **caption（76 words）**：`Figure 1. Overview of the TEDBench. TEDBench is a large-scale, non-redundant benchmark for protein fold classification. Given the high diversity of protein structures, CATH (Orengo et al., 1997) provides a hierarchical classification of protein domain structures. TED (Lau et al., 2024) extends this to AFDB. ### Figure 3 — Overview of the MiAE architecture

- **位置与类型**：p.5，正文 method，跨栏 page-width；向量式 pipeline/architecture diagram。五个主要阶段为 input coordinates、masked frames、geometric encoder、decoder、reconstructed coordinates，中间用箭头连接。
- **设计与 grammar**：左到右的单一流程；红色 ribbon/输入输出、浅灰 mask 方块和 encoder/decoder、青色 visible latent、灰青相间的 full latent sequence，标签放在图标/模块下方。无坐标轴、legend 或数据坐标；渲染主要为 vector；direct labels=true；无 uncertainty。
- **编码**：x 是处理阶段顺序，y 是各阶段内部的 token/结构排列；颜色和形状共同区分 visible frames、mask tokens、latent representations 和 reconstruction；箭头表达信息流；文字直接标出 geometric encoder/decoder。复杂度为单 panel、约 5 个阶段、约 7 个标签/箭头注释。
- **caption（91 words）**：`Figure 3. Overview of the MiAE architecture. During pre-training, a high masking ratio (e.g., 90%) is applied to backbone frames. The geometric encoder processes only this small subset of unmasked frames, maintaining SE(3)-invariance relative to the input coordinates. Following the encoder, mask tokens are reintegrated into the latent sequence. A lightweight decoder then operates on the full set of encoded frames and mask tokens to reconstruct the original backbone coordinates. After pre-training, the decoder is discarded, and the encoder is applied to uncorrupted backbone coordinates for downstream tasks.` caption 同时完成标题、操作路径、SE(3) 机制和 pretraining/downstream 边界；`headline_bold=true`、`self_contained=true`、`main_finding_stated=true`。
- **证据关系**：把 §4 的 frame representation、masking strategy、asymmetric encoder–decoder 和 decoder discard 组织成可执行接口；Appendix B.1/B.2 负责 geometric attention/loss 细节，Table 6/7 负责架构和训练参数，Figure 3 不承担效果比较。
- **优点**：全宽位置和左到右箭头建立强方法接口；mask tokens 重新加入 latent sequence 这一关键机制有显式视觉节点；输入/输出结构图使 abstraction 与蛋白几何保持对应。
- **弱点**：图中没有标出每层/每 token 的实际数量、mask ratio 的可变范围或 decoder 何时丢弃的时间边界；浅灰/青色在灰度或低分辨率下区分度下降；需要 caption 才能理解 encoder 只看 visible frames。
- **可复用模式**：将「输入表示—稀疏操作—恢复完整序列—下游接口」画成单一跨栏 pipeline，并在 caption 明确训练期与推理期组件边界。

### Figure 6 — t-SNE projection of pretrained MiAE embeddings

- **位置与类型**：p.8 右栏、results，single-column 大型单 panel scatter；标题为 `MiAE t-SNE (Topology)`，彩色点云无坐标轴刻度。类型为 `scatter`，向量渲染。

- **数据与统计**：每个点代表一个 protein-level embedding；encoder 在 fine-tuning 前运行，residue representations 做 mean pooling，颜色为 CATH topology。图面约有 1,000 个点（rendered estimate），没有 cluster purity、nearest-neighbor、sample count 或统计检验。
- **caption（24 words）**：`Figure 6. t-SNE projection of pretrained MiAE protein embeddings (before fine-tuning), colored by CATH topology; several topologies form clear neighborhoods in the learned space.` caption 说明投影阶段、颜色和主要 qualitative finding；`headline_bold=true`、`self_contained=true`、`main_finding_stated=true`。
- **证据关系**：为 §5.5 的「topology neighborhoods」提供定性支持，Figure 8 扩展到 class/architecture；Table 3 的 linear probing 是 representation quality 的定量伴随证据。图 6 不支持 topology separation 的普遍量化结论。

### Figure 7 — Visualization of attention weights

- **位置与类型**：p.17，Appendix C.2，跨栏 page-width，四幅蛋白 ribbon raster，图下有 `(a)`–`(d)` panel labels。类型为 `qualitative_grid`、`image_montage`、`other`（residue attention heatmap over structure）。

## 跨对象系统与最终判断

### Visual narrative

论文的视觉顺序是 `Figure 1 benchmark map → Figure 3 MiAE pipeline → Table 1 denominators → Table 2/3 protocol comparisons → Table 4/5 component controls → Figure 4/5 trends → Figure 6 qualitative latent space → Appendix Figure 7/8/9 and Tables 6–9 reproducibility/coverage`。Figure 1 先固定「结构输入—CATH labels—long tail—external test」，Figure 3 再固定「masking—geometric encoder—lightweight decoder」，Table 2/3 让 scratch、linear probing、fine-tuning 的比较可读，Table 4/5 与 Figure 4/5 将 recipe 拆成可检验组件，Figure 6–9 最后提供 representation/attention/reconstruction 的定性直觉。

### Caption 与 header system

caption 多使用「斜体编号 + bold title + setup/finding」结构；Figure 1–3 的 caption 较自足，Figure 4–6 以短 finding 为主，Appendix Figure 7–9 以模型条件/visual key 为主。表格 header 统一使用 minimal horizontal rules；Table 1–3 的 grouped header 区分来源、protocol 和 test/external；Table 2/3 的 bold/underline 是 ranking cue，Table 5/9 的 gray row 是 default cue。主要残缺是 Figure 7 的 panel label 冲突、Table 4/9 的 slash/继承语义，以及 Figure 8 后两 panel 没有 color legend。

### Method–result–ablation 与 main–appendix link

Figure 3/Appendix B.1–B.3 给出 method interface 和复现参数；Table 2/3 回收 performance/representation；Table 4/5 和 Figure 4/5 对应 masking、decoder、loss、scale、sequence 等 design choices；Appendix Table 9 完整复列这些 ablation，Figure 7–9 扩展 qualitative evidence。链接清楚，但点估计没有 seed/uncertainty，不能把方向性组件差异包装成普遍最优或因果 effect。

### 最高价值对象

1. **Figure 1**：把 benchmark 身份、标签层级、long-tail 和 external test 一次固定，是读者理解全篇的入口。
2. **Figure 3**：最清楚地表达高 masking、visible-only encoder、mask-token reintegration、轻量 decoder 和 decoder discard。
3. **Table 2**：主比较中同时给 protocol、参数规模、test/external acc/F1，直接改变读者对方法定位的判断。
4. **Table 3**：隔离 linear probing，并把 >1B ESM2 单列，保留 representation quality 与 parameter-budget 语境。
5. **Table 5 + Figure 4**：一个给组件消融的可复用 recipe map，一个给 masking ratio 的 performance/error trade-off。

### 可复用模式

- 用一张跨栏 benchmark overview 固定输入、标签、分母和独立测试域。
- 用 matched pipeline 图先说明训练期/下游期的组件边界，再用表格承载精确 protocol。
- 主结果表同时给模型规模、训练协议、数据域和项目指标，不用单一 ranking 掩盖比较条件。
- 消融表以统一 default row、局部 subtitle 和同一指标组组织组件问题；趋势图同时画收益和代价。
- 定性 embedding/attention/reconstruction 图必须在 caption 中写明 protocol，并明确它们不是定量稳定性证据。

### 主要失败模式

- 所有结果表、Figure 4/5 的曲线都没有跨 seed、误差范围或重复实验信息。
- Figure 6/8 的 t-SNE 没有坐标语义、完整 legend 或 cluster metric；Figure 7 没有 colorbar，caption 还有 panel mapping 错误。
- Table 4/9 的 slash 数值和空白继承依赖正文/相邻表；Figure 5 caption 不写 dataset-size 单位。
- 公共 TEDBench 仓库虽能验证方法/数据代码，但没有 Figure/Table 视觉源；不能声称已获得 exact visual source。
- 正文 §3.2 的「fewer than 10 samples」与 Appendix A 函数默认 `cts_cutoff=20` 的 label boundary 不一致，这是数据可复现性问题，不能由视觉 audit 自行选择阈值。

### 一句话视觉策略

先用可扫读的 benchmark 与 MiAE pipeline 固定对象和机制，再用带参数/协议语境的主表与 targeted ablation 回收可判定结果，最后把没有统计不确定性的 latent、attention 和 reconstruction 作为明确限定的定性补充。
