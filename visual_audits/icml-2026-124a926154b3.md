## Cross-object judgment

- **Narrative:** 视觉叙事从 Figure 2 的 cross-model rating instability 与 Table 1 的定量对照开始，经过 Figure 1/3 的 extraction–VIDB–evaluation method interface，再用 Figure 4–8 建立 steerability、profile 和 multi-value 主线；Appendix B 的 Figure 9–17 固化数据/层级/embedding 结构，Appendix C/D 展开 evaluator ablations、四理论单值/多值和 safety failure，Appendix E/F 展示 demographic、language 与 Buddhist extensions，Appendix G 用 Figure 41/42 与 Tables 14/15 闭合 human-evaluation evidence。
- **Most reusable patterns:** 三阶段 extraction–steering–evaluation 全宽接口图，后接同轴 diverging-bar 结果图。；默认值黑点 + 正负方向 bars/arrow 的冗余编码，适合强度 steering 与 baseline shift。；理论/模型/条件 small-multiple grids：共享尺度、固定类别顺序、caption 明确上下 prompt block。；agreement/similarity/cross-theory evidence 用带 cell 数值的 sequential/diverging heatmap，并保留 colorbar。；人类评估用 UI screenshot 说明任务界面，再用 grouped-header tables 报告 scalar/pairwise/windowed fidelity。
- **Highest-value objects:** Figure 1：把三阶段方法和输出接口压缩成可追踪主视觉。；Figure 4：正文最直接的 model×prompt steerability 总览。；Figure 8：把 two-value vector interaction 与 five-value matrix 放在同一 multi-value 叙事。；Table 1：把 rating instability 与 ranking improvement 放在一个决策面。；Tables 14–15 + Figures 41–42：将人类协议、scalar reliability、pairwise/windowed evidence 闭合。
- **Failure patterns:** 主文/附录大量 mean-only bars、lines 与 heatmaps 没有 error bars、sample denominators 或 run dispersion。；附录 20+ panel steering grids 和 24-radar demographic grid 信息密度过高，缩放后文字/颜色成为瓶颈。；多处颜色承载方向/模型/理论但灰度冗余不足；部分图（Figure 19/29/33）依赖跨图 legend 或正文解释。；Figure 19 以 0.5 为理论 reference 却未画 reference line；Table 6 split blocks、Table 14 Baselines aggregation 需要额外解释。；方法/安全/扩展图覆盖广，但不同模型、理论、语言的 sample size 和 uncertainty 仍未可视化。
- **One-sentence strategy:** 以统一的强度 diverging bars、默认基线点、层级/相似度 heatmaps 和 grouped-header reliability tables，把“价值结构可嵌入—模型可按强度 steering—排名评估更稳定—扩展与失败边界可复核”串成一条从方法接口到人类证据的视觉链。
