## 跨对象系统与最终判断

### 证据闭环

论文的视觉叙事是：Figure 1 先提出 “quality–throughput” headline；Figure 2 从 MGM 的 mask waste 对照 PGM 的 two-group clean-token mechanism；Figure 3 给出 Encoder/GroupSwap/Decoder 的实现接口；Table 1/2 与 Figure 4 将方法连到 text quality、downstream 和 distillation；Figure 5、6 以及 Tables 3–10 在附录回收 sampler coverage、precision、training cost、stability、guidance sweep 和 long-context。主文对象与 appendix 对象之间有明确指针，但主图的 selected settings 仍依赖附录完整 sweep。

Caption 系统通常采用“对象标题 + setup + comparison + main finding”，表 caption 比图 caption 更常包含 batch/GPU、指标方向、缩写、highlight 和附录指针。表头统一使用 downward/upward arrows 与单位，dataset/condition 用 row groups 分隔，成本与质量在主要表中同列。方法图使用 color + position + text；结果图使用 color + marker + direct label；表格用粗体、浅灰/下划线表达 best/second-best。

最重要的未闭合点是：论文声称 complementary supervision 同时降低 gradient variance、带来 1.95 PPL reduction，但 Figure 6 只展示 loss spikes、表格没有直接 gradient-variance 测量，而且 Table 1/Table 5 的 PGM 6/6 vs MDLM 差值是 0.87，不是 1.95。另一个边界是 quality/FID/accuracy 多为单点值，只有速度类指标给 batch-level SD；因此 “comparable” 应理解为已选模型/sampler/step 条件的点比较，而非跨 seed 稳健性结论。

### 最可复用的模式

1. 首面用两个共享决策变量（质量与 throughput）压缩跨模态 headline，同时让 caption/附录表暴露 sampler、steps、batch 和 model capacity。
2. 用 baseline/proposed 的同构 token/模块几何图把“机制差异”映射到实际计算路径；GroupSwap 图的颜色和箭头可直接迁移到其它 conditional-attention architecture。
3. 结果表把 metric direction、参数量、质量和成本放在同一 decision surface；附录按 row group 展开 steps、guidance、precision 和 sampler，而不是只复制主图。
4. 将 stability/failure 作为同尺度 small multiples（Figure 6），caption 同时报告观察到的 spike 与未观察到的 divergence。

### 最高价值对象与失败模式

- 最高价值对象：Figure 1（首面主张压缩与选点透明度）、Figure 2（mask-to-partition mechanism）、Figure 3（可实现架构接口）、Table 6/9（完整质量–效率条件）和 Figure 6（消融中的负面稳定性证据）。
- 主要失败模式：多面板/多指标坐标和小 legend 降低可读性；结果图不提供 quality uncertainty；selected point 依赖附录，且 OWT 模型参数不同；Figure 5 以示例 grid 支持机制直觉但不提供重复 coverage/MI；Figure 6 不足以直接测 gradient variance；Table 7/8/9 的长 row groups 让条件容易错配。
- **一句话策略：** 以“去除 mask 后只计算 clean tokens”的机制图为解释轴，用第一页 quality–throughput 对照建立主张，再以条件完整的附录 sweep、训练成本、精度和稳定性表/图约束 headline 的适用边界。

## 结论

本论文的 6 Figure/10 Table 全部按 PDF 实物核对并逐对象记录；对象视觉源以官方 PDF 为准，公开仓库仅提供 Figure 2 的部分 rendered asset。整体设计把机制、质量、效率和附录边界串成一条可复用的 visual argument，但应在复用时保留参数匹配、sampler/steps、precision 和不确定性条件，不能把主图选点或 caption 中未实测的 gradient-variance 机制扩展为无条件结论。
