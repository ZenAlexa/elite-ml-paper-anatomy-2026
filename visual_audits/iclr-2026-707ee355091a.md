## 跨对象评价

1. **方法—结果—附录链**：Theorem 1、Propositions 2–4 和 §2.4 complexity 提供 transformed-kernel estimator 与成本预期；Tables 1–2 把 accuracy/runtime 放到两种 synthetic regime；Table 3 改变 support window；Table 4 转到 financial 数据；Figures 1–2 给出 kernel shape；Tables 5–7/Figure 3 扩展 `N/U` 成本；Table 8 把 `Δ²` 与 nll 并列。对象之间的调用关系完整，但动态机制量、组件删除和多数据集外部性没有独立图表。
2. **Caption 系统**：所有 caption 采用 `Figure/Table n:` + 正文 Roman 的描述句。Table 1/4/8 对统计量或缩写解释最多；Table 2 明确继承 Table 1；Figure 1/2 只说明 scenario 与虚线真值；Figure 3 说明颜色语义。没有 caption 使用粗体结论标题，也没有 caption 直接写出定量主发现。
3. **表头系统**：Tables 1–2 共享 `T/Ñ → method → Δ²/cpu` 的两级结构；Table 3 将 `A` 置于上层；Table 4 将 `N → method → nll/cpu` 对齐；Tables 5–8 使用 `T/U` 上层和 CPU/nll/Δ² 下层。方法命名稳定，横线承担分层而不使用竖向全网格。
4. **正文—附录关系**：正文保留 Tables 1–4，并在 §4.1.1/4.1.2 文字中调用 Appendix A 的 Figures 1–2；附录 H 继续检查 larger `N`、larger `U`、grid、solver 和 accuracy–prediction relation。Table 8 明确复现 Table 1 的 `Δ²`，Table 7 与 Figure 3共享数据，形成可回查链。
5. **字体/颜色一致性**：正文、caption、table 主要为 Nimbus Roman No9 L/Computer Modern；Figures 1–2 在 plot 内加入 Arial/AppleSymbols，Figure 3 混用 Arial/CM；方法颜色只在 Figures 1–2 固定，Figure 3 的蓝/黑语义是 measured/reference，表格全程黑白，因而跨对象颜色一致性有限。
6. **不确定性与失败**：Tables 1–4、7–8 报告 SE；Tables 5–6 只有均值；Figures 1–3 不显示误差。Table 2 文字披露 Ber 的 `Δ²>1000` 样本排除，但没有数量或敏感性表。图表整体可审计，但不确定性与失败的可视化覆盖不均。

## 最终判断

- **最可复用模式**：
  1. Figures 1–2 的同构 3×3 facet、真值虚线和直接 `True g_ij` 标签，用统一坐标支持跨机制形状对照。
  2. Tables 1–2/4 的 paired quality–cost columns，把误差或 nll 与 CPU 放在同一比较面并显式给出 trials/SE。
  3. Table 3 的单因素 support-window accuracy–cost 消融，和 Table 5 的大规模成本最小表面。
  4. Table 7 + Figure 3 的「原始均值/SE 表 + log–log 理论参考线」配对，用表保留数值、用图展示趋势。
- **信息价值最高的对象**：Table 1（理论 estimator 的主 synthetic tradeoff）、Table 2（inhibitory robustness 与 outlier 边界）、Figures 1–2（9-panel kernel shape evidence）、Table 7/Figure 3（维度成本与复杂度回收）。
- **失败模式**：
  1. Figure 1–3 均为代表性/均值呈现，图内没有误差、trial identity 或选择规则；Table 5–6 也没有 dispersion。
  2. Table 2 的 outlier 排除只在正文叙述，未给排除数量和包含异常值的敏感性结果，比较分母无法从对象恢复。
  3. Table 2/4 依赖 Table 1 notation，多个 caption 未定义 `Δ²`、`U` 或 scenario；Figure 2 单独裁剪会丢共享图例。
  4. Figure 1–2 的五色曲线缺少 marker/线型冗余，灰度或曲线重叠时方法识别成本高；Figure 3 只有 Ours scaling，没有 baseline 同图对照。
- **一句话视觉策略**：用黑白 paired accuracy–cost 表建立理论 estimator 的主证据，再用同构 kernel grids 和 log–log scaling 图补上 shape 与复杂度直觉，附录以小型消融和复现表扩展范围，但把 trial 变异、异常值和机制动态的可视化留在对象之外。
