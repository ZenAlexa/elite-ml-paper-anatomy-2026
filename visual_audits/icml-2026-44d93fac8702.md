## 跨对象闭环与最终判断

1. **视觉叙事**：Figure 1 建立策略→LoRA sweep→ID/OOD 的接口；Figure 2 把 4B 定义变成 threshold crossing；Tables 1–2 给出主比较和 baseline correlations；Table 3 检查 threshold robustness；Table 4 把机制延伸到 Reasoning Gym 并保留 cognitive 反例；Table 5 把 correctness 作为 failure/mechanism ablation；Figure 3 和 Tables 6–9 提供 scale、配置、metric replacement 与 split-level reproduction。
2. **Caption 系统**：所有对象都有编号开头的短 caption；Figures 1–3 说明设置、编码和（前两幅）主发现，Tables 1/2/4/8/9 定义 ID/OOD/Overall、箭头和缩写，Tables 3/5/6/7 偏向设置或比较。主文图表会用 section/table pointer 形成交叉引用，但没有误差带/interval 的统一 caption 语言。
3. **表头系统**：正文 Tables 1/2/4 共用 strategy + performance + metric-baseline schema；Table 8/9 以两级 spanner 恢复 split 细节；方向箭头置于 metric header，row groups 斜体，best/second-best 用粗体/下划线，横线遵循 booktabs。
4. **方法—结果—消融连接**：Figure 1/2/3 与 `d_int` operational definition 直接相连；Tables 1/2 量化 headline predictor，Table 3 处理 threshold 选择；Table 5 与跨域 Table 4 提供机制/失败线索；Table 7 排除 LongPPL 这一 baseline replacement。图表展示的是 strategy-level correlation 和 capacity proxy，不构成独立 causal proof。
5. **正文—附录连接**：Table 1→Table 8、Table 2→Table 9；Figure 2→Figure 3；Table 4→Table 6；§3/§4 的 LongPPL 讨论→Table 7。附录承担 split 异质性、任务配置和样例/metric details，正文仍保留定义和主要决策数字。
6. **最高价值对象**：Figure 2（把抽象 ID 定义变成可读 crossing）、Table 1（主模型全 strategy 与 baseline 对照）、Figure 1（完整接口总览）、Table 5（把 correctness 与 ID/Overall 的机制变化并列）。
7. **最可复用模式**：固定模型/问题源后，用共同 capability threshold；用 log-x Pareto frontier + 同色 crossing guides；主表同时报告效果和替代 metric；把 aggregate 表与逐 split 附录同构连接；跨域时保留独立 row group 与反例。
8. **主要失败模式**：图 1 的概念/数据混排和手绘装饰在缩小后降低精度；Figures 2–3 只选部分曲线且无训练波动；Tables 1/2/4/8/9 用 geometric mean 隐藏 split/task 异质性；全套对象没有 seed dispersion、区间或误差编码；absolute ID 跨 1B/4B 受不同 threshold 限制。

**一句话视觉策略**：论文用一张高信息量方法总览把 strategy→capacity→generalization 串起来，再用共享的 log-scale Pareto crossing 图和黑白 booktabs 结果/消融表把“低 intrinsic dimensionality 预测更好泛化”的证据闭合到跨模型、跨域和逐 split 附录。
