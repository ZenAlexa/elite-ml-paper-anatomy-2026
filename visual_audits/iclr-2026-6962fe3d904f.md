## 7. 跨对象系统判断

- **视觉叙事**：Figure 1 用六个面板从长程生物动机、SSM 技术限制、multimodal signal，到长度/删信号诊断建立问题；Figure 2 给出 Seq2Exp test-time shortening；Figure 3 将 background confounding 写成 SCM；Figure 4 将 SCM 映射为 Prism 双 encoder 和 n 个 weighted contexts；Table 1/2/3 依次给主性能、超参折中和参数开销。Appendix Tables 4–7 展开 Figure 1/2 的 raw data，Table 8/Figure 6 连接长程 prevalence 与 qualitative locus，Tables 10–16 补足 pretraining、额外 signal、跨 cell、length 和 dropout。
- **Caption system**：所有 caption 使用 `Figure/Table N:` + sentence case；Figure 1/4/6 caption 负责设置/组件，结果 caption 很多只给标题（Figure 2/3/5），Table 1/2/4/8 的 header/caption 较完整。没有图表 caption 定义 error bar/band，因为本 PDF 图表无 error bar/band；表格 ± 的统计含义主要在正文而不是各 caption 中说明。
- **Table header system**：性能表统一使用下降/上升箭头；主表按 cell type 两级 header，附录多数为单级 `Model/Metric` 或 `Signal/MSE/MAE/Pearson`。表格整体采用 booktabs/partial-grid、少用竖线；Table 5/2 用子表结构承载 sweep。
- **Method–result–ablation link**：Figure 3/4 是理论—方法接口；Figure 1/2、Tables 4–7 是输入长度与 signal dependency diagnostics；Table 2 是 n/α/β sensitivity；Figure 5/Table 16 是 learned-weight mechanism；Table 1、10–15 是主、预训练、组合 signal、跨 cell 与第三 cell line robustness。没有独立 ground-truth confounder state 或完整去掉 diversity loss 的机制实验。

## 8. 最终判断

- **最可复用模式**：六面板诊断链把 biological premise、technical failure、component contribution 和 test-time intervention 放在同一视觉锚点；SCM 节点图后紧接跨栏 architecture；性能表固定指标方向箭头并用粗体/下划线表达 best/second-best；长度和信号消融采用对称子表与公共 baseline。
- **最高价值对象**：Figure 1（主问题和诊断链）、Figure 4（Prism 方法接口）、Table 1（两 cell line 六指标主比较）、Table 2（n/α/β 选择）、Table 7（训练全信号/测试删信号的机制诊断）、Figure 6 + Table 8（定量 prevalence 与 qualitative locus 的互补）。
- **失败模式**：Figure 2/3/5 caption 信息不足；Figure 1 多面板色彩和字体角色未全局统一；多数 appendix 单点表无不确定性；Table 2 的“only mean”与实际 ± 不一致；Table 7 文字百分比与 raw values 不相容；Figure 5/6 的样本覆盖有限，learned states 的 biological semantics 和 causal interpretation 尚无独立验证；Table 1 的 cited baselines 与 Prism 自跑结果 provenance 不完全对称。
- **一句话视觉策略**：论文用一张六面板诊断图把“长序列不足与信号过度依赖”转成问题，再用 SCM/architecture 固定 Prism 接口，主表给出短序列性能，附录以长度、signal、pretraining、跨 cell 和 learned-weight 对照补齐边界证据。
