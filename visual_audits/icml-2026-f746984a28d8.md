## Paper-wide visual style

- The main paper (pp. 1–9) is a conventional two-column proceedings layout; the appendix (pp. 16–30) is one-column. Figure 1 and Table 3/Table 4 use a single column in the main layout; Figure 2 and Tables 1–2 are full-width. Appendix Figures 3–10 and Tables 5–9 are page-width except the compact inset Table 7.
- Body, captions, equations, and table text are serif/math PDF objects centered on Nimbus Roman No9 L and Computer Modern-like math. Chart titles/axes use a small serif/sans-like Matplotlib face depending on the object. Rendered chart/table text is generally about 6–9 pt; Figure 1's large box labels reach approximately 10–11 pt. These are rendered estimates unless a checked source routine gives the parameter exactly.
- The visual language has three distinct families: pastel salmon/lavender/green boxes and black arrows for the method schematic; viridis-like density fields and red/blue sample marks for qualitative sampling panels; and orange/blue measured curves with square/circle markers for sensitivity plots. Tables use black rules/text with bold and underline as the only emphasis. Color is semantically useful but is not uniformly safe in grayscale; marker/line redundancy rescues Figures 7–9 more than the qualitative panels.
- Figure 1 and all table rules/text remain vector-like PDF objects. Figure 2 and the generated-sample panels (Figures 3–6) contain embedded raster panels. Figures 7–9 are vector curves/error bars in the PDF. Figure 10 is a rasterized 2-D histogram per panel, although axes/text remain PDF objects. This mixed production is consistent with the source routines and the 200 dpi render.

- **Visual narrative:** Figure 1 defines the objects/update loop; Tables 1–2 establish gradient-free/gradient-based benchmark outcomes; Figure 2 and Table 3 connect learned intermediate targets to the mechanism; Table 4 isolates buffer prioritisation. Appendix Figures 3–6 turn the benchmark claim into sample geometry, Table 5 fixes reproduction settings, Table 6 audits loss choices, Figures 7–9 expose sensitivity and failure boundaries, and Table 7/Figure 10 plus Tables 8–9 test molecular and discrete applications.
- **Caption system:** Captions use italic Figure/Table labels and mostly descriptive titles. Main findings are generally stated in the surrounding paragraph rather than in short captions; Table 1 supplies the global five-run/best-versus-second-best convention, while Figures 7/9 define error bars or censoring locally. This makes captions concise but leaves several appendix visuals non-self-contained without nearby prose.
- **Table-header system:** `Target →` and `Alg./Algorithm ↓ Metric →` recur across result tables. Grouped target headers, metric-direction arrows, mean ± standard deviation, bold best means, and underlined second-best means create a stable table grammar from the main paper through discrete applications. Hyperparameter Table 5 appropriately switches to design-parameter rows rather than forcing metric headers.
- **Method–result–ablation link:** The schematic's flows/policies/SMC/IW Buffer map directly to the TB/SubTB, SMC, and IW-Buf rows in Tables 1–4. Figure 2/Table 3 test flow learning; Table 4 tests prioritisation; Table 6 tests loss assignment; Figures 7–9 test the three operational knobs chosen in Table 5. - **Main–appendix link:** Main pages carry only the method interface, headline benchmark tables, and one mechanism grid. Appendix G reproduces the same targets and methods qualitatively, then extends to loss/sensitivity; Appendices H/I reuse the result-table grammar for ALDP and sequence design. - **Typography consistency:** Serif/math text and black table rules are stable. Matplotlib-like chart text is smaller and occasionally more sans-like, but panel labels, captions, and equations retain the proceedings face. Appendix visual montages trade exact chart typography for raster sample density; source routines explain that tradeoff.

## Final judgment

- **Most reusable patterns:** (1) a method-interface diagram that names every learned object and arrow direction; (2) a fixed target-by-method qualitative grid with a ground-truth/reference column; (3) grouped target/metric tables with direction arrows, five-run ±SD, and bold/underline best/second-best semantics; (4) log-scale sensitivity panels with marker/line redundancy and explicit error bars; (5) failure-aware tables/plots that define `×` or censoring thresholds in-band.
- **Highest-value objects:** Figure 1 for the method boundary; Tables 1–2 for exact headline comparisons; Figure 2 + Table 3 for the learned-flow mechanism; Table 4 for the IW-Buf isolation; Figure 10 + Table 7 for the ALDP application boundary.
- **Failure patterns:** Appendix qualitative captions often omit seed/sample-count/projection details that are only stated in surrounding prose; raster density panels lack colorbars; compact tables rely on indentation and nearby text for hierarchy; categorical spacing of numeric sweeps can hide nonuniform parameter distances; Figure 9 censors off-scale failures without reporting a count; first-seed qualitative panels cannot establish replicate robustness.
- **One-sentence visual strategy:** Define the reinforced SMC/IW-Buf loop once, quantify it with grouped monochrome tables, then reuse fixed-coordinate density/configuration montages and log-scale sensitivity plots to connect mechanism, robustness, and application limits.
