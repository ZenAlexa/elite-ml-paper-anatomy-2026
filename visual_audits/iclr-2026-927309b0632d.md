### 字体、版式与输出

论文采用 ICLR 单栏 LaTeX 版式，正文与 caption 主要使用 Nimbus Roman No9 L，数学使用 Computer Modern，代码/等宽片段使用 Inconsolata。图内 Matplotlib 风格标签使用嵌入的 DejaVu Sans 或 STIX/Computer Modern Type 3 字形。正文和表格是 PDF 字体/矢量对象；主文折线、柱状和直方图主要由矢量路径组成，Ramachandran 热图由栅格图像嵌入并叠加向量化坐标与色条，整体属于 mixed output。图中文字约 5–9 pt，caption 约 8–9 pt；图内数学标签和图例在单栏 inset 中偏小。

### Figure 1：Flow map 与 SNIS（PDF p.2）

- **版式与图形语法**。页宽横向 conceptual diagram。左侧 Source 密度通过大量半透明 flow path 连接到 Biased Target；中部是带边框的 Self-normalized Importance Sampling 公式框；右侧是 Debiased Target 密度。局部标注 `x0`、`xs`、`xt`、`x1`、`v(xs,s)` 和 `uθ(xs,s,t)`，两支蓝色箭头表达处理方向。无坐标轴、legend、marker、error bar 或 band。
- **编码与数据**。密度轮廓表示 source/target 分布，流线表示 map，SNIS 框表示权重归一化，右端分布表示校正后的目标。数据值、样本分母和重复次数均未绘制；“approaching equality with infinite samples”来自 caption 的理论条件，不是图内估计误差。
- **Caption** `Figure 1: Flow map learns from biased data, with SNIS re-weighting generated samples consistent with the Boltzmann distribution, approaching equality with infinite samples under mild regularity conditions.` 词数 27；动作包括 title、setup、encoding_key、main_finding。caption 说明源、重加权、目标和渐近条件，未定义颜色与流线方向。
- **证据关系**。连接 §1–§2 的 BG/SNIS 主张与 Eq. 1–2；Figure 2 将 BG 的质量—时间关系量化，Tables 2–5 检验 corrected samples 和成本。
- **优点**。把有偏数据、flow map、SNIS 和 debiasing 组织成单条视觉因果链；密度形状和多条路径同时表达 local/global transport。
- **弱点**。图标和密集流线在缩小后易重叠；没有显示 proposal likelihood、energy 或权重分布的数值规模。
- **可复用模式**。用“有偏来源→校正操作→目标分布”的页宽流程图把理论接口变成实验入口，并在箭头附近放置关键变量。

## 5. 数据、统计与证据关系总览

- **实验单位**。定量实验通常使用三个 model seeds，表和消融文字报告 mean ± standard deviation；Figure 2、4、6、7、13 的 error bars 在不同处代表运行、draw 或 seed 不确定性，图注没有全部复述。Figure 4 的三次 SBG draw 在 Appendix F.1 明确，Figure 7 的三 trained seeds 在正文说明。
- **指标语义**。ESS 越高越好，E-W2/T-W2 越低越好；Figure 3/5 的 Normalized Density 和 Figure 8–11/14–17 的 Free energy / kBT 是分布可视化，不能与表中距离数值直接比较。Figure 2/4/13 的 W2 曲线分别承担 time/sample/NFE 的成本关系。
- **缺失与失败**。Table 2–3 用 dash 表示 unavailable，SBG SMC 的 ESS 明确无效；FALCON-A、FALCON 在不同 metric 上分获 best，不能压缩为单一 overall winner。Figure 11 caption 的 “Last three” 与实际五个 test panels 不一致。Table 3 caption 的 2×10^5 与 Appendix D.1 的 10^4 proposal samples 需要保留为未解决复现冲突。
- **理论与实证**。Proposition 1–2 只在 ideal minimizer/pointwise Linv→0 条件下给出 invertibility/change-of-variables；Figure 12 是局部 auxiliary reverse 实验，Figures 14–17 是 mode-level qualitative check。Figure 6/7 解释正则和 schedule 的机制，Tables 2–5 将质量、样本预算和系统成本放到决策面上。

## 7. 最终判断

### 最可复用的模式

1. Figure 1 用 biased source、flow map、SNIS 和 debiased target 建立理论接口；Figure 2 用 log evaluation time 与 W2 把接口连接到实际成本。
2. Figures 3–5 将真值、proposal、reweighted proposal 和 step count 用同构 histogram 展开，读者能同时检查 distribution shape 与 post-hoc compute trade-off。
3. Tables 2–5 把指标方向、best/second-best、seed dispersion、sample budget、NFE 和累计成本放在相邻对象中，连接 quality 与 system cost。
4. Figures 8–11、14–17 复用 shared free-energy colorbar、角度坐标和固定 torsion index，形成训练/测试 bias 到模型预测的可追溯矩阵。
5. Figure 6/7 采用并列指标、对数轴和 error bars 展示正则/采样 schedule 的单因素折中；Table 6 固定跨数据集模型容量。

### 最高价值对象

- **Figure 1**。把 SNIS 统计校正和 flow map 视觉化，是整篇论文从 BG 问题过渡到 FALCON 方法的入口。
- **Figure 2 与 Table 4–5**。Figure 2 给出 time frontier，Table 4 给出 cumulative cost，Table 5 给出 NFE/quality 成对数字，三者共同承载效率主张。
- **Table 3 与 Figure 3**。Table 3 负责 larger-peptide 的 local/global metrics，Figure 3 负责四个系统的 energy-shape sanity check。
- **Figure 6 与 Figure 12**。前者呈现 λr 的 performance trade-off，后者提供 auxiliary reverse loss 的实践 invertibility 证据；两者需与理想理论边界同时阅读。
- **Figures 8–11 与 14–17**。前者公开 train/test distribution，后者公开 prediction/test mode coverage，是数据偏差和定性泛化的主要审计对象。

### 失败模式与改进优先级

- Figure 2、4、6、7、12、13 的 inset 图和小字号 legend/error bars 增加估读成本；配对数值表应补充 operating point、误差定义和单位。
- Figure 3/5 的多 panel x/y 范围与 binning 未在 caption 中完全定义；Figure 6/7 的 caption 未列出指标、series 或 schedule 全称。
- Figure 4 只显示 E-W2，不能单独支撑 across-all-metrics；Table 2–3 的 best 变体不同，摘要/引言宽表述应收窄到具体 metric 和 dataset。
- Figures 8–11、14–17 的 free-energy 热图依赖单一色条，缺少样本数、mode-wise difference 或定量 coverage；Figure 11 caption 把五个 test panels 写成 “Last three”。
- Table 3 的 2×10^5 evaluation caption 与 Appendix D.1 的 10^4 proposal samples 冲突；Table 4 缺少显式时间单位；Table 6 不含 optimizer/split/scheduler。
- FALCON 代码 URL 当前不可访问，只有 baseline 仓的相关 plotting utilities；因此不能把 STIX 字体、dpi、bins 或 linewidth 从 baseline 脚本冒充为 FALCON 图源。

### 一句话视觉策略

以 biased-to-debiased flow 图建立 SNIS 与可逆 map 的因果骨架，用 W2/ESS/时间/NFE 表图绑定质量和成本，再以 train/test 构象热图、regularization/schedule 消融和 auxiliary reverse 曲线限定 few-step likelihood 的实践边界。
