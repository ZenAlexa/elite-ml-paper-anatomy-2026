## 全文视觉风格

- 正文为双栏；Figure 1、2、3、4 与 Table 1 跨栏，Table 2 在 p. 9 右栏，附录的宽图和主结果表多为近全宽。附录 hyperparameter/config 表使用中央窄表或跨栏表混排。
- PDF 是混合渲染：表格规则、正文/caption 字体、图中大量数学/标签为 PDF 对象，照片、slot mask、热图和部分曲线是嵌入栅格。`pdffonts` 显示 Nimbus Roman No9 L、NimbusMonL、Computer Modern、CambriaMath、Aptos/Calibri/Arial 和 DejaVu Sans 等；图中文字主要为 Arial/DejaVu 与 Computer Modern 数学字体，估计图内文字约 6–14 pt，表格主体约 7.5–9 pt。
- 主色策略是暖灰/橙/蓝/淡绿/淡黄/淡紫的模块色（Figure 1），slot mask 使用彩色注意力覆盖，similarity/attention matrix 使用绿—黄或蓝—绿连续色带，结果曲线/柱图使用蓝、黄、绿、橙等局部 categorical palette。颜色与位置、标签、形状或 hatch 有一定冗余，但整体并非灰度安全。
- 量化表主要为 booktabs/partial-grid 黑白表，以粗体标注各列较优值；主结果按 learner 成对排列 vanilla 与 `†`，并用二层表头区分 `Continual` 与 `CFST`。Table 1、5、7、8、12 的 caption 明确写出 3 trials 的 mean ± 95% confidence interval；其他表/图无不确定性。
- 视觉叙事从方法接口（Figure 1）到稳定性机制（Figure 2）、CGQA 主比较（Table 1/Figure 3）、组件和机制（Table 2/Figure 4），再由附录扩展到 mask、similarity、超参数、数据集、backbone 和成本。最明显的版面缺陷是 appendix qualitative grid 信息密度高、标签很小，以及 Figure 6 caption 的复用错误。

## 最终判断

- **最可复用模式**：
  1. 以全宽 pipeline 固定 module/data-flow vocabulary，并在后续图表中复用。
  2. 用「样本/类别 × task stage」qualitative grid 固定 `wp → image → primitive → slots` 列顺序。
  3. 用 concept → primitive → feature/logit 的同样本 similarity matrix chain 把机制观察连接到 loss ablation。
  4. 用 paired rows、二层 metric header 和 `†/*` key 把 plugin effect 与 rehearsal baseline 放到同一决策面。
  5. 将 total parameter bar 与 plugin-only/baseline/enhanced baseline time table 配对，明确成本边界。
- **最高价值对象**：Figure 1、Table 1、Figure 4/9、Figure 3、Figure 14/Table 13。
- **需要优先修复的对象问题**：核对并修正 Figure 6 caption 类别名；为 Figure 3 band、Figure 11–13 sweep 和 qualitative sampling 补统计/抽样定义；为 Tables 2、6、10、11、13 补缩写、重复和计时/数据来源；在高密度 grid 降低列数或增加可读性的 supplement。
- **一句话策略**：论文以稳定的 slot/primitive/logit 视觉词汇贯穿架构、paired benchmark、机制矩阵、qualitative grid 和成本附录，形成从接口到证据边界的完整叙事，但公开仓库只提供 Figure 1 的 rendered diagram asset，且部分附录 caption 与不确定性说明仍不足以独立复现。
