## 最终判断

- **最可复用模式**：
  1. 用上下两层 pipeline 把属性专用测量与低成本 ranking/selection 连接起来，输出端同时写出操作动作和公式接口。
  2. 用固定 Query—Positive—Negative qualitative grid 将 influence score 解释为可观察内容，并把 negative examples 作为 failure 证据。
  3. 用“同 budget 主表 + 人评三分表 + 组件/成本 appendix”形成 automated quality、perceptual preference 和 operational cost 的三面决策面。
  4. 对机制 shortcut 使用 paired distribution/bin 或 paired heatmaps，并在 caption 中定义方向、聚合和 reference。
- **最高价值对象**：Figure 1（方法可执行接口）、Table 1（两 Wan 模型主结果）、Table 2（人评补充）、Figure 5（projection 选择）和 Figure 4（frame-length 机制消融）；附录 Table 6/7 对实际可部署性很关键。
- **失败模式**：代表性定性图缺少抽样分母与失败率；VBench、LTX 和 projection 以点估计呈现且无重复/不确定性；Table 2 的 850 judgments 与四行比较分配不明；Figure 4 的 Left/Right caption 位置映射冲突；Figure 8 每类展示两个样例而 caption 声称五个 query；150 小时 upfront gradient 成本与 marginal query cost 分散在两张表和段落中；Eq. 11 的 algebraic role 未被单独消融。
- **一句话视觉策略**：论文用 NVIDIA green 串联“motion mask → projected influence ranking → targeted subset → motion-quality evidence”，再以同构 qualitative grids、VBench/human tables 和 appendix cost/mechanism views 补齐内容、结果与可部署性。
