## 全文视觉风格

- **版式**：正文和附录使用密集双栏 letter 页面；正文 Figure 1–2、Table 1–3 为单栏对象，附录 Figure 3–13 和 Table 4–7 主要为跨双栏宽度的复合对象。结果页把图与表按“时间/迭代曲线 → ESS/s → correctness”排列；附录 G 以大幅三列或多面板图占据大块页面，caption 在对象下方。
- **字体**：页面正文、表格和 caption 以 Nimbus Roman No9 L/Computer Modern Roman 与数学字体为主；算法和数学符号混用 Computer Modern 系列。图像内的轴、刻度、legend 和标题是无衬线的 Matplotlib 风格，因图被嵌入为栅格而以 `DejaVu Sans` 类字体和 6–12 pt 视觉大小估计。表格 PDF 字体对象可核对，字号为渲染/PDF 版面估计。
- **颜色**：实验曲线主要使用高饱和 categorical palette：蓝、橙、红、绿、紫、粉、灰/黑；不同 acceptance-rate 面板复用相同方法颜色。彩色曲线有 legend 和位置冗余，但 7–8 条曲线叠加时灰度区分会减弱。表格基本黑白，最佳行/单元用粗体而不依赖底色。
- **矢量/栅格**：`pdfimages -list` 显示 Figure 1、Figure 2 及附录 Figure 3–13 的绘图区以 RGB PNG 形式嵌入（图像对象的有效分辨率约 314–2634 ppi，取决于显示尺寸）；表格、caption、算法和正文是 PDF 文本/线条对象。因此 figure 的视觉细节 provenance 为 `rendered_estimate`，表格字体 provenance 主要为 `mixed`/`pdf_object`。
- **一致性**：同一实验家族的图共享方法颜色、acceptance-rate 分面和 MSE/accuracy 轴语法；主文与附录重复使用 `Best` ESS/s 与 rate-by-rate 表结构。附录 Figure 10–13 的 MNIST 图用更大的无衬线标题和不同的面板密度，整体方法颜色仍保持可追踪。

## 跨对象系统

- **视觉叙事**：Algorithm 1–3 在正文定义 two-auxiliary-variable transition、locally balanced PoissonMH 和 Tuna–SGLD；Table 1/2 把 Gaussian/robust regression 的最佳 ESS/s 放在 headline 决策面，Figure 1/2 分别给 time-MSE 和 MNIST accuracy；Table 3 检查 target correctness。附录 Figure 3–9 与 Table 4–7 展开 rate、estimand、iteration、N/d scale 和 HMC sensitivity，Figure 10–13 处理 MNIST tuning 与任务迁移。叙事从“可逆性/效率机制”到“时钟结果—per-iteration 对照—correctness—边界”是闭合的。
- **Caption 系统**：所有对象均为对象下方 `Figure/Table n.`；Table 1–5、7 采用相似的 `(Min, Median, Max)`/Best 句式并说明 runs，Figure 1、3、5、8、9、13 能在 caption 中给出设置与观察窗口；Figure 4、6、10、11 和 Table 6 的 caption 过短，关键条件留给正文/图内。
- **表头系统**：Table 1–7 采用 `Method` + ESS/s 三元摘要，附录 Table 4–7 增加三列 acceptance/target rate 与 Best；表头单层或顶层 ESS/s 分组，无竖线，横向规则形成 booktabs/minimal 系统。表格没有把不确定性与成本作为独立列，成本只隐含在 ESS/s。
- **方法—结果—消融链**：Algorithm 2/3 的 proposal/ratio minibatch → Figure 1/2 的 time efficiency → Table 1/2 的 ESS/s → Table 3 的 KS correctness；Appendix Figure 3/4/6/7/8 连接 posterior mean/variance、time/iteration、N/d scale；Figures 5/9 提供 HMC controls，Figures 10/12 提供 step/minibatch tuning。没有“删除 ω1/ω2 或 acceptance correction”的 component ablation，因此附录消融主要是 sensitivity/scale，而非组件因果。

## 最终判断

- **最可复用模式**：
  1. Figure 1/3 的“全时间范围 + 早期 inset + acceptance-rate 横向分面”，同时表达 wall-clock efficiency 与 early minibatch behavior。
  2. Table 1/2 的 compact Best ESS/s 与 Appendix Table 4/5/6/7 的 per-rate 展开，主文短、附录可核验。
  3. Figure 4/6/7/8 的 time vs iteration、N/d scale 配对，避免把计算成本和链混合混为单一速度结论。
  4. Figure 5/9 的单变量 HMC sensitivity，以及 Figure 10/12 的 panel×line hyperparameter audit。
  5. Figure 2/11/13 在不同 step/task 下保持同一 accuracy-time 曲线色表，便于识别方法排序和任务边界。
- **最高价值对象**：Figure 1 是 robust-regression 的最直观时钟效率证据；Table 1 与 Table 2 是主文可扫描的 ESS/s headline；Table 3 是 exactness/bias 边界的关键对照；Figure 11 最清楚地把 Tuna–SGLD 的 wall-clock 优势与 MALA 的 iteration 优势拆开；Appendix Table 4/5/7 使 acceptance-rate 与高维稳健性可复核。
- **失败或低价值模式**：缺少公开 plotting/table layout source，使数值可复核但视觉不能精确重建；Figure 4、6、10、11 和 Table 6 caption 过短，需来回正文才能解释实验条件；所有曲线和表格都不给 run-level uncertainty；Best 聚合压缩了 tuning heterogeneity；Figure 10–12 在局部把颜色改作 step size/minibatch 语义，跨图复用时容易误认；没有组件删除式 ablation，无法单独把效率增益归因于某个 auxiliary variable。
- **一句话视觉策略**：用统一方法色和 acceptance-rate 分面把 two-auxiliary-variable 算法的效率、正确性与调参边界串成“time/iteration 曲线 → ESS/s 表 → KS check → scale/task sensitivity”证据链，主文给 Best headline，附录给完整条件展开。
