## Final judgment

- **most_reusable_patterns**：
  - 用组件对照示意图先说明方法删减，再用 evaluator × metric 小倍图连接到主结果。
  - 用固定基线虚线和目标方法 marker 轨迹隔离 margin 对优化动态的作用。
  - 为 scatter 附上 exact numeric tables，并用 template/judge slice、safe-safe pair 和 qualitative response 逐层检查 evaluator confounding。
  - 把安全收益与 over-refusal、网络组件、训练时间和 supervision 放入同一证据系统，而不只报告 harmless ratio。
- **highest_value_objects**：
  - Figure 2：四面板双 evaluator 主比较同时承载 helpfulness、harmlessness 和 ratio，且 caption 定义阈值。
  - Figure 3：把 ∆ 的机制预测、基线水平和 ∆=50 有限训练退化放在一张图内。
  - Table 3：将 100% harmless ratio 与 12.4% over-refusal 置于 XSTest 的同一决策面。
  - Table 10、Table 23 与 Table 12：分别暴露 evaluator overoptimization、safe-safe helpfulness 和安全 failure direction。
- **failure_patterns**：
  - 主图/主表多为聚合点估计，缺少重复、区间、judge agreement，难以区分稳健差异与 evaluator noise。
  - Table 12 每个 baseline 的四类计数合计 798，却没有与约 3,000 test entries 对齐的 subset/denominator 说明。
  - Figure 3 的 caption 未说明图中额外出现 ∆=50；Table 5–7 只覆盖 ∆=0–10，跨对象参数范围不一致。
  - 长 qualitative tables 以约 6 pt response 文字填满页面，且颜色图例和多方法名称在灰度下不够冗余。
- **one_sentence_visual_strategy**：论文采用“组件删减示意 → 双 evaluator 主散点 → ∆ 机制曲线 → 规模/人评/过度拒答表 → 模板、safe-safe 和文本失败附录”的证据链，以 hard safety guarantee 的收益与保守性成本同时可视化。
