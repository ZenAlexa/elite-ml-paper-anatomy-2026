## 跨对象关系与最终判断

### 证据链

论文的视觉叙事是：Figure 1 给出梯度流/WLM 的理论动机，Figure 2 把 least action 连接到 density/marginal rollout，Figure 3 给 Proposition 2.4 的稳定/不稳定机制图；Tables 1–3 和 Figure 4 依次覆盖 GF、Ocean、EB，Figure 5/Table 4 用 Boids 作为最强 emergent-dynamics 例子。附录 Table 5 给成本，Table 6 展开 Table 1，Figure 6–7 解释 learned friction，Figure 8 做 mini-batch cost/performance ablation，Table 7 与 Figure 9 检查初速度和未见初始分布。理论对象→可训练潜能/摩擦→W₁/qualitative rollout 的映射清楚，但 W₁ 与定性图仍主要是 marginal-level evidence。

### Caption 与表头系统

Figure captions 多以“对象 + 数据设置 + 视觉角色”组织；Figure 2、5、9 用 lead title，Figure 4 明确 marker 语义，Figure 5 明确训练/预测时间和采样数。Figure 7 的 band 和 Figure 8 的 error bar 没有在 caption 中完整定义，是最明显的 caption 缺口。表头稳定使用 `Train/Forecast(or Test) W₁`、paired/unpaired 或任务时间分组；Table 1/6 的 `Forecast`/`Test` 术语轻微不一致，Table 2 以 row group 表达 reference-process 公平性，Table 5 把成本列与规模列放在一起。

### 复用价值最高的对象

1. **Figure 2**：把抽象 least action、density-space path 和可观测 Boids rollout 放进一个方法接口，是理论论文最值得复制的“机制→观测”桥。
2. **Figure 5 + Table 4**：同一行列顺序同步定性时序和 train/forecast W₁，主张与指标互相校验。
3. **Table 2**：把 reference-process 是否可用显式分组，避免将不对称 baseline 当成同一公平比较。
4. **Table 6 + Figure 6**：聚合主表之后按 SDE 展开并用 learned friction 解释异质性，形成 mechanism audit。
5. **Figure 8 + Table 5**：将性能、运行时间、mini-batch 和硬件预算连接成 efficiency/cost 证据。

### 主要失败模式与边界

- Figure 7 的阴影没有统计定义，Figure 8 的 error bars 只写“3 random seeds”而未说明 SE/SD；若将它们作为不确定性结论，证据不足。
- 大型 qualitative grids（Figures 5、9）缺少 cell 轴、单位、样本/坐标范围和显式 train/forecast 标记，适合形状比较，不适合个体轨迹或严格量化。
- 汇总 Table 1 隐藏逐 SDE 差异，Table 6 虽补充但 baseline 条件和外部转录值仍需附录/引用；Table 2/3 的部分值来自先前工作，不能和自算值无条件视为同一 provenance。
- Learned γ 只能作为模型内部 dissipation parameter 的观察，Figures 6–7 没有独立 calibration；最小 γ 的 collapse 现象说明参数解释存在 failure case。
- PDF 没有 figure-specific source 或 `.tex`/Notebook；`guanton/WLM` 的共享 helper 可以复用风格而不能证明每个 PDF 对象可重建。W₁ 和 marginal rollout 不能单独闭合 broad identifiability、causal path 或 universality claim；Figure 9 只给定性未见 mixture 泛化。

### 一句话视觉策略

用 Figure 1–3 将“从梯度流到可学习的 Wasserstein 二阶 mechanics”的理论转成直接可见的路径与初值条件，再用同一套 train/forecast marginal 语法把 W₁ 主表、机制曲线、成本消融和未见分布定性 grid 串成一条证据链。
