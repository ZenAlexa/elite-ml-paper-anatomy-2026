### Figure 1（p.3，正文，method）

- **设计与布局**：近页宽的三段横向 pipeline。左侧为 Local/Global 两行视角，原图/扩散图经过 Smoothing、Filter 与两套 Unshared MLP，形成 `Embeddings Z^l`/`Z^g`；中间为 Compactness Learning，包含 Low-rank Subspace Training 的 E/M 循环、`γ(y_jk)`、更新 `Λ`、Feature Reconstruction 与 `Z̃`；右侧为 Consistency Learning，两组 Anchor 相似度直方图连接到 `Consistency Loss L`。实线箭头表示流向，蓝色/黑色虚线框和阴影区分阶段。
- **图型与绘图语法**：`pipeline + architecture + conceptual_diagram`；无坐标轴、无数据图例或不确定性；左→右为处理顺序，上下为 local/global facet，三块内部以节点、箭头、公式和小网络图作直接标注。最终 PDF 以栅格图呈现，公开 `framework.png` 是匹配的源图。
- **字体与颜色**：图内为 Times 风格 roman、数学变量和粗体阶段标题；约 5–14 pt 为渲染估计。Local 面板使用浅粉 `#FCF1EF`，Compactness 为灰 `#D3D9D8`，Consistency 为浅黄 `#FCF1CF`，蓝色 `#93A9D7`、绿色 `#83B55A`、黄色 `#F5C944` 与深蓝墨线承担视角/状态区分。颜色与标签、位置共同编码，但灰度会损失支路区分。
- **Caption/header**：`Figure 1: Illustration of the proposed framework CoCo.`（8 词）；仅有 title，无粗体结论、设置、编码键、不确定性或 appendix pointer。图内标签使阶段可读，但 caption 单独不自足。
- **数据表达**：概念流程，没有样本数、聚合、统计量、误差或失败值；`K`、`M`、`α` 等只作为接口变量出现。
- **证据关系**：Introduction 的“局部消息传递无法捕获长程关系”和“冗余/噪声损害表示” → §2.1 local/global view 与 Eq.1–2 → §2.2 GMM/EM low-rank 与 Eq.3–5 → §2.3 anchor distribution consistency 与 Eq.6–7 → Table 1、Figure 2、Table 2 的实验验证。
- **优点**：单图把两视角、低秩模块和一致性损失置于同一条可复述链条；内部箭头和公式接口与正文 Eq.1–7 对齐；Local/Global 与三阶段位置编码互补。
- **不足**：模块内部文字很小且没有显式输入/输出张量尺寸；阴影和颜色承担大量层级语义；caption 只是命名，不能独立解释 EM 循环或 anchor 分布。
- **可复用模式**：对多组件方法采用“并行视角 → 共享压缩/重建 → 关系损失”的三段总图；每个箭头旁放公式接口，并在图注中补充训练状态与输出定义。

1. **主叙事**：Figure 1 先把 Introduction 的两个缺口压成 local/global → compactness → consistency；Table 1 负责 overall clustering headline；Figure 2 与 Table 2 拆组件和 loss；Figure 3 提供 representation qualitative slice；Figure 4/Appendix Figure 6 展开超参；Table 3–5 承担 noise/graph-type robustness；Figure 5/Table 6 并列实测资源；Table 7 测 downstream transfer；Appendix Table 8–10、Figure 7 补理论复杂度、完整 loss、完整 sensitivity 与 filter robustness。
2. **方法/结果/消融链接** — Figure 1 的三段模块分别被 Figure 2 的 M1–M5、Table 2/10 的 MSE/InfoNCE/Consistency 和 Figure 4/6 的 K/M/α 接住；但“去除 redundancy/noise”和“捕获 long-range”仍主要由最终性能、noisy BAT 和定性 t-SNE 间接支撑，缺少中间表示量的直接 measurement。
3. **正文—附录链接**：主文保留一张 overview、主表和选择性的三数据集/两数据集诊断；附录按 A–K 提供证明、算法、复杂度、扩展 baseline、全数据集 loss/sensitivity、filter robustness 与 related work。Table 2→Table 10、Figure 4→Figure 6 是最清晰的同构扩展。

## 最终判断

- **最可复用模式**：
  1. 用一幅三段式架构图把并行视角、共享压缩和关系损失连成可复述接口。
  2. 用同构的主表/附录扩展表与主文/附录 loss 表保持数据集、指标和精度不变。
  3. 用“组件 grouped bars + surrogate-loss table + sensitivity small multiples”把模块删除、替代损失和超参边界分开呈现。
  4. 用 ACC–runtime/memory scatter 与 EM-time table 让质量/资源成为同一决策面。
