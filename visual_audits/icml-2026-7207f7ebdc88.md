- **Caption（122 words）**：Figure 3. Illustration of the softened ternarization (ST) process. For a linear layer, taking its pre-trained weights W as the initialization point (t = 0), ST employs a learnable two-stage relay of differentiable ternarization and hard ternarization to ensure stable convergence. In the first stage, ST produces an asymptotic ternary output by performing continuous quantization based on the transformed weights Ŵ. ## 最终判断

**最可复用模式**
- 用 Figure 1 的单一 pipeline 把可学习参数、离散算子和部署重构连成方法接口。
- 用 Figure 2/ C–K 的固定蓝橙绿语义和散点点云保留误差离群与跨层/专家异质性。
- 用 Table 2/3 将 calibration/training token 预算和五任务准确率置于同一决策面。
- 用 Tables 5–12 的 row-group 参数扫描、默认下划线和最佳粗体形成可复用消融系统。
- 用 Figure B 的重复 sliding-window 小倍图展示机制是否跨窗口成立。

**最高价值对象**
- Figure 1（p.3）：最清楚地定义 LM、ST、T 与部署边界。
- Table 1（p.6）：十模型跨规模主结果基准。
- Table 2（p.6）：把约 1M calibration tokens 与 QAT 的 10B–1T tokens 直接并列。
- Table 13（p.9）：把低比特表示连接到真实 CPU/GPU 内存和吞吐。
- Table B（p.15）：显式保留数学/代码任务失败边界，避免主结果泛化过度。

**失败模式**
- Figure 2 与 Figures C–K 以颜色作为唯一方法编码，灰度和色觉差异下不稳健。
- 密集散点图未给样本量、误差定义或汇总统计，且跨面板 y 轴范围不统一。
- 多张表仅报告点估计；没有重复、方差或 profiling variability。
- Table B 缺少模型身份，Table A 缺少配置覆盖说明；这些缺口削弱复现。
- Table 13 的 CPU|GPU 竖线复合列以及 ✓ 组件矩阵增加无障碍和机器读取成本。

**一句话视觉策略**：论文以方法接口图串起可学习调制与软化三值化，再用统一颜色的误差点云、紧凑性能/成本表和附录消融小倍图，把“低成本、跨规模、但复杂推理仍失败”的证据边界压缩到一条可追踪视觉叙事。
