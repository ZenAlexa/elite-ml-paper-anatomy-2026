## 最终判断

### 最可复用模式

- Figure 1/21 的层级 benchmark map → Figure 3–5 的构建/标准接口 → Table 3/9 的聚合与类别分解，形成从覆盖范围到可判定结果的视觉链。
- Figure 4 使用同一场景和相同帧位比较三种 prompt，Table 4 再把 prompt 变体转成跨模型数字对照。
- Figures 8–19 固定五行×四帧 qualitative plate，Figures 20 与 Tables 16–17 将复杂/突变失败连接到配对分母。
- Tables 2/5/6 把 evaluator baseline、CAP 组件和 precision/recall 分层排列，适合复用到自动评估器审计。

### 最高价值对象

- Figure 1：一页内定义三层级、十类、子类、场景和 prompt 变化，是 benchmark scope 的最短入口。
- Figure 6 + Table 2：用 matched frame/text examples 和 CAP ablation 共同支撑 evaluator mechanism。
- Table 3：主文跨模型、跨物理层级的核心比较面，尽管 caption 模型数有错误。
- Table 9 + Figure 21：把总体结果还原到十类并连接到具体数据结构。
- Figures 8–20 + Tables 13/16/17：将失败模式从模型样本、条件分母和 paired probes 三个层级呈现。

### 失败模式

- 除计数/比例之外几乎所有结果都是点估计，没有区间、重复、inter-rater agreement 或 paired significance；图注也不定义抽样不确定性。
- Figure 2/3/6、Figure 1/21 与 qualitative plates 混用粉彩、自然像素、红框和不同字体，颜色语义不能跨对象迁移且灰度不稳。
- 主/附录表格 caption 存在模型数量错误（Table 3）、语法问题（Table 4/6）和极短标题（Tables 10–14），降低脱离正文后的自包含性。
- Figures 8–20 是选择性失败示例，Table 13 还是失败条件分母；若不回到正文，读者容易把诊断样本误读为总体率。
- 作者仓库提供评估/抽样/数据文件但没有论文图表源，限制了颜色、字号、精确几何和数值 source_exact 复核。

**一句话视觉策略**：PhyWorldBench 用“层级覆盖图 → human-in-the-loop 与 CAP 接口 → 跨模型/提示的比例表 → 失败条带与配对边界”把物理真实性评测从数据结构推进到诊断，但以选择性 raster 案例、低不确定性披露和缺少图表源换取高密度覆盖。
