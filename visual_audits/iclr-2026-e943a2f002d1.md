## 全局版式观察

- 正文、caption 和表格主要使用 Computer Modern Roman 及数学字体；`pdffonts` 还显示图内或外部嵌入内容使用 Calibri、TrebuchetMS、CambriaMath、Times New Roman、Abadi 等对象。栅格图内部的 sans-serif/office-like 字体不能由 PDF font object 可靠反推源字体，因此 Figures 的 typography 均标为 `rendered_estimate`；表格主体的 CMR/数学字体可由 PDF objects 确认。
- 定量图使用高饱和蓝、绿、橙、红和多阶蓝色；Figure 5/6 的主线颜色接近 Matplotlib/基础 CSS `#0000FF`、`#008000`、`#FFA500`、`#FF0000`，Figure 5(b) 还用六档蓝色区分数据量。架构和流程图使用蓝、绿、桃色、灰色的柔和块面，Figure 7 使用按 token 位置变化的彩色矩阵。颜色通常承担方法或模态身份，只有部分图同时用 marker/线型提供冗余，整体不保证灰度安全。
