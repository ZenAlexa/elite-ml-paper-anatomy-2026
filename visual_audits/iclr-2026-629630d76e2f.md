## 3. 全局视觉系统

正文的主视觉顺序是「机制失败/修复（Figure 1）→ dataset-defined image measure（Figure 2）→ 全域决策表（Table 1）→ 计算代价（Table 2）」。附录 B 把 Table 1 的聚合点展开成曲线（Figures 3–4）、定性样例（Figures 5–6）、archive heatmap（Figure 7）和 discount model 过程（Figure 8），附录 D 再用 Figures 9–11 检验学习率、empty points 和 restart rule，附录 E 的 Figure 12 回到 measure distortion 的分布机制。

量化曲线由 `analysis/src/analysis/figures.py::comparison` / `ablation_plot` 生成，采用 `simple.mplstyle`：Times New Roman、Computer Modern math、12 pt 基准字号、浅灰网格、1.25–1.5 pt 线宽；算法用 `COLORBLIND_REORDERED` 的蓝/橙/黄/绿/粉和不同 marker 冗余编码。archive 类图由 `src/evaluation.py::plot_discount_archive` 或 `analysis/src/analysis/supplemental.py` 生成，使用 `magma` 风格的连续色阶并将 heatmap mesh rasterize；`src/visualize.py` 明确定义 `cornflowerblue` emitter circles 和 `yellow` empty-point triangles。表格由 LaTeX `booktabs` 规则排版，主要使用 Nimbus Roman/Computer Modern math，数值通常保留两位小数；最佳项通过粗体，Table 7 以及 Figures 9–10 内嵌结果表另用黄色 cell highlight。

视觉一致性总体较强：quantitative panels 共用 Iterations/`α`/`n_empty` 横轴与 QD Score/Coverage 行结构，所有图表都把 DMS 与相同的 baseline 集合放到可比坐标中。主要代价是高信息密度：Figure 3/4 将 16/8 个小图与重复末值表塞入一页，Figures 8/11 的图例与 colorbar 需要依赖 caption，Table 4/5 的旋转表头和符号矩阵在普通缩放下阅读成本高。

## 4. 逐对象审计

### Figure 1（p.2，正文 theory）

- **版式/类型/复杂度**：`page_width`，三面板横排；(a) 是 CMA-MAE step-function 示意，(b) 是 DMS smooth discount 示意，(c) 是 2D/10D LP 的 unique cells 折线。类型为 `conceptual_diagram`、`line`；复杂度 3/5（3 panels、2 条数据系列和多处数学标注）。
- **绘图语法**：a/b 没有数值坐标，横向 `m(θ)` 只表达 measure 方向；c 的 x 为 0–10,000 `Iterations`、y 为 `Unique Cells`，线性轴、可见 x/y 灰网格，右上共享图例。a/b 用虚线 cell 边界和水平 objective，c 用圆点/菱形区分 2D/10D。PDF 为矢量对象，线宽约 1.5 pt，未显示不确定性或 hatching。
- **编码与颜色**：蓝色 `#0173B2` 表示 `f_A`/DMS 曲线，橙色 `#DE8F05` 表示 arrows/10D series，黑色表示 objective/θ，灰色表示 cells 与 guides；颜色之外还有面板位置、虚线、圆点/菱形和 `∆_1/∆_2` 标注，灰度下基本可辨。
- **caption**：`Figure 1: (a): One failure mode of CMA-MAE. On a flat objective f, solutions θ1 and θ2 fall in the same archive cell based on their measures, resulting in identical discount values from the discount function fA. (b): In our proposed DMS, the discount model provides a smooth discount function that assigns distinct discount values to θ1 and θ2, showing that θ2 has greater archive improvement than θ1 (∆2 > ∆1) and thus providing a stronger signal to guide search. (c): Number of unique cells where solutions sampled by CMA-MAE land in two benchmarks (mean over 20 trials; Sec. 4).`（100 词）。动作：title/setup/encoding_key/comparison/main_finding/appendix_pointer；非粗体；说明 failure、repair、指标和重复数，基本自洽，但 `CMA-MAE`/`DMS` 缩写和 `Sec. 4` 仍需正文背景。
- **数据与统计**：c 为两个 LP benchmark 的 20-trial mean unique cells；a/b 是机制示意，不是实测曲线。图把 cell collision 直接连接到 `∆(θ)=f(θ)-f_A(m(θ))` 的排序信号，未提供误差带。
- **证据关系**：引言的 high-dimensional distortion→Figure 1a 的离散 collision→Figure 1b 的 smooth discount 修复→Sec.5 Eq. (1)/Algorithm 1→Figure 1c 的 unique-cell 诊断→Figures 3/7/8 的性能与空间机制证据。
- **优点**：把失败、替代机制和可观测诊断放在同一横向阅读路径；`θ_1/θ_2`、cell 边界、`∆_2>∆_1` 和两种 marker 形成冗余解释。
- **弱点**：a/b 的曲线是概念形状，没有数值尺度或实际 model error；c 只展示 unique cells，不直接展示 archive objective 或 coverage。
- **可复用模式**：先并排画出离散失败与连续修复，再用一个紧邻的小型实测 panel 给出可证伪的 representation diagnostic。

### Table 1（p.8，正文 results）

- **版式/结构**：`page_width`；5 个算法行、25 列（左侧 algorithm + 12 domain × QD/Cov），两层语义表头，domain 分成三组横向块；无 row group。`booktabs` 风格，只有横向规则，没有竖线。
- **表头/精度**：domain 名称在第一层，`QD`/`Cov` 在第二层；caption 定义两个缩写但不写 trial 数。QD 与 percentage 均保留两位小数；无误差项。
- **强调与颜色**：最佳 cell 用粗体；其余为黑白，`grayscale_safe=true`。没有 underline、箭头或 second-best 标记。
- **caption**：`Table 1: Mean QD Score (“QD”) and Coverage (“Cov”) for each algorithm in each domain.`（15 词）。动作：title/abbreviation_definition/comparison；非粗体；未在 caption 直接陈述哪个算法获胜，也未写 20/5 trials，因此 `self_contained=false`。
- **数据与统计**：12 个 domain × 5 个算法；报告 mean QD Score（archive objective 之和）与 Coverage（有 solution 的 cell 百分比），benchmark 20 trials、QDDM 5 trials 的 trial 数在 p.9 正文补充。表把性能与 domain 条件置于同一决策面，但不包含误差、显著性、成本或失败原因。
- **证据关系**：p.8 的「DMS 应在两个因变量上超过 baseline」→Table 1 全域点估计→Appendix Figures 3/4 的 learning curves 与 Tables 3–5 的 omnibus/pairwise 统计→p.9 对 Arm coverage、TA (MNIST) QD、LSI 等例外的限定。
- **优点**：同一表覆盖 12 个 domain 和两项决策指标，DMS 与 baseline 关系可快速扫描；粗体突出每个 domain/metric 的局部最优。
- **弱点**：没有误差或 trial 数，不能独立判断变异；`Cov` 缩写、DDS 在 QDDM 中缺失的原因和显著性都依赖正文；跨 domain 的 QD 数值不可直接比较。
- **可复用模式**：主表按 domain 分组、每组固定「总体质量 + 空间覆盖」两列，并在表头直接展开缩写、单位和重复数。

- **可复用模式**：对组件必要性提供同构的 positive/negative process visualization，让反事实只改变一个配置。

### Figure 12（p.36，附录 E.1 theory/mechanism）

- **版式/类型/复杂度**：`inset`；单面板 grayscale `line`，上方为 measure function 公式，下方为 density plot；4 条曲线（`r=1,2,5,10`），复杂度 2/5。图本身为矢量 PDF，细线型区分曲线。
- **绘图语法**：x 为 `m(θ)` 0–50、y 为 Density，均线性；无 grid；右上 legend，solid/dotted/dashed/dash-dot 四种 line styles 表示 r；无 marker、hatching、uncertainty/reference line，线宽约 1.5 pt。
- **颜色**：grayscale，主要 `#000000` 和 `#FFFFFF`；语义完全由 line style/legend 承担，灰度安全。
- **caption**：`Figure 12: Irwin-Hall distribution when summing r uniformly random variables with range [−5.12, 5.12].`（14 词）。动作：title/setup/encoding_key；非粗体；定义 r 和范围但没有在 caption 直接陈述 higher-r distortion，`self_contained=true`。
- **数据与统计**：从 `[−5.12,5.12]` 均匀变量按 block size `r` 求和的理论 density；不是实验样本。曲线说明 r 增大使质量集中到 measure space 中部、极端值概率降低。
- **证据关系**：Sec.4 distortion claim→Figure 12 的 Irwin–Hall density→Figure 1c unique-cell diagnosis→LP benchmark 的 dimension/coverage curves（Figures 3/7、Table 1）→DMS smooth discount motivation。
- **优点**：用 line style 而非颜色适合理论附录和打印；公式、范围、density plot 同页，解释从 measure function 到 distortion 的桥接短。
- **弱点**：caption 过短，读者需读后文才能知道曲线如何支持 distortion；`r=1` 在图上是边界分布，视觉上与其它峰形差异大但没有额外注释。
- **可复用模式**：把理论分布、关键参数的 line-style legend 和正文引用放在同一附录 panel，为实证机制图提供可计算的先验解释。

## 5. 对象间系统判断

- **视觉叙事**：Figure 1 先把离散 archive 的 failure 变成可见的 cell collision，Figure 2 把 QDDM 的 dataset-defined measure 变成 paired images；Table 1/2 给出 performance/cost 决策面，Figures 3/4 展开 trajectories，Figures 7/8 将结果连接回 measure geometry 和 discount model，Figures 9–11 检验可调组件与 failure，Figure 12 提供 distortion 的分布解释。主线完整，但 Figure 1/2 到 quantitative source 的过渡依赖正文文字，且 Table 1 的广泛 “outperforms” 需要 p.9 的逐 domain 限定。
- **Caption system**：caption 统一以 `Figure/Table n:` 开始，Figure caption 多用「对象定义→实验设置→颜色/位置编码→结论」顺序；Figures 3/4/9/10 只给 aggregate/uncertainty，具体 domain 与 marker 解释留在图面；Figures 7/8/11 的长 caption 承担机制与主发现。Figure 9/10/7 的“highlighted lines”或“standard error may not be visible”对视觉事实的描述不够精确。
- **Table header system**：主结果表按 domain→metric 两层头，统计 pairwise 表按 domain→algorithm 旋转头，hyperparameter 表按 domain 横向头。这个系统让 Table 1、Figures 3/4、Tables 4/5 的 domain 顺序可对齐；代价是 Table 4/5/6 在单页宽度内出现极小旋转字和大量空白/符号。
- **Method–result–ablation link**：Algorithm 1 与 Table 6 定义训练/搜索配置；Table 1/2 量化结果和 cost；Figures 9–10/ Table 7 改动 `α`、`n_empty`、restart；Figure 8/11 将 empty-point 机制正反例可视化。Figure 11 是最强的 method→failure→ablation 闭环，Figure 9 的 alpha 结论则更多依赖末值表。
- **正文–附录 link**：正文 p.9 明确指向 Appendix B 的 performance/error/heatmap/discount visuals，p.8/p.11 指向 C/F hyperparameters/implementation，p.9 指向 D ablation，p.7 指向 E domains。附录调用清晰，但统计细节、完整 trajectories、默认参数和 QDDM objective 不能只靠正文复现。
- **Typography consistency**：论文正文和表格以 Nimbus Roman/Computer Modern math 为 PDF 事实，定量 plot source 使用 Times New Roman + Computer Modern math；视觉上同属 serif lineage。源样式字号在生成阶段为 12 pt（small archive panels 5–7 pt），最终论文缩放后 Figures 3/4/9/10 和 Table 4/5 的最小字偏小。
- **Color consistency**：algorithm line figures 固定五色并以 marker 冗余；archive figures 固定 magma objective scale 和 blue/yellow point markers；qualitative grids 用黑白图像；Table 7/ablation summary 用黄色 highlight。语义稳定，但 algorithm colors 与 heatmap colors 不是同一层含义，Figure 8/11 的混合 colorbar 需要 caption 明确区分。

## 6. 最终判断

### 最可复用模式

1. **机制三联图**：用 Figure 1 的「离散 failure→连续 repair→可观测 diagnostic」结构，把表示选择与可证伪后果放在同一对象。
2. **固定 domain 顺序**：Table 1、Figures 3/4、Tables 4/5、Table 6 和 Figures 9/10 都复用 domain/algorithm 顺序，降低跨对象核对成本。
3. **endpoint + trajectory + spatial state**：Table 1 给终点，Figures 3/4 给收敛轨迹，Figures 7/8 给 archive/discount 的空间状态；三种粒度共同支撑结果而不是只重复一个均值。
4. **正反机制对照**：Figure 8 与 Figure 11 只改变 empty-point 训练条件，直接展示组件存在/缺失的空间后果，再由 Figure 10 给出 aggregate drop。
5. **配置与主结果绑定**：Table 6 列全量参数，Figures 9/10/Table 7 用黄色/粗体标回 Table 1 的默认行，形成复现入口。

### 最高价值对象

- **Figure 1**：最有效地把 high-dimensional distortion、CMA-MAE collision 和 DMS smooth discount 连接成方法动机。
- **Table 1**：覆盖 12 个 domain 的 QD/Coverage 决策面，是所有后续 curves/statistics/ablation 的索引。
- **Figure 8 + Figure 11**：正向训练过程与 no-empty-points 反例构成最清晰的机制闭环。
- **Figure 7**：把 coverage 与 objective value 的空间 trade-off 变成可见的 archive state。
- **Figures 3/4**：为主表提供收敛速度、平台和 SEM 的完整补充，并保留 Arm/TA/LSI 的边界行为。

### 失败模式

- 主文/图注的广泛 `outperforms` 不能替代逐 domain 统计限定：Arm coverage 由 DDS 更高，TA (MNIST) 与 CMA-MAE 的 QD Score 无显著差异，LSI 与 MAP-Elites 无显著差异，QDDM 还缺 DDS。
- 大型复合图重复嵌入末值表和 legend，Figures 3/4/9/10 的视觉密度使小字号、误差带和科学记号难以快速读取。
- Figure 9/10/Table 7 将黄色 cell highlight 描述为 “Highlighted lines”，图注语义与实际视觉对象不完全一致。
- Table 4/5 的 `>`/`<`/`∅`/`−` 没在 caption 定义，也没有 pairwise 数值 effect/p-value，显著性方向可追踪但比较强度不可复核。
- qualitative Figures 2/5/6 只给正向样例，不给抽样规则、失败样例、held-out measure 控制或独立质量评估；Figure 2 的原始拼图资产也未在作者仓库树中出现。
- Table 1/2 把关键 trial 数、DDS 缺失原因和运行条件分散到正文/附录，读者不能仅凭表格复建不确定性或成本边界。

**一句话视觉策略**：论文用「机制示意→dataset-defined qualitative pairing→全域 endpoint/cost→trajectory 与 spatial archive→组件消融和反例」的 serif、低装饰、色彩语义稳定的视觉链路，把 DMS 的表示修复主张连接到性能、代价和失败边界。
