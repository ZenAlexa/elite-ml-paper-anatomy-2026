## 最终判断

### 最可复用模式
- 用 Figure 1 的 matched baseline/proposed paths 先固定训练阶段接口，再以 Figure 2/7 的数值 similarity matrix 把抽象“bridge”变成可检查的 measurement layer。
- 用 Table 2/8 的 target-group × mixture × model-size 表面同时报告 in-domain 与 C4 retention，并在主表中明确 baseline-relative Δ 和方向。
- 用 Figure 3 的 shared-panel scatter（颜色=SFT、形状=midtrain）配合 Table 3 的 direct alternative 和 Figure 4 的 timing×weight grid，依次覆盖关联、替代解释和边界条件。
- 以 Figure 6/9–13 固定四状态 CKA small-multiple 模板跨规模/探针扩展，但应补统一色标、panel key 与不确定性。

### 最高价值对象
- Table 2：1B 四目标、五混合物和两端点的主决策面。
- Figure 3：把 PA measurement 与跨模型 association 放在同一可比较坐标中。
- Table 3 + Figure 4：分别检验 full-specialized alternative 与 timing×weight interaction。
- Figure 6：正文唯一 representation-level exemplar，并由 Figures 9–13 扩展。

### 失败模式与证据边界
- 理论核心 gradient alignment 只在 Figure 1 中以 schematic 表示，实验使用 token PA 与 CKA proxy，不能把相关/相似度写成已验证的优化中介。
- Figure 3 的 70M Pearson r 在 §5.1 正文（0.869）与 panel（0.521）不一致，且缺少 pair denominator/subset 说明。
- Table 3 的 continued-pretraining 与 default midtraining 起点因数据可用性不同，替代解释存在 timing confound。
- Tables 2/3/8 只有 5-seed mean；Figure 5 band 未定义，所有对象都缺少可审计的 seed dispersion。
- CKA panels 没有 colorbar/common normalization，410M raster 矩阵的 cell labels 与 Figure 5 的小图在打印缩放下阅读成本高。

**一句话视觉策略**：论文用“几何示意 → token-similarity diagnostic → paired loss table/scatter → continued-pretraining 对照与 timing×weight 边界 → CKA representation proxy”的连续视觉链把 midtraining 叙述为 distributional bridge，但其机制强度仍受 PA/CKA proxy、统计不确定性缺失和一处相关系数不一致限制。
