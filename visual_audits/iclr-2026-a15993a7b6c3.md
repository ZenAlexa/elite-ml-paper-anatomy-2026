## 跨对象证据关系与最终判断

### 视觉证据链

Figure 1 先给端到端输入→hybrid context→LLM/diffusion→speech 的方法入口；Figure 2 和 Figure 4 用 separate/coupled tokenizer pipeline 将 representation 机制拆开。Table 1–3 依次覆盖 podcast quality、duration/speaker-count capability 与 tokenizer reconstruction；Figure 3 暴露 CFG/steps 的 WER–SIM-O trade-off。附录 Table 4–10 补齐工具、tokenizer ablation、短 utterance、跨数据集重构、RTF、训练配置和 dataset denominator；Figure 5/6 与 Table 11 使主观协议和 SIM-O mismatch 可复核。整体叙事是“架构图→tokenizer 机制→能力矩阵→质量/效率对照→附录反事实与解释”，但 90 min、state-of-the-art 和环境纹理因果解释超出已展示的直接证据。

### Caption 与表头系统

Figure captions 普遍采用“对象标题＋简短机制/设置”，Figure 1–4 有流程或比较说明，Figure 5 极短，Figure 6 有 main finding 但 panel label 错位。Table 1–3 的 caption 相对完整，Table 2 的失败/子集符号和 Table 3 的指标方向最可复用；Table 4、6、9、Figure 5 缺少设置与分母。表头稳定地用 `Subjective/Objective`、dataset group、speaker count、inference cost 等二级分组；主表与附录多数保持 WER/SIM-O、PESQ/STOI/UTMOS 的列语法，但 Table 11 的 six dimensions 与主文 three-dimension MOS protocol 需要额外说明。

### 最可复用对象

1. **Table 2**：以 duration row groups × speaker-count columns × overall 聚合构成 capability matrix，并把 tokenizer/model-size 对照放入同一阅读坐标。
2. **Figure 2 + Figure 4**：以同构 pipeline 对照 separate 与 shared latent，将机制反事实直接连接到 Table 5/7 的 downstream/reconstruction 结果。
3. **Figure 3**：两个目标使用同一个 3×4 条件网格，cell 数字与色阶共同表达多目标 trade-off。
4. **Table 1/11**：主观指标和客观指标同表，主动保留 CosyVoice/SIM-O 与 human Similarity 的冲突。
5. **Table 8 + Table 9**：将推理成本和训练配置作为可复现边界，而不是只报告 headline 质量。

### 主要失败模式

- capability wording 超出 evidence envelope：Figure 1/摘要/结论写 `90 min`，Table 2 与 Table 10 的数据最多覆盖 30 min。
- 主表和附录多为单次 point estimates；MOS 有 mean±SD，但没有 participant-level/raw distribution、seed aggregation 或显著性检验。
- MoonCast 的 crash/retry/subset 分母需要依赖 Table 2 caption；Higgs 的 parallel chunks 与 VIBEVOICE strict streaming 不是完全同协议。
- Figure 5 截图和 Figure 6 montage 缺少关键轴、样本/处理元数据；Figure 6 还存在 `(a),(b),(b)` 与 caption `(c)/(b)` 错位。
- Table 11 的六维第一阶段与正文三维 MOS 表述不一致，虽然结果表和 rubric 保留了冲突，但 caption 没有解释 protocol 变体。
- GitHub 只有与项目相关的后续 rendered assets，没有 PDF 对象的 exact `.tex`/plot script；不能凭 `VibeVoice.jpg` 等 README 图反推 proceedings 的图表源码。

### 一句话视觉策略

用页宽 Figure 1 建立 VibeVoice 的长篇多说话人生成管线，以 Figure 2/4 的 tokenizer 机制对照和 Figure 3 的 WER–SIM-O 条件热图连接到 Table 1–3 的能力/质量主结果，再用附录的分母、成本、评测界面、第一阶段冲突和频谱 montage 约束主张边界。
