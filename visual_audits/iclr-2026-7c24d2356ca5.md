- visual_narrative；Figure 1 先把 offline MOO 重述为 conditional sampling；Figure 2 给出 reference-direction conditioning mechanism；Table 1 是跨五类任务的 headline rank，Table 2 是组件消融，Figure 3–7 依次覆盖 guidance、dataset quality/reweighting、noise/extrapolation、denoising budget；Figures 8–9 以 MO-Hopper 与 RE21 的定性 failure/reconstruction 收束，Tables 9–32 提供三个 percentile 的逐任务底表。
- caption_system；Figure captions 使用 “Figure n:” 加标题、设置和结论，主结果与敏感性图通常直接陈述发现；Figure 2 偏机制说明，Figure 8/9 明确定义 marker 角色。Table 1–8 的 caption 说明指标、方向、比较和高亮，Table 9–32 仅给出 percentile/domain 标题，统计 spread、任务定义和 N/A 语义留给正文或表体。
- table_header_system；主结果和消融表采用 Method/Variant 加任务列的单层表头；Table 3 用两组 Parameter/Value(s) 并列训练与 EDM，Table 4 用 Dataset Info/Sampling Time 行组，Table 8 用 No. objectives 的二层列组。长附录表保持 Method-first、任务横向、三种 percentile 分卷。
- method_result_ablation_link；Figure 1/2 是方法接口与机制；Table 2、Figure 3、Figure 5–7 和 Tables 5–7 将 reweighting、CFG、noise、J、direction vectors、sampler 与 denoising steps 逐一拆解；Table 1 和 Tables 9–32 负责综合比较；Figures 8–9 解释 MORL/RE21 的定性成功与失败边界。
- main_appendix_link；正文 Figure 1–3 与 Tables 1–2 形成主论证；Appendix A.1–A.8 的 Figures 4–9 和 Tables 3–8 回接每个设计选择；Appendix A.11–A.13 Tables 9–32 由 §5.3 的 Table 1 调用，作为 100/75/50 percentile 的逐任务可复核底表。Algorithm 1 和 Algorithm 2 也已逐页检查，但因 schema 仅建模 Figure/Table，未放入 figures/tables 数组。
- typography_consistency；正文和 captions 的 serif 字体与数学符号统一，图内 axes 使用 sans/Times New Roman 风格；表格 body/header 约 6.4–8 pt，长表在 200 dpi 仍可读但不适合快速比较。
- color_consistency；task-series 折线跨 Figure 3、5、6、7 复用 marker/颜色语义但任务集合不同；散点图在 Figure 8 以角色色，在 Figure 9 以 front 色，导致跨图颜色不可作全局语义。所有颜色在 grayscale 下均需结合 marker、面板标题或文字。

## Final judgment

- most_reusable_patterns
  - 用全宽 Offline Training/Sampling 双 lane 固定数据、模型、条件与生成结果的接口。
  - 用三步 objective-space small multiple 把 reference-direction 算法变成可检查的 rank → assign → extrapolate/noise 视觉语法。
  - 用统一 normalized HV ratio、task marker 和 shared legend 组织 guidance、temperature、noise、distance、denoising-step 的敏感性图，并用 booktabs 长表保留逐任务底表。
- highest_value_objects
  - Figure 1：把离线 MOO 的方法主张压缩成训练与采样两段端到端接口。
  - Figure 2：解释 conditioning points 生成机制，是 Table 2/7 消融的视觉前提。
  - Table 1：跨五类任务给出一致性 headline，且可回链 Tables 9–32。
  - Figure 8/9：将高维 MO-Hopper 的 failure 与 RE21 的 reconstruction success 具体化。
- failure_patterns
  - Figure 3、5、7 把离散超参数点用折线连接，但 caption 没有完整说明归一化基准、spread 或数据分母。
  - Figure 6/7 的 error bars 未在 caption 中定义 SD/SE 或重复次数；Figure 8/9 的点云没有 count、distance 或匹配阈值。
  - Tables 9–32 以极小字号承载 15×多任务矩阵，caption 缺少任务定义、spread、N/A 和 percentile 解释，适合查表而非独立阅读。
  - 公开仓库提供 plot/table 家族和 exact defaults，但没有论文 TeX 或 Figure 1/2 的明确组装源；必须以 PDF 的对象布局与 caption 为事实源。
- one_sentence_visual_strategy；先用全宽 pipeline 和三步几何图解释 PCD 的 conditional sampling 与 reference-direction mechanism，再用 normalized-HV 敏感性/消融、headline rank 和逐任务 percentile 表验证效果，并以 MO-Hopper/RE21 的定性对照暴露泛化边界。
