## Final judgment

### 最可复用模式
- 将 efficiency curve 与 quality bar/table 并置，先给出数量级成本，再给出模型质量和规模条件。
- 用固定结构的双 panel sweep 对照 implementation modality、Jacobian type、cell family 或 memory variable，并让颜色/线宽各承担一个明确维度。
- 用完整 appendix tables 保留精确数值，以 main figure 提供趋势和 operating-point headline；caption 明确单位、条件和比较对象。
- 对算法机制采用 target→step-state 的矩阵序列图，把局部线程、warp 和 block 的 hand-off 连起来。
### 最高价值对象
- Figure 1：最有效地把 speedup 与 7B/多尺度 PPL 放在同一视觉入口。
- Figure 2：将 Algorithm 1a/1b 的 solver 层级映射到 sequence-length timing，是方法到系统证据的关键桥接。
- Table 1：同时呈现 nonlinear expressivity、full-Jacobian control 和 A5 failure，保留了主张边界。
- Figure 4 与 Figure 9：分别检验 N_its=3 的收敛经验和 O(Ld_h) memory 预测，但应配套更明确的不确定性/斜率信息。
### 失败模式
- 多条曲线依赖蓝/绿/黄/紫及浅色透明度，灰度和色觉受限时识别成本高。
- Figure 1/3/10 等 caption 过短，硬件、模型规模、重复/聚合规则和 panel 语义需要回正文查找。
- runtime、PPL、accuracy、memory 多为 point estimate，缺少 seed/repetition dispersion、error bar 或 failure accounting。
- 密集 multi-column tables 与 appendix mechanism diagrams 在页面缩放后难以逐项读取，且少数命名/单位需依赖正文解释。
### 一句话视觉策略

以统一的蓝绿黄紫模型语义和 log-scaled cost plots，从 Figure 1 的 speed/quality headline 经 Figure 2–3 的 runtime consequence、Table 1–2 的 expressivity/LM decision，再由附录的 convergence、kernel ablation、memory、training configuration 和 solver diagrams 闭合 ParaRNN 的“可并行、可训练、但受结构与 point-estimate 边界约束”视觉论证。
