## 跨对象系统判断

- **视觉叙事**：Figure 1 先把 uniform training 与 planner path 的失配实体化；Tables 1–4 依次给出 protein、text、code infilling/completion 的主结果；Figure 3/4 将收敛、采样预算、温度与 τ/α 作为 ablation；Appendix Table 5/6 分离 inference planner，Figure 5/6 与 Table 7 暴露 pure-loss instability、训练动态和理论近似边界。对象顺序形成“机制→跨域 headline→设计/推理干预→负面诊断”的闭环。
- **Caption 系统**：Figure 1、3–6 和 Table 1–2/4 采用粗体标题句；Figure 3–6 的 caption 直接陈述方向或主发现，Table 3、5–7 caption 较短，设置/聚合/不确定性依赖正文；Table 1–2 的方向、阈值和 sampling symbol 说明较完整。
- **表头系统**：主表以 model/scale 或 sampling step 为顶层，metric/benchmark 为第二层；Tables 1、3、4 用规模 group，Table 2 用 T group，Table 5–7 保持对应 ablation 轴。黑白 booktabs 规则、粗体 best 和 †/– 状态标记贯穿所有表。
- **方法—结果—消融链**：Figure 1 的 planner-aware loss → Table 1–4 的同规模 DLM/PAPL 结果 → Figure 3/4 的训练、采样、温度和超参数敏感性 → Appendix Table 5/6 的 planner choice → Figure 5/6 与 Table 7 的 instability/approximation diagnostics。表格没有把 inference planner 的收益误写成 training loss 的单独因果。
- **正文—附录链**：正文 p.7–10 负责三域主结果和头对头 ablation；Appendix B.2/B.3 补充 sampling protocol，Appendix C.1–C.3 给出负面训练和理论近似证据。附录对象确实被正文引用，但 Table 5/6/7 的关键条件仍需要返回对应 section。
- **字体/颜色一致性**：表格和 caption 共享 Nimbus Roman/Computer Modern，主表与附录表均使用黑白规则；Figure 3–6 的彩色曲线不完全共用 palette，但 legend/panel label 显式给出角色。Figure 1 的 Helvetica Neue 与其他图的栅格无衬线字体形成局部风格差异，且多条曲线仅靠颜色，灰度可读性低于表格。

## 最终判断

- **最可复用模式**：用 Figure 1 的状态网格显式对照训练路径与推理路径；以稳定的 benchmark/metric 分组表头承载三域结果；共享 legend 的多 panel 曲线同步展示训练、采样和超参数；把 inference planner ablation 与 training ablation 分表；附录同时公开不稳定曲线和近似项数值。
- **最高价值对象**：Figure 1（最清晰地定义方法接口和失配）；Table 1（质量与 diversity 同屏且 foldability 阈值可复核）；Figure 3（训练/采样/温度三类实证行为）；Figure 5 与 Table 7（将稳定化需求和理论近似的不利边界显式化）。
- **主要失败模式**：图表普遍没有 seed、区间、任务分母或重复；Figure 3/4/6 的颜色依赖削弱灰度可读性；Table 3 的 Oracle length 行远高于普通 PAPL 但条件需要正文解释；Figure 5 的 panel-specific y scale 未在 caption 明示；Table 5/6 的 planner ablation 容易被误读为训练 loss 效果。
- **一句话视觉策略**：论文用一个路径示意图定义 training–inference mismatch，以三域黑白主表证明 PAPL 的 point-estimate 增益，再用共享曲线、planner 对照和附录负面诊断逐层限定这些增益的条件与稳定性。
