- **可复用模式**：对 agent trajectory failure 使用可操作的序列定义，并按环境变量长表报告平均计数，避免只给定性 failure screenshot。

### Table 12 — p.33，appendix F / invalid actions

- **版式与结构**：4 列（Model、Appearance、Content、avg. invalid action count），1 层表头、约 23 行、5 个 model row groups（GPT、Kimi、LLaVA、Qwen、UI-TARS；未报告模型/组合按 0 处理）；部分网格，约两位小数，部分高值 bold。宽度为 `page_width`，职责为 `mechanism`、`failure`、`reproduction`。

## 跨对象系统判断

- **视觉叙事**：Figure 1 先提出“app variation 是 reliability 新轴”，Figure 2 展示可配置应用，Figure 3 定义可执行 loop，Figure 4–6 依次给出总体范围、STD 对照和具体 appearance/content case。附录 Figure 7/8 把视觉变体与 action vocabulary 实体化；Table 1–10 复现任务、variation、metric 与 ablation；Table 11–13 将性能差异闭合到 loop、invalid action、intent misunderstanding。
- **Caption 系统**：主结果 caption 使用粗体结论式开头并在正文设置、比较对象、聚合和误差后写出 finding；方法/qualitative caption 主要说明接口和对象。主要缺口是部分附录 caption 没有定义误差线、精确分母或数据来源，且存在原文小拼写/语法问题。
- **表头系统**：结果表以 Model/Task/Variation/metric 反复组合；Table 5–6 的同构列便于 appearance/content 横向比较；Table 11–13 将环境变量拆成 Appearance 与 Content，保持与 Figure 6 和 Figure 7 的命名一致。高密度长表缺少重复表头/分母说明，表格阅读依赖 caption。
- **方法—结果—消融链**：Figure 3 的 state-based success 与 BrowserGym action set（Figure 8）是结果可信度的接口基础；Figure 4–6 是 headline；Figure 9 的 temperature、Table 7 的 resolution、Table 8–10 的 variation interaction/multi-step/popular choices 是消融边界；Table 11–13 提供行为机制，不把低分只归因于视觉变化。
- **正文—附录链**：正文只保留六个主图，附录承接完整 variation montage、action vocabulary、task-level extremes、全量矩阵、metric robustness 与 failure taxonomy。Figure 5/10 和 Table 4–6 在统计量上互相复核，Table 2–3 对 Figure 4 做从极值到全量的展开。
- **字体与颜色**：正文图中数学/衬线 caption 与截图内 sans/monospace 混合是有意的层级，但栅格图中文字在缩小后偏小。表格统一黑白 PDF 字体和 booktabs/partial rules；图表类别色在对象内相对稳定，但跨 Figure 4–6、9–10 并非一个完全固定的色值字典，直接标签和面板标题应保留。

## 最终判断

- **最高价值对象**：Figure 4 是最强 headline comparison；Figure 6 是最强机制切片；Figure 3 是方法接口锚点；Table 3、Table 5–6 和 Table 11–13 提供从 aggregate 到 failure mechanism 的可审计细节；Figure 7 对 variation 的质性可解释性最高。
- **最可复用模式**：三段式 system overview；固定行顺序的 STD/MAD paired comparison；appearance/content 同构长表；variation montage 与 categorical table 共用命名；把 invalid action、loop、intent misunderstanding 定义成独立 failure endpoints。
- **主要失败模式**：高密度栅格图/长表在缩小后字号过小；若脱离 caption，部分图例、误差线、分母和 unreported=0 规则不完整；颜色在灰度下不总安全；长表的 count 缺少 trajectory/action 总长度归一化；公开仓库没有论文数据图/表生成器，复现不能声称为 source-exact。
- **一句话视觉策略**：论文用“可配置应用截图 → agent–environment 闭环 → 跨 variation 的范围/离散度 → variation-specific failure tables”的层层展开，把 UI-agent reliability 从固定应用分数变成可观察、可复核、可解释的环境变化证据。
