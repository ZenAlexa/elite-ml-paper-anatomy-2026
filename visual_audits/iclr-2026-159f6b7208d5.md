## 5. 跨对象视觉系统与最终判断

### 5.1 视觉叙事

论文的视觉叙事是“模型约简（Figure 1）→ path/edge rank 理论桥接（Figure 2、Table 1）→ 等价类变换（Figure 3、Figure 5）→ solution traversal proof（Figure 4）→ CP(G) presentation（Figure 6）→ enumeration/runtime/oracle baseline（Table 3–5）→ finite-sample simulation（Figure 7）→ real-world network（Figure 8）”。正文 Figures 1–3 都服务于理论/算法接口，附录图表把同一 grammar 扩展到证明细节、成本、robustness 和 qualitative case；没有独立的 ablation Figure，但 Table 4 的 phase split 和 Table 5 的 oracle protocol承担方法边界检查。

### 5.2 Caption/header system

Figure captions 多为 regular `Figure k:` 开头，先给对象标题，再按 Left/Right 或颜色/线型说明 setup；只有 Figure 6 明确写出 maximal/must-appear 的解释，Figure 7 明确写出 mean±standard deviation 和 25 models，其他 theory diagrams 主要依赖正文 theorem context。Table captions 同样以 regular `Table k:` 开头；Table 4/5 的实验协议最完整，Table 1/2 的定位 caption 最短。表头整体采用 Nimbus Roman/Computer Modern、bold/medium header 和 booktabs 线；Table 2/3 的多层结构增加了 row grouping 但也提高脱离正文的阅读门槛。

### 5.3 Typography/color consistency

页面正文、caption 和理论图主要使用 Nimbus Roman/Computer Modern；Figure 7 的统计图使用 TeX Gyre Termes/Heros 和 NewTX 数学字体，Figure 8 可见 Times New Roman/Type3；因此跨对象字体不是严格单一家族，但均保持 serif/math-paper 语气。理论图倾向 black/gray、节点形状与线型编码；Figure 2 和 Figure 8 使用 categorical fills，Figure 7 使用 blue/orange/green series + translucent bands。颜色语义在单个对象内稳定，却没有全局 palette/legend：Figure 1/3/5/6 依赖 caption 或 shape/line style，Figure 7 有共享 legend，Figure 8 仅在 caption 中定义 sector colors。

### 5.4 证据闭环、优点和失败模式

- **最强证据闭环**：Figure 2 将 rank duality 具体化，Figure 3/5 将 theorem transformation 变成可遍历 class，Figure 6 将 same theory 变成可解释 CP(G)，再由 Figure 7/8 连接 finite-sample 与真实数据；Table 4 的 phase cost 和 Table 5 的 oracle protocol 清楚划定“算法效率”与“模型失配”的证据边界。
- **主要优点**：理论对象使用结构化 network/graph grammar，而不是装饰性示意图；runtime table保留 failure semantics；Figure 7 用 facet 与 SD band 表达多维 simulation；Figure 8 的 solid/dashed edge 直接携带 equivalence uncertainty。
- **主要失败模式**：很多 caption 只说明“是什么”而不写主结论；Figure 2、Figure 4、Table 1–3 需要读者回看 theorem/appendix 才能理解抽象符号；浅色 categorical palette 和 Figure 7 的同线型 series 在灰度下退化；Table 3 旋转且 CDF microplots 密集；Figure 8 dense edges 可读性受交叉限制；没有公开能精确复现 PDF 图表的 `.tex`/plot/table source。

## 6. 可复用优先级

1. **最高价值对象**：Figure 6（maximal basis + solid/dashed invariant/optional edges），因为它把理论等价类、可信关系和不确定关系压缩成一个用户可用 presentation；其次 Figure 2（图—matching—matrix 的 rank duality bridge）和 Figure 7（多维 simulation small multiples + uncertainty band）。
2. **最可复用模式**：状态/等价类使用 node shape + operation line style；理论桥接用同一颜色在 graph、matching、matrix 中做对应；实验 comparison 用 shared legend、规则 facet、统一 uncertainty encoding；表格用 booktabs 与 end-to-end/phase/timeout 同表。
3. **重构建议**：若用于新论文，应为 Figure 7 增加线型/marker 冗余、统一或明确 y scale，为 Figure 8 提供 sector legend/可展开边表，为 Table 3 拆分旋转 CDF composite，并在每个 caption 中写清分母、主结论和对象是否只为 illustrative example。

**一句话视觉策略**：论文用黑白结构图把“等价类如何判定、遍历和呈现”逐级展开，再用少量彩色 network/curve 与附录表格补足模拟、成本和真实数据的边界证据，但复现源和灰度可读性仍是主要缺口。
