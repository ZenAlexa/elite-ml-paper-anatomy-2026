## 总体判断

本文的可复用视觉策略是：用递归链示意图定义操作方向，用小型属性表和 page-width 主表把 estimator trade-off 与跨任务 reward 对齐，再用训练曲线、组件/h sweep 和附录 qualitative/prompt/cost 对象补足机制、效率与复现。最高价值对象是 Figure 4（机制接口）、Table 2（Text2Image 主比较）、Table 3 + Table 10（VBench 主比较与完整维度）、Figure 5 + Table 9（效率/成本关系）和 Figure 6 + Table 4（DCoT 组合）。主要失败模式是 caption 过短、band/重复未定义、主比较缺少单位/seed/不确定性、定性 grid 选择规则缺失，以及 source repository 只有两个组合 diagram assets 而没有可复现 plot/table/LaTeX 源。单句策略：**以 FO/HO/ZO 递归机制图为骨架，用统一 reward 表格证明跨任务结果，用动态曲线、成本消融和附录定性/prompt/完整 benchmark 逐层把“低方差、低内存、多尺度”主张连接到可检查证据。**
