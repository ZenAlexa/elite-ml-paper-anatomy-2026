## Cross-object visual system

- **Visual narrative:** Figure 1 先提出同分不等于同能力，Figure 2 把 PIPE 的接口重写与小/大 Delta 判别规则画成方法主线；Tables 1–2 给出 AgentBenchPlus/AgentGymPlus 的跨环境性能，Figure 3 与 Tables 5/6/9 把失败变成旧 action 调用证据，Tables 3/4 把偏好定义为 IR，Figure 4 与 Appendix Figure 5 把 performance/IR 接回训练 epoch。Tables 7/8、21–25/26–28 和 10/18–20 提供环境、mapping、prompt 与规模的复现底座，Tables 11–17 约束聚合与 alpha 敏感性。
- **Caption system:** Figure/Table 编号后接句号和描述性标题；caption 大多说明设置、环境和比较对象，几乎不把数值主发现写进标题。Table 3/4 定义缩写，Table 11 明确公式、alpha 和舍入，Figure 5 逐项说明四面板；其余模型条件、分母和统计口径常留在正文。所有 caption 均非粗体 headline 标题。
- **Table header system:** 主结果表使用环境/模型的两层分组表头，数据行按 Origin/Perturb 1/Perturb 2/Delta 或 Untrained/Trained 分组；IR 表用 agent×environment 单层列头和 italic row group；mapping/prompt 表用 Original–Perturb 1–Perturb 2 或 Setting–Prompt 两列；统计表用 Environment、count、rounds、functions 四列。规则以部分网格/稀疏横线为主。
- **Method result ablation link:** Figure 2 的“只改 interface”构造 → Tables 1/2 的 performance 与 Delta → Figure 3/Tables 5/6/9 的旧 action failure → Tables 3/4 的 counterbalanced IR → Tables 11–17 的聚合/alpha sensitivity → Figures 4/5 的训练动态。Tables 10、18–23/26–28 暴露 counterbalance、prompt 与 identifier 细节，Tables 7/8/24/25 说明环境和监督规模。
- **Main appendix link:** 主文 Figure 1/2、Tables 1–4、Figure 3/4 分别在附录 Tables 5/6、7/8、9、10–17、18–28 和 Figure 5 得到 qualitative、dataset、failure、metric、prompt、mapping、statistics 与 epoch 扩展。附录没有新绘图语法，主要重复主文矩阵或把接口条件展开；Table 26–28 是 PDF 中以新编号重印的 mapping duplicate。
- **Typography consistency:** 表格层面使用 Nimbus Roman/Computer Modern 和粗体/italic 行组保持稳定，提示与 mapping 中 monospace 适合 action token；图层面 Figure 1/2 的 office-style 字体和 Figure 3–5 的不同 plotting fonts 造成明显跨图切换。主文小表字号约 7–8 pt，附录案例/提示表约 8–10 pt，长表在渲染中更密。
- **Color consistency:** Table 1/2 的 Delta 蓝/红、Figure 1/2 的机制角色色、Figure 3 的扰动柱色、Figure 4/5 的条件线色均为局部语义；没有统一的“原始/扰动/训练后”跨对象颜色 token。多数表格黑白且依赖 bold/规则，灰度鲁棒性主要来自表格而非图。

## Final judgment

### Most reusable patterns
1. 用双栏概念图把同一任务的语义路径、接口捷径和相同 benchmark score 并置，再以 counterfactual small/big Delta 连接方法预测。
2. 用两层环境/模型表头和固定条件行块（Origin、Perturb 1、Perturb 2、Delta）把性能与接口敏感度放在同一决策面。
3. 用 agent×environment IR 矩阵配合训练组 row group，并在附录以 alpha 同构表和 epoch 小倍图扩展机制敏感性。
4. 用原始/扰动/混淆三列 mapping 与两列完整 prompt 保存可执行 interface 细节，辅以逐步 failure trajectory 和全环境调用计数。

### Highest-value objects
- Figure 2：最强的方法接口图，把接口最小改写、两类学习机制和可测 Delta 预测集中在一页。
- Table 1 与 Table 2：最高价值的跨环境主比较，逐环境展示 trajectory-SFT gain 是否迁移到 perturbation。
- Tables 3/4：将 interface shortcutting 转换为可复核 IR 矩阵，直接连接主张与环境异质性。
- Figure 4：把 Origin/perturb performance 与 IR 对齐到训练 epoch，说明仅看原接口 checkpoint 的风险。
- Tables 5/6/9：把抽象 failure 解释落实为纠正反馈后的旧 action 重复调用，并从案例扩展到全环境。

### Failure patterns
- source inventory 仍标记 no_public_source_found，但 exact-title gh 检索找到作者名下的公开仓库；该仓库有 benchmark/PIPE 实现和通用资产，却没有本文 Figure/Table 的 plot、LaTeX 或视觉源，状态应记录为 repository_without_visual_source。
- Figure 1/2 字体和颜色来自独立概念图，Figure 3–5 又各有 plotting font/palette；颜色没有跨对象稳定语义，灰度/色弱读者需依赖文字。
- 主结果和 IR 表以点估计为主，未展示 seed、重复、误差或任务级分布；Delta、IR 的聚合和分母需要正文/附录公式补全。
- 长表、mapping、prompt 和 qualitative trajectory 在小字号及后置浮动页中密集；Table 26–28 重印 Tables 21–23，增加冗余而未给出视觉 duplicate 标识。
- caption 主要是描述性设置，Figure 3–5 不直接陈述关键发现，T5/T6 没有显式列头；表格需跨正文才能解释 metric、单位和筛选边界。

### One-sentence visual strategy

以多色概念图建立“同分不等于同能力”和 PIPE 反事实主线，用密集的黑白分组表承载跨环境性能、IR 与失败计数，再以附录的同构敏感性表、完整 prompt/mapping 和 epoch 曲线补齐机制与复现边界。
