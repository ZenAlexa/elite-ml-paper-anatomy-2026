## 跨对象系统判断

- **visual narrative**：论文以 Figure 1/5 的 theorem-to-structure 示意开路，Figure 2/7 的 Q1 curves 给 size-generalization 结果，Table 1/2 将 Q2/Q3 理论问题变成 matched comparisons，Figure 3/4 和 Tables 3–10 将训练构造、failure boundary、资源和扩展配置下沉到附录。最清晰的闭环是 “general finite-cover theorem → K+1 constructive Bellman–Ford set → Q1/Q3 matched empirical check”；Q2 只覆盖 1-WL/1-iWL pair，不能读成所有 architecture 的分类。
- **caption_system**：所有 caption 使用斜体 `Figure/Table N.` 标签加正文式句子；图 caption 通常解释 setup/encoding，表 caption 通常解释表头/seed/硬件。Figure 2/7 对 smoothing 明确，Table 1/2/6/9/10 对实验条件明确，但大多数表注不命名 `±` 统计量，且多数 caption 只在正文/附录上下文中自足。
- **table_header_system**：数值表统一用两层 `Dataset/Nodes` 或 `Nodes - General` 表头，方向箭头 `(↓)` 出现在 score/reg 列名，row label 承载 task、model 或 regularizer。Appendix Table 3/4 用单层配置表头；Table 5–10 延续 booktabs/no-vertical-rule 视觉语言。选定超参仅 Table 4 用 bold，结果表不做 best/second-best color/highlight。
- **method_result_ablation_link**：Figure 3 的 K+1 path basis construction 为 Theorem 16 的方法接口；Figure 2/7 和 Table 6 检查 Q1 size generalization；Table 1 与 Table 10 检查 Q2 expressivity；Table 2 检查 Q3 regularizer；Table 9/7 把 two-layer/depth limit 与 extension 分开。Figure 6 提供参数轨迹，但不能取代 ablation 表的 matched result。
- **main_appendix_link**：正文只保留 Figure 1–2、Table 1–2 和 Q1–Q3 结论；Appendix N 的 Tables 3–10/Figures 6–7 给出 generator、hyperparameters、runtime、跨规模、real-world、weight traces 和 failure extension。Figure 3–5 还承接正文 Theorem 2/3/16 的 formal assumptions。主文对象的量化解释若不回到 Appendix N/Definitions，容易丢失 dataset/seed/step 边界。
- **typography_consistency**：页面字体与 booktabs 表格高度一致；理论图的数学字和附录图的 DejaVu Sans-like plot text 有可见切换。Figure 6 的嵌入栅格在字号/线宽上比矢量 Figure 7 更脆弱，但 caption/标题字号体系基本稳定。
- **color_consistency**：结果曲线固定使用 green test、blue training、orange regularization、violet loss；理论图按对象局部使用 green/red/blue/gray，节点/边/箭头有位置或线型补充。表格刻意保持 monochrome，以 row/column/layout 和 Table 4 bold 传达语义；灰度复现对 Figure 2/7 的四系列区分不安全。

## 最终判断

- **most_reusable_patterns**
  1. 用 Figure 1/5 的“抽象 theorem → 结构化对象 → 可迁移度量空间”三段式图，把理论条件连接到后续实验，同时避免单独绘制装饰性 architecture。
  2. 用 Figure 2/7 的统一 log-axis small multiples 展开训练、测试、正则化和 theorem reference，并将完整 scale 数值下沉到 Table 6。
  3. 用 Table 1/2 的 matched row/column design，分别只改变 expressivity 或 regularizer，配合 Table 3/4 明确数据生成和超参分母。
  4. 用 Figure 3 的 general instance + basis-vector construction 表达最小训练集，用 Figure 4/ Table 9 显式呈现 conjectural/failure boundary。
- **highest_value_objects**：Figure 1（理论到 MPNN 的接口）、Figure 2（Q1 headline dynamics）、Table 1（Q2 expressivity contrast）、Table 2（Q3 regularization ablation）、Figure 3（Theorem 16 的 constructive set）、Table 6（完整 size-generalization numerical slice）。
- **failure_patterns**
  1. 许多表格把三-seed 均值和未命名 `±` 混在一起，读者无法判断 SD/SE/其他 spread；表格缺少统一统计脚注。
  2. Figure 2/7 使用 `σ=1` Gaussian smoothing 且 Figure 7 只用同一 seed，没有 uncertainty ribbon，原始训练随机性不可从图面判断。
  3. Figure 4/5 的概念/猜想几何没有定量坐标，若不读 caption/正文可能把示意路径或 compact neighborhood 误读为实证数据。
  4. Figure 6 多轨迹、无参数/seed legend，且嵌入栅格细线在缩放时损失；Figure 7 跨页造成阅读断裂。
  5. 公开仓库只提供训练/数据/模型代码，没有论文视觉生成源或锁定 commit 的 figure/table exporter，无法复现对象级版式和颜色。
- **one_sentence_visual_strategy**：论文用克制的理论结构图建立 finite-cover/MPNN 机制，用统一 log-axis 曲线和无竖线数值表完成 Q1–Q3 matched evidence，再把 constructive training set、failure edge case、资源与完整 size slices 放入附录以保持正文速度与可追溯性。
