### Figure 1 — Framework Overview（PDF p.3）

- **分类与目的**：`pipeline`、`architecture`、`conceptual_diagram`；`method_interface`、`experimental_design`、`theory_mechanism`。page-width 混合图。上部训练区分为 `Structured Description Generation`（粉色）和 `Attribute/Relationship Search`（蓝色），中部由虚线分隔 training/inference，推理区先画 fMRI-to-text projection，再画 object-centric generation。
- **几何/布局**：左到右、上到下的阅读方向；训练图像/VLM/结构化描述和 attribute/relationship search 在顶部并行，fMRI 预处理→encoder/LM→text 在中部，两个 object condition 的 cross-attention、latent concatenation 和 reconstructed image 在底部。面板由彩色标题条、黑色箭头、虚线分隔线、红色虚线 emphasis 框和 raster thumbnail 组成，留白较少但层级明显。
- **plot grammar**：`rendering=mixed`；`x_scale=none`、`y_scale=none`、`grid=none`；无 legend（`legend_present=false`、`legend_placement=null`、`shared_legend=false`）；流程节点采用 direct labels（`direct_labels=true`）；无数据 marker（`marker_types=0`），实线箭头/边界和虚线分隔/强调（`line_styles=2`），`hatching=true`（LM Space 橙色斜线区），无 reference line，`uncertainty_display=none`，连接线约 1.0 pt；`provenance=mixed`。
- **Typography/color**：图内标题/节点为 Georgia/DejaVu Sans 的 regular/bold，公式使用 Computer Modern/CambriaMath，局部斜体标签；渲染估计 6–14 pt。主要 pastel 色为约 `#D55BC4`（结构化描述）、`#5799D2`（搜索）、`#D9651A`（fMRI-to-text）、`#F3D7C5`（projection 背景）、`#F2C36A`（text）、`#4F9DB8`（object-centric generation）、`#C00000`（红色强调）和 `#000000`；`mode=mixed`、约 8 色。颜色与面板标题、位置、箭头和文本冗余编码，语义分区可追踪但自然缩略图不灰度安全。
- **数据编码与证据关系**：不承载数值序列；节点编码训练/推理状态、对象级文本、cross-attention 和空间 concatenation。它把 §3.1 的 latent alignment 动机与 §3.2–§3.3 的结构化描述/生成实现连接起来，直接指向 Table 1 的 representation 选择、Table 5 的模块必要性以及 Figure 4–6 的 object-level case study。
- **Caption**：`Figure 1: Framework Overview: PRISM generates structured text descriptions for each training image using a VLM to iteratively extract brain-aligned object attributes and relationships. These descriptions capture the image’s compositional and relational content and serve as supervision to train an encoder and fine-tune a language model to map fMRI signals into the text space. During inference, the model predicts descriptions from fMRI signals, which then guide a pre-trained diffusion model for object-centric image reconstruction.`（74 词；动作：`title/setup/encoding_key/main_finding`；`headline_bold=true`，PRISM 加粗；可脱离正文理解，直接陈述方法作用。）
- **优点**：将训练/推理、文本中间空间和对象级扩散放在一张闭合 pipeline 中；颜色、箭头和结构化文本示例互相冗余，读者可从 fMRI 输入追到图像输出；与后续消融及附录案例有清晰接口。
- **缺陷**：顶部搜索循环和底部两个 condition 的语义密度高，少量节点字号偏小；“text”与“structured description”在不同阶段的边界需依赖 caption/正文；没有把 CKA/LPIPS 的搜索目标或 m=2 约束编码为定量标记。
- **可复用模式**：对多模块生成方法，用训练/推理虚线分区、模块色带、对象级分支和最终合并节点形成可追踪的机制图；把每个分支的条件名直接写在箭头/框内而不是依赖外部 legend。

## 最终判断

- **最可复用模式**：
  1. 用 Figure 1 的训练/推理分区、彩色模块带和对象分支，把中间表示选择与生成接口画在同一因果链上。
  2. 用同构的 latent/module/object-count tables（Tables 4、5、7、8）保持指标列不变，让删除测试和跨数据集扩展可以直接对读。
  3. 用 Table 6 的 rank×round 摘要、Figure 7 的全量分布和 Table 9 的初始集排除，分层呈现黑盒 prompt search，而不只报告单个最优词。
  4. 用 Figure 3 的原图/错误输出双 panel 先固定 failure semantics，再用 Figure 4–6 展示 object-level decomposition 的修复接口。
- **最高价值对象**：Figure 1（方法接口）；Table 1 + Table 4（representation choice 从 alignment 到 reconstruction）；Table 5（模块必要性）；Table 2（跨三数据集的主比较）；Figure 3（attribute-binding failure 的可证伪视觉锚点）。
- **失败/缺口模式**：Table 3 后的 QA “significantly”没有统计检验和不确定性；Figure 2、3–6 的 qualitative sample selection、随机性和失败率不明；Table 2/4/5/7/8 的 ± 在 caption 中没有统一定义；Table 8 显示固定 m=2，但四对象边界可能遗漏对象；prompt search 只在 667 张训练图上运行；SDXL 只覆盖 PRISM/Mindeye2；Figure 7 灰/珊瑚色对灰度不安全且标签密集；Figure 4–6 caption 信息不足以脱离正文复现设置。
- **一句话视觉策略**：论文以“LM text latent alignment → structured object/attribute/relationship interface → object-centric generation → matched multi-dataset metrics and ablations → appendix failure/search boundary”的流程图、同构表格和定性案例串起 PRISM，但应补足不确定性定义、QA 检验和 qualitative sampling 规则才能让视觉证据完全闭合。
