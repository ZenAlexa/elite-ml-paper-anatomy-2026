## 最终判断

### 最可复用模式
- 用 Figure 1 的三阶段 pipeline 把输入字段、模型接口和可执行 test success 放在同一阅读路径上。
- 用 Table 1/3 的 grouped headers 与 baseline-relative delta 把 benchmark dimensions 和 ablation conditions 压缩到可审计表面。
- 用 Figure 5 的 shared-scale small multiples 展示模型×任务类别交互，而不是只报告一个 aggregate score。
- 用统一浅蓝 histogram/bar grammar 组织附录分布，并以 caption 明确 derived variable 的单位与语义。
- 用 Figures 13–15 的同构 prompt cards 记录实验协议中被操纵的字段，支持复现和消融解释。

### 最高价值对象
- Figure 1：最有效地把 real-world instructed edit 的输入边界和测试闭环可视化。
- Table 1：在一张表内连接数据来源、语言/context coverage、highlight affordance 与 prior benchmarks。
- Figure 4：清晰传达 40-model pass@1 排名和 closed/open gap，是 headline comparison。
- Table 3：把 headline context claim 转成可比较的四条件 ablation，并给出 signed deltas。
- Figure 5：揭示 aggregate ranking 之外的 category-specific model heterogeneity。

### 失败模式
- Figure 4 的 40 个旋转模型名和 Figure 3/12 的密集多色 legend 牺牲精确读取，且没有足够的冗余编码。
- Figure 3/12 的 stacked strips 没有共同数值轴，Table 1 的 length 单位与 test-case 维度也不完整。
- Figures 6–10 与 Tables 7–8 多数不给样本量、bin 规则或完整不确定性定义，长尾/巨大 SD 的解释留给正文。
- Tables 2/4/5、Figure 11 和 Figures 13–15 的长代码/提示文本字小且占用版面，caption 对选择字段和索引约定不足。

### 一句话视觉策略

以一个输入—模型—测试 pipeline 为主轴，用 grouped benchmark/ablation tables 和 shared-scale model/category plots 证明现实性、难度与 context dependence，再以附录分布、实例和同构 prompt cards 补齐数据与复现细节。
