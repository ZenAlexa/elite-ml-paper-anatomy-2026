## 3. 全局视觉系统

- **版式**：正文是 ICLR 双栏论文；Table 1 在第 4 页右侧浮动并让文字绕排，Figure 1、Figure 2 及多数结果对象跨双栏或按宽浮动体居中。附录图表保持紧凑单栏/页宽布局，24×24 矩阵为高信息密度页宽对象。
- **字体**：`pdffonts` 显示正文主要使用 Nimbus Roman No9 L、Computer Modern 数学字体（CMR/CMMI/CMSY）、NimbusMonL；图中还出现 DejaVu Sans、Liberation Sans、Arial/Type3。表格正文约 8 pt、表头约 8–9 pt；图轴/刻度约 7–10 pt，caption 约 8 pt。PDF 对象字体与源码指定的图中 12–14 pt 配置结合记录为 mixed，而不是把渲染后的视觉估计当作源值。
- **颜色**：表格为黑/灰度 booktabs；方法对比主要用 Seaborn colorblind 的蓝/橙（约 `#0173B2` / `#DE8F05`）；矩阵用连续 `YlGnBu_r`；Figure 1 用 husl 的循环分类色，Figure 7/11 用 model-family categorical colors。热图色彩是定量编码，色条承担唯一主要数值 key；Figure 1 的 61 色不具备可靠的灰度冗余编码。
- **统计显示**：主体和附录矩阵、bars 主要是 point estimates，没有 error bars；Figure 1 的半透明 band 是 confidence-rank interval。Figure 12–15 的 τ-b 是把不显著 model comparison 视作 ties 的 robustness 版本；caption 对此有定义，但绝大多数对象不显示单元级不确定性。
- **一致性**：所有对象采用 `Figure N:`/`Table N:` 的 caption 前缀；结果图重复 direct 与 train-before-test 左右/上下配对，颜色、坐标范围和热图色标保持统一。缺点是 61 系列 Figure 1 没有可读的独立 legend，Figure 11 没有 family legend，短 caption（Figure 7、Figure 11、Table 2）脱离正文时自解释性弱。

## 6. 跨对象证据关系与最终判断

### Visual narrative

论文以 Figure 1 的 direct/TBT 两任务 rank 对照引出“equal preparation”叙事，Figure 2 把局部现象扩展到 24 benchmark 的均值，Figure 3 分解到六个 category，Figures 4–5 追问 perplexity 与 downstream 的连接及 base/IT 边界，Figures 6–8 再把 agreement 提升为 score-matrix PCA、compute 对照和 family-controlled case。Appendix Figures 9–10、Tables 3–8 保留 pair-level、异常 BPB、成本、few-shot、size/family 分层；Figures 12–15 把同一链路重算为 ties-aware τ-b。因此主文是“现象→总体比较→类别/机制→结构解释”，附录是“完整矩阵→失败诊断→分层/替代统计”。

### Caption system

所有 captions 以 `Figure N:` 或 `Table N:` 开头；Figure 1–6、12–13 的 caption 会同时给 setup、编码/统计定义和 main finding，Figure 9/10/14/15 采用简短的矩阵定义 caption；Table 1/3/4 和 Figure 5 的 caption 信息相对充分。Figure 7、Figure 11、Table 2、Table 5–7 过短，离开正文后无法恢复 subset、shot、family size 或 aggregation denominator。Figure 1 以粗体 `Top`/`Bottom`/`Note` 做层级，其他 caption 通常只有标题式开头，没有统一的结论短标题。

### Table header system

Table 1/2 是 taxonomy headers；Table 3–7 是单层 metric headers，条件（direct 0/5 shot、TBT）写入列名；Table 8 是唯一明显的两层 grouped header（Direct Evaluation/Train-before-test × PC1–PC5）。booktabs 贯穿所有表，黑白输出安全；但大多数 result tables 不写 `n`、pair denominator 或 uncertainty，All models/家族分组主要依靠顺序和空白而非显式 rule。

### Method–result–robustness link

方法在正文/Appendix A.2 定义 benchmark-specific fine-tuning、LoRA 和 validation selection，Figure 1/Appendix C.1 提供 rank-alignment interface；Figure 2–5 是主比较与 perplexity mechanism；Figure 6–8、Figure 11、Table 4、Table 8 是 PCA/compute structural interpretation；Table 5–7 与 Figures 12–15 是 few-shot、size/family 和 significance-aware robustness。没有删除 LoRA、训练 epoch、template 或 checkpoint selection 的 component ablation；这些对象支持的是“等化准备程度与可迁移 ranking”的经验链，而不是单独识别某个实现组件的因果作用。

### Main–appendix link

Figure 2 的 aggregate bars 在 Figures 9/10 获得完整 24×24 pair matrix；Figure 3 在 Figure 13 得到 τ-b category robustness；Figure 4 的 Gemma exclusion 由 Table 3 给出 BPB diagnostic；Figure 7 的 compute subset 由 Table 4 给出 exact model/cost rows；Figure 6/8 的 PCA pattern 在 Figure 11/Table 8 展开到完整 model/family。附录不是孤立补充，而是把主图的分母、异常、条件和替代统计显式化。

### Typography and color consistency

正文 serif（Nimbus Roman/Computer Modern）与图中 sans-serif（DejaVu/Liberation/Arial）形成稳定区分；数学符号 τ、PC、FLOPs 与正文 math font 一致。Figure 2/12 使用蓝/橙表达 direct/TBT，Figures 3–5/9–10/13–15 统一 `YlGnBu_r` 和 0–1 色条，Figure 6/8 复用单蓝 PCA bars，Figure 7/11 复用 family categorical colors。主要视觉断裂来自 Figure 1 的 61 色和 Figure 11 的无 legend，而非 palette 在对象间漂移。

### 最高价值对象

1. **Figure 1**：把 ranking disagreement、TBT 的比较单位和 Appendix C.1 的显著性边界在一页内可视化，是最强的叙事入口。
2. **Figure 2 + Figures 9/10**：mean bars 给出 0.52→0.76 headline，full matrices 让 274/276 pair claim 可复核。
3. **Figures 4–6**：从 perplexity/downstream 的连接、base/IT heterogeneity 到 PC1 concentration，形成可解释性而非单纯性能 bar。
4. **Tables 3/4/7/8 与 Figures 11/12–15**：分别暴露 Gemma failure、compute denominator、family/size boundary、完整 score 分布和 ties robustness，防止总体均值掩盖适用范围。

### 失败模式与限制

- Figure 1 的 61 条线、Figure 9/10/14/15 的 24×24 labels 在页面缩放下信息密度过高；颜色缺少形状/线型冗余。
- Figures 2–8、11–15 和 Tables 5–8 主要只给 point estimates；没有 per-task uncertainty、pair counts 或 seed aggregation，读者难以判断小 bin/family 的稳定性。
- Figure 7 的 PC1–compute 共变没有趋势线/相关摘要，且只纳入公开 token count 模型；它是观察性结构对照，不是 compute 的因果证据。
- Figure 11 没有 family legend；Table 2/5–7 captions 过短，脱离正文后缺少成员数、shot 语义或 denominator。
- Gemma 的 BPB 异常、IT 预测较弱（平均 τ=0.51）和 Yi family TBT 较低（0.30）被保留在附录/分层结果中，但主文 headline 仍由全体均值和 PC1 主导。
- source inventory 的本地视觉源只有任务 YAML；GH notebook/data 能精确说明 plot grammar，但没有 PDF TeX/table generator，故不能把它升级成 exact_visual_source。

### 最可复用模式

- **paired comparison grammar**：保持 direct/TBT 的颜色、轴域、排序和 panel 几何完全一致，只改变 evaluation condition。
- **aggregate→audit ladder**：主文先放 per-task aggregate，再在附录放 full pair matrix；均值负责决策，矩阵负责复核异常。
- **measurement-source heatmap**：用 rows 表示 perplexity corpora、columns 表示 downstream tasks，并用 caption 明确每个 ranking 的训练状态。
- **structure-to-boundary ladder**：explained-variance bars → compute scatter + exact cost table → family/size tables，逐步把 latent-factor 解释收窄到可观测范围。
- **alternate-estimand reuse**：τ-b/ties robustness 重用 τ 的 bar/heatmap geometry，使统计处理差异可审计而不制造新的视觉混淆。

### 一句话视觉策略

论文以 Figure 1 的 direct/TBT 排名对照引出 equal-preparation 叙事，用 Figure 2–5 从总体与类别 agreement 追到 perplexity 机制，再用 Figure 6–8 的 PCA/compute 结构和附录的完整矩阵、异常诊断、分层表与 τ-b robustness 补足全局一致性及模型族边界。
