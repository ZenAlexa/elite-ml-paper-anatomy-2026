## 对象逐项审计

### Figure 1（p. 3，正文 method，`page_width`）

- **类型/目的/布局**：`scatter + conceptual_diagram`；`method_interface`、`theory_mechanism`。三面板横排，共享 x/y 几何但不共享数据语义；左为输入 features/labels/bids，中为 SVM-induced accuracy allocation，右为 incentive-compatible payments。每个面板有 `$x_1$`/`$x_2$` 标签，刻度隐藏，留白小，整图占双栏页面宽度。
- **绘图语法**：PDF 以矢量路径和嵌入字体为主；x/y 坐标均 `none`（示意坐标而非量化轴），无网格、无 legend、无 direct labels；点 marker 为圆形、无线型数据系列；中/右面板各有一条虚线决策边界，并叠加 `RdBu` 的半透明 score/classification 背景；无 uncertainty。源代码未显式设 linewidth，渲染约 1–1.5 pt。
- **数据编码**：左面板约 100 个合成训练点，红/蓝代表 label，点面积代表 value；中面板固定点大小、橙/浅绿代表 prediction correctness，背景色代表 learned score，虚线代表 boundary，annotation 为 `accuracy: 0.85; welfare: 91.8`；右面板只绘制正 payment 点，magenta 和点面积代表 payment magnitude，annotation 为 `#payers: 16; total pay: 7.0`。这是机制示意，不是样本汇总统计；公开 notebook 的 payment 计算用 100 个 bid 网格点，不能把图中数值当作精确理论估计。
- **字体/颜色**：面板标题约 9 pt Computer Modern Sans/TeX，annotation 约 7–8 pt，轴标签约 8 pt，regular；PDF 还包含 TeX 数学字体。颜色为红 `#FF0000`、蓝 `#0000FF`、橙 `#FFA500`、浅绿 `#32CD32`、magenta `#FF00FF` 以及 `RdBu` 背景的多级浅红/浅蓝；颜色本身可由源码语义确认，背景色为渲染估计。色盲/灰度下点大小和颜色语义不能完全保持。
- **caption**：`Figure 1. Accuracy auction induced by a classification algorithm. (Left) Each training point represents a participant in the auction: color represents label, and size represents value of accurate prediction. (Center) Welfare-maximizing allocation of pointwise accuracy via weighted loss minimization, showing learned score function (background color), decision boundary (dashed line), and prediction correctness (point color). (Right) User payments (size depicts magnitude) guarantee truthful elicitation, despite being highly sparse.`（65 词）。标题不以粗体结论开头；包含 title、setup、encoding key、comparison 和 main finding；脱离正文基本可读，但不定义 welfare 单位或 payment 计算细节。
- **与论证的关系**：把引言的“accuracy 是待分配资源”和 p. 3–5 的加权目标/auction/payment 连接成单一视觉链：features/labels/bids → classifier-induced allocation → sparse truthful payments。它是方法接口和机制 headline，不是消融或统计不确定性证据。
- **优点**：同一坐标系重复使用，三阶段方向清晰；点大小同时把 heterogeneity 与 sparse burden 变成可见差异；背景/边界/正确性编码对应正文 Eq. (3)–(7)。
- **缺陷**：点大小在左代表 value、右代表 payment，语义切换依赖 caption；无刻度/legend，读者无法量化背景和坐标；中面板同时叠加三种视觉层，边界附近点较拥挤；annotation 的 welfare 与 total pay 没有单位或归一化说明。
- **可复用模式**：用固定三栏和同一坐标把“输入—学习分配—机制结果”画成可追踪的机制接口；若复用，应给 value/payment 分开的图例或 redundant shape/label，避免大小编码在相邻 panel 间变义。

- **caption**：`Table 1. Comparison of payment algorithms. O is the learning objective, \tilde m the number of candidate points, k the number of search steps, N the number of (possible) random draws. ## 论文级视觉系统判断

- **主线**：Figure 1 先给出 bids→weighted classifier allocation→sparse payments 的机制接口；Table 1 说明 payment algorithm 的保证/调用权衡；Figure 2 将稳定性主张变成 synthetic payer plateau 与 accuracy relation；Figure 3 在 folktables 上接出 welfare/accuracy/group allocation/cost；Appendix Figure 4、Table 2、D.3、Table 3、Figure 5、Figure 6 分别补 constructive gap、algorithm bias/variance、calls complexity、loss/λ sensitivity、value variance 和 k-NN contrast。
- **caption system**：统一为斜体 `Figure/Table n.` 加短标题和 panel 说明，主要报告 setup/encoding/comparison；只有 Figure 1 在 caption 中接近结论句，其他 caption 通常把主发现留给正文。主文 caption 比附录完整，但 trial count、seed、uncertainty 和归一化细节普遍缺失。
- **table header system**：理论表用 property columns；实验表用 grouped metric headers 与 row groups。Table 2 的 total-payments 四列和 Table 3 的三组四列是同一“先指标、后 m”模式，但 Table 2 的统计层级和 Table 3 的 c(m)/λ 记法不够明确。
- **method–result–ablation link**：Figure 1/Table 1 是 method interface；Figure 2/3 是 main result；Table 2/D.3 和 Figure 4–6 是 appendix extension。正文明确把 Algorithm 1、Figures 2–3 与 Appendix C/D 相互调用，视觉证据链闭合但需要跨页阅读。
- **main–appendix link**：正文保留机制、Theorem 2/3 的 informal statement 和 Figure 1–3；Appendix A 给 proof/conditions，B 给 Algorithms 2–4，C 给 data/model details，D 给 Table 2/3 和 Figures 4–6。Figure 6 caption直接指向 D.6，Figure 3 caption则没有指向 C/D 的具体小节。
- **typography consistency**：正文与表格为 Nimbus Roman/Computer Modern 体系，表格约 10 pt；Matplotlib 结果图使用 DejaVu Sans，Figure 1 使用 TeX/CMSS。图内 sans 与正文 serif 的角色区分清楚，但 Figure 4 的 JPEG 内部字体和其余矢量图不一致。
- **color consistency**：没有全篇统一的语义 palette。Figure 1 自定义 red/blue/orange/limegreen/magenta；Figure 2 使用 plasma；Figure 3 使用 viridis 加默认循环；Figures 5–6 使用默认循环；Table 全部黑白。颜色常常是唯一的系列区分，跨图复用和灰度可读性有限。

## 最终判断

1. 最可复用的模式是 Figure 1 的三阶段机制链、Figure 3 的“总体 Pareto→分组 allocation→payer cost”page-width 叙事，以及 Table 1 的保证/调用次数决策面。
2. 最高价值对象是 Figure 1（让 auction mechanism 可见）、Figure 3（把 welfare/accuracy/payment 连接到真实/semi-synthetic 数据）和 Figure 6（在同一坐标中对照 SVM/k-NN 理论差异）；Table 2 对部署成本也有价值，但需要修正统计列说明。
3. 主要失败模式是窄图中过多彩色 series、caption 不报告 trial/uncertainty/归一化定义、Table 2 的统计列语义不直观、Table 3 的密度过高，以及 Figure 4 使用未能从公开仓库匹配的 JPEG 源。
4. **一句话视觉策略**：用一个机制示意图建立“价值—准确率—支付”的接口，再用一张高密度主结果图和附录中的成本/敏感性/模型对照对象，逐层把理论保证映射到有限实验，但依赖正文和附录共同解释颜色、统计层级和适用边界。
