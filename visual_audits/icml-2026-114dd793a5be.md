## Cross-object system

- **visual_narrative:** The paper follows a tight visual argument: Figure 1 defines prompting as a counterfactual activation difference; Figure 2 falsifies constant token magnitude; Figure 3 links token/layer faithfulness to output comparisons in Tables 1–3. Appendix Figures 4–9 expand the intervention mechanism and qualitative evidence, Figures 10–11 expose the judge instrument, Tables 4–9 expose layer/configuration choices and benchmark decompositions, and Figures 12–15 close the Persona, IFEval, AxBench, faithfulness, and vector-geometry loops.
- **caption_system:** Captions begin with a bold Figure/Table label, then state setup and metric/encoding definitions. Main result tables additionally define macro-averaging, highlight rules, abbreviations, missing cells, and appendix pointers; plot captions mostly define axes and normalization but rarely state uncertainty because no uncertainty is displayed. Figure 13 is the notable caption-level failure interpretation, explicitly naming oversteering.
- **table_header_system:** Result tables use grouped two-level headers: method/configuration at left and model groups over paired metrics (TA@C80/TA@Cp or IF Acc./Coher.). AxBench tables use separate subtable headers for rank/intervention families or score dimensions. Appendix layer tables use compact one-level headers with literal integer layers. Booktabs rules, no vertical rules, one-decimal Persona/IFEval values, and three-decimal AxBench values are stable.
- **method_result_ablation_link:** The intervention vocabulary S/A, Const/PSR, LL/MSE/DiM, and R/QR is reused in Figure legends, Table rows, appendix layer choices, and source notebook variables. Main Tables 1–3 establish performance; Figures 4–9 and 14–15 test mechanism/faithfulness; Tables 6–9 restore omitted factors and score dimensions rather than introducing a second naming system.
- **main_appendix_link:** Every appendix object has a clear backstop role: Figure 4/5 and Figures 6–9 elaborate the mechanism cited in §3.4; Figures 10–11 define the judge cited in §4.1; Tables 4–5 and Algorithm 1 expose selection procedures; Table 6/Figures 12–13 expand Persona; Tables 7–8 expand IFEval failures; Table 9 decomposes AxBench; Figure 14 generalizes Figure 3; Figure 15 diagnoses vector geometry. - **typography_consistency:** PDF text uses NimbusRomanNo9L/Computer Modern mathematics with NimbusMonL for prompt templates; source notebooks request serif text, TeX, NewTX math, 12 pt base plot font, 12 pt labels, and 9 pt ticks/legends. Tables are compact and consistently bold/regular, with smaller appendix tables. Raster plots inherit the source typography, while F10/11 are directly vector monospaced text.

The system is semantically disciplined but grayscale-safe only for viridis and the hatch/marker-rich Persona plots, not for most line charts.

## Final judgment

- **Most reusable patterns:**
  - Define a black-box behavioral operation as a visible counterfactual state difference before showing performance results (Figure 1 → Eq. 3).
  - Use a token×layer heatmap and an explicit baseline/reference line to test a simplifying intervention assumption before fitting a replacement model (Figures 2, 3, 4, 5).
  - Pair a compact headline table with an exact appendix expansion that restores omitted configurations, filtered slices, score dimensions, and hyperparameter choices (Tables 1–9).
  - For dense method comparisons, combine categorical color with hatch or marker redundancy, as in Figures 12–13, rather than relying on hue alone.
- **Highest-value objects:**
  - Figure 1 (p.3): exact PSR_illustration.png turns the method claim into a computable activation interface.
  - Figure 3 (p.9) with Tables 1–3 (p.8): output-level gains and intervention-level faithfulness form the central evidence closure.
  - Figure 13 (p.25): the full alignment–coherence curves reveal oversteering and prevent a single operating point from hiding the failure regime.
  - Tables 7–9 and Figure 14/15 (pp.26–30): the appendix makes omissions, composite-score trade-offs, cross-model faithfulness, and vector geometry auditable.
- **Failure patterns:**
  - Most line charts use color as the primary method identity, so grayscale and small-screen comparison are weak despite strong viridis/hatch choices elsewhere.
  - Dense page-width tables and 9–18-panel appendix figures have small repeated labels and legends; the visual grammar is reproducible but costly to scan.
  - Point estimates dominate: no Figure/Table reports uncertainty, per-example distributions, failure counts, or cost, so visual differences should remain descriptive.
  - Figure 10/11 prompt templates are complete on the PDF page but lack a public standalone source file; the judge instrument is visually reproducible, not directly code-reusable.
- **One-sentence visual strategy:** Make prompt steering inspectable as a token-specific activation intervention, use faithful visual diagnostics to bridge mechanism and benchmark tables, and push every omitted configuration or boundary condition into a source-paired appendix.
