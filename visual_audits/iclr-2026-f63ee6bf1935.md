2. **Caption 系统**：多数 caption 以粗体标题开头；主结果/机制图（Figures 1、3、8，Tables 1–2）会写主要 finding，短 caption（Figures 2、7、Tables 5–6）依赖正文。Figure 3、9、10 明确使用 appendix pointer 或 cross-reference；没有任何对象提供误差条或区间定义。
3. **表头系统**：主表和 Table 6 统一使用 Out/Out+In/In domain spanner；Table 3 改用任务复杂度 spanner；Table 4/5 用配置/数据集列语义。三位小数与 `δ1 (↑)` 保持一致，但相对百分比列、比值文本和混合超参数破坏统一精度，且多数 caption 不解释加粗/灰带。
4. **方法—结果—消融**：Figure 2/4 的消融证据支持 Figure 6 的 marker + unified focal length；Figure 3/10 与 Table 5 支持 SFT 的效率/跨域趋势；Figure 5/4c 与 Table 4 支持稀疏标签和数据规模；Tables 1–3、Figures 7–8 是对应 headline、复杂任务与 qualitative mechanism 的结果端。
5. **正文—附录连接**：Figure 2↔Figure 9、Figure 3b↔Figure 10、Figure 4c↔Table 4、Figure 3↔Table 5、Table 3↔Table 6 的调用链明确。附录 Table 5 的 group size/β 等关键条件仍部分留在文字中，appendix-only 图表如果脱离正文会损失实验协议。
6. **字体/颜色一致性**：PDF 文本字体基本统一为 Nimbus Roman/Computer Modern；彩色图使用稳定的桃/紫训练或模型对比、蓝色连续趋势、黄 marker、红边界框，但不同 rendered asset 的卡片底色/自然图像色彩不完全统一。图表整体依赖颜色，只有直接数值、位置、形状和表格文字提供冗余；不应宣称全局灰度安全。

## 最终判断

- **最可复用模式**：
  1. 摘要三联图将代表性输入、方法接口和跨数据集 headline 置于同一视觉对象（Figure 1）。
  2. 分析图按“离散策略→连续超参→数据规模”排列，使用直接数值标签和 regime reference line（Figures 2、4、5）。
  3. 主文平均/域分组表与附录逐数据集表保持列语义和任务顺序（Tables 1–3、6）。
  4. 以同一输入列×方法行的 qualitative grid 展示平均指标之外的机制性 failure，并用 caption 解释观察（Figure 8）。
  5. 方法接口图复用 marker/箭头视觉锚点，并在 appendix 给出实际 primitive 和跨域复验（Figures 6、9、10）。
- **最高价值对象**：Figure 1（论文主张的最短视觉摘要）、Figure 4（camera ambiguity 与训练规模的因果式分析链）、Table 2（与 pure vision 的边界比较）、Figure 8（boundary failure 的机制性 qualitative 证据）。
- **失败模式**：短 caption 未定义图例/δ1/实验 regime（Figure 2、Figure 7、Tables 5–6）；窄栏和页宽复合图中的小字号；颜色在灰度下的系列区分弱；点估计没有重复/不确定性；定性样例和外部表格的可推广范围需要正文约束；Figure 3/10 将计算成本留在文字而非同一图面。
- **一句话策略**：DepthLM 以黄 marker 和蓝/桃/紫的轻量图形语言，把“视觉 grounding→焦距归一化→文本深度”从摘要 headline、机制消融到跨域/多任务结果串成一条可追踪的证据链，但其定量图表仍主要依赖小字号、颜色和无不确定性的点估计。
