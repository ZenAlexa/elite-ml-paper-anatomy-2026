## 最终判断

- **最可复用模式**：
  1. Figure 1 的 fixed-D/fixed-C 双 panel，把训练 compute、data size、activation rate 和 dense reference 放进同一 BPC grammar。
  2. Figure 2/5 复用 AR/BPC 坐标，将 unique、strict、loose data reuse 作为不同线型，并以 marker size 显示 consumed/data tokens。
  3. Figure 3 的 training phase×benchmark family 九 panel 矩阵，保持共同 x semantic 后再用 Table 2 恢复逐任务结果。
  4. Figure 4 与 Table 8 的 trend-plus-exact-settings pairing，以及 Figure 1/2 与 Tables 9–17 的 curve-to-configuration pairing。
  5. 附录绿色 validation-minimum row 加 shared-hyperparameter caption，使大量结构/资源参数具备可定位的复现入口。
- **最高价值对象**：Figure 1 是 equal-resource AR 主线的首要视觉证据；Figure 2 是 scale consistency 与 data-reuse 的核心对象；Figure 3 和 Table 2 最直接连接 downstream headline 与逐项不利信息；Table 10、12、13、14 是重建 N/C/D 公平条件的关键表。
- **失败模式与低价值模式**：所有 Figure 都是单 checkpoint/点估计曲线，缺 seed、误差或 uncertainty；Figure 3 的 category averages 掩盖 Table 2 的任务级反转；Table 5–17 超宽小字号使复现成本高；绿色 best row 易被误读为统计显著；expert specialization 机制没有对应图表；项目页仓库是 generic template，不能提供视觉 source；Table 1/2 等短 caption 无法脱离正文解释符号、strict/loose denominator 与 dense baseline。
- **一句话视觉策略**：论文以统一 N/C/D/r_a 参数化为视觉骨架，用 2B→7B→3B 的 BPC–AR 曲线证明约 20% activation-rate region，再以九 panel 下游图、逐 benchmark 表和附录的完整 architecture/reuse 配置把 MoE–dense 的等资源比较与其数据代价同时呈现。
