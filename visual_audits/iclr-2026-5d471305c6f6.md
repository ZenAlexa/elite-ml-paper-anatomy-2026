## 最终判断

- **最可复用模式**：
  - Use one explicit symbolic tree before introducing hierarchical attention.
  - Keep a stable 2×2 loss/token/sequence accuracy grammar across problem-size and architecture ablations.
  - Use grouped density/field headers and method-group rows to place success metrics beside cost or training conditions.
  - Separate directly trained versus interpolated configurations with a redundant marker, not color alone.
- **最高价值对象**：
  - Figure 1, because it makes the token→term→equation→system inductive bias inspectable.
  - Figure 2, because it pairs learning speed with exact-match behavior under a controlled common setup.
  - Table 1, because it puts exact/support/token accuracy and runtime on one density axis.
  - Table 2 and Table 4, because they expose curriculum versus architecture and training/interpolation boundaries.
  - Table 11, because it makes the classical-runtime protocol discrepancy auditable.
- **主要失败模式**：
  - Short appendix captions (Figures 4–5, Tables 8–10) omit metric definitions, seeds, denominators, or aggregation details.
  - Loss/accuracy panels mix y scales and repeated local legends, increasing visual decoding cost.
  - Bands appear asymmetrically and are rarely defined; Table 4 relies on red text without redundant encoding.
  - Main runtime headline compares inference-only neural output to timeout-censored classical runs, and Table 12 contains an ambiguous sequence-length value.
  - There is no public exact source for the target paper figures/tables; the only linked repository is prior-work code.
- **一句话视觉策略**：Make the symbolic hierarchy concrete first, use a repeatable 2×2 learning-dynamics grammar to establish efficiency, place density/field/curriculum comparisons in compact tables, and move scale, data-distribution, timing, and implementation caveats into explicitly linked appendix objects.
