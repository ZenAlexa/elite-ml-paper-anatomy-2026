## 全文视觉风格
- **结构**：正文 Figure 1 建立 degradation/budget/recovery/throughput headline，Figure 2 诊断低熵机制，Figure 3–5 给出方法接口与 Q-FIT/entropy 机制，Figure 6–7 连接效率和梯度；Table 1–7 负责主比较、消融、长度鲁棒性和代码泛化。附录 Figure 8–11 与 Table 8–17 提供路由/trace qualitative case、layer/calibration、quantization metadata、年度、epoch、超参、decoding、MMLU 和 Q-FIT/RHT 边界。

- **一致性与缺口**：caption 位置、Letter 双栏外壳和 booktabs 横线稳定；常见缺口为无 error-bar/±、分母/重复定义、best-across-budget 选择、hardware path 例外、缩写解码和 source/version 绑定。

## 跨对象系统判断
- **Visual narrative**：视觉叙事从 Figure 1 的 FP4 degradation/budget/recovery/throughput headline，经 Figure 2 的低熵 token 机制诊断，进入 Figure 3–5 的 TAQ、SEM、Q-FIT 方法接口，再由 Figure 6–7 连接部署成本与梯度机制；附录 Figure 8–11 和 Tables 8–17 扩展路由案例、trace 噪声、layer calibration、rotation、配置、年度切片、超参与消融边界。
- **Caption system**：Figure caption 统一采用对象标题加 panel 说明；机制和附录 caption 会写出方向性结论，主结果 caption 多为设置/比较标签。caption 很少定义误差、重复、分母和缩写，T/TQ/TQS 等语义主要留给正文。
- **Table header system**：表头主要用 Bit-Precision/Method、token budget、benchmark 和 deployment format 组合；booktabs/minimal 横线与稀疏 row group 保持外壳一致。多级表头见 Tables 1、13、15、17，且多数表只给点估计，不带 uncertainty 列。
- **Method/result/ablation**：Figure 3 建立 BF16 FT→Q-FIT→TAQ+SEM 的流程，Figure 4/5 与 Tables 4/5/12/16/17 分别将 entropy、trace alignment、Q-FIT、SEM 和 rotation 变成可检验消融；Tables 1–3、6–7 把组件组合映射到准确率/泛化。
- **Main/appendix link**：正文 Figure 5 指向 Appendix Figure 10，正文 Figure 2 的 routing/noise 诊断由 Figures 8–9 具象化；正文 Tables 1–7 的配置、年度分解、epoch、解码策略、MMLU 和 λ/rotation 消融由 Tables 8–17 补齐。
- **Typography**：正文 caption 与表格的 PDF 字体对象稳定为 Nimbus Roman No9 L 配合 Computer Modern 数学；图内标签多为 4–9 pt 的渲染估计，Figure 9 的 trace 使用等宽字。附录复合图的内部字号变小，但未出现跨对象字体家族断裂。
- **Color**：灰色常承担 BF16/reference，蓝/绿/红/紫承担量化或 ReQAT stage，低/高熵和 Q-FIT heatmap 有局部语义；表格主要用黑白粗体/星号。直接标签、panel、row group 和 checkmark 提供冗余，但图内红色警示与多色小图在灰度和缩印下辨识度下降。

## 最终判断
- **最可复用模式：
  - Figure 1 把 degradation、training-budget recovery 和 accuracy–throughput trade-off 排成一个证据阶梯，适合把机制论文的 headline 与部署代价放在同一阅读路径。
  - Figure 2 将直觉 token 示例、分布扰动、routing policy、noise sensitivity 和 tail/mismatch 组合成从现象到机制的诊断链。
  - Figure 3 的阶段化 pipeline 与 Tables 4–5 的二值组件消融形成方法接口—结果对照，读者可以追踪 TAQ、Q-FIT、SEM 的增量。
  - Table 6 的 acc/#samples 和 Table 10 的 year-wise breakdown 展示了把分母/切片显式放进结果对象的可复用做法。
  - Appendix Figure 10/11 与 Tables 8、11、15–17 将 layer、quantization metadata、hyperparameters、decoding 和 alternative transformation 作为复现边界补齐。
- **最高价值对象：
  - Figure 1：最直接的 degradation→recovery→efficiency headline，但应补配置与不确定性定义。
  - Figure 2：把低熵失败机制连接到可观测分布与干预，承担全篇机制入口。
  - Figure 3：最清晰的方法接口图，能将 BF16 FT、Q-FIT、TAQ、SEM 的顺序与数据关系集中表达。
  - Table 1：跨 precision/budget 的核心 AIME 决策面，支撑 ReQAT 的 headline recovery。
  - Figure 7 + Table 4：将 trace alignment 的方向性梯度机制与受控准确率消融相互绑定。
- **失败模式：
  - 几乎所有性能图表都只有点估计；八随机种子、best-across-budget 选择和长响应尾部的稳定性没有在对象内显式编码。
  - 复合图将定性示意、3-D surface、heatmap、bar/line 混在同一对象，带来小字号、轴语法变化和阅读方向负担。
  - 缩写、checkmark/dash、row group 与 hardware path 经常依赖正文或附录才能解码；Figure 6 的 DGX Spark FP8 KV 例外尤其容易被忽略。
  - 定性 Figure 8–9 能解释局部机制，却没有样本选择规则或 prevalence，无法单独承担 aggregate accuracy claim。
  - 表格普遍缺少成本、失败率或不确定性列；Table 10 的跨 budget 取 best 和 Table 15 的 decoding confound 需要正文边界才能正确解释。
- **一句话视觉策略：**论文用低熵 token 这一稳定视觉词汇把 FP4 失败诊断、TAQ/SEM/Q-FIT 方法接口、准确率恢复、部署成本和附录消融串成一条证据链，结构复用清楚，统计不确定性、分母与源码绑定仍是主要缺口。
