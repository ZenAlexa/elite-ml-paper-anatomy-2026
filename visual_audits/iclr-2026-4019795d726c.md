## Cross-object judgment

- **Caption system:** every object uses `Figure/Table n:`. Figure 3 has a bold “Overview of TeCh” title; Tables 2–5 and 7–8 use long captions that combine setup, intervention definitions, and highlighting rules; Figure 4 is the strongest caption for encoding and perturbation setup; Figure 5 is the weakest for self-contained interpretation.
- **Table-header system:** Table 1/2/3 use a single metric header row (with dataset groups as row blocks in Tables 2/3); ablation/comparison tables use two levels of dataset group then Accuracy/F1-Score; Table 11 adds a signal-family tier above dataset names. Header order is stable enough to support cross-table comparison.
- **Method–result–ablation link:** Figures 1–3 and Algorithm 1 provide the conceptual/method interface; Tables 2/3 are headline comparisons; Table 4 isolates Adaptive Dual Tokenization; Table 5 isolates CoTAR; Figure 4 tests efficiency/robustness; Figure 5 supplies qualitative representation evidence; Tables 7/8 provide full appendix ablations.
- **Main–appendix link:** Appendix Table 6 supplies per-dataset settings, Tables 7/8 expand the main ablations to all seven datasets, Table 9 contextualizes related temporal models, Table 10 tests subject-ID split sensitivity, Table 11 diagnoses centralization, and Table 12 adds MedGNN. No appendix Figure repeats or quantitatively calibrates Figure 5.
- **Typography consistency:** native text is coherent Nimbus Roman/Computer Modern, but raster figures use a separate sans-serif-like visual language and dense appendix/main tables shrink numeric text below comfortable reading size. Caption size is stable while object text is not.
- **Color consistency:** pastel categorical colors are reused only locally inside figures; table best values are dark red and, in Tables 2/3, second-best values blue/underlined. There is no cross-object color key for “proposed method,” “baseline,” or “uncertainty,” so shape, labels, and typography carry the global link.

## Final judgment

- **Most reusable patterns:** (1) matched conceptual/method panels before equations (Figures 1–2); (2) parallel branch pipeline with explicit fusion (Figure 3); (3) stable dataset×metric headers across main, ablation, and appendix tables; (4) paired cost/perturbation views in one figure (Figure 4); (5) hierarchical domain headers with metric definitions for a mechanism diagnostic (Table 11).
- **Highest-value objects:** Figure 2 for the method's operation-level interface; Table 2 for the headline multi-metric comparison; Table 4 plus Table 5 for separable tokenization/CoTAR interventions; Figure 4 for the only combined efficiency/robustness visual; Table 11 for connecting the centralization premise to measured dataset diagnostics.
- **Failure patterns:** extremely dense 5–6 pt multi-metric tables; captions overloaded with intervention prose but missing `±`/aggregation definitions; color-dependent highlighting without a robust grayscale equivalent; Figure 4 resource claims without a visible measurement protocol; Figure 5 qualitative centrality claims without axes, t-SNE parameters, uncertainty, or quantitative centrality summary; public source limited to four README raster attachments with no plot/table generators.
- **One-sentence visual strategy:** make the centralized-versus-decentralized mechanism explicit with matched diagrams, preserve a stable dataset×metric table grammar for result and ablation evidence, and pair every qualitative or efficiency claim with a reproducible protocol and uncertainty-bearing quantitative view.
