## 全文视觉系统

PDF 使用双栏论文版式；Figure 2/3/6 用全宽机制或 qualitative evidence 打断正文栏流，Figure 4/5 与主表紧邻结果叙事。正文、caption 和表格以 Nimbus Roman No9 L/Libertinus Sans 与 Computer Modern math 为主；图内少量代码或 token 标签出现 Nimbus Mono L/无衬线字形。可见字号大致为正文/caption 9–10 pt、表格 8–9 pt、图内小标签约 5–8 pt；图内栅格字形的估计置信度低于 PDF 外置文字。

颜色以方法类别和 attribution 方向为主：主结果中 FlashTrace 常用青色，baseline 多为深蓝/绿/紫；Figure 3/6 用蓝色 attribution 和绿增红减的 diverging delta；Figure 7 用深蓝与青色区分 CoT/Input。表格用 booktabs 黑白横线，FlashTrace 行或列通过浅青底色与粗体突出。多数图有颜色之外的 panel、位置、marker 或文字冗余，但 Figure 4 的八方法曲线和 Figure 6 的 delta map 仍不适合仅靠灰度阅读。

## 跨对象系统判断

- **视觉叙事**：Figure 1 先诊断 reasoning-token attribution sink、recovery drop 与效率问题；Figure 2 将问题转成 span aggregation + recursive-hop 机制；Figure 3 把 Hop 变化画成 token evidence；Tables 1–2 与 Figure 4 给出跨任务 faithfulness 和 scaling headline；Table 3–5、Figure 5 做 approximation、structured-output、model-generalization 与 length robustness；附录 Algorithm 1/Table 6–10、Figure 6–7 再把复杂度、hop depth、长 context、cache trade-off、target scope 和样例/分布边界补齐。整体形成“诊断→机制→主结果→消融→限定条件”的链条。
- **Caption 系统**：Figure 1–4、6–7 的 caption 多采用加粗标题句并给出设置/颜色/主发现；Figure 5 和 Tables 1–5、7–10 的 caption 长短不一。主表 Table 1/2 定义指标，Table 3/8/9 写出成本或条件，附录 Figure 6/7 明确 Hop、样本与颜色；误差线（Figure 5）和 ±（Table 9）的统计语义仍不完整。
- **表头系统**：主结果表按 dataset/context→metric 分组，方法行和 FlashTrace 高亮保持一致；消融表把 rollout、target scope、hop depth 或 attention mode 直接放在行轴；附录复杂度表使用符号列和 prose caption 定义边界。booktabs 横线和无竖网格贯穿全篇，减少宽表噪声。
- **方法—结果—消融链**：Figure 2/Algorithm 1 的接口 → Tables 1–2 的 faithfulness → Figure 4 的 measured cost → Figure 5/Table 3 的 reasoning-length 与 exact-rollout controls → Table 4/5 的跨域/模型边界 → Table 7/10、Figure 7 的设计变量分解。对象之间职责清楚，尤其 Table 3、9 把成本与质量/资源 trade-off 放在可复核的局部面。
- **正文—附录链**：正文 p.1–9 保留 motivation、机制图、主 faithfulness/efficiency 表图和有限消融；附录 p.16–25 承载 Algorithm、复杂度、额外 hop/长 context/cache/target-scope 控制与 qualitative samples。Figure 6/7 和 Tables 7–10 对正文结论有直接补充，但 baseline adaptation、correctness filtering、metric schedule 仍需读者跨 Appendix B–F/K–N 重建。
- **字体/颜色一致性**：caption/表格字体与 booktabs 结构稳定；图内方法 palette 在 Figure 4/5 与 attribution heatmap/violin 间不完全共享，来源仓库的 current palette 也与 PDF 成品存在差异。表格的青色 FlashTrace 高亮和图中青色方法线形成可识别但非严格统一的品牌色；小字号和多方法曲线是主要阅读成本。

## 最终判断

- **最可复用模式**：以 Figure 1 的“故障诊断小图”建立单一问题，再用 Figure 2 的全宽机制接口连接公式/算法；主表用 dataset/context→metric 分组同时展示 recovery 与 faithfulness；Figure 4 将 time、memory、Pareto 同屏；附录把 hop、cache、target scope 和 unfiltered long-context controls 与 qualitative distribution 配套公开。
- **最高价值对象**：Figure 1（把 reasoning attribution sink 变成可测问题）；Figure 2（最清楚地定义 span/recursive 机制接口）；Table 1（主质量矩阵）；Figure 4（效率、OOM 与 Pareto 同屏）；Table 3 与 Table 9（近似/缓存成本边界）；Figure 7（把局部 heatmap shift 变成 100-sample 分布）。
- **主要失败模式**：多数 Table 和 Figure 4/6 只有 point estimates，没有 seed、样本分母或重复；Figure 5 的 error bar 与 Table 9 的 ± 没有定义统计量；Figure 4 的八方法颜色/legend 密度和 Figure 3/6 的小 token heatmap 影响灰度与缩放阅读；正文的 broad faithfulness 与 O(N) efficiency 叙述需要附录的 filtering、M·N residual term 和 attention-cache 条件才能完整解释。
- **一句话视觉策略**：论文先用 attribution-sink 诊断和全宽 span-wise 机制图锁定问题，再以 faithfulness/效率主表图建立 headline，最后用递归、target、cache、长 context 和 qualitative distribution 的附录对象逐层限定方法收益的适用条件。
