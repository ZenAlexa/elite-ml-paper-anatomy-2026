## 跨对象系统与最终判断

### 视觉叙事

叙事按 `information-density mismatch → latent patch interface → static/aligned boundary mechanism → controlled-budget main tables → scaling → ASR/TTS transfer → representation diagnosis → ablation → appendix robustness/accounting` 展开。Figure 1 是 headline 入口，Figure 2–3 将方法接口和边界可视化，Tables 3–5 把性能/下游成本放入主文，Figure 4 把优势放到规模轴，Table 6 和 Figure 5 解释机制。Figure 6、Tables 7–13 把 ratio、运行稳定性、BPE/TTS 版本、低层能力与 token accounting 后移。

### Caption 与表头系统

Figure caption 多为“对象标题 + 设置/解释”，Figure 2、3 的 caption 解释机制，Figure 4 的 subcaption 写出主 finding；Figure 1、6 缺少系列定义与不确定性。表 caption 使用“主比较/数据集/模型配置/补充稳健性”的短句，只有 Table 9 明确三 runs/Ave/Std，Table 13 明确 token accounting 推导。主结果表采用二层 header 统一 S→S/T→T，Table 5 用 Task/Model/Iters/clean/other/units 把质量和成本绑定；附录复用同一 header 语法，跨页一致性较好。

### Method–result–ablation 链

Figure 2 的 encoder/global transformer/decoder 对应 Section 3 与 Table 7；Figure 3 的 fixed/aligned/silence boundary 对应 Table 6、Table 10；Figure 1/4 对应 Tables 3/4/8；Table 5 对应 decoder 的 downstream transfer；Figure 5 对应 alignment 的 representation mechanism；Figure 6 与 Table 9 则把训练比例和稳定性放在附录。链条能够闭合主要主张，但 alignment 促进性能的解释仍主要由同变异的 patch size、边界和 qualitative cluster 支撑，缺乏独立 mediation/causal test。

### 主要可复用模式

1. `Figure 2` 的 token→patch→global→token 接口图：把局部压缩、共享建模和重建输出放到同一阅读路径。
2. `Figures 1/4/6` 的四系列跨设置折线系统：固定颜色/marker/线型，比较 budget、scale 和 ratio。

4. `Table 9` 的 Ave/Std 二层不确定性表头和 `Table 13` 的显式 accounting 表。
5. `Figure 3` 的抽象 segmentation 与真实 alignment 例子并置；`Table 6/10` 绑定边界语义和 patch length。

- **Figure 2**：最短路径解释方法接口和跨模态共享 latent。

### 失败模式与边界

- 定量折线与主表几乎都是单次 point estimate；重复和 Std 仅在附录 Table 9 出现，主文 caption 不定义 run/denominator。
- `Compute Savings`、`0.25×` context/gen units、`~20%` FLOPs 和 `~4×` generation 主要是 token/sequence proxy；没有硬件 wall-clock 或端到端 latency。
- Table 6/10 的“approximately matched patch sizes”同时改变 patch length、silence handling 和 boundary semantics，机制归因不完全隔离。
- Figure 5 的 t-SNE 无轴、无样本数、无随机稳定性，适合作为 qualitative evidence，不适合作为独立性能或因果证据。
- 颜色是四系列和散点类别的重要身份信号；虽有实/虚线、marker、panel 标题和文字冗余，灰度/小尺寸下仍有混淆风险。
- Table 5 的 TTS `other` CER 为 LST 16.2、Baseline 15.1；“matches baseline”只在总体/clean 语境较成立，不能推广为所有 split 无质量代价。
- Section 7 将研究描述为不含 downstream adaptation，但 Section 5.3 已报告 ASR/TTS fine-tuning；审计保留该范围张力，不把 fine-tuning 结果扩大为完整 deployment 结论。
