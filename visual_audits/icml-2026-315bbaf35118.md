## 最终判断

- **最可复用模式**：
  1. 用 Figure 1/2 的多层 overview 把输入、memory、联合输出和 evaluator interface 固定在同一视觉坐标系，再让后续图表逐个验证组件。
  2. 用 `scenario × source` 或 `model × time` 的稳定 grid 组织多视角 robot rollouts，保证真实/生成、成功/失败和 forward/inverse 的比较维度正交。
  3. 用 Table 1–5 的短表头、方向箭头、统一精度和粗体目标行把 LPIPS、∆LPIPS、horizon 与 action shuffle 变成可扫描的机制证据；连续 corruption Figure 9 则补足 binary ablation 的剂量关系。
- **最高价值对象**：Figure 2（方法接口）、Figure 5（action failure + memory drift 的双机制）、Figure 7（跨域 policy-ranking scatter）、Table 1/2/4（点值机制锚点）以及 Appendix Figures 10–12（progress 与 round-trip 的定性闭环）。
- **失败模式**：公开项目页只有若干 rendered assets，没有完整绘图/表格源；自动 inventory 将 19 个 PDF 对象误标为 reading-only；图表普遍不展示不确定性/seed/样本数；Figure 7 legend 密集、Figure 10–14 照片缩小后细节弱；Figure 12 caption 的“四个模型”计数与五个列举不一致；`horizon.png` 不能覆盖 PDF Table 4 的 Ctrl-World 行。
- **一句话视觉策略**：dWorldEval 以“统一 token/memory/progress 机制图 → action/consistency 定量与定性 stress test → progress/ranking 跨域验证 → 模拟/真实附录多视角证据”的层层闭环，证明世界模型不仅生成画面，还必须遵循动作、保持时间结构并支持可排序的 policy 评估。
