## 跨对象系统判断

- **视觉叙事**：Figure 1 先建立 procedural warm-up → semantic pretraining → domain transfer 的总览；Figures 2–3 依次验证 source–skill matching、shuffle control 与 layer-selective transfer；Figures 4–8 将收益延伸到 semantic curves、token efficiency、downstream MBPP、domain localization 与 data mixture；Appendix Figures 9–14 给出 data interface 和 mechanism controls，Figures 15–20 承担 hyperparameter/robustness boundaries，Figures 21–23 承担 code/BLiMP/MLP-only downstream slices。Table 1 是 weight-mixture headline，Tables 2–7 是 recipe/scale/downstream，Tables 8–14 保存完整矩阵和 variance。
- **Caption system**：Figure/Table label 使用斜体式编号后接 sentence-case caption；主结果 caption 通常按 setup → encoding/comparison → main finding 顺序，明确 lower-is-better 或 accuracy 方向，并把完整 variance 指向 Appendix N。附录 heatmap/ablation caption 更偏向说明扫描轴、best-cell 标记和控制语义；仅少数 caption 定义 error bars 的具体统计量。
- **表头系统**：结果表以 Model/Pretraining task/Transfer mode 为行或首列，以 domain/task metrics 为列；↑/↓ 写进指标表头，parameter scale 通过 group row，GLUE 的 Avg 用末列和竖分隔。所有表使用 booktabs、少量横向分隔、无完整网格，数值列右对齐并用粗体/下划线突出 best。
- **Method–result–ablation link**：Figure 9 与 Table 2 解释 generator、delimiter、loss target 和训练 recipe；Figures 2–3/Tables 8–12 把 source/task/transfer 诊断量化；Figures 10–14 与 Table 13 将 attention entropy、shuffle 和 noise 作为机制/反事实 controls；Figures 4–8、21–23 与 Tables 1、3–7、14 承接 semantic/downstream/mixture outcomes。
- **Main–appendix link**：正文 Figure 2/3 明确把完整 variance 指向 Appendix N.1；Figure 5/6/7/8 的 token、scale、downstream 和 mixture claims 在 Appendix L/M/N 由 Tables 3–14 与 Figures 21–23 扩展；Figure 1/6 的 layer/domain story 在 Figures 10–12、21–23 中切成机制与 downstream slices。
- **Typography consistency**：PDF 字体对象显示 Nimbus Roman No9 L、Computer Modern math、Nimbus Sans/Mono 与少量外部 TrueType；figure/table 估计字号约 5–10 pt，caption/table body 多为约 7–8 pt。正文与附录维持同一 serif caption/booktabs 体系，但多 panel heatmaps 和小型 charts 的实际可读性依赖高分辨率。
- **Color consistency**：蓝/橙/青绿稳定表示 full/MLP/attention 或 procedural sources，灰色 dashed line 稳定表示 no procedural pretraining；heatmaps 独立使用 sequential/diverging colorbars，green best-cell outline 是附录配置选择的共同标记。颜色对 transfer/source 仍是主编码，灰度安全性普遍有限。

## 最终判断

- **最可复用模式**：
  - 用 source×skill small-multiple bar matrix 加 shuffled/no-pretraining controls，呈现结构性匹配而非单一 aggregate。
  - 用 semantic-domain columns × training/additive/substitutive rows，把效果、互补性和 token cost 放在同一曲线系统。
  - 以 domain/scale 作 facet、MLP/full/attention 作固定 transfer encoding，再用附录同构表补充 mean±SD。
  - 用 length×pretraining-steps heatmap 与绿色 best outline 承载高维配置敏感性，把主文留给因果主线。
- **最高价值对象**：
  - Figure 1 p.2：把 procedural、standard 和 multi-domain transfer 组成单一总览接口。
  - Figure 2 p.4 + Table 8 p.25：主图的 source–skill pattern 与完整均值/SD 底稿形成互证。
  - Figure 5 p.6：九 panel 同时呈现 semantic training、additive complement 和 substitutive savings。
  - Figure 6 p.7 + Figures 21–23：把 component localization 连接到 domain-specific downstream 与 MLP-only efficiency。
  - Table 1 p.9 + Table 14 p.30：点估计 headline 与完整 weight-mixture variance 配对。
- **失败模式**：
  - 多图以颜色区分 source/transfer，却少用 marker、hatch 或直接标签；灰度打印和色弱阅读会损失层级。
  - 主文 Figures 2–8 多为均值曲线/柱而无误差，caption 只把 variance 推到附录，局部差异的稳定性不能在图面判断。
  - perplexity 与 accuracy、pure code 与 documented code 在同一复合图中并置，若不逐 panel 读轴容易误合并。
  - 附录高密度 heatmap、transfer matrix 与长 legend 承担重要边界，但小字号和长 caption 提高独立审阅成本。
- **一句话视觉策略**：论文用一致的 pastel source/transfer 编码和 gray baseline，将“抽象 procedural structure → layer-localized transfer → semantic/downstream efficiency → multi-source composition”串成主文曲线/柱图，再用附录 heatmap、perturbation 和 mean±SD 表补齐边界与不确定性。
