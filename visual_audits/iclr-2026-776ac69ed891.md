## 跨对象结论

1. **叙事路径**：Table 1 用真实 API 映射提出“少数 primitive + 可变 vectorization”，Table 2 将该主张放入相关 notation 的 capability matrix；正文继续用代码示例说明 grammar/implementation，附录 Table 3/4 再给 overhead 与 adoption 的描述性边界。四表承担“接口 → 对照 → 成本 → 生态”链条，没有 figure 或消融对象。
2. **Caption 系统**：四张表都在表上方使用 `Table n:`；Table 1 caption 有粗体结论标题，Table 2/3/4 为普通标题。Table 2/4 用 caption 解释脚注/特殊符号，Table 1/3 的 metric 或示例范围写得简短；不确定性定义在所有 caption 中都缺失，Table 3 的 `±` 尤其需要表注补充。
3. **表头系统**：指标/操作名称放在 header；Table 1/2 通过双列/多列 header 表达 notation 对照，Table 3 明确 `(ms)` 单位，Table 4 将 stars/forks/files/usage 并列但没有在 header 写 snapshot、denominator 或 query 口径。
4. **方法/结果/消融**：正文方法组件（vectorization、primitive decomposition、compiler）与 Table 1/2 的结构性证据相连；Appendix G/H 是效率与生态结果。没有 component deletion、controlled ablation 或 figure，因此不能把四表包装成消融或性能 benchmark 全景。
5. **主文—附录链接**：正文 p. 2–3、p. 9–10 回引 Table 1/2；正文在 §4.4 文字定义 cache，而 Table 3 仅在 Appendix G；Table 4 由 §2.2/§2.3 adoption 叙述在 Appendix H 落地。附录 A–F 的长 expression/compiled/error 例子补足语义，但不新增表格。
6. **字体与颜色一致性**：正文 serif/数学字体与表格一致，代码列统一 Inconsolata；红色 `#FF0000` 只用于 code expression 的视觉强调，Table 4/2 保持黑色文本。规则线和缩进承担主要结构编码，颜色不是必要通道。
7. **最高价值边界**：Table 1/2 最有价值的是把语义差异压缩为可检索的离散映射；Table 3/4 提供工程成本与生态快照，但测量协议和分母信息在表外，适合保留为附录描述性证据，不宜支撑跨 backend 或未来 adoption 的强泛化。

## 最终判断

- **最可复用模式**：
  1. 将真实 API/notation 变体与少数稳定 primitive 放入左右对照表，按 primitive 分组并在 caption 明确“examples vs census”。
  2. 对 capability 使用有限 taxonomy、字母编码、破折号和脚注限定，而非伪造连续评分。
  3. 将一次性初始化成本和稳态成本作为并列列，单位写进 header；将 popularity、source-surface count 和 target-corpus prevalence 分列，并把 snapshot/分母/缺失值写进表注。
  4. 以横线、缩进和等宽代码建立结构，红色只作冗余强调，确保灰度仍可读。
- **最高价值对象**：Table 1（API reduction 的 headline/interface 映射）和 Table 2（notation capability comparison）；Table 3 是低成本但协议不足的 efficiency evidence，Table 4 是揭示生态指标异质性的附录 comparison。
- **失败模式**：Table 1 的 examples 容易被误读为全 API coverage；Table 2 的 `Any other`/support taxonomy 缺少分母；Table 3 的 `±`、n、硬件和重复定义缺失；Table 4 的 snapshot、regex denominator、百分比不确定性和不可比 repository 标记主要留在 prose。
- **一句话视觉策略**：用单栏、serif + 等宽代码、最小规则线和离散能力/成本表，把“统一接口、对照 taxonomy、工程 overhead、生态使用”压缩成可扫读但边界仍需依赖正文的四步证据链。
