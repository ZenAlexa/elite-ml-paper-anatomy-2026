## 全文视觉系统

### 版式、字体与颜色

论文使用 A4 双栏正文，题名/摘要、宽图表、目录和证明页改变阅读节奏。Figure 2、3、5–13 以及 Tables 1、4、5、9 使用跨栏或近似页宽的视觉空间；Table 3、6–8 更接近单栏/窄幅。图中 sans-serif 标签与 PDF 外围的 Palatino-like serif 正文形成层级：`URWPalladioL`（Roman/Bold/Italic）承担正文/caption，DejaVu Sans/HelveticaNeue/Aptos 出现在图内标签，XCharter/Cambria math 与 tx 系列字体承担公式，LM Mono 只在代码样式/等宽标记中出现。正文和 caption 估计约 8–9 pt，图内刻度约 6–8 pt；较小图的文字在单栏缩放后核验成本高。

概念图使用浅黄、浅绿、浅粉、浅蓝、灰色卡片以及黑/灰箭头；定量图主要使用蓝、橙、绿、灰的 categorical palette，Figure 12 另用 viridis success colorbar 和气泡大小。表格以 booktabs-like 黑色规则和浅色 group header 为主。颜色在同一组图中往往有语义，但跨 Figure 5/6/10/14 的方法颜色和 caption 定义并不完全统一；多数 chart 通过线型/marker 或行列标签提供了一部分冗余编码，Figure 12 的连续色和气泡大小仍较依赖彩色阅读。

### 叙事骨架

视觉链条是：Figure 1 把 entropy 的盲点定义成二维问题；Table 1 和 Figure 2 把 proxy 与 SNR mechanism 接口化；Figure 3 与 Table 2 给出梯度证据；Figure 4 把筛选算子变成可执行流程；Figures 5–7 与 Table 4 展示主结果及行为签名；Tables 5–8、Figures 8–13 做指标、噪声边界、粒度、成本和机制 stress tests；Appendix Table 9 与 Figure 14 扩展替代 metric、sampling 和 proxy 曲线。正文主张与附录理论（H.2/H.3、J.1 等）有调用关系，但附录的 bias caveat 和假设不在每个主图 caption 中重复。

## Caption/header 与证据关系的跨对象判断

1. **Caption 系统**：caption 一般以“Figure/Table N:”直接命名对象，而不是粗体结论标题。Figure 1–4、9、13 和 Tables 1/4/5/9 较能独立交代设置/编码；Figures 6/7/10/11/14 和 Tables 2/3 更依赖正文。主图 caption 常写主发现（MI 方向、filter advantage、collapse boundary），但 seed、error bar/band 定义、aggregation 和分母几乎都不写。
2. **表头系统**：结果表使用 baseline/variant group 或多层 metric group；Table 4 的五个 pastel row groups、Table 5 的 NF/F/Δ 三层指标、Table 9 的 block headers 是最清楚的层次化模式。窄表通过短 header 节省版面，但 ✓/✗、`P/G`、`RV`、`Traj/Update` 等缩写多由正文解码。
3. **方法→结果→消融**：Figure 1 的二维定义和 Table 1 proxy family 把 construct 固定；Figure 2/3/Table 2 把 signal/noise mechanism 固定；Figure 4 把 mechanism 转成筛选操作。Figure 5/6/Table 4 负责主结果，Figure 7/8/10–13 和 Tables 5–8 负责行为、相关性、成本、边界与粒度，Table 9/Figure 14 把失败和 metric family 放回附录。
4. **正文→附录**：正文保留主故事和主比较，附录 p.24–44 给环境/训练细节、替代 filters、六种 proxy 与 H–N 的 theorem/proof；Figure 14 与 Table 9 是附录唯一的图表对象。Appendix J 的 filtered-estimator bias、Appendix H 的假设和 Appendix L 的松 bound 会改变对主文因果语言的强度，但没有在主图 caption 逐条重复。
5. **信息缺口**：所有主结果图表均缺 seed-level uncertainty 或样本量；Table 4 用 peak baseline+delta，Table 6/8 用单次/setting summaries，Figure 8 用 correlation。Figure 9 caption 的 color name 与渲染颜色不一致，Figure 6 的环境命名与正文段落也存在可见 mismatch。这些是对象证据质量的一部分，而非源代码问题。

## 最可复用模式、最高价值对象与失败模式

- **最可复用模式**
  1. 用 Figure 1 式二维 conceptual grid 明确现有 metric 未覆盖的轴，再让后续 proxy、机制图和结果图复用同一词汇。
  2. 用 Figure 3 的“行=算法、列=机制分量、x=分位 bucket”small multiples，把理论链条拆成可逐项证伪的视觉证据。
  3. 用 Figure 4 的三卡 pipeline 写清输入、按组统计、排序阈值和 update mask，避免只给一句“we filter prompts”。
  4. 用 Table 4/5/9 的 grouped headers 在一个 decision surface 同时呈现绝对性能、delta、成本和 collapse/failure；对 block-specific baseline 必须在 caption 明示。
  5. 用 Figure 9/11 和 Table 8 主动展示 proxy 的适用边界与失败分布，而不是只保留 positive result。

- **最高价值对象**
  - **Figure 1**：定义 entropy–MI blind spot，是全文视觉词汇的锚点。
  - **Figure 3 + Table 2**：把 SNR claim 连接到梯度分解、算法对照和可控噪声。
  - **Figure 4**：最清楚地把 method 变成可实现流程。
  - **Table 4**：横跨算法、规模、模型类型和模态的主 decision surface，同时保留负 delta。
  - **Figure 9 + Table 8**：给出 reward-variance proxy 的噪声边界，防止把方法写成无条件普适。
  - **Table 9 + Figure 14**：附录中最有复现价值的 failure/alternative/proxy completeness 对象。

- **失败或弱呈现模式**
  - 无 seed-level uncertainty、n 或 aggregation definitions，使 peak/delta、correlation 和 median 的稳定性难评估。
  - caption 过度压缩：Figure 6、7、10、11 没有完整定义颜色、阴影或 panel semantics；Figure 14 的“all proxies confirm”缺少一致性判据。
  - 颜色语义未完全跨图冻结；Figure 9 caption 写 orange 而 PDF bars 视觉为 blue。
  - 表格中的 block-specific baseline、✓/✗、缩写和 `P/G` 需要正文回查；Table 4/5/9 小字号降低页面缩放下的可核验性。
  - Figure 13 用两个 checkpoint 的直线代表 training trajectory，Figure 12 用阈值/趋势线但未报告计算规则；这些图适合机制叙事，不应被当作完整统计模型。

## 最终视觉判断

这篇论文的视觉策略是“先用二维概念图命名 entropy 的盲点，再用 proxy family 和 SNR gradient decomposition 将盲点操作化，随后以 prompt-level RV pipeline、跨配置结果和显式 failure boundary 完成诊断—机制—干预闭环”。最强的设计是 Figure 1→Figure 3/Table 2→Figure 4 的概念到操作链，以及 Figure 9/Table 8 对 proxy 适用范围的诚实展示；最需要改进的是结果对象的重复/不确定性与 caption 自包含性，以及 Figure 6/9 的命名/颜色一致性。公开 GitHub 项目页提供了大多数 figure 的 rendered assets，但没有精确的 plotting/table source，因此本审计所有数值、标签、页码和 caption 均以 PDF 观察为准。
