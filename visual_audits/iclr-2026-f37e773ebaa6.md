## 跨对象关系与结论

- **视觉叙事**：视觉叙事从 Figure 1 首页 montage 与 Figure 2 的异质轨迹/ARI 观察开始，经 Figure 3 的 offline cluster→solver→inference 接口，再用 Tables 1–5 覆盖 Qwen-Image、FLUX、HunyuanVideo、Qwen-Image-Edit 和 distilled models 的成本/质量，Figure 4/5 给 qualitative checks，Figure 6/7/8 给 geometry、solver-pool ablation 与 LoRA，Appendix Figures 9–15 给 distilled/video failure、ARI、极端条件和 early-step boundary。
- **Caption 系统**：所有对象均采用 “Figure/Table n:” 起始并置于对象附近；Figure 2/3/7/8/12/13 与 Table 1–5 的标题短语使用粗体，其他 caption 多为普通字重。主结果表 caption 只有任务/模型标题，设置、aggregation 和不确定性留在正文；Figure 2/6/11/13/14/15 caption 写出主发现，但多数 qualitative caption 不自包含。
- **表头系统**：五张表都把 acceleration（Latency、Speed、FLOPs、Speed）与 task-specific quality 放在同一决策面，使用 ↑/↓ 方向符号、两层 grouped headers、方法列和浅灰/bold 行高亮。Table 1/5 加 Quality/Perceptual Metrics；Table 4 用 GEdit-CN/GEdit-EN 的 SC/PQ/OS 对称分组；Table 2/3 保留 Efficient Attention 开关；Table 4/5 的 footnote 负责缩写/reference convention。
- **方法—结果—消融**：Figure 3 是方法接口，Table 1–5 是主成本/质量结果，Figure 4/5 是同任务 qualitative evidence；Figure 6/8/12/13 检验 cluster/LoRA 稳定性，Figure 7 是唯一直接的 solver-pool single-solver ablation，Figure 15 暴露 early-step failure boundary。没有 component deletion、k-sensitivity 或 offline overhead 的独立表/图。
- **正文—附录**：主文 Figure 2/6/8 已提出 assignment invariance；Appendix Figures 9–10 扩展 distilled image/video visual quality，Figure 11 扩展 ARI/drift，Figure 12–13 重复并汇总 LoRA，Figure 14–15 检验 extreme settings 和 early-step mitigation。附录没有表格，且 Figure 12 与 Figure 8 高度重复，新增信息主要来自 Figure 13。
- **字体一致性**：正文/caption 主要为 Nimbus Roman No9 L 与 Computer Modern；表体使用约 6.4–8.2 pt Nimbus/CM；图内 plot labels 多为 Times New Roman/Cambria，Figure 3 使用 Comic Sans/Calibri，qualitative headers 又混入 Times。因此语义结构较统一，字体系统只有局部一致。
- **颜色一致性**：blue/light-blue 是 cluster、ARI 和 PCA 的主要语义，red dashed 0.8 和 red HyCa/artifact labels 跨多对象复现；但 Figure 1/3 pastel 和 qualitative grids 的自然色不遵循同一 palette。多数 chart 依赖颜色区分，虽有 legend/row labels/threshold 等冗余，灰度安全性仍偏弱。

### 最可复用的模式
- 用“动态轨迹/稳定性分布→方法接口→主结果→solver/LoRA/极端条件扩展”的视觉链把机制和应用证据串起来。
- 将 acceleration cost 与 task quality 放进同一 grouped table，并用固定方法行、方向箭头、bold/灰色高亮支持快速决策。
- qualitative grid 固定 prompt 行和方法列；视频图用同一 prompt 的三帧对齐并以红框定位 failure。
- 在 appendix 用 ARI distribution、normalized drift 和 stress-test small multiples 追踪主文的 cluster invariance claim。

### 最高价值对象
- Figure 3：最清楚地把 one-time choosing/all-time solving、cluster-specific solver 与 compute/skip 执行连接起来。
- Figure 7：把主比较与 single-solver ablation 放在同一坐标语法，是“solver pool 有必要”的直接视觉证据。
- Tables 1–5：覆盖五个任务/模型族并将 latency/FLOPs 与质量指标放在同一决策面。
- Figure 11 与 Figure 15：分别补足跨条件稳定性统计和 early-step failure boundary。

### 失败模式
- 小字号和多列/多 panel 密度高，Figure 3、Figure 6–8、Table 1/2/5 在页面缩放下难读。
- 主表和大多数 qualitative 图没有重复、分母、区间或失败计数；ARI histogram 也未给 n/bin/aggregation。
- 颜色是许多 chart 的主 series channel，灰度可读性弱；红色 artifact/threshold 在低质量打印中可能消失。
- Figure 8 与 Appendix Figure 12 几乎重复；caption 标题粗体和 self-contained 程度不一致，且没有公开原始 plot/table source。

### 一句话视觉策略

论文以浅蓝 cluster/ARI 机制图和成本—质量 grouped tables 建立 HyCa 的可复用 solver 论证，再用 prompt 对齐的 qualitative grids 与附录 stress tests 展示跨任务质量和稳定性，但以高信息密度、点估计和有限可复现视觉源为代价。
