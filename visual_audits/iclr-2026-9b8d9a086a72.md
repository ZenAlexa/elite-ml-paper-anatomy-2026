### Figure 1（p2，method interface / theory mechanism）

**结构与布局。** 双栏宽的架构图由两个虚线外框组成：左侧 `Feature Extraction` 垂直堆叠 Image、红色梯形 `Input Encoder`、灰色 `Feature`；右侧 `Feature-Space Warping and Iterative Updates` 横向连接 Feature 2/Feature 1、圆形 `W`、橙色 `Recurrent Update Module`、输出 `f_{t+1}`，右上有 `×T` 和回环箭头。当前流 `f_t` 通过 W 索引 frame-2 feature；箭头和两级外框给出读图顺序。面板逻辑为 2，视觉复杂度 3/5，标注约 11 个，数据 mark 不适用。

**绘图语法。** `rendering=mixed`；无 x/y 轴（`none/none`）、无网格、无 legend、direct labels=true；marker_types=1（W 圆形），line_styles=2（实线流程箭头、虚线模块框），hatching=false，reference_lines=0，uncertainty_display=none，箭头/框线约 1.0 pt（渲染估计），provenance=mixed。类型为 `architecture`、`pipeline`、`conceptual_diagram`；purpose 为 `method_interface`、`theory_mechanism`。

**字体与颜色。** PDF 对象显示 `HelveticaNeue` regular/medium，图内主标签约 9.3 pt，组标题约 8.7 pt；数学 `f_t/f_{t+1}` 使用 `STIXGeneral`，下标约 5.3 pt，字体对象置信度高。渲染估计中性灰约 `#929292`、编码器红约 `#B51700`、更新模块橙约 `#FF9300`、流程缩略图紫/蓝约 `#6D47E8`，另有黑/白；共约 5 个功能色。形状、位置和文字与颜色共同编码，`redundant_encoding=true`；结构可灰度识别，但流程缩略图的颜色语义仍会退化，`grayscale_safe=true` 仅指模块关系。

**数据、统计与证据关系。** 机制图无样本、单位、分母、重复或不确定性；图中两幅流缩略图只作 illustrative state。引言/§3 的 cost-volume 代价问题 → Figure 1 给出 input encoder + recurrent update + feature-space warping 接口 → §4 展开编码器、更新模块和迭代流程 → Table 1 的成本、Figure 3/4 的定性结果、Table 5 的组件消融验证该接口。图承担机制接口，未承担数值 headline。

**Caption。** 原文：`Figure 1: The meta-architecture of WAFT consists of an input encoder and a recurrent update module. We first extract image features from the input encoder, and then use these features to iteratively update the flow estimate for T steps. At each step, we perform feature indexing through a lightweight backward warping on the feature of frame 2, removing the dependency on expensive cost volume used by previous work.` 词数 68；动作包含 `title`、`setup`、`comparison`、`main_finding`。标题非粗体结论式；caption 自包含，明确 T-step 更新、frame-2 backward warping 和 cost-volume 依赖移除，并直接说出方法主点。

**优点。**
1. 以两个外框把特征抽取和循环更新分开，组件边界与 §4 文字一一对应。
2. `f_t → W → update → f_{t+1}` 和 ×T 回环把迭代状态传递显式化，减少读者对更新顺序的推断。
3. 结构形状、颜色、标签和箭头有冗余，缩略图即使不读取数值也能说明输入/中间/输出角色。

**缺陷。**
1. 模块颜色没有跨全文的图例或规范，颜色只在本图内有效；色盲读者主要依赖形状与文字。
2. 虚线组框和中心流程共享相近黑色线宽，W 的索引算子与普通箭头在缩小后区分度有限。
3. 该图能说明接口，却不能暴露 recurrent updater 的内部注意力、分辨率或计算量；这些边界需要正文和 Table 5 补足。

**可复用范式。** 用“输入编码 → 单次可解释索引 → recurrent update → 输出回环”的双组框架呈现替代组件；保留直接标签和回环箭头，并在源图规范中固定角色色、线宽和数学字号。

1. 三栏把“全候选—局部候选—单对应点”压缩为一个可扫描的复杂度梯度。
2. 红框与连线数量共同呈现 partial 与 full 的差异，Warping 的单线结果很醒目。
3. caption 对视觉相似度、neighborhood 和 corresponding pixel 的语义解释足够完整，可脱离正文阅读。

1. 像素网格尺寸和邻域半径是示意值，caption 没有标注“非比例示意”，容易被误读为真实分辨率。
2. 连线重叠较多，full 面板中心汇聚后局部密度高，缩小查看时单条线难追踪。
3. “更高准确率”是论文实验主张，图本身没有误差或数据支持，需要依赖后续表格。

**可复用范式。** 对资源瓶颈用并列结构图固定同一查询点，再逐步减少候选集；使用数量/范围的视觉冗余，并在 caption 中明确示意图不承载数值比例。

- **视觉叙事**：Figure 1 给出 WAFT 的两段式接口，Figure 2 将 warping 与 full/partial cost volume 的查询范围并列，Table 1 量化显存失败，Figure 3/4 展示高分辨率与跨 benchmark 的视觉输出，Table 2/3/4 汇总主比较和泛化，Table 5 回到组件机制，Table 6 拆解 Sintel outlier。顺序形成“为什么替换 → 如何替换 → 资源/结果 → 消融与边界”的证据链。
- **Caption 系统**：caption 均以对象编号和标题起句，主比较表比定性图更完整地写出 split、硬件和主结论。Figure 4 和 Figure 3 缺少色标/行语义，Table 5 依赖 §5.5；Table 6 的 caption 与实际高亮不一致。
- **表头系统**：性能表使用 dataset/metric 两层 grouped header，方向箭头集中在指标名；Table 1/5 将分辨率、步骤、成本列与结果列并置；Table 6 使用方法列展开序列。字体、booktabs 规则和小数对齐一致，但 Table 3/4/6 的字号偏小。
- **方法—结果—消融链接**：Figure 1/2 的组件与查询机制在 Table 1（memory）、Table 2–4（accuracy/generalization）、Table 5（component perturbation）中重复出现；Figure 3 的 high-resolution boundary claim 有 Table 5 对照，Figure 4 仅提供 qualitative context。Table 6 负责把 Table 2 的总体 Final EPE 拆成序列级证据。

## 7. 最终判断

- **最可复用模式**：双组架构图把接口和循环状态显式化；并列 full/partial/warp 示意图用候选范围的结构差异解释效率机制；表格以 grouped headers 同时呈现指标、分辨率、成本和失败状态；消融表固定 baseline、按机制分组并把 MACs 与结果放在同一决策面；附录逐序列表保留 outlier 影响和去除 outlier 的敏感性切片。
- **最高价值对象**：Figure 1（方法接口）、Figure 2（效率机制）、Table 2（主结果与推理成本）、Table 5（机制消融）共同承担论文核心论证；Table 6 对总体 Sintel 结果提供必要的异常值边界。
- **失败模式**：定性 Figure 3/4 缺少共享色标和样本选择规则；Figure 4 caption 过短；小字体压缩 Table 3/4/6；点估计表格缺少重复和不确定性；Table 6 caption 承诺最佳值高亮但 PDF 没有可见标记；Table 5 彩色行组缺少灰度冗余。
- **一句话视觉策略**：论文以“架构接口—查询范围机制—成本与 benchmark 排名—组件消融—逐序列边界”的链条，用紧凑概念图和 grouped-header 表格支撑 WAFT 用高分辨率 warping 替代 cost volume 的主张，但定性图色标、表格不确定性和 Table 6 高亮执行仍需补齐。
