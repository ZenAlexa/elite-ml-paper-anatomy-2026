## 跨对象判断

- **视觉叙事：** Figure 1 turns the geometric mismatch into a toy path/energy story; Figure 2 shows artifact differences; Table 1 places fidelity, artifact proxies and alignment in one cross-model surface; Figure 3 adds human preference heterogeneity; Tables 2–4 and Figures 4–5 remove metric/strength/schedule alternatives; Tables 5–11 document protocols, pooled user statistics and extended robustness; Figures 6–7 extend the qualitative claim to SD3.5 and Flux.1.
- **Caption 系统：** Captions use an italic Figure/Table label followed by a short title; main tables and appendix user-study/schedule captions often bold the title and state the headline comparison. Figure 4–5 captions are title-only, while image-grid captions explain settings and claimed artifacts. Encoding keys and uncertainty definitions are uneven: Figure 3 relies on its legend, and Table 8’s interval/test details are mainly in surrounding prose.
- **表头系统：** Tables use centered/italic or bold headers with metric-direction arrows where a metric is optimized, grouped model/method columns for main results, and a minimal horizontal-rule hierarchy without vertical rules. Main Table 1 uses model blocks and guidance rows; appendix tables shift to protocol, parameter, user-study and schedule headers.
- **方法—结果—消融：** The visual sequence mirrors the method interfaces: MOG metric → Auto-MOG energy balance → image symptoms and cross-model outcomes → metric/ρ/scale/γ/schedule ablations. Table 2 tests metric components, Table 3/11 test ρ, Figure 4 tests scale/steps, Figure 5 tests γ, and Table 10 tests fixed/linear schedules.
- **主文—附录：** Main Figures 2–3 and Table 1 are expanded by Appendix Tables 5–9 and Figures 6–7; main Tables 2–4/Figures 4–5 are extended by Tables 10–11. Appendix E supplies the user-study denominator and failure analysis that the main captions omit, while §H records boundaries with no additional visual object.
- **字体一致性：** Page-level typography is consistent across double-column main text and single-column supplement (embedded Nimbus Roman/Computer Modern with mathematical faces). Plot labels are smaller and often sans-like, and raster grids contain their own micro-labels; this creates a readable paper shell but uneven object-level size and source provenance.
- **颜色一致性：** Black/gray tables and white canvas are stable. Method curves use a recurring Matplotlib blue/orange/green vocabulary, while Figure 3 and the appendix grids introduce local categorical keys. The grids redundantly use colored borders plus CFG/Auto-MOG tags, but Figure 3 depends primarily on color and the natural-image grids are not grayscale-safe.

## 最终判断

### 最可复用模式
- 把机制示意图、机制相关 proxy、headline 对比和针对替代解释的消融排成单向视觉叙事；每个对象都回指同一方法接口。
- 主结果表用模型 block × 方法 row 的重复语法，同时把 fidelity、artifact proxy、alignment 和方向箭头放在同一决策面。
- 定性比较固定 prompt/seed 行与方法列，并用列位置之外的 border+text 冗余编码方法身份。
- 参数稳健性用小 multiples 或简短 sweep 表呈现，并在表头写出 metric direction 与具体 setting。

### 最高价值对象
- Figure 1：把 off-manifold drift、方向修正和能量下降压缩成可读的机制入口，但应与真实轨迹测量区分。
- Table 1：唯一同时覆盖六个模型 block、六种 guidance 和 fidelity/artifact/alignment 指标的 headline surface。
- Figure 3：在同一 100% stacked grammar 中暴露模型与领域偏好异质性，并由 Table 8 补足 pooled denominator。
- Table 10：把 fixed CFG、linear decay 和 AutoMOG 放到同一 schedule counterfactual 中，最直接回应“只是降低强度”的替代解释。

### 失败模式
- 定性网格缺少 prompt、seed 和选择规则，且 Figure 2 caption 未列出 MOG-Score；视觉案例难以复现。
- Figure 4–5 caption 过于简短，双 y 轴、窄 y 范围和无 uncertainty 会放大微小趋势。
