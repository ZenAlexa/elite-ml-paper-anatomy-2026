- **visual_narrative**：视觉叙事从 Figure 1 的双输出 headline，经 Figure 2–3 的“复用 3D 模型并对齐 latent”接口，进入 Tables 1–5 与 Figure 4 的主性能/定性证据，再由 Figures 5–6、Table 6、Figures 7–10 检验 layer criterion、reward alignment 和 noise robustness，最后以 Figures 11–16 扩展 benchmark、pointmap、novel-view 与长序列边界。

- **table_header_system**：表格统一以 Method/Model 为第一列、无竖线的 booktabs 规则和箭头方向；Table 1/5 用多层 spanner（benchmark/representation→dataset→metric），Table 6/1–2 用 Unified Reward 分组，灰行/粗体/下划线承担 best/variant 识别。
- **method_result_ablation_link**：Figure 3 把 model stitching 与 direct reward finetuning 定义为两个组件；Tables 1–5 建立生成、NVS、pointmap/pose 主结果；Figure 5/6 与 Table 6、Figures 7–8 分别将 layer criterion、CKA、reward components 和 integrated-vs-sequential robustness 连接到机制/失败现象。
- **main_appendix_link**：正文 Figure 1/4 与 Tables 1–5 通过文字指针连接 Appendix Figures 7–16、Table 6–7；附录覆盖更多同 prompt baseline、decoder variant、camera trajectory、pointmap、VBench 与 extended frames，但没有补充完整 quantitative uncertainty 或 sample denominators。

## 最终判断

- **most_reusable_patterns**：
  - 以相同方法列和匹配视角组织 benchmark qualitative grid，并用 caption 明确每个 block 的数据集/任务。
  - 将 layer-wise diagnostic 与 downstream metric 放在同一多 panel 图（Figure 5/10），同时显式区分 log/linear 轴和 within-pair/cross-pair 结论。
  - 用“原始模型→拼接变体”或“无训练→单 reward→双 reward”的分组表，把机制组件和结果指标放入同一决策面。
  - 在 robustness 图中把数值曲线与同一扰动参数的图像 strip 对齐（Figure 8），让可见伪影与指标退化互相校验。
- **highest_value_objects**：
