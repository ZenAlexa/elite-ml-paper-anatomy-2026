## 证据闭环与跨对象系统

1. **问题与接口**：Figure 2 把引言的 annotation/deployment gap 变成训练双阶段与 mask-free inference 接口。
2. **机制**：Figure 3 将 dual encoder、noisy pseudo-label、LoRA、occlusion head、adaptive weighting、DDIM 和 gradient backflow 放在一个可追踪的流程中；Figure 4 用两个样本把 `M^{prior}` 与 `M^{pred}` 对齐。
3. **主比较**：Table 1 汇总 Chinese subtitle test set 的 reconstruction、perceptual、temporal、flow、time 指标；Figure 5 用两组视频逐帧对照 baseline 与 CLEAR。
4. **消融与权衡**：Table 2 将 Figure 3 的模块按 M1–M4 累加，Table 3 给出 steps/CFG/LoRA scale 的质量—时间权衡，Figure 6 给出 LoRA-only 对 full CLEAR 的定性补充。
5. **附录扩展**：A1/A2 扩大基线场景，A3–A5 扩大语言和内部 mask overlay；它们扩展案例数但没有补逐语言统计、误差或 failure set。
6. **系统性弱点**：主图和附录的颜色常承担唯一条件身份，缺少形状/纹理冗余；Figure 3 的配置文字与正文/表格存在 rank、backbone/参数比例、schedule 不一致；A3–A5 图注的 Arabic 与图内 German 不一致；Table 1–3 全部没有 run-level uncertainty。

## 最终判断

### 最可复用模式

- 用 Figure 2 的“训练期辅助信号／部署期最小输入”平行泳道明确接口边界。
- 用 Figure 3 的三列管线将训练 prior、可学习权重和内部推理串成单条机制链，并显式画 gradient flow。
- 用 Figure 4 的固定列序展示 noisy prior 如何变成 adaptive weight，同时标明哪些 mask 仅在训练期存在。
- 用 Table 1 的指标分组与 time 同表、Figure 5/6 的统一 Input—baseline—Ours 帧对齐，形成定量—定性闭环。
- 用 A3–A5 的 Input—Mask Overlay—Output 模式解释“训练使用 guidance、推理不输出 mask”的生命周期。

### 最高价值对象

- **Figure 3**：机制接口信息最完整，适合复现但需要修正配置冲突。
- **Table 1 + Figure 5**：同一 Chinese test set 上的指标和可视化对照互相支撑主结果。
- **Table 2 + Figure 6**：模块累计消融与 LoRA-only 对照共同解释收益来源。
- **Figure 4**：对 mask/prior/weight 关系的视觉解释最直接。

### 失败模式

- Figure 3 的高密度小字、颜色主导编码和不一致配置会阻碍独立复现。
- Figure 5/A1/A2/A3–A5 依赖小尺寸真实帧，caption 未提供样本、帧数、来源和量化定义。
- Table 1–3 只报告点估计，缺分母、重复和不确定性；Table 3 共享 time 值的留白容易被误读。
- 附录 A3–A5 的语言 caption 与图内语言条不一致（Arabic/German），削弱 zero-shot 覆盖主张。
- 颜色和红色虚线框缺少灰度冗余；Figures 1、5、A1 等定性对象难以在低分辨率独立阅读。

### 一句话视觉策略

CLEAR 用 Computer Modern 风格的黑白论文骨架和低饱和阶段色，把双阶段训练、adaptive mask/weight 机制、Chinese quantitative comparison、视频帧定性对照与跨语言 overlay 案例串成“训练期 prior → 内部推理 → 质量/成本权衡 → zero-shot 展示”的视觉证据链；其主要代价是复合图密度高、配置与语言图注需校正、统计不确定性缺失。
