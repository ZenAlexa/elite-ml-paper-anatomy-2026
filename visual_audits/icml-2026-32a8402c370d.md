## 最终判断

- **最可复用模式**：
  1. 用 paired panels 固定坐标，直接比较一个机制干预的 symmetric/asymmetric 版本，并把 theoretical regime 画成 reference annotation。
  2. 用“原函数、干预后函数、保持的最优点”概念图解释定理，再由 ternary trajectory grid 把抽象策略约束落到可见动态。
  3. 对多任务曲线复用 panel 顺序、共享坐标和真实 strategy-update 横轴，caption 明确多 run 的成本换算和 band 定义。
  4. 用 `x_i × y_j` 紧凑 payoff matrix 和 `Game × Algorithm × η × μ` 配置表作为实验图的可复现接口。
- **最高价值对象**：Figure 1 是理论现象的 headline；Figure 2 是方法机制接口；Figure 3 是 last-iterate dynamics 的直观桥接；Figure 4 是 extensive-form 的主比较。附录 Figure 6 的 standard-error bands、Figure 8 的 μ sensitivity、Figure 9 的 CFR baseline 和 Table 4 的逐 game 配置对复现边界最有价值。
- **失败模式**：
  1. Figure 1/5 的单实例曲线没有重复或不确定性，阈值只以 annotation 呈现。
  2. Figure 4/9 的 extensive-form curves 没有 seed、误差、失败值或终止规则，六色 legend 也没有 marker/linetype 冗余。
  3. Figure 3/7 的 ternary initial strategies 没有独立 legend，颜色依赖较强；高密度 grid 缩放后小刻度难读。
  4. Figure 2 没有坐标尺度，Figure 8 没有把理论 threshold 画成 reference line；定性机制与定量界限需要跨页拼接。
  5. Table 4 显示了按 game/algorithm 变化的 η、μ，却没有说明选择协议、预算或 seed；作者仓库没有最终 TeX/plot/table source，完整重绘仍需自行实现。
- **一句话视觉策略**：用一组 paired proximity curves 和 objective-landscape schematic 先展示 asymmetric perturbation 的 invariance 机制，再用固定 simplex 的 trajectories 与 cost-normalized multi-game NashConv 曲线承接理论到实践，最后以附录的矩阵、μ 扫描、CFR 对照和 hyperparameter table 补齐可复现边界。
