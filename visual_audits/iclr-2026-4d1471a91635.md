## 跨对象系统判断

- **视觉叙事**：论文先把评价单位从静态 generation quality 推到 closed-loop utility（Figures 1–2），再给出 proposal/API/WM/revision interface（Figure 3）和四任务 scope（Figure 4），用 Tables 1–3 给出主结果，以 Figures 5–7 与 Tables 4–6 做 scaling、context、revision、domain ablations；附录 Figures 8–11 解释机制与输入，Tables 7–11 固化配置、成本和数据集，Figures 12–18 展示采样和 prediction failures。该链条把“benchmark 是什么—为何有效—在哪些条件下失效”连起来。
- **Caption 系统**：主文 Figure 1–7 的 caption 通常包含 setup，Figure 2、5 的派生指标定义较充分，Figure 6–7 直接写出 scaling trend；Table 1、5–7 会写方向或缩写。附录 Figures 15–18 使用重复的 7 词 caption，弱化了案例的 model/scene/action provenance；Table 8–11 的配置 caption 也偏短。
- **表头系统**：主结果用 `Model Details` + task group 的二级表头，方向箭头直接放在指标名；ablation 表用 component/domain/context 列表达反事实，附录 inventory/cost 表改为单层表头和 row-group band。group fill 有助于跨任务扫描，但颜色不是全局方法语义，必须依赖文字。
- **方法—结果—消融**：Figure 3 的四阶段 interface 在 Table 1–3 体现为统一 WM comparison，在 Table 5 拆成 WM/revision components，在 Figure 5 分离 quality/control，在 Figures 6–7 展开 training/inference budget，在 Table 6 试验 domain transfer；Figure 8–11 为主 claim 提供案例化 mechanism，Figures 13–18 给出 failure boundary。
- **正文—附录关系**：正文 Figures 1–7 和 Tables 1–6 给出最小论证面；附录 Figures 8–18、Tables 7–11 负责 policy control、视觉机制、配置、成本、数据构造和错误样本。主文 caption 对附录没有大量显式 pointer，但正文段落会回指附录章节；附录 qualitative grid 的极短 caption 使其脱离正文后不够自包含。
- **字体与颜色一致性**：表格横线、箭头方向、sans/roman 混排整体稳定；图内字体、照片与 diagram asset 来源混合，figure-specific chart 的 DejaVu Sans 与正文 Times-like 不完全同构。主图 categorical colors 在每图内清楚，但没有跨图固定模型颜色，灰度安全性有限；marker、direct label、row-group 和文字能部分补偿。

## 最终判断

- **最可复用模式**：
  1. 用 Figure 1 的“平台/任务—leaderboard—scaling/correlation”overview 建立视觉论证地图，但为每个 mini-panel 保留可读单位与指标入口。
  2. 用 Figure 3 的 real loop + imagined planning box + numbered stages 把异构模型统一到可执行 interface。
  3. 用 Tables 1–3 的 grouped headers 把模型属性、任务指标和方向箭头放在同一比较面，再用 Tables 4–6 做组件、输入和域的 paired ablation。
  4. 用 Figures 8–11 的 candidate/prediction/real branches 展示机制，用 Figures 13–18 的 fixed-action Good/Bad grids 展示可审计的 failure boundary。
  5. 用 Tables 8–11 显式记录 repository、frame horizon、resolution、资源和 dataset modalities，补足性能表无法复现的条件。
- **最高价值对象**：Figure 3（统一闭环接口）、Table 1（跨模型/任务主比较）、Figure 5(b)（controllability 与 SR 的局部机制证据）、Figure 6/7（两类 scaling）、Table 5（WM/revision component ablation）、Figure 8/9（预测观察如何进入 planning/perception）。
- **失败模式**：qualitative grid 的 caption 反复写成 `Additional examples...`，没有 model/scene/action/frame provenance；多张 chart 没有不确定性或重复协议；彩色 categorical encoding 的跨图语义不稳定且灰度可读性弱；窄栏中小字体、长 URL、密集标签和箭头交叉增加核验成本；Table 10 的“cheaper”与 Figures 13–18 的 good/bad 证据都缺少可量化分母/筛选规则。
- **视觉策略一句话**：以统一 closed-loop interface 为主轴，把静态视觉质量与 embodied utility 分离，再用跨任务主表、paired scaling/ablation 图、配置/成本附录和固定动作的 Good/Bad 诊断网格组成从 benchmark framing 到机制与失败边界的证据链。
