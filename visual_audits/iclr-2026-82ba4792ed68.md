- **优点**：14 个数据集、三类 regime 和 split 在一个稳定表格中可复核；整数逗号和百分比格式清晰。
- **缺陷**：caption 过短，数据集来源、homophily 定义和 split 语义不在表内；regime group label 占用视觉空间但没有单独列头说明。
- **可复用模式**：在附录用 regime-grouped dataset statistics 表作为所有结果对象的索引；caption/脚注应补来源、统计口径和 split 定义。

## 跨对象系统

- **视觉叙事**：Figure 1 先定义 Prompting、GraphTool、Graph-as-Code 三种 interaction surface；Tables 1–3 依次覆盖 short-text homophilic、heterophilic、long-text homophilic regimes；Figures 2–4 把性能比较推进到 feature/edge/label deletion surfaces；Tables 4–7 在附录展开 model-size、reasoning、token、latency；Tables 8–11 提供 summary、random-adjacency、synthetic algorithmic、supervised controls；Table 12 作为 dataset index。整体叙事从接口→结果→依赖→资源/替代解释→数据背景。
- **Caption 系统**：所有对象 caption 以编号和标题开头；Figures 2–4 说明 metric/method/dataset/deletion setup，Figures 1/3 仍依赖图内标签和正文；Tables 1–3/8 明确 best/runner-up encoding，Tables 4–12 以 title/setup 为主，没有 caption 中的主发现粗体。整体 caption 以描述为主，只有表格的 bold/underline 规则承担排序提示。
- **表头系统**：主表把 dataset 作为列、interaction mode/baseline 作为行，顶部 metadata 将 classes/text length/homophily/degree 与 accuracy 对齐；附录表按用途切换为 model/reasoning columns、cost columns、path-length columns 或 architecture row groups。规则统一为无竖线横向 booktabs-style，减少网格噪声。
- **方法—结果—消融链**：Figure 1 的 access contract → Tables 1–3 的 cross-regime accuracy → Figures 2–4 的 dependency/robustness surfaces → Tables 6–7 的 cost → Tables 8–11 的 mechanism and alternative controls。主线的主要缺口是接口的实际 resource set 不匹配：Graph-as-Code 可 query 任意 DataFrame 行列，Prompting 使用预组装邻域；因此 surface 的视觉对齐不等于 fully matched treatment。
- **正文—附录链**：正文 Tables 1–3 与 Figures 2–4 负责主证据；Tables 4–5 补 model/reasoning axes，Tables 6–7 补 deployment cost，Tables 8–11 补 summary/noise/algorithmic/supervised controls，Table 12 补数据统计。页 20 的 Example 1 与页 21–23 Templates 1–3 是 qualitative/reproduction artifacts，不计入 Figure/Table 清单但解释 Graph-as-Code 的可访问权限。
- **字体一致性**：页面正文/表格使用 Nimbus Roman + Computer Modern math；热图内部 sans-serif 为嵌入栅格的 rendered estimate；附录代码模板使用 Nimbus Mon。表格内字体和规则稳定，图内字体来源不同，属于视觉一致性较弱的 raster 子系统。
- **颜色一致性**：Figure 1 的三类模式使用 pastel categorical labels；Figures 2–4 的共享 viridis-like sequential palette 在热图系列内部一致；所有 Tables 采用黑白和 weight/underline 强调。颜色有局部语义稳定性，但没有跨接口和热图共同的 palette token；灰度打印对连续色阶和 Figure 1 分类不完全安全。

## 最终判断

- **最可复用模式**：
  1. Figure 1 的同构三路 interaction-surface 图，把输入可见性、操作能力和反馈方向放在同一流程坐标中。
  2. Figures 2–4 的 matched 2D deletion heatmaps：固定 dataset columns、method rows、百分比轴和共享 colorbar，把 dependency surface、崩溃区和稳健区直接并置。
  3. Tables 1–3 的 regime-specific 结果模板：metadata→baselines→interaction modes，显式保留 `TokenLimit` 和 best/runner-up。
  4. Tables 4–5/8–11 的 row-group/多层表头消融，把 model scale、reasoning、summary exposure、random adjacency、algorithmic task 和 supervised context 分别放在可扫描的对照结构中。
  5. Tables 6–7 将准确率主线之外的 token 与 wall-clock 成本对齐，避免把资源瓶颈隐藏在失败单元格里。
- **最高价值对象**：Figure 1 是 access contract 的核心方法图；Table 3 最直接暴露 long-text/token-limit regime；Figures 2–4 是机制/稳健性证据；Table 8 与 Table 9 分别给出 exposure-only 和 structure-noise controls；Table 12 为全套 dataset columns 提供复核索引。
- **失败或低价值模式**：Figure 2–4 的栅格热图没有 seed dispersion、删除 realization 或 TokenLimit status layer；Tables 1–5 的 `±` 未定义，Tables 8–11 又切换为 point accuracy，统计口径不一致；Figure 3 浮动宽度偏窄；captions 普遍不自包含，Table 12 尤其过短；Table 11 混入外部 imported results，不能视为匹配实验；没有公开绘图/表格/LaTeX 源，视觉无法做 source-level 复现。
- **一句话视觉策略**：用 Figure 1 定义三类信息交互界面，用主表和同构 deletion heatmaps 将跨数据集结果与依赖机制连成一条线，再用附录的 scale/reasoning/cost/control 表补足可运行性、替代解释和数据范围。
