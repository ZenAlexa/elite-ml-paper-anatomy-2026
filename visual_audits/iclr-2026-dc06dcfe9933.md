## 跨对象系统判断

- **视觉叙事**：正文按“接受率 Figure 1 → solver runtime Table 1 → time-budget acceptance Table 2”收束 headline；附录 O 用 Figure 2/3 做 greedy 机制切片，P 用 Table 3 复制 Gemma runtime，Q 用 Figure 4/5 做温度 robustness 与 failure-cost，R 用 Table 4 接到 SpecTr 多步 walltime，S 用 Table 5 结束在 non-i.i.d. 可扩展边界。主文图表与附录对象之间有明确文字回指，但 headline 依赖读者跨页追踪。
- **Caption system**：统一 `Figure/Table n:` 普通罗马体开头，无 caption 内粗体结论标题；Table 1/3 caption 最完整，包含单位、比较、红色下界、success rate 与理论偏差；Figure 2/3、Table 4/5 更像对象索引，关键发现留在相邻正文。大多数 caption 与对象合看可独立理解，但颜色方向、failure denominator 和 winner 配置经常缺失。
- **Table header system**：solver 表用 `(k,n)`+方法列，Table 2 用模型组二级表头，Table 4 用指标+单位复合表头，Table 5 用 drafting regime+Step 1–3；语义层级清晰但缩写（G.R., M.F.）依赖 caption，且 optimized max-flow 在 Table 2 没有独立列。
- **Method–result–ablation link**：Section 5 的 max-flow/optimized max-flow 与 Section 6 的 global resolution 在 Table 1/3/2 中以方法列出现；附录 O 对比 greedy，Q 改变 temperature，R 检验 SpecTr integration，S 逐步拆解 non-i.i.d. 迁移。这条链是完整的，但图表没有把 theory guarantee、success rate 和 empirical acceptance 放到一个共同的 visual grammar 中。
- **Main–appendix link**：p.9 Figure 1 明确指向 Appendix O，p.10 §7.3/7.4 明确指向 Q/R，正文把 Table 1/2 的设置和结论交给 P/Q/M 扩展；附录对象反过来复用正文的颜色/列语义。Table 3 是 Table 1 的同构补充，Figure 2/3 是 Figure 1 的差值版本。
- **Typography consistency**：表格和正文使用嵌入的 Nimbus Roman/Computer Modern 体系，表体约 8.7 pt 且结构稳定；图全部是 DejaVu Sans 外观栅格。Figure 2/3 以整页双栏宽度显示，Figure 1/4/5 被拆成小 panel 后字号显著下降，导致跨对象可读性不一致。
- **Color consistency**：Figure 1/4 用颜色表示 `k`，Figure 5 用同一前三色/红色表示 `n`，每幅 legend 都明示语义；热图独立使用 zero-centered RdBu 类色标。tab 颜色保持一致是优点，但颜色在不同对象中承担不同变量，且所有曲线均无 marker/线型冗余，打印与色觉缺陷场景不稳。

## 最终判断

- **最可复用模式**：
  1. 以 Figure 1 的双模型同轴 line panels 把离散 n 扫描和 k 的收益拐点放到同一 headline 视觉中；
  2. 以 Table 2 的“资源上限 × 模型组 × 方法”结构把速度与 acceptance 变成可执行决策面；
  3. 以 Figure 5 的 paired cost/failure panels 显示 temperature regime，而 Table 5 用无色 pipeline matrix 明确理论扩展边界。
- **最高价值对象**：Figure 1（主接受率结论）、Table 2（时间预算下的实际选择）、Figure 5（适用温度与失败代价）、Table 5（方法边界）。
- **主要失败模式**：Figure 1/4/5 的 raster panel 缩放把字体压到约 3–5.5 pt；曲线、热图和表格高亮过度依赖颜色/粗体；Figure 2/3 的真实 k 数值以等距 categorical 行呈现；Table 1/3 把 runtime、lower bound/OOM 和 success rate 混在同一单元格；所有实验图表都没有重复/seed、分母或不确定性；Figure 5 各 k block 独立 y 轴且 caption 未写关键低温结论。
- **一句话视觉策略**：论文用统一的 k/n 参数颜色、双栏小 multiples、零中心差值热图和紧凑 solver 表，把“高接受率—低求解成本—温度/非 i.i.d. 边界”的理论算法论证串成一条主线，但以栅格缩放、颜色单编码和缺少重复统计换取了版面密度。
