- **Palette / rendering:** Main scaling figures use saturated red/blue/green/purple/orange trajectories plus a gray dashed Qwen baseline; process diagrams use pastel stage hues; prompt cards, qualitative traces and robustness summaries use grayscale/neutral ink. Color is usually paired with position, marker, line style or direct text, but several dense panels remain color-dependent. No raster-only scientific figure was identified from 200 dpi inspection.
- **Consistency:** Captions consistently use a bold opening title/claim followed by regular explanatory text, while figures repeat a sans-serif chart face, thin gridlines and saturated categorical colors. Tables share booktabs-like rules and grouped benchmark headers. Appendix prompt cards and long tables intentionally trade size for reproducibility/completeness.

- **visual_narrative:** The visual sequence moves from headline scaling (Figure 1) to the six-stage curation interface (Figure 2), the selected 1.2M accounting flow (Figure 3), then appends stage ablations, full benchmark scaling, compute/length diagnostics, safety/generalization checks and prompt reproductions. Figures 5–7 and Tables 31–48 make the main-to-appendix link explicit.
- **caption_system:** Every PDF caption begins with a bold title or finding phrase, then uses regular text for setup, comparison and caveats. Main figures are unusually explanatory (Figures 1, 5–8, 11–12), while prompt screenshots and Figure 3 are title-only. Tables often state the decision rule and point to full appendix tables.
- **table_header_system:** Performance tables use a left condition/model/source column followed by grouped benchmark columns and domain row labels. Metadata tables use explicit units or ranges. Vertical rules separate model families or full-scale versus controlled groups; horizontal booktabs rules establish table hierarchy.
- **method_result_ablation_link:** Figure 2 names each curation decision; Tables 2–7 test those decisions in order; Figure 5 stacks selected winners; Figure 3 renders the final recipe; Figures 6–10 and Tables 8–30 test scaling, compute, transfer, safety and failure boundaries; Tables 31–48 preserve omitted candidate rows.
- **main_appendix_link:** Figure 1 points to Figure 6, Table 2 points to Tables 31–33, Tables 3–7 point to Tables 34–48, Figure 2 points to Appendix O prompt cards, and Figure 11 points to AIW references. The link is strong in captions, although held-out panels are not visually marked in Figure 6.
- **typography_consistency:** Nimbus Roman/Computer Modern-like paper text, bold caption lead-ins and compact chart/table text are consistent across main and appendix pages. The monospaced prompt/trace artifacts form a deliberate secondary type role; appendix long tables fall to approximately 6 pt and are the main legibility compromise.
- **color_consistency:** Red/blue/green/purple/orange recur as model or pipeline identities in scaling charts, while gray dashed lines consistently denote Qwen baselines. Process and prompt objects use independent pastel/grayscale systems, so color semantics are local to each object rather than globally categorical.

## Final judgment

### Most reusable patterns
- Shared-baseline log-scale small multiples for showing recipe scaling across heterogeneous benchmarks.
- Cumulative pipeline curves paired with one-factor ablation tables, preserving both narrative and causal isolation.
- Horizontal prompt cards with monospaced text, exact placeholders and a direct downstream table link for reproducibility.
- Variation-level grouped bars followed by horizontal distribution summaries for separating average utility from generalization instability.
- Alluvial accounting for dataset retention and repeated-answer expansion, with explicit intermediate counts.

### Highest-value objects
- Figure 1: concise cross-domain headline with shared log x-axis and Qwen reference.
- Figure 5: visualizes the cumulative contribution of each pipeline step and explains the science-domain exception.
- Figure 6: twelve-panel benchmark-level expansion of the headline, including held-out tasks.
- Table 2 plus Tables 31–33: connects source quality to the full long-tail candidate set.
- Figure 11 and Figure 12: complementary instability/average views for AIW generalization.

### Failure patterns
- Dense appendix grids and long tables compress labels, series and standard-error subscripts below comfortable reading size.
- Color-heavy categorical charts often lack complete grayscale redundancy, especially when many trajectories overlap.
- Several captions state findings but omit replicate counts or uncertainty definitions; Figure 11 calls bars “variance” without specifying the plotted statistic.
- Prompt screenshots publish interface text but not prompt version, model, sampling settings or source-file provenance.
- Figure 6 held-out status is described in prose/caption but not marked as a visual grouping, and the reading inventory under-counted its PDF panels (nine vs twelve).

**One-sentence visual strategy:** OpenThoughts uses a saturated, baseline-anchored scaling grammar to turn a sequential data-curation recipe into cumulative, benchmark-level and robustness evidence, then publishes the hidden prompt interfaces and full ablation tables in a deliberately dense appendix.
