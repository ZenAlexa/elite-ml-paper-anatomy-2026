## 跨对象系统判断

- **视觉叙事**：Figure 1 先给 WGM set-union MM 的大数据集主比较；Figure 2/3 依次接 top-k 和 k-hitting 下游接口。Appendix Table 1 锁定六个数据集的规模，Figures 4/5 验证 Theorem 3.3 所需 Zipf 形状，Figures 6/7 给 user item-set ECDF；Figures 8–10 扫描 `Delta_0` 与 `epsilon`，Figures 11/12 将 top-k 扩展至 ordered `ell_1`，Figure 13 做低 epsilon k-hitting。叙事顺序与 Algorithm 1→Meta Algorithm→peeling mechanisms 对齐。
- **Caption 系统**：所有 caption 使用“对象编号加粗 + 短标题 + 参数设置”的同一模板；Figure 1 额外给 lower-is-better，其他 caption 很少写主发现；没有 caption 定义误差条、5-trial 聚合、`LimDom_*` 或 public-domain 假设。Figures 4/5 的 slope 只出现在图内 legend，不在 caption 中。
- **表头系统**：Table 1 是单层描述统计表，4 列、整数精度、booktabs 横线、无性能高亮；与结果图相比，它提供 dataset identity/scale，但没有不确定性或版本信息。
- **方法—结果—附录链**：Theorem 3.3/3.5 与 Algorithm 1 → Figure 1/8–10；Theorem 4.3 与 Algorithms 2/3 → Figure 2/11/12；Theorem 4.5 与 Algorithms 2/4 → Figure 3/13。Appendix F 是参数与 metric 扩展，不是 component-deletion ablation；论文没有 WGM stage deletion 或 unweighted mechanism 的图。
- **正文—附录链接**：正文 p.8–10 明确把 small-data、低 epsilon 和 ordered `ell_1` 结果放到 Appendix E/F；附录按 large/small、privacy、metric、task 维度补齐主图未显示的切片。证明和 lower bounds 位于 Appendix A–D，Table 1/diagnostics 只支撑数据/假设背景，不能替代性能证据。
- **字体一致性**：caption/Table text 的 CMR 与数学字体稳定；所有图体的 raster 无衬线字来自不可追溯源文件，图内字号明显小于正文但跨 Figures 1–13 一致。Figure 4–7 的标题很长且在小 panel 内缩小，影响附录可读性。

## 最终判断

- **最可复用模式**：
  1. Figure 1/8–10 的三数据集 facet + 固定方法颜色 + 参数扫描，适合把主结果与规模/隐私 sensitivity 对齐。
  2. Figure 4/5 的 log10 frequency–rank 与 Figure 6/7 的 ECDF 配对，分别验证理论分布前提和用户集合分布。
  3. Figure 12 的“数据集行 × MM/`ell_1` 列”嵌套矩阵，集中呈现下游 metric robustness。
  4. Table 1 的 users/items/entries 极简 booktabs 统计表，作为所有图的 dataset contract。
