## 最终判断

- **最可复用模式**：
  1. 用 dataset×metric 多层表头、方向箭头、best/second shading 和 caption uncertainty 定义组织主比较（Table 1）。
  2. 用 method×NFE sweep 与 matched distribution triptych/overlay（Table 2、Figure 4、Figure 5）把预算鲁棒性和分布形状放在同一证据链。
  3. 用语义 row groups 的 appendix hyperparameter matrix（Table 4/5）补齐模型、SDE、replay buffer 和训练配置。
  4. 用 direct-labelled 三联概念图或重复密度快照（Figure 1/2）解释 source/target conditioning 和流形过程。
- **最高价值对象**：Table 1 是 synthetic headline 的最高信息密度对象；Table 3 最直接承接大规模 amortized/efficiency claim；Figure 2 是理解方法机制的最佳接口；Figure 4 为 Table 2 提供最直观的 joint-density 交叉检查。
- **失败模式**：
  1. 没有公开且经论文元数据验证的绘图/表格/LaTeX 源，图内 typography、HEX、line width 只能估计。
