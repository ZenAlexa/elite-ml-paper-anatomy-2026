## 公开源核查

PDF 首页明确给出 `https://github.com/rhwxmx/SECNet_ICML`。source inventory 同样以 `rhwxmx/SECNet_ICML` 为显式 code URL 候选，但标为 `repository_without_visual_source`，本地 `corpus/visual_sources/icml-2026-93e4d45740d5/` 没有已取得文件。进一步用 `gh repo view` 和 main 分支递归树核查：仓库标题/README 与论文直接对应，树中存在 `SECNet.png`（2858 × 1497 的总体架构 PNG）、四个 DHP19 3D GIF，以及 `DHP19/tools/image_save.py`。后者用 OpenCV/TorchVision 生成 2D skeleton overlay（prediction 颜色在 OpenCV 中为 `(255, 0, 0)`，输出通道呈蓝色；圆点半径 3、骨架线宽 2；`make_grid` 默认 `nrow=8`），是 Figure 7/8 的局部生成证据。README 还给出 arXiv 2412.20803、十个数据集配置和训练入口。

递归树未发现 `paper.pdf`、`.tex`、`.ipynb`、`.tikz`、`.pgf`、SVG、plot/table generator 或导出配置；`SECNet.png` 是与 Figure 3 对应的渲染资产，GIF 是与附录姿态可视化相关的渲染资产，但没有当前会议版图表的可编辑生成源或数据文件。因此最终源状态记录为 **`partial_visual_source`**：有明确的仓库、架构/姿态渲染资产和局部 OpenCV 生成代码，但没有可重建全部 8 幅 Figure 与 13 张 Table 的绘图/排版源码。

## Figure 审计

### Figure 1（p. 1，`results`）

- **设计与版面**：右栏单栏嵌入的单面板雷达图，七条径向轴为 CIFAR10-DVS、N-CARS、N-MNIST、UCF101-DVS、DVS128 Gesture、ASL-DVS 和 N-Caltech101。三个多边形分别对应 SECNet、VMST-Net 和 ECSNet；径向网格同心、外圈未显示完整数值刻度，顶点附近直接印出结果。
- **Plot grammar**：PDF 中是嵌入 JPEG（约 1288 × 926 px、约 396 ppi）；角度维度为 categorical dataset，半径是 0–100 左右的 linear score。灰色径向/同心网格，右下 legend，SECNet 实线填充、VMST-Net 紫色虚线填充、ECSNet 橙色点线填充；没有误差条、误差带或 reference threshold。
- **编码**：角度=dataset，半径=accuracy；颜色、填充和线型=representation/model，文字值=约 21 个点估计。SECNet 为蓝色、VMST-Net 为紫色、ECSNet 为橙色，legend 以彩色圆点重复编码。图中可读到例如 SECNet 在 N-MNIST 99.7、UCF101-DVS 91.6、ASL-DVS 99.993、N-Caltech101 82.4。
- **Caption（逐字）**：`Figure 1. The comparison with the SOTA voxel-based VMST-Net (Liu et al., 2023) and frame-based methods ECSNet (Chen et al., 2022b) on seven classification datasets.` Caption 给出比较对象和数据集数量，但没有定义雷达半径、单位、缺失值、重复或不确定性。
- **数据与证据关系**：七个 classification dataset 的单点 accuracy 可视化；Table 2 是五个 object dataset 的精确表，Table 3 补充三个 action dataset，二者与 Figure 1 的 dataset 集合并不完全相同。它承担摘要/引言里的 headline comparison，不证明跨任务统计稳定性。
- **优势**：单图把 event-cloud、voxel 和 frame 三种表示跨七任务的相对轮廓压缩出来；数值直接贴在顶点，颜色与线型双重区分三方法。
- **弱点**：雷达面积和多边形形状会放大相邻轴的视觉差异；径向刻度不显式、图例及点标签小；没有样本量、seed、误差或统一缺失值规则。Figure 1 的七个数据集与 Table 2/3 的表格覆盖范围需读者自行拼接。
- **可复用模式**：用少量代表性任务的径向轮廓做 overview，再用按任务类型拆分的表格给出精确数值；必须标出径向刻度、指标单位和跨表覆盖边界。

- **编码**：panel/facet=representation，点的颜色/密度=事件与时间或 polarity 的可视化，箭头=坐标方向，raw row 与后两行=point/frame 方法族。七个 panel 共享 qualitative sample，不承载 accuracy 或分母。
- **Caption（逐字）**：`Figure 2. Visualization of different representations in yin-yang from N-Caltech101 dataset.` Caption 仅给样本与数据集，不解释颜色、轴、time bins、分组或可比性。
- **数据与证据关系**：用同一 N-Caltech101 yin-yang 样本说明从 raw Event Camera 到 Event Cloud、Point Cloud、Voxel Grid、Event Frame、Time Surface 和 Binary Map 的转换差异；为 §2.1 的表示选择和 “保留时序/稀疏性”论证提供定性证据，不支持性能或效率数值。
- **优势**：顶部 raw 输出、中央 point-based、底部 frame-based 的三层排列把 representation transformation 的信息损失做成直接视觉对照；坐标箭头和 panel 名称形成冗余。

### Figure 3（p. 3，`method`）

- **设计与版面**：页宽的高密度架构图。上层从 Event Cloud 3D 输入进入 Embedding、Hierarchy Structure 和 Predict Head；中层展开 Event-based Grouping & Sampling（G&S）；下层并列 Frequency-aware、Aggregation 和 Residual/FA 子模块。Hierarchy 内含 Event-based G&S、Spatial-FA、AGG、Temporal-FA、RES，并以 LOOP 表示多 stage 迭代。
- **Plot grammar**：嵌入 JPEG（约 2803 × 1488 px、约 396 ppi），属于混合的 pipeline/architecture diagram；无定量 x/y scale，箭头给出左到右/上到下的数据流。右侧有共享符号 legend（Concat、Hadamard product、GELU、matrix multiplication）和 `LOOP: 3`、`T`、`D`、`K` 参数注记；模块标题和 tensor shape 直接标注。
- **编码**：模块颜色/标题=功能（蓝 G&S、红 Spatial-FA、紫 AGG、绿 Temporal-FA、橙 RES）；黑色边框/箭头=结构；输入输出形状如 `[T,4]`、`[T/2,K,2D+4]`=张量尺寸；圈状箭头=跨 stage 更新，Mean/Max 汇聚后分到 Object、Action、Human Pose 三个 heads。
- **Caption（逐字）**：`Figure 3. SECNet’s architecture. It accomplishes three tasks by processing the Event Cloud into a sequence of distinct modules: Embedding, Hierarchy Structure, and Predict Head. In more detail, the Hierarchy Structure contains five different modules: Event-based G & S module captures the local neighborhood relationships, Spatial-FA abstracts the explicit spatial and implicit temporal features, AGG aggregates the features in a group, Temporal-FA catches the global explicit temporal features, and RES is responsible for the abstraction and high-level representation of features. The final results are obtained by the max-pooling and average-pooling features.` Caption 定义主要模块和最终 pooling，但没有完整解释所有 shape、参数或 legend 符号。
- **数据与证据关系**：方法接口图，不含统计样本或不确定性。它把 §3 的 Eq. (3)–(7) pipeline、§3.2.1–3.2.3 的 D-FPS/EF-KNN/CES/FA/AGG/RES 连接到 Table 8 的模块删除、Table 9 的事件数扩展和 Table 10/12 的效率测量；附录 Figure 5 进一步具体化 shape 变化。
- **优势**：全局 pipeline 与关键子模块同时可见；shape、颜色、箭头和 legend 让工程实现路径可追踪；页宽布局容纳三个 prediction heads。
- **弱点**：信息密度很高，字号与模块内公式在缩放后变小；同一 “FA” 术语覆盖 spatial/temporal 子模块；图未显示训练/推理边界、实际 batch 或资源测量。
- **可复用模式**：用上层总图、中层关键接口、下层局部算子三层展开网络，并在每个箭头上写 shape；把循环参数、颜色含义和输出任务放进同一 legend。
