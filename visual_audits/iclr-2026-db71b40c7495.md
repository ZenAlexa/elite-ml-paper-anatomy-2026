## 3. 论文级视觉系统

### 3.1 版式、字体和渲染

PDF 是两栏 ICLR 版式：F1–F3、F5、F7–F14 以及 T1/T2/T4 横跨两栏；F4、T3、T6 使用单栏，F6 和 T5 是窄 inset。表格和 caption 以 PDF 矢量文字为主，定性图、热图、柱/线图大多是嵌入 raster；`pdffonts` 显示正文以 Nimbus Roman No9 L/CMR/CMMI 系列为主，图内可见 Calibri、Arial Black、Times New Roman 等嵌入字体。图内字体与论文正文并未完全统一，尤其是由 PNG 直接嵌入的 F1–F3。

### 3.2 颜色和语义

热图反复使用浅粉/粉红/洋红的顺序强度，语义 token 用绿色勾/“Correct”、红色叉/“Wrong”，蓝色文字和箭头表示 token 流或 saliency 说明。F4 用蓝、绿、红三条曲线；表格用白、浅蓝或浅薰衣草色行带/方法高亮。颜色承担显著语义，但热图的强度判断缺少统一数值 colorbar（F13/F14 有局部 colorbar），所以转换到灰度后定性对照会变弱；勾/叉、文字和 marker 为部分冗余编码。

### 3.3 叙事顺序

F1 先建立「attention 看不出差异、saliency 能区分」的 headline；F2 将差异具体化为 recent-output 的距离衰减与上下文断连；F3 把机制接到 LocoRE 前后；T1/T2 给出跨方法、跨模型的主结果；F4/T3 分别暴露 α 的成本权衡与 α/β 选择。附录再给效率（F6）、saliency 示例和实现结构（F5/F7/F8）、融合策略（F9）、统计验证与干预（F10/T5/T6）、失败边界（F11）以及长序列/层切片（F12–F14）。这条线把「观察信号 → 干预方法 → 结果 → 消融 → 机制验证 → 失败边界」串联起来。

## 5. 跨对象判断与可复用结论

### 5.1 Caption 与表头系统

Figure 1–3、9–12 和 Table 1–5 的标题多以加粗 label 开始；F4–F8、F13–F14 和 T6 的 caption 较短，通常只给对象名或 setup。高质量 caption（F1/F2/F3/F9/F10/T4）同时写 setup、比较对象和主发现；效率图 F6、层图 F13/F14 仅写标题，依赖正文。T2 和 T4 对指标方向/缩写的解释相对完整，T1/T3/T6 仍需要正文才能解释列语义、模型和缺失值。

表头总体遵循两层 grouped header + ↑/↓ 方向标记；T1/T2/T4 将多个 benchmark 放在同一横向决策面，T3 则把两种干预参数放在左侧。表格精度在同一 benchmark 内基本一致，T1 的 MME 比 POPE/CHAIR 多一位小数，T5 明确呈现 `mean ± SD`。所有主结果表都缺少重复/不确定性信息；T5 的 SD 是唯一显式变异表达，F10(a) 有 error bar，F10(b) 的 band 定义不足。

### 5.2 方法—结果—消融—附录闭环

- **观察到的方法问题**：F1/F2 给出 output-token saliency 与 hallucination 的可视化区分，提出 Pattern 1（recent output grounding collapse）。
- **方法接口**：第 3 页文本、Algorithm 1/2 和 F7 说明 SGRS 在 token 提交前拒绝低 saliency，LocoRE 在提交后强化最近输出；F3 将这一路径具象化。
- **结果**：T1/T2 将 hallucination、POPE/CHAIR/MME、跨模型和跨任务结果放到主文，T4 延伸到 video benchmarks。
- **消融和成本**：F4/T3 选择 α、β，F6 报告单响应耗时；F6 的高成本提示 SGRS 与 LocoRE-only 的部署边界。
- **机制验证和边界**：F10/T5 给出跨模型 token-level统计，T6 做 saliency decay intervention；F11 明确 high-saliency hallucination 反例；F12–F14 检查长序列和层维度。

这条对象关系能支撑论文的主要视觉论证，但 F1–F3/F5/F9/F11–F14 主要是单例或定性热图，缺少统一色条、样本级汇总和可量化视觉解读；因此不能仅凭视觉对象替代正文中对 benchmark protocol、样本量和统计假设的说明。

### 5.3 最高价值对象、失败模式与复用建议

- **最高价值对象**：F1 是最有效的 headline；F3 把 LocoRE 干预变成可见的 before/after；T1/T2 承担跨方法/跨 backbone 的决策面；F10/T5/T6 将观察、跨模型统计与人为干预连成更强的机制链；F11 是必要的反例边界。
- **最可复用模式**：同一场景的 attention/saliency 对照；固定 token 的 intervention before/after；分组表头 + 方向箭头 + 轻量作者方法高亮；grouped summary（均值±SD）与 saliency-bin 曲线并列；correct/hallucination 的同构 layer small multiples。
- **主要失败模式**：短 caption 不定义对象、单位和主发现；热图多数无共享 colorbar/归一化；定性 grid 面板密且图内字体小；双轴 F4 可能造成尺度误读；F10(b) 的 uncertainty band 未定义；T1/T2/T4/T6 没有完整样本/重复/失败值协议；公开仓库只有 F1–F3 的 rendered PNG，没有可重算的图表生成源。
- **一句话策略**：论文用「粉色 saliency 热图揭示 token 上下文断连，前后干预图解释 LocoRE，分组 benchmark 表确认效果，附录用跨模型统计、decay 干预和失败/层切片限定机制边界」完成从诊断到方法再到证伪边界的视觉叙事。
