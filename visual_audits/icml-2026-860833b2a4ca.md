## 最终判断

- **最可复用模式**：
  1. Figure 2 的对齐 multistream token matrix，把 source forcing、Inner Monologue、semantic/acoustic output 和写入动作放在一个方法图中。
  2. Figure 3 的时间 waveform + process-reward 公式，把局部评分机制连接到最终 BLEU。
  3. Figures 4/7/8 的同构 BLEU/LAAL 双 panel，让超参、频率和 alternative setup 在共同坐标语法中可比较。
  4. Figure 5 的 marker/颜色/路径多重编码，直接呈现 quality/latency trade-off。
  5. Figures 9–10 的 train/valid × text/audio 2×2 诊断和 Figures 11–14 的固定 alpha timeline，分别支撑训练复现与定性机制。
- **最高价值对象**：Figure 2（多流方法接口）、Figure 3（process reward mechanism）、Table 1（主结果决策面）、Figure 5（quality/latency trade-off）、Figure 8（alternative configuration failure diagnosis）。
- **失败模式**：caption 仍把关键定义留给正文；Figure 4/7/8 的多曲线和附录 Figure 9/10 的多 stream 在小字号下拥挤；Table 1/4/5 的宽表缩放后表头难读；Figures 11–14 是单样本 raster qualitative evidence，不能替代总体统计；主图和附录图普遍缺少重复、不确定性或明确样本量。
- **一句话视觉策略**：用对齐 token/波形图解释无 word-level alignment 的模型与 process reward，以多指标表和 BLEU–latency 曲线承载主证据，再用附录训练曲线与固定 alpha 时间线补足复现和定性机制。
