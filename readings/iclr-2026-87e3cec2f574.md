## 5. 方法、公式与理论

### 5.1 单一方法主线

方法的因果链为：`setup_notation → state_problem → define_component → derive → give_intuition → connect_to_prediction → connect_to_experiment`。

1. **问题对象**：编码器观察 X~pX，解码器输出目标边际 pY 的 Y；S 与 X 具有给定 covariance，且满足 S↔X↔Y（p.2–3 §2）。distortion `d(X,Y)` 满足当且仅当 X=Y 时为 0，可取 Hamming 或 MSE。
2. **共享随机性与 one-shot reduction**：U 与 X 独立，编码器产生 Z，解码器依据 `(Z,U)` 生成 Y；Definition 2 用 `pU pX pZ|X,U pY|Z,U` 定义可行集合，约束 `H(Z|U)≤R` 和 `H(S|Y)≤C`。Theorem 1 通过 functional representation lemma 将随机映射吸收到 U，得到 `H(Y|X,U)=0`、`I(X;U)=0`、`H(Y|U)≤R`，并保留分类约束。其直觉是先由 `(X,U)` 做 deterministic transport，再无损压缩 Y；transport 与 compression 由 U 结构性分离（p.3–4）。
3. **Bernoulli/Hamming 闭式**：X、Y 为 Bernoulli，S=X⊕S1。先用 monotone/antimonotone/independent coupling 得到 `Dmin=|qX−qY|`、`Dmax=qX+qY`、`Dind=qX+qY−2qXqY`，再把四个确定函数 `f1(x)=x,f2(x)=1−x,f3(x)=0,f4(x)=1` 的概率 pU（1–4） 写成 linear program。Theorem 2 按 rate/classification constraint 的 active set 给出 DRC 三段式（p.4–5）。
4. **Asymptotic extension**：Definition 3 对 i.i.d. block 定义平均 distortion、rate 与 conditional entropy；Theorem 3 把 one-shot 的 entropy constraint 换成 `I(X;Y)≤R` 的 single-letter coupling。Remark 1 说明 block coding 已提供随机化，U 不再收紧 bound（p.5）。
5. **Gaussian DRC**：Theorem 4 用 jointly Gaussian coupling、MSE 和 covariance `θ1=Cov(X,S)`，将目标化成对 `θ2=Cov(X,Y)` 的 KKT 分析。classification-active、rate-active 与两约束都 inactive 时分别得到不同表达式；`C>h(S), R>h(X)` 时 Y=X，distortion 为 0（p.5–6）。
6. **DRPC**：Definition 4/ Theorem 5 加入 perception divergence `ϕ(pX,pY)≤P`；本文考察 `ϕKL(pY∥pX)` 和 `W2²(pX,pY)`。Theorem 6 用 matching first/second moments 的 Gaussian `YG` 证明 Gaussian extremality；Theorem 7 和 Appendix A.4 分别给出 KL 与 quadratic-Wasserstein 的 closed form（p.6–7）。
7. **深度实例化**：§5 的 stochastic autoencoder 由 encoder f、quantizer Q、decoder g、classifier c、WGAN discriminator d 组成。rate 上界写成 `h log2 L`；universal quantization 实现 U，WGAN-1 对齐 pY，CE(S,Ŝ) 作为 H(S|Y) 的上界代理。训练时优化 MSE、Wasserstein-1 和 classification CE 的 relaxed loss（p.8）。

### 8.2 负面结果

- 高 rate penalty 的 accuracy/MSE/PSNR 显著恶化（p.41–45 Tables 1–5、7–8）。

## 14. 最终判断

- **单一主线**：在 encoder 看到 degraded X、decoder 需要输出 distinct target marginal pY 的 cross-domain restoration 中，把 expected distortion 最小化问题写成同时受 rate 与 `H(S|Y)` 约束的 OT coupling；shared randomness 先将 one-shot transport 化为 deterministic plan，再把 Bernoulli/Gaussian/DRPC tradeoff 化为可解的闭式，最后以 universal quantization + entropy model + WGAN-GP + classifier 近似这一目标。
- **正文保留的决策关键内容**：Definition 1–4、Theorem 1–7 的主结论、Bernoulli/Gaussian/DRPC 的适用条件、Figure 3–6、§5.1 relaxed loss 和任务范围。读者可据此理解问题、数学对象和实验方向。
- **移入 appendix 的细节及影响**：证明、active-set LP、inverse RDC、Wasserstein branch、网络结构、优化器/步数/λ、exact rate、inpainting masks、real-noise 与 comparator 全部在 p.15–50；主线仍可读，但公平比较、统计聚合、计算预算和复现无法仅凭正文判断。
- **最有效的写作/图/表/公式模式**：Theorem 1 的 factorization-to-deterministic-plan reduction 把系统架构与 OT 统一；Theorem 2/4 的 active constraints 将 tradeoff 分段；Figure 17 把 closed form 与 synthetic empirical points 直接叠加；Tables 1–5/11–15 把 rate penalty、任务指标与真实噪声扩展成可读数值。
- **最大叙事缺口**：正文的 empirical claim 主要由单条曲线和 appendix aggregate 支撑；没有 seeds、误差定义、显著性或 matched-rate comparator。Table 15 缺 rate 列却讨论 smaller representation rate；theory–deep-model bridge 也只验证 trend，没有测模型是否满足目标 marginal/conditional entropy。
- **可迁移规则**：当论文把恢复/生成任务重写成受多个约束的 coupling，应在正文同时放出「约束如何变成可解对象」「每个约束对应哪一个指标」「一张直接机制验证图」和一个可复现的 rate/compute 表。
- **规则边界**：该规则适合有明确 marginal、rate/utility/perception constraints 与可构造 synthetic coupling 的压缩/恢复论文；当数据不可配对、下游标签不可得、分布非 Gaussian/Bernoulli 或 rate 与 perception 由不同训练代理表达时，闭式理论与深度模型结果只能在显式实验域内解释。
