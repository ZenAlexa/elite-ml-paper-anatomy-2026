## 5. 方法与理论

### 5.1 最小逻辑单元和动作序列

方法段落的动作转移为：

`setup_notation → derive → define_component → explain_mechanism → instantiate_algorithm → contrast_alternative → connect_to_experiment`。

1. **统一序列与目标**：把图像变成 continuous image tokens，与 discrete text tokens 拼成 (x={x_0,ldots,x_n})，用 (p(x)=\prod_i p(x_i\mid x_{<i}))（Eq.1）统一 next-token 目标；文本 token 走 LM head，图像 token 走 FM head（p.2 §2.1，`explicit`；Eq.1）。
2. **双损失**：文本用 cross-entropy，连续 patch 用 flow matching；FM loss 是预测 velocity 与目标 velocity 的 MSE，联合目标为 (mathcal L_{total}=lambda_{text}mathcal L_{text}+lambda_{visual}mathcal L_{visual})（Eq.2，p.3 §2.1，`explicit`；短语 “weighted sum of these two losses”）。
3. **Tokenizer**：从 Flux VAE 微调，仅用 reconstruction 与 perceptual loss；8× spatial downsampling、16-channel latent；token-wise normalization；再加从 (sigma)-VAE 借鉴的随机噪声扰动（Eq.3），用于稳定和防 variance collapse（p.3 §2.2，`explicit`）。
4. **序列压缩**：2×2 space-to-depth/pixel shuffle 将 256×256 的 latent 变为 16×16 grid 的 64-channel token，再展平为 256 tokens（p.3 §2.2，`explicit`；短语 “flattened into a 1D sequence of 256 tokens”）。
5. **Causal Transformer 与 head**：decoder-only Qwen2.5-14B；序列为 `{text} <image_area>h*w <boi>{image} <eoi>...`；image-area 提供二维 token 尺寸元数据。输出 hidden states 进入 LM head 或 157M、12-layer、1536-hidden MLP 的 patch-wise FM head（p.3 §2.2，`explicit`）。
6. **位置编码取舍**：本文选择标准 1D RoPE；更复杂的 2D/multimodal RoPE 未被采用。作者给出的理由是 mixed text-image 序列中仍有效，并追求 simplicity/efficiency（p.3 §2.2，`explicit`；短语 “retain it for simplicity and efficiency”）。

### 5.2 形式对象、输入输出与假设

- **输入**：离散 text tokens、连续 image tokens，以及图像区域的 (h*w) 元数据；对每个连续 patch 的 hidden state，还采样 timestep (t) 与 noise sample（p.2–p.3 Figure 1、§2.2，`explicit`）。
- **状态**：统一的前缀 (x_{<i})、causal transformer hidden state、噪声到目标 patch 的 flow state；输出是下一个离散 token 或由 FM head 生成的连续 patch token（p.2 Figure 1、Eq.1，`explicit`）。
- **目标函数**：Eq.1 的联合序列似然、Eq.2 的 CE/MSE 加权和；表 1 将预训练 CE/MSE 权重比写为 0.01/1（p.2–p.4，`explicit`）。
- **显式假设**：论文没有单列概率模型假设、数据独立性假设或定理条件；它给出的工程性前提是 tokenizer latent 需要 per-token normalized、分散且可承受扰动（p.2–p.3、p.8–p.9，`not_present` 对形式化假设）。

## 6. 实验设计

### 6.1 研究问题与顺序

论文没有预先编号的 hypothesis、预注册分析或显式失败判定标准（p.5 §4、p.7 §5.1，`not_present`）。从章节安排可提取四个隐含问题（均为本读法的 `interpretation`）：

1. strict causal AR + continuous tokens 是否能达到高保真 T2I，并与 diffusion 对照（p.2、p.5–p.6）；
2. tokenizer 的 normalization/noise 是否解释稳定性与质量（p.3、p.8–p.9）；
3. 生成逻辑主要来自 14B transformer 还是 FM head（p.6–p.7）；
4. 同一统一框架能否扩展到 instruction-based editing 与知识／组合性 benchmark（p.2、p.5、p.17–p.19）。

实验顺序大体按「主 T2I → editing → head ablation → CFG/tokenizer diagnosis → reconstruction → appendix 扩展结果／限制」推进，和引言的三个贡献存在对应关系（p.5–p.9、p.17–p.23，`layout_observation`）。

### 6.2 数据、任务和训练

- **Tokenizer 训练**：Flux.1-dev VAE 初始化；在 B.2 image-text 数据上微调；AdamW (eta_1=.9,eta_2=.95,epsilon=10^{-8})，50K steps、total batch 512、constant LR (10^{-5})、linear warm-up 1K（p.3–p.4 §3.1，`explicit`）。
- **Pre-training**：Stage 1 200K steps、1.23T tokens、256×256、20% text-only/60% image-text/20% interleaved；Stage 2 100K steps、0.61T tokens、动态 256–512 分辨率和 aspect-ratio buckets；Annealing 20K steps、40B tokens、20M curated samples 一 epoch（p.4 Table 1、§3.2，`explicit`）。
- **Post-training**：SFT 10K steps、5B tokens、5M samples；DPO 300 steps、LR (2\times10^{-6})、约 20K prompts，训练 recipe 见 Table 1（p.4–p.5 Table 1、§3.3，`explicit`）。
- **SFT 组成**：人选高语义／视觉质量 image-text pairs（另含其他生成模型图像的 distillation）、CoT data、instruction-guided image-to-image data（p.5 §3.3，`explicit`）。
- **DPO 构造**：每 prompt 由 SFT 生成 16 candidates；ImageReward 打分，top 4 随机选 winner、其余 12 随机选 loser；Self-CoT 先生成详细文本 CoT 并扩展原 prompt，再走相同流程（p.5 §3.3，`explicit`）。
- **数据集细节**：B.1 使用 Step-3 的 400B text-only tokens；B.2 经过 sourcing/filtering/dedup/re-caption 得到 550M image-text pairs；B.3 由 1M synthesized ControlNet samples + 3.5M collected data 过滤为约 1M high-quality instruction-guided image-to-image；B.4 含约 80M video-interleaved、NextStep-Video-Interleave-5M、tutorial 与 multi-view 数据（p.19–p.20 Appendix B，`explicit`）。

### 8.2 负面结果和自我设限位置

- **Artifacts（`generality`／`causality`）**：高维 VAE（8× downsample、16 channels）比 4-channel 配置更容易出现 bottom noise、bottom solid color、noisy image、grid；原因仍是 open question，只列 numerical instability、under-convergence、1D positional encoding 三个 plausible factors（p.20–p.22 Figure A4，`explicit`）。
- **CFG 稳定性（`assumption`／`causality`）**：作者说 prior work 将伪影归因于 1D position discontinuity，而本文分析认为是 token-level distributional shift 被 high CFG 放大；没有给出对 prior hypothesis 的完整反事实实验（p.8 §5.2，`explicit` + `interpretation`）。
- **高分辨率（`compute`／`generality`）**：严格 sequential generation 需要更多 steps 才能收敛，diffusion 的 parallel refinement 和 2D bias 难以复制；timestep shift 对该架构影响边际，专门的 high-resolution strategy 留作 future work（p.23 Appendix D，`explicit`）。
- **Inference latency（`compute`／`deployment`）**：serial LLM 是主要瓶颈，FM multi-step 也有 3.40 ms last-token 成本；作者建议 head distillation/few-step sampler、speculative decoding 或 multi-token prediction（p.21、p.23，`explicit`）。
- **SFT（`data`／`compute`／`generality`）**：小规模高质量数据会出现 marginal improvement 或 abrupt overfit；实质提升要到 million-sample scale，中间 checkpoint 难找（p.23 Appendix D，`explicit`）。
- **数据与可复现性（`data`／`generality`）**：训练依赖 550M image-text、in-house data、其他生成模型图像以及 proprietary 数据源；PDF 未给出完整数据许可、去重阈值、训练硬件或代码运行配置（p.5、p.19–p.20，`explicit`；缺失项为 `not_present`）。
- **评估边界（`baseline`／`metric`／`causality`）**：Table 2/3/A1/A2 是异质模型、协议和 judge 的点估计；editing 行的模型命名和段落命名不完全一致；没有 seed/uncertainty 或 human protocol（p.5–p.6、p.18，`explicit`）。
- **位置**：正面结果在 p.5–p.9，正式 `LIMITATIONS AND CHALLENGES` 延后到 Appendix D 的 p.20–p.23；这属于版面顺序事实，不据此推断作者意图（p.5–p.10、p.20–p.23，`layout_observation`）。

8. **未报告统计不确定性**：表格和图注独立说明指标／趋势，但没有分母、seed、区间或显著性；此缺口限制跨模型点值的可辩护范围（p.6–p.9、p.18，`explicit`）。

## 13. 最终判断

1. **单一主线**：论文把“连续 image token 的 AR 质量／稳定性缺口”收敛为一个表示问题。具体做法是使用 token-wise normalized、noise-regularized 的高维 VAE latent，让标准 causal transformer 负责 next-token context 建模，轻量 patch-wise FM head 只把每个条件 hidden state 转成连续 patch；benchmark、CFG 漂移、head-size 和 reconstruction 对照都围绕这条主线（p.2–p.3、p.7–p.9，`interpretation`）。
2. **正文保留的决策关键内容**：统一 factorization Eq.1、联合损失 Eq.2、tokenizer Eq.3、序列格式、head 规模、训练 recipe Table 1、T2I/editing 主表、head-size 消融和 CFG/tokenizer 诊断图；这些内容足以让读者理解模型为何区别于 VQ AR 和 hybrid diffusion（p.2–p.9，`explicit`）。
3. **移入附录的细节及损害**：OneIG/WISE 扩展 benchmark、550M/400B/80M 等数据 pipeline、Algorithm 1、latent histogram、artifact、latency、high-resolution 和 SFT 限制都在 Appendix。附录保留了数据与失败事实，但把主张的统计可复现条件（seed、分母、区间、硬件）仍留空，因此正文在机制叙事上自足、在完整审计上不自足（p.17–p.23，`interpretation`）。
4. **最有效的写作／图表／公式模式**：Figure 1 将输入、causal path、两个 head、noise-to-patch 训练闭合；Figure 3 将 Eq.4 的 CFG 插值转为 per-token mean/variance 的机制诊断；Table 5 用同一 baseline 下不同 FM head 容量做最小容量对照；Table 6 把 reconstruction quality 与 latent shape 放在同一表中（p.2、p.7–p.9，`interpretation`）。
5. **最大叙事缺口**：`state-of-the-art` 的范围在摘要中限定为 AR，但 Table 2 仍有 AR 基线在部分指标高于 NextStep；Self-CoT、rewrite、finetuned edit variant 和异质 judge 使跨表比较不是同一协议；head-only 10K-step 消融不足以确认生成逻辑的归属（p.1、p.6–p.7、p.18，`interpretation`）。
6. **可迁移规则**：当论文把连续表示、架构简化和质量提升作为一个因果链时，应在正文同时给出「表示干预 → 中间统计机制 → 同协议主结果 → 失败／成本」四个层次，并把每个比较对象的 prompt protocol、模型 variant、seed 和分母写进表注（p.7–p.9、p.21–p.23，`interpretation`）。
7. **适用边界**：该规则适合有多阶段生成模型、连续 latent、judge-based benchmark 或部署成本的论文；若任务只有理论定理或单一数据集，应把中间机制改为可证明量／误差分解，不能机械套用 CFG、tokenizer 或 benchmark 表格模式（p.2–p.9，`interpretation`）。
