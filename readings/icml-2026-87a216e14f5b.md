## Method 与 Theory

### OPL 的最小逻辑链

- `setup_notation`：中间特征 `f ∈ R^d`，可插入 backbone、layer 或 block；可学习 `W ∈ R^{k×d}`，约束 `1 < k < d`（p. 3，§3.1，anchor “let f ∈ R^d be an intermediate feature”，`explicit`）。
- `state_problem`：OPL 要在 VAD 目标下学习应被移除的 nuisance subspace，目标是保留 task-relevant information（p. 3，§3.1，anchor “remove task-irrelevant information from intermediate feature representations”，`explicit`）。
- `derive`：对 `W^T` 做 QR 得 `Q`，构造 `P = I_d − QQ^T`，再得 `f_proj = P f`；投影保留正交补，残差为被移除分量（p. 3，§3.1，公式 (1)–(3)，`explicit`）。
- `explain_mechanism`：作者把 QR 描述为数值稳定、可微、模块化的实现，并将 `Q Q^T` 视为可解释的 removed subspace（p. 3，§3.1，anchor “numerically stable and orthonormal basis”，`explicit`）。

### G-OPL 的最小逻辑链

- `define_component`：面对 OPL 可能保留的 face、gender、age，G-OPL 用 face presence 作为 weak supervision；原视频帧和 detected/generated face crops 经过同一 encoder（p. 3–4，§3.2，anchor “Both the original video frames and detected / generated face crops are passed through the same encoder”，`explicit`）。
- `explain_mechanism`：`Q Q^T f` 被定义为 sensitive component，cosine loss 使 face embedding 与该分量对齐，随后由正交补投影移除（p. 4，§3.2，公式 (4)，`explicit`）。
- `derive`：`L_task = L_ori + λ_face L_cos`，`L_orth = ||Q^TQ − I_k||_F^2`，`L_total = L_task + λ_orth L_orth`（p. 4，§3.2，公式 (4)–(6)，`explicit`）。
- `define_component`：多属性时拼接多个 weak attribute embeddings，并对每项 cosine alignment 求和；不训练 attribute classifier，也不收集 attribute labels（p. 4，§3.2，anchor “G-OPL can jointly encode several sensitive attributes”，`explicit`）。
- `connect_to_prediction`：作者预测低 `ARD` 表示 anomaly-score distribution 变化小，低 `FPD` 表示早期 face-presence leakage 小，高 `SSC` 表示敏感方向被 capture；这些是诊断预测，并非 formal privacy guarantee（p. 4–5，§3.3，`explicit` 与 `interpretation`）。

### 评估指标

- `SSC`：对 sensitive embedding 做 `Q Q^T` 投影，取原 embedding 与投影分量的平均 cosine similarity；越高表示 subspace capture 越强（p. 4，§3.3，公式 (7)，`explicit`）。
- `ARD`：用 KDE 或 histogram 估计 raw/projected anomaly-score densities，计算 `KL(P_raw || P_proj)`；越低表示 decision landscape 变化小（p. 4–5，§3.3，公式 (8)，`explicit`）。
- `PD/FPD`：在各层 feature 上训练 linear SVM 预测 sensitive presence，`PD` 是层级 accuracy 曲线，`FPD = Acc^(1)`；越低表示 probe 可恢复性越弱（p. 5，§3.3，公式 (9)，`explicit`）。
- 外部 probe：使用预训练 ArcFace embedding，训练 linear mapping 做 rank-1 identity retrieval；作者将其作为 attacker baseline（p. 5，§3.3，anchor “rank-1 retrieval accuracy (lower is better)”，`explicit`）。

段落动作序列为 `setup_notation → state_problem → derive → explain_mechanism → define_component → explain_mechanism → derive → define_component → connect_to_prediction → connect_to_experiment`。正文理论主要服务于方法链和诊断解释，Appendix E 才给出 linearly separable sensitive subspace 的形式化动机（p. 3–5、17–18，`interpretation`）。

### 公式与理论对象清单

正文与附录共识别 12 个 displayed、numbered equations。公式 (1)–(3) 构成投影核心链，(4)–(6) 为 G-OPL 训练目标，(7)–(9) 为指标，(10)–(11) 为 Appendix E 的 separability/projection，(12) 为多层递归过滤。形式化对象为 Assumption E.1、Definition E.2、Proposition E.3 和其 Proof；没有 Theorem、Lemma、Corollary（p. 3–5、17–18、21，`explicit`）。

有两个需要保留的技术边界。第一，QR 每次 forward 产生正交 `Q`，而公式 (5) 又对 `Q^TQ − I_k` 加正则，正文称梯度更新可能侵蚀正交性，但该实现关系没有进一步解释。第二，OPL 只由 VAD loss 间接学习 nuisance directions，缺少独立 nuisance label 或 direct nuisance probe，因此“removed = task-irrelevant”仍是机制解释而非充分识别（p. 3–4，公式 (1)–(6)，`interpretation`）。

## Experimental Design

- 数据集与协议：ShanghaiTech、UCF-Crime、CUHK Avenue、UCSD Ped2、MSAD 五个数据集，MSAD 使用 Protocol ii；任务指标为 frame-level AUC 和/或 AP（p. 5，§4.1，anchor “We evaluate on five VAD datasets”，`explicit`）。
- 模型与 backbone：OPL/G-OPL 插入 RTFM、MGFN、TEVAD、EGO；backbone 示例为 I3D 和 SwinT（p. 5，§4.1，anchor “four recent state-of-the-art weakly supervised VAD models”，`explicit`）。
- Face guidance：ShT、UCF、CUHK 使用 RetinaFace 检测并生成 face videos；另从 Georgia Tech Face Database 取 50 subjects、每人 15 images 生成 controlled face videos；两类输入共享 encoder（p. 4、22–23，§3.2、Appendix K，`explicit`）。
- 层位与配置：RTFM 有首个 aggregate 前及 C1–C5 六个 insertion points；MGFN 使用 B1、C1、B2、C2、B3；OPL 只能跟在至少一个 G-OPL 后，最多使用可用 slots（p. 23，Appendix K，`explicit`）。
- 隐私评估：SSC、ARD、PD/FPD 与 ArcFace rank-1 retrieval 并行使用；PD/FPD 可用于 baseline，SSC/ARD 依赖 projection（p. 5、22，§3.3、Appendix J，`explicit`）。
- 统一对照：Table 5 让 input masking、differential privacy、feature bottleneck、GRL 和 OPL/G-OPL 使用同一 backbone、训练协议与标准配置（p. 8，§4.2，anchor “same backbone with identical training protocols”，`explicit`）。
- 扩展设计：包括 MSAD blurred-face、CHAD high-resolution/unconstrained、VISPR attribute probe、multi-attribute suppression、latency/memory 和 missing face supervision（p. 24–28，Appendix L，`explicit`）。
- 部署假设：Appendix H 设想 device 侧只上传 filtered features 或 anomaly scores；没有 on-device compute 时可在 server 早期处理，但 raw data exposure 仍存在（p. 20，Appendix H，`explicit`）。
- 随机种子：正文和附录给出 batch size、max epoch 与超参数范围，未给 random seeds、重复运行次数或 seed-level aggregation（p. 5、23–24，§4.1、Appendix K–L，`interpretation`）。
- 训练预算与实现细节：未完整给出每个模型的 optimizer、learning-rate schedule、数据划分、预处理、早停规则和硬件配置；Acknowledgments 只说明 NCI Australia 计算资源（p. 10、23–24，§ACKNOWLEDGMENTS、Appendix K–L，`interpretation`）。
- 失败判定：论文讨论失败模式和配置退化，但没有预先定义统一 failure criterion 或停止规则（p. 28、32，Appendix L–N，`interpretation`）。

实验顺序大体对应贡献顺序。先做 rank、λ 和 layer placement，再给 MSAD anomaly/scenario 结果，随后给 privacy metrics、替代 privacy strategy、属性、效率和扩展集；Appendix K–M 承担大部分复现级配置（p. 5–9、22–32，`interpretation`）。

## Results、统计与可视化

### 统计口径

论文报告 point estimates。AUC/AP 是 frame-level 聚合指标，表格以 dataset、scenario 或 anomaly type 为列；SSC 是 embedding-level 平均 cosine，ARD 是 KDE/histogram density 的 KL divergence，PD/FPD 是 linear-probe accuracy，ArcFace 是 rank-1 retrieval，MI 在 Appendix L 以 face-presence 与 anomaly label 的二元量报告（p. 4–9、26，`explicit`）。

正文没有报告 seed 方差、标准误、bootstrap、Bayesian posterior、p-value、多重比较校正或 conventional uncertainty intervals。图 3、Table 1–8、Table 14、17–19 主要呈现单组数值；“significantly reduces”这类措辞没有配套显著性检验（p. 6–9、25、27–28，`interpretation`）。因此实质差异、统计判别与机制证据没有被充分拆开。

### 主要结果

- MSAD anomaly-level：RTFM-I3D 从 86.6/68.4 提升到 RTFM-G-OPL/OPL 的 88.0/70.9（AUC/AP）；MGFN-I3D 为 81.2/59.3，MGFN-OPL-I3D 为 86.2/68.3，MGFN-G-OPL/OPL 为 84.0/65.8（Table 2，p. 6，§4.2，`explicit`）。作者据此强调 anomaly-type robustness，但不同类型差异仍较大。
- MSAD scenario-level：RTFM-G-OPL/OPL 的 overall 为 88.0/70.9，RTFM baseline 为 86.6/68.4；MGFN-G-OPL/OPL 为 84.0/65.8（Table 3，p. 6，§4.2，`explicit`）。
- Rank 与正则：Table 1 在 ShT 上独立变化 `k_OPL`、`k_G-OPL`，最佳点为 `k_OPL=4`、`k_G-OPL=4`、AUC 97.3%；Appendix L 的 Ped2 最佳点为 16 和 8、AUC 89.6，说明 rank 选择依赖设置（p. 5、24，Table 1、11，`explicit`）。
- 隐私指标：RTFM ShT baseline 的 AUC/FPD/ArcFace 为 96.8/0.72/0.99，detected-face G-OPL/OPL 为 97.3/0.19/0.01，generated-face 变体为 97.2/0.01/0.02；UCF detected-face 变体为 78.3/0.23/0.03（Table 4，p. 8，`explicit`）。SSC 与 ARD 同时报告，detected-face ShT 为 0.97/0.29，generated-face 为 0.20/0.17，显示 probe 之间的语义并不完全相同。
- 替代隐私策略：ShT 上 baseline 为 AUC 96.8、FPD 0.42、ARD 0.08，G-OPL 为 97.3、0.22、0.06；input blur 为 93.5、0.18、0.30。UCF 上 G-OPL 为 85.2、0.34，优于 blur 的 80.2、0.20，表 5 没有误差项（p. 8，Table 5，`explicit`）。
- 计算效率：RTFM baseline 28.5 GFLOPs、AUC 96.8、FPD 0.42；early G-OPL 增加 0.6 GFLOPs，AUC 97.2、FPD 0.28，privacy gain/GFLOP 为 0.233；三层的 FPD 为 0.20、比值 0.073（Table 6，p. 9，`explicit`）。
- 属性与累积 suppression：单属性 Table 7 中 face AUC 83.8→85.3、FPD 78.2→61.4，gait AUC 83.8→83.2、FPD 71.0→57.9；Table 8 将 face、gender、clothing、gait 逐步加入后，FPD 73.3→49.5，AUC 85.3→84.4（p. 9，Tables 7–8，`explicit`）。
- 结构与可视化：Figure 5 在 MSAD 的 RTFM-I3D 上用 dots/crosses 展示 task-relevant 与 removed features；G-OPL 的 removed cluster 更紧，作者将其解释为 face-guided separation，但图中没有 cluster metric 或跨数据集复核（p. 7，Figure 5，`explicit` 与 `interpretation`）。
- Projection matrix：Figure 6 对 detected/generated faces 的 `Q Q^T` 做 log-scale、global min-max normalization，并展示 central 100×100 region；作者把 localized energy 解释为可读的 sensitive directions（p. 8，Figure 6，`explicit`）。
- Blurred MSAD：EGO baseline AUC/FPD/ArcFace 为 86.9/0.60/0.72，G-OPL 为 87.5/0.18/0.11；TEVAD baseline 为 82.1/0.58/0.70，G-OPL 为 82.5/0.17/0.10（Table 14，p. 25，`explicit`）。
- VISPR 与 CHAD：VISPR 的 face-conditioned attributes 接近 chance，例如 gender 0.68→0.25，clothing 0.61→0.59；CHAD 上 baseline AUC/FPD 为 84.7/0.91，G-OPL 为 85.4/0.34、SSC 0.88（Table 16–17，p. 27，`explicit`）。
- 延迟与内存：RTFM 为 142 FPS、7.0 ms、812 MB，G-OPL 为 134 FPS、7.5 ms、834 MB；作者将其概括为约 7% latency 增加和小于 3% memory 增加（Table 18，p. 27，`explicit`）。
- 自适应调参与缺失监督：固定参数 AUC/ARD/FPD 为 85.4/0.29/0.43，adaptive `k_G-OPL` 为 85.8/0.21/0.36，adaptive `λ_face` 为 86.1/0.18/0.38；face guidance drop 0%、30%、60%、100% 时 AUC/FPD 为 85.4/0.34、85.1/0.39、84.8/0.47、85.9/0.78（Tables 19、13，p. 25、28，`explicit`）。

作者的核心解释是 face identity 与 anomaly-relevant signal 在 feature space 中近似可分，G-OPL 因而能移除 sensitive component。实验支持“probe leakage 下降且 AUC 大体保持”的关联模式；它没有单独识别 identity subspace 与 anomaly semantics 的因果独立性，因此该解释属于 `partially_closed`（p. 8，Table 4；p. 17–18，Appendix E，`interpretation`）。

## Ablation、负面结果与自我设限

- `component/rank removal`：Table 1、11 改变 `k_OPL` 与 `k_G-OPL`，识别 subspace capacity；过大 rank 会降低 AUC（p. 5、24，`observed`）。
- `hyperparameter sensitivity`：Figure 3、Table 12 改变 `λ_face`、`λ_orth`，识别 semantic alignment 与 orthogonality regularization 的窗口；正文报告 `[10^-4,10^-2]` 的稳定区间，过大值伤害 performance（p. 5–6、24，`observed`）。
- `placement/frequency`：Figure 4、Tables 20–29 比较 G1O0、G1O1…G6O0 与 C/B insertion points，识别层深和堆叠效应；单个 early G-OPL 通常最稳，Ped2 是低分辨率例外（p. 6、28–32，`observed`）。
- `guidance source`：detected faces 与 Georgia Tech generated faces 对比，识别 noisy versus controlled supervision；Figure 6 与 Table 4 显示指标组合会随来源变化（p. 8、22–25，`observed`）。
- `missing supervision`：随机 drop 0%–100% face guidance，识别 detector failure 下的退化曲线；AUC/FPD 在 60% drop 时为 84.8/0.47（p. 25，Table 13，`observed`）。
- `mechanism/attribute scope`：VISPR、single/multi-attribute 和 MI 分析识别 face-conditioned 与 non-face attributes；gait 造成小幅 AUC 下降（p. 9、26–27，Tables 7–8、15–16，`observed`）。
- `privacy strategy alternative`：blur、DP、bottleneck、GRL 与 OPL/G-OPL 对比 utility/privacy trade-off（p. 8，Table 5，`observed`）。
- `adaptive tuning`：以 validation ARD 选择 `k_G-OPL` 或 `λ_face`，识别固定参数是否必要；adaptive `λ_face` 得到 AUC 86.1、ARD 0.18（p. 28，Table 19，`observed`）。
- `negative/configuration result`：MGFN 对过多 OPL 或 layer arrangement 敏感，RTFM 过度 OPL 会压掉 task-relevant cues；作者将其归因于 over-filtering（p. 28、32，Appendix M，`explicit`）。

作者明示的限制集中在 Appendix N，编码为 `generality`、`data`、`compute`、`deployment` 和 `causality`。Appendix A 还把 G-OPL 限定为 operator-configurable privacy control，面部语义若属于 anomaly causal chain 时建议只用 OPL（p. 14–15，Appendix A，`explicit`）。

## Adverse Presentation Strategies

- `附录迁移`：正文把 theory、implementation、layer placement、失败模式与大量配置放入 Appendix A–M；正文仍可读，但“普适 placement”“robustness”“deployment”主张需要回看附录（p. 3、6、20、22–32，`layout_observation`）。
- `聚合掩盖异质性`：Table 2–3 的 overall AUC/AP 压缩 11 类 anomaly 和 12 个 scenario；UCF、Ped2 与单类异常波动仍存在，整体均值无法独立表示异质性（p. 6，Tables 2–3，`interpretation`）。
- `代表性可视化`：Figure 5 只在 MSAD、RTFM-I3D、首次 OPL/G-OPL 上展示 UMAP，图中没有 cluster separation 的数值检验（p. 7，Figure 5，`explicit` 与 `interpretation`）。
- `指标替代`：FPD 是 face-presence probe accuracy，ArcFace 是线性 mapping 的 rank-1 retrieval；它们可作为 leakage proxy，却不能单独承载“identity cannot be recovered”的全攻击者结论（p. 5、8，§3.3、Table 4，`interpretation`）。
- `对比范围`：Table 5 选择四类代表性 privacy strategy，正文称 G-OPL 达到最佳 balance；没有给相同调参预算、重复种子或非线性 adaptive attacker 的结果（p. 8，Table 5，`interpretation`）。
- `语气强于证据`：正文使用“first comprehensive privacy analysis”“significantly reduces”等表述，而统计检验、系统检索边界与不确定性未随文给出（p. 8、27，Table 4、Appendix L，`interpretation`）。
- `未来工作化`：高分辨率、privacy-unconstrained 数据和 resolution–disentanglement interplay 留到 Appendix N 的 future work，成为当前范围边界而非主文测试（p. 33，Appendix N，`explicit`）。

## Conclusion、Limitations 与闭环

### Conclusion 编码

Conclusion 只有一段，依次执行“重述问题与方法 → 回收 G-OPL 和 cosine alignment → 回收 privacy-aware metrics → 回收 utility/privacy 结果 → 影响主张”。它没有新增数字、数据集或实验主张（p. 9，§5. Conclusion，`explicit`）。

### Claim closure

- OPL 能通过 learned orthogonal subspace 过滤 nuisance 并保留 anomaly cues：`partially_closed`。公式 (1)–(3) 给出方法，Tables 2–5 给出 utility，Figure 5 给出 representation visualization；但没有 nuisance ground truth 或独立 causal test（p. 3、6–8，`explicit` 与 `interpretation`）。
- G-OPL 能用 weak face signal 捕获并抑制 facial-sensitive component：`partially_closed`。公式 (4)–(6)、Algorithm 2、Table 4、14、16–17 和 ArcFace probe 形成证据链；probe 只覆盖给定攻击形式，无法推出无条件 identity erasure（p. 4、8、19、25、27，`interpretation`）。
- SSC/ARD/PD/FPD 提供 utility/privacy 联合诊断：`closed`。四个指标有定义、方向和跨 baseline 使用；SSC/ARD 的 projection dependency 已在 Appendix J 说明（p. 4–5、22，`explicit`）。
- layer placement、frequency 和 rank 有可迁移规律：`partially_closed`。主文 Figure 3–4 与 Appendix M 大表覆盖多设置，结果支持 early single G-OPL 的经验规则；但 Table 10、11 显示数据集和模型依赖，且未给 seed uncertainty（p. 5–6、23–32，`explicit` 与 `interpretation`）。
- privacy constraints 能提升或保持 VAD utility：`partially_closed`。多个表中 AUC/AP 维持或提升，但 MGFN、UCF、过度堆叠和 gait 条件存在退化（p. 6–9、25、32，`explicit`）。
- 方法是首个 realistic privacy-aware projection VAD：`open`。论文给出近邻工作差异，但没有可审计的完整检索边界或排除标准（p. 3，§2，`interpretation`）。
- 适合 edge/cloud privacy deployment：`partially_closed`。Appendix H 给出 device-side filtered feature pipeline，Table 18 给出小额开销；raw frame exposure、非线性攻击和客户端硬件可用性未在实验中覆盖（p. 20、27，Appendix H、Table 18，`interpretation`）。

闭环主线为“accuracy-first VAD 的 representation leakage → OPL/G-OPL 的 subspace filtering → privacy/utility probes → placement 与 deployment rule”。正文保留最终决策数字和最小公式链，附录承担理论动机、实现细节、配置网格和扩展验证；主张闭合度因此依赖附录，尤其是 placement、face guidance source 和 failure boundary（p. 3–9、14–33，`interpretation`）。

## Final Judgment

1. **单一主线**：论文把 VAD 的 accuracy-first representation leakage 重新表述为可在 feature space 处理的 subspace problem，用 OPL 学 nuisance complement，用 G-OPL 以 weak face signal 对齐 sensitive residual，再用 utility/privacy probes 选择层位和 rank（p. 3–9，§3–4，`interpretation`）。
2. **正文保留的决策关键内容**：OPL/G-OPL 的三步投影、G-OPL loss、SSC/ARD/PD/FPD 定义、五数据集 setup、主 utility 表、privacy 表、placement 图和 efficiency 表构成了最小决策链（p. 3–9，`explicit`）。
3. **移入附录的细节及影响**：理论 separability、算法伪代码、deployment pipeline、所有配置网格、VISPR/CHAD/blurred-face 扩展和失败模式主要移入 A–M；这使正文简洁，但 placement generality、privacy threat scope 与复现边界必须依赖附录才能判断（p. 14–32，`interpretation`）。
4. **最有效模式**：Figure 2 把模块、loss 和 data flow 放在同一条图上；Figure 5/6 分别把 feature separation 和 `Q Q^T` 变成可视证据；Table 4/5/6 以 utility、privacy 和 cost 并列，读者可以直接做 deployment trade-off 判断（p. 2、7–9，`layout_observation`）。
5. **最大缺口**：OPL 的 nuisance semantics、G-OPL 的“identity removal”与 edge privacy guarantee 都依赖 linear probe、ArcFace 和 UMAP 等有限代理；没有 adaptive nonlinear attacker、formal privacy bound、seed uncertainty 或 nuisance/identity causal intervention（p. 3–5、8、17–18、20，`interpretation`）。
6. **可迁移规则**：若论文的核心主张是“移除某类 representation information 后 utility 仍在”，正文应同时给出可审计的 removal target、攻击者 probe、任务效用、误差/重复运行和明确 threat boundary，并让每个组件至少对应一个机制检验（p. 4–9，`interpretation`）。
7. **规则边界**：该规则适合 representation filtering、fairness、privacy 和 disentanglement 论文；它不能把 proxy probe 当作所有攻击者的等价物，也不能替代针对真实敏感语义的标签、因果干预或正式 privacy definition（p. 14–18、22，`explicit` 与 `interpretation`）。
