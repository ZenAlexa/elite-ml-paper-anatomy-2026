## 5. 方法与理论

### 5.1 方法逻辑链

方法由四个组件构成，正文 p.3-p.6 共 8 个编号公式、3 个方法图。推进序列为；

`setup_notation → state_problem → define_component → explain_mechanism → give_intuition → connect_to_prediction → instantiate_algorithm → connect_to_experiment → summarize`

1. **Self-calibrated Uncertainty Signal（§4.1，p.3-4）**；先指出 entropy 在近 uniform/near-peaked 分布区分度不足，confidence 忽略 tail mass；再对每条 decoding trajectory 归一化 H/C，定义 `M_t = α H̃_t + (1-α)(1-C̃_t)`。Figure 3 用三角 contour 对照 H、C 与 M；作者的解释是 M 保留 top-1 stratification，同时对 residual mass 有 curvature，因而更能区分实际 class-confusion 分布。证据；p.3，§4.1，`Ct and Ht are complementary`，`explicit`。
2. **Token-Level Thinking Intervention（TTI，§4.2，p.4-5）**；以 `Δ_t^k = |M_t^k-M_{t-1}^k|` 监测相邻 token 的信号变化；仅在 `t>L_min` 且尚未 stop 时计算 trailing window 的平均变化，低于 `ε` 时得到 `t*`。作者解释为什么不直接在峰值截断；高 uncertainty token 可能是 connective/discourse 或 task-specific product tokens；滑窗可减少孤立任务 token 造成的误触发。触发后强制 logits 让 `</think>` 概率为 1，并注入固定队列 `[</think>, \n, <action>]`；one-time activation 与 `L_max` 保证终止。证据；p.4，§4.2，`truncation would likely occur on task-specific tokens`，`explicit`。
3. **Turn-Level Dynamical Sampling（TDS，§4.3，p.5）**；在 turn 内对 `M_t^k` 求 geometric mean 得 `Φ_k`，以 `Γ_k=|Φ_k-Φ_{k-1}|` 识别相邻 turn 的稳定/重复。`Γ_k<η` 时在相同 state 重新 rollout 当前 turn，直到 `Γ_k≥η` 或耗尽 `B_max`；信号在 regeneration 后重算。它把 DAPO 的 prompt-group filtering 改成不需要 per-turn accuracy 的 trajectory-level control。证据；p.5，§4.3，`discard the current turn’s generation and resample a new reasoning trajectory`，`explicit`。
4. **Policy Update（§4.4，p.5-6）**；用最近 `P` 个 turn 的 memory context 避免完整轨迹过长；用 turn discount `β` 传播稀疏终局 reward；先按同任务/同初始 state 的 full trajectories 求 global advantage，再按相同 state 的 turn group 求 `A_turn`，融合为 `A′=A+ωA_turn`，最后使用 clipped objective 与 KL reference。它承担 credit assignment 与优化器接口，不是新理论保证。证据；p.5-6，§4.4，`provides outcome and turn-level process credit`，`explicit`。

## 6. 实验设计

### 6.1 任务、模型、基线与指标

- **WebShop**；模拟 HTML shopping website，搜索、浏览、购买；环境含超过 1.1M products 与 12k human instructions。Appendix A.1.1 将 Task Score 定义为 `10 × avg. reward`，Success Rate 为 terminal reward `r=1` 的 episode 比例，并提供 Title Score、reward type、reward attribute、reward option 四个细粒度项。
- **ALFWorld**；3,827 个 task instances、六类 household activities；Pick & Place、Examine in Light、Clean & Place、Heat & Place、Cool & Place、Pick Two & Place；主指标为跨六类评估 episode 的 pooled Success Rate。
- **Search QA**；single-hop 的 NQ、TriviaQA、PopQA；multi-hop 的 HotpotQA、2Wiki、MuSiQue、Bamboogle；以 `<answer>` 标签抽取答案，用 exact string matching 的 EM 作为 outcome reward 与测试指标。训练在 NQ 与 HotpotQA 上，Table 2 的 `†/⋆` 标注 in-/out-of-domain。
- **模型与基线**；Qwen3-4B/8B-RFT 作为 WebShop/ALFWorld RL 初始化；Search QA 为 Qwen3-4B，另列 Qwen3-32B、R1-Instruct、Search-R1、ZeroSearch、StepSearch。WebShop/ALFWorld 比较 PPO、GRPO、GiGPO、GiGPO+DAPO 与 T2PO，并列 GPT-4o、Gemini-2.5-Pro、Claude Sonnet 4、Qwen3-32B prompting 及 Qwen3-4B+SFT。Appendix D.1 再把 policy optimizer 换成 GSPO。
- **统一条件**；所有 RL baseline 共享 RFT 初始化与 format penalty；group-based RL 的 rollout group size 为 8，Search QA 为 5，最大 turn 为 4；实验基于 verl agent loop，在 8× NVIDIA H100 上运行。作者称以三种 environment random seeds 初始化训练，但未给出 seed 值、每个任务的 episode 数或独立模型 seed 数。

### 7.2 统计口径

- **聚合单位与分母**；WebShop Task Score 是 episode reward 的平均再乘 10；Success Rate 是 terminal `r=1` episode 比例。ALFWorld 是六类 pooled evaluation episodes 的成功比例。Search QA 是每一数据集 EM 比例，Avg 列的算术聚合方式未明示。
- **中心量与离散量**；Table 1、Table 8 的 RL 行报告 `mean ± value`；论文没有说明 `±` 是 standard deviation、standard error 还是跨 env seeds 的其他量。Table 2、Table 3、Table 4、Table 6、Table 7 不报告离散量。
- **层级**；正文明确提到三种 environment random seeds；没有逐任务 seed、trajectory、episode、participant 的样本量。Table 1 ALFWorld category 与 overall 的关系由 Appendix A.1.2 解释，其他表的分母未给出。
- **未观察到**；hypothesis tests、p-values、multiple-comparison correction、bootstrap、Bayesian analysis、regression、correlation、effect-size 标准化或 95% intervals。
- **决策量**；best metric、Task Score、Success Rate、Avg EM、token budget 下 success fraction、平均 interaction turns、clip ratio、reward component；没有 win rate 或平均排名。
- **图注自足性**；Figure 1/5/6/7 能说明曲线任务与方向，Table 1-8 能说明列/行含义；图注和表注不能独立恢复 seed 数、`±` 定义、episode 分母或误差带解释。

## 12. 最终判断

1. **单一主线**；多轮 agentic RL 的 collapse 被作者归因于“hesitation”导致的无效 exploration；把 token predictive stability 变成 TTI，把 turn-level stability 变成 TDS，再接入 hierarchical credit assignment，以较少低信息 rollout 换取更稳定的 policy update。
2. **正文保留的决策关键内容**；problem/collapse 图示、M 的定义、两个触发规则、forced structured output、policy objective、三类任务、主结果表、核心/替代消融、Figure 5 效率方向。这些足以重建方法决策链。
3. **移入附录及其代价**；reward/EM 定义、全部超参数、RFT/parser/staleness、替代方法公式、GSPO/长度/α/ALFWorld 分析、伪代码与案例移入附录。正文概念自足性尚可；复现实验、理解不确定性和核对失败边界需反复查附录。
4. **最有效模式**；Figure 2 的双尺度流程总览 + Figure 3 的 signal geometry + Figure 4 的 trigger 直觉形成“对象→机制→动作”；Table 3/4 以同一 WebShop 指标并列组件删除和替代控制，读者能直接看到差异。
5. **最大叙事缺口**；MuSiQue 的“more than doubles prior best”与 Table 2 数值冲突；§5.5 错引 Figure 7；预告的 ε/η/N sensitivity 未出现；`±`、分母、seed 与 episode 数缺失。没有 formal stability/utility guarantee，也没有把 M/TTI/TDS 与共同 pipeline 组件区分的反事实证据。
6. **可迁移规则**；若核心贡献是多尺度控制，应让每个尺度各有一个可执行 signal、一个局部触发规则、一个组件删除实验和一个与主 claim 对齐的效率指标，并在正文明确分母与不确定性定义。
7. **适用边界**；这条规则适用于具有层级状态/动作、可观测过程信号与明确 rollout 成本的 agentic RL；当过程 reward、信号校准或同 state 重采样不可获得时，`Γ_k`/`Φ_k` 的语义和可识别性需另行验证，不能从本论文直接推广。
