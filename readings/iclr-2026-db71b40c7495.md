## 7. 方法与理论

### 7.1 逻辑单元与形式对象

方法首先令输入序列为 `x ∈ V^n`，模型为 `M`，attention matrix 为 `A^(l,h)`，输出分布为 `y`，目标 token 的 logits 为 `s`。Eq. (1)–(5) 将 loss 对 attention 的梯度变成 saliency matrix；Eq. (6)–(7) 将历史输出位置上的 layer-normalized saliency 汇总为 SGRS 接受阈值；Eq. (8)–(10) 将 LocoRE 的局部增益写成逐元素 attention update。形式对象首次出现于 p.4，`S`, `P`, `J`, `L_target`, `W`, `w_s`, `β` 的解释分散于 pp.4–5。

### 7.3 SGRS

在位置 `P`，给定 `x_<P`、图像 `I` 和 logits `s^(P)`，方法先用 top-`K` sampling 得到候选集。对候选 `c_i`，在目标层集合 `L_target` 与历史输出位置集合 `J` 上计算 Eq. (6)。候选分数达到 Eq. (7) 的阈值就提交；否则从候选集中删除并继续采样，最多循环 `R` 次。全部候选失败时，Algorithm 1 回退到原候选集中 saliency 最高的 token。阈值 `α∈(0,1)` 负责灵敏度，`W` 是 history window。论文给出 LLaVA-1.5 的 `SysL=35`、`ImgL=576`，但没有列出 `K`、`R`、`W` 或具体 `L_target`。

### 7.4 LocoRE

LocoRE 在 token 接受后工作。对预测位置 `P+1`，历史输出位置集合为 `J_P`；距离不超过 `w_s` 的位置获得 `1+β`，其余位置获得 1。Algorithm 2 在 batch 与 attention head 上修改 query `P+1` 对 `J_P` 的 attention，再把结果用于 softmax 与 weighted sum。论文强调该模块只改 forward attention structure，不需要 gradient 或参数更新。`Synergistic Workflow` 明确给出时序：SGRS 先选 `x_P`，LocoRE 再为下一次 forward pass 加强历史依赖。

### 7.5 算法核对

- **Algorithm 1 SGRS，p.6**：输入包含 `M,x,K,R,α,W,L,S=35,I=576,H`；循环 `r=1..R`，从 `C` 采样、计算 saliency、按最近历史阈值接受或删除；未接受时在原始候选集上取最高 saliency。算法行 8 用 `H[j]` 记录历史分数，行 10 又使用 `H.append`，与 Eq. (7) 中 `H` 作为位置集合的记号重载。
- **Algorithm 2 LocoRE，p.6**：输入是位置 `P` 的 attention tensor、局部窗口 `w_s` 和 `β`；若还没有输出 token 或历史集合为空则原样返回；否则遍历 `J_P`，按距离得到 `γ_j`，再在所有 `b,h` 上更新 attention。

方法动作转移序列为：`setup_notation → state_problem → derive → define_component → instantiate_algorithm → explain_mechanism → connect_to_prediction → connect_to_experiment → summarize`。核心因果链是低 saliency 观测 → SGRS 的前置筛选与 LocoRE 的后置强化；没有独立理论保证。

### 9.2 主结果

**Table 1，LLaVA-1.5-7B。** LocoRE 的 POPE F1/Acc 为 86.9/87.3，SGRS+LocoRE 为 87.0/87.5；CHAIR S/I 从 LocoRE 的 38.4/11.2 降至 35.6/8.2，MME Total 从 656.66 升至 668.33。作者将其表述为 POPE 上的 SOTA，并称 CHAIR descriptive dataset 仅次于 EAH；表中还显示 Reverse-VLM 的 CHAIR S 为 35.3，因而 S 与 I 两个指标的最佳方法并不完全相同。表内没有误差条或 seed 分布。

**Table 2，跨模型与任务。** LLaVA-1.5-7B 的 baseline 到 LocoRE 为 LLaVAW 72.5→74.8、MM-Vet 30.5→33.8、VizWiz 48.5→54.8、CHAIR_S 48.0→38.4、CHAIR_I 13.9→10.2；SGRS+LocoRE 再到 76.7、36.0、54.9、35.6、8.2。对 LLaVA-1.5-13B，SGRS+LocoRE 的 LLaVAW/MM-Vet/VizWiz/ScienceQA 为 76.8/42.0/64.0/75.5，CHAIR_S/I 为 39.8/8.8。Intern-VL-7B 的对应值为 55.5/35.0/56.2/67.9 与 34.4/7.5；Intern-VL-13B 为 56.8/37.3/52.0/71.0 与 45.2/14.0。Qwen2-VL-7B 的 SGRS+LocoRE 为 79.7 LLaVAW、67.7 MM-Vet、60.3 VizWiz、75.3 ScienceQA、19.3 CHAIR_S、5.1 CHAIR_I、82.6 POPE-R、88.0 POPE-F1、89.0 POPE-A。

Qwen2.5-VL-7B 的 SGRS+LocoRE 行也给出 80.0/66.2/62.7/82.1、21.0/6.5、81.5/88.3/89.5；Qwen2.5-VL-32B 只列 baseline 与 LocoRE，后者为 82.7/73.1/71.2/89.3、41.8/8.5、79.5/86.9/88.0。最后一行没有 SGRS+LocoRE，和附录 A.4 所述 SGRS 的 72B 规模限制相符，但也说明「any model size」主要是对 LocoRE 的 forward-only 适用性表述。

**Figure 3 的机制示例。** Qwen2-VL-7B 在 baseline 中将图像中的手表场景生成 `clock`，对应 prior outputs 的 saliency 较低；LocoRE 后同位置生成 `watch`，最近输出 saliency 增高。第二个示例将 `teaching` 变为 `standing`。这些是代表性案例，不能单独给出总体错误率。

**Table 4 的视频扩展。** Video-LLaVA 加 LocoRE 后，MSVD-QA accuracy 64.8→65.9，MSRVTT-QA 59.0→61.3，ActivityNet-QA 41.5→41.9；Video-LLaMA2 分别为 70.9→71.8、67.2→69.9、49.9→52.2。Video-Based Text Generation 的五个 GPT-3.5 Turbo 相对分数也随模型行略有上升，例如 Video-LLaMA2 的 Cr/Cs/De/Ct/Te 从 3.13/3.23/2.70/3.42/2.45 到 3.36/3.41/2.91/3.55/2.66。表头给五个分数标了向下箭头，但正文没有解释分数变高为何代表更优，表注只说明量程 0–5。

### 9.3 统计处理与不确定性

论文的统计单位有三层。主 benchmark 结果按任务和模型报告单个点估计，Appendix C 称每项平均 500 samples；D.1 的 saliency 关系以 token 为单位，约 12,000 个 token；Table 5 的离散量为 token-level standard deviation。Figure 10 先按 label 分组给 mean ± SD，再把 saliency 划为 10 个等宽区间，计算每区间 conditional hallucination probability。论文声称三模型均呈 monotonic negative correlation，最低区间 `[0.0,0.1)` 的 hallucination rate 为 68%–76%，最高区间 `[0.9,1.0]` 为 18%–28%。

Table 5 的数值如下。LLaVA-v1.5-7B correct `0.472 ± 0.136`、hallucinated `0.193 ± 0.087`；Qwen2-VL-7B 为 `0.664 ± 0.158`、`0.355 ± 0.103`；InternVL-7B 为 `0.508 ± 0.124`、`0.224 ± 0.095`。Table 6 通过把高显著性正确 token（saliency > 0.45）在 decoder 中乘以 `r` 模拟衰减。`r=1.0` 时 CHAIR_S/POPE-F1/POPE-A 为 35.6/87.0/87.5，降到 `r=.2` 时为 56.0/83.0/83.8。该趋势支持连续诊断信号的说法，但论文没有提供正式相关系数、检验统计量、p-value、置信区间、bootstrap 或多重比较校正。

统计结论、实质改进和机制证据没有完全分层。正文 p.4 直接使用 `statistically significant differences`，附录 D.1 再给均值、SD、分箱和人工衰减；没有说明检验对象或自由度。Table 1–4 仅给点估计，Table 2 括号是相对提升而非不确定性区间。因而跨模型方向较一致，但「显著」的可复核程度低于数值表面呈现。

### 自我设限的位置与类型

- **Compute**。A.0.1 量化 SGRS 的 backward pass 造成约 30–40% token latency；LocoRE 单独的 forward-only 增量被写成 `<2%`。A.4 又指出 72B 模型在 A100 80GB 上无法运行 gradient-based SGRS，实验范围因此落在 7B–13B 为主。证据见 pp.14、16–17。
- **Metric/compute**。Section 4.5 说明增大 `α` 可能拒绝 moderately salient 的正确 token，导致 fallback、流畅性和多样性下降。证据见 pp.8–9。
- **Generality/causality**。D.2 说明 high-saliency hallucination 仍会发生，且模型可能在错误答案上保持高置信度。证据见 pp.20–21。
- **Data/ethics**。B 节说明只使用公开模型和 benchmark、没有 private 或 human-subject data，并承认高风险部署仍可能产生 harmful/misleading output。证据见 p.18。
- **Reproducibility**。C 节列出代码、超参数、benchmark、A100、Hugging Face checkpoint；但代码用 `will be released upon publication` 表述，未在 PDF 内给出版本或 commit。证据见 pp.18–19。

## 15. 最终判断

### 15.1 单一主线

论文的单一主线是「autoregressive LVLM 在生成 hallucinated token 时会丢失对近期 output context 的 saliency」，由此构成一个两阶段闭环：SGRS 在 token 被提交前拒绝低 saliency candidate，LocoRE 在提交后放大近期 output attention。LVLMs-Saliency 是把这个机制转为可观察量的 gradient-aware diagnostic。

### 15.2 正文保留的决策关键内容

正文保留了 Pattern 1、Eq. (1)–(10)、Algorithm 1/2、candidate threshold、局部 attention gain、主要模型/benchmark 列表、Table 1–2、Figure 3、Figure 4 与 Table 3。读者可以理解「诊断 → 前置 gate → 后置 stabilizer → 结果/参数折衷」的基本决策路径。

### 15.3 迁入附录的细节及其代价

附录补足了 Eq. (11)、LLaVA saliency maps、fusion alternatives、generation-time overhead、video benchmark、500-sample/fixed-seed 说明、token-level statistical validation、人工 saliency decay、high-saliency failure、long-sequence 和 32 层可视化。迁移使正文更短，但也把 SGRS 的显存限制、核心反例和统计可复核性放到最后三分之一；读者只读正文会高估 causal 与 generality claim 的闭合程度。

### 15.4 最有效的写作、图、表和公式模式

最有效的模式是把同一个 token 例子连续映射到三种载体：Figure 1/2 先展示 attention 与 saliency 的可视差异，Eq. (4)–(7) 给出计算和阈值，Figure 3 再展示 LocoRE 干预前后的 token 变化。Table 2 将 LocoRE 的插件性质扩展到多模型，Table 3 则用高 `β` 退化和高 `α` 延迟把参数边界显式化。

### 15.5 最大叙事缺口

最大缺口有三项。第一，正文把 association、人工缩放 intervention 和 `direct causal link` 连接得过快，D.1 没有交代缩放 saliency 的实现中介。第二，p.8 的 `β=1.2` recommendation 与 Table 3 的 `.15/.20`、Appendix C 的 `.15/.20` 冲突，且 Table 3 的 `β=1.0` 已明显退化。第三，high-saliency hallucination 与 72B compute boundary 主要留在附录，正文的 robust/fully applicable 表述因此缺少同页边界。

### 15.6 可迁移规则

每一个机制主张都应同时给出可观察 token-level signal、独立 intervention、明确分母与 uncertainty，以及主文中的失败案例。算法的默认参数、表格值和复现声明应保持一组可逐项对齐的数字。

### 15.7 规则适用边界

该规则适用于有明确中介信号的 autoregressive LVLM decoding。它无法单独解决视觉信息不足、上下文本身含糊或模型高置信地产生错误答案的情况；若诊断需要 backward pass，模型规模和实时延迟也会限制可部署范围。对于仅有 forward attention 的轻量插件，应把「可运行」与「已经在更大模型验证」分开表述。
