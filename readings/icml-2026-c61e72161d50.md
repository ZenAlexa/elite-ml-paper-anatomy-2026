## Related work：定位方式

Section 2 是独立的约 470 词章节，包含三组按方法/实现维度组织的引用簇，包括 RandNLA/OSE sparse embeddings、structured/localized sketches、GPU implementations。它以 taxonomy 和 credit/foundation 为主。两种 nearest-neighbor contrast 建立缺口：localized SJLT 的 block coherence 与本方法的 union-of-permutations；GraSS/CountSketch 的 global scatter-add atomics 与本方法的 local accumulation。〔p. 2–3, Section 2；explicit〕

- `Sketching in RandNLA`：从 JL、OSE 到 CountSketch/SJLT/OSNAP，承担基础定义与保证来源。〔p. 2, Section 2；“reduce application cost”〕
- `Structured and localized sketches`：从 SRHT/expander 到 localized sketching，说明 `B LOCK P ERM-SJLT` 是 block-local SJLT 的 mixing 扩展。〔p. 2–3, Section 2；“generalization of this block-local SJLT”〕
- `GPU implementations of sketches`：dense `cuBLAS`、GraSS SJLT、CountSketch 和 FHT 的实现差异，明确前两类 sparse scatter-add 依赖 global atomics。〔p. 3, Section 2；“rely on global atomics”〕

该章节不重复完整方法推导；被引用的 localized-sketching 结果在 Section 6 的理论框架再次承担论证作用，GraSS 在 Section 7.4 和 Appendix E 再承担管线/指标来源。〔p. 3, Section 2；p. 6, Section 6；p. 8, Section 7.4；explicit〕

## 方法、kernel 与理论

### 最小逻辑单元

| 单元 | 前文问题 | 机制与不变量 | 位置 |
|---|---|---|---|
| block partition | random SJLT 无稳定 tile locality | 将 `d` 和 `k` 分为各 `M` 个 `B_c`/`B_r` blocks。〔p. 4, Section 4；“block sketch matrix S is always square”〕 | p. 4 |
| edge-disjoint wiring | 单一 block-local sketch mixing 不足 | 每个 output block 连接 `κ` 个不同 input blocks；bipartite graph 两侧均为 `κ`-regular。〔p. 4, Section 4；“each output block touches exactly κ”〕 | p. 4 |
| intra-block SJLT | 结构化 block 不应丢失细粒度随机性 | 每个非零 block 为每列 `s` 个非零的 SJLT；列总共 `κs` 个非零，幅度 `1/√(κs)`。〔p. 4, Section 4；“exactly κs nonzeros per column”〕 | p. 4 |
| tiled CUDA kernel | global atomic contention | thread block `(g,j)` 私有 `sY`，输入 tile `sA` 流入 shared memory；所有 local updates 后只写一次 global output tile。〔p. 5, Sections 5.1–5.2；Algorithm 1〕 | p. 5 |
| on-the-fly randomness | materialized `S` 的 index/bandwidth 开销 | 用 structured permutation 和 per-element hash 生成邻居、row 与 sign。〔p. 5, Section 5.2；“never materializes S”〕 | p. 5 |
| prior-kernel contrast | 功效来源可能含混 | GraSS/CountSketch 为 global scatter-add，文中给出 `Θ(sdn)` global atomic updates；FlashSketch 标示为无 global atomics、`Θ(kn)` global writes。〔p. 6, Section 5.3；explicit〕 | p. 6 |

### Algorithm 1 与 Algorithm 2

`Algorithm 1` 的输入是 `A`、block id `g`、column tile `j` 和 `(M,B_r,B_c,κ,s,T_k,T_n)`；嵌套循环为 neighbor `h` → row-tile `u_0` → parallel element `(u,t)` → `i=1..s`。关键不变量是 `sY` 仅属当前 CUDA thread block，故 `atomicAdd` 位于 shared memory；在处理全部 `κ` 邻居后按 `1/√(κs)` 缩放并写入一次 `Y`。〔p. 5, Algorithm 1；explicit〕

`Algorithm 2` 是附录的 `F LASH B LOCK ROW`。它按 row 独立抽样 `κ` 个 input blocks，改为 gather，省去任一层 atomic；代价是列非零数不再固定，某些列可被完全忽略，作者明确说明因此没有 OSE-style guarantee。〔p. 16–17, Section C/Algorithm 2；explicit〕

## 实验设计、统计与主结果

### 设计事实

- **运行与聚合**：使用 CUDA events，warm-up 后计时 10 次并报告 mean；所有 sketch 和 downstream task 固定 FP32。主表/主图使用 NVIDIA RTX 4090，Appendix G 在 RTX A6000 复测。论文未在正文给出随机 seed、计时离散量、置信区间、显著性检验或多重比较程序。〔p. 7, Section 7；p. 36, Section G；explicit〕
- **baselines**：Dense Gaussian + `cuBLAS`、SJLT + `cuSPARSE`、SJLT + GraSS kernel、SRHT + Dao-AILab FHT。〔p. 7, Section 7.1；explicit〕
- **输入与任务**：四类输入是 synthetic Gaussian、synthetic low-rank + noise、SuiteSparse `spal_004`（约 1.4% nonzero density）、GPT2-medium/Qwen2-1.5B stacked weights；任务是 Gram approximation、OSE、sketch-and-ridge、sketch-and-solve。〔p. 7, Sections 7.2–7.3；explicit〕
- **质量指标与分母**：Gram 使用 `‖AᵀA-(SA)ᵀ(SA)‖_F/‖AᵀA‖_F`；OSE 使用 `‖(SQ)ᵀSQ-I_r‖₂`；ridge/solve 使用 `‖Ax-b‖₂/‖b‖₂`（分母为零时改报告未归一化残差）。〔p. 7, 7.2；p. 18–19, F.1；explicit〕
- **GraSS control**：仅替换 gradient-compression 内 SJLT projection kernel，其余组件和 LDS code path 维持官方 GraSS repo；模型是 3-layer ReLU MLP、109,386 parameters，`4k→{1024,2048,4096}`。〔p. 8, 7.4；p. 18, E.2；explicit〕
- **LDS 聚合单位**：每个例子 `z` 的 LDS 是 50 个、各含 50% 训练数据的 retraining subset 中真实与 attribution-predicted outputs 的 Spearman correlation；报告值是 evaluation examples 上的平均 LDS。〔p. 18, E.2；Eqs. (54)–(57)〕

实验顺序将 Section 7 的两项承诺接成 `primitive sketch quality/speed → three RandNLA tasks → GraSS end-to-end`。理论的 `κ` tradeoff 与 ablation 图中的 `(κ,s)` style/colour 是对应关系，但论文没有设置单独的对照来隔离 shared-memory atomics、on-the-fly generation 和 block wiring 各自的速度贡献。〔p. 5–7, Sections 5–7；p. 19, Figure 6；interpretation〕

## 消融、负面信息与自我设限

正文没有独立的 ablation section，相关证据转入 Appendix F/G：通过 `κ,s`、`k`、输入分布、形状与 RTX 4090/RTX A6000 变化，展示速度–质量异质性。`F LASH B LOCK ROW` 被明确定义为 “fast but fragile”，对应 mechanism alternative，而非组件删除实验；其可能遗漏输入列、在 high-coherence 与 `d` 大/`k` 小时失真，且无 OSE-style guarantee。〔p. 16–17, Section C；p. 19, Figure 6；p. 19–51, F/G；explicit〕

可识别的自我设限包括：

1. **compute/scope**：`k` 很低时 GPU occupancy 限制速度；split-`B_c` fallback 用 global atomics，仍少于 prior kernels。〔p. 8, Section 8；p. 16, B.1；explicit〕
2. **compute**：`κ` 过大增加 input reads，kernel template tuning 并非 exhaustive。〔p. 8, Section 8；p. 16, B.2；explicit〕
3. **assumption/generality**：理论使用 independent uniform permutations，kernel 使用 structured distinct edge-disjoint family，作者只在 `κ≪M` 与 `κ²≪M` 处将差异描述为轻微。〔p. 7, Remark 6.3；p. 16, Remark A.12；explicit〕
4. **metric/causality**：分析集中于 OSE；作者把 Gram-matrix guarantees 与 end-to-end learning performance 的直接连接列为未来方向。〔p. 9, Section 8；explicit〕
5. **statistics**：报告 mean timing、geomean speedup 和 LDS average；未见测试、interval、seed count 或 per-configuration failure denominator。该项是报告缺口，不等于性能不存在。〔p. 7–8, Section 7/Table 1；p. 18, E.2；layout_observation〕

对不利信息的呈现策略有三个可验证事实：主文以 “preview” 和 “representative” 图先展示 Figure 1/3，配置级异质性图后置至 F/G；`F LASH B LOCK ROW` 的失败机制放在 Appendix C，但正文 p. 6 明确交叉引用 Section C；Section 8 在 references 前正面列出低占用、`κ`、理论和 metric 范围。文中缺少“弱 baseline”或“只展示代表性成功案例”的直接证据，因而不推断作者意图。〔p. 2, Figure 1；p. 6, Section 5.3；p. 7, Figure 3；p. 8–9, Section 8；p. 16–17, C；explicit/layout_observation〕

## 最终判断

**单一主线**：把 sparse sketch 的随机性重塑为 block-level edge-disjoint permutations，使每个 output tile 可以由一个 CUDA thread block 私有累积；`κ` 从这一结构同时导出 GPU locality 与 `µ_nbr` 控制的 sketch quality。〔p. 2, 1；p. 4–7, 4–6；explicit〕

**正文保留的决策关键内容**：张力、co-design construction、Algorithm 1、`µ_nbr`/Theorem 6.2、四类 baseline、三个 RandNLA tasks、GraSS control、Table 1、三张结果图与 Section 8。〔p. 1–9；explicit〕

**附录迁移是否损害自足性**：主文足以判断机制和聚合结果；配置级稳健性、`F LASH B LOCK ROW` 失败模式、理论完整证明、LDS 的重训练细节和 128 张 ablation 图位于附录。若读者需要核验“across regimes”的覆盖面，必须读取 F/G。〔p. 8, Table 1/Section 8；p. 11–51, A–G；interpretation〕

**最有效的写作/图/表/公式模式**：在引言先用 Figure 1 把单一 tradeoff 可视化，再以四项 Contributions 绑定 distribution、kernel、theory、benchmark；Section 6 的 `µ_nbr` 在构造与 OSE 条件之间形成可追踪的中介量；Table 1 用任务×baseline 的紧凑矩阵完成汇总。〔p. 2, Figure 1/Contributions；p. 6–8, Sections 6–7/Table 1；interpretation〕

**最大读者成本与未闭合处**：理论把 independent uniform permutations 当模型，runtime 却用 structured distinct family；速度机制缺少逐组件隔离；主结果没有 timing/seed uncertainty；重要的 128-panel 异质性图依赖共享图例，读者要在 p. 19 和后续页间往返。〔p. 7, Remark 6.3；p. 16, Remark A.12；p. 19, Figures 5–6；p. 19–51, F/G；explicit/layout_observation〕

**可迁移规则与边界**：当随机算法的理论随机性损害硬件访问规则时，先找一个可证明的结构化随机中介量，再让 data structure、kernel 与 evaluation 围绕它共同设计。此规则适用于结构能够保留任务关键混合性质、且 kernel 受明确 memory/synchronization 瓶颈约束的场景；若结构化实现的随机分布偏离理论模型，必须把近似条件和实证范围写入主文限制。〔p. 1–2, 1；p. 6–7, 6；p. 8–9, 8；interpretation〕
