## 单一主线与总体判断

论文把 diffusion model 的递归去噪链视为一个可重新编排的梯度估计图。完整 backpropagation（BP）提供结构信息，却受显存和计算限制；truncated BP 省成本但产生结构偏差；reinforcement learning（RL）保持无偏性却有高方差。RLR 在链首保留一阶（FO）路径，在一个连续的局部子链使用利用 inherent noise 的 half-order（HO）likelihood-ratio 路径，其余步骤用 zeroth-order（ZO）参数扰动补足全链。于是，论文的核心因果链是「递归链的局部计算图重排 → 在预算内保留跨尺度结构且保持无偏 → 更低方差/更快收敛 → Text2Image、Text2Video 和 DCoT 分数提升」（p.2–6，显式主张；p.9，理论回收）。

最有决策价值的证据包括 Text2Image 的四类 reward 在 SD1.4/SD2.1、Pick-a-Pic/HPD v2 上均高于所列 DDPO 与 AlignProp（表 2，p.6）；Text2Video 的 VBench weighted average 为 84.63，高于 VADER 的 83.45（表 3，p.6）；RLR(h=2) 在显存与分数之间给出明显折中（表 9，p.22）。理论部分给出截断 BP 的偏差表达、FO 与 ZO 的方差比较、RLR 无偏定理和 L-smooth 下的收敛界（命题 6.1–6.2、定理 6.3–6.4，p.8–9）。证据边界在于，方差优势主要由上界和间接的奖励曲线支持，随机种子、重复运行、不确定性表达、直接梯度方差测量和人类评测均未给出；视频组件指标也不是 RLR 全部最优（p.6–9、p.21–23）。

## E. 方法与理论

### E.1 形式化对象与设计空间

- **递归对象**：每步 `x_{t-1}=ϕ_t(x_t,z_t;θ)`，其中 `z_t=σ_t ε_t`、`ε_t∼N(0,I)`；噪声既可表示 DM inherent noise，也可表示参数注入噪声（公式 (1)，p.3）。共享 backbone `φ` 在各时间步复用，完整输出写为 `x_0=ϕ_{1:T}(x_T,z_{1:T};θ)`（公式 (2)，p.3）。
- **目标与约束**：最大化 `E[R(x_0)]`（公式 (3)，p.4），再在 estimator 空间中最小化 `Var(G)`，满足无偏约束 `∇θE[R]=E[G]` 和预算 `C(G)≤B`（公式 (4)，p.4）。成本以 backward-pass 长度或中间 activation 量衡量；正文没有给出统一的硬件归一化成本函数。
- **三种局部策略**：FO 直接对 `ϕ_t` backprop；ZO 对参数加噪声并用 function evaluation/LR 估计；HO 使用 inherent noise、在长度 h 的 local sub-chain 上做 Jacobian 加 likelihood-ratio。作者把 RL 视为 h=1 的 HO 特例（p.4）。
- **组合空间**：`G_full={(g_1,…,g_T)|g_t∈{FO,HO,ZO}}`（公式 (5)，p.4），Table 1 给出 FO「低方差/高显存」、ZO「高方差/低显存」、HO 居中、truncated BP 有偏。

### E.2 RLR 结构、h 与 j

RLR 对 full design space 加两条结构约束。HO 段必须连续，以免切断局部 path；FO 必须连接 reward model。于是 `G_RLR` 只保留一个首步 FO、一个从 j 开始的 h-length HO sub-chain，以及其余时间步的 ZO。公式 (6，p.5) 将三项写成首步 FO 的 `D_θ^Tϕ_1·dR/dx_0`、局部 HO 的 `-R(x_0)D_θ^Tϕ_{j:j+h}∇_z log f(z_j)`，以及集合 C 上的 ZO score-function 和。

三个组件各自回收一个前文问题：FO 让 reward model 保持可微结构；HO 在不缓存整条链的情况下保留局部多尺度 path；ZO 以参数扰动补齐未覆盖时间步并维持全链无偏。作者把 DM 生成描述成 coarse-to-fine，因此 j 被解释为所关注视觉尺度的位置（p.5）。

h 的选择先以方差上界作为 surrogate（公式 (7)，p.5），约束为 `B_hh+B_z(T−1−h)≤B`。在 `V_h≪V_z`、`T>2` 和 `B_zT<B<B_hT` 下，正文给出 h* 的预算/方差截断式（公式 (8)，p.6）；取 `B_h=8 GB`、`B_z=0.24 GB`，预算 30–40 GB 时建议 h=2。作者同时指出增大 h 会降低方差但带来线性显存和更快增长的时间成本。j 使用梯度范数的 softmax categorical distribution；DCoT 实验再把 j 限制到缺陷尺度的窗口 `U(30,40)`（p.6、p.8）。

### E.3 DCoT 方法扩展

Diffusive Chain-of-Thought（DCoT）把一个原始 prompt 拆成 coarse-level、mid-level、fine-level 三条 prompt，使其分别对齐噪声邻近的粗轮廓、中间几何结构和输出邻近的细节。Figure 6（p.7）把「prompt scale → diffusion step window → HO 更新」画成闭环。hand task 使用 5 个原始 prompt，请 ChatGPT 生成三层文本；在 `a=30,b=40` 上约束 j，表 4 比较 SD1.4、SD1.4-DCoT、RLR w/o DCoT、RLR-DCoT（p.8；详细 prompt 在 Appendix F）。DCoT 是 prompt-side 的方法扩展，作者没有把它作为独立 gradient estimator 或理论对象证明。

## I. 结论、限制与主张闭环

结论按「重述 RLR → 回收理论（bias/variance/convergence）→ 回收 Text2Image/Text2Video → 回收 DCoT → 承认 h 选择困难」组织，没有新增数字或新实验。它把 h 的困难作为唯一直接措辞化限制：「determining the appropriate sub-chain length h can be nontrivial」，并以理论 justification 与 ablation guide 收束（p.9）。

### 最终判断

1. **单一主线**：把递归 diffusion chain 的梯度估计拆成 FO、HO、ZO 三类局部决策，并用连续 HO 子链在预算内恢复 pathwise 多尺度信息；RLR 的价值来自“结构信息保留”和“全链无偏补足”的同时发生。
2. **正文应保留**：公式 (1)–(8)、Figure 4 的计算图、Table 1 的 estimator 对照、Table 2/3 的主任务结果、Figure 5 的动态曲线、Table 4/5 的 DCoT/组件消融，以及理论命题的条件和结论。它们共同决定方法选择、经验效果和适用边界。
3. **适合移入附录的内容**：J 节证明、B/C 的长设置、G 的资源/sampler、H 的 h 全扫描、I 的 16 维 VBench、D/E/F 的定性图与 prompt 模板。迁移没有损害主线，但缺少 seed、完整 budget 和原始曲线会削弱独立复现。
4. **最有效的模式**：Figure 3 先把结构偏差画成 reward collapse，Figure 4 再把图重排画成三段 estimator；随后 Table 2/3 给横向结果，Figure 5/表 5 给动态和机制对照，附录表 6–10 补成本/完整指标。公式、图和表的职责基本互补。
5. **最大叙事缺口**：作者以“低方差”贯穿摘要、理论和 sample-efficiency 解释，但没有直接报告 estimator variance、重复运行或不确定性；p.7 对 AQ 的「large margin」描述与 Table 3 的分数不一致，Eq. (6) 的 h/index 记号和 Eq. (8)/Eq. (19) 的 `V` 记号也增加读者核对成本。
6. **可迁移规则**：若方法主张来自计算图重排，正文应把每个图段对应的偏差/方差机制、预算代价和可证伪 ablation 放在同一条证据链，并让聚合分数旁边保留关键组件维度。
7. **适用边界**：该规则适合有递归链、可区分局部路径且预算受限的生成/序列优化；若 reward 不可微、噪声不满足 LR 假设、任务只有一个尺度、或组件指标之间存在明显冲突，不能直接把 RLR 的无偏/低方差和 DCoT synergy 外推为一般结论。
