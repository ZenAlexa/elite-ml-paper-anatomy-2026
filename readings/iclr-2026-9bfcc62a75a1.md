## 5. 方法、flow-matching 表征机制与理论

### 5.1 预备知识：从 CNF 到 FM

`2 PRELIMINARIES`（p.3–4，归入 `other`）先定义时间向量场 `v_t`、概率密度路径 `p_t`、flow `φ_t`、条件向量场 `u_t(·|z)` 和条件 flow。CNF 用 continuity equation `∂_t p_t=-∇·(v_t p_t)` 描述密度演化，Eq. (2) 把它写成 characteristic ODE，Eq. (3) 给出同时更新状态和 log density 的 instantaneous change-of-variable。FM 的 Eq. (4) 则在 `t∼U[0,1]`、`x_1∼p_data`、`x_t∼p_t(x|x_1)` 下，最小化 NN vector field `v_t(·;θ)` 与 reference conditional field `u_t(·|x_1)` 的平方误差。作者特别指出 noising/denoising 在这里是 deterministic；linear Wasserstein interpolation 是一个具体 path choice。

### 5.2 核心桥：posterior-weighted conditional vector field

SFA 的决定性洞见是 Eq. (5)：

> `v_t(x) = ∫ v_t(x|z) [p_t(x|z)p_t(z) / ∫p_t(x|z')p_t(z')dz'] dz = E_{p_t(z|x)}[v_t(x|z)]`（p.4）。

该机制并非把 latent 直接拼进网络，而是把**条件 flow 的速度**按当前 posterior `p_t(z|x)` 混合，得到生成 marginal `p_t(x)` 的速度。Theorem 3.1（p.5）在 regularity conditions 下说明：若每个 `v_t(x|z)` 生成条件 probability kernel `p_t(x|z)`，则这个 posterior expectation 生成 `p_t(x)=∫p_t(x|z)p(z)dz`；反向地，由该 marginal field 经 continuity equation 得到的路径与混合路径一致。证明在 Appendix A.1 通过条件 continuity equation、Bayes rewrite、Jensen 的 kinetic-energy bound 和 uniqueness 完成。

SFA 因此让 `p_t(·|z_t)` 与 `p_t(·|x_t)` 随时间共同演化：t=1 是数据端 likelihood/posterior，t=0 是可采样、可评价的 base。SCFM 的 Eq. (6) 为

> `R(θ,q)=E_{x_1∼p_data, x_t∼p_t(x|x_1), t∼Unif}[ || E_{q_t(z_t|x_t)}[v_t(x_t|z_t;θ)] - u_t(x_t|x_1) ||² ]`（p.5）。

这里外层沿 observed data 的 conditional flow trajectory 采样，内层沿 approximate posterior trajectory 取期望，`q∈Q` 是可带 graphical structure 的 posterior family。SCFM 的“de-mixing”语义是：把 observation signal 分解成 data-generation component 与 latent-structure component，同时让 marginal path 对 FM reference 保持一致。与 VAE 的 ELBO/KL 不同，作者声称不需要 reconstruction/KL 的 β trade-off；Appendix 的 posterior-collapse remark 只给出优化上“collapsed posterior 是可选解，优化 q 不会比固定 prior 更差”的不等式，并不等价于所有数据上的 non-collapse guarantee。

### 5.3 三种图模型实例

1. **Continuous latent（p.6，Eq. (7)）**：`z∈R^p`、`x∈R^d` 且 `0<p<d`；conditional likelihood 由 `dφ_t(x)/dt=v_t(φ_t(x)|z;θ)` 生成。内层 posterior expectation 可用单样本 `z̃∼q_t(z|x)` 近似。posterior 可取 maximally expressive conditional CNF（要在每步反向传播 adjoint ODE），也可取带 `(t,x)` 参数的 Gaussian family（Bures-Wasserstein submanifold），后者以 reparameterization 换取速度和稳定性。
2. **Latent finite mixture（p.7，Eq. (8)）**：全局 `π∼p(π)`，局部 `ξ_i|π∼Cat(π)`，`z_i|ξ_i∼p(z|ξ_i)`，`x_i|z_i∼p(x|z_i)`；posterior 同时包含 `ξ_i,z_i,π`。当 `π∼Dir(α)` 时，整体比例的 posterior 为闭式 `Dir(α̃)`。SCFM 对 `ξ` 与 `z` 都积分；class posterior 可用 time-dependent 或 constant-time Gumbel-Softmax，连续 `z` 用 conditional CNF/Gaussian。
3. **Latent dynamical system（p.7，Eq. (9)）**：连续 latent state 按 Markov dynamics 演化，observations 在给定 `z_s` 时条件独立；完整 posterior 按 `p(z_s|z^{[s−1]},x^{[S]})` factorize。SCFM 对 `s∈[S]` 的 conditional vector-field residual 求和，借助 Theorem A.2 证明与 sequence-level marginal FM 具有相同 gradient。后验每一步需要 full observed sequence，因此训练是 offline；Appendix B.4 用 frame MLP embedding、GRU history、cross-attention 和 diagonal Gaussian 实现。

### 5.4 方法动作序列与理论职责

方法段动作转移为：`setup_notation → state_problem → derive → define_component → explain_mechanism → instantiate_algorithm → connect_to_prediction → connect_to_experiment → summarize`。这里没有伪代码／algorithm listing，只有公式和 graphical-model diagrams。形式对象的输入是 observed `x_1`、base `x_0`、latent `z`、conditional/marginal vector fields 与 posterior family；输出是 conditional CNF likelihood、approximate posterior，以及可生成的 marginal path。正文没有给出 Big-O 的训练复杂度；只给出 qualitative 的 CNF-adjoint cost，并在实验 p.8 报 runtime。

理论结果的职责聚焦于**条件 vector fields 的 posterior mixing 与 marginal probability path 相容性**；它不宣称神经网络必然学到真实 latent。Theorem 3.1 是核心因果链；Theorem A.1 是 Appendix 中处理 non-Lipschitz vector field 的 measure-valued ODE 基础；Theorem A.2 是 sequence extension。它们支撑 representation mechanism 的 consistency/guarantee，不直接提供 clustering 或 sample-quality 的 statistical guarantee。

### 限制清单

1. **CNF posterior 的计算成本（`compute`）**：每个 gradient step 都要做 ODE solve；167.460±176.817 s/epoch 远高于 parametric SFA/VAE（p.8）。
2. **posterior family 选择未原则化（`generality`/`compute`）**：latent dim 小时简单 family 足够，但 principled selection strategy 是 open question（p.10）。
3. **复杂图像扩展的 decoder bypass 风险（`deployment`/`generality`）**：deep decoder 可能通过 skip connections 绕过 stochastic latent，尚未给出高分辨率实验（p.10）。
4. **方法贡献边界（`generality`）**：作者明确说主要贡献是 SCFM 的 composition recipe，而非已解决 identifiable/decomposable latent；干预和 OOD generation 留作 future work（p.10）。
5. **RNA-seq likelihood 缺失（`metric`）**：5,000 维 observation 的 CNF log likelihood 不能通过 adjoint-ODE 直接计算，因此 Table 4a 只比较 posterior/diversity/clustering（p.10）。
6. **LDS 训练是 offline（`deployment`）**：Eq. (9)/Theorem A.2 需要完整 observed sequence，不能直接推出 online filtering 方法（p.7、p.17）。
7. **实证不确定性报告不足（`causality`/`generality`）**：没有 seed、replicate count、hypothesis test 或 confidence interval，跨方法小差异的稳定性未知（p.8–10、Appendix B）。这是由报告缺口编码的边界，不推断作者意图。

## 13. 最终判断

1. **单一主线**：论文从“FM 有 density fidelity 但无结构、VAE 有结构但 fidelity 弱”出发，以 Eq. (5)/Theorem 3.1 的 posterior-weighted conditional vector field 为桥，构造 SCFM Eq. (6)，再把同一机制实例化到 continuous、finite-mixture、LDS latent 图模型，并用 Pinwheel/MNIST/RNA-seq/Pendulum 检验生成、表示和动态恢复。
2. **正文保留的决策关键内容**：问题对比、Eq. (1)/(5)/(6)、Theorem 3.1 statement、Figure 3、三类结构、任务/指标/held-out size、Tables 1–4、runtime cost、Table 4a 的 likelihood omission 和 p.10 limitations。读者可据此判断机制与主要结果方向。
3. **移入附录的细节及影响**：A/A.1/A.2 放 regularity、proof、Bayes/Jensen/uniqueness 和 sequence gradient derivation；B 放 architecture、sampling protocol、softNMI、TSNE/posterior grids 与 LDS encoder。迁移没有破坏主线，但削弱了“theorem ⇒ learned representation”与“高维 scalability”的自足性，因为 proof conditions、split/seed 和 5,000 维 likelihood 细节不在正文。
4. **最有效的写作、图、表或公式模式**：Eq. (5)→Theorem 3.1→SCFM Eq. (6) 是最短因果链；Figure 3 把 co-evolving `x/z` path 视觉化；Table 2–4 把 density、diversity、clustering、RMSE 的方向性决策量集中在正文。Figure 1 的 latent color 与 Table 1 的 W1 形成“表示+生成”的双通道证据。
5. **最明显的叙事规避、未闭合主张或读者成本**：摘要/Discussion 使用 `consistently outperforms` 和 `broadly/any graphical model`，但 Table 1 只显示与 FM comparable、RNA 缺少 CNF log likelihood、没有 seed/interval/robustness；posterior collapse remark 是无 KL force 的优化论证，不是 empirical non-collapse guarantee。读者还需从 Appendix B 反推训练与 projection 细节。
6. **可迁移规则**：若方法声称把高保真生成与结构化表示统一，应先给出一个能把 conditional mechanism 映射到 marginal objective 的桥接公式，再给出带前置条件的 consistency theorem，随后让每个结构实例和每个实验指标各自回收桥接预测。
7. **适用边界**：该规则适合具有可写成 conditional probability path、可定义 posterior family 且能满足 continuity/regularity 的 flow-based latent models；对高分辨率 decoder bypass、identifiability、online filtering、跨 seed 稳定性或没有可观测 marginal bridge 的系统，不能把 theorem statement 直接升级为 representation guarantee。
