## 6. FSTA 方法与理论

### 6.1 问题对象与稳定边

Section 3.1（p.3）把 VRP 写成图 (G=(V,E))，节点是 customer，边有 travel cost。CVRP 约束 vehicle capacity、depot 起终点、customer exactly once；VRPTW 追加 service time 和 ([t_i^l,t_i^r])。更严格的稳定定义放在 Appendix A.1（p.16）：在第 (t) 次 backbone invocation 得到 (R^t)，若边 (e\notin R^{t+1})，则在该 lookahead 下为 unstable；否则为 stable。一次 invocation 包含固定 budget 内的完整多次 local-search round，因而 label 不是某一步局部 move 的结果。

Figure 1（p.3）在 100 个 CVRP 实例上用 LKH-3 绘制 re-optimized edge percentage 随迭代下降，CVRP2k/CVRP3k、C=300 两条曲线均由约三成降向个位数。图支持“稳定边越来越多”的动机，但它是 LKH-3/CVRP 观察，不能单独推出所有 solver/VRP variant 的稳定性。

### 6.2 FSTA 的最小逻辑单元

给定每条 route (R_i=(x_0\to x^i_1\to\cdots\to x_0))，segment (S^i_{j,k}) 是连续节点序列。模型/启发式先标记 unstable edges，去除这些边后，stable edges 连接出的连续节点组成 disjoint segments。每个 segment 被表示为一个 hypernode 或两个端点 hypernodes；属性如 demand、时间窗和 service time 按 variant 聚合。Reduced problem (	ilde P) 由这些 hypernodes 与未聚合节点组成，backbone 在 warm start (	ilde R) 上重优化，最后展开 hypernodes 得到 (R^+)。

Algorithm 1（p.19）的不变量是：每一轮都只通过 `M(P,R)` 重新决定 unstable edges，随后顺序执行 `GetSegments`、aggregation、backbone re-optimization、recovery，并把恢复解作为下一轮当前解。边连 depot 时强制算作 unstable，以保留合法 depot 连接。

两种聚合选择揭示了方法的实际权衡。**Dual hypernode** 保留两端、可支持双向 segment traversal，但要固定端点连接边；**single hypernode** 减少更多节点，却固定 traversal 方向并可能把 symmetric routing 变成 asymmetric。FSTA 因而需要能利用 initial solution 的 solver；dual 还需要 solver 支持 fixed-edge local search。作者实际接入 LKH-3、LNS、L2D，HGS 的 initial-solution 接口留作未来工作（p.19）。

### 6.3 跨变体的聚合与保证

Section 3.2（p.4）明示两个 theorem。

- **Feasibility**：若 aggregated solution (	ilde R^+) 对 reduced problem 可行，则展开的 (R^+) 对原 problem 可行。
- **Monotonicity**：若两个 feasible aggregated solutions 满足 (f(	ilde R_1^+)\le f(	ilde R_2^+))，展开后仍保持 (f(R_1^+)\le f(R_2^+))。

证明在 Appendix B.2（p.21–26），先假设 segment 外节点按原表示保留，dual aggregation 固定两端连接边，再分别处理：

- **CVRP（p.21–22）**：双 hypernode 端点位置保留，segment demand 平分为两端；式 (4)–(5) 保持 route capacity，式 (6)–(7) 说明展开与聚合目标只差一次 segment-dependent constant。
- **VRPTW（p.20、p.22–25）**：先用式 (3)/(8) 递归构造 (ar t_j^l,ar t_j^r,ar s_j)。若 (ar t_j^l\le ar t_j^r)，用 single hypernode；否则用 dual hypernode，一端负责 feasibility time window，另一端负责 travel-time expenditure，且端点间 distance 置零。式 (9)–(16) 对 segment 长度做 induction，证明 waiting/service/travel 的总时间函数相同；式 (17)–(18) 回收 monotonicity。
- **VRPB（p.25–26）**：single hypernode 只在 segment 内 customer type 一致时使用，linehaul/backhaul 交界边纳入 unstable set；式 (19)–(21) 分别保持 backhaul、linehaul 与容量条件。
- **1-VRPPD（p.26）**：使用三个 hypernodes (x_j,x_{mid},x_k)，以 (D_{min},D_{max}) 编码 segment 内 prefix-load range，端点到中点再到端点有强制 directed edges；式 (22)–(23) 保持每个 prefix load 在 ([0,C])。目标单调性归约到 CVRP 的双 hypernode 证明。

理论在因果链中的角色是**聚合后的结构保证**，不是学习预测正确率的保证。它建立了“只要 reduced problem feasible 且 mapping 条件满足，搜索可安全收缩”的边界；FSTA 的效率收益仍取决于不稳定边预测和 backbone 的 warm-start 能力。

## 7. L2Seg 的架构、训练与推理

### 7.1 共享 encoder 与增强输入

Figure 3（p.5）把输入划成两类边：当前 solution 中的 route edges 与每个节点的 k-nearest-neighbor edges。节点特征包括 xy、normalized demand、subtour centroid、两条相邻 solution edges 的端点坐标/成本、relative coordinates、相对 depot 的 angle 与 distance-weighted angle、最近邻距离、同一 subtour 的 K-nearest 比例等；VRPTW 再加入 time window/service time。标准输入 (X\in\mathbb R^{n\times25})，VRPTW 为 (n\times28)，edge features 包括 travel cost、是否属于当前 solution、相对端点的 cost rank（Table 8, p.28）。

初始节点 embedding 是 (h_i^{init}=Concat(h_i^{MLP},h_i^{POS})\in\mathbb R^{2d_h})。两层 route-specific masked Transformer（(d_h=128)，2 heads）编码同 route 结构，随后两层 Graph Attention/transformer convolution 在 solution+kNN 图上整合全局关系，输出 (H^{GNN})。mask 防止 Transformer 在不同 route 之间直接计算，GNN 保留跨图的全局信息。

### 7.2 NAR、AR 与 SYN

- **L2Seg-NAR**：对每个节点用 MLP+sigmoid 一次前向产生 (p_i^{NAR})，阈值以上节点的所有关联 edges 标记为 unstable。它覆盖全局但会把同一区域的相邻边一起标成 unstable。
- **L2Seg-AR**：序列 (a=\{x_{\pi_0},x_{\pi_1},\ldots\}) 交替 deletion/insertion。Deletion 从当前 solution 中 target node 的至多两条 incident edges 选择一条并只作标记；insertion 选择不在 solution 的 pseudo-edge，桥接到下一个 target，并可用 (x_{end}) 终止。GRU 累计序列 context，MHA 选择节点；deletion 用 1 层、insertion 用 4 层 MHA，适应“至多 2 个候选”与 (O(|V|)) 候选规模。它能表达局部依赖，却需要起始 target，因此可能漏掉远处 unstable region。
- **L2Seg-SYN**：先把约 (|R|) 对 adjacent routes 组成子问题，NAR 以 (eta=.6) 找 global unstable nodes，再在预测节点上做 (n_{KMEANS}=3) 聚类，每簇选 (p_i^{NAR}) 最高的起点交给 AR。所有子问题的 AR edge 集合并集构成最终 (E_{unstable})。AR-only 在全部节点上 K-means、取离簇中心最近节点；NAR-only 直接标记关联边。

Figure 2（p.4）把上面四步画成“detect → group → aggregate → re-optimize → recover”，Figure 3 则把 global NAR 与 local AR 的数据流并置。方法介绍中，global/local 的互补是最清晰的可检验机制假设。

### 7.3 Lookahead imitation training

给当前 (R) 用 iterative solver 得到 (R^+)，差异边为 (E_{diff}=(E_R\setminus E_{R^+})\cup(E_{R^+}\setminus E_R))，端点集合 (V_{unstable}=V_{E_{diff}})。NAR 样本是两条 adjacent routes 的 node-level binary labels；AR 样本由 (E_{diff}) 的 connected components 生成，只保留跨至多两条 routes 的 component，并用 DFS 得到交替 deletion/insertion 序列与 `x_end`。Figure 4（p.6）明确展示 deleted/newly inserted edges 如何转成 connected component 和 label sequence。

训练使用 NAR weighted binary cross-entropy（(w_{pos}>1)）和 AR weighted cross-entropy，其中 (w_{insert}>w_{delete}) 以平衡两个阶段。Algorithm 2（p.29）补充了 (N_P=1000) instances、(T_{IS}=40) iterations、(eta_{improv}=0)，大容量 CVRP 的 (alpha_{AC}=0.4)，小容量 CVRP/VRPTW 为 0。附录文字称 AR labels 只保留 improvement 超过阈值且按 (alpha_{AC}) stochastic sampling，因而数据同时受 lookahead solver、improvement threshold 和 acceptance coefficient 影响。

### 8.2 统计口径

论文真实报告的是每实例 cost/time 的平均值与相对 gain/gap。Table 1 的 gain 相对同一 backbone，Table 2 的 gap 相对 HGS，Table 11 相对 best-known solution，Table 13 为 5 次独立 trial 的 mean ± standard deviation。没有回归、相关、bootstrap、Bayesian analysis、假设检验或多重比较校正。Table 5 的 label similarity 是 stable-edge overlap percentage；Table 4 的 Recall/TNR 是 edge prediction confusion metrics。主文把“统计意义”与“机制证据”分开得不充分，机制部分主要依靠 Table 4、Figure 6–7 与附录 Figure 12。

## 9. 结果、图表与算法证据

### 9.1 主文结果

**Table 1（p.8，Section 5.1）**在 large-capacity CVRP 上比较三种 L2Seg 与 LKH-3/LNS/L2D。CVRP2k 的 full SYN objective 分别为 43.92（LKH-3，+2.92%）、43.42（LNS，+3.34%）、43.35（L2D，+0.78%）；CVRP5k 分别为 64.12（+1.87%）、63.94（+1.16%）、63.89（+0.50%）。NAR 与 AR 单独也均改善各 backbone，但 SYN 每个 backbone 都给最低 objective。表中时间约 151–249s，与基线同量级；headline 的 2x–7x speedup 由 Figure 5 的达到同一 objective 所需时间曲线表达，不能从 Table 1 的固定时间单元直接读成 2x–7x。

**Figure 5（p.8）**绘制 CVRP2k 上两栏 search curves，曲线标注最高约 7.4x，CVRP5k 仍有约 2.0x–5.7x 的标注。它的任务是呈现“达到相同 objective 的时间缩短”，不是新的统计估计；图注没有误差带。

**Table 2（p.9，Section 5.2）**在标准 CVRP/VRPTW 上比较 baseline。最强的 L2Seg-SYN-L2D 在 CVRP1k/2k/5k 的 objective/gap/time 为 41.23/+0.07%/2.5m、56.05/−2.01%/4.1m、121.87/−3.55%/5.1m。VRPTW 对应为 87.25/−3.43%/2m、163.74/−5.60%/4m、333.4/−3.14%/10m。L2Seg-SYN-LNS 的 VRPTW 三个 gap 是 −3.36%、−5.49%、−2.93%。这些数值显示增益随 backbone 和规模而异；CVRP1k 的 L2Seg-SYN-L2D objective 41.23 略高于 HGS 的 41.20，因而“surpass”应按大多数规模/组合理解，不能读成每个单元都胜出。

**Table 3（p.9）**把随机 FSTA 与 feature ablation 放在 LNS 之上。CVRP2k 的 LNS/Random40%/Random60%/SYN-without-enhanced-features/full-SYN objective 是 44.92/46.24/46.89/43.65/43.42；CVRP5k 是 64.69/66.72/65.92/64.22/63.94。随机标边恶化，去掉增强 feature 仍有部分收益但不及完整方法。

**Table 4（p.10）**给出 CVRP2k 的 edge-level prediction：SYN Recall 89.02%、TNR 61.24%、objective 43.42；NAR 为 91.46%、51.79%、44.02；AR 为 74.39%、54.07%、44.12。它直接支持“综合 recall 与 TNR 的平衡”这一机制解释。Figure 6 是概念图，展示 NAR 过标、AR 起点漏检、SYN 互补；Figure 7 把 conservative ((\eta=.9,n=2))、moderate ((\eta=.6,n=3))、aggressive ((\eta=.3,n=10)) 的 reduced/original size、Recall、TNR 和 objective 放在一起，中间配置的 objective 最低。

**Table 5（p.10）**检验 label 是否主要是 problem structure。HGS 60s 与 LKH-3 3000-step 作为 ground-truth 参照，HGS 与 LKH-3 1000-step 的 stable-edge overlap 分别是 78.3% 与 85.1%，LKH-3 3000-step 自比为 100%。作者解释为结构因素占主导，同时存在 solver-dependent pattern；这是跨 solver label 的相关性证据，不是因果分解。

## 14. 最终判断

1. **单一主线**：把迭代 VRP solver 中“只少数 edges 真正变化”的现象转成可学习的 edge-level unstable prediction；FSTA 固定 stable segments 为 hypernodes、只在 reduced problem 上重优化，L2Seg-SYN 再以 NAR 找区域、AR 做局部精修。
2. **正文保留的决策关键内容**：稳定性动机、FSTA segment/hypernode/recovery 定义、feasibility/monotonicity theorem 的陈述、共享 encoder 与三 decoder 的差异、lookahead label 逻辑、Table 1–5 的主结果和 recall/TNR 机制证据。
3. **移入附录的内容及影响**：完整证明、VRPTW/VRPB/1-VRPPD 属性规则、enhanced feature/mask、训练/推理算法、baseline/数据/超参、realistic 与 variance/overhead/training-time 结果。核心叙事仍可读，但复现 reduced problem 和 AR label 需要附录共同成立。
4. **最有效的写作/图表模式**：Figure 2 用一条横向 FSTA pipeline 配三条 decoder 分支，Figure 3 将 encoder、NAR、AR 放在同一数据流；Algorithm 1 把理论五步落实为循环；Table 4 把“global recall 与 local precision 的互补”转成可检验指标。
5. **最大叙事缺口**：2x–7x 是曲线/摘要 headline，不是每个固定时间表单元的直接 speedup；label 由特定 lookahead solver 生成，跨 solver 的相似性只做 overlap 分析；HGS 与未测试 VRP variants 的兼容性保持为边界主张。Table 6 还把 oracle label 的 lookahead 时间排除在外。
6. **可迁移规则**：当搜索空间中存在可识别的稳定结构时，先证明“聚合—展开”保持可行性和目标顺序，再用一个 global region detector 提供覆盖，用一个 conditional local refiner 控制过标；同时把 warm-start/fixed-edge 能力写成 solver contract。
7. **规则边界**：只有当 segment 的约束属性能被有限 hypernode 表达、recovery 的目标差是 segment-dependent constant、backbone 能利用 reduced warm start，且 label 分布与部署 solver 足够接近时，global-local synergy 才有同样含义。对需要跨 segment 交互、无 fixed-edge 接口或 lookahead 标签偏移显著的 solver，本文证据不能外推。
