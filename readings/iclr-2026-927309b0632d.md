## 5. 方法与理论

### 5.1 形式对象与前置假设

1. 目标是 `ptarget(x) ∝ exp(−E(x))`，`Z` 为配分函数；`E: R^d→R` 可有效计算但不要求可微。作者另外假设有小型、有偏数据集 `D={xi}`，用来先拟合 proposal `pθ(x)`（p.3 §2，Eq. 1，`explicit`）。
2. BG 从 `pθ1` 抽取独立样本，权重为 `exp(−E(xi))/pθ1(xi)`，用 SNIS 估计任意 observable（Eq. 2）。这是全篇“likelihood 必须可计算”的因果接口（p.3，`explicit`）。
3. Flow matching 在 `p0=pnoise` 与 `p1=pdata` 间使用 `xs=sx1+(1−s)x0`；CNF 的 ODE 通过 instantaneous change of variables 追踪 `[xs, log pθs(xs)]`，需要 exact trace 或 Hutchinson 近似。积分离散误差与 trace 计算是 CNF 端瓶颈（Eq. 3，p.3，`explicit`）。
4. Few-step flow map 用同时输入当前时间 `s`、目标时间 `t` 的平均速度 `uθ(xs,s,t)`。理想平均速度为区间内向量场积分除以 `t−s`，采样时按任意时间 schedule 做离散更新；但训练未完美收敛时 `uθ` 的离散映射不保证可逆，标准 change-of-variables 不能直接用（Eq. 4–5，p.4，`explicit`）。

### 5.2 FALCON 的最小逻辑单元

#### (a) 从连续 map 到离散 map

作者先定义连续向量场 map `Xv(xs,s,t)=xs+∫_s^t v(xτ,τ)dτ`（Eq. 6，p.4）。在足够光滑、且 average-velocity objective 达到最优时，离散 map `Xu(xs,s,t)=xs+(t−s)u⋆θ(xs,s,t)`（Eq. 7）等于 `Xv`，因此由 Picard–Lindelöf 取得可逆性和 change-of-variables likelihood。Proposition 1 的关键范围是“最优点”和“`Xu=Xv`”情形，作者随后明确说明实际训练通常不满足这一条件（p.4–5，`explicit`）。

#### (b) cycle-consistency/invertibility loss

FALCON 不要求学到特定的 `Xv`，而只要求离散 map 有逆。于是加入
`Linv=E||xs−Xu(Xu(xs,s,t),t,s)||²`（Eq. 8），再和 flow matching、average-velocity 两项合并为
`L=Lcfm+λavg Lavg+λr Linv`（Eq. 9，p.5）。这把前文“few-step 生成但 likelihood 不可用”的缺口直接转成前向/反向 cycle consistency 目标。Proposition 2 声称 `Linv` 的最小化足以在不精确复现连续流时得到 pointwise invertible map 和相应 log-density change（p.5，`explicit`）。

#### (c) 架构、平均速度与训练实现

- 主干是带额外 time-embedding head 的 standard DiT；data augmentation 用于 soft `SO(3)` rotation equivariance，减去均值用于 translation invariance（p.5）。
- 主实验采用与 MeanFlow 等价的 `Lavg`（Eq. 10），通过一个 forward-mode automatic-differentiation 的 JVP 实现；因为 `xs=sx1+(1−s)x0`，可直接取 `v(xs,s)=x1−x0`（p.5）。
- 当把一部分 `(s,t)` 采样设为 `s=t` 时，`v(xs,s)=uθ(xs,s,s)`，可在同一训练分布中合并 `Lcfm` 与 `Lavg`（p.6）。
- 前后向都需要 flow map。由于 `t→s+` 与 `t→s−` 的速度符号不同，作者以 `uθ(xs,s,t)=sign(t−s)hθ(xs,s,t)` 处理 `s=t` 附近不连续性（p.6）。

#### (d) 算法与不变量

Algorithm 1 的输入是可采样 `p0,p1`、`λr` 和网络 `uθ`，每轮抽 `(x0,x1)`、构造 `xs` 和 `vs=x1−x0`，一次 JVP 得到 `uθ, ∂uθ/∂s`，构造 stop-gradient target `utgt`、前向 `x̂t`、反向 `x̂s`，再优化 regression + `λr` reconstruction loss（p.6）。关键不变量是 `x̂s` 应回到 `xs`；算法没有显式求逆网络，也没有在训练伪代码中给出 schedule/EMA/gradient clipping 等实现细节，这些被移到 Appendix D。

## 6. 实验设计

### 6.1 问题、数据、模型与基线

- 研究问题按 §4 顺序隐含列出：FALCON 是否在更大分子上超过 continuous flows；是否超过给出更大采样预算的 discrete NFs；`λr` 是否同时影响 invertibility 与 sample quality；inference schedule 是否影响 few-step 指标（p.6，`explicit`）。没有独立的 H1/H2 预注册清单。
- FALCON 的两个 loss：MeanFlow-equivalent 的 FALCON，以及 Appendix B additivity loss 的 FALCON-A；默认 FALCON，因为在较大系统的指标上“best or second best”（p.6）。
- 数据集：alanine dipeptide（ALDP）、tri-alanine（AL3）、alanine tetrapeptide（AL4）、hexa-alanine（AL6）。数据来自 implicit-solvent MD，Amber force fields；训练集有偏，测试为 held-out unbiased data，并通过 SNIS 与 force-field energy 重采样（p.6）。
- 离散基线包括 SE(3)-EACF、RegFlow、SBG IS、SBG SMC；连续基线包括 ECNF、ECNF++、BoltzNCE。连续流统一用 Dormand–Prince 4(5)，`atol=rtol=10−5`；BoltzNCE 的正文描述限定在 ALDP（p.6）。
- 指标：normalized Effective Sample Size（ESS，越大越好）、energy 2-Wasserstein（E-W2，越小越好）、dihedral torus 2-Wasserstein（T-W2，越小越好）。作者解释 E-W2 对局部 bond-length 变化敏感、T-W2 反映 metastable mode coverage（p.6；公式 p.22）。
- 随机性与硬件：定量实验用三个 model seeds，表和图报告 mean ± standard deviation；训练在 H100/L40S heterogeneous cluster 上用 DDP，Table 4 的计时在 NVIDIA L40S、batch size 1024（p.7、p.8、p.18）。

### 6.2 训练、推断与数据切分的复现粒度

Appendix D 给出 DiT hidden size 192、6 blocks、6 heads、conditioning dimension 64、3.2M parameters，四个 peptide 使用相同配置；EMA decay 0.999，logit clip 0.002，关闭 compositional energy regularization；AdamW 学习率 `5×10−4`、`β=(0.9,0.999)`、`ϵ=10−8`、weight decay `10−4`，cosine schedule 加覆盖 5% iterations 的 warm-up（p.18，Table 6）。

数据切分是单条 MCMC chain 的 train/validation/test = `10^5 / 2×10^4 / 10^4`；train 与 validation 为 contiguous chain regions，test 从余下 chain 均匀 stride，以模拟从已生成轨迹继续建立 BG。MD 时长 1 μs、timestep 1 fs；温度按正文列出为 ALDP 300 K、AL3 310 K、AL4 300 K；force fields 依次为 Amber ff99SBildn、Amber 14、Amber ff99SBildn（p.20）。PDF 此处写的是 “all three molecules”，没有单独给出 AL6 的温度和 force field（`not_present`，p.20）。

推断时 CNF 用 Dopri5 adaptive solver；exact trace 被认为是 BG 稳定性所需，Hutchinson 的 single-sample estimator 更快但方差更高。FALCON 每个离散步精确算 Jacobian determinant，Algorithm 2 累积 `p_i=p_{i−1}−log|det JXu|`，成本约为 `N·d` function evaluations；CNF likelihood 约为 `Tl·d`，正文示例 `Tl≈200,N≈8`，另有 `O(d³)` determinant 项但作者认为不是瓶颈（p.19，`explicit`）。

### 6.3 控制、泄漏与缺失项

训练 contiguous 区域与 held-out unbiased test 的设计提供了“有偏 proposal → energy/SNIS 校正”的基本控制；Tri-alanine 还明确构造训练缺失 `ψ1≈π/3` mode、`ψ2` undersampling 的情形（p.20，`explicit`）。然而 PDF 没有给出每个 baseline 的统一训练预算、完整随机种子值、预先失败判定阈值、超参数搜索空间、显著性检验或多重比较流程。`mean ± SD` 是跨 model seeds 的离散量，不是置信区间或假设检验。

有一项直接影响复现的数字冲突：Table 3 caption 写 `2×10^5 samples`，而 Appendix D.1 的 Training Configuration 写 evaluation 生成 `10^4` proposal samples 并用同数重采样和计算指标（p.7、p.18，`explicit`）。论文没有解释这是不同实验阶段、不同表，还是笔误。

### 8.1 自我设限与呈现策略

- **摘要/引言范围偏宽**：摘要说 FALCON outperforms state-of-the-art models，贡献清单说 across all metrics；但 ALDP Table 2 中 ECNF++ 的 ESS、T-W2 以及 FALCON-A 的 T-W2 更好。这里能确认的是 claim scope 与一张表的指标排序不完全一致，不能据此推断作者意图（p.1–2、p.7，`interpretation`）。
- **限制延后**：theoretical correctness、one-step generation、领域只限 molecular Boltzmann Generation 统一留到 p.10 Limitations；主结果先以 “accurate enough” 与速度图建立可用性。该延后由版面位置直接可见（p.8–10，`layout_observation`）。
- **图代替匹配数值**：two-orders speed claim 主要依赖 Fig. 2/13 的 log-scale 曲线；没有单独列出同一 T-W2 下两种 solver 的时间/NFE 配对表。图有误差条，图注能说明指标和比较对象，但不能独立恢复每个 operating point（p.2、p.24，`layout_observation`）。
- **全局结构移入附录**：正文 §4.1 明说 energy histograms 留在 main text，而 Ramachandran plots 放到 §F.4；因此主文保留局部 energy 与 aggregate metrics，把 mode coverage 的直接图证据延后（p.7、p.22，`explicit`）。
- **分母不一致**：Table 3 的 `2×10^5` 与 D.1 的 `10^4` 同时存在；这是文本事实冲突，不应解释为作者选择了某种有利分母（p.7、p.18，`explicit`）。

## 9. Conclusion、Limitations 与论证闭环

### 9.1 结论逐段

1. **重述问题与方法（p.10）**：FALCON 是解决 scalable/efficient Boltzmann sampling 的 few-step flow model，以 hybrid objective 组合 expressiveness、training efficiency 与快速 likelihood estimation。
2. **回收结果（p.10）**：作者回收“胜 discrete normalizing flows”和“相对 continuous flows 显著更省计算”，重报 two orders of magnitude faster，并将意义外推到 drug discovery/materials science。
3. **Limitations（p.10）**：computed likelihoods 只在经验上足够好，无法高效保证理论正确；true one-step generation 尚未实现；当前主要限于 molecular conformation 的 Boltzmann Generation，未来考虑 Bayesian inference、robotics、structured Jacobians。

结论没有引入新的数字，但重复了速度量级；最后一段明确回收了尚未解决的三条边界（`explicit`）。p.11 的 Ethics Statement 进一步要求在敏感场景谨慎使用；Reproducibility Statement 指向 §F.1、§D.1 及数据 split/MD 参数，并说 acceptance 后公开代码（p.11，`explicit`）。

## 12. 最终判断

1. **单一主线**。BG 的 SNIS 需要每个样本都能快速取得 proposal likelihood；CNF 的连续积分精度带来高 NFE；FALCON 将 few-step average-velocity flow map 与前后向 cycle-consistency 结合，使自由架构在实践上提供足够准确的离散 Jacobian likelihood，再以 DiT 和 schedule 把速度优势扩展到较大 peptide。证据位于 p.1–6、Eq. 2–10、Algorithm 1（`explicit`）。
2. **正文保留的决策关键内容**。目标/BG/SNIS 接口、CNF 成本瓶颈、`Linv` 与 hybrid loss、Proposition 1–2 摘要、Algorithm 1、三项指标、Tables 2–5、Fig. 2–7 和三条 Limitations。这些足以判断“速度、质量与正则折中”是否成立（p.3–10，`explicit`）。
3. **移入附录的细节及影响**：证明展开、Lavg 替代、DiT/optimizer/EMA、Dopri5/trace、schedule 方程、MCMC split、指标定义、reverse-map/NFE/Ramachandran 图移到 A–F；正文的速度与指标结论仍可读，但完整复现和全局 mode coverage 依赖附录（p.16–25，`explicit` + `interpretation`）。
4. **最有效的写作、图、表、公式模式**：Eq. 3 对照 Eq. 8–9，把“likelihood 成本 → 可逆性目标”显式转译；Table 3 以三个分子规模并列 local/global metrics；Table 4 把 training+inference 合并为真实系统成本；Fig. 5–7 把 steps、`λr`、schedule 三个可控旋钮分别可视化（p.3–9，`layout_observation`）。
5. **最大叙事缺口**：理论只在精确 minimizer/`Linv→0` 条件下闭合，实际 finite training 的 likelihood 偏差没有上界；ALDP Table 2 不支持“所有 metrics 都胜”这一宽范围句子；Table 3 与 D.1 的样本分母冲突进一步提高复现成本（p.7、p.10、p.16–18，`interpretation` + `explicit`）。
6. **可迁移规则**：若论文把“可逆/可计算 likelihood”作为能力主张，必须同时报告（i）形式条件与误差量化边界，（ii）有限训练后 reconstruction/Jacobian/likelihood 误差，（iii）按相同 operating point 的速度—精度配对表，而不能只以理想定理和一张 log-scale 曲线连接二者。
7. **适用边界**：该规则适合有显式可逆性、数值误差和样本预算接口的生成/采样论文；若研究对象没有 likelihood 或 inverse map，需把误差对象改成任务特定 estimand，不能机械要求 CNF 式 Jacobian 证据。FALCON 本文也明确把 Bayesian inference、robotics 留为 future work，未在当前设计中检验（p.10，`explicit`）。
