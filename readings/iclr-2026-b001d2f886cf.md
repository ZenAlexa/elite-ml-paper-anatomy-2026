## 2. 一句话主线与总体判断

论文把「value evaluation 缺乏 informativeness」设为唯一问题：静态、通用或可能被污染的问题使已对齐 LLM 给出趋同答案；AdAEM 以 diverse LLMs 的回答差异为搜索信号，交替生成回答、改写问题，并用 Multi-Armed Bandit 扩展 topic，从而构造更能区分模型的动态题集。〔PDF p.1，Abstract；“current value measurement methods face the informativeness challenge”〔explicit〕；PDF p.4，§3.2；“maximize value difference”〔explicit〕〕

论文完整交付了形式目标、可执行代理分数、题集生成、相对排名指标、构念效度检验与多组稳健性分析。核心识别缺口仍然存在：题目本身按照「模型间差异更大」的代理目标优化，随后又用「观察到更大差异」支撑测量更真实；value priming 与内部一致性验证了 sensitivity、discriminant response 和 reliability，尚未提供独立于该优化信号的外部 value ground truth。这个判断属于解释，依据来自目标定义、主结果与作者对「LLM 是否真正拥有 value」不可回答的明示边界。〔PDF p.4，§3.2；“distinguishability score, and aim to find x to maximize S”〔explicit〕；PDF p.9，§4.3；“AdAEM exposes more value differences”〔explicit〕；PDF p.22，Appendix A；“is an unanswerable question”〔explicit〕〕

## 7. Method 与 Theory

### 7.1 形式对象、输入、输出与目标

- **被评模型**：`{pθ_i(y|x)}_{i=1}^K`；输入 `x`，输出 response `y`。〔PDF p.3，§3.1；“Define {pθi(y|x)}”〔explicit〕〕
- **测量对象**：`v=(v1,…,vd)`，每维位于 `[0,1]`；value analyzer `pω(v|y)` 从 response 推断 value。〔PDF p.3，§3.1；“v as a d-dimension vector”〔explicit〕〕
- **题集输出**：经验分布 `p̂(x)`，实现上是高 `S(x)` 的 questions；最终 benchmark 为 `X`。〔PDF p.3–4，§3.1–3.2；“construct test questions x”〔explicit〕〕
- **双重目标**：distinguishability 要求模型间 `pθ_i(v|x)` 可分；disentanglement 要求 response value 不被 question value 主导。〔PDF p.4，§3.2；“distinguishability” / “disentanglement”〔explicit〕〕
- **生成时状态**：每个 topic arm 保存 `Xi`、scores `Si`、访问计数 `Ci`、平均增益 `Qi`；预算 `B` 决定 outer-loop 成本。〔PDF p.5，Algorithm 1；“Ci ← 0, Qi ← 0”〔explicit〕〕
- **评测输出**：每个模型在每个 value dimension 上的 TrueSkill-relative win rate。〔PDF p.6，§3.3；“final v is calculated by the win rate”〔explicit〕〕

### 7.2 最小逻辑单元与动作转移

1. `setup_notation`：定义 model、question、response、value analyzer 与经验题分布。〔PDF p.3，§3.1；“The value evaluation process can be formalized”〔explicit〕〕
2. `state_problem`：把 informativeness 写成 distinguishability + disentanglement。〔PDF p.4，§3.2；“poses two requirements”〔explicit〕〕
3. `derive`：Eq. (1) 以 generalized JS / KL 项和 question-response value distance 构造目标。〔PDF p.4，§3.2；“solving the optimization problem”〔explicit〕〕
4. `derive → give_intuition`：引入 response `y` 作为 latent variable，以 IM / EM-like alternation 处理黑盒目标。〔PDF p.4，§3.2；“involve the response y as a latent variable”〔explicit〕〕
5. `define_component`：Eq. (2) 的 response generation 同时奖励 value conformity、semantic coherence、value difference、semantic difference。〔PDF p.4–5，§3.2；“value conformity”〔explicit〕〕
6. `define_component`：Eq. (3) 的 question refinement 奖励 context coherence、value diversity、opinion diversity，并加 disentanglement regularizer。〔PDF p.5，§3.2；“Question Refinement Step”〔explicit〕〕
7. `instantiate_algorithm`：Algorithm 1 用 UCB 式 topic selection 连接 exploration 与 optimization；`P1` 负责低成本生成，`P2` 负责较可靠 scoring。〔PDF p.5，§3.2 / Algorithm 1；“variant of Multi-Arm Bandit”〔explicit〕〕
8. `define_component`：evaluation metric 先抽取每个 response 的三条 opinion，再按 value-wise logical OR 合并。〔PDF p.6，§3.3；“Opinion based value assessment”〔explicit〕〕
9. `contrast_alternative`：相对 TrueSkill 聚合代替 absolute LLM-as-judge score，以 win rate 输出。〔PDF p.6，§3.3；“Relative ranking based aggregation”〔explicit〕〕

主转移序列为：`setup_notation → state_problem → derive → define_component(response) → define_component(question) → give_intuition → instantiate_algorithm → define_metric → connect_to_experiment`。

## 10. 结果、统计与不利解释

### 10.1 主要结果

1. **规模与 novelty proxy**：AdAEM Bench 有 12,310 题，`Avg.L.=15.11`、`Self-BLEU=13.42`、对其他题集的 average similarity 为 0.28–0.44。指标支持题面多样性与低文本相似，无法直接证明训练数据未见。〔PDF p.6、32，Table 1 / Tables 7–8；“lower probability that these questions were memorized”〔interpretation〕〕
2. **Human question quality**：300 pairs、5 annotators；Rationality 2.54→2.76，Controversy 1.42→2.17，Value Elicitation 1.47→2.24；Cohen’s κ=0.93。表中没有 annotator/task dispersion 或对均值差异的 inferential test。〔PDF p.33，Appendix C.10；“Cohen’s κ = 0.93”〔explicit〕〕
3. **Schwartz priming validity**：o3-mini target mean 76.46→98.62，paired `t=-3.90, p=0.004, d=1.23`；same-group `d=0.464`；opposite-group `d=-1.85`。这支持 construct sensitivity 与 discriminant response。〔PDF p.33–34，Appendix C.11；“support the benchmark’s construct validity”〔explicit〕〕
4. **GPT-5 priming replication**：target、same-group、conflicting 的平均变化分别为 +396.6%、+25.7%、−35.7%；Hedonism 低 baseline 造成 +3189.47% 的 ratio inflation，平均 percentage 容易被小分母放大。〔PDF p.35，Table 12；“Hedonism 3.04”〔interpretation〕〕
5. **Predictive utility case**：unseen education question 上 o3-mini 与 Llama-3.1-8B 立场被作者称为和 Tradition score 98.8 vs 49.06 一致；这是单例 case，未给 case-set accuracy。〔PDF p.7，§4.2；“98.8 vs. 49.06”〔explicit〕〕
6. **Reliability**：5 random partitions 得 `Cronbach’s α=0.8991`、`CV=0.2845`；聚合单位是 partition-level evaluation profile，未报告 uncertainty interval。〔PDF p.49，Appendix K.3；“0.8991 and 0.2845”〔explicit〕〕
7. **Regional / temporal extension**：Figures 5–6、15–16 显示 model-specific country coverage 和 cutoff-matched events；它们证明生成内容可随 backbone knowledge 变化，尚未验证真实周期 deployment 的长期 drift tracking。〔PDF p.8、39–40，§4.3 / Appendix E.2–E.3；“whenever a new LLM is released”〔interpretation〕〕
8. **Optimization**：Figure 7/18 显示 `S(x)` 随预算总体上升并趋稳；作者同时指出后期集中到更少 topic，quality–diversity 存在 trade-off。〔PDF p.8–9，§4.3；“may hurt diversity”〔explicit〕〕
9. **Value difference**：Figure 8 中 SVS / ValueDCG / ValueBench 的 model profiles 更相似，AdAEM 更分离；由于 `S(x)` 就含 model separation，该结果同时反映构造目标成功与测量差异，二者需要独立 criterion 才能完全区分。〔PDF p.4，Eq. (1)；“distinguishability”〔explicit〕；PDF p.9，Figure 8；“exposes more value differences”〔interpretation〕〕
10. **16-model benchmark**：Figure 9 给出 160 个 score；作者提出 advanced models 偏 safety-relevant values、family similarity、reasoning/chat 差异与 size amplification。这些是描述性 pattern，未做 family/size control regression。〔PDF p.9–10，§5 / Figure 9；“We obtain four interesting findings”〔explicit〕〕
11. **Topic heterogeneity**：Figure 8(b) 与 Figure 13 显示同一模型随 topic 改变 value profile；这与 p.22 的「overall, average orientation」操作定义一致，也提醒 Figure 9 的单一 profile 会聚合掉情境异质性。〔PDF p.10，§5；“differ notably between these two topics”〔explicit〕；PDF p.22，Appendix A；“overall, average value orientation”〔interpretation〕〕
12. **Approximation audit**：100 seeds 下 approximate vs exact 版本得到 Pearson 0.8560、Cronbach’s α=0.8978。它支持两个版本测量相近构念，仍未量化每个 question score 的 calibration error。〔PDF p.45，Appendix I.2；“Pearson Correlation reaches 0.8560”〔explicit〕〕
13. **MFT extension**：589 题的 AdAEM Bench-MFT 使四模型 average correlation 从 MFQ 0.625 / ValueBench 0.561 降到 −0.169，average within-profile std 从 0.096 / 0.133 升到 0.212；GPT-5 target priming 全维上升。它证明 framework 可重实例化一次，尚未覆盖「any value system」的普遍量词。〔PDF p.45–47，Appendix J；“theoretically applicable to any value system”〔interpretation〕〕
14. **Participant robustness**：AdAEM 与更小 `P1/P2` 的 AdAEM-2 profiles 得 ICC 0.8159、Pearson 0.7899、Spearman 0.7309、Cronbach’s α 0.8387；reward mean 6.99 vs 6.51，说明参与模型会影响上限。〔PDF p.48，Appendix K.1；“better questions…by more advanced LLMs”〔explicit〕〕
15. **Question-count robustness**：200/500/1000 subsets 与 full set 的 consistency 随数量上升；作者称 200 已 consistent、1000 strong。具体四指标值只在 Figure 21，正文没有表格数字。〔PDF p.48，Appendix K.2；“even 200 samples can obtain consistent results”〔explicit〕〕

### 10.2 聚合与统计层级

- 基本 observation 是 `question × respondent model × opinion × value dimension` 的 binary labels；一个 response 内对三条 opinions 做 OR。〔PDF p.31，Appendix C.8；“v1 ∨ v2 ∨ ··· ∨ vl”〔explicit〕〕
- TrueSkill 按某题是否表达 value 把 models 分组更新，最终对其他 models 的 pairwise win probability 求平均。分母依赖参与比较的 model set，新增/删除模型可能改变 score scale。〔PDF p.31–32，Appendix C.8；“win rates against the other models”〔interpretation〕〕
- Human evaluation 的单位是 300 question pairs × 5 annotators；报告平均 Likert 与 κ。Priming t-tests 的表述显示配对单位为 value dimensions；没有多重比较修正说明。〔PDF p.33–34，Appendix C.10–C.11；“paired t-tests”〔explicit〕〕
- Robustness 使用 Pearson、Spearman、ICC、Cronbach’s α、CV；除 paired t-tests 外，没有 bootstrap、Bayesian model 或 uncertainty interval。〔PDF p.45、48–49，Appendix I/K；“ICC”〔explicit〕〕
- 论文区分 statistical significance 与 effect size：priming 同时报 `p` 与 Cohen’s d；human evaluation 与主 benchmark 主要报告 descriptive differences。〔PDF p.33–34，Appendix C.11；“Large effect size”〔explicit〕〕

## 14. 最终七项判断

1. **单一主线**：用自适应题目搜索把 LLM value measurement 从静态、趋同的问卷改造成以 controversial boundary 为中心的信息最大化过程，再用相对排名呈现差异。〔PDF p.2，§1；“value boundaries among LLMs”〔explicit〕〕
2. **正文保留的决策关键内容**：problem label、Figure 1、formal objective、E/M-like mechanism、MAB、TrueSkill metric、benchmark construction、human/priming/reliability 摘要、regional/temporal/budget 分析、16-model result matrix。〔PDF p.1–10，Abstract–§6；“Figure 9”〔layout_observation〕〕
3. **附录迁移及自足性影响**：exact executable proxy、prompts、完整控制流、统计检验、failure cases 和 robustness 均在附录。迁移明显降低方法复现与 validity audit 的正文自足性；作者已明示这项代价。〔PDF p.11，Reproducibility Statement；“concise main body may affect the readability”〔explicit〕〕
4. **最有效模式**：Figure 1 先把 generic consensus 与 AdAEM disagreement 具体化，Eq. (1) 将直觉压成两个可解释项，Figure 4 用 intervention 验证 measurement sensitivity，Figure 9 以一张全宽矩阵给最终产品面。这个顺序把 problem、mechanism、construct check、decision output 串成单线。〔PDF p.2、4、7、10；“Value priming results”〔interpretation〕〕
5. **最大读者成本 / 未闭合主张**：formal probability objective 与 practical proxy 相隔约 25 页；headline separation 同时是 optimization target 与 evaluation success criterion。读者需要跨 Appendix C/D/I 才能判断该差异代表 measurement validity 还是 selection-induced separation。〔PDF p.4、29–30、35–37、44–45；“approximation”〔interpretation〕〕
6. **可迁移规则**：动态 benchmark 若直接优化最终 headline metric，应在正文同时给出 exact executable proxy，并安排独立于该 proxy 的 intervention、external anchor 或 held-out criterion；主结果分别报告「优化目标达成」与「构念被测准」。〔PDF p.7、44–45；“construct validity”〔interpretation〕〕
7. **规则边界**：该规则适用于 test items 由受测模型、近邻模型或同类 judge signals 自适应生成的评测。固定题集且拥有独立 ground truth 的任务，selection-induced separation 风险较低，验证重点会转向 label quality、sampling 与 domain shift。〔PDF p.5，§3.2；“use K1 faster LLMs”〔interpretation〕〕
