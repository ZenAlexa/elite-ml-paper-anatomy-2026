## 5. 方法与理论

### 5.1 形式化对象和最小逻辑单元

1. **MDP 与 SF**（p.2）：reward-free MDP `M=(S,A,P,µ,γ)`；SF 是沿 policy 的 discounted feature sum（Eq. 1），若 `r(s)=z^Tϕ(s)`，则 `Q_r^π=z^Tψ^π`（Eq. 2）。
2. **BFM policy family**（p.3）：学习 `π_z` 使其对 `ϕ(s)^Tz` 最优（Eq. 3）；`z` 是低维 task embedding。标准离线 inference 用带标签数据解投影回归（Eq. 4）。
3. **在线设定**（p.3–4）：每个 episode/step 选择 `z_t`，执行 `π_{z_t}`；观察下一状态与 reward label。episode discounted return 和 expected regret 分别为 Eq. 5–6。
4. **reward-level estimator**（p.4）：以 feature–reward pairs 做 ridge least squares（Eq. 7–8），维护 `V_t` 与 `\hat z_t`；confidence ellipsoid `C_t`（Eq. 9）包含未知 `z_r`。
5. **optimistic acquisition**（p.4）：在 `z∈Z` 与可信 reward parameter `w∈C_t` 上取最大 predicted return（Eq. 10）。关键区分是 regression/context 使用 `ϕ`，acquisition 使用 BFM successor features `ψ`。
6. **算法实例化**（p.5）：Algorithm 1 每个环境步（理论变体则每个 episode）求 optimistic `z_t`、执行动作、收 reward/next state、用 `(ϕ(s_t),r_t)` 更新 estimator。
7. **理论条件**（p.5）：A1 perfect USF 与 greedy policy，A2 reward 在 feature span 内加 iid mean-zero `σ`-subgaussian noise，A3 exact optimization oracle，A4 `||z_r||₂≤S`、`||ϕ||₂≤L`。
8. **可实践化**（p.5–6）：Eq. 11 将搜索限制在 `C_t`，Eq. 12 把 inner maximization 写成 linear-UCB 形式；128 个候选 random shooting、ellipsoid push-forward、`O(d²)` Cholesky/information-vector updates；TS 和非平稳 reward 是变体。

方法动作转移序列为：

`setup_notation → state_problem → derive → define_component → explain_mechanism → give_intuition → instantiate_algorithm → state_complexity → connect_to_prediction → connect_to_experiment → contrast_alternative → summarize`。

### 5.4 实用机制

- **UCB 求解**：Eq. 12 用 `\hat z` 的 exploitation 项和 `β_t||ψ||_{V^{-1}}` 的 exploration 项替代双重优化；random shooting 取 128 个候选。`z∈C_t` 的搜索空间随置信椭球收缩。
- **TS**：把 ridge components 解释成 posterior `N(\hat z,V^{-1})`，采样一个 task embedding，避免 UCB 优化；实验名为 `OpTI-BFM-TS`。
- **Non-stationary**：用 `ρ^{t−s}` 对旧 feature–reward points 降权；`ρ=1` 是 stationary，较小 `ρ` 能追踪变化但减少 uncertainty 收缩速度。
- **标签主动请求**：Appendix B.2 以 D-gap `Δ(ϕ_t)=log(1+||ϕ_t||^2_{V^{-1}_{t−1}})` 与阈值 `κ` 决定是否请求 reward label。

## 6. 实验设计

- **环境／任务**：ExORL benchmark 中的 DeepMind Control Suite Walker、Cheetah、Quadruped，每个环境 4 个 reward tasks（p.6 §5；p.31 E）。
- **BFM 与训练**：以 Forward-Backward（FB）为 successor-feature BFM；Appendix D 说明 RND 采集的 10M-transition offline dataset、2M training steps、`γ=0.98`、task dimension `d=50`。
- **方法／基线**：`OpTI-BFM`、`OpTI-BFM-TS`、LoLA、Random、Oracle。LoLA 从 uninformed `z` 开始，使用 on-policy episodic returns，不允许 privileged resets；Random 每步从 `Unif(Z)` 取 embedding；Oracle 使用 Eq. 4 的线性回归并以 50k labeled pre-training samples 近似 `z_r`（p.6）。
- **交互与指标**：主图用 episode discounted return（Eq. 5）和相对 Oracle performance；task-inference 数据效率用前 `n` observed transitions 重新解 Eq. 4 后评估 `π_{z_n}`。Fig. 2/4/6 等多 episode 结果均值 over 10 trials；单 episode 结果均值 over 20 episodes（p.31）。
- **不确定性／聚合**：所有 error bars/shaded regions 是 3 个 training seeds 的 min–max interval；正文没有 p-value、显著性检验、bootstrap、Bayesian interval 或 participant-level uncertainty。论文把 seed 作为主要重复层级，trial/episode 均值未提供独立误差区间（p.6、p.31）。
- **控制变量与实现来源**：主比较固定环境、task、FB BFM 与 online interaction budget；Appendix F 对各方法做 hyper-parameter grid search，并按每个 environment 的 highest cumulative return 选报告配置。完整 FB architecture/loss/hyperparameters 在 D/F（p.30–34）。
- **顺序对应**：5.1 回答“相较在线 inference 是否更快”；5.2 回答主动数据是否 informative；5.3 对齐理论限制（episode vs per-step）；5.4 测 non-stationarity；5.5 测少量 labeled warm-start。该顺序与方法组件和理论预测逐一对应。

### Appendix D/F 的复现粒度

### 7.2 主要结果与不利解释

1. **主在线比较**：OpTI-BFM 在所有 DMC tasks 五 episodes 内达到 Oracle（p.7 Fig.2）；TS 在 Cheetah 明显落后，LoLA 的 black-box policy search 更慢。可能的不利解释是 Oracle 使用 privileged 50k labels、而方法选择了按环境累计回报最优的超参；作者没有在主图中给 exact per-task values，而把逐任务曲线移到 Fig.14。
2. **数据是否 informative**：用每种方法前 `n` 个 transitions 重解 Eq.4 以去除 ridge bias；主动 OpTI/TS 与 RND 超过 passive Random（p.7 Fig.3）。这支持“主动采样改善 inference data”的机制，但 RND 本身也是 exploration source，不能把全部增益归因于 task-awareness。
3. **更新频率**：per-step 版本更快，episode-level 理论版本最终相当（p.8 Fig.4；p.30 Fig.16）。这同时是实证优势和理论覆盖缺口，定理不能直接证明实践中更强的 per-step 版本。
4. **计算开销**：Table 1 的 latency 为 Oracle 0.772 ms、OpTI 3.567 ms、TS 2.756 ms，对应约 4.6× 与 3.6×；论文文字用“about 5x/4x”。因此“minimal compute overhead”在绝对毫秒上成立，但相对 policy-only baseline 并不小；没有给 GPU memory 或端到端训练成本。
5. **非平稳与错配**：ρ、α、projection error、noise 的附录实验都显示可解释的性能退化；这些是条件性鲁棒性曲线，不是对任意 misspecification 的保证。

## 9. 结论、限制与主张闭环

### 9.1 结论逐段

- **p.9**：重述“把可扩展 BFM 与 rigorous linear optimization 连接”，收回 efficient task inference、少 reward evaluations、可扩展到 rewards 不易取得的像素场景。

## 12. 最终判断

1. **单一主线**：把 BFM 的低维 task embedding 与 feature–reward 线性结构转成 reward-level online regression；以 confidence ellipsoid 上的 optimism 选择下一种行为，使 task inference 同时收集信息和控制 regret。线性 bandit 证明只覆盖 well-trained USF、线性奖励、exact oracle 和 episode-level switching，实验再展示 per-step、非平稳、错配与少标签扩展。
2. **正文保留的决策关键内容**：MDP/SF/embedding 关系、Eq.7–12 的 estimator/UCB、A1–A4、Prop.1 的 regret 量级、Algorithm 1、主 DMC 比较、active-data diagnostic、更新频率与变体结论。读者无需附录即可理解为什么 `ϕ` 做 regression、`ψ` 做 acquisition。
3. **移入附录的细节及损害**：完整 proof（A）、计算表、label-threshold、gradient optimizer、OGBench、错配／噪声、逐 task 图、FB training/architecture/protocol/hyperparameters（B–F）均后移。迁移保留了主线可扫读性，但让“minimal overhead”、逐任务异质性、真实复现条件和 theorem 的 determinant 细节不能从正文独立验证。
4. **最有效的写作／图／表／公式模式**：先用 Figure 1 把 offline point estimate 与 online belief pipeline 并置，再用 Eq.7–12 把 estimator→uncertainty→optimism 写成连续链；主结果按问题标题组织（compare、informative、updates、non-stationary、warm-start），附录逐任务复刻主图，形成可追溯的 evidence ladder。
5. **最明显的叙事规避／未闭合主张／读者成本**：摘要的 “minimal compute overhead” 没有数字，Table 1 直到附录才显示约 4.6×/3.6× policy latency；主图先聚合 relative performance，per-task absolute 曲线后移；理论最强的 per-step 版本没有 formal guarantee；pixel/复杂领域是动机和 future possibility，而非已测试能力。
6. **可迁移规则**：若方法依赖一个低维 latent 且观测可以直接更新其参数，应把“估计器、置信对象、采集准则、行为执行”写成一条公式、算法、实验链，并让每个理论更新边界有对应 ablation。
7. **适用边界**：该规则适合有可观测 feedback、可在线控制数据收集、latent 与 reward/utility 近似线性且 policy family 已预训练的 sequential decision 问题；若 observation label 昂贵到不能逐步取得、latent 高维无结构、或行为模型未近似最优，OpTI-BFM 的 confidence/UCB 链和 regret解释不能直接迁移。
