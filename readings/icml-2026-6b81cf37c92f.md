## Introduction 的推进链

1. **context**：reasoning models 依赖 inference-time compute；RLVR 在小模型上面对 cold start。[PDF p. 1，§1，explicit，锚点 `RLVR encounters a cold start problem`]
2. **context／method_preview**：on-policy distillation 提供 teacher 的 dense token-level supervision，并以 student rollout 缩小 training–inference gap。[PDF p. 1，§1，explicit，锚点 `dense, token-level supervision`]
3. **problem**：VLM 中的 on-policy distillation 尚少，Qwen3-VL 的 cited 例子限于 text-only backbone distillation。[PDF p. 1–2，§1，explicit，锚点 `neglecting visual grounding alignment`]

## 方法与理论：逻辑单元、公式和衔接

### 因果链

1. 在自回归轨迹 `τ=(h1,...,hT,ŷ)` 上定义 teacher–student token distribution 的 Forward KL 与 Reverse KL；OPD 采用 `τ∼pθS` 的 Reverse KL。[PDF p. 2–3，§2.1，explicit，锚点 `trajectory-wise Reverse KL`]
2. 将含 image 的 monolithic loss 写为 `LStandard`，指出它把视觉和语言信号视作统一目标。[PDF p. 3，§2.2，explicit，锚点 `obscuring the distinct contributions`]
3. 通过 Bayes rule 把 sequence likelihood 分成 `language prior + visual likelihood − evidence`；以 teacher visual information gain 构造 `q*T`，从而可计算 `LVis`。[PDF p. 3–4，§3.1，explicit，锚点 `constructing a visual target distribution`]
4. 用 teacher 的 multimodal/unimodal KL 定义 Visual Dependency Score（VDS），按 token 的十个等频分位观察 `∇LLang` 与 `∇LVis` 的夹角；高 VDS 时由约 60° 扩大到约 92°。[PDF p. 4，§3.2，explicit，锚点 `10 equal-frequency quantiles`]
5. 将 `γLVis` 加进 `LStandard`，用 `ηVGS(γ)` 使 steered gradient 的 norm 与标准梯度相同；作者称此举只改变更新方向。[PDF p. 5，§4，explicit，锚点 `changes only the direction`]
6. 在 top 30% VDS tokens 上加 `LLP`，避免 high-conflict regime 的视觉更新损失语言先验。[PDF p. 5–6，§4，explicit，锚点 `top 30% of tokens`]

段落动作序列为：`setup_notation → contrast_alternative → state_problem → derive → define_component → explain_mechanism → connect_to_prediction → instantiate_algorithm → explain_mechanism → define_component → connect_to_experiment`。方法图 Figure 2 给出数据流、`q*T` 构造和三梯度几何图；Figure 3 负责诊断前提；Figure 4 负责 LP 的必要性。[PDF p. 2，Figure 2，explicit，锚点 `Visual Target Construction`] [PDF p. 4，Figure 3，explicit，锚点 `Geometric Analysis`] [PDF p. 5，Figure 4，explicit，锚点 `Language Preservation`]

### 主要结果与可替代解释

1. **几何诊断**：VDS 由低到高时，`∇LLang` 与 `∇LVis` 的夹角从约 60° 到约 92°；bin 9 的 `∇LStandard` 仍距 visual gradient 约 42°。Figure 3 支持作者的局部 token-level 诊断，但 validation prompt 的数量和重采样设计未给出，不能从图中推出跨数据集稳定的普遍几何规律。[PDF p. 4，§3.2／Figure 3，explicit，锚点 `θ ≈ 92°`] [PDF p. 4，§3.2，explicit，锚点 `≈ 42° from ∇LVis`]
2. **纯 OPD 主结果**：2B 的跨 benchmark Acc@1 为 46.10，对比 standard 的 43.74，差值 +2.37；4B 为 58.12 对比 56.64，差值 +1.56。2B 的 VisualPuzzles +3.68，4B 的 VisualPuzzles Acc@1 却为 −0.44；后者限制了「所有单项均改善」的读法。[PDF p. 6，Table 1，explicit，锚点 `Average ... +2.37`] [PDF p. 6，Table 1，layout，锚点 `VisualPuzzles ... -0.44`]
3. **stochastic sampling**：Table 1 的跨 benchmark Acc@16 改善是 2B +1.07、4B +0.50；指标是 16 generation average，表中没有 generation-level dispersion。[PDF p. 6，Table 1，layout，锚点 `+1.07`]
4. **inverse steering**：Figure 5 显示 visual steering 的 bars 位于 standard baseline 之上，而 language steering bars 在其下；这是与 asymmetric maturity 一致的反事实比较，图中未标注具体数值或 uncertainty。[PDF p. 7，§7／Figure 5，explicit，锚点 `accuracy dropping below the baseline`]
5. **RL + OPD**。Table 2 的 2B 平均 Acc@1 为 47.20，对比 GRPO + Standard-KD 的 45.41，+1.79；Acc@16 是 46.57 对比 45.22，+1.35。两个单项 Acc@1 差值为负，MathVerse-VO −0.23、VlmsAreBlind −0.16。[PDF p. 8，Table 2，layout，锚点 `Average ... +1.79`] [PDF p. 8，Table 2，layout，锚点 `-0.23`]

## 消融、负面结果与自我设限

- **组件删除／机制**：Figure 4 比较 standard、`LVGS(γ=1)`、`LVGS(γ=2)` 和 `LVGS-LP`。作者将没有 LP 的高 `γ` 的 `LLang` 上升解释为 unlearning，LP curve 较低；该证据是 loss dynamics，非独立 text-only benchmark。[PDF p. 5，Figure 4，explicit，锚点 `causes the language prior to diverge`]
- **反向机制替代**：Language Steering 是对 `Asymmetric Maturity Hypothesis` 的刻意反向操作。[PDF p. 7，§7，explicit，锚点 `inverse steering experiment`]
- **扩展性**：RL + OPD 表与训练曲线检查 VGS 是否可用作 GRPO regularizer。[PDF p. 8，§8，explicit，锚点 `GRPO + VGS (Ours)`]
- **超参数／规模**：Appendix B.3 对 `γ` 和 `λ`；Appendix E 对 token-level `γt`；Appendix D 对 high/low visual dependency 和 text-only；这些都在正文后部。[PDF p. 15–17，Appendix B–E，explicit，锚点 `Sensitivity Analysis`]

## 最终判断

1. **单一主线**：作者把 VLM on-policy distillation 的 monolithic Reverse-KL loss 分解为 language prior 与 visual grounding，利用高 VDS token 上的近正交梯度主张标准更新会走 compromise trajectory，再以 VGS + LP 将更新方向偏向视觉。[PDF p. 3–6，§3–4，explicit，锚点 `prioritize the visual subspace`]
2. **正文保留的决策内容**：主文保留 decomposition、Eq. 1–22、Figure 2–6、Table 1–2、两个 student scale 和 RL extension，因此读者可判断其机制、平均 benchmark 效果与已展示的反例条件。[PDF p. 2–9，layout，锚点 `Figure 2` 至 `Table 2`]
3. **移入附录的细节**：可复现配置、prompt、sensitivity、cost、visual-dependency scope、adaptive VGS、qualitative cards、显式 limitations 都在第 13 页以后；这不破坏「VGS 的定义 + Table 1」的主文可读性，但成本、scope 与限制的判断需跨入 appendix。[PDF p. 13–18，Appendix A–G，layout，锚点 `Implementation Details`]
4. **最有效的呈现模式**：Figure 2 的「rollout → target logits → gradient steering」三段流程，与 Figure 3 的分位角度诊断、Figure 4 的 loss-dynamics 后果、Table 1 的跨 benchmark 效果，形成清晰的机制、干预和结果链。[PDF p. 2、4–6，Figures 2–4／Table 1，interpretation，锚点 `Visual Gradient Steering`]
5. **最大读者成本**：强主张依赖 benchmark averages 和 selected qualitative cards，但 seeds、重复训练、benchmark denominator、Figure 3 的 STD 单位、confidence intervals 与 selection protocol 缺失；此外 G 限制置于 appendix，读者须追读才能看到 teacher-calibration failure boundary。[PDF p. 4、6–8、18，Figure 3／Tables 1–2／Appendix G，layout，锚点 `Mean ± 0.5 STD`]
6. **可迁移规则**：当论文把一个联合目标拆成可解释子目标时，正文应依次展示分解、可观测诊断、目标方向的干预，以及与干预一致的结果和反向对照。
