## 相关工作如何定位

- §2 是独立章节，约 650 词，占主文可读文字约 8%。四个引用簇依次为 strategic learning、private information 的变体、fairness/welfare、single-parameter auction design。证据见PDF p. 2, §2，`Our work relates to`。
- 第一簇为 `taxonomy + nearest_neighbor_contrast + limitation_of_prior`：战略分类通常处理可操纵 features 或 labels，本文处理 private values，并由 mechanism 约束 overreporting。证据见p. 2, §2，`none of these consider user values as private`。

## 最终判断

1. **单一主线**：把分类准确性当作稀缺 allocation，把私有受益值通过 truthful accuracy auction 变成 example weights，再用 algorithmic stability 解释为何这一福利目标只让少数训练者支付。证据见PDF pp. 3–6，`accuracy itself ... limited resource`、`algorithmic stability`。
2. **正文保留的决策内容**：正文保留了 setup、Eq. (1)–(10)、monotonicity/DSIC、两种 asymptotic payment 结论、Algorithm 1、Table 1、Figures 1–3、Discussion 和 Impact；这些足以判断核心 mechanism 与主要实证图形。证据见PDF pp. 3–10，§§3–8。
3. **迁入附录的细节与自足性**：证明、full data/model/preprocessing、randomized algorithms、loss sensitivity、valuation variance 与 k-NN supplemental evidence 位于 A–D。迁移没有使主线不可读，但 Theorem 2/3 的完整条件、实验可复现性和 robustness 判断无法只靠正文闭合。证据见PDF pp. 5–9，`Proof in Appendix`、`Full experimental details`；pp. 13–29。
4. **最有效模式**：Figure 1 将 mechanism 一次画成 bids→classifier allocation→payments；Figure 2 接着把 constant-payer theorem 转成两个容易读的几何/统计曲线；Figure 3 再把 welfare tradeoff 接到半合成社会数据。证据见PDF pp. 3, 8–9，Figure 1–3。
5. **最明显的未闭合处或读者成本**：private bids、human rationality、payment feasibility、群体分布后果均未做 deployment/human study；feature-based value 的 WKHP 是否从 model input 排除存在文内冲突；多数 curves 缺少每图 trial count 与不确定性显示。证据见PDF p. 10, `real users are rarely fully rational`; p. 26, `WKHP` 与 `not included in features x`。
6. **可迁移规则**：当论文的理论主张依赖严格条件时，正文先给 mechanism、关键 theorem statement、能对应条件的主图和清楚的 deployment boundary，再把推导和 parameter sweeps 迁到可定位附录。该论文的 p. 4–10 与 A–D 是这一分层的实例。证据见PDF pp. 4–10, 13–29。
7. **规则边界**：如果完整条件、数据构造或关键统计读数决定读者是否接受主张，附录调用必须在正文给出足够具体的条件摘要。这里 Theorem 2 的 fixed-`λ` 条件和 feature-value implementation 的 WKHP 冲突使读者仍需进入附录。证据见PDF p. 19, `fixed regularization parameter`; p. 26, `WKHP`。
