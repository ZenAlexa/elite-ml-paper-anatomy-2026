## 0. 单一主线与先行判断

论文的单一因果主线是：MDLM 训练用均匀随机的 masking/unmasking 路径，而推理为了质量会使用 greedy、P2 等 planner；不完美 denoiser 使路径顺序影响样本分布，因此 vanilla ELBO 与实际 reverse dynamics 脱节。作者用离散时间 Markov chain（并以 CTMC 复证）把采样路径写成 path-wise KL，证明非均匀 planner 下标准 ELBO 可能失去下界性质（Proposition 3.1，p.5，proof p.23–24），再把 planner 直接放进参考链和目标链，得到包含 planner-weighted cross-entropy 与 planner correction 的 P-ELBO（Proposition 3.2，p.6；Eq. (4)–(5)、p.20–21）。

PAPL 是从该 bound 到可训练算法的近似链。它用 denoiser confidence 的 softmax 作为 self-planner，detach planner gradients 以去掉难算的 correction term，仍从 vanilla masking 分布抽取 `x_k`，最后用 `1/(L-k)(1+αw^i)` 与 vanilla loss 插值（Eq. (7)，p.7；Appendix A.2.3，p.27–28）。三域结果支持「在实际 P2 inference path 上训练」这一工程主张：protein foldability、text MAUVE/Gen PPL、code completion/infill 均相对同规模 DLM 上升；理论上可保证的是给定 planner 的 ELBO/path-KL 关系，不能从这些结果直接升级为所有 planner、任务或模型规模下的收益保证。

## 5. 方法与理论

### 5.1 形式对象与最小逻辑单元

- 有限 vocabulary `V={1,…,d}`，最后符号 `m` 是 mask；序列 `x∈V^L`，训练分布 `p_data` 支持在 `D⊂V^L`（p.2–3）。
- denoiser `D_θ:V^L→(Δ^d)^L` 输出每个位置的 clean-token 分布；vanilla Gillespie sampler 从 `[m]^L` 开始，每步均匀选 masked coordinate，再采样 token（p.3）。
- planner `G_ϕ:V^L×V^L→Δ^L` 读取 denoiser sample `z` 与当前状态 `x`，选择下一个坐标；`F_{θ,ϕ}` 是对 `z` 边缘化后的 planner 选择概率（Eq. (4)–(5)，p.5）。
- 参考链 `Y^{x_0}` 以 clean target `x_0` 监督，目标链 `X^{θ,ϕ}` 由 denoiser 与 planner 产生；二者初始均为全 mask，参考链在终点命中 `x_0`（p.4、p.20–21）。
- vanilla objective 是 uniform path 的 ELBO；P-ELBO 的 `E_1` 是 planner-weighted cross-entropy，`E_2` 是 ideal planner 与 effective planner 的负 KL/correction（p.6）。

**方法动作转移**：`setup_notation → state_problem → derive(path-wise KL) → define_component(planner/F) → state_failure(greedy) → derive(P-ELBO) → give_intuition(E1/E2) → instantiate_algorithm(soft planner) → stabilize(detach/random mask/interpolate) → connect_to_experiment`。CTMC 附录重走 `setup_rate → derive(Girsanov) → prove_time_independence`；P2 支线重走 `define_subset_planner → derive_remasking_transition → derive_ELBO → expose_computational_boundary`。

### 5.2 机制与理论边界

1. **失配对象**：vanilla chain 的 transition uniform 选 masked position；planner chain 的 coordinate probability 依赖 `z`。当 denoiser imperfect 时，不同 denoising orders 的 token likelihood 不一致，故 inference distribution 不能继续由 uniform ELBO 直接下界（p.5，Proposition 3.1）。
2. **P-ELBO**：对任意 planner，目标链和监督参考链的 path KL 给出 `log p^{G_ϕ}_θ(x_0)≥E_1+E_2`。`E_2` 在 planner 不依赖 `z` 的 uniform 情形消失；它在 planner 需要 clean target 或 denoiser-conditioned choice 时承载 correction（p.6、p.20–22）。
3. **PAPL 近似**：exact greedy ELBO 需每个 `k` 模拟路径并多次 denoiser evaluation；softmax planner 使权重连续，但 full correction 仍复杂。detach logits 后只保留 weighted CE；再用随机 vanilla mask 采样 `x_k`，以 `α` 与 vanilla loss 插值。该过程使 Eq. (7) 可一 forward pass 实现，但它是 surrogate，不等同于 exact P-ELBO（p.6–7、p.27–28）。
4. **planner family**：uniform planner 恢复 Eq. (1)；greedy planner 给 deterministic-path ELBO（Corollary A.9）；soft greedy 给 corrected ELBO（Corollary A.10）；P2-TopK 可有 path ELBO，但正则化为 full-support 后需枚举大量 subset，实践中只把 PAPL 看作更接近采样路径的近似（p.25–29、p.34–38）。
5. **CTMC 复证**：Appendix A.3 以 coordinate-wise corruption、reverse rate 和 Girsanov path KL 复导 Prop.3.2，并由 beta-function 计算证明 ELBO 与 time schedule `α_t` 无关（p.29–34）。这是证明视角的独立核对，不是新的实验预测。

### 6.2 统计与可视化口径

- **Protein**：对 100 条序列及长度集合计算 pLDDT、pTM、pAE、token entropy、sequence diversity；foldability 是满足三个阈值的序列百分比。附录定义 pLDDT 为 residue-level local confidence，pTM 为 global similarity，pAE 为 alignment error；entropy 使用生成集合中的 amino-acid empirical frequency，diversity 为 pairwise identity 的 `1−average`（p.38–39）。文中报告点值，没有 seed-level dispersion 或区间。
- **Text**：每个 `T` 的 MAUVE、Gen PPL、entropy 是生成分布的聚合值；MAUVE 比较 generated/held-out reference embedding distributions，Gen PPL 由 pretrained LM 评估，且作者主动指出 Gen PPL 可被过度自信 sampling “gamed”（p.40）。因此作者把 MAUVE 作为较稳健指标，但仍未给重复采样误差。
- **Code**：pass@1/pass@10 与 exact match 按 official protocols；主表同时放大模型 reference 与 ≤1B compact models。没有显著性检验、任务级 bootstrap 或每题分布，附录 C.4 只对 40 个 HumanEval 任务给定性案例。

## 13. 最终判断

1. **单一主线**：用 path-wise KL 让 reverse dynamics 的 planner 进入 ELBO；Prop.3.1 先证 uniform objective 对 greedy inference 的失配，Prop.3.2 再给任意 planner 的 P-ELBO，最后以 soft self-planning 与稳定化得到 PAPL Eq. (7)，三域结果承担质量与路径对齐的经验检验。
2. **正文保留的决策关键内容**：核心变量、Eq. (1)/(4)–(7)、两项 P-ELBO 含义、Algorithm 1、三域 setup/主表、Fig.3–4 和结论中的 compute boundary。读者可在十页正文内判断方法是否值得复现。
3. **移入附录的细节及自足性影响**：KL/Markov/CTMC proofs、P2 remasking、所有 implementation hyperparameters、planner sampling ablations、近似 loss 数值和 code failures 被移入 p.17–46；正文对主结果方向自足，对 exact guarantee、近似忠实度、稳定性和适用边界则需要附录。
4. **最有效的写作/图/表/公式模式**：Fig.1 先用可视路径把 uniform 与 planner loss 的差异实体化；Prop.3.1 的最小 `L=2` 反例把「ELBO 失效」变成可证伪对象；Eq. (7) 将理论映射为一行加权 CE；Table 7 逐项展示从 exact bound 到 surrogate 的数值变化。
5. **最大缺口与读者成本**：PAPL 实际是多步近似，pure PAPL instability 与 P2 full-support 不可行削弱“wide applicability/no overhead”的宽表述；缺少 seed、误差和任务级分析，Table 3 的 oracle length 行也让 code gain 的因果归因需要额外核对。
6. **可迁移规则**：当 inference 使用非训练分布的路径选择器时，先把选择器写进生成 transition，再将 bound 中不可计算项逐步标成 surrogate、稳定化和残余误差；每一步都配一个最小反例或 approximation ablation。
7. **适用边界**：该规则适用于离散/连续状态转移能写成 Markov path、目标路径可定义且 planner 选择概率可评估的生成模型；当 planner 有大规模 subset/remasking、不可微 external state 或无法采样 reference path 时，只能保留诊断框架，不能直接承诺可训练 P-ELBO 或同等效果。
