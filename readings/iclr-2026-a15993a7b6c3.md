## 4. 相关工作

相关工作是独立的 §5，位于结果之后、结论之前（p.8–9），约 632 词，占正文估计约 11.8%。它按问题／方法分三簇，并在每簇尾部定位本方法：

1. **Zero-shot TTS 方法谱系（`taxonomy`、`nearest_neighbor_contrast`）**：multi-stage 先预测 semantic/coarse representation，再用 non-autoregressive 或 diffusion 生成 acoustic feature；one-stage 直接生成 discrete code、Mel 或 continuous VAE latent。作者的差异是把目标从 individual utterances 推到 multi-party dialogue 和 podcast。【p.8 §5；“multi-stage and one-stage methods”】
2. **Podcast generation 缺口（`limitation_of_prior`、`gap_creation`）**：NotebookLM 没有学术论文／技术报告且只有两个固定 speaker；SpeechSSM 可到 16 分钟但单说话人；MoonCast、FireredTTS、Higgs Audio V2、Moss-TTSD、DSM-TTS 被列为近期进展，缺口被收束为 generation length、speaker count、stability。【p.9 §5；“generation length, number of speakers and generation stability”】
3. **Speech tokenizer 进展（`chronology`、`credit_or_foundation`、`nearest_neighbor_contrast`）**：从 VQ-VAE、SoundStream、Encodec 到 discriminator、compression、frame-rate 和 semantic latent；本方法继承这些方向，同时强调 7.5 Hz 和 acoustic/semantic decoupling。【p.9 §5；“explicitly decouples the acoustic and semantic tokenization pathways”】

引用承担的是方法谱系、基线身份和工具归属；§5 没有逐一比较训练数据、参数量或测试协议，也没有在后续章节再次把某个引用作为因果证据。它避免了复述公式，但对 MoonCast 等近邻工作的具体限制主要是页内一句话概括。

## 5. 方法、机制与公式核对

### 5.1 表示、输入与生成链

- **Acoustic Tokenizer**：以 VAE、尤其是 LatentLM 的 σ-VAE 为基础；encoder `Encoder_ϕ(x)` 产出均值 `μ`，固定方差来自 `N(0,Cσ)`，通过 reparameterization 得到连续 latent `z=μ+σ⊙ε`，再由 `Decoder_ψ(z)` 重构 `x̂`。固定 σ 被作者用来缓解 autoregressive modeling 下的 variance collapse；它不是离散 codebook。【p.3 §2.1；“variance σ is a pre-defined distribution”】
- **Semantic Tokenizer**：复用 hierarchical encoder 结构但去除 VAE 组件；以 ASR 为 proxy task，通过若干 Transformer decoder layers 预测 transcript。预训练后丢弃 decoder，仅保留 content-centric encoder。【p.3 §2.1；“without VAE components”】
- **Voice prompt 与 script**：每个 speaker `k` 的 prompt waveform `v_k` 只走 acoustic encoder，得到 `Z_{a,k}`；script turns `W_k` tokenized 为 subword，再映射为 `E_k`。script 不包含 prompt 的 transcript。Prompt Sequence `X` 先拼 acoustic prompt features，再拼各 speaker 的 script embeddings 与 `<S>`，speaker identifiers 插在对应段前；acoustic features 经 projection 对齐 `d_llm`。【p.3 §2.2.1】
- **Hybrid speech representation**：LLM 在第 `i+1` 步预测 acoustic VAE `z_{a,i+1}`，Acoustic Decoder 还原 waveform `y_{i+1}`；随后以 `z_{p,i}=W_a z_{a,i}+W_s SemanticEnc(y_i)` 融合 acoustic 与 semantic。每个 segment 仅依赖历史 context，最终 `Y=concat(y_0,…,y_I)`，因此架构天然支持 streaming。【p.3–4 §2.2.2】
- **Diffusion Head**：LLM hidden state `h_i` 条件化轻量 noise-prediction network，仅生成 acoustic VAE，不直接扩散 semantic feature；LLM 同时判断当前 segment 是否结束并发出 `<E>`。训练用 forward Gaussian corruption 与 L2 noise loss；推理用 CFG，unconditional context 取 `<S>`，再用 DPM-Solver++ 加速。【p.4 §2.2.3】
- **数据处理**：Silero VAD 将长音频切成最多 30 秒片段；Whisper-large-v3-turbo 给 punctuation 与 word-level timestamp，并在 `.?!` 结束处再切分。WeSpeaker 的 vblinkp／voxblink 模型做 speaker embedding，1.5 s window、0.75 s hop，HDBSCAN 聚类，centroid cosine similarity >0.67 的 clusters 合并。二次 ASR WER >20% 则 segment 不可靠，文件中不可靠 segment 超过 30% 即丢弃；speech duration <60% 或 speaker>4 也丢弃。作者明确不做 speech enhancement，因为它可能损坏 interjection 和 prosodic cues。【p.4–5 §2.3；p.14–15 Appendix A】

### 5.2 六个编号公式

PDF 中共有 6 个编号公式，均在 p.4，形成“LLM 生成 acoustic latent → waveform／hybrid state → diffusion 训练 → CFG 推理”的一条 core chain。另有 p.3 的无编号 σ-VAE 三行公式；没有 theorem、lemma、proposition、corollary 或证明。

|编号|公式功能|变量／结论|在因果链中的角色|证据|
|---:|---|---|---|---|
|(1)|Next-token acoustic prediction|`z_{a,i+1}=VibeVoice(X,z_{p,0},…,z_{p,i})`。|把长历史 context 变成下一 acoustic VAE segment。|p.4 §2.2.2；“the generated speech segment is predicted as”。|
|(2)|Acoustic decoding|`y_{i+1}=AcousticDec(z_{a,i+1})`。|把连续 acoustic latent 还原为 waveform。|p.4 §2.2.2。|

## 6. 实验设计

### 6.1 训练与实现

- Acoustic encoder/decoder 为 mirror-symmetric、7 stages 的 modified Transformer blocks，以 1D depth-wise causal convolution 取代 self-attention；六个 downsampling layers 给出 3200× compression，从 24 kHz 得到 7.5 frames/s；每个 encoder/decoder 约 340M 参数。训练目标沿用 DAC discriminator/loss。【p.5 §3.1】
- Semantic encoder 结构镜像 acoustic encoder，以 ASR cross-entropy 训练，decoder 训练后丢弃。【p.5 §3.1】
- VibeVoice LLM 使用 Qwen2.5 1.5B 与 7B；Diffusion Head 4 layers，1.5B 版本约 123M 参数。Acoustic/Semantic tokenizers 冻结，只训练 LLM 与 head。【p.5 §3.2】
- LLM sequence-length curriculum 为 4,096（前 40k steps）、16,384（40k–80k）、32,768（80k–100k）、65,536（100k–110k）；7B 因资源限制省略最后阶段。主模型使用约 80B internal pseudo-labeled podcast tokens；1.5B 训练约 170 小时、64 AMD Instinct MI300X、nnscaler。推理 CFG=1.3、denoising steps=10。【p.5 §3.2】
- Appendix F 给出部分 hyperparameters：Tokenizer 300k steps、Acoustic VAE dim=64、`Cσ=0.5`、batch 160s、sample 4s；VibeVoice 110k steps、batch 4M、LR `1×10⁻⁴`、cosine schedule、warmup 500、weight decay 0.1、gradient clip 2、Diffusion Head train steps 1000、loss weight 5。【p.18 Table 9】

### 6.2 评测对象与协议

- **VibeVoice-Eval objective**：108 podcast samples，1–30 分钟，来自与训练集不同的 podcast sources；按 1/2/3/4 speakers 分层。正文使用 WER-W（Whisper）、WER-N（Nemo）与 SIM-O。为计算 SIM-O，diarization 使用 ground-truth speaker count 作为 cluster centers，再按 prompt speaker embedding 的最大相似度映射标签。【p.5–6 §3.3.1；p.18–19 Appendix G】
- **主观评测**：8 个由 LLM 生成的两说话人 dialogue texts，科技、艺术、旅行主题，3–15 分钟，平均约 7.3 分钟；24 位 annotators 对 Realism、Richness、Preference 做 5-point MOS。六个有主观分数的模型覆盖全部 8 样本；每位 annotator 约听 6 小时（约 2,160 个 10 秒 utterances）。rubric 在 Appendix H。【p.6 §3.3.1】
- **Tokenizer reconstruction**：LibriTTS test-clean/test-other 与 LibriSpeech test-clean；指标是 PESQ、STOI、UTMOS。论文只说明指标方向和数据集，没有给 seed、训练／评测随机性、置信区间、假设检验或 preregistered decision rule。【p.6 §3.3.2；p.8 Table 3】

实验顺序大体跟随引言：先主观／客观 podcast 质量，再 tokenizer、model scale、CFG／steps、重构质量和推理效率。它能回答“是否能生成”的范围问题，但没有直接测量 turn-taking latency、gradient stability、speaker-turn error、non-lexical-cue recall 或 90 分钟长程失真。

## 8. 消融、负面结果与自我设限

### 8.1 消融对象

1. **Tokenizer 配置**（正文 p.7–8，Appendix B p.14–16）：Acoustic-only、Hybrid；附录增加 Coupled。识别目标是 semantic guidance 与 acoustic fidelity 的权衡。Acoustic-only 在多说话人下 WER spikes，Hybrid 把 overall WER 从 6.22 降至 1.84，但 SIM-O 从 .68 降至 .64。【p.7 Table 2；p.16 Table 5】
2. **Model scale**（正文 p.7）：1.5B→7B，识别规模对主观、WER、SIM-O 的联合影响；没有等 compute 或 sequence-length control。【p.7 §4.2】
3. **CFG 与 DDPM steps**（正文 p.7–8）：Figure 3 的 3×4 heatmaps；识别条件强度、denoising 预算与 WER／SIM-O 的指标冲突。【p.8 Figure 3】
4. **Coupled Tokenizer**（Appendix B）：共享 encoder latent 同时服务 Acoustic Decoder 与 Semantic Decoder；Table 5/7 显示它把整体 WER 从 6.22 降至 3.55，却把 SIM-O 降至 .45，PESQ/STOI/UTMOS 也低于 Acoustic variant。【p.15–17 Figure 4、Tables 5、7】

### 8.2 负面结果与限制

- **主张范围超出评测范围**：摘要／结论写 up to 90 minutes；Table 2 和 Appendix G 只覆盖 1–30 分钟，正文 §4.1 也写“durations up to 30 minutes”。这是最明显的未闭合能力边界。【p.1 Abstract；p.7 §4.1；p.19 Table 10】

## 12. 最终判断

**单一主线。** VibeVoice 将 podcast TTS 的瓶颈定义为长时程、多说话人上下文与高保真声学生成的共同问题；它以 7.5 Hz 的连续 acoustic σ-VAE、ASR 语义 encoder、hybrid history state 和 LLM-conditioned next-token diffusion 组成 streaming segment generator，再用 podcast 伪标注管线提供 turn-taking 学习信号。主结果支持 1–4 speakers、1–30 分钟和若干指标上的优势；90 分钟是未被主实验闭合的扩展能力主张。【p.1–8；p.18–19】

**正文保留的决策关键内容。** 正文保留了问题动机、Figure 1、tokenizer／LLM／diffusion 的机制、六个编号公式、训练规模、评测协议摘要、Table 1–3、Figure 3、STOI 的不利解释和主要能力包装。读者可以理解“表示→LLM→diffusion→waveform”的链条，但不能仅凭正文重建数据过滤阈值、评测分母、推理成本或 Coupled 反事实。

**附录迁移及其代价。** 附录把最能区分机制的 Coupled tokenizer、SEED/LibriSpeech、RTF profile、完整 hyperparameters、108 段分布、rubric、第一阶段人评和频谱分析后置。迁移没有破坏方法的基本可读性，却使 Hybrid 的因果解释、SIM-O 反例和“实时／泛化”边界依赖跨页查找；90 分钟证据并未因附录而出现。

**最有效的模式。** Figure 1 先给出端到端流程；公式 (1)–(3) 用最少符号把 next segment、decoder 和 hybrid state 串起来；公式 (4)–(6) 再把 diffusion training／CFG inference 接上；Table 2 同时按 duration、speaker count、sequence length 展示可扩展性，Figure 3 用 WER／SIM-O heatmap 暴露速度与相似度的张力。这种“架构图→最小方程链→范围化主表→条件消融”的排列最适合算法型语音论文。

**最大缺口。** 最大缺口是 capability wording 与 evidence envelope 不一致：摘要／结论的 90 分钟、state-of-the-art 和 naturalness 包装，实际由最多 30 分钟的 objective set、8 个两说话人 subjective samples、单值 metrics 和非对称 baseline protocol 支撑。另一个关键 gap 是把 next-token diffusion、hybrid representation、turn-taking cues 和 SIM-O/environment 解释说成机制，却没有长程误差、turn-level metric、controlled acoustic intervention 或多次运行统计。

**可迁移规则。** 长篇生成论文应把能力声明拆成 `(speaker count, duration, stream protocol, metric)` 四维矩阵；每个正文 capability 数字必须在同一矩阵中有直接样本覆盖，并让主表保留一个机制对照，附录仅作补充。对“自然度／相似度”这类感知主张，应同时报告指标定义、聚合单位和一个能区分替代解释的反事实。

**适用边界。** 这条规则适用于多说话人语音、视频、长上下文 agent 等具有组合式 capability 的生成模型；当数据集无法覆盖全部 duration 或 speaker count 时，应把未覆盖轴写成 `partially_closed`，不得以架构支持上限替代实测范围。若研究问题本来只关心单一短 utterance，则不需要构造长程矩阵，但仍需明确 metric 与人类感知之间的边界。
