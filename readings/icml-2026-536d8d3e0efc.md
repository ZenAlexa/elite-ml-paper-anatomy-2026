### 算法粒度与复杂度信息

Algorithm 1 的输入包括 `{α_t}`、`{β_t}`、`ν_i`、`D_i`、`ε_i`、`τ_i`、`λ`、episodes `T` 与每次更新 samples `K`；循环先把 `π_i,p_i` 投影回各自 simplex，再收集 transition，形成 target，最后更新 `Q_i`。可见不变量是 policy 与 adversary policy 始终经 `Proj_Δ` 保持在 simplex。〔PDF p. 18, Algorithm 1；explicit〕

## 最终判断

1. **单一主线**：把风险厌恶和有限理性置入 agent objective，使 4-player representation 满足可验证的单调性；单调性给出 RQE 的规则性和 Bellman contraction，后者让 faster-actor/slower-critic 的 coupled Actor-Critic 可以获得收敛分析。〔PDF pp. 2–8〕
2. **正文保留的决策关键内容**：定义、两张理论机制图、主 theorem statement、coupled update、三类环境的主比较图和唯一 summary table。〔PDF pp. 3, 6–9〕
3. **迁入附录的内容**：所有完整 proof、网络/replay implementation、环境规则、超参数和逐 run 曲线。迁移不妨碍读者识别主张，却使 theorem 复核与复现实验依赖附录。〔PDF pp. 18–63〕
4. **最有效模式**：Figure 1 将抽象的 4-player 转写可视化，Figure 2 把新条件与前作条件画成同一参数平面，随后以 Figure 3 将 `τ` 的行为含义接到 Figures 4–7 的训练稳定性。图与因果链次序一致。〔PDF pp. 3, 6, 8–9〕
5. **最大缺口**：有限样本理论作用于具强假设的 tabular Algorithm 1；深度 Algorithm 2 的经验优势没有相应理论闭合。实证还缺少 matched component ablation、seed/hardware 记录和 formal significance analysis。〔PDF pp. 8, 18–25〕
6. **可迁移规则**：若一个 behavior-side regularizer 是论文的核心，需在正文把它连成「目标函数中的行为含义 → 可检验的结构性质 → 算法 update → 与该性质相符的观测」的连续链，并把每个保证明确写出前提。〔PDF pp. 2–8〕
7. **规则边界**：当改变 agent preference 不符合任务语义、不能验证 regularity assumptions，或实验改变了多个机制且没有 matched control 时，不能把这种链条写成对一般学习稳定性的无条件因果结论。〔PDF pp. 6–8, 19, 23〕
