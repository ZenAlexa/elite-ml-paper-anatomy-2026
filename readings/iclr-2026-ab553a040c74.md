## 6. 方法、理论对象、公式与算法

### 6.1 方法因果链

1. **架构前提**：考虑词表大小 `v` 远大于 hidden size `d`，且最后层是 normalization 后接 `R^d → R^v` linear/affine layer。【p.2 §2，`explicit`】
2. **球面来源**：RMSNorm 把表示缩放到球面；简化的无 `ε` norm 令 `||x̂||₂=1`。学习到的 `γ` 和 `β` 形成 `γ ⊙ x̂ + β`。【p.3 §2.1，`explicit`】
3. **椭圆映射**：`W(γ ⊙ x̂ + β)` 是球面的 affine image，落在嵌入到 `R^v` 的 `d` 维 ellipse；API 返回 logprobs，因此用 centering matrix `C` 消除 softmax 的 scalar-shift ambiguity。【p.3、p.13 Appendix A，`explicit`】
4. **验证量**：对 logprob `ℓ` 做 ellipse 的 inverse affine transform，检查变换后向量的 norm 是否偏离 1；该距离用于跨模型 attribution。【p.3–4 §2.2，`explicit`】
5. **攻击难度**：给定至少 `d` 个 token 的 logprobs，先提取 column space/上投影，再拟合 ellipse；一般 quadric 需要 `O(d²)` 样本，API token-prefix 与多次查询带来 `O(vd + d³ log d)` 总成本，ellipse fit 还需 `O(d⁶)` time。【p.5–8 §3，`explicit`】
6. **输出验证协议**：ellipse 是 secret key，logprob 向量同时携带 next-token message 和位置 tag；verification 只需检查向量在秘密 ellipse 上。【p.8–9 §4，`explicit`】

方法动作序列为 `setup_notation → state_problem → derive → define_component → explain_mechanism → connect_to_prediction → connect_to_experiment → contrast_alternative → instantiate_algorithm → state_complexity → connect_to_experiment`。【p.2–9，`interpretation`】

### 6.3 算法与参数恢复

**Algorithm 1，Get output layer parameters of a language model（p.6）**：输入 `ℓ₁,…,ℓₙ∈R^v`；拼出 `WH=[ℓ₁ … ℓₙ]`，用 `rank(CWH)` 找 `d`，以 `A=I_{1:d}` 作 down-projection；用前 `d` 个样本解 `A⁻`，把 centered outputs 投影到 `R^d` 后调用 `EllipsoidFit`；对 `Cholesky(E⁻¹)` 做 SVD 得 `U,Σ`，返回 `A⁻,Σ,U,b`。关键不变量是 down/up projection 恢复 centered output space，ellipse fit 返回 positive-definite ellipse；`Vᵀ` 因 ellipse 对右侧旋转不敏感而不返回。【p.6、p.14–15，`explicit`】

**Algorithm 2，Get output layer parameters of a language model with a layer norm（p.16）**：在 `d−1` 维 sphere 上先取 `Z=I_{1:d−1}`；以一条 biased-ellipse 点 `b₁=A Cℓ₁` 平移，解 up-projection `Y`，对 `Z(A Cℓ_i−b₁)` 拟合 `E,b₂`，再以 `b=b₁+Yb₂` 恢复 bias，返回 `A⁻,Y,Σ,U,b`。它只扩展 layer norm 的中心平面处理，没有新增 theorem。【p.16，`explicit`】

算法没有显式伪代码复杂度行；复杂度在 §3.2–3.3 prose 中给出。正文解释覆盖到每一行的数学目的，但 `EllipsoidFit` 的具体 SDP 实现被移到 Appendix F。【p.6、p.17，`explicit`】

### 6.4 参数可识别性与假设

- RMS-like norm 的 `ε` 被暂时忽略以获得单位球；真实 `ε` 让样本进入椭球内部，造成 scaling 的轻微低估。【p.3、p.6、p.17，`explicit`】
- `A` 是任意 full-rank `d×v` down-projection 的一种简单选择；实现取 identity 的前 `d` 行，需有足够 rank 才能解 generalized inverse。【p.14–15，`explicit`】
- `U` 的列方向有符号/旋转不唯一性，作者用「每列第一个非零元素为正」的任意约束选代表；`Vᵀ` 属于 ellipse-invariant gauge，无法由 ellipse 本身恢复。【p.15，`explicit`】
- Layer norm 先中心化再归一化，输出维度变为 `d−1`；bias 把 ellipse 从中心平面 lift 到 `R^d`，需 `Y` 上投影。【p.15–16，`explicit`】

## 10. Forgery、协议和攻击面

Forgery 在 Section 3 中被形式化为：给定一组通过 black-box verifier `f` 的 outputs，生成一个新的 `x̂` 使 `f(x̂)=1`；ellipse verifier 的通过条件是点位于 model ellipse。linear signature 的线性约束可从 API 抽取并满足，ellipse 则被作者限定为「现有已知方法下很难」。【p.5，`explicit`】

协议在 Figure 7 中分两层。标准 MAC 使用 shared secret key 生成 tag；ellipse 方案以 model ellipse 为 secret key，以 logprob vector 为 message，tag 隐含在 `R^v` 中的位置，Bob 只需检查是否在秘密 ellipse 上。模型训练通常决定 ellipse，也可以随机采样 ellipse；签名动作发生在模型产生 logprobs 时。【p.8–9，`explicit`】

论文主动暴露两类攻击边界。第一，攻击者可以收集 outputs、拟合 ellipse，再生成新 logprobs；成本在生产规模上被认为不可行，但作者没有给出 cryptographic security reduction。第二，攻击者可保存真实 logprob vectors，按 top-token `arg max_i ℓ_j^(i)=g_j` 拼接成看似合理的 token sequence；候选防御是 provider output database，或用 language-model inverter 检查前后半段 prefix likelihood。后者是启发式 tamper signal，并非协议证明。【p.9，`explicit`】

## 15. 最终判断

1. **单一主线**：论文把 final normalization 后的 hidden states 视为 sphere，经 learned affine/unembedding map 成为模型特有的 high-dimensional ellipse；API logprobs 的 centered 版本保留该几何约束，于是可以用 ellipse distance 做来源识别，并把「拟合 ellipse 才能伪造」的样本与计算成本转成 forgery resistance 和 MAC-like verification。
2. **正文保留的决策内容**：正文保留架构假设、RMSNorm→ellipse 推导、verification distance、跨模型 Figure 3、smoothing Figure 4–5、sample-cost Table 1、fit-time Figure 6、MAC Figure 7 和三项 Discussion limitations。这些对象直接决定「可识别但难伪造」的因果链。
3. **迁移到附录的内容**：centering identity、recoverable reparameterization、Eq. (5)–(11) proof、layer-norm Algorithm 2、solver implementation、norm histograms 和 post-processing analysis。迁移保持正文叙事自足，但要核对 logprob 等价性、`Vᵀ` 不可识别性、`ε` 误差和 layer-norm 边界时，正文无法独立完成审计。
4. **最有效的模式**：Figure 2 的 sphere→ellipse 图和 Figure 7 的 MAC 对照分别降低几何与协议门槛；Algorithm 1 把抽取步骤、参数含义和复杂度连接在一个短对象中；Table 1 将抽象 `d²/d³` 增长翻译为可比较的 samples、美元和年份。
5. **最大叙事缺口**：`forgery-resistant` 的核心结论依赖「当前已知方法必须先 fit ellipse」这一知识边界，且 production 结论主要依赖小维度测量、degree-6 外推与若干 hypothetical pricing；协议还只验证单个 logprob vector，拼接攻击没有 formal defense。读者需要同时追正文、脚注和 appendix 才能区分 theorem-like geometry、empirical efficacy 与 conjectural hardness。
6. **可迁移规则**：当把自然约束包装成安全/验证能力时，应在主文同一条论证链中并列「约束的可验证性」「攻击者可获得的样本与计算成本」「未知攻击和 replay 的边界」，并把每个外推数值标成 measured、estimated 或 hypothetical。
7. **适用边界**：该规则适合有黑盒攻击面、几何/系统约束和安全语义的 ML 论文；若方法有 cryptographic reduction 或真实 deployment，成本外推不能替代相应的 security game、阈值校准和端到端实验。
