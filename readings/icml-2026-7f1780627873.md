## E. 方法与理论

### E.1 最小逻辑单元与推进序列

1. **`setup_notation`（p. 3, §2.1）**：定义 clean sequence `x_0`、masked state `x_t`、masking ratio `t` 和 token index `k`；inference 从全 `[MASK]` 开始。依据 “generate sequences by iteratively denoising a masked state” `[explicit]`。
2. **`derive`（p. 3, Eq. (1)）**：给出独立 masking 的 forward process。依据 “forward process independently masks each token with probability `t`” `[explicit]`。
3. **`derive`（p. 3, Eq. (2)）**：把 MDM 的 Negative Evidence Lower Bound 写成 masked-token weighted cross-entropy。依据 “reduces to a weighted cross entropy loss over masked tokens” `[explicit]`。
4. **`setup_notation`（p. 3, §2.2）**：定义 GRPO 对每个 query 采样 `G` 个输出、用 group mean/std 标准化 reward，避免 value function。依据 “avoids value function estimation by using group level reward normalization” `[explicit]`。
5. **`derive`（p. 3, Eq. (3)）**：给出 clipped surrogate、token-level ratio 和 KL regularization。依据 “clipped surrogate function with a KL regularization term” `[explicit]`。
6. **`setup_notation` + `connect_to_prediction`（p. 4, §2.3）**：把 Pass@k 定义为 k 个独立样本中至少一个正确解的概率，并解释为 RL 可访问 solution space 的 proxy。依据 “probability that at least one correct solution is generated within k independent samples” `[explicit]`。
7. **`derive`（p. 4, Eq. (4)）**：用 unbiased estimator 写出 `n` 个样本、`c` 个正确解时的 Pass@k。依据 “following the unbiased estimator formulation” `[explicit]`。
8. **`state_problem`（p. 7, §4.1）**：指出若保留任意 order，policy 必须容纳 denoising trajectories 的组合空间。依据 “policy must accommodate the combinatorial space of denoising trajectories” `[explicit]`。
9. **`explain_mechanism`（p. 7, §4.1）**：随机 unmasking trajectory 使 noisy state 没有唯一的 index-aligned conditional，token-level credit assignment 与 importance ratio 不清楚。依据 “generation state ... conditioned on a stochastic unmasking trajectory” `[explicit]`。
10. **`state_complexity`（p. 7, §4.1）**：序列 likelihood 需对所有合法轨迹边际化，长度 `N` 时声称 `|T| = O(N!)`，因此 exact likelihood 不可行。依据 “trajectory space grows as `|T| = O(N!)`” `[explicit]`。
11. **`explain_mechanism`（p. 7, §4.1）**：confidence-based rollout policy 与 ELBO 所针对的原始 diffusion distribution 不同，形成 sampler–learner mismatch。依据 “ELBO objective still targets ... the original model distribution” `[explicit]`。
12. **`state_problem` + `contrast_alternative`（p. 7, §4.2）**：因纯 AR order 在 Section 3 展示更高 potential，训练阶段明确放弃 arbitrary-order。依据 “explicitly forgo arbitrary-order generation during the RL stage” `[explicit]`。
13. **`define_component`（p. 7, Eq. (5)）**：构造 `\tilde{x}_k=[o_{<k},[MASK],...]`，过去 token observed、future token masked。依据 “the past is observed and the future is masked” `[explicit]`。
14. **`define_component`（p. 7, Eq. (6)）**：只取 dLLM 在位置 `k` 的 logits，定义 surrogate `π^AR_θ(·|o_{<k},q)`。依据 “the autoregressive policy concerns only the next token” `[explicit]`。
15. **`derive` + `connect_to_prediction`（p. 7, Eq. (7)）**：把 permutation marginalization 变成可精确计算的 AR product likelihood。依据 “convert the intractable marginalization over permutations into an exactly computable likelihood” `[explicit]`。
16. **`instantiate_algorithm`（p. 8, Eq. (8)）**：在 `π^AR` 上直接使用 standard GRPO 的 group sampling、clipped ratio 与 group-standardized advantage。依据 “enables the direct application of standard GRPO” `[explicit]`。
17. **`explain_mechanism` + `connect_to_experiment`（p. 8, Remarks）**：AR constraint 只作用于 RL training，不加 causal mask；模型分布被 refinement，而 native bidirectional/parallel inference 保留。依据 “applied exclusively during RL training” `[explicit]`。

方法推进序列为：`setup_notation → derive → define_component → explain_mechanism → state_complexity → contrast_alternative → instantiate_algorithm → connect_to_experiment`。它先把“任意顺序为何难以优化”形式化，再用一个可因子分解的 surrogate policy 解 likelihood/credit-assignment 问题；AR 与 parallel inference 的解耦是方法的边界条件；方法本身未引入额外架构模块。

## K. 用词与修辞

- **高频实词/概念场**：`order`、`reasoning`、`diffusion`、`generation`、`model`、`token`、`arbitrary`、`AR`、`Pass@k`、`entropy`、`RL`、`training`、`sampling`、`trajectory`、`potential`。它们同时出现在标题、方法、图注与结果，主要由真实论证动作驱动，而非只由模板语言驱动。
- **高频二元词组**：`arbitrary order`、`reasoning potential`、`parallel decoding`、`diffusion language models`、`solution space`、`entropy degradation`、`general reasoning`、`standard GRPO`、`sampling strategy`、`denoising trajectories`。
- **三元表达**：`solution space accessible to RL`、`reasoning potential of dLLMs`、`parallel decoding capability of dLLMs`、`high-entropy ... forking tokens`。其中 `reasoning potential` 与 `solution coverage` 是把 proxy、机制和结果串起来的关键词。
- **主张动词**：`observe`/`find` 用于发现，`show`/`demonstrate` 用于证据回收，`propose`/`introduce` 用于方法，`suggest`/`appear`/`likely`/`plausible` 用于机制或外推。强主张集中在表图和 conclusion，机制段落使用较多 `may`、`appears`、`suggests`，形成“结果确定、机制相对保守”的强弱梯度。
- **对比与因果词**：`however`、`in contrast`、`by ...`、`as a result`、`consequently`、`motivated by`。论文最有效的因果句式是“先解低不确定性 token → future context 固定 → fork entropy 下降 → coverage 受限”，但最后一步主要由平行的 Pass@k/entropy 证据支持。
- **图文修辞**：Figure 1 的标题 “Less flexibility unlocks better reasoning potential” 先把反直觉结论视觉化；Figure 2 将 “Confronts Uncertainty” 与 “Bypasses Uncertainty” 做成二分图；Figure 3–5 从跨模型 scaling、集合 coverage 到连续 `B` sweep，逐步把一句 headline 变成可检验的比较。Table 2 放在异质 Table 1 之后，是对 baseline 可比性的修正。
- **同义/误切分风险**：`AO`、`Arbitrary Order`、`arbitrary-order generation` 指相近但不总是同一 sampler；`AR Order`、`autoregressive order`、`AR policy` 需按“解码方式/训练 surrogate”区分；`entropy` 既指全局 token entropy，也指 connector/fork entropy，不能混为一个量。`Margin` 在 Appendix B 是 sampling algorithm 名称，不应理解为未定义的统计阈值。

## L. 最终判断

1. **单一主线。** 论文把 dLLM 的“理论上更灵活”拆成训练探索与推理执行两个问题：confidence-based arbitrary order 会绕开 high-entropy logical forks，导致 entropy degradation 和较窄的实际 solution coverage（p. 4–6，Fig. 3–7）；因此 RL 不必优化组合 trajectory，而可在训练中构造 exact AR policy、直接应用 GRPO，再在 inference 恢复 parallel decoding（p. 7–10，Eq. 5–8、Fig. 8–9）。
2. **正文保留的决策关键内容。** 主文保留 AO/AR 的定义与 Pass@k proxy（p. 4）、跨模型/任务的 scaling 和 coverage（p. 4–5）、connector entropy 机制（p. 6）、likelihood/trajectory tax（p. 7）、JustGRPO 公式（p. 7–8）、matched benchmark（p. 9）和 parallel/efficiency 结果（p. 9–10）。这些内容正好覆盖“为什么约束、如何约束、约束后是否仍能部署”的决策链。
3. **附录迁移与自足性。** A 提供训练可复现细节，B/C 提供温度、sampler 与 connector 稳健性，D 提供 random-order failure，E 提供通用能力与 bidirectional refinement 边界。迁移没有损害中心主张的可读性，但把“不是某一 temperature/sampler 伪影”“random order 也失败”“通用能力大体保留”等范围判断留在后文，读者若只读正文会高估主张的普遍性。
4. **最有效的写作、图和公式模式。** 最有效的是 Figure 3→4→5→6→7 的证据阶梯：先看 scaling，再看集合交集，再连续扫 order arbitrariness，最后以局部 entropy 解释；随后 Table 2 解决比较可比性，Figure 8 验证训练/推理解耦。Eq. (5)–(7) 用一个 masked-prefix 构造把“dLLM sequence denoiser”转换成 exact AR likelihood，避免另造 diffusion-specific RL 算法。
5. **最明显的叙事缺口。** 最大缺口是 entropy degradation 仍是观察性机制：connector entropy 下降与 coverage 下降同时出现，但没有干预 fork、固定 future context 的反事实或因果识别（p. 6，Fig. 7；p. 17–18，Fig. 12）。其次，JustGRPO 的 RL 结论主要来自一个 base model，Table 1 的异质 baseline 与无 seed/不确定性报告也限制了外推（p. 8–10、15–19）。
6. **可迁移规则。** 在把模型的 order flexibility 当作能力优势前，先用高 `k` 的 solution coverage 检验“新增路径”是否真实存在，再定位高 entropy 的决策 token，并把训练期探索顺序与推理期并行执行分开验证（p. 4–7、p. 9–10）。
7. **规则的适用边界。** 该规则适用于本文覆盖的 general reasoning（数学与代码）、LLaDA/Dream 等 dLLM 的测试设置及 confidence/semi-AR/random order 对照；它不是“AR 在所有任务优于 arbitrary order”的定理，也没有覆盖更多模型、非 reasoning 生成、全部 sampler 或 bidirectional iterative refinement（p. 1 footnote、p. 4–5、p. 17–19）。
