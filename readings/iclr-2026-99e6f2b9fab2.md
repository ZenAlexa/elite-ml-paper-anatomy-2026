## E. 方法与理论

### E.1 形式化对象、输入输出与三阶段闭环

- 输入是带有音频及相关语义／元数据的 emotion query；最终输出被约束为 `<think>...</think>` 与 `<answer>...</answer>` 两个 XML-style 区域（p. 5，§3.3.1，`explicit`，锚点，“reasoning content must be enclosed within”）。论文没有给出统一的张量形状、显式状态转移或环境定义；RL 说明以 query、多个 sampled outputs、reward 与 group normalization 为主（p. 5–6，Figure 3，`layout_observation`）。
- 阶段一，EmotionCoT-35K 含 35,000 个 speech–reasoning pairs、约 200 小时音频、9 个 emotion categories；来源为 IEMOCAP、MELD、Expresso、MEAD、EARS（p. 4，§3.1，`explicit`，锚点，“35,000 speech–reasoning pairs”）。
- 阶段二，EmotionThinker-Base 以 Qwen2.5-Omni-7B 为 backbone，使用约 500 小时 prosody-enhanced SFT，并加入 5K EmotionCoT cold-start samples（p. 4，§3.2；p. 16–17，Appendix C.2，`explicit`，锚点，“SFT corpus (∼500 hours)”）。
- 阶段三，只优化 policy model 的 GRPO-PTR，将 format reward、outcome reward 及带 trust gate 的 reasoning reward 组合；Figure 3 上部展示候选输出与 group normalization，下部展示从不稳定 rule reward 向稳定 reasoning reward 的渐进路径（p. 5，Figure 3，`layout_observation`，锚点，“only the policy model is optimized”）。

### E.3 公式与理论对象

PDF 中有 7 个 displayed equation block，均未编号；没有 theorem、lemma、proposition、corollary 或 proof。公式属于方法机制的定义和诊断 gate，不构成独立数学保证（p. 5–6，`explicit`，锚点，“Formally”／“and define”）。

1. `R_f(o)` 的二值 format reward，遵守 `<think>`／`<answer>` 为 1，否则为 0（p. 5，§3.3.1，`core_chain`）。
2. `R_o(ŷ,y*)` 的二值 outcome reward，预测 label 等于 gold label 为 1，否则为 0（p. 5，§3.3.1，`core_chain`）。
3. `R_t = Σ_{j=1}^4 w_j \tilde g_j`，其中 `\tilde g_j=g_j/5`、`Σ_j w_j=1`、`w_j>0`（p. 6，§3.3.2，`core_chain`）。
4. `G_correct={i|R_o^i=1}` 与 `G_wrong={i|R_o^i=0}` 的分组定义（p. 6，`diagnostic`）。
5. 正确组和错误组的平均 reasoning reward `\bar R_t^(c)`、`\bar R_t^(w)`（p. 6，`diagnostic`）。
6. trustworthiness weight `τ` 的分段定义，正确组均值不低于错误组时为 1，否则为两组均值差的 exponential（p. 6，`core_chain`）。
7. 总 reward `R_i=α_fR_f+α_oR_o+α_tτ·R_t`（p. 6，`core_chain`）。

作者未证明 `τ` 必然提高正确率，也未给出收敛定理或复杂度分析。正文与附录均未说明 `G_correct` 或 `G_wrong` 为空时如何计算组均值；公式本身无法补齐这一实现边界（p. 6，`not_present`，锚点，“We partition the responses into two disjoint sets”）。

### F.2 设计与主张对应关系

实验顺序基本追随引言，先评估 Base 的 prosody perception，再比较 SFT／GRPO，再拆分 reward model、trust gate 和 progressive schedule，最后检查 `K` 与 reward weights（p. 8–9，§4.3，`explicit`，锚点，“We first examine … Second … Third … Finally”）。这为“prosody 是 RL 前置条件、GRPO-PTR 的三组件各有作用”提供了可读的验证顺序。

### H.2 负面结果与不利信息的呈现

- **明确保留的 trade-off。** V1 SFT 的 ER=3.78 高于 V2 rule-only GRPO 的 ER=3.45，说明单纯加入 RL 并不自动提高 reasoning quality；正文仍报告该行并解释 V2 的 accuracy 提升（p. 8–9，Table 4，`explicit`，锚点，“Standard GRPO … yields a clear improvement”）。
- **基线不是每项最优。** EmotionThinker 的 RAVDESS accuracy 71.56 低于 BLSP-Emo 的 72.00；作者使用 “most benchmarks” 而非 “all benchmarks”，但摘要的 “outperforms … both” 更宽泛（p. 7，Table 2，`interpretation`，锚点，“superior accuracy on most benchmarks”）。
- **超参结果的折中。** Table 6 的 `K=16` Avg=67.66 高于 `K=8` 的 67.35，但作者仍选 `K=8`，把选择解释为 compute–accuracy trade-off；没有给出具体成本值（p. 9，Table 6，`explicit`，锚点，“choose 8 for trade-off”）。
- **评价偏差的主动处理。** 作者主动承认 GPT-based evaluation 可能有 bias，并加入 100-sample、4-reviewer human assessment；人工规模和方差仍不足以检验所有模型差异（p. 7，§4.2，`explicit`，锚点，“To mitigate potential biases”）。
- **位置延后但非隐瞒。** 具体 prompt、评分 rubric、案例输出和 LLM 使用说明放入附录；正文用一句话调用它们。这降低正文负担，却使 reward model 数据生成和评价可重复性主要依赖附录（p. 7–8、15–26，`interpretation`，锚点，“Detailed prompt and rubric are provided in the Appendix”）。

未观察到“只展示代表性案例”以外的分母操纵、显著性挑选或未来工作化表述；该判断仅限论文给出的表格和文字。案例确实被称为 `selected example`，但未说明抽样规则，因此其代表性保持 uncertain（p. 18，Appendix F，`explicit`，锚点，“The selected example corresponds”）。

## L. 最终判断

1. **单一主线。** 论文把 SER 从“输出一个 emotion label”改写为“先识别 prosodic／semantic cue，再生成可解释 reasoning，再给出 label”，并把这一主线拆成数据、感知初始化和 reward alignment 三个必要阶段。最关键的因果断点是，prosody-centric SFT 先修补输入感知，GRPO-PTR 再用 `τ` 与 progressive schedule 约束开放式 reasoning（p. 2、4–6，`interpretation`，锚点，“fine-grained acoustic cues”）。
2. **正文保留的决策内容。** 正文保留三阶段架构、`R_f/R_o/R_t/τ` 的核心公式、四 benchmark 主结果、reasoning 四维指标，以及 V3/V4/V5 的组件消融；这些内容足以让读者理解为什么不是 rule-only GRPO（p. 5–9，`explicit`，锚点，“ablate key components”）。
3. **移入附录的细节及其代价。** prompt 原文、数据源背景、自动标注、SFT 两阶段、reward data 生成、评分 rubric 和多模型案例被移入 p. 15–26。迁移使主线清晰，却使数据质量、reward model 训练和评价可复现性依赖附录；seed、split、hardware 等仍未出现（p. 15–26，`interpretation`，锚点，“Details are provided in the Appendix”）。
4. **最有效的写作／图／表／公式模式。** Figure 3 将候选输出、三类 reward、group normalization 和 progressive trust gate 放在一张图中；Table 4 采用“full vs no-X”并列，使 mechanism ablation 能与公式一一对应；Table 5 把 prosody prerequisite 单独量化，避免只用最终 SER 解释 SFT（p. 5、8–9，`layout_observation`，锚点，“Effectiveness of the reward model”）。
5. **最大叙事缺口。** “trustworthiness” 是核心因果词，但论文没有报告 `τ` 的分布、校准、空组处理、错误 reasoning rate 或跨 seed 稳定性；GPT 评分也没有 inter-rater／区间。单一案例和四个 benchmark 的平均 accuracy 不能完全闭合“trustworthy explainable reasoning”的强主张（p. 6–9、18、25–26，`interpretation`，锚点，“only when … global agreement”）。
6. **可迁移规则。** 若论文将开放式 explanation 作为 RL 的中间目标，应同时提供，可审计的维度化评分定义、与 outcome 的对齐 gate、组件删除实验，以及独立的人类或人工可复核检查；否则“正确答案”与“正确理由”容易被一个总分混在一起（p. 5–9、18–26，`interpretation`，锚点，“factual alignment”／“interpretative quality”）。
7. **规则边界。** 该规则适用于 explanation 有明确事实 grounding、存在 reward hacking 风险且 outcome 可自动判定的任务；若任务没有可靠 gold outcome，或 reasoning 本身不可拆为稳定维度，`τ` 的正确／错误分组并不直接适用。本文只在 4 个 SER benchmark、给定 emotion labels 和 1–5 rubric 下提供证据，不能外推到一般 multimodal reasoning（p. 4、6–9、18–26，`interpretation`，锚点，“ground truth”／“four dimensions”）。
