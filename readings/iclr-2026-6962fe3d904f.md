## 6. 方法与理论

### 6.1 形式对象与组件

- **输入/输出** gene sequence `X=[x₁,…,x_L]`，每个 `x_i∈R⁴` 是 A/T/C/G 的 one-hot；multimodal signals `S=[s₁,…,s_L]`，`s_i∈Rᵈ`；signal encoder `gθ:R^(L×d)→R^(L×d′)` 输出 `H=gθ(S)`；predictor `hφ` 接收 `(X,H)`，输出 expression `Y∈R`。[p. 4, §3.1, explicit；“Given a gene sequence X”]
- **标准预测路径**：smooth L1/Huber prediction loss `L₁`。[p. 4, Eq. (1), explicit；“smooth L1 loss (Huber loss)”]
- **SCM**：Figure 3 只绘制 `C→H`、`C→Y`、`H→Y`，为隐藏 background chromatin state `C` 同时影响 observed features 和 expression 的 confounding path；图中为清晰起见省略 `X`。[p. 4–5, §3.2, explicit；“H ← C → Y”]
- **C 的定义**：`C` 表示多个 epigenomic dimensions 的组合状态，覆盖的对象超出单个手工指定的 DNase/Hi-C 通道；作者借鉴 ChromHMM 和 computer-vision background modeling 的组合表征思路。[p. 5, §3.2, explicit；“background chromatin states”]
- **状态分层与权重**：`C={C₁,…,Cₙ}`，`gω(S)` 输出 `A=[a₁,…,aₙ]∈R^(n×d′)`，每个 gene 的 `a_i` 通过 Hadamard product `H⊙a_i` 给出一个 context。权重按 gene 共享 across positions，体现“gene-wise rather than position-wise”的假设。[p. 5–6, §3.4, explicit；“These weights are gene-wise rather than position-wise”]
- **融合**：附录 F.3 明示 DNA `X` 与 `H⊙a_i` 分别投影到 `d′`，再 element-wise addition 后送入 Caduceus；interventional prediction 在 backbone representation 层对 `n` 个 context 求平均，再过 shared head。[p. 18, Appendix F.3, explicit；“combined via element-wise addition”]

### 6.3 方法动作与转移

方法段的最小动作序列为：

`setup_notation → state_problem → define_component(C) → explain_mechanism(SCM edges) → derive(backdoor) → define_component(gω,A) → give_intuition(gene-wise weights) → derive(interventional prediction) → connect_to_prediction(L2) → derive(diversity loss) → summarize(total objective) → instantiate_algorithm(Appendix E) → state_complexity(Appendix F.2) → connect_to_experiment(2k input)`。

其中 `derive` 主要是把 causal graph 写成状态平均，而非从可检验假设推出新定理；`state_complexity` 只给 confounder encoder 的参数量，未给端到端时间或显存复杂度。[p. 6, §3.3–3.5, interpretation；三项 loss 的连续定义] [p. 18, Appendix F.2, explicit；“requires only 11K parameters”]

### 6.4 算法

Algorithm 1（p. 17）要求 `X,S,Y,α,β,t,n`，随机初始化 `θ,φ,ω`，循环执行 `H=gθ(S)`、标准预测、`A=gω(S)`、`n` 个 weighted-context 的 intervention average、`L₁,L₂,L₃`，再以梯度下降更新三个网络。循环不变量是每步都保持同一 `X,S,Y` 下的 standard/interventional predictions 以及 normalized `a_i`；算法写出“while not converged”，没有给停止判据。[p. 17, Appendix E, explicit；“while not converged”]

附录 F.2 的 `gω` 为三层 1D-CNN：channels `d→8→16→32`，kernel sizes 7/5/3，BatchNorm、ReLU、MaxPool(kernel 4)，AdaptiveAvgPool1D(1)、Flatten，再 Linear 到 `n×d′`；总池化因子 64，sigmoid 将权重限制在 0–1，参数量约 11K。[p. 18, Appendix F.2, explicit；“three-layer CNN followed by a projection layer”]

### 8.3 统计与可视化审计

- **聚合单位/分母**：主任务按 cell line 的 18,377 protein-coding genes 做表达预测，但表格未单列 test chromosome 上实际 gene 数；Table 1 的中心量是五个 random seeds 的 run-level mean，离散量是 SD。Table 8 以 gene 为单位给比例和 median；Table 13 以混合训练行比较 cell line；其余 appendix 表按表面呈现的 run/point estimate 报告。[p. 6–8, §4.1–4.2, explicit；“18,377 protein-coding genes”]
- **中心/离散量**：MSE、MAE、Pearson 是中心性能指标；主要重复实验使用 mean ± SD。没有 conventional confidence interval、p-value、effect-size estimator、multiple-comparison correction、bootstrap 或 Bayesian posterior。[p. 8, Table 1, layout_observation；“±”]

## 15. 最终判断

1. **单一主线**：把 gene-expression prediction 的优化问题从“继续扩展 DNA sequence length”转到“在短 proximal context 中区分并整合 multimodal epigenomic signals”；signal-drop paradox 提供 confounding 动机，Prism 用 gene-wise latent background states、backdoor averaging 和 diversity regularization 回应它。
2. **正文保留的决策关键内容**：Figure 1 的六面板诊断、Figure 2 的 shortening curve、SCM 与 Prism architecture、Eq. (1)–(5)、数据/基线/指标/染色体切分、Table 1 的六项主结果、Table 2 的 (n,alpha,\beta) 选择、Figure 5 的 weight pattern 和 Table 3 的 11K overhead。读者可据此理解为何方法被提出以及主比较如何成立。
3. **附录迁移及其影响**：实现细节、完整 length/signal ablations、signal-drop raw values、pre-training、additional signals、cross-cell、H1、dropout 和 prevalence/case study 移到 Appendix B–L。正文叙事保持紧凑；causal claim、robustness 和某些异常曲线的自足性依赖附录，尤其是 representation averaging、Seq2Exp mask constraint 与 Table 7/8/15/16。
4. **最有效的模式**：Figure 1 把“生物远程作用、当前模型技术限制、signal role、train/test asymmetry”压缩为一条可读诊断链；随后用 Figure 3/4 把 SCM 和实现映射到 Eq. (2) 到 (5)，再用 Table 1/2/3 对性能、超参、参数量做紧凑决策汇总。这种“悖论图 → 因果图 → 三项目标 → 主表”的节奏有效降低读者的模型重建成本。
5. **最大缺口**：Prism 的 causal language 超过了可识别证据。(C) 没有 ground-truth state，uniform prior 和 (Xperp H) 未验证，representation averaging 只在线性 head 下与公式等价；Figure 5/6 是小样本可视化，Table 7/8 是 observational/diagnostic 证据。基线直接引用、缺少 inferential test、Table 2 与 Table 7 的报告分歧进一步限制 SOTA 与 confounding 的强度。
6. **可迁移规则**：当论文把长上下文作为核心路线时，先在 matched training/test settings 中做输入缩短与模态删除的对照，再决定增加 context 或增加融合机制；若引入 latent-causal state，必须同时给出 state validation、替代解释对照和与主表一致的重复/不确定性处理。
7. **规则边界**：该规则适用于具有 proximal multimodal proxies、长程依赖和观测性 signal confounding 的 genomic/sequence-to-function 任务；它不能单凭短 context 的性能推出 distal biology 不重要，也不能把 predictive invariance 或 latent weight structure 当作 causal identification。真正的跨物种、跨 cell type、真实 perturbation 或 deployment 结论需要额外数据和设计。
