作者对 capacity 的两个 operationalization 是：结构视角把 `θ^e` 的 rank 当 capacity；优化视角把 gradient dominance 当 allocation。L1-norm 只作为 pruning 的 diagnostic proxy；p.21, E.1 将 capacity 定义为网络捕获和存储特征的 representational resources。这使 CM 的因果主线清晰，但 rank 仍是 capacity 的代理，尚未构成一般意义上的 representational capacity 定理。

自我设限的出现位置主要延后到 appendix I；正文对 IS 不可靠性（p.7）和 CIFAR-10 Medium/Few 难度差异（p.8）有主动解释。作者没有把 few-shot/zero-shot 失败条件放入摘要、引言或主结果段，直到 p.40 才明确写出。

可证据支持的 presentation strategies：

1. **附录迁移**：Table 2、4、6 保留主结果点值，Mean±Std 移到 G.1–G.6；human、downstream、broader、Overlap 和分类扩展均移到 appendix（p.7–10 明确 cross-reference）。这是 `appendix_migration`，不是对作者动机的推断。
2. **以相对改进替代绝对门槛**：作者指出 imbalanced regime 的 baseline FID 较高，强调统一 pipeline 下的 relative gains，而没有提出外部 FID 通过线（p.7）。
3. **主动降低不利指标的解释权重**：IS 可能被 majority 特征压倒、且不参考 real images；作者用这一点解释 vanilla DDPM 的部分高 IS（p.7）。
4. **代表性随机视觉案例**：Fig. 1、3、G.4–G.12 多处声明 images are randomly selected；视觉结果承担直观佐证，但不替代全量统计（p.3、p.9、p.30–37）。
5. **未来工作化处理边界**：modalities 与 few-shot/zero-shot transition 在 p.40 以 future research 表达；因此主文性能叙事较完整，但闭环的适用域在最后才出现。

## 13. 最终判断

1. **单一主线**：class-imbalanced diffusion 中，majority 的样本聚合梯度会占用 shared capacity，使 minority information 落入脆弱参数；CM 以 low-rank `θ^e` 预留容量，再用 class-count-adaptive consistency/diversity output loss 把 minority expertise 分配到该分支，最后合并为无额外 inference branch 的模型。
2. **正文保留的决策关键内容**：Fig.1 diagnostic、Eq.(1)–(4)、Theorem 2.1/3.1、Table 1–7、Many/Medium/Few split、多个数据集与架构、λ/rank/branch/loss ablations、推理合并声明。
3. **迁移到附录的细节及代价**：proof、DDPM/CBDM/OC 公式、Algorithm C.1、完整实现超参、Mean±Std、human/downstream、broader settings、Overlap/classification extension 和大量视觉图。这样正文保持可扫读，但理论可核查性、复现粒度和外部效度均依赖附录。
4. **最有效模式**：Fig.1 用“质量失败 + pruning sensitivity”同屏建立 mechanism；Fig.2 把 reservation、allocation、split performance 连成一图；Table 7 用 θg-only 与去掉 `LCon/LDiv` 同时验证分支职责和损失必要性；Table G.1–G.8 再把 uncertainty/utility 补回。
5. **最大叙事缺口**：作者将 rank 视为 capacity、将 pruning sensitivity 视为 fragile knowledge 的证据，但没有真实 per-layer capacity allocation map、gradient-share measurement、`αr` estimation 或 runtime/parameter accounting；Theorem 3.1 还以 simplified optimizer model 和省略 class-ratio 的 bound 支撑工程结论。
6. **可迁移规则**：提出“资源被谁占用”的机制时，必须把 resource proxy、组件反事实和下游效果放在同一证据链中；至少报告一个 branch/component deletion、一个 matched structural alternative、一个异质性 split，并把 uncertainty 与运行单位写清楚。
7. **适用边界**：该规则适用于资源分配能由结构分支和可观测反事实操纵、且有足够 minority samples 学习专属表示的长尾生成任务；在 single-digit/zero-shot minority、不可合并的动态专家、无可靠 per-class evaluation 或数据模态差异很大的情形，本文证据不足以直接迁移。
