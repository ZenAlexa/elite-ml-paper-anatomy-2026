## 11. 最终判断

1. **单一主线**：对 recurring heavy users 的身份进行 contribution capping 看似需要记忆；论文通过 AvoidHeavyHitters 把这一直觉变成通信下界，再把 accurate low-space DP streaming algorithm 规约为该 game 的 protocol，得到空间下界。【p. 2，§1；p. 6–8，§2.3–§3.3；explicit；“low space alternative”】
2. **正文保留的决策关键内容**：问题定义、promise、prior capping 对照、hard instance 四步、game 的赢法、Lemma 3.1/3.2/Corollary 3.3、fingerprinting/rounding 直觉、Theorem 2.1–2.3 和结论均留在正文；读者可看到从构造到结论的骨架。【p. 5–8，§2.2–§4；layout_observation；连续的 theorem-to-proof chain】
3. **迁入附录的细节及自足性**：概率集中、usefulness coupling、encoding proof、strong fingerprinting gadget 的完整证明迁至 A.1–A.4。迁移不阻断主线，却使核心 Lemma 的严格验证依赖附录。【p. 6，§3；explicit；“All missing proofs are deferred”】
4. **最有效的写作/公式模式**：先用 CountDistinct 的 capping 作为可感知难点，再提供能单独陈述的 game，最后将 `algorithm memory = protocol message` 的规约写成 Corollary 3.3。这让抽象通信下界成为机制链的一环，不是孤立技巧。【p. 5–8，§2.1–§3.3；interpretation；“communication complexity M”】
