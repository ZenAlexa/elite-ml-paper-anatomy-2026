## 方法、理论和逻辑闭环

### 形式化对象与方法链

- **输入／状态／输出**：每轮已有历史、当前特征和点预测 `Yhat_t`；`S_t=|Y_t-Yhat_t|` 是 nonconformity score；输出半径 `b_t` 和中心区间 `Chat_t=[Yhat_t-b_t,Yhat_t+b_t]`（pp.2–3, `non-conformity score`；p.8, Algorithm 1）。
- **目标**：使误覆盖频率趋近 `α`，式 (1)，并以式 (5) 将其写作子梯度均值（pp.2,4, `MisCov_T`）。
- **损失和关键差异**：pinball loss 式 (2) 给 `g_t∈{-(1-α),α}`；普通 regret 被线性化 regret 上界，但反向不成立。Remark 3.2 的常数 score 反例说明只有 sublinear ordinary regret 仍可持续失覆盖（pp.3–5, `may control regret but not linearized regret`）。
- **一般理论**：Theorem 3.1 用 `F_T*` 把任意 algorithm 的 linearized-regret 上界转为梯度和、即 coverage 的有限时域约束（p.4, Eq.7, `bounds the range of the sum`）。
- **UP-OCP 实例化**：将 coverage／miscoverage 的不对称子梯度编码为两个 synthetic stocks；`λ_t` 是 Jeffreys-prior universal portfolio 的 wealth-weighted 份额，wealth 再映射为 `b_t`（p.6, Definitions 4.1–4.2, Eqs.9–11）。
- **可执行更新**：closed form `λ_t=(N_{t-1}+1/2)/t`，非负 clipping 不改子梯度，故 Algorithm 1 为每轮常数时间（p.7, `only O(1) time per step`；p.8, Algorithm 1；p.25–27, `Radius Clipping` 和 Theorem G.1）。

段落动作主序列是：`setup_notation → state_problem → define_component(pinball) → define_component(gradient) → derive(linearized regret) → state_theorem → contrast_alternative → define_component(conformal market) → define_component(wealth) → derive(portfolio-to-radius) → state_theorem → instantiate_algorithm → connect_to_experiment`。

### 理论清单与证据职责

- **Theorem 3.1**（p.4；证明 p.16）：假设 `LinRegret_T(u)≤F_T(u)`，以 `F_T*` 和 score 累积给出 `-Σg_t` 的集合值上界。它是主因果链的桥，而非装饰。
- **KT/OSD warm-up**（pp.5,16–17）：把现有 KT conjugate 和 OSD linearized-regret 带入一般结果，说明对 `S_t≤Dt^q` 的有限／渐近 coverage 推导。
- **Theorem 4.3**（p.6；证明 pp.20–23）：Universal Portfolio 的 wealth guarantee 通过 asymmetric coin 和 Fenchel duality 变成 `O(sqrt(T log T))` 级 linearized regret；是 UP-OCP 的机制保证。
- **Theorem 4.4**（p.7；证明 pp.24–25）：在 polynomial score growth 下，以 Bernoulli KL 反演给出 `|T^{-1}Σg_t|` 的明确 `ε_T` 上界；是“finite-time”主张的直接证据。
- **Theorem C.1**（pp.17–18）：在 `q<p<1` 和 `F_t(t^p)/t→0` 下给渐近 coverage。
- **Theorem D.3**（p.19）：仅在 i.i.d.、compact support、density 下界等额外条件下，平均半径由 expected pinball regret 收敛到 oracle quantile；它不是 adversarial efficiency 结论。
- **Theorem G.1**（pp.26–27）：Jeffreys Beta(1/2,1/2) prior 的 closed-form 权重，补全计算闭环。

### 算法与复杂度

Algorithm 1（p.8）只有一个 `for t=1,2,…` 循环：维护 wealth `W` 和误覆盖计数 `N`；从计数计算 `λ_t`，计算并截断 `b_t`，观测 score 后按 coverage 与否乘法更新 wealth。关键不变量是计数与收益情形的一一对应，且 clipping 后 gradient 相同（p.25, `does not alter the subgradient sequence`）。正文解释到公式、输入输出和循环级；每轮 O(1) 的理由放在 Section 4.2 与 Appendix G。Algorithms 2–6 则被移动到 Appendix H，用于 KT、DtACI、SF-OGD、P/PI 与 trivial predictor 的可比实现。

## 实验设计、统计口径与结果

### 设计事实

- **数据与基础模型**：四支 2008–2018 美国股票的日开盘价 log-scale，用 Prophet 每日重训；NSW electricity demand 用 lag-3 AR；主文仅聚焦 AXP 和 synthetic sinusoid（p.8, `domain-standard choices`；p.9, `Due to space constraints`）。
- **合成序列**：sinusoid 是周期 200、`S_mag=10`、`S_min=2`、噪声 `σ=0.3`、`T=3000`（p.11；p.53）；stationary wavelet 用常数 10、Bernoulli(0.1)、Exponential(1/10)、25-window rolling max（p.56）；quadratic drift 从 0 至 20、同类随机 waves（p.59）。
- **comparators**：KT、DtACI、SF-OGD、Conformal P/PI；不纳入需要 uniform score bound 的方法（pp.8–9, `do not rely on prior knowledge`）。
- **调参和公平边界**：parameterized baselines 以 ex-post grid search 选最佳超参数；作者明确这给 baseline `oracle advantage`，因而可能高估它们（p.9）。SF-OGD grid 在 p.29；P/PI 的 heuristic 和 grid 在 pp.29–30。
- **时间控制**：AXP 初始训练 100 days（p.9）；完整 AXP 图丢弃评估前 50 days，local coverage/width 的 rolling window 为 100 days（pp.31–32）。其他股票 100-day burn-in，electricity 和 synthetic 300 steps（p.36）。
- **随机性**：synthetic 结果是 10 independent seeds 平均；Figure 4 的双轴 error bars 是 standard error of the mean（pp.11–12,36）。真实时间序列没有 seed 层级或重复次数报告。
- **指标与分母**：marginal coverage 是时间轮次的平均；longest error sequence 量化相邻误覆盖；平均、median、75/90/95% set size 分别检验常规与尾部尺寸（p.9, Table 1）。Pareto sweep 对 AXP 用 50 个 `α∈[0.05,0.25]`（p.10, Figure 1）。
- **理论到实验的对应**：Section 5 紧接 Section 4，先检验 parameter-free 方法与 tuned baseline 的 size/coverage 后果，再用多 target Pareto 和 additional tasks 检验 operating point 与任务异质性。PDF 未给逐项校准 Theorem 4.4 中 `D`、`q` 或 `ε_T` 的机制实验。
- **统计缺口**：未见假设检验、多重比较、bootstrap、Bayesian 分析、回归或硬件配置；该条目只记录 PDF 中没有出现的复现／统计细节，不据此替代未报告数值。

## 用词、修辞和最终判断

清理 references、图表数值与公式碎片后的粗略上下文统计显示核心实词是 `coverage`、`size`、`portfolio`、`regret`、`online`、`universal`、`algorithm`、`quantile` 与 `miscoverage`。高频二元／三元主短语是 `linearized regret`、`universal portfolio`、`online conformal prediction`、`prediction set`、`parameter-free` 和 `finite-time bounds`。`we show` 在正文／附录理论与结果段落多次出现；`we propose` 集中于摘要、Section 4 与 Appendix J；`we demonstrate` 主要用在经验／score-growth 语境。`support`、`may`、`can`、`typically`、`possibly` 是常见限定；`however`、`in contrast`、`moreover` 串联 prior-work gap 与理论推导。领域名词与实际论证动作共同驱动这些词频；模板式贡献句的影响不显著。

1. **单一主线**：把 OCP 的 coverage error 化为 pinball subgradient 的均值，以 linearized regret 作为可移植的充分条件，再用不对称两资产 universal portfolio 实现这个条件，最终用 Pareto 图把 coverage–size 后果可视化（pp.4–12）。
2. **正文保留的决策关键内容**：问题、损失／梯度关系、Theorems 3.1/4.3/4.4 的陈述、Algorithm 1、主 AXP/sinusoid 和 size/coverage trade-off；这些足以理解论文为何选择 UP，而不等于已自行验证全部证明。
3. **迁移到附录的细节**：证明、closed-form 推导、全部 baseline update/hyperparameter、local plots、额外任务、failure examples。迁移使主文短而有主线，但跨任务和再现实证完全依赖附录。
4. **最有效模式**：在理论上按「误覆盖指标 → gradient sum → regret duality → wealth」逐层关闭；在实验上用同一 Pareto 坐标系，并另列无限半径与最长错误串，避免只报 marginal coverage。
5. **最明显缺口／读者成本**：非 adversarial benchmark、单时序真实数据、baseline 的 ex-post selection、无测试/硬件细节，以及没有 UP 组件消融；主文部分“best”叙述需要读 48 页附录和复核不同任务表格后才可判断范围。
6. **可迁移规则**：若预测有效性取决于在线误差频率，先寻找能直接约束该频率的优化量，再用一个可计算的 parameter-free 实例和与效用相连的联合图指标来闭环。
7. **适用边界**：这条规则依赖能把任务误差写成可控 gradient/wealth 或相近累积量；不自动给出 conditional validity、逐时刻 coverage、adversarial efficiency 最优性，或对任意模型类的组件因果解释。
