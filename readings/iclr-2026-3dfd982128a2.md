# A Scalable Distributed Framework for Multimodal GigaVoxel Image Registration：深读备忘

## 1. 一句话结论

论文把 ultra-high-resolution image registration 的规模断点归因于两类系统开销：单 GPU 上 non-GEMM operators 物化大量 intermediate HBM，多 GPU 上 convolution boundary 与 deformable random access 又使普通 tensor sharding 失效。FFDP 用 Composite Implicit Grid Sampler、Implicit Parzen Windowing、fused LNCC 先缩减单卡状态，再用 Grid Parallel（GP）halo synchronization 与 Distributed Ring Sampler 把 fixed image、moving image、warp 和 optimizer state 分片。整篇论文最完整的证据链是「资源核算 → decomposition → asymptotic prediction → component-off ablation」。[PDF p. 4, §3.1, explicit; anchor= `costing a total of 9N overhead`] [PDF p. 6, §4.2, explicit; anchor= `aggregate of partial sums`] [PDF p. 10, §5.4, explicit; anchor= `independent of H`]

系统 capability 已由 100µm real ex-vivo registration 的约 58 秒运行和多组 kernel/scaling measurements 支撑；真实案例的 quantitative accuracy 仍未闭合。作者明确说明 fiducial markers 为私有标注，主要 accuracy comparison 因此改用 simulated Faux-OASIS。[PDF p. 8, §5.2, explicit; anchor= `took ∼58 seconds`] [PDF p. 9, §5.2, explicit; anchor= `privately annotated fiducial markers`] [PDF p. 9, §5.3, explicit; anchor= `synthesize the faux-OASIS dataset`]

## 6. 方法与理论

### 6.1 形式化对象

- **输入与输出。** Fixed image F、moving image M 定义在 Ω；输出 coordinate transform φ，使 M∘φ 与 F 接近。[PDF p. 1, §1, explicit; anchor= `Given d-dimensional images F ... and M`]
- **目标函数。** Eq. (1) 为 `L(φ)=C(F,M∘φ)+R(φ)`；C 是 dissimilarity，R 是 regularizer，G 是 admissible transform class。[PDF p. 1, §1, explicit; anchor= `Eq. (1)`]
- **transform state。** composite transform 写为 `φ(x)=Ax+t+u(x)`；u 是每 voxel 的 d-vector，因此 image size N 对应 dN displacement parameters。[PDF p. 1, §1, explicit; anchor= `composite transform φ(x) = Ax + t + u(x)`]
- **distributed state。** H hosts 把 Ω 等量、互斥地划分为 Ω₁…Ω_H；GP 持有 fixed image、warp `[u]` 和 optimizer states `[m1]`、`[m2]` 的 shards。[PDF p. 6, §4 Distributed Setting, explicit; anchor= `|Ωi| = N/H`] [PDF p. 6, §4.1, explicit; anchor= `optimizer state [m1], [m2]`]

方法依赖四个明示条件：domain shards 覆盖 Ω 且互斥；MI bin count B 相对 N 很小，典型 B=32；bi/tri-linear interpolation 可分解为 per-shard partial sums；halo padding 足以恢复跨 shard convolution neighborhood。[PDF p. 6, §4 Distributed Setting, explicit; anchor= `Ωi ∩ Ωj = ϕ`] [PDF p. 5, §3.2, explicit; anchor= `B is typically chosen to be 32`] [PDF p. 6, §4.2, explicit; anchor= `aggregate of partial sums`] [PDF p. 6, §4.1, explicit; anchor= `sufficient boundary padding`]

### 6.2 单 GPU：把 HBM materialization 转成 implicit computation

#### Composite Implicit Grid Sampler

普通 composite sampling 会先后 materialize identity grid、affine grid 与 deformable composite grid，正文核算为 9N overhead。FFDP kernel 在寄存器内计算 `Ax+t+Su(x)`，用 `xbounds` 隐式定义 identity coordinates。三个作用分别是：extra grid HBM 从 O(N) 降到 O(1)；分布式时无需实例化 partial identity grid；S 直接完成 shard coordinate rescaling。[PDF p. 4, §3.1, explicit; anchor= `costing a total of 9N overhead`] [PDF p. 4, §3.1, explicit; anchor= `from O(n) to O(1)`]

这个组件的段落动作是 `state_problem → define_component → explain_mechanism`。正文给出一个 unnumbered displayed operator，没有 main-body pseudocode；forward/backward derivation 和 pseudocode 被调用到 unavailable Section H。[PDF p. 4, §3.1, explicit; anchor= `fused grid sampler`] [PDF p. 4, §3.1, explicit; anchor= `pseudocode ... Section H`]

#### Implicit Parzen Windowing for MI

Eq. (2) 先把 marginal/joint distributions 写成 KDE sums。显式实现需要 B×N Parzen blocks；正文以约 30MB clinical volume、B=32 估算 7.5GB HBM。FFDP 利用 B 小的条件，在 shared memory 中逐像素累计 histogram entries 和 partial gradients，避免 materialize Ψ_I、Ψ_J。固定 B 时 additional HBM 为 O(1)，正文报告实验 image sizes 上最多约 98% HBM reduction。[PDF p. 5, §3.2, explicit; anchor= `requires materializing the entire Parzen Block`] [PDF p. 5, §3.2, explicit; anchor= `use high-throughput shared memory`] [PDF p. 5, §3.2, explicit; anchor= `upto 98% lesser HBM usage`]

动作序列为 `setup_notation → state_problem → explain_mechanism → connect_to_experiment`。完整 derivation 被调用到 unavailable Section G。[PDF p. 5, §3.2, explicit; anchor= `detailed derivation in Section G`]

#### Efficient Implicit Fused Cross-Correlation

LNCC computational graph 被核算为 forward 16× HBM intermediates，backward 最多再加 16×。FFDP 把 intermediate computation fuse，forward 保存 5× tensors，并在 backward 原位改写 saved intermediates。正文给出的 component prediction 是 memory reduction 最多 76.5%；对应实证集中于 Figure 7、Table 1 与缺失 Table 3。[PDF p. 5, §3.3, explicit; anchor= `computational graph adds 16× HBM overhead`] [PDF p. 5, §3.3, explicit; anchor= `modifying the saved intermediates in-place`] [PDF p. 5, §3.3, explicit; anchor= `76.5% reduction in memory`]

### 6.3 多 GPU：保持 convolution correctness 与 random-access sampling

#### Grid Parallel

generic Tensor/Sequence/Expert/Context Parallel 假定被分片的 state 无需 convolution-boundary synchronization；registration 中 LNCC、TV、Sobolev operations 违反该条件。GP tensor metadata 保存 sharded dimension/bounds，并在 convolution 前从相邻 shards 获取 halo。其目标是让 fixed image、warp 与 optimizer state 都能分片，同时维持 boundary correctness。[PDF p. 6, §4.1, explicit; anchor= `require boundary synchronization`] [PDF p. 6, §4.1, explicit; anchor= `propose ‘Grid Parallel’`]

#### Distributed Ring Sampler

warp coordinate `φ(x)` 具有 random access：同一 local warp shard 的相邻坐标也可能指向两个不同 moving-image shards。若每 GPU 保存完整 M，最大问题规模仍受单卡 V 限制。Ring Sampler 依赖 bilinear/trilinear interpolation 的 partial-sum decomposition；每个 image shard 沿 ring 发送，各 host 原位累计自己的 moved-image shard。正文给出额外 fetch HBM 为 N/H。[PDF p. 6, §4.2, explicit; anchor= `random-access nature of the grid sample operation`] [PDF p. 6, §4.2, explicit; anchor= `sent across hosts in a ring topology`] [PDF p. 7, §4.2, explicit; anchor= `additional N/H HBM overhead`]

方法动作是 `state_problem → derive → state_complexity`。正文通过 Figure 4 给 intuition，通过 Figure 8a 给 matched ablation；detailed derivation/correctness 位于 unavailable Section I。[PDF p. 6, Figure 4, explicit; anchor= `Figure 4`] [PDF p. 7, §4.2, explicit; anchor= `correctness ... shown in Section I`]

#### Distributed losses

- MSE 为 per-pixel loss，各 host 先算 local MSE，再 allreduce。[PDF p. 7, §4.3 MSE, explicit; anchor= `perform an allreduce operation`]
- LNCC 先由 GP 同步 boundary patches，算完 per-pixel similarities 后再 allreduce。[PDF p. 7, §4.3 LNCC, explicit; anchor= `boundary synchronization with its neighboring shards`]
- MI 把 joint/marginal histogram 写成 `N_h/N` 加权的 per-host aggregates，再 allreduce；communication overhead 为 B²+2B，与 N 无关。[PDF p. 7, §4.3 MI, explicit; anchor= `weighted average of these histograms`] [PDF p. 7, §4.3 MI, explicit; anchor= `B² + 2B communication overhead`]

## 8. 结果、统计与不利解释

### 8.1 Clinical pipeline acceleration

**TransMorph LNCC。** non-diffeomorphic row 从 171.20h 降至 27.84h，GPU memory 从 20.01GB 降至 16.95GB，Val DSC 从 86.74 到 87.23；约 6.15× training-time speedup。diffeomorphic variant 同样从 171.42h 降到 27.93h。[PDF p. 9, Table 1, explicit; anchor= `Baseline LNCC ... 171.20`]

**TransMorph MI。** 26.09h 到 24.94h 的 runtime 改善较小，GPU memory 从 22.34GB 到 16.80GB，约 24.8% reduction，Val DSC 基本不变。[PDF p. 9, Table 1, explicit; anchor= `Baseline MI ... 22.34`]

**FireANTs MI。** PyTorch MI 为 `75.88±3.45 Dice, 7.51±0.37s, 12206.3MB`；Ours 为 `75.88±3.44, 2.90±0.16s, 577.5MB`。对应约 2.59× speedup 与 95.3% memory reduction，accuracy center 不变。[PDF p. 9, Table 1, explicit; anchor= `MI PyTorch ... 12206.3`]

**FireANTs LNCC。** FireANTs backend 为 `78.81±3.87 Dice, 1.44±0.08s, 1044.5MB`；Ours 为 `78.67±3.04, 0.50±0.01s, 577.5MB`。Ours 约比 FireANTs backend 快 2.88×，比 FastLNCC 的 3.76s 快 7.52×。[PDF p. 9, Table 1, explicit; anchor= `LNCC Ours ... 0.50`]

这些 rows 的统计边界很明确：表中给 mean±std，却没有 denominator、hardware 或 seed hierarchy。torch.compile LNCC 的 Dice 为 69.35，显著低于其他 LNCC rows；supplied main text 没有解释该 accuracy divergence。[PDF p. 9, Table 1, layout_observation; anchor= `LNCC torch.compile`] [PDF p. 9, §5.1, layout_observation; anchor= `multiple LNCC backends`]

### 8.2 Real 100µm capability

Section 5.2 报告 fixed image `1760×1760×1278`，deformable problem 超过 11.2B optimizable parameters、warp memory 44.8GB；multimodal deformable registration 在 8 A6000 上约 58 秒。Figure 6 用 fixed/moved/moving 切片展示 cerebellar white matter 等细节。[PDF p. 8, §5.2, explicit; anchor= `more than 11.2B optimizable parameters`] [PDF p. 8, Figure 6, explicit; anchor= `1760 × 1760 × 1278`]

### 9.1 Primitive replacement

### 9.2 Ring Sampler weak scaling

对 H GPUs 构造 `700×700×700H`，保持 per-GPU workload 固定。关闭 Ring Sampler 时，每 GPU 保存随 H 增长的完整 moving image；开启后 peak memory 与 H 独立，scaling efficiency 只受轻微影响。这是论文最干净的 mechanism test，因为 predicted state term 和 measured resource curve 直接对应。[PDF p. 10, §5.4, explicit; anchor= `with and without ring sampler`] [PDF p. 10, §5.4, explicit; anchor= `independent of H`]

该结果来自 synthetic finite-H tests。它支持「移除 full-image replication」；对任意 cluster size 的稳定性、网络拓扑或 fault behavior 没有覆盖。正文结论使用 `arbitrarily large`，证据范围应保留这一 empirical boundary。[PDF p. 10, §5.4, interpretation; anchor= `For H GPUs`] [PDF p. 10, §6, explicit; anchor= `arbitrarily large image registration problems`]

GP 被替换为无 boundary sync 的 DTensor。Figure 8b 用 red arrows 标出 fMOST moved image 的 boundary artifacts，正文还报告 labelmap overlap 下降。这个测试识别 halo correctness；main text 没有给 overlap magnitude 或 pair distribution，额外 quantitative visuals 指向 Figures 9–10。[PDF p. 10, §5.4, explicit; anchor= `incorrect boundary synchronization leads to undesirable artifacts`] [PDF p. 10, §5.4, explicit; anchor= `reduces labelmap overlap`]

1. **单一主线。** 将 registration 的 materialized-state bottlenecks 改写为 implicit fused computation，再将 random access 与 convolution neighborhoods 改写为 ring partial sums 和 halo synchronization。[PDF p. 4, §3.1, explicit; anchor= `avoids materializing any additional grids`] [PDF p. 6, §4.1–4.2, explicit; anchor= `boundary synchronization`]
2. **正文保留的决策关键内容。** Eq. (1)–(2)、六个主要 components、Figures 1–8、Table 1、58-second real case、Faux-OASIS metrics、Ring/GP ablations。[PDF p. 8, §5.2, explicit; anchor= `∼58 seconds`] [PDF p. 10, §5.4, explicit; anchor= `Ablation on GP`]
3. **移入 appendix 的内容。** Derivations、pseudocode、dataset/metric details、hyperparameters、profiling、extra results。supplied PDF 缺少这些内容，使 correctness/reproduction audit 不完整；主线的系统判断仍可完成。[PDF p. 4, §3.1, explicit; anchor= `Section H`] [PDF p. 9, §5.3, explicit; anchor= `Section K`]
4. **最有效模式。** 资源核算后立即提出 decomposition 和 asymptotic prediction，再用 matched ablation 关闭因果链。Ring Sampler 的 N/H → memory independent of H 是最清晰实例。[PDF p. 7, §4.2, explicit; anchor= `additional N/H HBM overhead`] [PDF p. 10, §5.4, explicit; anchor= `independent of H`]
5. **最大读者成本与未闭合主张。** real 100µm accuracy 没有 quantitative fiducials；simulated benchmark 承担主要 accuracy claim；64× denominator 与附录推导缺失；11.8B/11.2B 和 Section 5.3 comparator 口径不一致。[PDF p. 9, §5.2, explicit; anchor= `privately annotated fiducial markers`] [PDF p. 2, §1, explicit; anchor= `over 11.8B transform parameters`]
6. **可迁移规则。** 每个 scale claim 都应显式给出 materialized state、local/distributed decomposition、asymptotic cost 和 component-off measurement。四者共同出现时，资源曲线可以承担机制证据。[PDF p. 4, §3.1, explicit; anchor= `costing a total of 9N`] [PDF p. 10, §5.4, explicit; anchor= `with and without ring sampler`]
