## 方法、公式与理论

### 方法的最小逻辑单元

方法动作序列为：`setup_notation → state_problem → define_component → derive → define_component → explain_mechanism → give_intuition → define_component → connect_to_experiment`。

1. §2 定义输入属性图 `G={V,E,X,A}`、节点数 `N`、属性矩阵 `X`、邻接矩阵 `A`、归一化 Laplacian；任务输出是 `C` 个 cluster 的结果。Figure 1 先给 local/global 两支、共享低秩模块和 consistency loss 的总图。[PDF p.2–3，§2 / Figure 1]
2. §2.1 用原图 `A` 为 local view，以 Personalized PageRank diffusion matrix `S` 的稀疏对称版本为 global view。Eq. 1 的 generalized Laplacian filters 得到 `X̃l` 与 `X̃g`；两个不共享 MLP 由 Eq. 2 生成 `Zl` 与 `Zg`。[PDF p.3，§2.1，Eq. 1–2]
3. §2.2 拼接两个视角为 `Z`，以 `K ≪ D` 的 `Λ` 和 latent assignment `Y` 在 GMM 下做 EM；Eq. 3 更新子空间，固定 equal priors 与 isotropic covariances。Eq. 4 用 `Λ̂` 与 posterior `γ̂` 重建，Eq. 5 以 residual `Z̃=Ẑ+Z` 将外部 EM 结果接回梯度路径。[PDF p.4–5，§2.2，Eq. 3–5]
4. §2.3 在 memory bank 中抽样 `M` 个 anchors，分别把每个节点对 anchor 的 cosine-similarity softmax 写为 `p_i` 与 `q_i`；Eq. 6 最小化双向 KL，Eq. 7 平均两视角后交给 K-means。[PDF p.5–6，§2.3，Eq. 6–7]

组件与前文问题的映射清楚：diffusion view 针对局部 message passing 的长程盲点，低秩 GMM 针对 redundancy/noise，共享相似度分布针对两视角 semantic gap。Residual connection 解决 EM 位于 gradient flow 之外的训练连接问题，并由作者解释为保留 local details 与缓解 collapse/over-smoothing。[PDF p.3，§2.1；PDF p.4–5，§2.2；PDF p.5–6，§2.3]

主要结果及其证据边界如下。

1. **主 clustering。** Table 1 的 CoCo 在 Cora 为 ACC 79.36±0.69、NMI 60.71±0.59、ARI 58.76±1.47、F1 77.95±0.72；BAT 为 78.85±0.91、55.00±0.87、53.52±1.15、78.56±1.01。比较对象为九个列出的 baseline，统计口径是 10-run mean ± standard deviation。正文据此宣称多数数据集几乎最佳；p.7 给出 Cora/BAT 的具体提升百分比，但这些百分比与 Table 1 的可见 runner-up 算术不一致，见下文测量分歧。[PDF p.6，Table 1；PDF p.7，§3.2]
2. **组件消融。** Figure 2 以 M1–M5/CoCo 的 grouped bars 支持「M3 优于 M1、M4 优于 M2、去掉 compactness 的 M5 弱于 CoCo」；图中没有逐格印刷数值，也没有明示 error bars。该证据识别组件删除和单视角替代，但没有直接测量 redundancy 或 noise 被移除了多少。[PDF p.7，§3.3 / Figure 2]
3. **一致性损失。** Table 2 的 Cora ACC 为 MSE 77.84±0.67、InfoNCE 75.57±1.16、Consistency 79.36±0.69；作者把 InfoNCE 的相对劣势解释为负样本与超参数敏感。Table 10 在 appendix 扩至全部五个数据集，故主文的三数据集表与附录的两数据集补充共同承担该主张。[PDF p.7，Table 2；PDF p.22，Table 10]

## 最终判断

- **主线：** 两个诊断缺口被压缩为一条先 compact 后 consistent 的表示学习链，图、Eq. 1–7、主表和 loss ablation 都围绕该链安排。[PDF p.2–7，§1–3.3]
- **正文保留：** 任务定义、完整前向/损失公式、框架图、主表、组件消融、噪声/图类型/效率/下游检查都留在正文，便于在不读证明时理解建模和经验目标。[PDF p.2–10，§2–4]
- **附录迁移：** 证明、Algorithm 1、复杂度、实现参数、扩展 baseline/loss/sensitivity/GCF 比较和 related work 都移入 Appendix。该迁移没有阻断主方法理解，却使可复核性和五数据集 loss 结论依赖附录。[PDF p.17–24，Appendix A–K]
- **最有效的写作模式：** Figure 1 先把三段链条可视化，§2 随后按 view extraction → compactness → consistency 对应展开，§3 再按整体结果 → 组件/损失 → 适用性/成本排序。该布局使每个主要组件至少有一项经验性对应。[PDF p.3，Figure 1；PDF p.6–10，§3]
- **最大缺口：** 作者把 low-rank reconstruction 解释为 redundancy/noise removal，也把 global view 解释为 long-range capture；当前实证以最终 clustering、噪声条件和定性图为主，没有直接报告这些中间机制量。另有 Table 1 与 §3.2 的提升算术、Table 7 与“all datasets”文字的内部不一致。[PDF p.7，§3.2 / Table 1；PDF p.9，Table 3；PDF p.10，§3.9 / Table 7]
- **可迁移规则：** 当方法有多个互补组件时，可将每个组件先绑定一个可读的表示变换或损失，再用全模型结果、组件删除和最近替代损失三种对象闭合叙事。
- **规则边界：** 该规则需要各组件能够被独立替换或删除；若组件共同决定同一不可分的优化状态，单独 ablation 不能识别其机制，仍需直接测量或专门设计的 counterfactual。[PDF p.7，§3.3 / Table 2]
