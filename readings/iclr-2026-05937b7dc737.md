## E. 方法与理论

### E.1 单一因果主线

论文的唯一主线是：**以可访问的 vocabulary branch 为局部校正单位，用 branch divergence 度量 target 相对 draft 的 deficit／excess，再把局部无法闭合的质量沿 prefix 层级转移；capped ratio 把已越过 1 的 prefix 截断，使一次 resampling 同时保留 target suffix，最终实现 lossless 且提高 accepted-token expectation。** 证据链为 p.3 的 tokenwise decomposition → p.3–5 的 divergence hierarchy → p.5–7 的 naive 与 capped HSD → p.19–22 的 telescoping proof → p.23–27 的期望长度比较。

### E.5 算法、图与机制粒度

- **Algorithm 1 — Naive HSD（p.5）**：输入 target probabilities `p(·|prefix)`、draft probabilities `q(·|prefix)` 与 `X1:γ`；从 `t=γ` 反向抽 `ηt`，找到最长 accepted prefix `X1:τ`；若 τ<γ，则对 τ+1 到 γ 逐层调用 `Pres` resample。循环层级为 backward scan + recursive resampling；关键不变量是每次局部 resampling 使用对应 branch 的 deficit mass。作者明确指出它需要 `γ−τ+1` 次额外 target calls。
- **Algorithm 2 — HSD（p.5）**：同样 backward scan，但 rejection 后只从 `P*res(·|X1:τ)` resample 一次，并输出 `[X1:τ, token]`；剩余位置由下一 speculative step 继续，因此把额外 target calls 降为一次 branch-level sample。图 1 将 `τ`、`γ`、backward operation、dropped path 与 resampled token 放在一个流程图中。
- **Algorithm 3 — HSD + Recursive Reject Sampling（p.32）**：在 K 条 draft 中只处理与已接受 prefix 相容者；按 `k` 递归选择后缀，反向按 Eq. (19) 验证，若 rejection 则把 `P*res` 设为新的 target distribution 和 ratio，最后采样 token。它承担 multi-draft compatibility；lossless proof 仍由前述理论章节承担。
- §5.3 只说明 vocabulary 与 draft positions 的并行化和相对成本；没有给出完整渐进复杂度定理。Appendix H 补上 `4γV` branch-divergence FLOPs 的拆解。

## H. 消融、负面结果与自我设限

- **组件删除**：Table A.3 直接移除 capping，识别 fidelity／效率 trade-off；HSD+Capping 的 ACC 更高，但 BE／DS 稍低（p.28，`explicit`）。

- **机制替代解释**：EAGLE-3 段落主动承认 top-K 使所有 draft probabilities 为 1，理论上三种 verification 行为退化相同；BE gain 可能受 sampling stochasticity 和 floating-point precision 影响，DS gain 更可能来自去掉显式 loop（p.10，`explicit`）。

- **统计边界**：主文没有误差表达；5 seeds 和 capping 的 mean ± SD 在 p.28 才出现；没有显著性或多重比较（p.9–10、p.28，`explicit`）。
