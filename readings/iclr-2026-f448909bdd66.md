## E. 方法与理论

### E.1 单一因果主线

论文的单一主线是把离线 bidirectional motion-conditioned teacher 通过 guidance-aware DMD 蒸馏为 causal student，并用训练期同步的 rolling KV cache、固定 attention sink 与局部窗口解决长时漂移和上下文成本，最后以 Tiny VAE 把解码瓶颈降到交互速度。这个链条依次回应慢、非因果、短时域和 drift 四个前文障碍，证据集中在 p.4–p.7 与 p.9。

### E.2 形式对象与组件

- 输入是单张 input frame、text condition `c_t` 与 2D motion tracks `c_m`。轨迹来自 50×50 uniform grid，随机抽取约 1,000–2,500 条，ID 经 d=64 sinusoidal positional encoding 得到 `phi_n`。
- Eq. (1) 把可见 track embedding 写入下采样空间位置，`v[t,n]` 表示可见性。track head 先做 4× temporal compression，再用 `1×1×1 Conv3D`，编码后沿 channel 与 video latents 拼接；不复制 DiT blocks。
- Teacher 以 Wan DiT 为基础，使用 rectified flow matching。text 与 motion 的联合 CFG 用 Eq. (2)，作者设 `w_t=3.0`、`w_m=1.5`。teacher 每个 denoising step 需要 3 次 function evaluations。
- Student 从 motion-guided teacher 权重初始化，先用 teacher ODE solution pairs 做 causal architecture adaptation，再做 Self Forcing-style DMD。视频 latent 分成 `L` chunks，每个 chunk 的条件集合包含自身 noisy tokens、`S` 个 sink chunks 和最近 `W` 个历史 clean chunks。
- rolling KV cache 让 local window 固定，sink token 保存初始 anchor，window token 在 cache position 上动态赋 RoPE。训练与推理都滚动 cache，避免长时 rollout 中的 train–test mismatch。
- DMD 的 target real score 复用 teacher 的联合 guidance，fake score 由无 CFG 的 trainable critic 近似，指导代价被蒸馏进 student 单次 function evaluation。generator/critic 更新比为 1:5，随机选 denoising step 并截断梯度，前序 KV 作为 stop-gradient context。

## I. 结论、limitations 与闭环

### I.1 结论段落

结论只有一段，动作链为 `重述问题 → 重述方法 → 回收结果 → 边界/未来工作指向`。它重申 infinite-length interactive motion control、29 FPS、track head/joint guidance、self-rollout、attention sink、rolling KV caches、跨任务 SOTA/速度，并将 limitations、future directions、ethics、reproducibility 指向 Appendix F/G。结论没有引入新数字，但复述了正文与摘要的强主张。

### I.2 Limitations

1. 固定 attention sink 锚定初始 chunk，稳定性换来了 complete scene changes 的适应能力损失。游戏引擎或连续变化环境中，模型倾向保留初始 scene；未来方向是 dynamic attention sinking。
2. 极快或物理不合理的轨迹会产生 temporal inconsistency、object distortion；作者建议 track augmentation 和更大 backbone。
3. 复杂 scene、text prompt 或 intended motion 会损失 source details，主要受 backbone capacity 约束。Wan 2.1 1.3B 在 imperfect flat-grid user trajectories 上有时优于 Wan 2.2 5B，作者将其联系到不同 image-conditioning design。
4. Figure A6 展示 cat/turtle 复杂动作、多人 identity、world exploration 的 deform/translation、identity loss 与新物体/场景变化失败。

## L. 最终判断

1. **单一主线**：用轻量 motion-conditioned bidirectional teacher 提供质量上限，把 joint text-motion guidance 蒸馏进 causal student，再以 attention sink、rolling KV cache、固定局部窗口模拟长时 inference，最后以 Tiny VAE 支撑交互吞吐。证据在 p.4–p.7、p.9。
2. **正文保留的决策关键内容**：Eq. (1)–(4)、teacher/student pipeline、Table 1–4、Figure 3–8、默认 `c3s1w1` 与 `w_t=3,w_m=1.5`，以及 Tiny VAE 后的 FPS/latency。它们直接覆盖速度、轨迹、质量和 drift 机制。
3. **移入附录的细节**：Tiny VAE 训练、VBench/user study、extended ablation、training details、evaluation protocol、failure cases、ethics。迁移使正文保持较短，但让复现、比较公平性和边界判断依赖附录。
4. **最有效的写作/图表/公式模式**：先在 Figure 2 给出两阶段 pipeline，再用 Figure 3 把 attention sink 从观察转成机制，随后以 Table 4 与 Figure 6 做组件/窗口对照；Eq. (2) 的 guidance 与 Figure 4–5 配对，Eq. (1) 的 track head 与 Table 3 配对，形成方法、预测、实验的局部闭环。
5. **最大叙事缺口**：`infinite-length`、`first`、`state-of-the-art` 和 `two orders of magnitude` 的范围超过了直接证据。最长外推为 241 frames，基线、backbone、输入协议并不完全同质，也没有统计不确定性或预注册阈值。
6. **可迁移规则**：每个实时系统主张都应同时给出固定硬件下的 throughput/latency、质量代价、长时外推曲线和组件删除对照，并把训练/评测匹配细节放在可调用的附录。
7. **适用边界**：该规则适用于具有系统速度、质量、稳定性三重 trade-off 的生成模型。若论文主张纯理论保证或只研究静态质量，它需要替换为对应的可证伪对象，不能直接套用 FPS/latency 闭环。
