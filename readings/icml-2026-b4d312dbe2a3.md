## E. 方法与理论

### E.1 形式对象和逻辑单元

- **对象与输入输出**：输入为长度 `L` 的 Cα backbone `x ∈ R^{L×3}`；`q_decompose` 将它确定性地映射为 `n` 个 scale，`x_n=x`；输出是逐 scale 生成的最终 backbone。[p. 4, §3, “x ∈ R^{L×3}”]
- **状态与目标**：状态是此前 scale 的集合 `X^{<i}` 和其上采样版本；`Tθ` 产生 scale-wise embedding `z_i`；flow-based decoder `vθ` 生成 `x_i`。训练目标为按 scale 平均并按 `size(i)` 归一化的 flow-matching squared error。[p. 5, Eq. (4)–(5)]
- **关键假设**：蛋白结构有 coarse-to-fine 层级；沿 sequence dimension 的插值可保留足够 pairwise spatial relationships；共享 decoder 可以通过 scale embedding 区分不同统计分布；NCL/SS 能缓解 teacher-forcing 与推理状态差异。前三项是设计前提或作者解释，最后一项由 Table 3 支持但没有独立理论保证。[p. 5–6, §3.1–§3.3; p. 22–23, §C.8]
- **公式总量**：正文与附录共 7 个 numbered displayed equations，分别为 Eq. (1)–(7)；没有 theorem、lemma、proposition、corollary 或 proof。自动测量草稿的 provisional equation 数为 10，见“测量分歧”。

### F.2 评测协议与复现粒度

- **质量/设计性**：每个长度 50、100、150、200、250 采样 100 个结构，共 500 个；每个结构用 ProteinMPNN 生成 8 个序列（temperature 0.1），用 ESMFold 折叠，记录 8 个预测中的最小 RMSD。designability 是 minimum RMSD <2 Å 的比例，sc-RMSD 是所有样本的平均最小 RMSD。[p. 16–17, §A.2]
- **分布层指标**：每个长度 60–255、步长 5 采样 125 个，共 5,000 个；不做 designability filtering。FPSD 比较 generated/reference fold-class feature 的 Gaussian approximation；fS 结合 sample-level fold confidence 与 fold-distribution entropy。[p. 17, §A.2]
- **多样性、novelty、secondary structure**：designable structures 内平均 pairwise TM-score；Foldseek 对 PDB database 取每个生成结构的最大 TM-score；P-SEA/Biotite 统计 alpha/beta proportions。[p. 17, §A.2]
- **prompt 与 motif**：prompt 任务比较最终结构与 reference 的 RMSD 以及与 16-point prompt 的 TM-score；motif benchmark 每题生成 1,000 个 backbone，固定 motif residues 生成 8 个 ProteinMPNN sequences，再经 ESMFold 判定。[p. 8, §4.2; p. 21, §C.5]
- **报告粒度**：正文给出主要表格、模型规模、训练步数、采样步数和部分样本数；层维度、评测阈值、Foldseek command、长蛋白筛选、self-conditioning 与数据细节放入 A–C。没有报告代码仓库、完整 config 文件、random seeds 或误差区间。[p. 7–11, §4; p. 16–23, Appendix]
- **统计处理**：论文报告 point estimates、均值/比例、RMSE、LDDT、TM-score、FPSD、fS、runtime 和 cluster counts；没有 hypothesis test、bootstrap、Bayesian model、regression、multiple-comparison correction 或 conventional uncertainty intervals。[p. 7–11、p. 16–24, tables and captions, layout observation]

实验顺序与引言贡献大体对应：§4.1 对应 unconditional distribution/quality，§4.2 对应 prompt 与 motif zero-shot，§4.3 对应 scaling/speed/exposure bias/attention，Table 4–5 补充 scale 与 transformer 组件；C.1–C.10 承担长蛋白、self-conditioning、motif、可变 scale、容量、空间关系和时间成本。[p. 6–11, §4]

### H.2 负面结果与限制

- **长度边界**：训练 AFDB 仅覆盖 32–256 residues；长蛋白需要额外 PDB fine-tuning，500–700 residues 的 designability 降到 52%/29%/10%。[p. 18, §B; p. 19–20, §C.3, Table 9]
- **未见 scale 的代价**：删 scale embedding 后用 5 scales 推理，FPSD 仍相对稳定，但 designability 下降到 72.6%，说明分布相似度不足以保证细节质量。[p. 21–22, §C.6]
- **全 ODE 与过少 SDE steps**：全 ODE designability 28%，将最后 scale 变为 2 steps 的 all-SDE 组合 designability 为 0%；只有在 coarse-to-fine 编排下才保留质量。[p. 9–10, Table 2; p. 18, Fig. 7]
- **per-token decoder 失败**：初步 200M AR + 20M MLP diffusion head 的平均 sc-RMSD 为 16，促使作者转向 per-scale Transformer decoder。[p. 22, §C.7]
- **AR 扩大并未带来收益**：AR400/decoder60 仅 87.80% designability、1.26 Å sc-RMSD，低于 AR60/decoder400；作者提出 overfitting/exposure-bias 解释，但没有直接验证。[p. 22, Table 13; §C.7]
- **只生成 Cα backbone**：正文没有 sequence、side chain 或 all-atom generation；conformational dynamics、all-atom、multi-chain 被列为 future work。[p. 1, Introduction; p. 12, §5; p. 24, Appendix E]
- **baseline 与数据可比性**：Table 1 的其余 baseline 结果直接取自 Geffner et al.；PDB fine-tuning 数据集不可公开复现。motif benchmark 中 PAR* 是 zero-shot，其他方法使用额外 motif conditioning 的 fine-tuning。[p. 7, §4.1; p. 16, Appendix A; p. 21, §C.5]
- **统计自足性缺口**：所有表格为 point estimate，未报告 seeds、误差区间或显著性检验；读者不能从正文判断跨 seed 稳定性。[p. 7–11、p. 16–24, layout observation]

## L. 最终判断

1. **单一主线**：蛋白 backbone 的自然层级提供了比 residue-wise 单向顺序更合适的 AR state；确定性 sequence downsampling 将结构变成 coarse-to-fine scales，AR Transformer 汇总此前 scales，shared flow decoder 在连续 Cα 空间逐 scale 生成，NCL/SS 让推理时的自生成 context 进入训练。这个结构链同时解释了空间依赖、连续 fidelity、zero-shot prompt 和 SDE/ODE 编排。[p. 4–6, §3; p. 7–11, §4]
2. **正文保留的决策关键内容**：Eq. (1)–(6)、Figure 1–2、Table 1–5、NCL/SS 训练说明、主要训练/采样条件、2.5× runtime 和 prompt/motif 案例。它们足以让读者理解模型如何工作、比较何时成立以及选择 3-scale 默认配置的理由。[p. 4–11]
3. **移入附录的细节及其影响**：评测阈值与 sample denominator、AFDB/PDB 数据构造、long-protein 退化、unseen scale 失败、per-token decoder sc-RMSD 16、seed 缺失、self-conditioning、Foldseek cluster 和 training time 均在附录。主线仍可读，但 motif 的低成功率、长长度边界和 scale-agnostic 的质量损失只有读完 C.3、C.5、C.6 才能准确界定。[p. 16–24]
4. **最有效的写作/图表/公式模式**：Eq. (1) 先固定 probabilistic decomposition，Figure 1 把 training/inference state 对齐，Figure 2 把 coarse-to-fine 变成可见过程，Table 3 以同一模型顺序展示 teacher forcing → NCL → SS，Table 2 以 runtime/designability 成对呈现 sampling trade-off。这样的安排把抽象 state、机制和决策结果串成一条可检查链。[p. 4, Eq. (1); p. 2–3, Figs. 1–2; p. 9–10, Tables 2–3]
5. **最大叙事缺口**：zero-shot motif 的成功率在 Table 11 中高度异质，且 fine-tuned baseline 与 PAR* 的训练条件不同；主文的“strong zero-shot generalization”没有同步给出这些失败边界。unconditional Table 1 的整体聚合也遮蔽了长蛋白退化与 PDB subset 可复现性问题。[p. 7–8, §4.1–§4.2; p. 20–21, Tables 9 and 11]
6. **可迁移规则**：当一个生成框架把粗粒度状态同时当作 AR context、可控 prompt 和采样 orchestration 的锚点时，应在正文用一张状态图、一条形式分解、一个组件消融和一个成本–质量表分别证明 state、mechanism、capability 与 trade-off；把每个能力的 denominator 和失败边界放在紧邻的补充结果中。[p. 2, Fig. 1; p. 4–6, Eq. (1)–(6); p. 9–11, Tables 2–5]
7. **规则边界**：该规则适用于有明确 coarse-to-fine 状态和可重复评测指标的生成任务。若 downstream capability 需要 sequence/side-chain/all-atom、复杂条件控制或跨数据源因果比较，单一 backbone state 与 point estimates 不足，必须新增对应状态、基线和 uncertainty/seed 证据；本论文将这些方向留作未来工作。[p. 12, §5; p. 24, Appendix E]
