## 6. 方法与理论

### 6.1 形式化对象与假设

Section 3.1 在 p.3 先给出 limit transformer 的统一 forward pass。输入 token xᵢ∈Σ 先与绝对 positional embedding pᵢ 相加；每层由 attention logits aᵢⱼ⁽ˡ,ʰ⁾、多头 residual attention、带 1-Lipschitz activation 的单隐藏层 MLP 和 unembedding U 组成。K、Q、V、Aₗ、Bₗ、bₗ、φₗ,ₕ、Yᵢ⁽ˡ⁾、yᵢ⁽ˡ⁾ 和 T(x)ᵢ 在同一段中被定义（p.3, “The computation of a limit transformer proceeds as follows”）。

为使无限上下文对象可由有限长度恢复，论文沿用三类结构假设。Positional embedding 是 Δ-periodic；φ translation-invariant；φ 是 τ-local，即 i > j + τ 时为零（p.3, §3.1）。这些条件把长前缀压缩为 token/position-mod-Δ 频率，同时保留最近 τ-suffix。

### 6.2 Finite-precision hardmax

Section 3.2 把数值不超过 2⁻ᵖ 的中间量舍入为零。Softmax 先减去最大 logit，再将 post-exponentiation 后不超过 2⁻ᵖ 的项舍零。对 single-layer f，论文构造 attention matrix A，并以 γ(f) 表示可观察最大 logit 与非最大 logit 的最小正间隔。若 N ≥ 2^(p/γ(f))，非最大项满足 sⱼ ≤ 2⁻ᵖ，于是 attention 等价于对 argmax tokens 做 uniform average（p.4, §3.2, “softmax attention acts as a hardmax”）。

### 6.3 Infinite-precision suffix scaling

Infinite precision 下，普通 bounded logits 会使 τ-suffix 的影响随长度趋于零，从而排除 induction head。论文只给 suffix positional logit 加 log i 缩放，形成 Eq. (1)（p.4, §3.3）。由 max φ 相对于 1 的位置关系得到三个 regime。

1. **Token Dominant**：maxₜ≤τ φ₁,ₕ(i−t,i) < 1，长前缀的 empirical token frequency 占主导。
2. **Balanced**：最大值等于 1，token aggregate 与 suffix 同阶。
3. **Position Dominant**：最大值大于 1，suffix positional terms 占主导并集中到最大 φ 的位置。

统一分析把第一层输出写成 suffix 与前缀 histogram 的 bounded/Lipschitz 函数；两层输出依赖 (xᵢ₋τ:ᵢ, μ(x≤i)) 的 empirical joint distribution。论文明确选择 infinite precision 来适配第二层的 continuous mixtures（p.5, §3.3, “tokens are in fact discrete … continuous mixtures”）。

### 6.4 方法动作转移

setup_notation → state_problem → define_component → derive → give_intuition → connect_to_prediction → connect_to_experiment → summarize。具体推进为 limit transformer 与三种 locality/periodicity 假设 → finite rounding 与 margin → hardmax sufficient statistics → infinite precision scaling 与三种 regime → finite precision 的显式 ratio simulation → average case 的 distribution-preserving simulation → two-layer 的 random subset simulation。

### 6.5 两个有限精度结果

**Theorem 4.1（p.5，Section 4）**：对两个满足 τ-local、Δ-periodic、translation-invariant、p-bit finite-precision 的 single-layer limit transformers，令 L=L_f+L_g，γ=min{γ(f),γ(g)}。存在

N = O(max{2^(p/γ), L²Δ⁷|Σ|⁶τ²/ε²})

使得长度 ≤ N 的输入上 ||f(x)−g(x)||≤ε 推出任意长度上 ||f(x)−g(x)||=O(ε)。证明用 hardmax attention pattern 的 token ratio 构造短串 z，显式匹配 f、g 的 attention sufficient statistics（p.5, “preserves these ratios up to O(ε) error”）。

Theorem 4.1 的完整 proof 在 Appendix A.2 展开。无 positional embedding 时先复制两个 attention pattern 的 union；pattern 大时用 Lemma A.4 的整数近似，控制 mₛ/N 与 nₛ/|x|；再用 Lemma A.2、A.3 把 attention state 误差传到 MLP/output。含 positional embedding 时把 vocabulary 扩成 Σ×[Δ]，并为周期对齐额外补最多 Δ 个 token，得到 Δ⁷|Σ|⁶τ² 因子（p.14–20, Appendix A.2）。

正文备注指出 2^(p/γ) 只保证 hardmax threshold；若较短长度已进入 hardmax，剩余训练长度可只按 τΔL²/ε² 缩放（p.6, “the training length N need only scale with…”）。

**Theorem 4.2（p.6，Section 4）**：对 token vocabulary 上的 categorical P=(pₛ)ₛ∈Σ，定义固定长度 n 的 P-平均输出误差，再对 P∼Dir((αₛ)ₛ∈Σ) 取期望，令 α₀=minₛαₛ、α*=Σₛαₛ。存在

N₀ = O(max{2^(p/γ), [16 α*^(α₀⁻¹) L^(2+2α₀⁻¹) |Σ|^(4+2α₀⁻¹) Δ⁵ / (α₀^(2α₀⁻¹) ε^(2+2α₀⁻¹))] log(|Σ|ΔL/ε)})
= Õ(ε^(−2−2α₀⁻¹))

使得 ||f−g||ₙ≤ε 对所有 n≤N₀ 成立时，任意 T 的平均误差为 O(ε¹ᐟ²)（p.6, Theorem 4.2）。

其 proof 将长序列映射为与末端 τ-suffix、长度模 Δ 对齐的最后 N′ 个 token。Lemma A.5 控制 token/position empirical frequencies，Lemma A.9 控制 Dirichlet 中小 token probability，Lemma A.10 控制 simulation 误差。作者指出 iid/Dirichlet regularity 是必要的，支持切换可在任意长处发生的分布没有统一 finite bound（p.6, Remarks）。在条件 min pₛ=Ω(1) 下，作者声称可回到 O(ε) error，但需要更长的 O(ε^(−(2+2α₀⁻¹)) log ε⁻¹) 训练长度。

### 6.6 两层无限精度结果

**Definition 5.1（p.7）** 限定 Fτ 为 depth-2、τ-local、translation-invariant、infinite-precision、第二层无 positional information、φₗ,ₕ≥0 的 transformers，且 ||Eₛ||≤1。复杂度 C(f) 对第一层 V、KᵀQ、MLP 权重给 exponential-polynomial 依赖，对第二层权重、U、τ、|Σ| 给 polynomial 依赖。Positional margin 为每个第一层 head 的最大 φ 与次大值的最小差。

**Theorem 5.2（p.7，Section 5）**：对 f,g∈Fτ，存在

N ≲ (max{C(f),C(g)} ε⁻¹)^(max{γ(f)⁻¹,γ(g)⁻¹,3})

使得长度 ≤ N 的 ε-agreement 推出任意长度的 O(ε)-agreement（p.7, Theorem 5.2）。Proof sketch 先把第一层写成 q_f(xᵢ₋τ:ᵢ, μ(x≤i), i)，再用 Lemma 5.3 的 Markov-chain subset I 保留 suffix/histogram 的 joint empirical distribution。

复杂度中的第一层 weight norm 指数来自 softmax 作为 probability-measure 函数的 Lipschitz 常数。作者承认该依赖是分析中的代价，并引用 Kim et al.、Wang et al.、Castin et al. 说明其他长度相关设置下可得到不同 Lipschitz bound（p.7, Remarks）。

**Definition 5.4（p.8）** 把 in-context k-gram estimator 定义为所有与末端 k−1-gram 相同的前缀后继 token 的 empirical distribution；无匹配 occurrence 时行为任意。Appendix B.3 沿 Nichani et al. 构造 k−1 个第一层 head、第二层 block-identity comparison，给出 C(f)=ε^(−Θ(k²))、γ(f)≥1 的 heuristic，因此训练长度 ε^(−Θ(k²)) 足以 LG。该例把抽象 complexity 与具体 k、S、τ 联系起来。

## 14. 最终判断

1. **单一主线**：把“短训练、长测试”的 LG 转化为两个 limit transformers 的 finite-prefix agreement 问题，再用能保留 forward-pass sufficient statistics 的短串 simulation map 把任意长输入拉回训练长度。Finite precision 通过 hardmax token ratios 实现，infinite precision 两层模型通过 suffix/histogram joint distribution 的 probabilistic simulation 实现。
2. **正文保留的决策关键内容**：形式化 forward pass、periodicity/locality/translation assumptions、Eq. (1) 的 suffix scaling、Theorem 4.1/4.2/5.2 的 bound、三类 regime、k-gram bridge、Figure 1–4 与 future-work boundary。读者可在主文判断主张范围与参数方向。
3. **附录迁移及其影响**：A/B 将计数构造、Dirichlet concentration、Markov-chain variance、q_f Lipschitz 和 C(f) 展开完整化；C 将实现参数和 expressivity sketch 移出正文。正文的机制直觉仍自足，定量常数、假设使用和可复核证明依赖附录，因此 theorem 的接受性成本较高。
4. **最有效模式**：同一 simulation principle 贯穿 precision/depth；机制图 Figure 3 直接检验 hardmax，参数扫描 Figure 1/2/4 检查方向性预测。
5. **最大缺口**：理论是 deterministic/average-case bound，实验只给 synthetic qualitative curves；没有直接估计 C(f)、γ、tightness、误差区间、baseline 或更深层模型。正文 p.9 的 monotonic 结论仍由有限网格视觉判断支持。
6. **可迁移规则**：当主张是“长输入可由短输入模拟”时，应先显式写出被保留的 sufficient statistics，再让 theorem、机制图和实验参数扫描各自对应同一统计对象。
7. **适用边界**：该规则适合有明确 forward-pass state、可对齐 suffix/position、且能把长短输入比较转成 finite statistic 的 sequence models；对非局部位置机制、任意数据分布、训练动态本身或大深度连续表示，本文尚未给出对应保证。
