## 5. 方法与理论

### 5.1 形式化对象与推进

方法/理论的最小动作序列为；

`setup_notation → state_problem → derive → define_component → give_intuition → instantiate_algorithm → connect_to_prediction → connect_to_experiment → contrast_alternative → summarize`。

1. **基线定义（p.3, §3）**；先写 Chinchilla loss `L(N,D)=A/N^α+B/D^β+E`（Eq. (1)），N 是 model size、D 是 training tokens；再写既有 EPM 版本 Eq. (2)，把 `N` 替换为 `N·eff(C)`。这一步把“模型容量损失”和“量化误差”放在同一 loss 体系中。证据；“Existing QAT scaling law ... introducing an effective parameter multiplier”。
2. **缺口推导（p.3, §3）**；由 Eq. (2)−Eq. (1) 得到只依赖 N 的 `δp(N)`（Eq. (3)），并明确指出该写法假设与 D 无关；Figure 4b 的观测否定这一充分性。证据；“previous QAT scaling laws assume the quantization error depends only on N”。
3. **统一模型定义（p.3, §3；p.6, §4.2）**；提出 `L(N,D,G)=A/N^α+B/D^β+E+δp(N,D,G)`（Eq. (4)），再给 `δp(N,D,G)=k·D^γD·(log2 G)^γG/N^γN`（Eq. (5)）。对 G 使用 `log2(G)` 的理由是 G=1（no quantization）时误差为 0；指数表示 N、D、G 敏感性。证据；“We incorporate a logarithmic term for G, as G = 1 (no quantization) yields δp = 0”。
4. **训练实例化（p.4, §4.1；p.18, Appendix F）**；Llama3-style dense models、OLMo2-Mix-1124、74/145/297/595M 与 10/20/50/100B；973M 的 100/200B 用于外推。QAT precision 是 W4A4、W4A16、W16A4；G 是 32/64/128/256/per-token/channel。证据；“These 268 QAT experiments on A100 GPUs consumed 276K GPU-hours”。
5. **变量方向与拟合（p.5–p.6, §4.2）**；Figure 4 先观察 N、D、G 三方向，Eq. (5) 再把方向编码为正指数/负指数；用 80 次 W4A4 runs 拟合，Table 1 给参数，Figure 5 和 973M 验证外推。这里理论是**核心因果链中的描述性 scaling model**，并非 theorem 或一般化保证；拟合准确不等于跨架构因果识别。证据；“We fit Eq. (5) ... obtained from 80 W4A4 QAT runs”。
6. **误差分解（p.6–p.8, §4.3）**；由于在 QAT 训练后直接关闭量化会受参数适应影响，作者训练 W4A16 和 W16A4 两个额外模型，以它们的 loss gap 近似 weight/activation 两部分。Figure 6 的线性系数为 0.906，随后以 `R=δW16A4/δW4A16` 比较贡献。证据；“model parameters adapt to quantization errors during training”。
7. **机制诊断（p.8–p.9, §4.3–§4.4）**；R、kurtosis 和 layer-level 观察把 activation bottleneck 定位到 FC2 Proj input；混合精度把该输入设为 8-bit，作为移除 bottleneck 的上界式 baseline。证据；“FC2 Proj input remains sensitive to outliers”。
8. **替代视角与实践量（p.9–p.10, §4.5；p.19–p.21, Appendix H–I）**；Table 2 比较旧 scaling law 和 Eq. (5)，Appendix H 将 `δp` 代入 EPM 得到 Eq. (11)–(13)，Appendix I 讨论 PTQ、QAT bit-width 与 FQT。EPM 是后置解释和资源权衡指标，并非新训练算法。证据；“EPM serves as a practical metric for evaluating the effective capacity”。

### 7.3 统计方法与不确定性边界

- **聚合单位和分母**；主要是 model-size/data/group-size 的实验 cell；百分比来自特定切片的平均或差值。论文没有写清每个平均的 seed、cell 数分母或是否按参数量加权（p.5–p.8）。
- **中心量/离散量/区间**；报告 loss gap、均值式百分比、比值 R、kurtosis、MSE、relative error、拟合指数 γ；未报告标准差、标准误、bootstrap、Bayesian posterior 或 conventional confidence interval（p.5–p.10、p.14–p.21）。
- **拟合**；Appendix C 明确 Chinchilla 参数用 predicted/observed log loss 上的 Huber loss 与 L-BFGS，且设 α=β；QAT Eq. (5) 的具体 optimizer 没有在正文重复说明，Table/Figure 给出点拟合误差（p.14–p.15）。
- **假设检验/多重比较**；未报告 hypothesis tests 或 multiple-comparison adjustment。量化器、precision、D 的对照是描述性 ablation。
- **统计判别 vs 实质意义**；论文以误差百分比、R 和层级 kurtosis 作为实质决策量；没有把统计判别与机制证据分开检验。FC2 bottleneck 的因果支持来自 8-bit intervention 与 outlier 对照，但只在一个 Llama3-style/OLMo2 体系中完成。
- **图注独立性**；Figure 4、7、9、Table 1–4 的标题/注释能解释变量和部分设置；Figure 5、10–13 的 MSE/R2 足够定位拟合对象，但没有不确定性说明。Figure 16 的 caption 截断式语句“significantly improve the EPM with”未完整表达条件（p.20）。

### 9.3 论文单一主线

单一主线是；**把低比特 QAT 的性能损失从只依赖模型容量的 EPM 视角改写为直接的 quantization-error scaling law，使 N、D、G 三个因素可在同一函数中拟合；再用 W4A16/W16A4 分解和 FC2 outlier intervention 把总误差从描述性趋势推进到可行动的 precision allocation。** 这条主线的证据链为 Eq. (3) 缺口 → Eq. (4)–(5) → Figure 4/5/Table 2 → Figure 6–9 → Appendix H/I。页码证据；p.3、p.5–p.10、p.19–p.21。

## 11. 用词与修辞

对正文 p.1–p.10 做人工清洗后（排除 references、公式碎片、图表数值和固定模板词），最高频实词集中在；`quantization`、`error`、`QAT`、`model`、`training`、`scaling`、`law`、`size`、`tokens/data`、`activation`、`weight`、`group/granularity`、`precision`、`outliers`、`FC2/input`。最稳定的二元词组是 `quantization error`、`scaling law`、`model size`、`training tokens`、`activation quantization`、`quantization granularity`、`weight quantization`、`group size`；三元词组是 `activation quantization error`、`weight quantization error`、`number training tokens`、`FC2 Proj input`。

- **主张动词**；`show/shows`、`propose`、`demonstrate`、`find`、`observe`、`indicate`、`suggest`、`confirm`。`show` 和 `observe` 多用于 Figure 4–9 结果，`demonstrate` 用于 FC2 mixed precision 和拟合，`suggest` 用于 future algorithm implication。
- **限定词**；`typically`、`often`、`especially`、`primarily`、`mainly`、`nearly`、`consistently`、`likely`、`for simplicity`、`in most cases`。限定词主要出现在 prior-work 归纳、FC2 诊断、代表性切片和 EPM 解读。
- **对比/因果词**；`however`、`in contrast`、`unlike`、`therefore`、`as a result`、`because`、`due to`、`while`。最重要对比是 prior EPM law→直接 δp，W4A16↔W16A4，W4A4↔FC2 8-bit。
- **贡献结构**；`unified`、`empirical validation`、`decomposition`、`bottleneck analysis` 复现摘要和引言贡献标题；这些是论文叙事模板词，也是实际结果组织的四个阶段。
- **强/弱主张**；强动词（`show/demonstrate/confirm`）用于 N/D/G 趋势、R、FC2 intervention 和 Table 2；弱化词（`suggest/likely/could/be valuable`）用于 outlier 机制的一般化、未来 ternary/MoE 和 FQT。由于没有正式检验，动词强度没有与 uncertainty reporting 配套。
- **词频驱动因素**；高频领域名词真实反映三变量与分解主线；`unified/practical/important` 等模板/影响词较少，主要出现在引言、结论和 Appendix H/I 的实践段。

## 12. 最终判断

1. **单一主线**；直接拟合 W4A4 QAT 与 BF16 的 loss gap，并显式加入 N、D、G；分解和 FC2 8-bit intervention 解释何时 activation/weight 是主要限制（p.3、p.5–p.10）。
2. **正文保留的决策关键**；Eq. (5)、Figure 4–9、Table 1–2、268/80-run 规模、FC2 的 kurtosis 与 8-bit reduction、prior law relative-error comparison，以及结论中的 equal-contribution implication（p.4–p.10）。
3. **移入附录的细节及代价**；Huber/L-BFGS Chinchilla fit、六种模型的完整架构/超参、量化器公式和 ablation、FP4、contour algebra、EPM derivation、D ablation 被移到 p.14–p.21。迁移保留了正文叙事速度，但使不读附录的读者无法核验 baseline fit、复现训练和 EPM cost assumption。
4. **最有效的模式**；先以 Figure 4 的三方向切片建立可视化 prediction，再用单一 Eq. (5) 和 Table 1 统一参数，随后 Figure 6–9 以 paired precision 和 layer intervention 把 scaling pattern 推到机制/行动建议；Table 2 用一列 law 数量和 relative error 结束比较（p.5–p.10）。
5. **最大叙事缺口**；973M 外推被称为 consistently accurate 但无数值区间；“primary bottleneck”依赖一个 dense Llama3-style/OLMo2 体系、少量 architecture/quantizer 选项；seed、重复、跨数据集/架构和真实部署代价没有报告。证据位置 p.4、p.6、p.9、p.14、p.18。
6. **可迁移规则**；若主张是多因素 scaling law，应先用单一函数给出变量方向和可证伪外推，再用保持其他变量不变的 component/precision intervention 分解机制，并把每个决策变量的消融放在同一误差尺度上（本论文 p.3–p.10、p.21）。
7. **规则边界**；该规则适用于有明确连续资源变量、可定义 matched loss gap、且能构造 component-isolating runs 的训练研究；若模型架构、数据分布或部署 kernel 改变，Eq. (5) 的指数与 intervention 结果必须重新验证，不能把拟合形式当作普适定律（本论文 Appendix A p.14；Appendix H p.19）。
