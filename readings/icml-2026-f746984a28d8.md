## 方法与理论：从字典到训练循环

### 形式对象和逻辑单元

1. **设置。**目标为可点查询的 `π(x)=R(x)/Z`；前向 hierarchical model `\vec p_θ(x_{0:N})` 与固定反向核 `\cev p` 给出 HVI 路径空间问题。(1)–(4) 定义链、联合、边缘和反向分解。[PDF p. 2，§2.1，(1)–(4)，explicit]
2. **HVI 到 MaxEnt RL。**将 state 取为 `(n,x_n)`，用 (5) 定义逐步奖励、用 (6) 给出熵正则 RL 目标；作者写明其等价于最小化路径空间 reverse KL。[PDF p. 3，§2.2，(5)–(6)，explicit]
3. **训练目标。**`F_n^φ` 是 exponentiated soft value / flow；SubTB (7) 与 TB (8) 让 flow、policy 对应路径一致性。作者明确指出 TB 不学习中间 flow，SubTB 在所有子路径为零时使中间 flow 与前向边缘成比例。[PDF p. 3，§2.2，(7)–(8)，explicit]
4. **SMC/AIS 字典。**(9) 给出增量权重，去掉 resampling 后的 (10) 是 AIS，(11) 是 geometric annealing。§3.1 利用 log-weight 与 TB/SubTB 的平方项的对应，把 `\vec p_θ` 作为 proposal、`F_n^φ` 作为 twisted intermediate target。[PDF p. 4，§2.3，(9)–(11)；PDF p. 5，§3.1，`Policies and Flows...`]
5. **行为策略循环。**SMC 的加权 terminal samples 经过固定 `\cev p` 反向补全为轨迹；这些 off-policy trajectories 与 on-policy rollout 混合训练。Figure 1 把 flows、policies、SMC 和 IW Buffer 的数据流画成闭环。[PDF p. 5，§3.2，`The current sampler...`；Figure 1]
6. **历史样本。**(12)–(13) 将 batch normalising-constant estimate 与 batch 内 self-normalised weight 相乘，再按最终权重从 buffer 取 terminal state。[PDF p. 5–6，§3.3，(12)–(13)]
7. **稳定化。**(14) 定义 `ESS`，(15) 选择维持 `ESS ≥ γK` 的最大 `λ`；文中明示 tempering 降低方差却引入 bias。adaptive resampling 使用 `κ`，diffusion-specific parameterisation 放在 Appendix E。[PDF p. 6，§3.4，(14)–(15)，explicit]

动作转移为：`setup_notation → derive → define_component → explain_mechanism → instantiate_algorithm → connect_to_experiment`。核心因果链是「路径一致性目标定义 proposals/flows → SMC 以它们产生更接近 target 的 terminal samples → 反向轨迹成为 off-policy training data → 更新后的 sampler 改善后续 SMC proposal」。这一链条由方程、Figure 1 和 Algorithms 1–7 共同承担，不以单一定理承担。[PDF p. 3，§2.2；PDF p. 5，Figure 1；PDF p. 19–21，Algorithms 1–7]

### 主要结果与不利解释

1. **多模态 continuous target。**在 gradient-free GMM40 `d=5`，`TB/SubTB + SMC + IW-Buf` 的 EUBO 是 `2.3±0.1`、Sinkhorn 是 `83.3±10.1`，相对 `TB + IW-Buf` 的 `1183.3±54.7`、`2813.9±133.1` 显示明显差异。该比较的统计处理仅为 5-run mean±SD，无显著性检验。[PDF p. 7，Table 1]
2. **gradient-based multi-mode cases。**Robot4 中组合方法的 MMD / Sinkhorn 为 `0.103±0.110` / `0.39±0.44`，Table 2 的 TB 为 `0.424±0.001` / `1.72±0.01`。同一表的 GMM40、MoS、ManyWell 并非每个指标都由同一方法最优，故「improves performance」应限于表中的 target–metric 对，而非统一 dominance。[PDF p. 7，Table 2]
3. **learned flow 消融。**Figure 2 的 2D GMM40 图将 `Learnt β_n^φ + \tilde F_n^φ (Ours)` 与 ground truth 对齐；Table 3 的 GMM40 `d=50` 给出其 MMD `0.035±0.001`、Sinkhorn `3579.2±163.4`，而 no-interpolation 为 `0.040±0.000`、`4622.4±249.3`。固定 linear/cosine setting 有 `×`，所以该图表也报告了不稳定性。[PDF p. 8，Figure 2、Table 3]
4. **buffer 消融。**Table 4 比较 uniform、reward-prioritised、loss-prioritised 和 IW buffer；在 GMM40 `d=5` 的 SMC 行，IW-Buf EUBO 为 `2.3±0.1`，其余 buffer variants 从 `30.12±18.63` 至 `5062.6±4758.2`。ManyWell 和 GMM50 的效应较小或依 metric 而变，读者应保留 target-specific 解释。[PDF p. 9，Table 4]
5. **ALDP 与离散延伸。**ALDP 中 `TB/SubTB + SMC + IW-Buf` 取得 ELBO `-180.3±1.9`、EUBO `-166.0±0.8`，对照中若干训练直接 `×`；作者仍写明结果「not fully satisfactory」和有 substantial room for improvement。离散 Table 8–9 中 IW-Buf 在四个任务的 EUBO 均低于 TB 行，但证据位于 appendix。[PDF p. 28，Table 7；PDF p. 29，H.1；PDF p. 30，Tables 8–9]

## 消融、负面信息与自我设限

主文消融由 Figure 2、Tables 3–4 组成；appendix 以 Table 6、Figures 7–9 扩展为 loss design、tempering、subtrajectory length 和 off-policy ratio。Figure 3–6 与 Figure 10 是 `first seed run` 的定性图，非 5-run 聚合图；该选择有明确说明，不能替代对应表格的分布统计。[PDF p. 8，Figure 2 / Table 3；PDF p. 9，Table 4；PDF p. 25，G.1；PDF p. 29，Figure 10]

- `γ=0` 关闭 tempering，`γ=1` 使权重均匀；过高 `γ` 稀释 importance weighting，过低如 `0.0/0.01` 可 mode collapse 或不稳定。作者主实验设 `γ=0.05`。[PDF p. 26，G.3]
- 更小 `L` 通常较好，但 partial energy 需要每 `L` step 评估 `R`，存在直接计算代价。[PDF p. 26，G.4]
- `I≥5` 会劣化表现并可能导致不稳定；主实验设 `I=2`。[PDF p. 27，G.4]
- ALDP 不使用 target gradient 时结果尚不满意；作者加入有限步 MCMC augmentation，同时明确小迭代数用于避免把收益完全归因于 MCMC。[PDF p. 28，H；PDF p. 29，H.1]
- 全文没有名为 `Limitations` 的章节；未来工作把 limitation 组织为更好的 SMC target、其他 flow-learning objective / MC corrector，以及向高维或新应用迁移。Impact Statement 仅称没有需特别强调的社会后果。[PDF p. 9，`Future work`、`Impact Statement`]

## 最终判断

1. **单一主线。**论文把 sampler 的 policy/flow 重新解释为 SMC proposal/twisted target，让 SMC 反过来供应 off-policy trajectories，再以 TB/SubTB 和 importance-weighted replay 改善这个 proposal—behaviour-policy 闭环。[PDF p. 5，§3.1–§3.3；Figure 1]
2. **主文保留的决策关键。**主文保留问题字典、SMC 权重、训练闭环、两个 benchmark 总表、learned-flow/buffer 消融和结论；读者可据此判定核心机制与主要连续空间证据。[PDF p. 2–9，§2–§5]
3. **迁移到附录的细节。**生成过程、algorithm listing、hyperparameters、sensitivity、ALDP、离散序列和大部分定性图被放到 Appendix B–I。该安排没有阻断主线理解，但摘要所称的 discrete/ALDP 覆盖需要附录才能审查，故正文自足性在这些任务上是 `partially_closed`。[PDF p. 6，§4；PDF p. 16–30]
4. **最有效的写作与视觉模式。**p. 2 的三段贡献预告先给统一字典、再给训练循环、最后给验证范围；p. 5 的 Figure 1 将对象与更新箭头集中到一张图；p. 7–9 用总表后接正交消融，形成机制—结果交替。[PDF p. 2，Introduction；PDF p. 5，Figure 1；PDF p. 7–9，Tables 1–4]
5. **最大读者成本。**理论无正式 theorem/proof，关键应用结果位于很长的 appendix，且部分 benchmark 优势随 target/metric 改变；因此全局效能主张应按报告的 task–metric 条目读取。GMM40 gradient-based dimension 的 `R^40` / `d=50` 内部冲突也应在复现前澄清（`uncertain`）。[PDF p. 7，§4.1 / Table 2；PDF p. 22，F.1]
6. **可迁移规则。**当新方法依赖多个已有范式时，先在主文用同一可计算对象建立字典，再让每个组件对应一个可隔离的总表或消融；算法细节和广覆盖案例可留附录，但正文应明确调用路径。[PDF p. 2–9，§2–§4；PDF p. 16–30]
7. **适用边界。**该规则适合有明确对象映射、可运行对照和页数约束的算法论文；如果创新是定理本身、风险边界或实际部署约束，证明、failure analysis 或 constraint specification 需要留在主文承担决策职责。[PDF p. 3，§2.2；PDF p. 9，Future work]
