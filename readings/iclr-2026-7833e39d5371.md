## 4. Related Work

Related Work 是独立第 2 节，跨 pp.2–3，约 600 词，分为 `Low-Rank Adaptation` 与 `Low-Rank Pre-Training` 两个小节。引用簇按问题/方法组织，而非严格 chronology；主要比较维度是 fine-tuning vs. pre-training、weight/update factorization vs. optimizer-state compression、periodic projection vs. online adaptation。

1. `taxonomy`（p.2–3）：PEFT/LoRA 家族；列出 LoRA、LoRA+、DoRA、LoFT、LoRA-Pro，说明差异分别是 differential learning rates、magnitude/direction decomposition、projected-gradient equivalence。
2. `gap_creation`（p.3）：把 fine-tuning 的 intrinsic low-rank 假设与 random-initialized pre-training 的 full-rank requirement 对照，导出现有 LoRA 直接用于 pre-training 的 mismatch。
3. `taxonomy`（p.3）：低秩预训练按 optimizer-state compression 归类，涵盖 GaLore、Flora、Fira、MLorc、MoFaSGD、ADAPM 等。
4. `limitation_of_prior`（p.3）：指出 projection-based 方法周期更新 subspace 造成 discontinuity、lag 和 error accumulation。
5. `nearest_neighbor_contrast`（p.3）：承认 MLorc 的 randomized SVD、MoFaSGD 的 factorization、ADAPM 的 linear regression，但把 LoRA-Pre 定位为「直接以 online gradient flow 演化 factors」；其新意在连续更新，不是首次使用 low-rank momentum 或 regression 词汇。

该节没有再展开 Adam/Muon 的公式，也没有重复实验结果；正文后续通过 Table 1–3 再次引用 GaLore/Fira/Muon 等作为比较对象。相关工作没有给出逐项性能或复杂度对照表，定位作用强于系统综述。

## 5. 方法与理论

### 5.1 方法边界与机制

Method 的正文核心跨 pp.3–6。首先以 Adam 式 (2)–(6) 固定输入 `g_t`、状态 `m_t,v_t`、参数 `θ_t`、`β_1,β_2,γ,ε`；随后把一阶 EMA 改写为在线梯度下降：

- 式 (7)–(8) 将 `m_{t+1}=βm_t+(1−β)g` 写成 `m_t−(1−β)(m_t−g)`；在线目标是式 (9) 的 `1/2‖m−g‖_F²`。
- 第一动量以 `m=m_Bm_A`、`m_B∈R^{p×r}`、`m_A∈R^{r×q}` 因子化，目标为式 (10)。Theorem 3.1 采用 Newton；相较普通 back-propagation，它给出式 (11)–(12) 的闭式因子更新；内存从 `p×q` 变为 `(p+q)×r`。
- 二阶动量先尝试式 (13)–(14) 直接拟合 `g²`，但不能保证元素非负；再用 `v=(v_Bv_A)^{◦2}` 和 `|g|` 的回归目标式 (15)，得到式 (16)–(17)，使平方根合法。
- 图 1 将「EMA → online linear learner → low-rank factors → online gradient flow」画成单一闭环；正文明确算法细节移至 Appendix B。

### 5.2 理论对象与适用边界

独立理论结果/证明清单按 PDF 语义共 6 项（不把 Appendix A 对 Theorem 3.1 的复述当作新命题；Assumptions 1–3 是前置假设而非命题）：

1. **EMA–online regression equivalence（式 (1)、(7)–(9)，p.2/p.4–5）**：在平方 Frobenius loss 下，EMA 是 online gradient step；这是方法核心解释，不是独立收敛保证。
2. **Theorem 3.1（p.5；Appendix A 复述 p.13）**：假设两因子 full rank，factorized least-squares 的 Newton direction 给出式 (11)–(12)；角色为 `core_chain`。
3. **Proof of Theorem 3.1（Appendix A，pp.13–14）**：先求梯度式 (20)–(21)、块 Hessian 式 (22)–(23)，再解 vectorized Newton systems 式 (24)–(25)，代回得到 (26)–(28)；角色为 `guarantee`/推导支撑。
4. **Lemma C.1（pp.18–20）**：在 bounded gradients、subspace residual 和 `β_1=(1−γ_1)^2` 下，重构误差 `E_t^m=‖m_t−\hat m_t‖_F` 有有限 steady-state bound，式 (53)–(63)；角色为 `guarantee`。
5. **Lemma C.2（pp.20–21）**：有效一阶误差由 `β_1E_bound` 控制，二阶误差还包含 squaring 引入的 intrinsic variance `σ_total²`，式 (64)–(77)；角色为 `guarantee`。
6. **Theorem C.3（pp.21–22）**：在 Assumptions 1–3 和 `η_t=η/√t` 下，LoRA-Pre Adam 的期望梯度范数收敛到由 `E_bound` 与 `σ_total²` 决定的 stationary neighborhood，式 (78)、(86)；角色为 `guarantee`，不是收敛到精确 stationary point 的保证。

Appendix C 的三个前置假设不可省略：Assumption 1 要求 `f` L-smooth、`g_t` 的 Frobenius/infinity norm 有界并使用 `ε`-smoothed update；Assumption 2 同时要求梯度方向和 `|g_t|` 能被 factor subspaces 以残差 `δ` 近似；Assumption 3 假设 full-rank Adam direction 在期望上与真梯度对齐。理论因此只覆盖具有双重低秩结构且以 standard Adam 为 descent reference 的设置，并未证明 LoRA-Pre 与 full Adam 轨迹相同。

## 6. 实验设计

### 6.1 预训练

- **问题/安排**：从 scratch 训练 Llama architecture 的 60M、130M、350M、1B 模型，比较 full optimizer、projection/low-rank optimizer 和 LoRA-Pre；主要指标是 hold-out C4 validation perplexity（越低越好）。没有预先列出形式化 H1/H2，但 4.1 的比较顺序与引言贡献一致。
- **数据与规模**：C4；training tokens 分别为 1.1B、2.2B、6.4B、13.1B，正文称没有 repetition。Table 1 给出 `r/d_model` 分别为 `128/512`、`256/768`、`256/1024`、`512/2048`。
- **方法/基线**：Adam、Muon、GaLore、Low-Rank、LoRA、ReLoRA、SLTrain、LORO、Fira；低秩方法默认建立在 Adam foundation 上，另测 LoRA-Pre Muon。Fira 行带 `*`，表示作者自行复现。
- **实现条件**：LoRA-Pre 默认作用于 attention 与 MLP 参数，其余参数用 standard Adam；rank 为 128/256/256/512；learning rate 从 `{0.01, 0.005, 0.001, 0.0005, 0.0001}` 按 validation perplexity 选；scale factor 固定为 GaLore 的 0.25。
- **缺失项**：正文/附录未给每个方法的随机种子、GPU 型号、总 wall-clock、每步 FLOPs、完整 batch/sequence length 或独立重复数；未报告 error bar/置信区间或统计检验。因此结果是点估计比较，不是跨 seed 的不确定性估计。

### 6.2 Fine-tuning

- Llama-3.1-8B 与 Llama-2-7B 在 MetaMath100k（100k subset）上 fine-tune，测试 GSM8K 与 MATH-500；rank=8、learning rate=2e−5，作者称各方法保持 identical hyper-parameters/training configurations。
- Baselines：LoRA、rsLoRA、DoRA、GaLore，以及 GaLore Muon、LoRA Muon；LoRA-Pre Adam/Muon 分别对照同类 optimizer。
- 设计只覆盖两个数学 benchmark、两个 base models 和一个训练子集；未提供多 seed、训练曲线、memory bytes 或 time 结果，因而“memory-efficient”主要由参数化/状态结构和 rank 设定支撑，而非实测 memory table。

## 8. Ablation、负面结果与自我设限

### 8.1 消融对象

1. **Rank sensitivity（正文 pp.8–9，Figure 2）**：删除/改变的是 rank，不是组件；识别 rank efficiency、低秩预算和连续 subspace adaptation 的作用。结论是 LoRA-Pre Adam rank=16 可匹配 GaLore 更高 rank，但没有独立 memory-byte 对照。
2. **Rank trajectory（Figure 3，p.9）**：改变 Muon rank，识别早期劣势是否会随训练消失；曲线显示快速收敛靠近，但无重复/方差。
3. **Optimizer transfer（Table 3，p.9）**：将 GaLore/Fira 适配到 Muon，并与 Muon upper bound、Muon w/o momentum lower bound 比较；识别方法是否依赖 Adam。结果支持 LoRA-Pre Muon，但 projection baseline 的适配实现是作者改写的。
4. **β–γ coupling（Appendix D，p.23，Table 4）**：改变 β1/β2，识别解析耦合和极端 decay 对动态 subspace adaptation 的敏感性。β1=.90/.95/.99 的 perplexity 为 32.57/37.62/1458.92（后者 Diverged）；β2=.90/.95/.999 为 34.61/32.57/1301.58（后者 Diverged）。

### 8.2 负面结果与局限

- 负面结果被明确展示：Low-Rank baseline 在 1B 达到 142.53；GaLore/Fira Muon 在 Table 3 差于 Muon w/o momentum；β1=.99、β2=.999 标记 Diverged。作者没有删去这些行，而是放在主表/附录敏感性表中解释。

- 没有独立 `Limitations` 小节，也没有讨论环境、部署、伦理或广泛影响；Appendix E 仅披露 LLM 用于 paper-writing assistance，且未用于 results/proofs/analysis without human verification。

## 12. 最终判断

1. **单一主线**：把 EMA momentum 视为在线平方损失回归，再用 Newton 更新的低秩因子连续逼近 optimizer state；连续 subspace adaptation 被用来解释在较低 rank 下仍能保持训练性能。
2. **正文保留的决策关键内容**：EMA 等价式、第一/二动量的 positivity 处理、Theorem 3.1 的最终 update、rank/模型/数据配置、Table 1–3、Figure 2–3 和跨 Adam/Muon 的对照。它足以让读者判断方法与主要相对结果。
3. **移入附录的细节及代价**：Newton proof、两个完整算法、误差递推、三个假设、收敛 theorem、β–γ sensitivity。证明和复现依赖附录；正文没有直接给出 state bytes、wall-clock、seed 或 convergence-bound 验证。
4. **最有效的模式**：Figure 1 将数学等价与压缩路径放在同一图；Table 1 以四个 model scales 让 rank/scale claim 可扫读；Figure 2 把“rank efficiency”变成同轴比较；Muon Table 3 用 upper/lower bound 暴露 optimizer transfer 的差异。
5. **最大叙事缺口**：摘要/正文把“highest/consistently outperforms all”写成全配置强 claim，但 Table 2 的单项 MATH-500 有明确例外；Table 3 的“second-best gap”数值口径也不能完全由表面值复算。理论收敛保证依赖同时低秩的梯度与 magnitude 假设，未在实验中检验。
6. **可迁移规则**：当提出 optimizer-state compression 时，先画出 state 的等价学习问题，再用同一图/表同时报告 compression budget、动态适配机制和 full/low-rank matched controls；aggregate improvement 必须与逐任务结果并列。
7. **规则边界**：该规则适用于有显式状态更新和可定义压缩预算的优化器；若状态不是矩阵、没有清晰等价目标，不能直接把“在线回归”或低秩 rank efficiency 当作机制结论。若只有单次点估计，也只能声明 observed comparison，不能外推为普遍稳定性。
