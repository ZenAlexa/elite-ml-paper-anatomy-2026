## 7. 结果、统计与可视化

### 7.1 统计口径

所有 Table 1–4 数值均为 descriptive point estimates。Table 1–3 的 `Average` 是四个任务列的未加权算术平均；例如 Qwen3-4B Plan-Answer 的 `(84.4+52.6+26.0+72.2)/4=58.8`，TTFR 的四任务平均为 516。论文没有报告 seed/task-level variance、error bar、bootstrap、Bayesian posterior、hypothesis test、multiple-comparison correction、regression 或 correlation。Table 4 给出 rewind 子集的 prompt 分母，但 `Rewounded P@1` 的总体/子集分母未定义。

`pass@1` 的分母是各 benchmark 的 prompt 数，含义为第一次尝试得到 fully correct solution 的比例；coding 的 unit-test pass rate 是通过的 ground-truth tests 占总 tests 的比例。TTFR 是 first visible plan 前的 thought-token 数，T/P 是每题内部 thought 与 user-facing output 的平均 token 数。正文虽定义 unit-test pass rate、T/P 与 helpfulness，却未在主要表格报告这些结果。

### 7.2 主要结果清单

#### Table 1：Plan-Answer 与 Think-Answer

- `Qwen3-4B`：TA 平均 P@1 56.9、TTFR 1419；Plan-Answer 58.8、516。四任务 P@1 为 TA `[82.8, 50.8, 25.4, 68.4]` → Plan `[84.4, 52.6, 26.0, 72.2]`，TTFR 为 `[1492,1298,1542,1345]` → `[628,523,484,428]`。
- `Qwen3-8B`：TA 平均 P@1 59.0、TTFR 1538；Plan-Answer 61.6、520。四任务 P@1 `[83.0,54.5,28.0,70.6]` → `[85.2,56.8,28.0,76.4]`，TTFR `[1587,1417,1684,1463]` → `[625,554,457,443]`。
- 相对 TA，平均 P@1 提升分别为 +1.9 与 +2.6 个百分点；平均 TTFR token 降幅约 63.6% 与 66.2%。No Thinking TTFR 为 0，但平均 P@1 仅 52.4/54.8，构成低延迟下限而非完整质量对照。

不利解释是 TTFR 仅为 token proxy，且没有方差或真实时间；Plan-Answer 的收益可由格式变化、训练数据和 token budget 同时造成，Table 1 没有隔离这些因素。任务级列仍保留，因此平均列对异质性的掩盖有限。

#### Table 2：计划级反馈与答案级重启

- `Qwen3-4B`：Plan-Answer 平均 58.8/516（P@1/TTFR）；Best-of-N(5) 61.1/556；R&R Plan 61.8/546；R&R Answer 60.5/3169。R&R Plan 相对 Plan-Answer 平均 +3.0 个百分点，MATH500 84.4→86.8，TTFR 628→578；相对 R&R Answer 的 MATH500 TTFR 为 4079→578，约 7.1×。
- `Qwen3-8B`：Plan-Answer 61.6/520；Best-of-N(5) 63.3/613；R&R Plan 64.8/571；R&R Answer 63.6/3348。R&R Plan 相对 Plan-Answer 平均 +3.2 个百分点，MATH500 85.2→89.4，TTFR 625→611；相对 R&R Answer 的 MATH500 TTFR 为 4279→611，约 7.0×。
- Table 2 与“无需额外训练”的主张一致：方法和 baseline 都在同一 RL-trained interleaved model 上做 inference-time control；但 judge 产生的额外计算、T/P 与 wall-clock 未报告。

Plan-level intervention 的机制证据比 answer-level restart 更贴近论文主线：plan 在 subsequent thoughts 之前被评估，R&R 可把 rejection history 传回下一候选。因果范围仍受 LLM judge 的外部视角与未测量 judge latency 限制。

#### Table 3：token-budget ablation

当 context window 从 4096 增至 8192 时：

- Qwen3-4B 平均 P@1：TA 56.9→59.8，Plan 58.8→60.9，R&R Plan 61.8→62.2。
- Qwen3-8B 平均 P@1：TA 59.0→63.5，Plan 61.6→64.5，R&R Plan 64.8→65.4。
- R&R 的平均变化仅 +0.4/+0.6 个百分点，支持“接近 4K 饱和”的描述；TA 在 8B 上 +4.5 个百分点，说明长 reasoning 仍能改变结果。

这项消融识别的是 context-budget scaling 与 token efficiency，尚未拆除 plan、format reward 或 rejection history 任一组件。因而“interleaving regularizes reasoning depth”的机制解释有对照支持，但没有 component deletion 的因果识别。

#### Table 4：rewind 频率与批准率

| 指标 | MATH500 | MBPP | Text-to-SQL | QuaLITY | Average |
|---|---:|---:|---:|---:|---:|
| Plans needing rewind | 120/500 | 55/257 | 60/250 | 40/250 | 22.4% |
| First rewind approved | 60.8% | 54.5% | 63.3% | 67.5% | 61.5% |
| Second rewind approved | 25.8% | 18.2% | 21.7% | 17.5% | 20.8% |
| Rewounded P@1 | 86.6% | 72.7% | 85.0% | 82.0% | 81.6% |

Table 4 支持“多数 initial plan 不需要多次 rewind，超过 80% 的纠正可在两次内完成”的方向性判断。其分母不完整：`Plans needing rewind` 的加权比例为 `(120+55+60+40)/(500+257+250+250)=21.9%`，不等于显示的 22.4%；未加权四项平均为约 21.9% 也不等于 22.4%。`Rewounded P@1` 没有说明是所有 prompt、rewound prompt 子集还是特定模型，且 MATH500 的 86.6% 与 Table 2 的 Qwen3-4B R&R Plan 86.8% 不能直接对齐。它更适合作为机制诊断，而非完整总体效果估计。

### 11.2 中性、可验证的呈现策略

## 13. 最终判断

1. **单一主线**：把 reasoning 中最早可行动的内容固定为短 plan，并让它在完整 thought rollout 前接受选择/拒绝；synthetic interleaving、SFT/PPO 负责把计划暴露行为变成模型默认格式，Best-of-N/R&R 负责在 inference-time 及时剪枝。证据链为 Figure 1（p.2）→ Algorithm 1–3（p.4–7）→ Table 2/4（p.10–11）。
2. **正文保留的决策关键内容**：问题与 user intervention 动机、`P→T→A` 对比、`τ` 结构、三阶段训练、plan-level judge、两个策略、Q1/Q2、模型/任务/指标、Table 1–4 的主要点估计，以及 structured/verifiable scope。读者可据此理解“干预发生在哪里”和“结果改变了多少”。
3. **附录迁移及其影响**：完整伪代码、system instruction、autorater rubric、数据集规模、VERL/H100/超参数、synthetic prompt、跨域计划示例、TA/R&R failure trace 全部在 Appendix。迁移没有破坏主线阅读，却使精确复现和判断训练范围依赖附录；human calibration、T/P、seed 方差、wall-clock 仍未补齐。
4. **最有效的写作/图表模式**：Figure 1 用同一任务路径并置 monolithic 与 plan-level rewind；Table 2 将 plan-level feedback 与 answer-level restart 放在同一指标框架；Table 3/4 分别提供 budget scaling 与干预频率诊断。方法单位、干预单位和结果单位保持相同的“短 plan prefix”粒度，论证方向清楚。
5. **最大叙事缺口**：最直接的证据问题是训练范围与“coding-only”叙事冲突，且 p.9 的结果数字把 Table 1 与 Table 3 混写；实验层面则缺少 human judge、真实 wall-clock、T/P 和不确定性。它们共同削弱“跨域、低延迟、无额外 token cost”的强范围表述。
6. **可迁移规则**：若系统声称用户能在推理中途纠偏，应把首个可见单元定义为同时满足“用户可读、模型可继续条件化、评估器可判定”的 plan，并用同一任务/预算对照 plan-level rejection 与 answer-level restart。
7. **适用边界**：该规则适用于 plan correctness 有外部可验证信号、任务结构清晰且短 prefix 足以承载 intent 的场景。面对含糊/欠规格请求、主观偏好、judge latency 占主导或需要真实人类响应体验的场景，本文证据仍不足。
