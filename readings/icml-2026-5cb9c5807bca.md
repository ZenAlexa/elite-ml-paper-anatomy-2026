## 4. Related Work 的定位方式

§2 位于 Introduction 后、Label Construction 前（p. 2–3），约 613 个估计词、约 9.9% 的核心正文。它由三个引用簇组成：

1. **signal → semantics taxonomy**：HuBERT/WavLM 一簇与 Emotion-LLaMA、EmoLLM、AffectGPT、BLSP-Emo、EmoSLLM、AA-SLLM 一簇对照。差异维度是 acoustic representation、semantic expressiveness 与 active querying；近邻缺口被表述为 static summaries／passive evidence。[p. 2, §2；“provided as embeddings or static summaries”]
2. **subjectivity／disagreement cluster**：plurality/majority aggregation、soft labels、uncertainty modeling、ensemble mitigation 依次承认已有处理，再把它们定位为平滑或降低分歧，未把分歧当作 co-occurring emotions 的 supervision。[p. 2–3；“primarily aim to reduce or smooth disagreement”]
3. **agentic／RL cluster**：Agent-MER、Affective-CoT、EMO-RL 被列为结构化 reasoning 或 emotion-aligned RL 的近邻；本文以 multi-turn interactive evidence acquisition、semantic 与 acoustic 的按需对照建立差异。[p. 3；“do not formulate emotion understanding as a multi-turn”]

段落动作依次为 `taxonomy → nearest_neighbor_contrast → credit_or_foundation → limitation_of_prior → gap_creation`。相关工作只给“passive / static”对照，§4 才定义四类 tool、phase boundary 和 reward。

引用在后文继续承担作用。Table 1 用文献标注 SSL 与 SLLM/MLLM baselines，§4.2/Appendix C、D 用 Scherer、Tak、MFA、Juslin & Laukka 支撑 schema、alignment 和 acoustic correlates。[p. 5；“grounded in Scherer’s Component Process Model”；p. 7, Table 1]

## 5. 方法、形式化与理论地位

### 5.1 最小逻辑单元与问题对应

| 单元 | 首次位置 | 输入／状态／输出 | 回应的前文问题 | 证据 |
|---|---|---|---|---|
| Flexible plurality label construction | p. 3, §3 | 每段至少 5 位 annotator 的 8-way votes；primary 为最高票集合（可 tie），minor 为非 primary 的标准类别；输出 primary＋minor | 避免 tie filtering 与 minority-vote 丢失 | “retain all tied classes as valid primary labels” |
| Phase 1: Global Perception | p. 4, §4.1 | 输入 `(x,t)`；状态 `C0`；输出 ranked top-K candidates 与 tie | 保留高召回候选与不确定性 | “ranking and prioritization rather than hard filtering” |
| Phase 2: Evidence Verification | p. 4–5, §4.1 | 状态 `Ct`；在 soft budget 下选择 tool、更新验证状态 | 主动区分 competing hypotheses | “conditional computation loop” |
| StructuralPriorTool | p. 5, §4.2；p. 15–17, Appendix B | 输入 candidate set 与 intent；输出 pair scheduling 或 minimal expansion | 将 co-occurrence 用于搜索预算，隔离 instance decision | “used exclusively to support efficient evidence acquisition” |

方法推进序列为：`state_problem(label loss) → define_component(plurality labels) → state_problem(signal–semantics gap) → instantiate_algorithm(three phases) → explain_mechanism(four tools) → derive(GRPO reward) → connect_to_experiment(metrics and baselines)`。Figure 2 是全过程图，Figure 3 用一个 Happiness／Neutral 示例把候选、tool-call summary 和 evidence-closed verdict 串起来；两者承担 workflow 解释，未给算法伪代码。全篇没有 `Algorithm` 环境，也没有明确循环层级、时间复杂度或大 O 说明；tool budget 只给了策略性范围（训练 reward 中 2–8 calls）。[p. 4, Figure 2；p. 6, Figure 3；p. 23, Eq. 19]

### 5.2 公式与理论对象

正文的 Eq. 1–3 是 GRPO composite reward、auxiliary evidence score 与 `τ_EIR`；p. 6 另给 Soft Recall、Set Recall、Jaccard 三个无编号评测式。Appendix B 给 Eq. 4–10 的 co-occurrence、normalization、pair scheduling 和 backtracking；Appendix D 给 `z_g`、`z_l` 两个无编号 dual-reference 标准化式；Appendix F/G 给 Eq. 11–22 的 reward implementation 与 sensitivity variants。[p. 6；“The resulting composite reward is formalized in Eq. 1”；p. 15–17；p. 20；p. 22–24]

`τ_EIR` 的形式化是本文最接近机制保证的对象：若同一 rollout group 的正确轨迹平均 evidence score 不低于错误轨迹，gate 为 1；否则取 `exp(μ+−μ−)`。[p. 6, Eq. 3] 这定义了 reward gating，不构成对 factual grounding、causal traceability 或性能提升的 theorem。文中“ensures decision integrity”“guaranteeing … causally traceable”是架构性陈述，后续对应的是 prompt constraints、Table 2 trust-gate ablation 和 Figure 3 示例，未提供 formal proof 或独立 audit study。[p. 5；“This evidence-closed constraint ensures decision integrity”]

### 7.2 主要结果与不利解释

1. **MSP-Podcast main table**：ADEPT+GRPO 的 `P-MacroF1=0.4224`、`Soft R=0.7874`、`Set R=0.6192`、`Jaccard=0.4751`、Avg Size `2.21`；Table 1 内对照中 fine-tuned WavLM 的 primary-only `P-MacroF1=0.3640`，ADEPT w/o GRPO 为 `0.3571/0.7032/0.5748/0.4450`（P-F1/Soft R/Set R/Jaccard）。作者将平均 set size `2.02→2.21` 与指标增长解释为 evidence-supported disambiguation，排除了纯粹过度扩标签的解释。[p. 7, Table 1；“rather than indiscriminate label expansion”] 该解释缺少 per-seed uncertainty 和 label-cardinality-stratified main metrics，仍有待其补充。
2. **tool budget 与 ambiguity**：Figure 4(a) 报 high/medium/low label-set cardinality 对应 `2.3±0.8`、`4.1±1.4`、`6.8±2.1` average tool calls；Figure 4(b) 将低 consensus 的增量分解到 comparison、prior expansion、replay audio 等 tools。作者的描述性结论是按不确定性分配计算。[p. 7, §5.4；“measured by the cardinality of the ground-truth emotion set”] `±` 的统计含义、各层样本数、控制了什么难度因子均未说明，所以它支持相关的行为描述，尚不足以隔离工具分配的因果机制。
3. **component ablation**：full model 相对 Omni3 (no tools) 的 Set R 从 `49.23` 到 `61.92`，Jaccard 从 `38.90` 到 `47.51`；删除 semantic 后 P-F1 为 `33.86`，删除 acoustic 后 Jaccard 为 `41.28`，删除 trust gate 后 Jaccard 为 `44.96`。[p. 8, Table 2] 这回应了各组件的必要性；每次只删一项且未给随机性，不能判断各组件交互或统计稳定性。
4. **IEMOCAP mapped 7-way**：ADEPT+GRPO 在 strict zero-shot 条件下为 `Acc=54.83`、`Soft R=67.42`、`Set R=54.80`、`Jaccard=43.15`；Table 3 的 fully fine-tuned BLSP-Emo 为 `76.13/80.51/52.30/48.90`。正文明确承认 fine-tuned models 在 single-label accuracy 上占优，并强调 ADEPT 的 Set R `54.80` 高于 `52.30`。[p. 8, Table 3；“distinct from baselines fully fine-tuned”] 同一张表还显示 ADEPT 的 Acc 与 Jaccard 低于 BLSP-Emo，因此“zero-shot robustness”应理解为一项 set-recall-oriented evidence，不等于全指标胜出。
5. **optimization sensitivity**：K 从 4 到 8 时 Jaccard `45.33→47.51`；8 到 12 仅 `47.51→47.78`，正文称后者约增加 50% training wall-time。reward balance 的 Baseline B 在 Table 9 中给出最强 Set R/Soft R/Jaccard，A 的 P-F1 稍高 `42.56`，C 的 Jaccard `47.15`。[p. 24–25, Table 9；“approximately 50%”] wall-time 没有绝对硬件、时长或方差。

## 12. 最终判断

1. **单一主线**：把 SER 中被 consensus aggregation 压缩的感情歧义保存为 primary/minor candidate structure，再让 agent 在 semantic/acoustic tools 中主动取得可验证证据，最后在 evidence-closed 阶段裁决；GRPO 的 trust gate 试图让这种取证行为随 prediction quality 对齐。[p. 3–6]
2. **正文保留的决策关键内容**：标签规则、三阶段 boundary、四 tool family 的角色、Eq. 1–3、main/ablation/zero-shot tables 和 tool-call scaling；这足以判断论文主张、主要数值和 trade-off。[p. 3–8]
3. **被移入 Appendix 的细节及影响**：co-occurrence prior、7-factor schemas、acoustic buckets、hard-format/phase rewards、sensitivity、mapping distributions、system prompts 均在附录。迁移保持主线紧凑，却让可执行复现和“gate 防 hacking”的具体约束依赖 p. 15–29。
4. **最有效的写作／图表模式**：Figure 2 将 phase boundary、tool family 与 output 一次呈现；Table 1 同时放 primary fidelity、set recovery 与 predicted cardinality，使“恢复 minor emotions 但非盲目扩标签”的论证可以在同一对象上检查。[p. 4, Figure 2；p. 7, Table 1]
5. **最明显的读者成本与未闭合处**：reward／prompt 实施跨多个 appendix；Table 3 的 zero-shot 与 fully fine-tuned baselines 比较需要同时读取其 setting、四个 metrics 与 mapping。全篇未给 seed、uncertainty type、test 或完整 implementation environment，且 trust-gate 的 anti-hacking 机制只有间接 ablation 支撑。
6. **可迁移规则**：当论文主张“agentic reasoning 使预测更可信”时，正文应并排呈现任务结果、行为过程量和能够反驳“无差别更多调用／更多预测”的校准量，并把各项映射到同一机制组件。
7. **规则边界**：此规则适合 tool-mediated system 的可审计性主张。若任务没有可定义的 observation、candidate trajectory 或可比较的工具预算，强行加入 process metrics 会制造伪机制证据；此时应改用任务本身可验证的中介量。
