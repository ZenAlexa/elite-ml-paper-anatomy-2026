## 5. 方法与理论

### 5.1 数据生成过程和假设

作者将说话者生成 token 序列 τ₁,…,τ_T 的因素分成 high-level/global latent h_t（semantics、intent）和 low-level/local latent l_t（某一 timestep 的 grammatical gender 等）。生成映射为 τ_t = ϕ(τ^{t−1}, h_t, l_t)；语言模型在 layer L 给出 x_t^L ∈ R^d，并假定存在可逆映射 g(h_t,l_t)=x_t。目标是把模型 latent 分解为对应数据生成变量的可解释 features（p.3–4，§3.1）。

- **Assumption 1（Temporal Consistency）。** 同一序列的高层变量随时间不变，h_t ≈ h_t′。
- **Assumption 2（Hierarchical Representation of Features）。** 0 = ||g(h_t,l_t)−x_t|| ≤ ||g(h_t,0)−x_t|| ≤ ε；h_t 可在 ε 内重构，而 l_t 带有未被 h_t 解释的 signal。

这两条是方法设计前提，不是由本文独立估计的 theorem。§3.1 没有 theorem、lemma、proposition、corollary 或 proof；理论角色是**核心建模链和可检验预测来源**。

### 5.2 T-SAE 组件和 loss

作者把 SAE 的 m 个 feature 前 h 个固定为 high-level，后 m−h 个为 low-level。基本架构为 f(x_t)=σ(W_enc x_t+b_enc)、x̂(f)=W_dec f(x_t)+b_dec。随后使用类似 Matryoshka SAE 的分层重构：L_matr=L_H+L_L，其中 high-level 部分重构 input，完整 feature 部分重构 input，作者把 low-level feature 解释为 residual signal（p.4，§3.2）。

Temporal loss 只作用于 high-level activation z_t=f_0:h(x_t)。对同一序列的相邻 pair 提高 cosine similarity，对 batch 中不同样本降低相似性，从而避免 high-level space 的 smoothness collapse（所有 feature 常数化）。总目标为 L=Σ_i L_matr(x_t^(i))+αL_contr；L_contr 是对两个方向的 batch contrastive softmax／InfoNCE 形式。训练时加载 x_t,x_{t−1} 成对激活并 shuffle pairs；另在 §4.6 试验从过去 x_1,…,x_{t−1} 均匀采样的 long-range pair。low-level features 没有直接约束，而是由 high-level residual 重构自然承接快速变化部分（p.4，§3.2）。

**推进序列。** setup_notation → state_problem → derive → define_component → give_intuition → instantiate_algorithm（无伪代码，直接给 loss）→ connect_to_prediction → connect_to_experiment → summarize。方法没有 Algorithm caption 或循环伪代码；实现算法由公式、feature split 和训练 pair 采样文字承担。

论文实际使用的是 probe accuracy、t-SNE、均值差、标准差、two-sided t-test、Pearson correlation、SAEBench judge score 和多序列平均 smoothness。没有 Bayesian 分析、bootstrap、多重比较校正、回归模型或跨 seed 区间。图注通常能说明任务、比较对象和标签，但 Figure 3 与 Appendix Figure 10–12 的精确数值和 seed 分母留在曲线图；Table 1 的 Autointerp 明示标准差，其他表格大多是单一平均／差值。

主结果的最强因果链是「temporal loss → high/low specialization → semantic/context probe 和长序列 structure」，但结果证据主要是 probe、相关性和案例可视化，不能把 temporal loss 解释成对真实语义变量的因果识别。Safety case study 的 t-test 证明 rejected/chosen 长度差异在该样本上的统计关联，不证明 T-SAE feature 是安全行为的成因。

## 12. 最终判断

1. **单一主线。** 语言中的高层语义／上下文在邻近 token 间更平滑、syntax 更局部；将该 temporal prior 写入只约束 high-level split 的 contrastive SAE loss，使 low-level residual 承担局部变化，从而提高 semantic/context 可读性并保持重构和 steering utility。
2. **正文保留的决策关键内容。** 两个数据生成假设、SAE／Matryoshka 重构、双向 contrastive loss、20:80 split、MMLU semantic/context/syntax probes、Table 1 标准 SAE 指标、Figure 4 长序列可视化、Figure 5 HH-RLHF／steering case study，以及 Table 2 的 trade-off 消融。
3. **移入附录的细节及影响。** Appendix 放入线性化 contrastive loss、HH-RLHF 首 1,000 样本的特征榜单和案例、steering 的 prompt／strength／feature 表、split smoothness／absorption、8B scaling、跨数据集 probes、更多 t-SNE 和 baseline “the” features。迁移让正文可扫读，但削弱了对 judge、分母、跨任务异质性和 scaling 边界的自足核查。
4. **最有效的写作、图、表、公式模式。** Figure 1 先用同一序列对比 baseline 噪声和 T-SAE phase shift；§3 立即给 high／low 生成模型和 loss；Figure 2/3 先可视化再 probing；Table 1 把语义收益和 reconstruction cost 放在同一行；Table 2 以差值显示 split／pair／loss 的机制 trade-off。该组合把直觉、形式化、任务证据和反事实式消融连接起来。
5. **最大叙事规避、未闭合主张和读者成本。** 「semantic disentanglement」依赖 proxy labels、t-SNE、LLM feature explanations 和有限案例，尚无 ground-truth 或 causal intervention；「significantly／without significant cost」缺乏对应的完整统计报告；steering Pareto claim 受 feature description 和 LLM judge 影响。读者需在 p.9 与 p.16–23 间跳转才能复核主张边界。
6. **可迁移规则。** 使用结构先验改写 representation learner 时，应把先验对应的 feature granularity 在方法中固定，并用「任务 probe + 标准重构 + 长序列可视化 + 删除／替代先验的差值消融」同时检查收益、代价和机制；单一 interpretability score 不足以承担这四项判断。
7. **适用边界。** 该规则适用于目标概念在相邻或可定义窗口内有持续性、输入存在可靠顺序且可分出不同时间尺度的场景；若语义在 token 间快速跳变、任务依赖长距离而非相邻 pair、或没有自然 temporal order，则 temporal smoothness 可能抹掉真实信号，需改用多尺度或其他结构先验。本文自己的 memory／compute 限制、contrastive geometry mismatch、单层／两模型范围和 20% steps scaling 也限制了直接外推。
