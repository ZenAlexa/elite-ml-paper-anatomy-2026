## 5. Method 与 theory

### 5.1 方法对象与推进

方法将前文的两个问题绑定到两个阶段，先用标注的 pattern-aware traces 做 cold-start，再用 online group sampling 与 rewards 做 exploration。推理输出最多包含五个 tag，包括 `<fast>`、`<planning>`、`<reasoning>`、`<reflection>`、`<conclusion>`，最后是 `<answer>`；短样本可以跳过 planning/reflection，难样本才激活它们。

逻辑单元与前文问题对应如下：

1. **SFT pattern injection（§4.1，p.5）**：定义 `D1={(q,s_i)}`，`q` 是图像与用户问题，`s` 是带 reasoning patterns 和 final answer 的目标序列；以 token-level likelihood（Eq. 1）注入格式和基础链。
2. **多步标注（p.5、p.24–25）**：先人工检查抽取三类 artifact taxonomy，再以多 MLLM 投票选两项显著异常，抽取视觉事实，最后由 Qwen3-235B-A22B 改写成 CoT；fake 产生 36K SFT samples，real 省略异常识别阶段。
3. **MiPO reasoning alignment（p.5–6）**：`D2` 同时包含正确但模糊／不精确的 `s_l^φ` 与错误的 `s_l^ψ` 作为 mixed non-preference，与人工精细的 preferred `s_w` 配对；Eq. 2 相对 SFT reference policy 进行 preference optimization。
4. **Pattern-aware GRPO（p.6–7）**：`D3={(q,a)}` 使用 9K in-domain images、binary labels；当前 policy 对每个问题采样 `G=4` 个输出，按 group mean/std 形成 advantage（Eq. 3–4），reference 为 cold-start model。
5. **Reward shaping（p.7）**：正确且包含 planning/reflection 得到 `R_pattern=2.0`，正确但不含两者得 1.0；错误且包含 planning/reflection 被惩罚（−0.5 或 −1.0），self-reflection 的错误惩罚更大。正确回答才获得 external reflection quality reward；valid format 再加 format reward（Eq. 5–6）。
6. **自适应 pattern**：绝对 reasoning length 不是目标；P-GRPO 奖励有用的 planning/reflection、惩罚导致错误的 overthinking，因而把“是否需要深推理”作为策略行为学习。

方法段的动作转移可写为：

`setup_notation → state_problem → derive (Eq.1) → define_component (D1/annotation) → give_intuition (three artifact groups) → derive (Eq.2) → explain_mechanism (MiPO) → derive (Eq.3–4) → define_component (pattern/reflection/format rewards) → derive (Eq.5–6) → connect_to_experiment (OOD generalization)`。

## 6. Experimental design

### 6.1 HydraFake 的对象与划分

HydraFake 目标是把“有大量训练图像、但新模型／新操作／新数据源在测试时出现”的工业情境显式化。总数据在正文称 50K real + 50K fake；训练集 48K，评测四个 split 合计 52K（ID 14K、cross-model 11K、cross-forgery 12K、cross-domain 15K）。训练 real 来自 8 个 real datasets 中的 5 个 subset，另 3 个 real subsets 留作测试；训练 fake 来自 21 个 subsets，但只保留 face swapping（FS）、face reenactment（FR）、entire face generation（EFG）三种 forgery type。

Real images：低分辨率为 LFW、CelebA、FF++、FFIW，高分辨率为 FFHQ、VFHQ、UADFV、CelebAHQ。Fake images 分为 classic（FF++、DF40、FFIW，10 个 generative models）、public（WILD、seeprettyface、TalkingHeadBench，16 个 generators）和 advanced（复现／抓取 10 个 advanced generators，外加 1K social-media commercial-app images）。质量控制包括舍弃低质量 classic sources、为 personalization 使用 sample-specific prompts、为 relighting 多光源生成后人工筛选；最终平衡到 50K real/50K fake。

四级评测为：

- **In-Domain（14K）**：训练来源相同、identity 不同。
- **Cross-Model（11K）**：model 未见但控制条件相近；含 Adobe Firefly、MAGI-1、Flux1.1 Pro、StarryAI、Infinity、HART；real 仍来自 ID、identity 不同。
- **Cross-Forgery（12K）**：forgery operation 未见；StarGANv2 attribute editing、IC-Light relighting、CodeFormer restoration、InfiniteYou/PuLID personalization、FaceAdapter generative face swapping；real 来自 ID、identity 不同。
- **Cross-Domain（15K）**：同时引入未见 data source／commercial or social-media generation 与未见 real datasets，含 DeepFaceLab、FFIW、InfiniteYou-CD、Dreamina、Hailuo AI、GPT-4o 等；分辨率跨 159–1536 或 256–1024，难点包含低质量 real。

## 7. Results、统计与可视化

### 7.1 主结果

Table 1（p.8）报告 Accuracy；ID 结果取平均，CM/CF/CD 按其子集汇总。Veritas（ours）四个 split 为 ID 97.3、CM 98.6、CF 90.3、CD 82.2，四分割直接平均 90.7。作者以此报告相对先前最佳 detector 的 6.0 percentage-point 平均提升；相对 base InternVL3-8B 的四分割平均由 58.3 到 90.7（+32.4），相对 Gemini-2.5-Pro 的 78.9 到 90.7（+11.8）。这些是 Accuracy 差值，没有显著性检验，文中“significant gains”应理解为实质差异而非统计意义。

主结果的跨层模式：既有专用 detector 在 CM 多数超过 90%，但 CF/CD 多数低于 85%；Veritas 在 Face restoration、personalization 等 CF 子集超过 90%，Dreamina 为 92.3、GPT-4o 为 89.2。冷启动模型已具竞争力，但 CF/CD 低于加 P-GRPO 的模型，支持在线 pattern reward 的增益解释。`Veritas-MINI` 在受限训练范围下仍高于既有 MLLM-based detector。

### 7.2 统计与证据边界

聚合单位主要是 image；Accuracy 为样本正确比例，fake 是 Precision/Recall 的正类。ID 的平均是 subset-level Accuracy 的直接均值，CM/CF/CD 也按 subset 汇总；Table 10–13 同时给每 subset 的 Precision、Recall 和 Accuracy。reasoning quality 使用 1K 随机样本，由 GPT-4o 与 Gemini-2.5-Pro 做 score/judge；ELO 是 pairwise 比较派生值。效率按 batch size 8 在单个 PPUE GPU 上取 inference time，按分辨率和 difficulty 切四格。

论文没有报告 confidence interval、显著性检验、多重比较校正、bootstrap、重复 seed 或错误条。图表的 table note 能解释指标和平均规则，但无法独立恢复每个 split 的样本分母；HydraFake 的 subset 规模在 Table 9 及正文给出。reasoning quality 的“Excellent/Good”等 1–5 criteria 在 Figure 33，reflection reward 的 0–100 rubric 在 Figure 36；这些 judge 分数依赖外部模型，并非人工标注的独立金标准。Accuracy、reasoning score 和案例中的机制解释被分开报告，但论文仍把 `transparent and faithful` 作为综合性结论。

## 8. Ablation、负面结果与自我设限

### 8.1 机制消融

- **Reasoning paradigm（Table 2，p.8）**：w/o reasoning 为 ID 97.8、CM 93.3、CF 73.0、CD 69.5；post-hoc explanation 为 96.3/95.0/79.0/76.8；flexible reasoning 为 96.2/94.3/81.2/76.8；pattern-aware reasoning 为 96.9/98.4/87.4/80.1。相对 flexible，CF +6.2、CD +3.3，ID +0.7、CM +4.1；增益集中在 OOD。
- **Training stages（Figure 4，p.9）**：SFT 上增加 MiPO 或 P-GRPO 都有收益，先 MiPO 再 P-GRPO 的组合最好；正文给出 CF +2.9、CD +2.1 的提升叙述。
- **Cold-start（Figure 5，p.9）**：无 cold-start 的 answer-only 模型 ID 较强；加 thinking 有利于 CM/CD，但所有纯 RL 设置低于带 cold-start，作者将低质量 exploration 与训练不稳定联系起来。
- **Reward functions（Table 3，p.8）**：pattern-aware reward 在 CF/CD 超过 vanilla accuracy reward；reflection quality reward 同时帮助原始 GRPO 与 P-GRPO；format reward 检查 tag 组合，属于行为有效性而非准确率机制。
- **Specific patterns（Table 5，p.9）**：完整模型 96.9/98.4/87.4/80.1；去掉 `<fast>` 97.3/98.8/86.9/79.1，去掉 `<planning>` 96.7/96.9/85.0/80.1，去掉 `<reflection>` 97.0/97.2/82.5/77.3，去掉 `<conclusion>` 97.2/98.2/86.2/79.0。文本解释 `<fast>` 对 CF/CD 有帮助但非整体关键，`planning` 偏向 CM，`reflection` 对 CF/CD 最关键，`conclusion` 提供证据合成。
- **MiPO non-preference（Table 6，p.9）**：完整模型平均 92.1；w/o MiPO 90.7；去掉正确但模糊的 `s_l^φ` 为 91.5（CF 89.2、CD 81.4）；去掉错误的 `s_l^ψ` 崩到平均 60.8（ID 65.3、CM 64.8、CF 58.6、CD 54.3）。Figure 20 显示保留 `s_l^φ` 后分析更精细，未使用它时答案虽可能正确但分析浅。

### 8.2 扩展消融与负面信息

- **Training data（Table 19，p.30）**：cold-start baseline 为 96.8/95.8/85.1/79.5；balanced sampling 为 97.3/98.6/90.3/82.2；hard sampling 为 96.9/98.4/88.6/81.3；加入约 1/3 未见 AIGIBench data 的 partially unseen 为 95.7/99.4/94.1/82.4。后者相对完整 Veritas 的 CF +3.8，但 ID 降低，且测试域与 HydraFake CD 不重叠。
- **KL 与 group size（Tables 17–18，p.29）**：`β′=0` 的 CF/CD 90.3/82.2 高于 β′=.04 的 89.1/80.2；`G=4` 的 CM/CF/CD 98.6/90.3/82.2，G 增到 16 后降至 93.2/88.9/80.4，作者据此把过多 rollout 解释为冗余探索。
- **效率（Table 16，p.29）**：post-hoc 27.08/28.19/37.64/36.06 秒，flexible 24.60/29.37/44.43/47.44，cold-start 19.26/24.94/40.72/46.40，ours 22.35/25.60/49.76/54.22；四格依次为 low-resolution easy/hard、high-resolution easy/hard，batch size 8。ours 的准确率 92.1，高分辨率更慢；相对 flexible 的准确率提升 5.3，但 high-resolution latency 增大。
- **Reward model（Figure 10，p.30）**：SophiaVL-R1-3B 的 instruction following 不足，难以测 reflection novelty；Qwen2.5-VL-3B 与 UnifiedReward-Qwen-3B 更能区分 reflection quality；扩至 7B 没有显著提升。图中高低值由柱图呈现，正文未给完整数值表。
- **Cross-benchmark（Table 14–15，p.28）**：AIGIBench 与 HydraFake-CD 均保持未见测试定位；扩大 training source 对 D3 等 AIGC detector 有益，对 IID／ProDet 等 deepfake detector 甚至带来性能下降。该结果把“多数据就自动泛化”作为负面对照。

### 8.3 失败、限制和呈现位置

- 失败集中在低分辨率 real（DeepFaceLab、FFIW）和完全未见 forgery（尤其 face relighting）。Figure 22（p.44）给出真实 DeepFaceLab 被判 fake、GPT-4o-generated water-droplet image 被判 real、IC-Light relighting 被判 real 的案例；错误 reasoning 仍指出 water droplets 或 warm lighting 等可复核线索。
- 主文的局限没有独立 §Limitations；A.12 在 p.32、结论之后，写明 HydraFake 仅 image modality、视频逐帧空间 artifact 不足、DeepFaceLab/FFIW 低质量导致 Veritas 短板，并提出 MLLM + small vision model 协作和统一 image-video benchmark。
- 摘要和引言使用“significant gains”“transparent and faithful”等强语气，实验主体使用 Accuracy，Precision/Recall、完整 subset 表和失败案例移入附录。这里记录版面与指标事实，不把它归因于作者动机。

## 10. 用词与修辞

以下为正文（p.1–10）和附录文字的语境标注，不替代汇总脚本的统一 token 计数。自动提取可能把 `deepfake/deepfakes`、`model/models`、`reasoning/reason` 分开，把带连字符的 `cross-forgery`、`out-of-domain` 拆成多个 token；数据集名、模型名、XML-like tags 和公式碎片应从词频中排除。

## 12. 限制、伦理与不利信息

- **数据模态限制**（`data`／`generality`）：HydraFake 只含图像；视频生成的时间一致性与手脸互动不在数据中。参见 p.32 A.12，“limited to the image modality”。
- **低分辨率限制**（`data`／`metric`）：DeepFaceLab、FFIW 等低质量 real 使 MLLM 难以看见细节；CD 的 DeepFaceLab 仅 58.6 Acc。参见 p.26–27 Table 13，p.32 A.12。
- **未见操作限制**（`generality`）：IC-Light relighting 是错误较多的 CF 子集，Veritas 75.7，Effort 94.8；A.9 把 face relighting 列为主要失败。参见 p.27 Table 12、p.31 A.9。
- **推理成本限制**（`compute`）：高分辨率需要更长 reasoning，ours 在高分辨率 hard case 为 54.22 秒／batch 8；无在线部署吞吐或成本分析。参见 p.29 Table 16。
- **评测统计限制**（`metric`／`causality`）：主文只有 Accuracy，reasoning quality 依赖 GPT-4o/Gemini judge；没有 seed variation、CI、显著性检验或 faithfulness gold labels。参见 p.8、p.10、p.55–57；此处为版面与统计处理的 `layout_observation`。
- **伦理边界**（`ethics`／`deployment`）：作者声明真实脸来自公开 academic datasets，自建 fake 来自公开／合成数据，非商业学术使用；没有给出部署误报治理、隐私撤回或模型滥用评估。参见 p.31 A.10–A.11。

## 13. 不利信息呈现策略（仅记录可观察事实）

1. **附录迁移**：完整 P/R、subset 分母、效率、hyperparameter、reward-model 细节和失败案例主要位于 A.5/A.9；主文用 Table 1、Table 2 和一句话总结；参见 p.8–10 与 p.25–32。
2. **局限延后**：p.10 Conclusion 之后直到 p.32 才出现集中 A.12，主文结论承载“greatly mitigates the gap”，读者需跨越 22 页看到 image-only 与 low-resolution 边界；参见 p.10、p.32，`layout_observation`。
3. **聚合掩盖异质性风险**：主文显示 CD 平均 82.2，附录显示 DeepFaceLab 58.6、FFIW 78.5 与 Dreamina 92.3、GPT-4o 89.2 并存；作者在 p.26–27 明确解释低分辨率 real 的 Precision 问题，因此这里是“平均值先呈现、异质性后展开”，不推断动机。
4. **强词缺少统计配套**：摘要与正文使用 `significant gains`，实际报告 Accuracy 点估计，无 p-value 或区间；参见 p.1、p.8、p.10。`interpretation` 表示统计语义边界，不称为作者意图。
5. **正向定性样例占主体**：Figures 11–21、23–27 主要展示正确且详细的 reasoning；Figure 22 承担失败分析，并且 A.9 明确承认失败类型；参见 p.33–49。可观察到“案例选择”，但无法由版面推断选择过程。

## 14. 最终判断

- **单一主线**：把“传统 detector 对未见 forgery/domain 的泛化缺口”转成可分层的 HydraFake 评测，再用 `SFT → MiPO → P-GRPO` 把 MLLM 从短、先分类后解释的模式转为按难度选择 pattern 的 forensic reasoning；性能与透明输出都服务于同一 OOD 主张。参见 p.1–10，尤其 p.2、p.5–7、p.8–10。
- **正文保留的决策关键内容**：四级 split 定义、训练只见 FS/FR/EFG 的关键控制、Eq. (1)–(6)、Table 1 主比较、Table 2/5 pattern 机制、Figure 4/5 阶段与 cold-start、Table 7/8 质量与鲁棒性、Conclusion。读者能沿着“问题、方法、OOD 结果、机制消融”复述主线。
- **移入附录的细节及影响**：完整 subset 规模与 P/R、训练硬件／epoch、prompt、reward rubric、cross-benchmark、效率、hyperparameter、失败与 ethics 均移入附录；主线可读性较好，自足性在“faithfulness”“低分辨率失败原因”“MiPO 如何筛 mixed non-preference”上下降；参见 p.22–32、p.50–58。
- **最有效的模式**：Figure 2 将数据来源、hierarchical protocol 与基线短板合一；Table 2/5 将 OOD effect 与 pattern deletion 对齐；Table 6 将 `s_l^φ`、`s_l^ψ` 的具体训练角色对齐到性能；Table 13 与 Figure 22 同时暴露低分辨率边界；参见 p.4、p.8–10、p.27、p.44。
- **最明显的叙事规避／读者成本**：正文以 split-level averages 先呈现高分，并把 CD 的 DeepFaceLab/FFIW 异质性、IC-Light 弱点和 image-only limitation 延后；`significant` 没有统计检验，`faithful` 没有 causal faithfulness 标注；浮动图页导致 A.6–A.9 的说明与图跨页分离；参见 p.8–10、p.27、p.31–32、p.33–58。
- **可迁移规则**：如果论文的能力主张是“跨分布泛化”，先把训练可见因素与测试未见因素写成互斥层级，并让主表、组件消融和失败案例分别回答“是否有效、为何有效、何时失效”。
- **规则边界**：该规则适用于有明确训练／测试分布和可核验输出的 detector 或 reasoning 系统；对于只关注理论保证、无真实 OOD 因素的论文，分层 benchmark 与 pattern deletion 不能替代证明。Veritas 自身也尚未覆盖视频、长期部署、seed 不确定性或 causal faithfulness。
