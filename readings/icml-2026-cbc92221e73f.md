## 4. 方法、理论与因果机制

### 4.1 形式化对象与动作序列

- **输入／输出与目标。** `x∼D_x`，标签精确为 `y=N*(x)`；固定 `ϕ(x): R^d→R^m`，student 为 `N(x;θ)=⟨θ,ϕ(x)⟩`，teacher 假设为 `N*(x)=⟨θ*,ϕ(x)⟩`。训练最小化 empirical MSE 加 `λ/2‖θ‖²₂`，以固定步长 `η` GD 更新。首次完整出现于 p.4 §2。[E, p.4, §2, “teacher is realizable”]
- **核心可观察量。** `L_n(θ)` 是训练 squared loss，`L(θ)` 是 population squared loss；`t1` 是训练误差仍至少为 `ε` 的最后一步，`t2` 是 population loss 首次不超过 `c` 的一步，且 `c≥ε`。这把“延迟”定义为 `t2−t1`。[E, p.5, §4.2, “t2 := t2(c)”]
- **逻辑动作序列。** `setup_notation → state_problem → instantiate_algorithm → connect_to_prediction → derive → explain_mechanism → state_complexity/conditions → connect_to_experiment`。§2 先给对象，§3 定义可被推翻的三阶段，§4 分解训练／泛化速度，再把预测交给 §5。
- **机制解释。** 数据行空间的 `θ∥` 在速率约 `1−ηλ_min⁺(ΦᵀΦ)/n−ηλ` 下拟合训练集；null-space 的 `θ⊥` 只由 weight decay 以约 `1−ηλ` 衰减。小 `λ` 使两种时间尺度分离，长期 residual `θ⊥` 保持较高 population loss，最终 regularization 收缩参数并支持 uniform convergence。[E, p.6, §4.2, “remains close to its initialization”]

## 10. 最终判断

1. **单一主线。** 过参数化 ridge regression 中，训练数据行空间快速拟合，而 null-space 初始化仅由小 weight decay 缓慢收缩；两个时间尺度产生 `t2−t1`，最终正则化使泛化恢复。[E, p.6, §4.2, “imbalanced trajectory”]
2. **主文保留的决策关键内容。** 模型、loss、GD、`t1/t2` 定义、五个正式 theorem、关键条件式、机制段落、四幅主文图与讨论边界均留在主文。
3. **附录迁移及后果。** 证明、Gaussian 特化和三个附加实验被迁至 pp.12–23；这未妨碍判断主张范围，却使 theorem 有效性依赖附录证明。
4. **最有效模式。** 把“训练快／泛化慢／最终好”拆成 Theorems 4.4、4.5、4.6，再让 Figure 2 以同一 `t1,t2` 定义可视化超参数预测。定义、因果机制、界和图共享变量。
5. **主要读者成本。** 关键结论依赖严格 realizability、bounded feature、宽度和小 `λ` 条件；非线性 evidence 只有定性曲线，且多数实证图未说明重复与不确定性。该成本在 §6 被部分主动披露。
6. **可迁移规则。** 对延迟泛化论文，先把“延迟”写成两个可测时间点，再分别给每个时间点的理论或实验证据；让机制变量、图轴和结论使用同一符号。
7. **规则边界。** 此规则适用于能定义训练与泛化时间尺度的场景。若 metric、样本机制或训练动态无法让 `t1/t2` 有稳定含义，强行套用会掩盖实际不确定性。
