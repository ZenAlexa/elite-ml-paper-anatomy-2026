## 方法与理论

### 方法最小逻辑单元

1. **setup_notation**：图 `G={V,E,A,X}`，邻接矩阵 `A`、节点特征 `X`、N 个 graph instances 和标签集 `Y` 在 Preliminaries 定义；目标是学习 `F:G→R^f` 并输出 classifier 的 label distribution。[证据 p.3，Section 3；“the goal of the graph-level classification task”；basis=explicit]
2. **state_problem**：方法总览把目标描述为 tail graphs 的 representation enhancement，同时兼顾 class imbalance 与 graph-size topology imbalance。[证据 p.3，Section 4；“enhancing the model’s capability to represent tail graphs”；basis=explicit]
3. **define_component**：Local Topology Encoding 计算 `M^Gi=D^{-1}A^Gi`，只保留 random-walk 从节点回到自身的 z-step landing probabilities，形成 `LE^Gi∈R^{|V|×z}`。[证据 p.3，Section 4.1.1，Eq. (1)；“only the landing probability of the node vj to itself”；basis=explicit]
4. **define_component**：Global Topology Encoding 从 Laplacian `L^Gi=D^Gi-A^Gi` 提取前 z 个 eigenvalues/eigenvectors，经 permutation-invariant `φ` 与 `ℓ` 映射为 `GE^Gi∈R^{|V|×d_h}`。[证据 p.4，Section 4.1.1，Eq. (2)；“global structural properties, such as subgraph frequency and connectivity”；basis=explicit]
5. **explain_mechanism**：Edge Drop 以 graph average degree `d^Gi=2|E^Gi|/|V^Gi|` 经 MLP 和 sigmoid 学习 graph-specific Bernoulli probability，再以 Hadamard product 作用于 adjacency。[证据 p.4，Section 4.1.2；“customizes learnable perturbations based on the unique characteristics of each graph”；basis=explicit]
6. **explain_mechanism**：Feature Mask 对每个节点 feature sample Bernoulli mask，生成 `M_f^Gi` 并作用于 `X^Gi`；作者将 edge 与 feature 的 perturbation 强度绑定到 graph 特征而非统一固定。[证据 p.4，Section 4.1.2；“personalized feature mask distribution”；basis=explicit]
7. **instantiate_algorithm**：输入特征、GE、LE 经 MLP 后送入 GIN；Eq. (3) 更新 graph feature，Eq. (4) 用独立 GNN 层更新 local topology encoding。邻居来自扰动后的 `A~^Gi`，层数为 L。[证据 p.4，Section 4.1.3，Eq. (3)-(4)；“we also employ an independent GNN layer to update the local topology encoding”；basis=explicit]
8. **derive → connect_to_prediction**：Eq. (5) 对节点表示 READOUT 得到 `H^Gi`；N 个 graph representation 形成 `H`，再用 Feature Mixup 生成 `H~∈R^{2N×d_h}`。Mixup 的 Beta 插值细节放在 Appendix C.0.1。[证据 p.5，Eq. (5)；p.19，Eq. (13)；basis=explicit]
9. **define_component**：DBP 使用可学习 prototype embeddings `S=[s_1,...,s_K]∈R^{K×d_h}`，且 `K≪N`；其设计目标是从 graph data 提取可共享 prototype features。[证据 p.5，Section 4.2；“prototypes are defined as a set of learnable embeddings”；basis=explicit]
10. **derive**：Prototype Perception 用 graph-prototype attention 的 `TopK_1` 选择与每个 prototype 匹配的 graph，再经 Softmax 和 `W_v` 聚合成 `H~_S`。[证据 p.5，Eq. (6)；“Prototypes are perceived from the graph data based on the attention coefficients”；basis=explicit]
11. **derive**：Prototype Balance 用 `TopK_2` 为每个 graph 选择最相关 prototype，加上 learnable `γ` 后经 Sigmoid 得到增强表示 `H^b`。[证据 p.5，Eq. (7)；“selecting the most relevant prototype to enhance its representational capacity”；basis=explicit]
12. **state_problem**：作者指出两阶段迭代学习仍可能因 imbalanced graph distribution 使 prototype 偏向 head data，因此引入 Information Bottleneck 以降低 prototype 对 input graph 的依赖。[证据 p.5，Section 4.2；“these learned prototypes may become biased due to imbalanced graph data distributions”；basis=explicit]
13. **derive → theory**：Theory 1 用 `min I(S;G)-βI(S;Y)` 表述 prototype 的信息瓶颈；作者把 supervised learning 对 `I(S;Y)` 的优化与降低 `I(S;G)` 的目标分开解释。[证据 p.5，Eq. (8)；“reducing the redundancy of imbalanced input information”；basis=explicit]
14. **derive → connect_to_prediction**：Proposition 1 把 activation probability distribution `P` 与 auxiliary prior `U` 联系起来，主文写成 `min KL(P||U)≈min 1/2 Σ(pk-uk)^2`；附录从 mutual-information upper bound、empirical distribution 和 Taylor expansion 逐步推导。[证据 p.5-p.6，Eq. (9)；p.20-p.22，Eq. (17)-(31)；basis=explicit]
15. **derive → instantiate_algorithm**：Proposition 2 为 2N 个 graph、每 graph 命中 `TopK_2` 个 prototype 定义总 hit count 和 per-prototype `n_k`，用 modulation vector `η` 进入 TopK score，形成 Eq. (10)-(12) 的 non-differentiable TopK surrogate 更新。[证据 p.6，Eq. (10)-(12)；“TopK operation is non-differentiable in practice”；basis=explicit]
16. **contrast_alternative**：附录 D.3 逐一给出 Uniform、Zipf、Exponential、Poisson 四个 U 的调节目标；D.4 的 Table 6-7 选择 Uniform，因为四个 class/topology 数据集的 Macro-F1 与 Micro-F1 均为四种 prior 中最高。[证据 p.23-p.25，Eq. (36)-(43)、Table 6-7；basis=explicit]
17. **connect_to_experiment**：DBP 增强表示的前 N 行送入两层 MLP decoder 预测 `Y_hat`；Algorithm 1 进一步把 cross-entropy 更新 `Θ` 与 sign-based `η` 更新分成两步。[证据 p.6，Section 4.2；p.25，Algorithm 1；basis=explicit]

**动作转移序列**：`setup_notation → state_problem → define_component → explain_mechanism → instantiate_algorithm → derive → theory → derive → connect_to_prediction → contrast_alternative → connect_to_experiment`。正文把组件、信息瓶颈解释和实验接续在同一条线；证明的大部分细节移到 Appendix D，方法读者需要跨 p.5-p.6 与 p.19-p.24 才能复原目标函数到更新规则的完整链条。[证据 p.3-p.6、p.19-p.25；章节和公式顺序；basis=interpretation]

### 形式对象、假设和组件作用

- **输入/输出**：输入是 N 个带节点特征的 graph instances；训练中经 Feature Mixup 扩为 2N 行表示，DBP 输出增强 graph representations，decoder 输出 graph-level label distribution。[证据 p.3、p.5-p.6、p.25；basis=explicit]
- **状态变量**：`H`/`H~` 是 graph representations，`S` 是 K 个 learnable prototypes，`γ` 是 prototype score 偏置，`η` 是 load regulation coefficient，`Θ` 是模型参数。[证据 p.5-p.6、p.25；Eq. (6)-(12)、Algorithm 1；basis=explicit]
- **假设**：`K≪N`；prototype activation 可用 probability distribution P 汇总；TopK2 命中数能代表 prototype load；`U` 作为 auxiliary prior；supervised training 足以优化 label-relevant information。作者未给出独立的 identifiability、distribution shift 或 convergence 条件。[证据 p.5-p.6、p.20-p.24；basis=explicit]
- **组件对应问题**：LE/GE 回应局部/全局 topology information；personalized perturbation 回应统一 augmentation 对 tail graph 可能不友好；DBP 回应 head graph 对 shared prototype 的 dominance；BalOpt 回应 prototype activation skew；Feature Mixup 回应 tail representation diversity。[证据 p.2-p.5、p.9、p.19、p.35；basis=interpretation]

### 公式与理论结果

正文和附录共有 47 个带编号公式。Equation list 在 JSON 中逐项记录；核心分段为 Eq. (1) local random-walk encoding、Eq. (2) global Laplacian encoding、Eq. (3)-(5) GIN/readout、Eq. (6)-(7) DBP、Eq. (8)-(12) Information Bottleneck/load balancing、Eq. (13) Feature Mixup、Eq. (14)-(43) theory proof/priors、Eq. (44)-(45) imbalance ratios、Eq. (46)-(47) Macro/Micro-F1。[证据 p.3-p.6、p.19-p.26、p.31；basis=explicit]

- **Theory 1，Information Bottleneck**：前置对象为 training graph G、prototype S、label Y；结论是优化 `I(S;G)-βI(S;Y)`，作者把 label-relevant information 交给 supervised learning，把剩余目标解释为压缩 imbalanced input redundancy。Appendix D.1 通过 Markov chain `Y↔G→S→Y_hat` 和 Data Processing Inequality 说明信息路径，但它是解释性推导，未给出 UniImb 收敛或泛化定理。[证据 p.5，Eq. (8)；p.20，Eq. (15)-(16)；basis=explicit]
- **Proposition 1，Prototype Load Balancing**：P 是 prototype activation distribution，U 是 empirical/auxiliary prior；作者把 mutual information 的可处理目标转为 `KL(P||U)`。Appendix D.2 先用 auxiliary marginal `r(s)` 给出上界，再使用 2N 个 graph 的 empirical distribution 和 Taylor expansion 得到近似。主文 Eq. (9) 与附录 Eq. (31) 的二阶项写法存在分母差异，详见 measurement disagreements。[证据 p.5-p.6，Eq. (9)；p.20-p.22，Eq. (17)-(31)；basis=explicit]
- **Proposition 2，Prototype-balancing Optimization**：定义每个 prototype 的 hit count `n_k=p_k K_total`，引入 η 调整 TopK2 similarity，使用 StopGrad 使 `η` 可通过 `L_M` 迭代更新；Uniform prior 时超出平均负载的 prototype 被惩罚。Appendix D.3 把同一规则展开为四种离散 U。[证据 p.6，Eq. (10)-(12)；p.22-p.24，Eq. (32)-(43)；basis=explicit]
- **证明位置**：Prop. 1 的完整 KL 上界、经验分布和 Taylor 推导位于 Appendix D.2 p.20-p.22；BalOpt 的 surrogate gradient 和四种 prior 的更新位于 Appendix D.3 p.22-p.24。p.20 出现 `According to Theorem 1`，但正文没有单独的 Theorem 1 陈述，疑似把 Theory 1 写成 Theorem 1 的交叉引用。[证据 p.20；“According to Theorem 1”；basis=explicit]
- **理论角色**：Information Bottleneck 是核心链上的解释与目标重写；Proposition 1 是 load balancing 的目标桥梁；Proposition 2 是可执行保证/优化规则；D.2-D.3 proof 是实现 surrogate 的证明性支撑。没有关于每个 tail class 必然受益、分类性能必然提升或 prototype uniformity 必然收敛的定理。[证据 p.5-p.6、p.20-p.24；basis=interpretation]

## 实验设计

### 研究对象与数据

- **总体范围**：论文声称在 19 datasets、23 baselines 上评估。19 的组成可由附录复原为 12 common graph classification datasets、AirGraph、3 个 MoleculeNet 3D datasets，以及 Enzymes、Letter-high、Letter-low 三个 multi-class datasets。[证据 p.1、p.7、p.26、p.33；“19 datasets”；basis=explicit]
- **Common datasets**：MUTAG、PTC-MR、PROTEINS、D&D、NCI1、DHFR、AIDS、FRANKENSTEIN、REDDIT-B、COLLAB、Synthie、IMDB-MULTI；覆盖 chemical、protein、social/collaboration、synthetic domain，9 binary 和 3 multi-class。[证据 p.26，Table 8；basis=explicit]
- **AirGraph**：2021-2023 年中国国家环境监测中心 hourly PM2.5，1,341 stations、28 provinces；节点为 stations，按 geographic distance 建 edge，节点取过去 24 小时 PM2.5，label 为未来 24 小时 province-average pollution。30,660 graphs 的 high/medium/low 比例为 6.86%/42.84%/50.30%，largest/smallest ratio 为 7.33。[证据 p.7、p.26-p.27、Figure 7；“30,660 graph instances”；basis=explicit]
- **3D conformers**：BBBP、BACE、HIV 来自 MoleculeNet；相应实验使用 SchNet、DimeNet、SphereNet，G2GNN/TopoImb/ImbGNN 使用 SphereNet，UniImb 只保留 core DBP module。[证据 p.7、p.10，Section 5.7；“we retain only the core DBP module”；basis=explicit]

### 切分、控制与训练

- **Class imbalance binary**：train 25%、validation 25%、test 50%；head/tail 按 class graph count 定义。附录给出 extreme `ρ=9`、medium `ρ=2.33`、low `ρ=1`，训练和 validation 在 binary 情况共享 class distribution。[证据 p.7、p.28，Table 9；basis=explicit]
- **Class imbalance multi-class**：train 25%、validation 10%、test 65%；按 exponential decay `N_i=N_0e^{-λt}` 采样，validation 每类等量；extreme `ρ≈100`、medium `ρ≈20`、low `ρ≈1`。[证据 p.7、p.28，Table 9；basis=explicit]
- **Topological imbalance**：8 个 datasets，10% train、10% validation、80% test；每类 train/validation 等量。按 graph node count 将最大 20% 置于 head、其余 80% 置于 tail，目标 ratio 因真实 size distribution 难以精确满足，最终使用近似 ratio。[证据 p.8、p.26、p.28-p.29，Definition 2/Table 10；basis=explicit]
- **Intertwined imbalance**；6 个 datasets，10%/10%/80% split。binary 训练 class ratio 1/9，再在每类内按 10% head graph/90% tail graph 构造 topology skew；multi-class 以 head class 对 combined tail classes 的 9/1 设计叠加每类内部 10%/90% topology split。[证据 p.9、p.29-p.30，Section 5.4/Appendix G.1.5/Table 11；basis=explicit]
- **Baselines**：主文分列 classic GNN、Graph Transformer、3D graph、class-imbalance、topology-imbalance 五类，具体包含 GIN、GCN、GraphSAGE、InfoGraph、GraphCL、GraphGPS、Exphormer、Graph-Mamba、SchNet、DimeNet、SphereNet、upsampling、reweighting、G2GNN、ImGKB、DataDec、SOLT-GNN、ImbGNN、TopoImb 等。[证据 p.7，Section 5.1；baseline list；basis=explicit]
- **实现**：40GB NVIDIA A100、PyTorch、Adam、learning rate 0.001；六个主数据集的 `K` 在正文写为 `{16,16,24,24,24,32}`，GNN layers `L=5`，φ=0.001；REDDIT-B、IMDB-MULTI、COLLAB 使用 one-hot node degree。[证据 p.7，Section 5.1；basis=explicit]
- **重复与误差**：所有实验重复 20 次，报告 average 和 standard deviation；Table 2 的 `*` 表示相对 best baseline 的 Wilcoxon Signed-Rank Test `p<0.05`。[证据 p.7，Table 2 caption；basis=explicit]
- **公平性处理**：作者发现 DataDec 原始代码用 test samples fine-tune SVM classifier，主文和附录改为只用 training set；这是 observed implementation correction，非独立 data-leakage audit。[证据 p.8、p.31；“we restrict all fine-tuning to the training set”；basis=explicit]
- **随机种子/失败阈值**：正文和附录说明 20 次重复，但未提供随机 seed 列表；没有预注册的失败判定、收敛阈值或停止规则。Algorithm 1 只写 `maximum epochs nor reached or not converged`。[证据 p.7、p.25、p.31；basis=explicit]
- **指标**：Macro-F1 对每 class 取 F1 后平均，Micro-F1 在全样本聚合 TP/FP/FN；作者明确指出 Micro-F1 更易受 head class 影响，Macro-F1 更适合观察 class balance。[证据 p.31，Eq. (46)-(47)；basis=explicit]

实验顺序为 U prior 选择 → extreme class/topology 主表 → backbone/ AirGraph applicability → intertwined scenario → component ablation → K sensitivity → 3D conformer → representation visualization；附录再补齐 all datasets、imbalance degrees、Micro-F1、perturbation variants、TopK1/TopK2 和 DBP-only。[证据 p.6-p.10、p.24-p.38；basis=interpretation]

## 最终判断

1. **单一主线**：论文把 class imbalance 与 graph-size topological imbalance 统一解释为 tail graph 对 shared representation/prototype 的贡献不足。UniImb 用 multi-scale topology encoding 和 graph-dependent perturbation增强输入，再以 DBP 的 prototype perception/balance 和 Uniform-prior load regulation 把训练影响导向更均衡的 prototype activation，最后用 cross-entropy 完成 graph classification。[证据 p.2-p.6，Sections 1、4；basis=interpretation]
2. **正文保留的决策关键内容**：双重 imbalance 缺口、Figure 1 pipeline、Eq. (1)-(12)、Information Bottleneck 目标、Uniform prior 选择、20-run 评测协议、Table 2-5 主结果、Figure 4-6 的组件/敏感性/表示诊断、以及 19 datasets 和 23 baselines 范围。[证据 p.1-p.10；basis=explicit]
3. **移入附录的细节**：Feature Mixup 公式、KL/Taylor proofs、Algorithm 1、ratio 定义、AirGraph/12 datasets 具体统计、class/topology/intertwined split、hyperparameters、Macro/Micro-F1 定义、低/medium 结果、all-dataset tables、TopK 扫描、backbone 和 DBP-only 结果、prototype structure visualization、limitations。[证据 p.17-p.38；basis=explicit]
4. **最有效模式**：Figure 1 先用维度流和 TopK selection 将复杂 DBP 具象化；Table 2-3 以同一列结构对齐多种 baseline；Table 5 用独立 3D domain 验证接口；Figure 6 用 before/after DBP 表示图补充数值表的机制直觉。方法、公式、组件删除和跨 backbone 表之间存在可追踪对应。[证据 p.3、p.7-p.10、p.35、p.37；basis=interpretation]
5. **最大叙事缺口**：信息瓶颈推导支持的是 mutual-information/KL 目标和 η surrogate，未闭合到 prototype uniformity 的 convergence、tail graph influence 的直接测量或分类性能 guarantee。AirGraph efficiency 和“dominant”叙述也主要依赖单图 bubble/多表平均，读者需要附录才能评估 per-dataset 异质性。[证据 p.5-p.6、p.20-p.24、p.9、p.32-p.38；basis=interpretation]
6. **可迁移规则**：当论文把两个数据偏斜统一成一个表示学习问题时，应同时给出共享状态变量、可执行的负载/贡献量、组件级反事实删除，以及按原始偏斜层级分层的结果表；否则统一框架只停留在命名层。[证据 p.3-p.10、p.31-p.38；basis=interpretation]
7. **适用边界**：该规则适用于 graph-level class/topology imbalance、拥有明确 graph representation pipeline 且可定义 tail/head 的任务。它不能由本文直接外推到 heterogeneous graph、few-shot/dynamic/anomaly task、无 graph-size 可比性的场景，也不能把 Information Bottleneck rationale 当成 convergence 或 generalization theorem。[证据 p.38，Appendix J；p.5-p.6、p.20-p.24；basis=explicit]
