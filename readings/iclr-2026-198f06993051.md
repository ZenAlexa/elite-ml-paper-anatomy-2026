## 5. 方法、理论和可执行对象

### 5.1 形式化对象与机制链

1. **问题与 reference**：合成语音是 one-to-many，同一文本不存在单一 ground-truth；设 `S` 为 speech signal，`R(S)` 为 feature representation，比较 synthetic empirical distribution `P̃(R(S̃)|D̃)` 与 real `P(R(S)|D)`，同时要求它与 noise distributions 区分。【p.3 §2，“one-to-many”】
2. **noise anchor**：`DNOISE` 包含 uniform noise、normally distributed noise、all ones、all zeros；作者选择 noise 而非 alternate anchors，理由是其不依赖 domain/speaker/confounder；noise reference URL 写在脚注。【p.3 §2】
3. **factorisation**：四个 factor 是 `GENERIC`（SSL embedding 的总体分布）、`SPEAKER`（speaker identity realism）、`PROSODY`（pitch/duration/rhythm）、`INTELLIGIBILITY`（ASR-derived features）。各 feature 分数先求 factor mean，再对 factor mean 求最终 unweighted mean。【p.3–4 §2】
4. **距离与归一化**：用对称、可区分不重叠分布的 2-Wasserstein distance `W2`/Earth Mover’s Distance；高维近似 multivariate Gaussian，一维使用 inverse-CDF integral。对每个 feature 以与 noise 的最近距离 `W2NOISE` 和与 real 的 `W2REAL` 计算 Eq. (1)，0 表示像 noise、100 表示像 real，>50 表示更接近 real。【p.4 “Computing Wasserstein distances”；Eq. (1)】
5. **feature update**：先将 ground-truth dataset 对半，计算一半对另一半的 TTSDS；平均低于 95 或跨 dataset 标准差高的候选被排除。Intelligibility 将 WER 换成 ASR final-layer activations；Prosody 将 HuBERT token length 换成去重 token/frame 的 utterance speaking rate，并加入 Allosaurus speaking rate；Generic 加 WavLM；多语言用 mHuBERT-147 和 XLSR-53。【p.4–5 “Updated factors and features”；Table 1】
6. **实验/benchmark 接口**：对 20 个 systems 和 4 个英语域计算 TTSDS2，与 MOS/CMOS/SMOS 做 Spearman rank correlation；Algorithm 1 将每语言的 YouTube 抓取、diarization、过滤、50 speaker-matched pairs、synthesis 和 TTSDS2 score 串起来。【p.6 §3.4；p.8–9 §4.1；Algorithm 1】

方法动作序列为 `state_problem → define_component → explain_mechanism → derive → connect_to_prediction → connect_to_experiment`。最紧的因果链是「one-to-many → distributional similarity → factor ensemble → W2 normalization → pre-registered-before-correlation feature screening → cross-domain rank correlation」。其中筛选阈值 95 是 feature selection 的操作准则，不是主结果的显著性阈值。【p.3–5 §2】

### 5.2 公式和理论角色

全文有 3 个显式 display equations，其中仅归一化分数标为 Eq. (1)；没有 Theorem、Lemma、Proposition、Corollary 或 proof block。两条未编号公式分别是高维 Gaussian 的 squared `W2`/Fréchet distance 和一维 inverse-CDF integral；它们解释实现所用距离，不构成独立收敛保证。【p.4 “Computing Wasserstein distances”】

|对象|页码|角色|前置与结论|
|---|---:|---|---|
|高维 squared `W2` 公式|4|`core_chain`|假设 feature distributions 以 multivariate Gaussians 近似，给出均值/协方差形式的 Fréchet distance。|
|一维 inverse-CDF `W2` 公式|4|`core_chain`|以 inverse CDF 差的平方积分给出 closed-form/integral 形式，说明 pitch 等一维特征的距离。|
|Eq. (1) TTSDS2 normalization|4|`core_chain`|用 `100 × W2NOISE/(W2REAL+W2NOISE)` 将 feature score 归一化到 0–100；factor 及最终均值在公式后定义。|

理论属于 metric definition、interpretation 和 diagnostic，不是 guarantee。论文写「each factor score requires computation of five Wasserstein distances」并声称 50–100 samples 足够，但没有给出复杂度界、误差界或独立样本量敏感性图。【p.4 Eq. (1) 后段】

### 5.3 表格、图和算法

- **Table 1（p.3）**：逐 factor 对照原 TTSDS 与 TTSDS2。Environment 被移除；Generic 增加 WavLM；Prosody 用 speaking-rate 替代 HuBERT token length 并加入 Allosaurus；Intelligibility 从 WER 改为 wav2vec/Whisper ASR activations；multilingual 版本替换 mHuBERT-147/XLSR-53。【p.3 Table 1】
- **Figure 1（p.5）**：F0 density 曲线，比较 Noise、Ground Truth、Synthetic；它是分布式评分的直观示例，没有误差表达。【p.5 Figure 1】
- **Algorithm 1（p.9）**：输入 `Languages L, TTS Models M`；外层遍历语言，逐关键词翻译/YouTube 搜索（`lastQuarter`、最短 20 分钟、最多 250、按 views），trim 5 秒、Whisper diarization、FastText language ID、单 speaker、最多 16 utterances；XNLI 过滤争议内容，Pyannote 过滤 crosstalk，Demucs 过滤 music；选 50 speaker pairs，拆 reference/synthesis，遍历模型合成并计算 TTSDS2，返回 `AllScores[m,l]`。【p.9 Algorithm 1；p.8–9 §4.1】

算法的关键不变量是同语言、speaker-matched 的 reference/synthesis pair 和按语言/模型存储 score；循环层级为 language→video→model，文本在 p.8–9 解释到组件级。论文没有给 Algorithm 1 的 time/space complexity，也没有把过滤阈值和失败恢复写入伪代码；H appendix 才给出争议过滤词和阈值。【p.9 Algorithm 1；p.20 §H】

### 7.2 主结果

1. **跨域相关性**：Table 3 中 TTSDS2 的 Clean `(0.75, 0.69, 0.73)`、Noisy `(0.59, 0.54, 0.71)`、Wild `(0.75, 0.71, 0.75)`、Kids `(0.61, 0.50, 0.70)` 分别对应 MOS/CMOS/SMOS；作者称平均 ρ=0.67，较原 TTSDS 相对提高 10%，且 TTSDS/TTSDS2 的相关性均 `p<0.05`。【p.6–7 §3.4；p.7 Table 3】
2. **与其他客观指标的相对位置**：作者称 RawNet3 与 X-Vector 的平均相关性约 0.6，SQUIM MOS 约 0.57；在 ECAPA-TDNN 后的其余指标平均低于 0.3。Table 3 显示部分单域/单 score 竞争者更高，例如 RawNet3 在 Wild MOS 为 0.85、X-Vector 在 Wild MOS/CMOS 为 0.82，故「TTSDS2 一致性」比「每个 cell 都最高」更准确。【p.7 §3.4、Table 3】
3. **主观分数和 TTSDS2**：Table 2 的 Ground Truth TTSDS2=93.21；E2-TTS=91.73、MaskGCT=91.76、F5-TTS=91.16。MOS 跨域最高的 E2-TTS=3.41，CMOS 的 GT=0、E2-TTS=−0.23；TTSDS2 排名并不与每一个 MOS/CMOS/SMOS 排名完全一致。【p.5 Table 2】
4. **可视化形态**：Figure 2 的 TTSDS2 被作者解释为更连续的尺度，SQUIM 和 X-Vector 出现 clustering；图上给出 overall 和 domain-specific Pearson `r`，但作者对黑箱指标的原因只写为可能 overfitting，未做机制识别。【p.7 Figure 2 及其后段】
5. **factor complementarity**：Appendix Table 8 的 Generic/Speaker/Prosody/Intelligibility 与 MOS 的 Pearson r 为 Clean `(0.42,0.84,0.38,0.47)`、Noisy `(0.59,0.86,0.46,0.59)`、Wild `(0.53,0.59,0.34,0.58)`、Kids `(0.80,0.70,0.60,0.63)`；作者称所有相关性 `p<0.05`，Speaker 在 Clean/Noisy 较强，Generic/Intelligibility 在 Wild/Kids 更互补。【p.19 Table 8】
6. **多语言 proxy validity**：比较 ground-truth language datasets 与 Uriel+ linguistic distances，regular TTSDS2 ρ=−0.39，multilingual TTSDS2 ρ=−0.51，均 `p<0.05`；负号符合高分表示距离小。Figure 3 还显示 ground-truth 分数跨语言范围较窄、低资源语言分数下降；这验证的是 typological-distance proxy，不是多语言 MOS 对齐。【p.10 §4.2；p.9 Figure 3】
7. **负相关/异常模式**：Appendix E.1 说明 WER 的负相关方向符合「WER 越高越差」，但 Kids MOS 最低仅 ρ=−0.45；MCD/PESQ 的负相关被提出可能与 oversmoothing 有关，即平均化输出在 metric 上变好而 human ratings 变差。该段是作者给出的解释性假设，不是额外实验。【p.19 §E.1】

### 7.3 统计处理与决策量

- **聚合单位**：每个 TTS system 在四域分别聚合 MOS、CMOS、SMOS，得到 gold ratings；相关性以 20 systems 的 rank 为主要单位。Table 2 再对四域做 mean over datasets；Table 7 保留 domain-wise raw values。【p.6 §3.2–3.4；p.5 Table 2；p.18 Table 7】
- **中心量/离散量**：MOS/CMOS/SMOS 表格使用均值和 `±`；Table 3、Table 4、Table 5、Table 8 报告单值相关性、系数或 score。论文未说明 `±` 的统计定义，Table 2 的 TTSDS2 也没有对应离散量。【p.5 Table 2；p.18 Table 7】
- **相关/拟合**：主决策量是 Spearman rank correlation；Figure 2 还画 overall/domain-specific least-squares fits 和 Pearson `r`；Table 4 的 learned weights 用 linear regression 最大化 MOS correlation；Table 8 用 Pearson r。【p.6–8 §3.4–3.5；p.19 Table 8】
- **检验与不确定性**：论文写 TTSDS/TTSDS2 相关和 Table 8 factor correlations `p<0.05`，Figure 7 只展示 significant `p<0.05` Spearman correlations；没有 bootstrap、Bayesian analysis、multiple-comparison correction、effect-size interval 或 seed-level CI。`p<0.05` 的检验方式和自由度没有说明。【p.6 §3.4；p.19 Table 8/Figure 7】
- **预设决策量**：摘要/结论以 `ρ>0.50` 和 average `ρ≈0.67` 作为强相关主张；§1.2 用 MOS/CMOS 与 GT 差 `0.05` 定义 parity；这些是作者的报告口径，不是正式预注册规则。【p.1 Abstract；p.2 §1.2；p.10 §7】
- **检验结果与实质意义**：作者将 `p<0.05` 和 ρ 大小并列报告，但未分别讨论统计显著性与实际可替代性；§5 明确指出最高 Spearman 不超过 0.8，TTSDS2 不能替代 subjective evaluation。【p.10 §5】

主结果的关键不利解释是：竞争者在某些 domain×score cell 更高，Table 2/3 的主体是 point estimate，平均跨域可能掩盖域异质性；多语言结果使用 typological distance 而非 gold MOS；作者正面承认这些边界，没有把 proxy 写成 human validation。【p.7 Table 3；p.10 §4.2、§5】

## 8. 消融、负面结果与自我设限

### 8.1 消融

- **等权 vs learned weights（Table 4）**：用 linear regression 在三个域训练、第四个 held-out 域评估的 LOOCV。Simple Mean 在 Clean `0.747>0.645`、Noisy `0.590>0.514`、Wild `0.752>0.658`，仅 Kids 为 Learned `0.853>0.606`；因此等权方案在 4 个 unseen domain 中胜 3 个。【p.8 Table 4 及 §3.5】
- **权重稳定性（Table 5）**：Generic/Speaker/Prosody/Intelligibility 系数随 training domain 变化；Clean 训练的 Generic=`−0.162`、Wild 训练的 Generic=`−0.017`，Wild 训练的 Intelligibility=`−0.020`，Kids 训练的 Prosody=`−0.032`；作者指出单因子与 human judgment 独立为正时，回归仍可产生负系数。【p.8 Table 5】
- **factor complementarity（Table 8）**：这是 additional result/机制支持，不是组件删除；它展示四 factor 与 MOS 的相关性差异，支持在非 read speech 中保留 Generic/Prosody/Intelligibility。【p.19 Table 8】
- **feature selection split**：在 correlation experiments 前用 ground-truth halves 检查候选；低于平均 95 或标准差高者排除。这是设计筛选，不是对最终模型的独立随机消融。【p.4 §2 “Updated factors and features”】
- **缺失的消融**：没有移除单个 factor、逐项恢复 Environment、替换 noise anchor、改变 unweighted mean、改变 50–100 samples、改变 filtering threshold 或报告 compute scaling 的实验；这些均为 `not_present`，不能从 LOOCV 推断机制闭合。【p.3–4 §2；p.8 Table 4/5】

消融占正文约 8.5%（Table 4/5 与 §3.5），不是完全迁移到 appendix；Table 7/8 和 Figures 7/8 在 appendix 承担额外域、factor 和相关性证据。

## 12. 最终判断

- **单一主线**：TTSDS2 充当针对 human-quality、one-to-many speech 的 distributional evaluator，而非生成模型。论文先保留原 TTSDS 的 perceptual factors/noise anchor，再用 pre-correlation feature screening、Wasserstein normalization 和 unweighted factor mean，最后连接受控听测与 multilingual recurring benchmark。【p.3–6 §2–3；p.8–10 §4】
- **正文保留的决策关键内容**：四域数据构造、200 人 MOS/CMOS/SMOS protocol、20 systems、Table 2/3 主结果、Table 4/5 等权消融、Algorithm 1、14-language Figure 3，以及 §5 的「不能替代主观评价」边界。读者能在正文重建主要 estimand、比较单位和核心结果。【p.5–10】
