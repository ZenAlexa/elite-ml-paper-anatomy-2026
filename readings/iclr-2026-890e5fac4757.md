## 5. 方法与理论

### 5.1 视觉空间恢复的最小因果链

1. **目标与投影**（p3，Sec. 2.1）：输入为 `N_v` 张图 `I_i ∈ R^{H×W×3}`；每张图有 depth `D_i`、pose `[R_i | t_i]`、intrinsics `K_i`。像素 `p=(u,v,1)^⊤` 通过 `P = R_i(D_i(u,v)K_i^{-1}p)+t_i` 进入 world point。该式直接连接 depth、camera 和 point cloud。
2. **depth-ray disentanglement**（p3，Sec. 2.1）：每个像素的 ray `r=(t,d)∈R^6`，origin `t∈R^3`，direction `d=RK^{-1}p∈R^3`；dense ray map `M∈R^{H×W×6}` 同时存储两者。`d` 不归一化，让其幅度携带投影尺度；`P=t+D(u,v)·d` 通过逐元素运算生成一致点云。
3. **最小 target 选择**（p3–4）：作者将 point map 的 depth/camera entanglement 与额外 depth heads 视为冗余，使用实验 Tab. 5 支持 `depth + ray` 的充分性。ray map 对正交 rotation 的隐式表达消除了直接回归 valid rotation matrix 的约束。
4. **camera head 的工程补充**（p4，Sec. 2.1）：从 ray map 通过 DLT 取 pose 较慢，因此增加 `D_C`，在每个 view 一个 camera token 上预测 `f∈R^2`、quaternion `q∈R^4`、translation `t∈R^3`；它服务于 inference speed，ray head 仍保留密集几何监督。
5. **single transformer**（p4，Sec. 2.2）：预训练 Vision Transformer 的 `L` 个 block 划为 `L_s` 和 `L_g`；前 `L_s` 层在 view 内 self-attention，后 `L_g` 层交替 cross-view / within-view attention，实践比例 `L_s:L_g=2:1`。单图输入自然退化为 monocular depth，计算无额外 view 维度开销。
6. **pose conditioning**（p4）：每个 view 前置 camera token `c_i`；若有 `(K_i,R_i,t_i)`，用 `MLP E_c` 对 `(f_i,q_i,t_i)` 编码，否则用共享 learnable `c_l`。camera token 和 patch token 共同参加所有 attention。
7. **Dual-DPT**（p4，Fig. 3）：共享 reassembly 后分成 depth 与 ray 两个分支，每支有独立 fusion/output layers；共用已处理特征促进对齐，同时避免重复 representation。depth 还输出 confidence map。
8. **teacher–student**（p4，Sec. 2.3）：real depth captures、3D reconstructions 和 synthetic data 混合；synthetic-only monocular relative-depth teacher 生成 dense pseudo-label，再以 RANSAC least squares 对齐原始 sparse/noisy depth，目标是保留几何准确性并补足细节。
9. **联合训练目标**（p4–5）：所有 ground-truth signal 先除以 valid reprojected point map 的 mean `ℓ_2` norm；损失由 depth、ray、reprojected point、optional camera 和 depth-gradient 项构成，正文设 `α=β=1`，附录给出 confidence-aware depth 与 gradient 细式。
10. **FF-NVS 扩展**（p5，Sec. 2.4）：在同一 visual tokens 上添加 `GS-DPT`，预测每像素 opacity、rotation quaternion、scale、RGB color 的 camera-space 3D Gaussian 参数；estimated depth unproject 到 world position，再按给定 camera pose rasterize novel views。

方法动作转移序列为：`setup_notation → state_problem → derive → define_component → explain_mechanism → contrast_alternative → define_component → instantiate_algorithm → connect_to_prediction → connect_to_experiment`。本文没有独立理论章节，理论性内容仅作为几何表示、损失和评测定义的可计算机制；无 theorem/lemma/proposition/corollary/proof 或复杂度定理。

## 6. 实验设计与统计

### 6.1 研究对象、数据与任务

- **Pose/geometry benchmark**：HiRoom 29 scenes（internal high-fidelity synthetic room）、ETH3D 11、DTU 22、7Scenes 7、ScanNet++ 20，共超过 89 scenes；从 object-centric 到 indoor/outdoor。HiRoom 与 benchmark 计划公开。
- **Pose accuracy**：同五个数据集，直接比较 predicted camera trajectory；报告 `Auc3`、`Auc30`，均为 relative rotation/translation score，越高越好。
- **Geometry accuracy**：用 predicted poses + predicted depths 融合 point cloud；`evo`（Umeyama）对 predicted pose 与 ground-truth pose 对齐后，以 F-Score 评估，DTU 使用 Chamfer Distance（mm）。pose-free 与 pose-conditioned 两种输入条件并列。
- **NVS benchmark**：DL3DV 140 scenes、Tanks and Temples 6、MegaDepth 19；每场景约 300 sampled frames，ground-truth camera poses 由 COLMAP 提供；报告 PSNR、SSIM、LPIPS，但 Table 4 仅展示 PSNR 和 LPIPS。
- **NVS 输入与训练**：正文称在 DL3DV-10K training set 统一训练并评估；附录明确每场景每 8 帧取 target novel views，从其余视点以 translation/rotation farthest point sampling 选 12 context views。NVS 所有模型重训，通常 8 A100、200K steps、batch size 1；pixelSplat 为 100K steps，分辨率 `270×480`。
- **主 geometry training**：128 H100、200K steps、8K warm-up、peak learning rate `2×10^-4`；分辨率随机取 `504×504`、`504×378`、`504×336`、`504×280`、`336×504`；`504×504` 时 view count uniform `[2,18]`，batch 动态保持 token count 近似恒定；120K steps 后由 ground-truth depth 过渡到 teacher labels，pose conditioning 随机激活概率 0.1。
- **训练数据**：Table 9 列出 pose-geometry train 的 AriaDigitalTwin/AriaSyntheticENV、ArkitScenes、BlendedMVS、Co3dv2、DL3DV、HyperSim、MapFree、MegaDepth、MegaSynth、MvsSynth、Objaverse、Omniobject、PointOdyssey、ReplicaVMAP、ScanNet++、ScenenetRGBD、TartanAir、Trellis、vKitti2、WildRGBD 等；NVS train 为 DL3DV 10015、Tanks and Temples 6、NVS benchmark 的 DL3DV 140。ScanNet++ 与 DL3DV 采用 scene-level train/test separation。
- **基线**：pose/geometry 包括 COLMAP、GLOMAP、DUSt3R、Fast3R、MapAnything、Pi3、VGGT；NVS 包括 pixelSplat、MVSplat、DepthSplat 与 Fast3R/MV-DUSt3R/VGGT backbone 对照。正文未给出代码 repository URL。

### 6.2 评测与统计口径

论文使用跨数据集表格的 point estimate：每个 dataset/setting 给一个指标，未报告 seed-level spread、standard deviation、bootstrap interval、confidence interval、p-value、multiple-comparison correction 或 Bayesian posterior。未给出训练随机种子；附录只说明 pose 场景超过 100 images 时用 fixed random seed 随机抽取 100 张。没有 human evaluation；属于 `not_applicable`。也没有单独的 failure threshold 或 preregistered hypothesis list。

- **Pose AUC**（App. B.2, p20）：先计算 Relative Rotation Accuracy（RRA）和 Relative Translation Accuracy（RTA）随 threshold 的准确率曲线，再以每个 threshold 的 `min(RRA,RTA)` 曲线积分；主要报告 threshold 3 和 30，对应 Auc3/Auc30。
- **Reconstruction**（App. B.3, p20）：用 `dist(R→G)` 与 `dist(G→R)` 定义 accuracy/completeness；按距离阈值 `d` 计算 precision/recall，再报告 `F1=2×precision×recall/(precision+recall)`；DTU 单独报告 CD。
- **NVS**：Table 4 用 PSNR（越高越好）和 LPIPS（越低越好），正文 Sec. 3 还声明 SSIM；每个场景/novel view 的具体聚合方式没有说明。
- **teacher monocular depth**：Table 3 报告 KITTI、NYU、SINTEL、ETH3D、DIODE 的 `δ1` 与 Rank；附录 Table 11–13 追加 `AbsRel`、`SqRel`。逐数据集数值与 Rank 是决策量，没有不确定性。

## 9. 结论、限制与闭环

### 9.1 结论段落动作

- p10 第 1 段：`重述方法 → 回收机制 → 回收 benchmark 结果`。它把 plain transformer、depth-and-ray、teacher–student、scale-aware depth、per-pixel ray、adaptive attention 和 FF-NVS backbone 串成单一最小模型主线。

- p10 第 3 段：`impact_claim`。希望 model、dataset、benchmark 与 simple modeling principles 推动 general-purpose 3D perception；属于愿景性结尾。

## 13. 最终判断

1. **单一主线**：将“任意视觉输入恢复一致视觉空间”压缩成可扩展的 `depth + per-pixel ray` dense target，以预训练 single transformer 和 input-adaptive cross-view attention 完成跨 view 交互；teacher–student 负责跨质量数据，camera head 负责快速 pose extraction，GS-DPT 证明几何 backbone 可转移到 FF-NVS。
2. **正文保留的决策关键内容**：ray 表示与点云生成式、单 transformer／camera token／Dual-DPT 架构、teacher pseudo-label 逻辑、五数据集 pose/geometry benchmark、三数据集 NVS 结果、两个核心 ablation（target 与 transformer）以及主要速度／规模数字。
3. **附录迁移与自足性**：DLT/RQ、loss 细节、teacher 的 normal/mask 目标、scene-level sampling/alignment、dataset voxel/threshold、训练预算、baselines 和扩展消融均移入 appendix；决策主线仍可从正文复述，但 geometry/NVS 复现无法仅凭正文完成。
4. **最有效模式**：Figure 1 先把输入、统一中间表示与多任务输出画成一张视觉契约；正文以同一 benchmark 顺序贯穿 Table 1–4，再用 Table 5–6 对 representation 与 architecture 做最小对照；Eq. (1)–(7) 延后到 appendix 让方法主线保持短。
5. **最大叙事缺口**：跨数据集 point estimates 没有不确定性；NVS “correlates” 没有相关统计；teacher label、pose conditioning 的消融条件不完全对齐；ScanNet++ bias 和 ground-truth pose 依赖虽已明示，但限制没有单独章节集中回收。
6. **可迁移规则**：若主张是统一 representation，正文应先给可计算的输入、表示与输出链，再安排一个 target-level ablation 和一个 architecture-level ablation；所有会改变复现或因果解释的 sampling、alignment、loss、预算和数据隔离写入可定位 appendix。
7. **适用边界**：该规则适合有明确中间表示、可做组件替代且 benchmark 可覆盖输入条件的视觉／系统论文；对纯理论论文、只有单一任务或无法构造受控 ablation 的工作，需改写为 theorem-to-corollary 或 mechanism-to-prediction 的闭环。
