## 方法与理论：从递推式到可缓存校正

**形式化对象。** §3.1 在 DDIM 设置中把 full-precision noise estimator 记为 `μθ`，量化模型记为 `μ̃θ`，同一步误差为 `εt`，累计状态偏差为 `δt`，并以 `δT=0` 作为递推起点 [p.5, Eq. (3)–(8)]。Eq. (7) 以 `δt−1 = At δt + Bt εt` 把前一累计误差、当前误差和 Jacobian 联系起来；Eq. (8) 展开为 cumulative error 的闭式求和。

**两项化简。** Approximation 1 忽略 `Jxt`，将矩阵连乘化为 α 比值 [p.5, Eq. (9)]，得到 Eq. (10)。Approximation 2 将时间窗口截断为随后 `m` 步 [p.6, Eq. (11)]；正文直接说在有界误差与上界缩小目标下 `m=1`，Appendix B 给出不等式推导，Appendix C 用 Table 5 比较 Eq. (10) 和 Eq. (13)。因此最终形式只使用 `(t+1,t)` 两个量化输出 [p.6, Eq. (13)]。

**误差重建与 TCEC。** §3.3 用 `εt = Kt ⊙ μ̃θ(x̃t,t)` [p.6, Eq. (14)]，以带 `λ1` 的 MSE 拟合每个 timestep/channel 的 `K` [p.7, Eq. (15)–(17)]。模型用 calibration data 离线缓存 full-precision 和量化输出，推理时只保留上一时刻 feature map；Eq. (18) 把 `K` 代回两步 correction。每个组件都回应前文问题：Eq. (7)/(8) 解释累积，近似使求解可算，`K` 解决未知的 `εt`，Eq. (18) 成为在线补偿项。

**理论清点。** PDF 中有 45 个 numbered/displayed equations：正文 Eq. (1)–(18)，附录 Eq. (19)–(45)。没有标作 Theorem、Lemma、Proposition 或 Corollary 的结果，也没有 pseudocode/Algorithm。因而「严格理论」主要是带显式假设的推导，不是经命名定理封装的保证。Appendix A 给出 `Bt·Jxt` 相对主项的 Table 4 数值；Appendix B 的 `m=1` 结论依赖有界 `εk`、有界 Jacobian 和其导出的比较不等式；Appendix D 的 DPM++ 版本还显式忽略高阶 Taylor 项并采用 truncated SVD [p.16, Eq. (37)–(45)]。

段落动作序列为 `setup_notation → state_problem → derive → define_component → explain_mechanism → contrast_alternative → derive → give_intuition → instantiate_algorithm → connect_to_experiment`。

## 结果、统计与图表

### 主结果

- **SDXL W4A4**：Table 1 的 TCEC+SVDQuant 在 sDCI 上 PSNR 为 21.9，对 SVDQuant 的 20.7，高 1.2；同一行 sDCI FID 为 23.4，对照 26.3 [p.8, Table 1]。这正是摘要的数值例子。表未给误差条或统计检验。
- **SDXL-Turbo W4A4**：MJHQ IR 从 0.816 到 0.833，sDCI IR 从 0.671 到 0.691；作者把较小增益解释为迭代步数少、累积误差小 [p.9, §4.2；p.18, Table 7]。
- **PixArt 的 W4A4**：MJHQ FID 从 19.2 到 18.1，sDCI PSNR 从 16.5 到 16.9 [p.8, Table 1]。这与 Appendix D 的「可适配 DPM++」叙事相连，但表不隔离 solver 的作用。
- **OpenSora**：W8A8 的 Imaging Quality 为 65.56，对 ViDiT-Q 的 63.48；W4A8 为 64.97，对 61.07 [p.9, Table 2]。正文还挑出 motion smoothness 与 scene consistency 的改善。表内 W8A8 Dynamic Degree 61.09 略低于 ViDiT-Q 的 61.11，因此并非每个单元格都上升。
- **时延**：Table 3 的 four pairs 从 26.211→26.316、49.67→49.894、118.45→119.029 与 9.947→9.996 seconds；正文据此称 E2E overhead `<0.5%` [p.9–10, Table 3]。未给重复次数或方差。
- **附录的机制/边界证据**：Table 4 报告 `Bt·Jxt` 相对主项为 0.107%、0.194%、0.454% [p.13]；Table 5 显示 Eq. (13) 在 SDXL 上 FID 16.0、PSNR 27.3，优于 Eq. (10) 的 16.5、26.1 [p.16]；Table 7 报告 2-step SDXL-Turbo 的 Avg improvement 为 0.2，而 3-step 为 0.5 [p.18]。

## 消融、负面信息与限制

主文没有独立 ablation；其正文版面占比可视为 0%。近似、`λ1`、steps、calibration size、DPM++ 推导和额外 QNCD 对照在 Appendix A–J。消融的识别目标分别是：忽略 Jacobian 的数量级合理性（Table 4）、two-step 截断（Table 5）、regularizer 选择（Table 6）、步数阈值（Table 7）、校准规模与域迁移（Table 8）以及与单步校正的比较（Table 9）。

论文的显式自我设限较少：

- 直接计算 Eq. (8) 被称为不可接受，因而需要 Jacobian 忽略和 temporal locality 近似 [p.5–6]；这是 `compute`/`assumption` 边界。
- `m=1` 的上界论证要求有界 per-step error 与 Jacobian 等条件 [p.13–15]；正文没有把条件放入贡献列表。
- TCEC 在少于 3 steps 时改善通常 `<0.2`，作者将其归因于可累积误差不足 [p.18, Appendix G]；这是 `scope` 边界，但摘要、引言和结论均未提。
- 文中没有专门 limitations 节，亦未报告随机种子、离散度、显著性或不确定性表达；这是可复现实证边界而非作者主动声明。

可验证的呈现策略是：将所有适用步数边界和近似验证置于附录；正文叙述选择了改善较大的结果维度，而完整表格仍暴露小幅反向单元格（例如 OpenSora W8A8 Dynamic Degree）。这是位置与叙述范围的事实，不足以推断作者意图。MixDQ W4A4 的异常 FID/IR 在正文 p.9 被主动报告为 quantization failure，而没有被隐藏。

## 用词与修辞

高频领域名词是 `quantization error`、`cumulative error`、`per-step`、`diffusion models`、`correction`、`timestep-aware`；这些术语服务真实的误差因果链，不属于通用模板语。主要对比连接词为 `Although`、`In contrast`、`Contrarily`、`Unlike`；主要因果连接词为 `Consequently`、`Therefore`、`This implies`、`This demonstrates`。主张动词集中在 `develop`、`propose`、`derive`、`present`、`introduce`、`observe`。在正文散文中，精确 `we propose` 出现 3 次，`we observe` 1 次，`we develop` 2 次，`we derive`/`we present`/`we introduce` 各 1 次；精确 `we show`、`we find`、`we demonstrate` 没有出现，但有 `we experimentally demonstrate` 和非第一人称的 `experiments demonstrate`。

强断言（`first`、`rigorous`、`significantly`、`SOTA`、`clear advantage`）集中在摘要、贡献列表、结果与结论；条件性语言（`approximately`、`under mild regularity conditions`、`can`、`partial`、`negligible`）集中在推导和附录。就论证位置而非机械 token 比例看，前者在 framing 略多，后者承担实际可成立的条件。高频语围绕 `εt → δt → Δt` 的重复机制链，而非会议模板。

## 最终判断

1. **单一主线**：量化模型在迭代去噪中将单步误差累积为轨迹偏移；把该偏移写成可近似的递推，再用校准得到的 channel-wise 系数在线抵消，可在已有 PTQ 底座上改善质量。
2. **正文保留的决策关键内容**：误差变量、Eq. (7)/(8)/(18)、量化配置、跨模型主表、视频表和 latency 表都在正文，足以看懂算法及主要 trade-off。
3. **迁移到附录的细节及代价**：Jacobian 忽略的数量级、`m=1` 条件、DPM++ 推导、`λ1`、步数/校准敏感性和 QNCD 比较都在附录。迁移保持了主文流畅，但削弱了读者对「理论 grounded」和 solver/low-step 范围的即时判断。
4. **最有效模式**：先用 Eq. (7) 把故事压缩成一个可解释的 state recurrence，再以 Figure 1 和 Table 1/2/3 分别承担机制、质量和部署判断；图表各有单一任务。
5. **最大缺口/读者成本**：没有命名定理或不确定性报告，少步数收益边界藏在 Appendix G，且「cumulative error 是 primary cause」没有独立因果消融。读者需要横跨正文与 9 页附录才可检查这些限定。
6. **可迁移规则**：当论文声称一个迭代系统的误差「会累积」时，正文应给出最小递推、可计算的 correction 和匹配的质量/成本主表；决定近似是否可信的条件与敏感性必须紧邻主张或被明确召回。
7. **规则边界**：如果机制只需一次前向推理、没有可观测的递推状态，或精确递推本身不是论文的能力来源，就不应强行以 closed-form error story 组织全文。
