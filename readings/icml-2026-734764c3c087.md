## 引言与相关工作

引言先给出应用背景，再说明 mask-guided diffusion 的前置依赖，随后以 L1–L3 定义 training inefficiency、inference fragility、static prior utilization；K1–K3 将这些问题转换为三种需要的能力。〔p. 2 · §1 · “three critical limitations” / “three key capabilities”〕 接着引入 self-supervised prior、LoRA adaptive weighting 和 end-to-end mask-free inference，最后以三个 bullet 回收对应贡献。〔p. 2–3 · §1 · “Therefore, we introduce CLEAR” / contribution list〕

贡献列表重述摘要中的三项机制而不重报性能数字或限制。可证伪主张为无需 inference mask、只训练 `0.77%` 参数及跨语言 zero-shot；后两项分别受到配置冲突和定性证据范围限制。〔p. 1–3 · Abstract / §1；p. 4, 6–8 · Figure 3 / §4.2 / Table 1〕

相关工作是独立 §2，约 510 词、正文约 8.2%。它以 taxonomy 组织 image text removal、video text removal、large-scale video diffusion 与 general video inpainting 四簇；结尾用 mask、全参训练、external pipeline、uniform weighting 四个维度与 CLEAR 对比。〔p. 3 · §2.1–§2.2 · “Image-based approaches include” / “Existing video inpainting methods require”〕 §4.1 重新调用 ProPainter、MiniMax-Remover、DiffuEraser 作为基线，故引用也承担实验选择功能。〔p. 6 · §4.1 · “three state-of-the-art video inpainting methods”〕

## 方法与理论

输入为带烧录字幕视频 `Xsub`，输出为 `Xclean`；训练不需 pixel-level mask，推理不需 external detection modules。〔p. 3 · §3.1 · “without requiring pixel-level mask annotations”〕

Stage I 以 `Δt = ||Xsub_t − Xclean_t||₂` 与 per-frame `μ+σ` 阈值构造 noisy `M̂`；dual ResNet-50 encoders 形成 `Fsub`、`Fcontent`，以 orthogonality、adversarial purification、BCE region loss、reconstruction 构成 `Lstage1`，并由 4-layer UNet 得到 `Mprior`。〔p. 3 · §3.2.1 · Eq. (1)–(2)；p. 4 · §3.2.2 · Eq. (3)–(9)；p. 7 · “dual ResNet-50”〕

Stage II 冻结 video diffusion transformer，在 attention/FFN 注入 LoRA；middle-layer 2.1M head 产生 `Mpred`。论文将 `Mpred` 定义为 weighting function 而非 inference output；它通过 `w`、dynamic `α(k)`、`εgen` 调制生成，并由 `Ldistill + Lgen + 0.1Lsparse` 训练。`Lgen` 对 `Mpred` 回传梯度，是 generation feedback 的机制落点。〔p. 5 · §3.3.2–§3.3.5 · Eq. (10)–(17)；p. 6 · Eq. (18)–(22)〕

Algorithm 1 从 `Xsub` 和噪声 latent 作 DDIM denoising，内部计算但不导出 `Mpred`，不需要 `Mprior`、detector 或 segmentation module。〔p. 6 · §3.4 / Algorithm 1 · “internal, not output”〕 方法动作可压缩为 `setup_notation → derive pseudo-label → define_component → derive losses → explain weighting → instantiate_algorithm → connect_to_prediction`。Figure 2、3、4 分别承担概览、完整管线和 prior refinement。〔p. 2 · Figure 2；p. 4 · Figure 3；p. 5 · Figure 4〕

正文有 25 个编号展示公式（Eq. (1)–(25)），附录有 4 个（Eq. (A1)–(A4)）；没有 theorem、lemma、proposition、corollary 或 proof。它们是建模和机制解释，不构成形式化 guarantee。〔p. 3–7 · Eq. (1)–(25)；p. 12 · Eq. (A1)–(A4)〕

## 结果、统计与可视化

## 消融、负面项与局限

Table 2 按序加入 Stage I focal weighting、context distillation、context-aware adaptation、context consistency；PSNR 从 LoRA-only 的 21.62 到 CLEAR 的 26.80，文中将增量写为 `+1.49`、`+1.61`、`+0.37`、`+1.71 dB`。〔p. 9 · §4.4 / Table 2 · “cumulative 5.18 dB”〕

不利项也可在主表中核对：M1 加入后 PSNR 上升，但 VFID 从 34.74 变差为 38.21，DISTS 从 0.088 变差为 0.091；紧随的段落聚焦 PSNR 递增和最终 synergy，并未解释该早期反转。这是叙述焦点的观察，不推断作者动机。〔p. 9 · Table 2；p. 9 · “each subsequent component providing incremental gains”〕

Table 3 更直接呈现 trade-off：steps 5→10 的 PSNR 增加 2.63 dB，但 TWE 变差、时间 4.86→9.92 s/frame；`cfg=1.2` 和 `lora scale=1.5` 被描述为带来 temporal artifacts 或 over-smoothing。〔p. 9 · §4.4 / Table 3 · “quality-diversity trade-off”〕

没有专门 Limitations 节。结论将 real-time inference optimization 和其他 occlusion-removal task 留作 future work；Impact Statement 承认 misinformation misuse 风险并计划以 license stipulations 缓解。训练约一天／8 GPUs 是计算边界，但不是作者以 limitation 名义提出的限制。〔p. 7 · §4.2；p. 10 · §5 / Impact Statement · “Future work” / “potential for misuse”〕

## 修辞、差异与最终判断

排除 references、公式碎片和表格数值后，高频实词是 `subtitle(s)`、`mask-free`、`context-aware`、`adaptive`、`prior(s)`、`generation`、`video`、`training`、`inference`；高频短语是 `mask-free inference`、`context-aware adaptive learning`、`self-supervised prior learning`、`adaptive weighting`、`zero-shot generalization`。主张动词集中于 `present`、`introduce`、`achieves`、`outperforms`、`demonstrate`、`validates`；强断言多在摘要、引言、结果，弱化／权衡表达主要在 Table 3 段。〔p. 1–10 · title / Abstract / §1–§5；文本观察〕

可直接核对的内部差异如下。

1. 摘要／结论称 `0.77%`；Figure 3 写 `rank r=8`、约 112M、`0.8% of 14B`；§4.2 写 base 为 1.3B、rank 为 64，Table 1 亦写 `rank=64`。这些配置不能由单一参数设置同时满足。〔p. 1 · “0.77%”；p. 4 · Figure 3 · “Rank r=8” / “14B”；p. 6–8 · §4.2 / Table 1 · “1.3 billion” / “rank=64”〕
2. Figure 3 标 triangular `α` schedule、`Tperiod=30`；Eq. (16) 是 sine 形式；§4.2 又称 triangular oscillation 且 `Tperiod=40`。文稿没有给出将该公式限制在 `[5,15]` 的变换。〔p. 4 · Figure 3；p. 5 · Eq. (16)；p. 7 · “Tperiod = 40”〕
3. 摘要与 §4.3 写 `-74.7% VFID reduction`；Table 1 最低 baseline 是 72.51，对 CLEAR 20.37 的 reduction 约为 71.9%，其他列示 baseline 也不产生 74.7%，且未指定 denominator。〔p. 1–2 · Abstract；p. 8 · §4.3 / Table 1〕
4. Figure 1、摘要和主文列 German；Figure A3–A5 captions 改列 Arabic，p. 15 图内可见 German。没有说明替换关系或是否七语言。〔p. 1–3 · Figure 1 / Abstract / §1；p. 14–15 · Figure A3–A5〕

单一主线是把训练期从 paired video 学得的 noisy prior，蒸馏到推理期 LoRA diffusion 内部的 adaptive weighting，从而把 mask-dependent pipeline 改述为只输入 `Xsub` 的 removal。〔p. 2 · Figure 2；p. 3–6 · §3；p. 10 · §5〕

最有效的写作模式是将 `Mprior → Mpred → w → Lgen` 连续放入 Figure 3、Eq. (14)–(22)、Algorithm 1 和 Table 2，使机制能从接口、损失到组件结果追踪。最明显的反模式是参数效率／配置与 schedule 的互相冲突，以及核心跨语言主张缺少逐语言量化。〔p. 4–6 · Figure 3 / Eq. (14)–(22) / Algorithm 1；p. 9 · Table 2；p. 14–15 · Figure A3–A5〕

可迁移规则：对 noisy auxiliary signal，可把它作为训练期 soft supervision，让主生成损失向 lightweight weighting head 回传梯度，并以组件消融核验每一步；适用前提是集中固定并审计 backbone、adapter rank、参数比例、schedule 和 timing scope。〔p. 5–6 · Eq. (14)–(22)；p. 9 · Table 2–3；p. 4, 6–8 · Figure 3 / §4.2 / Table 1〕
