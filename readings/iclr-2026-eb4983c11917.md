# 单篇深读：Learning to See Before Seeing

## 1. 文档边界与单一主线

- **论文身份**：ICLR 2026 oral，paper_id `iclr-2026-eb4983c11917`，Junlin Han 等 7 位作者。
- **读取版本**：PDF 物理页 31 页，来源为 ICLR 官方 proceedings PDF。主文编号页为 1–10，references 位于 11–17，appendix 位于 18–31。第 11 页还承载 LLM 使用、ethics 与 reproducibility 声明，因此将它们记为正文后的 `other`，不计入编号主文页。
- **版面事实**：PDF 使用单栏正文，图和表多为整栏或跨栏宽度。主文把实验结果与 finding 框放在同一阅读流中，附录改为字母分节。未提供独立 supplementary 文件。

**单一主线**：论文把 text-only pre-training 中的 visual prior 拆成两条可分辨的能力链。reasoning prior 随 code、math、science 等 reasoning-centric data 的比例递增，并跨 vision encoder 转移；perception prior 更依赖广泛文本、encoder 与 visual instruction tuning。作者据此从 300B-token pool 先找视觉有利比例，再在 language-favorable 与 vision-favorable 端点之间插值，得到 mix6，并用 1T-token 的 7B 对照验证该 recipe。证据链横跨单源数据、比例混合、Spearman 结构分析、encoder 替换、instruction-data removal 与大规模复核（p. 4 §3.2，p. 5 §3.3，p. 7 §3.5，p. 8–10 §3.6–§4.2）。

### 5.2 理论对象

论文没有 theorem、lemma、proposition、corollary 或 proof。理论成分是解释性假设与可检验结构诊断，核心因果链是 `data composition → LLM latent reasoning/perception → MLLM category performance`。Appendix A.2 把 reasoning 的 modality-agnostic transfer 作为 hypothesis，Appendix A.3 把结构化语言与 visual representation alignment 的关系作为 hypothesis，作者明确这些不是 definitive conclusions。

### 主要结果

1. **Scaling（Figure 2）**：model/data size 通常提高 AVG VQA。General/Knowledge 随两者改善，OCR & Chart 对 model size 更敏感，Vision-Centric 中大模型从更多 data 获益而小模型较早 plateau（p. 4 §3.1）。
2. **Single-source（Figure 3）**：3B LLM 固定 30B tokens 时，不同 source 造成明显性能差异；Vision-Centric 超过 42% 的高分来自 reasoning-centric 与 visual-world source（p. 4–5 §3.2）。
3. **Proportions（Figure 4）**：reasoning-centric 比例提升至 75% 仍带来视觉收益，visual-world text 的初始加入关键，继续增加出现 diminishing returns（p. 5 §3.3）。
4. **Vision-favorable grid（Table 1）**：24 个 blend 的最高 downstream VQA 约在 reasoning 60%、visual 15%（p. 6 §3.4）。
5. **Balanced recipe（Table 2）**：mix6 为 overall rank 1，t-acc 52.7%、ppl 13.52、v-acc 33.3%；mix0 为 language baseline，t-acc 53.0%、ppl 13.46、v-acc 32.4%（p. 7 §3.4）。
6. **Structure（Figure 5）**：General/OCR Spearman 为 0.37，Knowledge/Vision-Centric 为 0.33，跨两簇相关为 -0.10、-0.03、0.08、0.07，支持 loosely coupled 的解释性拆分（p. 7–8 §3.5）。
7. **Encoder universality（Figure 6）**：MetaCLIP、DINO、MAE 的 reasoning-heavy task 都随 reasoning proportion 上升，perception-oriented trend 跨 encoder 更不一致（p. 8 §3.6）。
8. **Instruction-data removal（Figure 7）**：移除 perception-targeted tuning 对 perception-heavy benchmark 的影响最大；移除 reasoning-targeted tuning 对 perception task 的增量影响较小，对 reasoning task 为 modest drop（p. 9 §3.6）。
9. **1T scale-up（Table 3）**：Balanced 对 Language-Favorable 的 ppl 是 7.49 对 8.72，avg acc 是 0.655 对 0.647，overall VQA 是 38.64 对 37.32；约 600B tokens 后 Balanced 的 language performance 超过对照（p. 10 §4.1–§4.2）。
10. **MLE-Bench（Figure 8、Table 5）**：web-crawl 单源模型总体与小/中对象更有优势。外部模型中 GPT-5 weighted overall 82.97%，small/medium/large 为 73.63/90.69/86.31；Gemini 2.5 Flash small 为 58.88%，Claude Opus 4 large 为 59.86%（p. 18 §A.1，p. 27 §J）。
11. **Reasoning trace quality（Figure 9–10）**：code reasoning 从 0% 到 100% 时 Logical Soundness 从 4.52% 到 9.52%，Reasoning Depth 从 8.31 到 53.25；qualitative trace 也从简短错误理由转为应用规则的长解释（p. 19–20 §A.2）。
12. **Alignment hypothesis（Figure 11）**：structured reasoning data 的 alignment score 总体上升，在 75% 附近达到峰值，100% 回落；作者把回落解释为缺少多样 vocabulary 的可能结果（p. 20–21 §A.3）。
13. **Blind tuning（Table 6）**：Lang-Favorable overall 从 37.32 到 38.20，Balanced 从 38.64 到 39.56；Knowledge 增益最明显，OCR & Chart 反而下降（p. 28 §K）。
14. **Hallucination cases（Appendix L）**：无图提问时，若干模型仍给出选项或视觉叙述，另一些模型明确拒答；两个随机改写问题的案例显示 model strength 并不保证更少 hallucination（p. 28–30 §L）。

## 12. 最终判断

1. **单一主线**：把 text-only LLM 的 visual prior 识别为 reasoning 与 perception 两条来源不同的能力链，随后用 data mixture 操作它们并在 MLLM 与 1T-scale 对照中检验。
2. **正文保留内容**：保留四类 VQA 定义、scale/source/ratio 主实验、mix6 选择、Spearman 结构、encoder/removal 诊断与 Table 3 scale-up。这些内容直接改变 recipe 选择或因果解释。
3. **附录迁移**：optimizer、benchmark 清单、分类 prompt、parser、MLE 构造、blind hallucination 与 qualitative traces 移入附录。迁移没有阻断主线阅读，却使 exact replication、外部 benchmark 边界和 shortcut 风险依赖附录。
4. **最有效模式**：先用单源与比例操纵建立可解释的 response curves，再用 Figure 5 的 cross-category matrix 与 Figure 6–7 的 intervention-like checks 分开结构与来源，最后用 Table 2–3 收束到可执行 recipe。
5. **最大缺口**：Spearman cluster、reasoning trace 与 mNN alignment 都是有方向性的诊断，缺少跨 seed 方差、rank 聚合公式、独立因果干预与系统 bias audit；blind tuning 的性能增益同时伴随 hallucination 风险。
6. **可迁移规则**：当论文声称一个 latent capability 可拆分时，应先把子能力映射到互补 benchmark，再用组件替换或删除测试来源，最后用独立规模复核把诊断闭合到决策量。
7. **适用边界**：该规则适合 adapter-style MLLM、静态 image VQA 与可控 data mixture；对 end-to-end joint training、discrete visual tokenization、video、动态因果任务和 safety claims，需要另行设计识别与审计。
