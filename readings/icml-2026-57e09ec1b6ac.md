## E. 方法与理论

### 形式化对象、组件与动作链

- **输入与输出。** §3.1 首次定义 token input `x ∈ R^{b×d}`、N 个 experts、Top-k sparse gating 和 `f_SMoE(x)`；§3.2 给出 `f_SSMoE(x)`；Algorithm 1 在 p.17 给出 batch-token 输入 `X ∈ R^{B×L×D}` 与输出 `Y ∈ R^{B×L×D}`。
- **核心状态。** expert 的 `FFN_1^(i)`、`FFN_2^(i)` 生成 Gram matrices `A^(i)` 与 `B^(i)`；top-c 与 learned router embedding `r^(i)` 选出 eigenvector sets `C_1^(i), C_2^(i)`，均值形成 `C^(i)`；拼接得到 `W_EV`，再将 token 投影为 `f_EV(x)`。
- **组合目标。** 真实实现的 §3.2 把 `softmax(f_EV(x))` 与标准 router 的 `S(x)` 按 `α` 混合，再做 Top-k；`α` 在 p.4 被描述为依据 downstream task data 调节，经验范围为 0.5–0.9。
- **段落动作序列。** `setup_notation → define_component (SMoE) → define_component (Gram matrices) → define_component (top-c) → define_component (W_EV/f_EV) → instantiate_algorithm (SSMoE) → connect_to_experiment (α) → state_problem (collapse) → derive (Lemma 3.1) → explain_mechanism → connect_to_prediction`。

**理论的闭合范围。** Lemma 3.1 是主因果链的条件性保证，不是对实装 SSMoE 的无条件性能定理。原因是 §3.2 的实际 `V(x)` 混合两个 softmax 后的量，而 Lemma 3.1 定义为 pre-softmax logits 的线性组合；论文亦承认 selective variant 只满足 approximate decorrelation。这个差异是 `interpretation`，不是对公式真假的否定。文中没有报告 `E[f_EV,i s_j]` 或 `ε` 的实测值，因而其“理论支持实际 selective variant”的强度为部分闭合。

- 证据（explicit；p.4, §3.2）：`α values between 0.5 and 0.9 tend to produce optimal results`。
- 证据（explicit；p.4, §3.3）：`EV–learned independence`。
- 证据（explicit；p.5, §3.3）：`formal proof is presented in Appendix B.2`。
- 证据（interpretation；p.4, §3.2–3.3）：Eq. (5) uses a post-softmax mixture; Lemma 3.1 defines pre-softmax logits.

**伪代码与复杂度。** Algorithm 1 位于补充 p.17，先对每个 expert 的两个 Gram matrices 做 `EigVec`、Top-c 与均值，再对每个 token 做 projection、probability mixing、Top-k 和 expert sum。循环层级为一次 per-expert pre-computation 加一次 per-token routing；关键不变量是每个 `C_i` 落在 token representation space，混合分布保留 `α ∈ [0,1]`。论文没有给出 Big-O、wall-clock latency、eigendecomposition cache policy 或不同 `c/k` 的复杂度说明，状态为 `not_present`。

## L. 最终判断

1. **单一主线。** 已训练 SMoE 的 learned router 仍会 collapse；expert FFN weights 的 eigenvectors 提供一种较为正交、可与 token 投影的补充 routing signal；SSMoE 将二者混合，并以多领域 performance、memory、corruption 与部分机制检查支撑其价值。
2. **正文保留的决策关键。** 主体研究问题和 Finding 1–4 callouts、Eq. (1)–(5)、Lemma 3.1、Figure 1–7、Table 1–6，以及唯一明确的 bootstrap 检验都在主文。它们足以判断方法是什么、平均收益在哪里、哪些对照用于排除 pruning 的简单解释。
3. **附录迁移与正文自足性。** 证明、算法、硬件、dataset-level MTEB、fine-tuning、training-free baselines、flips/PPL/overlap 和 full-capacity GSM8K 被移至补充。证明和 Algorithm 1 的迁移不阻碍理解，复现/稳健性判断依赖补充；seed、corruption budget、metric definitions 仍缺失。
4. **最有效的写作/视觉模式。** 引言中“Research Question → Finding”框使抽象问题和观察对应；Figure 2 把 performance 与 memory 同置；Table 5 以 average-EV 对照切开“eigenvectors 是否本身有用”；Table 4 对小 retrieval gain 直接给 bootstrap 证据。
5. **最大缺口与读者成本。** 条件性 correlation lemma 与实际 post-softmax selective routing 的连接没有由 `ε` 或 independence 的实测量闭合；MTEB/多数 LLM/VLM 结果的重复、seed 与不确定性不明；不利的 pruning/GSM8K 解释在附录，读者需要跨 p.6、p.19、p.24 才能获得完整边界。
6. **可迁移规则。** 若核心贡献是“新表示改善选择机制”，正文应把**可操作机制、最接近的剥离式 ablation、任务级不利结果与统计单位**并列；平均收益和图示不能替代它们。
7. **规则的适用边界。** 该规则适合跨模型/任务的系统论文。只有在机制已被直接测量、所有关键不利结果同样可见、并且理论对象与实装对象相同的情况下，才可以压缩这些证据；本篇没有满足全部条件。
