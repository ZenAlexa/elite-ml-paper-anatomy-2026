## 5. 方法与理论：最小逻辑单元

### 5.1 形式化对象、输入、输出与逻辑转移

- **输入。** 预训练 dLLM policy `πref`、prompt 集合 `D`、奖励 `r(q,o)`、温度 `α>0`、当前/缓冲 sampling policy `pv`，以及部分 mask 的 response。MDM 定义在含 mask token 的有限 vocabulary；每一行 `πθ(x)` 是 probability vector。 【p. 2, §2.1, “each row … valid probability vector”; explicit；p. 4, §3.1, “temperature α > 0”; explicit】
- **目标。** 将 sequence distribution `pθ(o|q)` 匹配 reward-tilted `p*(o|q) ∝ pref(o|q) exp(r/α)`，从 reward maximization 的 KL-regularized optimum 转成 distribution-matching task。 【p. 3, §3.1, Eq. (5), “reward-tilted distribution”; explicit；p. 4, §3.1, Eq. (6), “Policy Distribution Matching Learning”; explicit】
- **可实现损失。** 用 order-specific target、`pv` importance sampling 和 negative ELBO 替代不可直接得到的 `p*` samples、partition function 与 dLLM sequence likelihood，得到 WDCE。 【pp. 4–5, §3.2, Eqs. (8)–(11), “weighted denoising cross-entropy”; explicit】
- **小 batch 修正。** group、individual、model 三种 `wbase` 使 `wreal=w-wbase` 出现 negative gradient；WDDO 是可选的 discriminative objective。 【pp. 6–7, §§3.3–3.4, “inject negative gradient”; explicit】
- **训练输出。** Algorithm 1 周期性刷新 rollout buffer；每个 refresh 用 `B` prompts 和每 prompt `N` rollouts 计算 reward/weights，随后随机 mask 并更新 `θ`。外层是无限 step loop，refresh 条件为 `step mod F=0`，prompt loop 可并行；未报告 Big-O complexity。 【p. 16, Algorithm 1, “step mod F = 0”; explicit；p. 16, Algorithm 1, “output πθ”; explicit】

段落动作转移为：`setup_notation → derive (ROAR/ELBO) → contrast_alternative (GRPO likelihood) → state_problem (mode seeking) → derive (reward tilt) → define_component (forward KL) → derive (importance weights/WDCE) → state_problem (small batch) → define_component (three baselines) → contrast_alternative (WDDO) → connect_to_experiment`。主文随后立即用 §4 的 backbones、tasks、Tables 1–2 和 Figure 4 来承接。 【pp. 2–8, §§2–4, “3. Distribution Matching”; layout_observation】

## 11. 最终判断

1. **单一主线。** dLLM 的 random-order/masked 生成使 GRPO 风格 likelihood 近似昂贵且 reward-mode 目标可能漏掉高奖励 mode；DMPO 把目标改为匹配 reward-tilted `p*`，用 WDCE 保留 dLLM 的 forward noising，再以 baseline 修补低 rollout batch 的更新方向，最后用四个 reasoning benchmarks 和效率曲线回收。 【pp. 1–9, §§1–5, “matching the entire reward-tilted”; explicit】
2. **正文保留的决策关键内容。** 问题、target distribution、可实现的 WDCE、small-batch mechanism（Figure 3/4）、两张主表、compute comparison、明确的范围限制均保留在主文。 【p. 4, §3.1, “Policy Distribution Matching Learning”; explicit；p. 8, Tables 1–2, “Model performances”; layout_observation】
3. **被移入 appendix 的细节及代价。** algorithm、SOC derivation、reward/implementation configuration、additional dynamics、hyperparameter robustness 和 qualitative examples 全部后移。主文的概念自足性较强；复现与理论审查须读取 appendix。 【p. 16, Algorithm 1, “Distribution Matching Policy Optimization”; explicit；p. 21, App. C.2, “Training Hyperparameters”; explicit】
4. **最有效的表达模式。** Figure 1 在 formalism 前交付跨任务动机，Figure 2/3 将两处抽象机制局部可视化，Tables 1–2 让 backbone×task×length 比较可逐格审查；这一顺序把叙事主线固定为「现象、目标、损失、失败修正、结果」。这是版面和章节衔接的解释。 【p. 2, Fig. 1, “Performance on reasoning benchmarks”; layout_observation；p. 6, Fig. 3, “effect of weight baseline”; layout_observation】
5. **主要未闭合点与读者成本。** 两个 backbone、四个 elementary benchmarks 是明示范围；单次点估计、未定义 curve bands、未披露 seeds/run count 限制了跨运行稳定性判断；entropy 曲线不能单独证明 reward-distribution mechanism。 【p. 9, §5, “two pretrained dLLMs”; explicit；p. 8, Tables 1–2, “Model performances”; layout_observation；p. 23, App. C.3, “entropy”; explicit】
6. **可迁移规则。** 当论文将一个学习目标从 reward/objective 层变为 distributional target 时，主文应连续呈现 target、可计算 surrogate、surrogate 的已知失效条件、针对失效的组件对照和任务结果，使每一步都能在后续对象中复核。该规则由本论文 Eq. (5)→Eq. (11)→Figure 3/4→Tables 1–2 的顺序支持。 【pp. 3–8, §§3–4, “reward-tilted distribution”; explicit】
7. **规则的适用边界。** 这条规则适合拥有明确 target distribution、可实现 loss 和可观察组件对照的算法论文。对于没有形式化 target、没有独立组件或主要证据来自开放式人类偏好的工作，强行使用同一链条可能制造不真实的闭环；此句是方法论解释，非本文作者主张。 【p. 4, §3.1, “Given … learn a dLLM policy”; explicit；interpretation】
