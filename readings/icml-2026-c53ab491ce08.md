## 方法、公式与算法

### 形式对象和最小逻辑单元

- **输入/输出**：phenomenon 是 observation pair `(x,y)`，潜在程序 `τ` 将 `x` 变为 `y` [p. 3, §2]。
- **共享对象**：primitive vocabulary `Z={z1,…,zM}`、每个 primitive 的 execution function `fzi`、序列程序 `τ=(zi1,…,ziK)`，和 composed executor `fτ` [p. 3, §2]。
- **训练假设**：`Dtrain={(xn,yn)}` 只包含 i.i.d. phenomena，`τn∈Ttrain` 完全潜在；训练长度上限为 `K`，测试集合与 `Ttrain` 不相交且长度更长 [p. 3, §2]。
- **NEO 组件**：encoder `Eθ`/`pθ(s1|x)`，目标条件 theory programmer `qϕ(zik|sk,y)`，共享 transition/executor `pθ(sk+1|sk,zik)`，decoder `Dθ`；每个组件从 `x,y` 构造、执行并解码一个离散 program [p. 4, §§3.1–3.2]。
- **适应长度**：MDL 从每个 intermediate reconstruction 中选 `k*`，由 `λMDL>1` 惩罚长程序 [p. 5, §3.3]。
- **anti-shortcut 约束**：state grounding 强制 `sk` 经 decode–encode 后回到有效 latent manifold；没有它，中间状态只需服务最终 reconstruction [p. 5, §3.4]。
- **测试时**：达到 reconstruction threshold `ε` 即返回当前程序；干预可通过覆写 primitive selection 实现 [p. 5, §3.5]。

方法段落动作序列为：`setup_notation → define_component → connect_to_prediction → connect_to_experiment → state_problem → derive → define_component → derive → explain_mechanism → instantiate_algorithm → connect_to_experiment`。

## 消融、负面结果与自我设限

- **组件删除**：移除 state grounding 使 primitive coverage 降至 0.002，所有 split 分数归零；作者以 off-manifold intermediate states 解释 [p. 8 Table 3; p. 9 §5.7]。
- **capacity/regularization sensitivity**：`|E|=36` 仍有高 transfer；`λMDL=1.2` 则普遍短、entangled，comp. OOD transfer 0.160、length transfer 0.169；`λMDL=0.8` 也降低部分表现 [p. 8 Table 3; p. 17–20 Figures 8–12]。
- **任务异质性**：Arithmetic length OOD 的纯 NEO 是主要反例；作者说明从 73 到 273,750 需要六步 exact multiplication，NEO-S 才显著改善 [p. 7 §5.4]。
- **计算成本**：NEO 的 GridWorld training 为 75.4 ms/batch，对 Disc-Mono 的 49.8；Arithmetic NEO-S `B=1024` inference 为 4867.3 ms/batch，对 NEO 的 27.5 [p. 29 Tables 12–13]。这给出 scalability 的可量化代价。
- **范围声明**：§6 明示 small discrete primitive set、short program、deterministic execution/reconstruction stopping、noise/ambiguity/partial observability、synthetic benchmarks；类别分别是 `scope`、`assumption`、`compute`、`data`、`generality` [p. 9 §6]。
- **影响/部署**：Impact Statement 将工作限定为 foundational study，称不针对 human subjects、personal data 或 automated decision-making；泛化 misuse 只作一般性提示，未识别此贡献特有风险 [p. 10, Impact Statement]。

不利信息的呈现方式有可验证边界：Arithmetic length-OOD failure 放在 §5.4 正面讨论；state-grounding failure 放在 ablation；compute cost 移到 Appendix D；最全面 split、hyperparameter 和 alignment evidence 移到附录。没有证据表明作者通过隐藏分母、弱化语气或只选成功例意图性规避；定性图确实是代表性样本，论文没有提供其抽样规则或分母。

## 最终判断

1. **单一主线**：把世界理解从 future prediction 重述为从 observation pair 归纳可执行、可复用、可组合的 latent program；NEO 以 shared executor、MDL 和 state grounding 把这个表示偏好落实为 transferable explanation。
2. **正文保留的决策关键内容**：问题定义、support→query transfer criterion、NEO 结构与 (1)–(7)、三域主比较、grounding/`λMDL` 消融、计算代价的定性承认、显式限制。Figure 1–2 先给出概念与机制，Tables 1–3 和 Figures 3–7 再给出证据。
3. **迁入附录的细节及代价**：算法、metric exact definition、每域 primitive/split、complete tables、alignment、cost、dataset sizes、hyperparameters 都在 p. 13–41；它们不妨碍理解主论证，但使 replication、fairness 和 statistical audit 无法只靠正文完成。
4. **最有效模式**：同一 latent program 的 support-to-query transfer 将“explanation”转为可观察判据；Figure 2 把 token、state、grounding 与 MDL 连接为一个执行链；Table 3 用删除/overcomplete/regularization 三个对照检验该链。
5. **最大缺口/读者成本**：受控 synthetic oracle alignment 不能证明 human-interpretable theory 或 causal mechanism；三次 mean 缺乏表内不确定性/统计定义；Arithmetic length OOD 显示对 search 的依赖；30 页附录才给足评估与复现细节。
6. **可迁移规则**：若论文声称学到“解释”而非只提升预测，应定义一个由第一实例抽取表示、在第二实例执行的 transfer test，并使该 test 与模型共享部件直接对应。
7. **适用边界**：该规则适用于存在可迁移 latent mechanism 的任务；当多个机制在 observation space 中不可辨识、query 不能共享机制、或 target 只能以预测质量定义时，support-to-query transfer 不能单独识别解释性。
