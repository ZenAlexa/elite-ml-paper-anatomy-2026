## 5. 方法与理论

### 5.1 形式化对象与组件职责

论文先定义每个用户的轨迹 `T_u = {(l_1,t_1), …, (l_N,t_N)}`，状态是截至时间 t 的 mobility history，动作空间基于 Exploration and Preferential Return（EPR）。`π(a|s)` 表示 policy，`R(s,a)` 表示 reward；两者均未观测，需要从 trajectory 推断（p. 2–3，§2.1，`Both the policy and reward functions are unobserved`，explicit）。GAIL 在 p. 3 给出 minimax 目标。随后 DP 定义和 Laplace density 作为隐私基础，问题定义要求 synthetic trajectory 保留 utility，同时任一用户 trajectory 的有无对输出影响受 `(ε, δ)`-DP 约束（p. 3，§2.4，`utility-preserving`，explicit）。

方法图 Fig. 2 展示设备侧的 user-specific private trajectory 与 synthetic trajectory、每个用户的 discriminator、服务器侧 reward aggregation 和 global policy network。方法总览把 C1 映射到 sensitivity module，C2 映射到 formal DP guarantee，C3 映射到 reward function ensemble / WGAN-GP 稳定策略学习（p. 4，§3，`addressing Challenge C1`、`addressing Challenge C2`、`tackle Challenge C3`，explicit）。

组件—前文问题映射如下。

| 组件 | 前文问题 | 论文机制 | 后续检验 |
|---|---|---|---|
| trajectory sensitivity module | uniform noise 混合高低风险样本 | 用 local discriminator confidence 产生 sample-level 权重和 per-sample ε | Table 2–3、Table 7；无独立敏感度校准实验 |

### 5.3 隐私机制的可检验边界

论文直接写出 DP 定义、sequential composition、post-processing 和 zCDP，但没有给出 theorem、lemma、proposition、corollary 或 proof。PATEGAIL++ 的关键自适应预算来自 DP pilot estimate `R̂_p(s,a)`，论文声称该 pilot 防止 adaptive allocation 泄漏；随后又声称保持 end-to-end `(ε,δ)`-DP。PDF 没有给出 pilot 的具体机制、`Δf` 的数值或界、每轮查询次数、跨轮 composition、`δ` 的取值、敏感度截断，也没有将 central 与 LDP 的保证写成可核验定理。因此 theory 模块是“定义与保证性语言已出现，证明链未闭合”。

方法中的另一个逻辑点是 high reward 被解释为更接近用户真实行为、因而更敏感。按 `w(s,a)=1−R̂_p(s,a)+δ′` 分配预算时，权重越小，per-sample ε 越小，Laplace scale `Δf/ε(s,a)` 越大。方向上符合“高风险强噪声、低风险少噪声”，但论文没有给出 reward 的取值域、`δ′`、`β`、`λ_c` 或 sensitivity 的数值范围，无法从文字单独验证所有预算为正且总和在每个训练轮次保持一致。

### 6.2 设计与引言、理论的对齐

实验先以 Table 1 给出无噪声 baseline compatibility，再以 Table 2–3 改变 noise，随后以 Table 4–5 测试 Geolife MIA，Table 6 测试 λGP，Table 7 测试 LDP central/local 对照。Telecom MIA、λGP 最优配置图和 user-subset 结果后移至 appendix。顺序基本对应“utility → privacy leakage → training design → deployment extension”，但没有一项实验直接识别 sensitivity module、pilot estimate 或 dynamics compensation 的独立因果贡献。

white-box MIA 的设计是 attack target trajectory 的 state-action reward 向量输入 Random Forest，70% 来自 training set、30% 来自 outside training set。black-box LiRA 用每个 example 的 Gaussian loss distribution 做 likelihood-ratio test（p. 8，§4.1，`fits Gaussian loss distributions for each example`，explicit）。两类攻击都报告 Accuracy 与 AUC，但没有说明 target 数量、训练/测试拆分、RF 超参数、LiRA shadow/training 过程或 ± 的统计含义。

## 7. 结果、统计与可视化

### 7.1 统计口径

五个 utility 指标都是 real 与 synthetic 分布之间的 JSD，表格给出单个小数值且没有误差表达。MIA 的 Accuracy 与 AUC 表格给出均值加 `±` 项，论文未说明该项是标准差、标准误、重复运行范围还是其他离散量，也未给出 seed 或 participant/task 层级。没有 p-value、假设检验、多重比较、bootstrap、Bayesian 分析、regression、correlation 或 effect-size 估计。结果叙事将“显著”“near-random”“stronger”与表中点估计并置，但没有单独的实质性阈值。

表注通常说明数据集、noise、member/non-member 比例或 lower-is-better 方向，能够部分独立解释表格。Table 1–3 没有误差与分母；Table 4–5、8–9 的 `±` 未定义；Fig. 3 选择每个 noise/metric 的 best configuration 后绘图，因此不是预先固定 λGP 的独立估计。

### 8.2 负面结果与呈现策略

论文有一处主动承认 comparator 限制，即 centralized non-federated non-DP baselines 不构成严格 apples-to-apples SOTA 比较。该句保留了重要边界，降低了 Table 1 的过度外推风险（p. 7，§4.1，`rather than to claim a strict apples-to-apples SOTA victory`，explicit）。

## 13. 最终判断

### 13.1 单一主线

单一主线是“把 uniform privacy noise 改成由 discriminator-derived trajectory sensitivity 驱动的 per-sample/per-user Laplace budget，在 federated imitation learning 中争取更好的 utility–privacy trade-off；用 WGAN-GP 缓和 adaptive noise 下的训练不稳，并把 central 版本延伸到 LDP”。证据链从 p. 2 的 uniform-noise gap，经 p. 5 的 sensitivity/ε 公式，至 p. 6 的 LDP/WGAN-GP 组件和 p. 8 的 Geolife noise 表。

### 13.2 正文保留的决策关键内容

正文保留了 problem definition、Fig. 2 系统边界、sensitivity allocation 公式、Laplace aggregation、WGAN-GP objective、PPO 实现、五项 JSD utility、Geolife MIA、Telecom utility 对照、LDP Table 7 和 baseline non-comparability caveat。这些内容足以让读者理解方法输入、服务器/设备边界、比较指标和主要决策方向。它没有保留完整 DP accounting、训练预算、seed、下游任务或 runtime/scalability measurements。

### 13.3 附录迁移与自足性

附录迁移了五个 baseline 的文字定义、Telecom 的两类 MIA、best-λGP Fig. 3、user-subset Table 10、ethics 与 reproducibility statement。迁移没有破坏“Geolife utility + white-box MIA + LDP”主决策的基本自足性，但削弱了跨分布和扩展性判断，因为这些判断依赖 p. 14–16 的表格。A.1 声称配置完整，却没有在 PDF 展示可复核的具体 hyperparameter 列表，导致 reproducibility 自足性只部分成立。

### 13.4 最有效的写作、图、表和公式模式

最有效的模式是把三个 challenge 与三个方法组件一一映射，再用 matched-noise Table 2/3、privacy Table 4/5、LDP Table 7 逐层展开。Fig. 2 用设备侧 discriminator、服务器侧 aggregation、global policy 的横向流程降低了 federated boundary 的理解成本；Eq. (6–8) 把 central、compensation、LDP 的差异压缩到同一套 ε 记号中。Table 2 的中等 noise 行给出明确 29% DailyLoc 对比，也是最易复述的定量句。

### 13.5 最大叙事规避、未闭合主张与读者成本

最大缺口是把 formal `(ε,δ)` guarantee 当作方法组件和解释性结论，却没有 theorem/proof、pilot mechanism、composition、`Δf`、`δ` 或 sensitivity bound。第二个缺口是把“consistently”“stronger privacy”推广到 Telecom 和 LiRA，而表格呈现明显异质性。第三个缺口是 abstract 的 downstream performance/scalability 主张没有对应任务、runtime 或 scaling evidence。读者还需自行解开 PATEGAIL++、PATEGAIL+++、PATEGAIL++−、PG 的命名，以及 Fig. 3 的 λGP=0/1 冲突。

### 13.6 可迁移规则

可迁移规则是：每一个自适应隐私或训练组件都应配一张固定预算、固定评测协议的独立对照表，并把“预算如何组成、敏感度如何界定、攻击如何重复”写成可复核的最小证据链；跨数据集结论必须逐项保留异质性，而不能由单一数据集的最佳行代表整体。

### 13.7 规则适用边界

该规则适用于包含隐私预算分配、adaptive noise、federated aggregation 或多阶段训练的生成模型论文。若论文只做理论机制、没有实证组件，规则中的对照表可替换为 theorem、assumption、composition 和 failure-boundary 的逐项证明；若数据集和攻击模型不能共享同一分母，则必须分别报告，不能合并为一个 utility–privacy frontier。
