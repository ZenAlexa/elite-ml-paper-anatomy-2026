## 5. 方法与理论

### 5.1 形式化对象与核心链

- **问题对象**：`x ∈ X ⊆ R^d` 是 solution vector，`f` 将 `X` 映射到 `R^m`；离线数据为 `D = {(x_i, y_i)}_{i=1}^N`，其中 `y_i = f(x_i)`。Pareto dominance 与 Pareto-optimality 在 p.3 的 Definition 1–2 给出。
- **扩散对象**：联合分布 `(x, y) ~ p_data(x, y)`，条件平滑分布为 `p(x | y; σ)`；denoiser `Dθ(x; y, σ)` 学习在目标向量条件下重建 solution。证据见 p.3–4，`explicit`，anchor 为 “The clean data is drawn from a joint distribution”。
- **训练偏向**：先以 dominance number 在目标空间中排序，再把 bin weight 乘到 EDM 的 denoising loss；目标是提高 Pareto 附近样本的学习权重，同时保留数据流形信息。
- **条件点生成**：用 Riesz s-Energy 产生 reference directions，按 non-dominated fronts 和 niche counts 选代表点，沿对应方向外推并加零均值 Gaussian noise，产生 (Q) 个高质量、分散的 (hat y)。
- **采样输出**：每个 (hat y) 从 (mathcal N(0,sigma_{max}^2I)) 开始，使用 CFG 组合 conditional/unconditional denoiser，经 (S) 个 EDM steps 生成一个 (x)，输出集合 (|X|=Q)。

段落动作转移序列为：`setup_notation → state_problem → derive → define_component → explain_mechanism → give_intuition → connect_to_experiment → instantiate_algorithm → connect_to_prediction`。方法没有单独的 theorem-proof 链，理论主要承担方法因果链和采样解释。

### 7.1 统计口径

- **聚合单位**：Table 1 先在 task category 内按 100th-percentile HV 对方法排名，再汇总各任务平均 rank；Table 1 的 `Avg. rank` 是跨任务聚合的 rank，不是原始 HV。
- **主中心量/离散量**：表格报告 mean ± standard deviation；D(best) 是 offline dataset 的 non-dominated set，表中通常没有 seed 方差。
- **决策量**：HV、average rank、relative HV improvement、normalized HV ratio、runtime 和逐任务胜负/最佳行。
- **不确定性**：主表使用标准差；没有 hypothesis test 或 conventional interval。图注能说明 normalized ratio 的基准或方向，但单独读图时部分曲线的精确数值不可恢复。
- **实质意义与机制证据**：Table 1 支持跨类别表现与一致性；Table 2 支持组件贡献；Figure 4/5、Figure 8/9 将数据质量、条件点、流形重构与失败模式联系起来。作者明确区分 MORL/MONAS 的任务困难与整体平均 rank，但没有把 mechanism evidence 变成 formal causal identification。

## 9. 不利信息的呈现策略（仅记录可观察顺序）

1. **位置延后（layout observation）**，Table 1 先以 overall rank 宣布 PCD 的优势，随后同一页写 MORL「no method」超过 D(best) 与 MONAS categorical difficulty，再到 p.10 Summary 才集中写高维/离散/组合限制。证据：p.8–10，anchor “The relatively weaker performance on MORL tasks” / “presents a challenge for our continuous diffusion model”。
2. **聚合掩盖异质性（interpretation）**，主表把五类任务压成 category average rank 和 Avg. rank；作者明确把 per-task HV 放到 A.11–A.13。聚合指标适合回答跨任务一致性，却不能独立呈现 RE21、MO-Hopper、ZDT2 等方向相反的任务行为。证据：p.8，Table 1 caption 与 A.11–A.13 调用。
3. **附录迁移（explicit/layout observation）**，训练网络、完整 Algorithm 2、per-task 100/75/50 percentile tables、runtime、sampler、tau、J、noise、direction vectors 和 case studies 全在 appendix；正文只保留 Table 1、Table 2、Figure 3。证据：p.5 的 “full pseudocode ... Appendix A.9”、p.8 的 “For detailed per-task HV ... Appendix A.11, A.12, A.13”。
4. **未来工作化（explicit）**，高维、categorical、fully discrete 和 combinatorial 的处理主要以 Latent Diffusion、Transformer、discrete guidance、constrained diffusion 作为 future extension，正文没有把它们纳入当前 capability。证据：p.10，anchor “Future work could extend PCD”.
5. **主动正面讨论例外（explicit）**，ZDT2、Regex 的数据处理伤害、Regex 的 deterministic sampler 优势和 MO-Hopper 重构失败都被单独解释，未被写成整体零效应。证据：p.9、p.16–22，anchor “these tasks appear to be the exception”。

## 13. 最终判断

1. **单一主线**：论文把 offline MOO 的「静态数据、需要探索 Pareto front、又不能信任 surrogate 外推」重写为 conditional sampling；用 dominance-aware reweighting 把学习容量放到高质量区域，再用 reference directions + front selection + extrapolation + noise 产生多样的 target objectives，最后以 CFG 从同一 conditional diffusion model 生成候选。证据链位于 p.4–6 的 Eq.5–7、Figure 2、Algorithm 1，并由 p.8–10 的 Table 1/2/Figure 3 与 p.21–23 的案例/扩展检验。
2. **正文保留的决策关键内容**：问题定义与 EDM/CFG 方程、两个核心组件、Algorithm 1、跨五类任务的 Table 1、组件 Table 2、guidance Figure 3，以及 MORL/MONAS/组合任务边界。它们让读者能理解「为什么这样训练/采样」和「主结果如何作出整体选择」。
3. **移入 appendix 的细节及其代价**：完整 Algorithm 2、A.3 的网络/EDM/default hyperparameters、A.4 runtime/complexity、A.5 sampler、A.6 超参数消融、A.7 机制案例、A.8 many-objective、A.11–A.13 逐任务 HV。迁移没有破坏主线自足性，却使「consistency」「速度」「扩展性」「target adherence」需要额外翻页才能核验；Table 1 的聚合无法替代 per-task 证据。
4. **最有效的写作、图、表、公式模式**：Figure 2 将 reference-direction selection 的三步机制和 Figure 1 的整体管线分开呈现；Eq.5→Eq.6→Eq.7 把「不可全序」→「dominance/bin weight」→「加权 denoising」压成连续公式；Table 2 采用组件交叉对照而非只展示完整模型；Figure 8/9 主动放入成功与失败任务，使 generalization claim 有可视边界。
5. **最大叙事缺口**：没有 formal theorem 或 generalization/target-adherence guarantee；「beyond observed data」在 RE21 和 many-objective 上有支持，在约 10,000 维 MORL 上却同时失败。主实验依赖 aggregate rank、percentile HV 和有限 representative tasks，缺少一个跨全任务的 target-to-output calibration 或分布外误差量，因此「robustness/consistency」的范围只能限于选定 benchmark、固定设置与报告的 HV estimand。
6. **可迁移规则**：若方法主张把 offline search 改写为条件生成，应把每个生成组件绑定到一个可观测决策量，并同时展示一个近流形成功案例和一个远流形失败案例；aggregate table 后必须给出 per-task 或结构性分解。
7. **适用边界**：该规则适合有静态数据、可定义目标向量和可批量 oracle 评估的 offline optimization；遇到 categorical/combinatorial constraints、高维 parameter manifold 或数据质量长尾时，必须把 representation、constraint handling、reweighting temperature 和 target extrapolation 当作单独实验问题，不能把 conditional sampling 的形式重写直接当成泛化保证。
