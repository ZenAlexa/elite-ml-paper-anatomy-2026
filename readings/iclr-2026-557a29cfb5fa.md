## E. 方法与理论

### E.1 形式化对象与问题链

1. **全局目标（p.2，§2）**：global plan `τ=(x₁,…,x_N)` 从 joint distribution `p(τ)` 采样；goal-directed 条件为 `x₁=x_s`、`x_N=x_g`。全 joint 建模依赖长 horizon data，论文改用 short-horizon local distributions。
2. **因子图（p.2–3，§2）**：变量节点 `{x_i}` 与表示连续子序列联合分布的 factor 节点 `{y_j}` 形成 chain；用 Bethe approximation 将 global distribution 写为局部因子乘积除以重叠变量边际的度数修正。
3. **扩散背景（p.3，§2）**：前向过程加入 Gaussian noise，score network `ε_θ(y^(t),t)` 通过 score matching 近似 reverse denoising transition；Tweedie estimate 给出当前 clean sample 估计。
4. **组合 score（p.3，§2）**：按 Eq. (3) 相加 local factor scores 与 variable marginal 修正；chain 中重叠变量 `d_i=2`，非重叠变量 `d_i=1`，重叠 marginal 以相邻条件 score 的平均近似。
5. **guided search（p.5，§3.1）**：对原 diffusion transition 乘以 `exp(-J/λ_t)`，用类似 Cross-Entropy Method 的 population sampling 保留 elite plans。
6. **局部可行性（p.5–6，§3.1）**：以 local segment 的 DDIM inversion 曲率作为高／低 likelihood 的代理，聚合成 `J` 做候选排名。
7. **远程信息传播（p.6，§3.2）**：在每个 denoising timestep 内重复 forward noising ↔ denoising，让相邻 overlap 的信息沿 factor chain 传播。

### E.3 组件、算法和动作转移

- **Algorithm 1 CDGS（p.5）**：输入 start `x_s`、goal `x_g`、horizon `H`、noise schedule、local score function `ε_θ`、候选数 `B`、elite 数 `K`。初始化 `B` 个 global noisy plans；每个 `t=T,…,1` 先调用 Algorithm 2 得到 composed score，估计 clean plan，按 Eq. (5) 排名，保留 best-`K`，用过滤计划 repopulate，再按 Eq. (2) 采样。输出 `τ^(0)`。关键不变量是候选 population 在每个 denoising step 都经过同一局部排名；论文没有给出时间／空间复杂度或每一步实际 score evaluation 次数。
- **Algorithm 2 ComposedScore（p.5）**：输入 noisy `τ^(t)`、t、`ε_θ`、start／goal 和 resampling 次数 `U`。每个 `u` 按 Eq. (3) 计算 score；若尚未到最后一次，则按 Eq. (2) 去噪、给 start／goal 加相应噪声、inpaint，再从 `p(τ^(t)\|τ^(t−1))` resample。输出最后一次 composed score。关键不变量是 start/goal 重新注入每轮，同时 overlap 信息被重复传播。
- **Figure 4（p.4）**把一次 denoising step 画成 `Batch τ^(t)` → local score/resampling → predicted clean sample → local feasibility metric → elite batch → repopulated batch。图中蓝色框是 global coherence，黄色框是 DDIM-inversion pruning。
- **动作转移序列**：`state_problem → derive (Bethe/score) → define_component (population search) → explain_mechanism (DDIM curvature) → give_intuition (belief propagation) → instantiate_algorithm (Algorithms 1–2) → connect_to_experiment (robot/content tasks) → summarize`。

### E.4 理论性质与内部规格问题

论文的关键机制主张是“global plan 可行当且仅当所有 local transitions 可行”（p.5，§3.1），但这是建立在 local model 学到可行短 horizon 行为之上的方法假设／直觉，并没有定理或证明。高 likelihood 也只被称为 local feasibility 的“strong indicator”，没有证明其与几何可行性的等价关系。

PDF 内有一处不能静默修正的方向不一致：Eq. (5) 定义 `J=∏exp(−g)`，且同一页说高 `g` 对应低 likelihood；但 Algorithm 1 和 p.5 文字说保留“minimizes J”的 elite，p.6 又说“Low-quality plans have high J values”。按字面，低 likelihood（高 `g`）会使 `J` 变小；按 p.6 的描述方向应相反。未说明是否应改为 `exp(+g)`、改为最大化 `J`，或反转排名。p.5 的 `p_J` 也使用 `J(τ̂_0^(t−1))`，而 Algorithm 1 在当前步写作 `J(τ̂_0^(t))`。这会影响 pruning 的可执行方向，属于方法规格的未闭合点；它不是测量误差。

## F. 实验设计

### F.1 机器人 sequential decision／stitching

- **任务与数据**：OGBench Maze and Scene suite；PointMaze、AntMaze、Humanoid-Maze 的 Stitch，以及 Scene 中 drawer、sliding window、cube 等五个 manipulation tasks 的 Play。作者说训练数据是 small maze trajectories 或 unstructured play，不能直接解决目标任务；多样 unstructured plans 使 local distribution multimodal（p.6，§4）。
- **模型与 horizon**：用 Diffuser 学 short-horizon local plans，最多 4 秒、20 Hz，`y={s_1,a_1,…,s_h,a_h}`；推理时给定 goal state 组合成最多 10 秒的 `τ={s_i,a_i}_{i=1}^H`，并明确 `h<H`（p.6，§4）。
- **比较**：GCBC、GCIVL、GCIQL、HIQL 等 OGBench inverse-RL baseline；GSC、CompDiffuser 等 compositional generative baseline。Table 1 的 baseline performance 借自原论文 [48,40]，未在同一实验中重新训练（p.7，Table 1 caption）。
- **统计单位**：Table 1 success rate，100 trials、3 seeds、随机 task ids；表中的 `±` 没有说明是标准差、标准误或其他 spread。Table 2 同样是 100 trials、3 seeds、随机 task ids（p.7，Tables 1–2 captions）。

### F.2 AntSoccer composite stitching

AntSoccer 中把 ball reaching 和 ball carrying 轨迹拼接；比较 4D 与 17D state-space 的 GSC/CD，并报告 `Ours w/o PR` 与 `Ours` 的 17D 结果（p.6–7，§4、Table 2）。该设置测试高维状态 stitching，但论文没有提供每个 task id 的分层结果或失败类型。

### F.3 Hybrid planning / TAMP

- **形式化**：TAMP 将 symbolic search 的离散 skill 序列（`pick`、`place`、`pull`）与每个 skill 的 low-level motion planning 结合；计划写为 `τ={y_1,…,y_m}`，`y_i={s_i,π_i,a_i,s_{i+1}}`，离散 skill `π_i` 与连续参数 `a_i` 必须同时满足 symbolic/geometric constraints（p.7，§4）。
- **任务**：三套 TAMP task suites；Hook Reach、Rearrangement Push、Rearrangement Memory，各有 horizon 4/5/7 的两个 task。具体场景说明被放在未提供的 App. E（p.7）。
- **基线分层**，① privileged PDDL（Random CEM、STAP CEM 在手工构造的 PDDL domain 上搜索 symbolic plan，并对 motion plan 做 CEM）；② prompting（LLM-T2M 使用 GPT-4.1，VLM-T2M 加 scene images，各有 `n=11` in-context examples，再由 STAP CEM 做几何检查）；③ compositional diffusion（GSC no-task-plan，与 CDGS 的差别在是否有 resampling／pruning）。作者强调 GSC/CDGS 不依赖显式 symbolic search 或 LLM/VLM task plan（p.7–8）。
- **统计单位**：Table 3 是 success rate over 50 trials，没有 seed、区间或 spread 说明（p.7，Table 3 caption）。

### F.4 Panorama

用 Stable Diffusion-2.0，将每个小图 patch 拆成三个重叠块 `y=(x_1,x_2,x_3)`，由 512×512 图像 stitch 到最多 512×4608 panorama。比较 Multi-Diffusion（MD，overlap score averaging，作为 GSC 的 image analogue）与 Sync-Diffusion（SD，LPIPS perceptual guidance），并加入 `CDGS w/o PR` 与 `CDGS`（p.8，§5）。Table 4 生成 1000 张 panorama、14 个 prompts；指标为 Intra-LPIPS、Intra-Style-L（×10⁻²）和 Mean-CLIP-S（p.9，Table 4 caption）。

### F.5 Long video

以 CogVideoX-2B 为 base model，模型原生约 50 frames，组合至 350 frames、720p。用 6 个 prompts 比较 naive composition（GSC／Gen-L-Video equivalent）、resampling-only composition 与 CDGS；以 VBench 的 subject consistency、temporal-flickering、aesthetic-quality、prompt-alignment 评价（p.9，§5、Table 5）。prompts 细节被调用到未提供的 App. B。

### F.6 设计充分性与缺失项

- **预先列出的研究问题／假设**：OGBench 段明确写“hypothesize that CDGS is an ideal method”；scaling 段明确以 adaptive inference-time compute 为 hypothesis（p.6、p.8）。但没有单独编号的 hypotheses 或预注册决策规则。
- **控制与泄漏**：文中说明 local model 来自短 horizon，推理时拼接更长 horizon；没有报告 train/test task split、数据泄漏检查、相同训练预算或 baseline 重训细节。Table 1–2 直接借用 [48,40] 的 baseline 数值（p.7）。
- **随机性**：3 seeds 只在 Tables 1–2 caption 出现，seed values、候选 population 的独立性和 `B/K/U` 默认值未在正文给出；TAMP 的 50 trials 没有 seed 说明。
- **硬件／训练预算／实现来源**：正文没有硬件、wall-clock、总 score evaluations 或训练预算；p.11 仅声称代码在项目网站，并把 motion/image/video hyperparameters 指向 App. F/J/K。由于这些 appendix 不在 PDF 中，复现粒度不完整。
- **失败判定与人评**：机器人任务使用 success rate，content generation 使用 LPIPS／Style／CLIP／VBench；没有 human evaluation。人评对这类机器视觉指标不是本文设置的一部分，标为 `not_applicable`；失败类型只在 Figure 5、Figure 7 以案例呈现，没有系统 failure taxonomy。
- **顺序对应**：先 OGBench/AntSoccer 测试长 horizon stitching，再 TAMP 测试离散／连续组合，再 Figure 5 测试 B/U scaling，最后 panorama/video 测试跨域。这与“composition → resampling/pruning → 跨域”的引言顺序基本对应，但没有独立实验把 resampling 与 pruning 在机器人上完全正交拆开。

3. **TAMP（Table 3，p.7）**：Hook Reach Task 1/2，CDGS `0.64/0.58`，低于 STAP CEM `0.66/0.70` 和 GSC Original oracle-task-plan `0.78/0.80`，但高于 GSC no-task-plan `0.18/0.04`；Rearrangement Push Task 1/2，CDGS `0.84/0.48`，接近 STAP CEM `0.76/0.70`、低于 GSC Original `0.88/0.64`；Rearrangement Memory Task 1/2，CDGS `0.42/0.18`，高于 STAP CEM `0.00/0.00` 与 GSC no-task-plan `0.07/0.00`。表注称 CDGS 在 Hook Reach 与 Rearrangement Push 持平或略落后 privileged methods，在 Rearrangement Memory 大幅领先；分母是 50 trials（p.7，Table 3；`explicit`）。

### H.3 论文自我设限

Limitations 仅在 p.10 明示三类限制：

1. **goal／scope**：假设可指定 goal state；作者称其可扩展到 goal generation 或 classifier-guided goal conditioning，但本文没有测试。

## L. 最终判断

1. **单一主线**：短 horizon local diffusion models 的组合在 multimodal overlap 上会把不兼容模式平均成无效 global plan；CDGS 把 population search 放进每个 denoising step，用 resampling 传递远程 overlap 信息、用 DDIM-curvature ranking/pruning 排除局部不一致候选，从而在不使用 long-horizon training data 的情况下寻找可行长计划（p.2，§1；p.4–6，§3）。
2. **正文保留的决策关键内容**：问题图示（Figures 1/3/5）、Eq. (1)–(5)、两份算法、B/K/U 控制、OGBench/AntSoccer/TAMP 的任务与 trial 分母、panorama/video 模型与 horizon、Tables 1–5 的定量值，以及 video aesthetic tradeoff。读者可以理解“为何搜索”“搜索什么”“结果比较什么”。
3. **移入附录的细节及影响**：感知、TAMP 场景、curvature 说明、prompts、超参数被指向 App. A/B/D/E/F/H/J/K，但供应 PDF 没有 appendix；这损害实现层面的正文自足性，尤其是训练／推理配置和真实机器人 setup（p.5–9、p.11）。
4. **最有效的写作／图／表／公式模式**：Figure 3 用同一 1D domain 并排展示 naive→resampling→pruning 的因果直觉；Figure 4 把两个组件嵌到同一 denoising loop；Table 3 按 task-information privilege 分层，Figure 5 用 B×U scaling 与失败案例同时承担机制和 compute 叙述。这些对象把“mode averaging”从抽象缺口变成可定位的 transition failure（p.3–4、p.7–8）。
5. **最大缺口**：Eq. (5) 的 `J` 符号方向、正文“high J”与算法“minimize J”互相冲突；同时没有 theorem/proof、真实 feasibility calibration、compute-normalized search comparison、完整 appendix 或独立 resampling/pruning 因子实验。故“locally feasible”“oracle performance”“adaptive compute”均只能在论文已给范围内部分闭合（p.5–6、p.7–11）。
6. **可迁移规则**：当用一个代理分数在生成过程中做搜索／筛选时，必须在同一页同时给出代理的方向、排序操作、采样权重和消融对照，并让一个可观测的失败案例验证代理确实对应目标性质；Figure 5 的失败案例与 Table 4/5 的 `w/o PR` 对照是可复用的结构。
7. **适用边界**：该规则适用于生成式规划、扩散 stitching 和其他 inference-time search；若目标属性无法由 local likelihood 或 curvature 代理观测，或筛选的排序方向尚未形式化，则只能写成诊断性关联，不能写成 feasibility guarantee。本文的 `J` 方向冲突正展示了这一边界（p.5–6）。
