## 相关工作定位

Related Work 是独立的 Section 5，位于 PDF 第 8 页右栏至第 9 页左栏，约 498 词，约占正文语义词数的 9%。它有两个段落和三个引用簇。

1. **Attention as EOT**：Litman (2025) 与 Litman & Guo (2026) 构成第一簇。比较维度是单边/双边 marginal、bias 的角色和研究目的。论文明确把自身定位为固定离散、双边 EOT 的计算实现，锚点为 PDF 第 8 页 Section 5，`we target standard two-marginal EOT`（explicit）。
2. **Sinkhorn-style attention**：Sinkformers、Sparse Sinkhorn Attention、ESPFormer、LOT-Former 和 Gumbel-Sinkhorn 构成按机制组织的 taxonomy。比较维度是 doubly-stochastic attention、sorting/sparsification、sliced transport 与 low-rank factorization。
3. **Online Sinkhorn**：Mensch & Peyré (2020) 被定位为连续分布的 sample-stream stochastic approximation。比较维度是 data regime 与对象表示，FlashSinkhorn 使用 fixed discrete measures 与 tile-streamed updates。

该节避免重讲 Section 3 的公式，转而用约束、数据模式和计算目标做最近邻对比。FlashAttention 引文在引言和 Section 3 再次承担“online LSE / IO-aware kernel”论证作用；Related Work 中大部分 attention 变体引文没有在后续正文承担新的实证证明角色。

## 方法、理论与算法闭环

### 最小逻辑单元

1. **问题与记号**：Section 2 定义 EOT、`P ∈ Π(a,b)`、squared Euclidean cost、stabilized dual potentials 与 Sinkhorn updates（式 (1)–(5)，PDF 第 2 页）。
2. **代数重写**：将 `C_ij = α_i + β_j - (QK^⊤)_ij`，并将 `f,g` 转为 shifted `f̂,ĝ`。Proposition 1 给出两次 update 都是 row-wise LSE（式 (8)–(11)，PDF 第 3 页）。
3. **kernel 机制**：Algorithm 1 固定 row block `Q_I`，流式读入 column blocks `K_J`，以 running max/sumexp 维持 LSE invariant，最后只写 `f̂_I`。Figure 1 把 HBM/SRAM 层级和这一数据流并列呈现（PDF 第 3–4 页）。
4. **IO 保证**：Theorem 2 在 tile fit condition 下给出 HBM access 上界，并在附录证明端点处与输入读取下界一致（PDF 第 3 页、附录 D.2，第 18 页）。
5. **transport application 与一阶导数**：Proposition 3 把 `PV` 和 `P^⊤U` 写成带 induced marginal correction 的 softmax-weighted value application；Corollary 4 在 fixed point 时导出 barycentric projection 和 gradient（式 (12)–(17)，PDF 第 4–5 页）。
6. **二阶导数**：Theorem 5 将 HVP 分解为 transport-vector、transport-matrix 与 Hadamard-weighted transport，再以 damped Schur complement/CG 处理 implicit term（PDF 第 5–6 页；附录 F，第 21–23 页）。
7. **可检验预测**：若上述重写减少 HBM 中间量和 launch fragmentation，应在 profiling 中表现为更低 HBM R/W、memory stalls 和 kernel launches，并在 forward/backward/HVP 与两个下游工作负载中显现。

段落动作转移为：`setup_notation → state_problem → derive → define_component → explain_mechanism → state_complexity → define_component → connect_to_prediction → connect_to_experiment → contrast_alternative`。

### 伪代码、图与表的分工

- **Algorithm 1（第 3 页）**：输入 `X,Y,ĝ,b`，输出 `f̂`；两层循环分别固定 row block、扫描 column blocks。不变量是每个 row block 的 online max/sumexp 对已扫描 logits 保持精确 LSE。复杂度解释在 Theorem 2 和 Appendix D.2。
- **Algorithm 2（第 5 页）**：输入再加入 `f̂,a,V`，输出 `PV`；沿用 `m_I,O_I` 并在末端施加 source marginal correction。它把 transport application 变成 fused matmul-softmax-matmul。
- **Algorithm 3–5（第 24–25 页）**：分别为 `ĝ` update、adjoint `P^⊤V`、Hadamard-weighted `(P⊙W)V`。这些实现细节放入 Appendix G，正文只保留两种核心操作。
- **Figure 1–2 与 Table 1（第 4–5 页）**：Figure 1 说明 memory hierarchy、tile 状态和箭头方向；Figure 2 将 `PV` 的 online weighted sum 可视化；Table 1 映射 source/query、target/key/value、regularization/scaling、dual bias/key bias。三者在 Section 3.1–3.2 被逐一调用。

成本结构的适用边界被明确写在第 4 页 Section 3.1：raw Euclidean distance 的 square root 与 learned neural costs 不具备该 affine dot-product form，因而不进入这一 fused streaming path（`Costs without this structure ... do not admit this fused-streaming form`，explicit）。

## 消融、负面结果与自我设限

正文没有组件删除式 ablation。Section 4 称实验“isolate the four main ingredients”，却没有报告关闭 fusion、关闭 tile streaming 或移除 transport operator 的 matched component-removal study（PDF 第 6 页，Section 4，explicit）。附录提供四类边界实验。

- symmetric 与 alternating update 的 schedule sensitivity（Table 17–18，第 33–34 页）；
- `ε∈{0.10,0.05,0.01}` 的 timing、fp32 precision、convergence budget 与 HVP parity（Table 19–22，第 34–36 页）；
- rectangular `n≠m` 的 shape sensitivity（Table 23，第 36 页）；
- damping/CG tolerance 的 numerical-parity sensitivity（Table 14、22，第 31、36 页）。

明确的自我设限包括：

1. **cost scope**：raw Euclidean 和 learned neural costs 留为 future work（第 4、9 页）。
2. **regime boundary**：small `n` 或 high `d` 且 dense matrix fits memory 时 tensorized 可能有竞争力（第 6 页）；`d=1024` grid 中可直接看到 Tensorized 更快（第 29–30 页）。
3. **conditioning/compute**：`ε↓0` 使 sensitivity system 病态，damping/CG 产出 regularized HVP，迭代预算随低 `ε` 增长（第 17、31、35–36 页）。
4. **shape boundary**：极端 aspect ratio 减少 row-block parallelism（第 31、36 页）。
5. **evidence boundary**：timing 只覆盖 A100-80GB，基准以 fixed iteration 为主；大部分 timing 只报告 mean。

不利信息的呈现方式有可验证的两种。完整 low-ε、parity、schedule、rectangular grids 放在 Appendix H，而正文在第 6–7 页显式引用相应表号；这属于附录迁移，文本没有给出作者动机。与此同时，Table 10–11 披露 `<1` 的 speedup，正文第 6 页直接说明 tensorized 的有利 regime，未发现“只展示有利设置”的充分证据。

## 用词、叙事与包装

以 PDF 第 1–9 页的正文文本做启发式词型检查，并排除重复页眉；公式和图表词仍会残留，因此这些计数只用于语境判断。高频实词为 `Sinkhorn`（40）、`HBM`（35）、`FlashSinkhorn`（33）、`memory`（29）、`transport`（28）、`streaming`（27）、`attention`（24）、`EOT`（23）。高频二元组为 `biased dot-product`、`transport matrix`、`score matrix`、`squared Euclidean`、`on-chip SRAM`；高频三元组为 `squared Euclidean cost`、`load on-chip SRAM`、`biased dot-product LSE`。这些词由方法机制和硬件对象驱动，模板语言占比有限。

一人称动词的可复核计数为：`we present` 1、`we introduce` 1、`we demonstrate` 1、`we evaluate` 3、`we derive` 1、`we report` 1；`we show/find/propose/observe` 为 0。强主张集中在“exact”、theorem 和带数值的 performance 句；弱主张集中在 `can`、`may`、`typically`、`up to` 与范围段。按摘要、引言贡献、结果解释和结论中 26 个可识别结论句的人工编码，强主张 15、弱主张 11，比例约 1.36；该比例是叙事编码，未把表格单元或公式碎片计入。

最有效的叙事模式是先把性能问题归因于一个可测量的 data-movement bottleneck，再给出 exact algebraic reformulation、IO theorem 和 profiler counters，最后用下游 workload 验证能力外溢。最明显的读者成本来自 24 页 appendix 对 9 页正文的比例，以及速度边界、precision、schedule crossover 和 HVP parity 分散在 Table 8–24。单一主线保持清晰：**将 squared-Euclidean EOT 的稳定 Sinkhorn update 变成 attention-form online LSE，使 Triton kernel 能以 row-stationary tiling 避免 `n×m` HBM intermediates，并把同一结构延展到 transport、gradient 与 HVP。**

可迁移规则：系统论文应把“瓶颈 → 可证明的重写 → dataflow 实现 → profiler 机制证据 → workload 后果”编成同一因果链，每一环都给出可反驳对象。该规则适用于算子代数可重写、瓶颈主要来自 memory traffic 且基线可在相同工作量下比较的场景。若 cost 不具备 affine dot-product 结构，或目标硬件/shape 使 dense GEMM 更有利，则需要改用相应的算法与基准设计。
