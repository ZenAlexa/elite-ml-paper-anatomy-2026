## 5. 方法、公式与理论地位

### 输入、输出与组件对应的问题

- **输入／状态**：fine-tuning corpus `D_ft={(v_n,c_n)}`, query video `(v̂,ĉ)`, 固定 `(t_fix, ε_fix)` 与 Fastfood projection `P`；video 先经 VAE 得 latent，AllTracker 在 pixel space 给 flow、visibility、confidence。[p. 3, §3.1；p. 5–6, §3.4；explicit]
- **输出**：每个训练 clip 对 query 的 `I_mot(v_n,v̂)`，以及按 top-`K`／majority vote 得到的子集 `S`。[p. 6–7, §3.5, Eqs. 17–18；explicit]
- **问题 1：现代模型的 gradient compute/storage 负担** → common randomness、单采样、Fastfood projection 与存储复杂度分析。[p. 4–5, §3.2；p. 7, §3.6；explicit]
- **问题 2：clip duration 影响梯度尺度** → Eq. 11 的 `1/F` 与 81-frame standardization 的消融。[p. 5, §3.3；p. 11, §4.4；explicit]
- **问题 3：appearance 混入 motion** → AllTracker motion magnitude、min–max mask、motion-weighted loss 与 projected gradient inner product。[p. 5–6, §3.4, Eqs. 12–17；explicit]
- **问题 4：多个 query 的原始分数不可直接校准** → percentile threshold 后 majority vote。[p. 7, §3.5, Eq. 18；explicit]

段落动作序列可概括为：`state_problem → contrast_alternative → derive common-randomness estimator → instantiate single-sample projection → define frame correction → define motion mask/loss → instantiate subset selection → state_complexity`。[p. 3–7, §3；interpretation]

### 图、算法和可检验的不连续处

Fig. 1 用上层「AllTracker → motion patch → motion-weighted loss → motion gradients」和下层「projected train/query gradients → influence matrix → ranking」对齐公式链；Fig. 2 再给 float／roll 查询与正负样本，连接 attribution score 和 data-selection 的语义。[p. 4, Fig. 1；p. 7, Fig. 2；explicit]

Algorithm 1 被放入 Appendix E。它有两个顺序循环：先逐训练样本提取 mask、算 `g_mot/F`、投影归一化；然后逐样本与 query 向量点积并排序。关键不变量是 train 与 query 共用 `(t_fix, ε_fix)`，所有向量用同一 `P`，且在点积前归一化。正文 p. 7 给出 compute/storage/ranking 的 Big-O；Table 6–7 才给实际 runtime。[p. 7, §3.6；p. 22, Algorithm 1；p. 24–25, Tables 6–7；explicit]

**公式与消融的张力。** Eq. 11 的 `1/F` 在 Eq. 10 的归一化之前出现。在线性投影后做 L2 normalization 的字面实现下，这个全局正标量不会改变向量方向或点积排序；p. 11 却把「standardize all videos to 81 frames」与 lower length correlation 归在 frame-length normalization。实验可能依赖 clip resampling、mask 或实现中未写出的步骤，但 PDF 没有把这些作用拆开测试。因此「frame-length fix」的经验结论有支持，其公式级机制仍是部分闭合。[p. 5, Eqs. 10–11；p. 11, §4.4；interpretation]

### 主结果与直接证据

1. **VBench（Wan）**：Motive 的 dynamic degree 为 47.6（Wan2.1）和 48.3（Wan2.2）；Random 为 41.3／41.6，Ours w/o MM 为 43.8／43.8，Full FT 为 42.0／45.3。表注说明数值为百分比、higher is better，所有 selection 方法用 10% training data。Table 1 同时显示 motion smoothness 为 96.3／97.6；这两列并非两模型中的唯一最优值，论文把 dynamic degree 定为主要 target。[p. 8, Table 1；p. 10, §4.2；explicit]
2. **定性结果**：Fig. 3 用 compress、spin、slide、free fall 的三帧组比较 Base、Random 和 Motive；正文把差异解释为更高 motion fidelity 和 temporal consistency。它是选择的四个场景，不提供逐项评分或失败分母。[p. 9, Fig. 3；explicit / layout_observation]
3. **人评**：Table 2 报告 Ours vs Base 74.1/12.3/13.6，vs Random 58.9/12.1/29.0，vs Full FT 53.1/14.8/32.1，vs w/o MM 46.9/20.0/33.1（win/tie/loss，%）。正文只把 74.1% 和 53.1% 作为「perceptually meaningful」的叙述重点。[p. 10, §4.3, Table 2；explicit]
4. **第三模型**：LTX-2B 中 Motive 的 dynamic degree 为 45.1，Base 36.5、Full FT 38.9、Random 37.8、Motion mag. 39.6、V-JEPA 40.2、w/o MM 41.8；这是 appendixed 结果，不在主文表中。[p. 20, Table 5；explicit]
5. **投影**：`D'=128/512/1024/2048` 对 full-gradient score 的 Spearman `ρ` 为 46.9%/74.7%/75.7%/76.1%；作者据此选 512。图没有 error bar 或重复设定。[p. 10, §4.4, Fig. 5；explicit / layout_observation]
6. **单 timestep**：`t=751` 与 10 个均匀 timestep 的「ground truth」有 `ρ=66%` agreement；正文称多 timestep 的增益很小。10-time baseline 的不确定性和每项计算单位未列出。[p. 11, §4.4；explicit / not_present]
7. **frame length**：未标准化时 score 与 video length 的相关性为 `ρ=78.0%`；81-frame standardization 声称将 spurious length correlation 降低 54.0%，并以 Fig. 4 的 floating examples 说明排名更连贯。后者是相对 reduction，文中未给标准化后的绝对 `ρ` 或重复结果。[p. 11, §4.4；explicit]
8. **附录分析**：top-10% influence 的 mean motion magnitude 为 3.85，bottom-10% 为 3.69；两数据集的 mean cross-motion overlap 为 24.0%／24.3%。这两组描述性分析没有 distributional uncertainty 或检验。[p. 20–21, §D；explicit / layout_observation]

### 统计审计

- **聚合单位**：Table 1 和 Table 5 为 VBench 百分比，但 PDF 没有说明每 prompt 的 sample 数、generation seed、run 数或跨 prompt 的聚合公式。p. 8 只说 10 类、每类 5 prompts；p. 23 说 test 与 query 共享类别但有不同外观。[p. 8, §4.1；p. 23, §F.1；explicit / not_present]
- **中心量与不确定性**：主表、LTX 表、projection 图与 heatmaps 都给 point values。没有标准差、standard error、interval、假设检验、多重比较校正、bootstrap、Bayesian 分析、回归或 effect-size 报告。[p. 8, Table 1；p. 10, Fig. 5；p. 20–21；layout_observation]
- **人评分母**：caption 说「50 videos with 17 participants (850 total)」，而正文先说「three pairings」，Table 2 却列出四个 pairings。850 是每一行、所有行合计，还是其他分配，PDF 不清楚；不能据此补写显著性结论。[p. 10, §4.3, Table 2；explicit / interpretation]
- **显著性措辞**：p. 10 使用 “significantly outperforming”，但相邻 Table 1 只提供点估计；此处的「significantly」没有对应的统计程序。[p. 10, §4.2, Table 1；layout_observation]

## 11. 用词、修辞与可迁移规则

- **高频语义组**：`motion`／`temporal dynamics`、`Motive`、`attribution`／`influence`、`gradient`、`training clips`／`fine-tuning data`、`motion-aware`／`motion-specific`、`scalable`。它们由研究对象、方法组件与结果叙事共同驱动，不是纯会议模板词。[p. 1–11；interpretation]
- **二元／三元词组**：`motion attribution`、`motion-aware attribution`、`motion-specific influence`、`motion-weighted loss`、`gradient-based attribution`、`high-influence data`、`fine-tuning subset selection`、`frame-length normalization`。词组会在摘要、方法标题、caption、结果段落重现，形成一致的名称、机制和结果链。[p. 1, 4–10；explicit]
- **主张动词**：精确字符串 `we show`、`we find`、`we demonstrate`、`we propose`、`we observe` 在 PDF text layer 中均为 0；`We present` 出现 1 次（摘要），`We introduce` 2 次（引言、§3.4）外加结论过去式 1 次，`We evaluate` 5 次（方法／实验／Appendix C），`We improve` 2 次（摘要、贡献）。论文较多以「As shown in Table/Fig.」和第三人称结果句承载效果主张。[p. 1–11, 20；layout_observation]
- **语气分布**：强断言集中于 `first`、`scalable`、`consistent`、`significantly outperforming`、`superior`；明确限定集中于 `To our knowledge`、`approximate upper bound`、`e.g.`、`may`、`suggests`、`future work`。按段落级人工编码，强断言约 14 个、带限定断言约 9 个，比例约为 3 比 2；这不是 token 统计。[p. 1–2, 5, 10–11, 25；interpretation]

**可迁移规则。** 当论文要把一个难以直接观察的生成属性连接到训练数据时，最有效的主文结构是：先在一张图中把 measurement transformation、low-cost representation 与 selection action 连成一条链；随后用同一 budget 的 baseline、组件删除和人评闭合该链。这里 Fig. 1、Table 1、Table 2 与 Appendix Algorithm 1 分工清楚。[p. 4, 8, 10, 22；interpretation]

**适用边界。** 这条规则要求 measurement function 的作用可被直接辨认。若其核心修正与后续 normalization 在代数上可能抵消，或目标属性没有独立测量，必须增加分解消融、输出绝对变化与不确定性；仅靠一组 aggregate point estimates 和代表性帧不足以闭合因果机制。[p. 5, Eqs. 10–11；p. 8–10；interpretation]
