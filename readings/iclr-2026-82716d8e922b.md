## 0. 单一主线与先行判断

论文的单一因果主线是：LLM agent 在部分可观测、长程主动推理中用不完美的内部 belief 更新问题状态；当更新误差随偏离增大时，轨迹进入 absorbing Belief Trap Region（BTR），后段不再带来有效信息，却会通过 outcome-only RL 的 GAE 把负漂移传回前段并污染探索信用；T3（Truncating Belief-Trapped Trajectories）用持续的 epistemic-stall proxy 在 BTR 尾部开始前截断轨迹，把信用保留在 informative prefix 上（p.2–5，Fig.1，Def.2，Thm.1–2，Cor.1）。

主线内部形成了「假设 → BTR 充分条件 → advantage inversion → proxy 截断 → 五任务结果」的链条。证据最完整的部分是截断改变 GAE 曲线与任务分数的方向一致性；最弱的部分是理论对象不可观测，真实 LLM belief 和 Bayesian oracle 被 PE 上的 preference-vector 距离与线性高斯 surrogate 替代，且若干证明步骤所需的逐样本条件没有在文字假设中给出（p.24–26，p.21）。因此，T3 作为已测任务上的工程方法有直接支持，作为一般 belief-control 原理则属于部分闭合。

### 5.2 形式对象、假设、定义和推导链

- **理论对象**：`b⋆t` 是理想 Bayesian belief，`bt` 是 LLM internal estimate；`I(b,a)` 为 oracle one-step informativeness，`Pθ(b)` 为 agent expected progress，`cθ(b)` 为 LLM–Bayes update error，`dt=||bt-b⋆t||1`。这些对象主要是分析变量，LLM 实际不会显式输出 `bt`（p.16–18）。
- **Assumption B.1**：oracle potential 有界并按 deterministic nonincreasing `ut` 收敛到 0（p.17）。
- **Assumption B.2**：reachable observation probability 下界 `O(o|s,a)≥η`（p.17）。
- **Assumption B.3**：policy 对 belief 为 total-variation Lipschitz，常数 `Lπ`（p.17）。
- **Assumption B.4/主文 Assumption 1**：对 `Ψ(b)≥U0`，`cθ(b)≥mθΨ(b)-c0`，即 deviation 越高，update error 至少线性放大（p.3，p.18）。
- **Def. B.5/主文 Def.1**：BTR 是 absorbing 且 `Pθ(b)≤0`，等价于 expected potential 不下降（p.4，p.18）。
- **Def.2 T3 condition**：若窗口 `[t-k,t)` 中每步 `d(Hτ,Hτ+1)≤Δmin`，则在 `t` 截断；有限可枚举 `H` 且 belief uniform 时 `Ψ(bt)=log|Ht|`（p.4–5）。
- **证明链**：Lemma B.1/B.2 给 informativeness 对 belief/action-policy 的连续性 → Eq.(8) 写 `Pθ=E[I]-cθ` → Eq.(9)–(18) 进入 BTR 的充分条件 → Eq.(19)–(36) 给 gap 的指数增长和 entry upper bound → Eq.(37)–(43) 分离 GAE prefix/tail 并得到 advantage inversion → Eq.(44)–(61) 给 false-positive bound 与两条 lemma proof。

## 6. 实验设计

### 6.1 任务、数据和 proxy

| 任务 | 数据/交互 | `H,d,k` 的实例化 | 证据 |
|---|---|---|---|
| GuessNumbers (GN) | 隐藏无重复数字；反馈 `xAyB`；agent 逐轮猜测。 | `H_t` 为符合历史反馈的候选数；`d=|Hτ|−|Hτ+1|`；guess 落在 `H_{t−1}` 外即 k=1 截断。 | p.5–6, §3.1, “candidate numbers consistent with the interaction history” |
| SituationPuzzles (SP) | 面对悖论故事，向 Qwen-2.5-14B judge 提 yes/no；judge 返回 Yes/No/Unknown。 | 以 judge “Unknown” 作为 refinement 不足 proxy；连续 k=5 个 Unknown 截断。 | p.6, §3.1/F.1, “Unknown” |
| CircuitDecoding (CD) | 从候选 Boolean circuits 中以 binary query 消除不一致候选。 | `d=|Hτ|−|Hτ+1|`；候选集 k=3 轮不收缩时截断。 | p.6, §3.1, “queries no longer reduce uncertainty” |
| PreferenceEstimation (PE) | 对 reference movies 提 pairwise comparison，估计隐藏 preference vector。 | 用 `Sim(vτ+1,v⋆)−Sim(vτ,v⋆)`；相似度连续下降 k=2 截断；训练 proxy 访问 `v⋆`。 | p.6, §3.1, “depends on access to the ground-truth preference” |
| MovieRecommendation (MR) | 先做 PE，再对 unseen movies 推荐，考察 OOD transfer。 | 沿用 preference-vector similarity proxy；最终 recommendation 是 unseen movie EM。 | p.6、p.30, “generalization beyond the training distribution” |

引言说覆盖“4 datasets and 5 tasks”，而 Appendix F 的 Table 9 列出 SP、GN、CD、PE、MR 五个 train/test 行；论文没有说明 PE 与 MR 的 dataset 计数为何合并或拆分。这是事实层的计数冲突，不能替作者补齐。

### 6.2 Baselines、模型与指标

- **Baselines**：Direct Inference（o3-mini、Gemini-2.5-Pro、Qwen-2.5-7B-Instruct）、PPO、GRPO、GSPO；T3 分别叠在三种 RL objective 上。p.6 的 Table 1 将所有 metrics 乘以 100，箭头表示相对 vanilla RL 的绝对 points。
- **模型/反馈**：主 RL 是 Qwen2.5-7B-Instruct；GN/CD/PE/MR feedback 为 rule-based；SP 的 interactive feedback 由 Qwen2.5-14B-Instruct judge 提供（p.6）。
- **指标**：GN/CD/MR 用 EM；SP 用 F1-word/F1-char；PE 用 cosine-based Binary Similarity，阈值 0.88（p.7）。阈值在 D.1 以 0.85/0.88/0.90/0.95 比较。
- **数据量**（Table 9, p.31）：SP 400/100，GN 1526/382，CD 1000/300，PE 700/300，MR 700/300（train/test）。GN 是从 AR-Bench 适配的 `(a,b,x0,y0)` 子组随机 train–test split；CD/PE/MR 是从 Multi-Turn Puzzles 适配。
- **训练实现**（F.3, p.32）：最大交互轮数 GN/SP/CD/PE/MR = 10/15/10/10/5；200 training steps；actor learning rate `1.0×10−6`；FSDP、BF16；GN/SP 用单节点 8×H100，CD/PE/MR 用单节点 8×B200；vLLM tensor parallel size 1；SP temperature 1.0、GN 0.6，所有数据 top-p 0.95。PPO 的 `λ=γ=1`、KL `β=0.001`、clip `ε=0.2`；GRPO 每 prompt 采 5 responses；GSPO 无 KL，`εlow=0.0003`、`εhigh=0.0004`。
- **复现粒度缺口**：正文和附录给出了 prompt、数据量、最大轮数、硬件和主要 optimizer 参数，但没有报告每个主结果的 random seeds、run 数、均值离散量、置信区间或显著性检验；图中线条没有误差带。证据位置为 p.6–10、p.31–35，属于 `not_present`，不把单次曲线写成统计稳定性证明。

### 6.3 设计顺序与识别目标

设计顺序是：任务 proxy（§3.1）→ baseline/metric（§3.2）→ main result（Table 1）→ reward/length dynamics（Fig.3–4）→ OOD（Table 2）→ proxy/window/random ablation（Table 3/Fig.5）→ scale/architecture（Fig.6）。它与引言的 BTR–credit–T3 结构一致；Appendix C 再用受控 fixed-policy/failure-rollout 实验隔离 GAE tail 机制。

三个识别目标分开：

1. **效能**：T3 对 vanilla PPO/GRPO/GSPO 的最终 test metric 是否提高。
2. **机制**：在失败 rollouts 上，T3 是否抬高早期 token 的 GAE，tail 是否随长度压低早期 advantage。
3. **误截断代价**：在成功 rollouts 上人工以 α 概率 turn 3 截断，观察未来正 TD-error 被移除后的 early advantage 下降（p.26–27）。

PE/MR 主 proxy 使用 `v⋆`，因此它是训练期 oracle-assisted detector；D.3 只在 PE 上补做 ground-truth-free moving-average detector，尚不足以覆盖 MR 或开放域。

### 7.2 训练稳定性、token efficiency 与 OOD

- **Fig.3（p.7）**：展示 CD-PPO、SP-GRPO、GN-GSPO、PE-PPO 的 reward 对 training steps。作者解释 vanilla 有较高 variance、partial convergence 后 collapse；T3 轨迹多为 monotonic/near-monotonic。图没有误差带，结论是曲线形状观察，不是方差估计。
- **Fig.4/p.8**：展示 response length。T3 早期 reward 可能略慢，但减少每 rollout token。达到 CD reward 0.65 时，PPO+T3 平均用 vanilla 总 token 的 66.4%；GN GSPO 达到 0.96 时用 76.3%。作者还称 vanilla 常 stagnate，而 T3 可到 CD 0.8、GN 0.99。这里的成本量是达到两个目标值的相对 token consumption，不是全训练预算或 wall-clock savings。
- **Table 2（p.8）OOD**：PPO+T3 在 PE reference size `S=5/10/15/20/30` 分别 44.3/49.0/47.0/53.7/46.3，对 vanilla 40.0/42.0/39.3/41.0/42.3，增益 +4.3/+7.0/+7.7/+12.7/+4.0；reference sampling min-max/uniform/max 为 +10.3/+7.0/+10.7。CD candidate size `S=10/15/20/25/30` 增益 +18.5/+13.0/+7.7/+10.8/+4.2；hidden circuits `C=2/3/4` 增益 +18.5/+15.0/+6.6。样本只覆盖 CD/PE 两任务和预设 shifts，OOD generality 属于 partially closed。
- **Fig.6（p.10）**：Qwen 3B 仅有限改进，7B/14B 更明显；LLaMA-3.1-8B 改进边缘，Qwen-7B 与 DeepSeek-R1-Distill-LLaMA-8B 较大，后者 T3+RL 总体最好。图给柱状/折线对照，却无数值表或误差量；作者用 `mθ` 的可能差异解释架构异质性，属于 conjecture。

### 7.3 理论的经验核对（Appendix C）

- **Fig.7，p.25，Assumption 1**：PE 上用 `Ψ̂t=||wt−w⋆||²`，用 linear-Gaussian `B̂` 近似 oracle，收集超过 150k 个 `(Ψ̂,ĉθ)` 样本；10th-percentile lower envelope 拟合。Qwen-2.5-7B 用 `Û0=10`、`ĉθ=0.0969×Ψ̂−3.0478`，32B 用 `Û0=2`、`ĉθ=0.4655×Ψ̂−1.5158`。这支持“在 surrogate active region 中有正斜率”，不等同于验证真实 `bt/B⋆`。
- **Fig.8，p.25–26，Thm.2/Cor.1**：固定 PPO policy，比较 w/o 与 w/ T3；只分析 final reward 0 的 failed rollouts，取前 500 token 的 mean GAE。PE/CD 无截断时 early-token advantage 有负 drift，T3 提升 early values；PE max turns 从 6 到 15 时 tail 越长，压制越强；CD k 越小，保留 prefix 的 advantage 越高。该实验直接对应 mechanism，但仍以 GAE proxy 代替真实 policy-gradient update。
- **Fig.9，p.26–27，false-positive**：固定 vanilla-PPO，筛 final reward 1 的成功轨迹，在 max turns=10 下以概率 α 在 turn 3 强制截断；α=0.1/0.5/0.9 越激进，CD/PE early exploratory token 的 mean GAE 越低。它验证误截断会删除正 future contribution，却没有给真实 proxy 的 false-positive rate。

## 9. 结论、局限与闭环

### 9.1 结论段落

p.10 结论只有一段，动作序列为 `重述问题 → 重述机制 → 回收方法 → 回收五任务结果 → impact`：belief deviation/BTR 被重述为 RL active reasoning 的 failure mode；T3 被重述为 early-truncation；五任务结果回收 training stability/final performance；最后外推到 robust/generalizable agents。结论没有新增数字、定理或新实验；它没有把 false-positive、ground-truth proxy 或理论证明边界带回主结论句。

## 13. 最终判断

1. **单一主线**：把 active reasoning 的重复/停滞行为重解释为 belief-update error growth 进入 BTR，再把 BTR 的 uninformative tail 解释为 outcome-RL credit assignment 的负漂移，最后用持续 progress-stall proxy 做 T3 early truncation。
2. **正文保留的决策关键内容**：POMDP 与 `Ψ/cθ` 最小形式化、BTR/GAE 两个核心理论结论、Def.2 proxy principle、GN/SP/CD/PE/MR 实例化、Table 1、训练稳定性/成本图、OOD 表、window/random/architecture ablation。读者可据此判断“是否值得采用 T3”。
3. **移入附录的细节及影响**：正式 statements/proofs、Assumption 1 surrogate fit、GAE fixed-policy controls、false-positive diagnostic、threshold/GT-free/adaptive variants、dataset construction、prompts、optimizer/hardware 全在 Appendix B–F。迁移没有破坏方法概念的可读性，却使理论有效域、proxy oracle access、证明缺口和复现边界无法从正文快速看到。
4. **最有效的模式**：Fig.1 将 vanilla 与 T3 的 rollout/credit 对照放在同一张跨栏图；理论用 `Ψ`、BTR 和 GAE tail 构成短链；Fig.8 把 tail length、truncation strength 与 early-token GAE 放入同一受控图组；Table 3 同时比较 window 与 random truncation，能区分“截断存在”与“proxy 设计”。
5. **最大叙事缺口**：主文把不可观测理论对象和可观测 task-specific proxy 连接得很顺，但真实 belief 的验证、random seed/uncertainty、PE ground-truth access、跨任务 general-purpose detector 和 Theorem B.1 的逐样本 drift 条件没有同等显著地呈现；“robust/generalizable”因而超出已闭合证据。
6. **可迁移规则**：若方法依赖不可观测内部状态，应在主文同时给出「理论状态、可观测 proxy、proxy 误差/误触发代价、最终决策」四联表，并把机制诊断与效能结果分开报告。
7. **适用边界**：这条规则适合有 latent-state 理论、trace-level proxy 和可操作 intervention 的 agent/RL 论文；若内部状态可直接测量，或任务没有长期尾部 credit 污染，T3 式 proxy–truncation 叙事不应强行套用。
