## 7. 结果、统计与可视化

1. **KS1 vs CEOs（Table 1, p.8）**：Word 的 Probe@1K 为 CEOs 90.203、KS1(Ssym) 90.265、KS1(Spol) 90.678；GloVe1M 的 Probe@10K 为 63.545、64.041、64.355；GloVe2M 为 54.916、55.240、55.394。最大绝对提升约 0.81 percentage points，与摘要/引言的“up to 0.8%”一致。10-run mean recall 是唯一明确的统计处理；没有 error bar、显著性检验或 effect-size interval。结果支持“多数设置轻微提升”，但 GloVe2M 的 top-2/top-10 补充表中 Spol 并非每个 probe 都胜出。
2. **主 ANNS（Figure 1, p.9；Figure 2, p.10）**：六个 recall–QPS panel 以 HNSW、ScaNN、HNSW+PEOs、HNSW+KS2 作曲线比较。作者报告除 Word 外 HNSW+KS2 最佳，约为 HNSW 的 2.5–3×、PEOs 的 1.1–1.3×；Word 高 recall 区域因 HNSW connectivity issues 由 ScaNN 胜出。图以曲线展示，未给具体 QPS 数值表或方差。
3. **indexing cost（p.9）**：在已有 HNSW graph 后，六数据集额外构建 KS2 structure 的时间依次为 Word 42s、GloVe1M 164s、GIST 165s、GloVe2M 188s、SIFT 366s、Tiny 508s；作者称低于 graph construction time 的 25%。这是 wall-clock 单点报告，没有重复运行或方差。
4. **index size（p.9–10）**：Figure 2 的上排比较 additional cost；作者解释 KS2 因存储 scalars 更少而略小于 PEOs，贡献列表把它概括为 5% reduction。没有给六数据集逐项 byte/MB 数值表。
5. **L mechanism（Figure 2, p.10；Figure 5 p.21；Figure 8 p.23）**：较大 L 通常增大 index size、减小 reference angle，但也增加 test time；在主展示中 (d'=d/L) 约 16 时搜索表现最好。Figure 5 显示增加 L 对 reference-angle cosine 的提升明显，而线性增加 m 的提升缓慢。
6. **k=100/k=1 robustness（Figures 6/7, p.22）**：k=100 保留 recall–QPS 比较；k=1 时 ScaNN 在 Word、GloVe1M、GloVe2M、Tiny 表现很好，作者将其部分归因于 HNSW connectivity；其他情形 HNSW+KS2 最佳。仍是曲线比较，没有置信区间。
7. **graph transfer（Figure 9, p.23）**：NSSG+KS2 在除 GIST 外的所有数据集上胜过 NSSG+PEOs；这支持优势不完全依赖 HNSW，但 GIST 例外使“independent of graph structure”更适合写成受限支持。

聚合单位是 dataset × setting × run（Table 1 的 run 平均），ANNS 图的聚合方式未说明；中心量为 recall 与 QPS 曲线，离散量/区间/检验/多重比较/bootstrap/Bayesian/regression 均未报告。图注能说明 k 和 axes，但不能独立恢复 hardware、L、ef 参数；表注可恢复 probe、m、top-s0 和 10-run average。作者区分了实质机制（reference angle、L）与性能，但没有把统计不确定性和机制证据分开量化。

## 11. 用词与修辞

正文（排除 references、公式碎片、表格数值和模板固定语）主要高频实词是 `angle / projection / vector / reference / query / structure / kernel / test / search / probability / dataset / recall / QPS / complexity`；高频二元搭配是 `reference angle`、`random projection`、`projection vectors`、`similarity search`、`query vector`、`search performance`；三元搭配是 `probabilistic kernel function`、`graph-based approximate nearest`、`reference angle information`、`query-per-second throughput`。这些词由真实论证对象驱动，领域名词占比高，模板化形容词较少。

主张动词集中在 `design/propose/introduce/show/demonstrate/establish/achieve`，限定词集中在 `slightly/generally/typically/reasonable/particularly/approximately`，对比词为 `unlike/in contrast/however/whereas`，因果词为 `therefore/thus/since/because`。`we show` 主要在摘要、贡献和实验（p.1–3、8–9）；`we propose` 在摘要、贡献和 §6；`we demonstrate` 在摘要与 ANNS 结果；`we find/observe` 在理论解释和 §7。强主张（solve/satisfy/best/superiority/outperform/achieves）集中于摘要、贡献、lemma/corollary 和结果小节，弱主张（slight/generally/often/can be regarded as）集中于 remarks、implementation 和 exceptions；没有可靠的全文句法计数可把两者当作统计量，语境编码比裸词频更可信。

## 12. 最终判断

1. **单一主线**：以 reference angle 作为唯一中间机制，先把 Gaussian extreme-order 的渐近关系替换为 random-rotation 下的 exact spherical relationship，再用 antipodal/cross-polytope configuration 减小该角度，最后分别实现 KS1 comparison 和 KS2 threshold/routing。
2. **正文保留的决策关键内容**：Problem 1.1/1.2、Eq.2–4、Lemma 4.2/4.3、Ssym/Spol 的结构动机、Lemma 5.1、Eq.9/Corollary 6.2、Table 1、Figures 1/2，以及 Word/GIST/L 的边界。
3. **移入附录的内容及损害**：证明、完整算法、符号表、数据/参数、不同 k/top-s0/L、NSSG 和 Figure 3–9。它们不破坏主线理解，却使数值复现和不确定性审查必须跨页读取；主文没有逐 dataset 原始 QPS 表。
4. **最有效模式**：让同一可操纵量 (A_S)/reference angle 同时出现在 conditional CDF、configuration objective (J(S))、结构算法、L sensitivity 和结果解释中；Eq.4 → Lemma B.1 → Figure 5 → Table 1/2 的链条比孤立的性能表更有解释力。
5. **最大叙事缺口**：理论 guarantee 是条件性的，经验优势主要由曲线和十次均值支撑，未给 seed、误差表达、原始 QPS 点或直接的 reference-angle-to-error mechanism test；“Gaussian suboptimal”和“graph-structure independent”因此只能作范围受限结论。
6. **可迁移规则**：先找一个既能被方法直接操纵、又能被理论精确描述的中间量；让每个结构/超参数变化先改变该量，再用匹配的结果设计验证预测，并将最终 benchmark 作为后续结果。
7. **适用边界**：该规则要求中间量可观测、可控制，并在基线与新方法之间保持同一 estimand；若数据分布、graph connectivity、query budget 同时改变，或只有 aggregate curve 而没有机制测量，就不能把相关性写成因果闭环。
