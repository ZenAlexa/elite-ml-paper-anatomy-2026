## 方法与理论链

**单一机制链**：SAM 把已观测 bias 归入 `B=W∪Z`；在 SAM、充分 overlap 等条件下，`\hat Y ⟂ B | Y` 使 counterfactual indirect effect 和 spurious effect 为零；以 MLE 任务损失加 conditional distance correlation 惩罚近似该约束；`DISCO_m` 用参考点子集，`sDISCO` 用矩阵因子化将全批局部 V-statistic 的内存从朴素 `O(n³)` 降为 `O(n²)`。【PDF p. 3–6, §2–§3.3】

- **因果层**：Eq. (1)–(5) 定义 total variation、`ctf-stable`、`ctf-IE`、`ctf-SE` 和 causal stability。Theorem 2.3 给出条件独立到 causal stability 的充分性；Theorem 2.4 连接受约束 MLE 与最大 stable effect；Corollary 2.5 将 mediator 与 spurious bias 合并为 `B`。【PDF p. 3–4, §2.1】
- **假设层**：需要 `P(B=b|Y=y)>0` 的 sufficient variability；允许把有用 mediator 留在 `W_stable`；未观测 `Z'` 只能在「没有有效 proxy」这一附加条件下得到已观测路径的最好近似，存在有效 proxy 时论文转向 proximal causal inference。【PDF p. 4–5, §2.2】
- **统计层**：Definition 3.1–3.4 和 Theorem 3.3 将 conditional distance covariance/correlation 与 strong negative type 下的条件独立联系起来；主文只给命题与证明位置，完整定义和证明位于 Appendix F。【PDF p. 5–6, §3.1；p. 19–21, Appendix F】
- **算法层**：`DISCO_m` 在 Eq. (13)–(15) 中抽样 `m≤n` 个 reference points；`sDISCO` 在 Eq. (16)–(18) 用 `T1,T2,T3` 的 Hadamard product / dense matrix multiplication 实现精确全局相关；Eq. (19) 将 `sDISCO(\hat Y,B|Y)` 作为训练期正则项。正文没有 Algorithm 环境或伪代码。【PDF p. 6–7, §3.2–§3.3】

主文有 21 个编号公式（1–21），附录有 30 个（22–51）。主文出现 3 个 Theorem、3 个 Proposition、1 个 Corollary 和 4 个 Definition；附录承担路径效应证明、条件距离相关证明、`DISCO_m` 一致性以及 `sDISCO` 精确因子化证明。没有 Lemma 或编号算法。【PDF p. 3–6；p. 15–23】

方法段落的实际动作序列可概括为：`state_problem → setup_notation → define_component → derive → define_component → connect_to_prediction → state_complexity → instantiate_algorithm → derive → connect_to_experiment`。Figure 2 只承担 SAM 图形语义；实际计算结构由 Eq. (13)–(19) 和 Appendix G 承担。【PDF p. 3, Fig. 2；p. 6, Eq. (13)–(19)；p. 22–23, Theorem G.1】

## 实验设计、统计与结果

### 设计

- **数据与任务**：dSprites 和 Blob 为合成回归；YaleB、FairFace、Waterbirds 为视觉分类；MNLI 为文本蕴含分类。偏差分别覆盖 confounder、mediator、selection/collider、连续或离散属性，以及 multi-bias dSprites 设置。【PDF p. 7, §4.1；p. 24–26, §H.1】
- **协议**：除 MNLI 外，训练集带 bias，validation/test 设为无偏；模型在无偏 validation 上选择、在未见无偏 test 上报告。MNLI 改用 Worst Group Accuracy（WGA）选择与报告。前五类数据还被加入 label noise。【PDF p. 7, §4.1；p. 26, §H.1.6】
- **模型与对照**：真实图像采用 ImageNet 预训练 ResNet-18，合成数据采用未训练或小型 ResNet，MNLI 用预训练 TinyBERT；比较 GDRO、adversarial、C-MMD、HSCIC、CIRCE、IRM、Fishr 以及两种 DISCO。【PDF p. 7–8, §4.2；p. 26–28, §H.2】
- **超参数**：论文称多数基线的网格宽于 DISCO；Table 5 列出搜索格数（例如 `DISCO (both)` 为 `6×6=36`，CIRCE 为 `5×5×5=125`，HSCIC 为 `3×4×3×3=108`）。HSCIC 的 `λ_ridge=0.01` 固定于初步运行后的选择。【PDF p. 8, §4.2；p. 27–28, §H.2.4/H.2.9】
- **未报告项**：Table 2 写明「mean ± standard deviation across runs」，但没有提供 run 数、随机种子、训练 epoch 数或主实验硬件。第 30 页仅报告 runtime benchmark 的 Titan RTX、Threadripper、8 个 dataloader workers 和 32-bit precision。【PDF p. 9, Table 2；p. 30, §H.5】

### 结果与统计

Table 2 是主结果中心。六列采用不同 estimand：dSprites/Blob 为 `R²`，YaleB/FairFace/Waterbirds 为 Balanced Accuracy，MNLI 为 WGA；每项是跨运行的均值 ± 标准差，run 的分母没有说明。【PDF p. 9, Table 2】

- `DISCO_m` 在 dSprites 为 `0.688 ± 0.018`，sDISCO 为 `0.687 ± 0.016`，高于 bias-only ResNet 的 `0.417 ± 0.037`；Blob 为 `0.759 ± 0.015` 和 `0.751 ± 0.014`。【PDF p. 9, Table 2】
- YaleB 与 FairFace 的最高 DISCO 值分别是 `0.804 ± 0.027` 和 `0.860 ± 0.006`（均为 `DISCO_m`）。【PDF p. 9, Table 2】
- Waterbirds 的最高数值属于 CIRCE（`0.894 ± 0.010`），高于 sDISCO 的 `0.874 ± 0.008`；MNLI 的 sDISCO 为 `0.760 ± 0.007`，略高于 GDRO 的 `0.755 ± 0.010`。这使「consistently outperform」在论文自己的表中应按「竞争性或多列靠前」理解，不能解读为每个数据集第一。【PDF p. 9, Table 2；p. 1, Abstract】
- 受控 multi-bias dSprites 的 Table 3 给出 `sDISCO_X,Y` 的 `S_X=0.066`、`S_Y=0.067`、`Acc_ctf=0.98`，对照 ResNet 为 `0.302`、`0.275`、`0.65`。该表没有 dispersion 或重复次数说明。【PDF p. 8, Table 3】
- Appendix H.4 的 Table 6 显示 sDISCO、HSCIC、CIRCE 的 `S_X` 相近（`0.058/0.064/0.064`），而对应 counterfactual `R²` 为 `0.7181/0.6021/0.5939`；这是机制诊断，范围限于 dSprites。【PDF p. 29–30, §H.4, Table 6】
- Table 7 的单机 runtime/memory benchmark 显示 sDISCO 在 batch size 1024 的 mean epoch time 为 `29.06` 秒；Naive DISCO 在 1024 OOM，`DISCO_m` 在 768 OOM。表中没有重复次数或不确定性。【PDF p. 30, §H.5, Table 7】

Figure 3 把数据集的因果图放在实验设置开始处；Table 1 随后对齐方法能力、bias/target 类型与多属性支持。Figure 4 和 Table 3 紧邻 path analysis，显示「模型看见两种偏差、只看一种偏差、完全不正则」的可控对照。Table 2 置于第 9 页顶部跨栏，承担总体性能判断；附录 Figure H.8 和 Table 6 才展开反事实图像和诊断量。【PDF p. 7–9；p. 28–30】

## 最终判断

1. **单一主线**：以 SAM 固定「哪些路径应消除」的因果准则，再用 conditional distance correlation 将该准则变成可训练的 output-level regularizer，并以 `sDISCO` 的精确因子化消除深度学习 batch 内存瓶颈。
2. **正文保留的决策内容**：三类偏差图、条件独立/损失、`DISCO_m` 与 `sDISCO` 的关键公式、六数据集主表、受控 path analysis、限制与伦理边界。
3. **附录迁移及代价**：证明、旧实现纠错、数据生成、参数网格、baseline adaptation、补充 counterfactual 结果与 runtime 均在附录；正文可理解方法与主结论，复现和保证审查必须进入附录。
4. **最有效的模式**：将因果图、可观察 criterion、可微 estimator 和可控反事实诊断串成同一链，再以异质数据集主表检验任务表现。
5. **最大读者成本/未闭合处**：主文的六数据集比较缺失 run/seed、训练预算和主实验硬件；基线 adaptations 与参数搜索细节在附录；有限样本 regularization 到 causal stability 的端到端保证未与 Theorem 2.3 同层级建立；Waterbirds 的最佳值属于 CIRCE。
6. **可迁移规则**：因果假设进入学习目标时，应将「图假设 → 观察准则 → 可计算惩罚 → 可控机制检验 → 任务级主表」逐段对齐，并在主文显示每段的边界。
7. **规则边界**：该链依赖可观察的 bias、overlap、SAM 结构与适当的 conditional-distance 估计；它不能单独处理未知混杂、零 overlap、标签语义失真或无监督 deployment。
