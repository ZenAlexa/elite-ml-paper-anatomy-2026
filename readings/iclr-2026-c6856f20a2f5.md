## 1. 一句话主线

作者将黑盒 LLM 指纹的触发条件从少量固定 query-key 对扩展为语义域，并将键替换为分散在生成 token 中、可累积的 Red-Green watermark 统计信号。训练时只在目标域蒸馏水印，同时保持域外分布；检测时拼接目标域查询回复并做单侧 Z-test。该设计把对输入扰动、模型修改和输出改写的脆弱性转化为可用查询数补偿的检测功效问题（pp. 3–5, Secs. 3–4）。

## 5. 方法、推导与理论链

### 机制分解

1. **目标与输入**：模型 owner 从开权重 `θ`、私钥 `ξ`、目标域数据 `D_target` 和域外 regularization 数据 `D_reg` 出发；主实验的目标域是 French（pp. 4–5, Sec. 4.1）。
2. **条件水印学习**：冻结复制教师 `θ₀`。在 `D_target` 上，将学生 next-token 分布拟合为在教师 logits 上施加 Red-Green watermark 后的分布（Eq. 1）；在 `D_reg` 上，以正向分布偏离 regularizer 保持学生与教师一致（Eq. 2）。
3. **更新**：Algorithm 1 每步采样一条 target 和一条 regularization 样本，叠加两项梯度，以 `λ` 平衡二者，返回 `θ^(T+1)`（p. 4）。
4. **检测**：从域内 `Q` 条查询得到回复 `ω_i`，拼接为 `ω`；按 private key 重新标定 green token，计算 `Z(ω)`，以 `α` 的单侧检验决定指纹（p. 5, Sec. 4.2）。回复长度和查询数增大时，信号可累积。
5. **因果链**：semantic domain 使输入轻微改写仍留在触发集合；统计信号分布于完整回复，输出 token 编辑会削弱而非抹除全部证据；拼接多次回复提升 detector power（pp. 4–5）。

段落动作序列为：`state_problem → contrast_alternative → define_component → instantiate_algorithm → derive → explain_mechanism → connect_to_experiment`。Sec. 3 先建立两个失败机理。

Sec. 4 的组件逐项处理这些机理。域处理 query perturbation／可疑输入，统计 watermark 处理脆弱 key，`L_reg` 处理 utility 与域外泄漏。

## 6. 实验设计

- **研究问题表达**：没有编号 RQ；Sec. 5 用 `effective`（可靠、无异常 false positive、低 utility 损失）、`robust` 与 `stealthy` 三段任务组织（pp. 6–10）。
- **模型与域**：Llama 3.2-1B、Qwen 2.5-3B、Llama 3.1-8B；主 fingerprint 为 French，`Q=1000` 条 French Alpaca prompts，每条回复最多 200 tokens（p. 6）。
- **训练**：`D_target=Lucie`，`D_reg` 为 Alpaca 与 OpenWebText 各半；`k=1`、`δ=4`、`γ=0.25`、2,500 steps、batch 64、Adafactor、250-step warmup、cosine schedule、learning rate `2e-05`（p. 17）。
- **baseline**：IF 使用 8 个随机 query 与同一 key；SF 使用 1,024 个 Dolly-derived query-key 对；两者按 App. A.2 的 SFT 配置适配 instruction-tuning（pp. 6, 17–18）。
- **效果与 utility**：Table 1 实际列出 8 个 benchmark，包括 ARC、MMLU、HellaSwag、TruthfulQA、HumanEval、PubMedQA、GSM8K、FrenchBench；正文先写 `7 popular benchmarks`，构成一处版面内计数矛盾。App. B.1 另用 Qwen 2.5-32B PPL 与 GPT5-MINI-as-a-judge（pp. 6, 20）。
- **聚合／统计**：每种方法和部署设置独立运行 detector 5 次，二值结果均值定义 FSR；主 detector 用 `α=1e-03` 的单侧 Z-test。Fig. 3–9 明示为 5 次独立运行的均值；图中没有 error bars，正文没有 seed 值、显著性检验或多重比较方案（pp. 5–6, 21–27；后半句为 `layout_observation`）。
- **攻击与控制**：prominent 部署覆盖 temperature、system prompts、generation watermark、Float8／Int4、Wanda／SparseGPT、Alpaca／Dolly／OpenMathInstruct 的 LoRA 或 full finetuning、输入／输出 paraphrase 与 translation；targeted 集合用 WildChatFr、反水印 paraphraser、English prefilling 和 English system prompt（pp. 7–9, 18–19）。
- **stealth 设计**：GPT5-MINI judge 在非指纹化 Alpaca 输入／base Llama 回复与三种 fingerprint query／reply 之间做二元 suspicious 分类；Appendix 给出 judge prompt（pp. 9, 19）。
- **复现粒度**：关键算法在主文，训练／攻击／prompt 细节在 App. A，硬件与成本在 App. F.2。代码随 submission 提供的说法出现在 p. 10；PDF 未给 repository URL、随机 seed 或权重 artifact 标识。

实验顺序与引言三项贡献大体一一对应：Table 1 回应可用性，Tables 2–3 回应 robustness，Fig. 2 回应 stealth；附录用 query count、域、`δ`、regularizer 和 full-watermark 对照检查机制。

## 8. 消融、负面证据和限制

### 消融的识别目标

- **组件删除**：`L_reg` 的有无（Table 8，p. 26）识别 utility preservation 与 stealth 的作用；FSR 不变，AVG 下降。
- **查询预算**：`|Q|`（Fig. 6，p. 24）检验统计信号的累积机制；三种扰动下 100 条即跨线。
- **域异质性**：French、Math、Medicine（Table 7／Fig. 7，p. 25）检验不依赖单一语言域，并指出 entropy 决定增长速度。
- **超参数敏感性**：`δ=.5–4`（Fig. 8，p. 26）显式展示 detectability 与 PPL 的交换。
- **机制替代**：条件 watermark 与 full watermark（Fig. 4，p. 22）检验条件化是否贡献 finetuning robustness。
- **泄漏边界**：Fig. 9（p. 27）检查非目标域是否带可检测信号。
- **能力边界的扩展实验**：multiple keys、opening/closing tokens、harmful content（Figs. 10–12，pp. 29–32）显示方法的可塑性，同时暴露 key mixing 与 harmful-domain 的有限 TPR。

## 11. 用词、修辞与最终判断

非 references 文本的简单 `we + verb` 清点为：`we show` 31 次、`we find` 17 次、`we propose` 6 次、`we observe` 3 次、`we demonstrate` 0 次。`show` 在主结果与附录图解释中承担证据指向；`find` 多用于从表／图到解释的经验判断；`propose` 集中在引言、Sec. 3 与 token extension。高频领域词由 `fingerprint`、`watermark`、`semantic domain`、`query`、`detection`、`robust`、`stealth` 驱动，属于对象与机制词，未见大段通用模板替代论证。限定主要通过 `tested`、`common`、`likely`、`may`、`we believe`、`in practice` 出现；标题级和主表文字的强断言多于限定句，强断言的有效范围通常由所列攻击、模型与 `Q=1000` 固定。

- **正文保留的决策关键内容**：两个损失、detector、主设置、主 benchmark／robustness／stealth 结果，以及两个关键 limitations。
- **最有效的写作模式**：Sec. 3 先把旧范式拆为 query 与 key 两条失败路径，再以「域＋统计信号」逐项替换；Table 2 与 Table 3 用同一 FSR 网格将所有部署条件压缩为可比较证据；Fig. 3 将机制性的 query accumulation 可视化。
- **最大读者成本／未闭合处**：主文的「all deployment scenarios」在资料内闭合到三个模型、固定查询预算与列举攻击；正式 theorem 的独立性前提和实务 stealth 的 domain secrecy 条件不在同一证据层。Table 4 的域内质量代价与 Table 9 的训练成本都被移至 appendix。App. C.3 还存在 `δ` 上限的文字／图例不一致；Sec. 5.1 的「7 popular benchmarks」与其随后列出的 8 个 benchmark 也不一致（p. 6）。
- **可迁移规则**：若鲁棒性来自可累积的统计证据，正文应明确展示「单次信号被削弱 → 多次观测恢复 detector power」的机制图，并把主攻击矩阵与该机制绑定。
- **适用边界**：规则依赖可定义的、未被攻击者完全阻塞的触发域，以及有可校准 null distribution 的统计 detector；不适用于只能依靠少量 exact-match key 或无法拼接多次输出的设置。
