## E. 方法与理论

### E.1 形式化对象与组件

- §3 Problem Formulation（p. 3）把输入写作 `X ∈ R^{T×C}`，其中 `T` 为 timestamps、`C` 为 channels；目标是预测 `Ŷ ∈ R^K`，`K` 为类别数（`explicit`，p. 3，§3， “Consider an input MedTS sample”）。
- Subject-Independent protocol 将 subject 及其全部 samples 排他地分配到 train/validation/test（`explicit`，p. 3，§3；p. 6，§5.1）。
- §4.1 的 attention 输入 `O ∈ R^{S×D}`；`S` 为 token 数、`D` 为 embedding/hidden dimension（`explicit`，p. 4，§4.1）。
- CoTAR 的 core dimension 为 `D_c`；p. 19 明确设置 `D_c = 1/4 D`，统一 batch size `B=128`（`explicit`，p. 19，Appendix C.2）。
- Temporal tokenization 的 patch 长度为 `L`，`P=⌈T/L⌉`；Channel tokenization 保留每个 channel 的完整时间序列（`explicit`，p. 5，§4.2）。
- `M`、`N` 分别为 Temporal/Channel encoder 数量；`M=0` 或 `N=0` 时移除相应 branch（`explicit`，p. 5–6，§4.2）。

### F.3 划分、控制与复现粒度

- **划分**：Subject-Independent；subject 与全部关联样本只进入 train、validation 或 test 之一（p. 3，§3；p. 6，§5.1）。ADFTD/PTB/PTB-XL 采用 60%/20%/20% subject split；APAVA、TDBrain 给出具体 subject ID 集合（p. 16–17，Appendix B）。
- **基线**：包含 10 个 Transformer-based 方法，即 Autoformer、FEDformer、Informer、iTransformer、MTST、Nonformer、PatchTST、Reformer、vanilla Transformer、Medformer（p. 6）。
- **指标**：Accuracy；macro-averaged Precision、Recall、F1；macro-averaged AUROC、AUPRC（p. 6）。
- **随机性**：seeds 42–46，共 5 个；报告 mean±standard deviation（p. 6）。
- **硬件**：NVIDIA RTX 4090（p. 6）。
- **选择规则**：validation set 上 F1 最优的 checkpoint，用于 test；early stopping 为 validation F1 连续 10 epochs 无改善（Appendix C.1，p. 18）。
- **训练预算**：baseline 100 epochs；Adam；`lr=1e-4`；batch size 按 APAVA/TDBrain/ADFTD/PTB/PTB-XL 为 `{32,32,128,128,128}`；encoder 6 layers，`D=128`，FFN hidden `256`（p. 18，Appendix C.1）。TeCh 使用统一 `B=128`、`D_c=1/4D`，各数据集的 `D,L,M,N,lr` 在 Table 6（p. 19）。
- **控制变量**：固定 train/validation/test split，改变 seed 计算均值与标准差（p. 18）。
- **缺失项**：没有报告统计显著性检验、多重比较校正、置信区间、功耗/吞吐定义、t-SNE 的 perplexity/seed、资源测量重复次数或数据增强消融（p. 6、8、10、16、19；`not_present`）。

## I. 结论、limitations 与闭环

### I.1 结论逐段编码

Conclusion 只有一个段落（p. 10），包含：

- `重述问题`：centralized MedTS 与 decentralized attention 的 mismatch；
- `重述方法`：CoTAR 用 core token 代理 inter-token relationships；
- `回收理论/复杂度`：quadratic→linear；
- `回收结果`：3 EEG+2 ECG，较 Medformer +4.11%；
- `回收影响`：domain-specific inductive bias 可带来更有效、可扩展的 MedTS 方案。

结论没有新数字（+4.11% 已在 p. 7 预先出现），没有独立 limitations 或 future-work 清单。关于 fMRI 的 broad claim 出现在前一节 Figure 5 解释；Conclusion 未承担该主张（p. 10，`explicit`）。

## L. 最终判断

1. **单一主线**：作者把 MedTS 的跨 channel interaction 视为来自中心生理源的协调过程，认为标准 Transformer attention 的去中心化 pairwise graph 会稀释这种统一结构；CoTAR 以输入条件的 core token 完成聚合—再分配，再由 TeCh 的 Temporal/Channel/Dual tokenization 选择应建模的依赖。这个主线由 Figure 1/2、Eq. (2)–(5)、Table 4/5 和 Figure 4 共同承载（p. 2、4–9）。
2. **正文保留的决策关键内容**：Subject-Independent 设定、CoTAR 的完整核心公式、双 tokenization 与 branch 融合、五个 MedTS 和两个 HAR 的主表、资源/噪声图、两组组件消融。读者可以理解模型为何不同以及主要结果如何比较。
3. **移入附录的细节与自足性**：数据预处理、baseline 训练、TeCh 超参数、伪代码、全部数据集消融、五折 CV、SCI/DIC 和 MedGNN 都在附录。迁移保持正文紧凑，但使数据划分核对、资源复现、中心性主张和外部比较不能仅靠正文完成。
4. **最有效的写作/图/表模式**：Figure 2 把去中心化 attention 与中心化 CoTAR 画成同一抽象层级；Eq. (2) 紧随图给出聚合、Repeat、Concat、融合；Table 4/5 使用小而直接的组件对照；Figure 4 将 accuracy、memory、inference time 与 noise robustness 放在同一节，形成机制、资源与鲁棒性链条。
5. **最明显的叙事规避与读者成本**：主文用 `best across all datasets` 类概括掩盖 ADFTD Avg 低于 Medformer；Table 12 显示相对 MedGNN 在 ADFTD/PTB-XL 也略输。+4.11%、+4.28%、平均 std、APAVA “11%/13%” 的聚合分母未充分展开；t-SNE 中心位置被解释为生理状态，却没有独立语义验证。读者还需处理 `FLAPP/FLAAP`、TDBrain subjects 72 vs Appendix 50 的待核对差异。
6. **可迁移规则**：当论文用领域结构（如“中心化生理源”）解释架构收益时，应在主结果之前预声明一个可测的结构诊断和一个机制区分实验；将 t-SNE 或类比图定位为可视化，不把它们写成生理语义证明。
7. **适用边界**：该规则适用于领域归纳偏置、结构—性能因果主张和跨域外推；若论文只声称工程效率而不解释领域机制，则可用直接资源测量和预设负载覆盖，不必引入 SCI/DIC。这里的 SCI/DIC 仍是事后诊断，不能替代干预式识别。
