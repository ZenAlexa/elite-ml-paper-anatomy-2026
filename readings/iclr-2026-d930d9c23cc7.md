## 4. 方法与理论

### 4.1 Aspect collection 与 taxonomy

方法先把问题写成资源建设问题，收集四任务 28 sub-tasks，覆盖六种输入/输出模态组合。ITIG 的 aspects 不足，因此从 NLG 等相似 sub-task 做 cross-task transfer，例如把 story generation 的 engagingness 迁移到 visual story completion。随后以 `overall` 为根分成两棵子树。

- **UAs**：任务无关、主要评价 output quality，并按文本、图像、ITI 输出模态分支。
- **TAs**：依赖具体任务，主要评价 task completion，例如 story generation 的 engagingness 或 mathematical reasoning 的 accuracy。
- **已有层级**：Readability、Bias、Instruction Following、Hallucination、Alignment、Complement、Image Coherence、Image Quality、Semantic Consistency、Toxicity 等树从文献采用。
- **未匹配 aspects**：先做 bidirectional name/definition matching，递归插入最具体节点；找不到匹配则建立新的 root，声称以减少主观误导。

Figure 1 把这个 taxonomy 接到运行时 pipeline。输入任务属性和 output modality 决定候选 aspect，UFEval 再输出 criterion-specific feedback 与两个 1–5 分数。图中示例以“cat image next to the orange dog picture”与实际图像不一致，触发 Context Inconsistency；文本输出则另选 Text Branch 的 Grammatically 相关 criterion。

### 4.2 FRABench 构造、标签和 split

FRABench 采用 pairwise comparison。作者援引 pointwise scoring 更容易受 contextual bias 影响，且 pairwise 形式可用于 reward-model training。29.3K pairs 来自 public datasets，30.1K 由 MLLMs 生成。每个 pair 平均分配 8 UAs 和 3 TAs，得到 325K labels。

标签有两路。ImageRewardDB 提供三-aspect human scores，GPT-4o 补充 feedback；其余 pair/aspect 由 GPT-4o 生成。作者观察到 GPT-4o 对 UA 会把 correctness 纳入判断，因此 UA 模板只给 response、不传 query。为减轻 position bias，先检查多数类，再对 surplus 样本的一半交换 response position 并重新标注。

训练集与 FRA-ID 覆盖 18 个随机 sub-tasks、22 UAs 和 35 TAs；FRA-OOD 覆盖 10 个 unseen sub-tasks、28 seen UAs、27 unseen TAs。样本规模是 255.4K/45.2K/24.4K。另从 FRA-ID/OOD 抽取并由三名人类标注 FRA-ID-H 6.9K 与 FRA-OOD-H 6.0K。UFEval-7B 以 Qwen2-VL-7B-Instruct 为 backbone 做 SFT；64 A100、batch 128、3 epochs、1e-5 learning rate、1% warmup、cosine decay 和 judgment/justification 双 cross-entropy 见 Appendix C.1（p.20）。

### 4.3 理论对象清单

正文没有 theorem、lemma、proposition、corollary、proof 或复杂度分析。论文的“理论”是两个经验假设，criteria 的互联性可支持 aspect generalization，联合学习可带来 synergy。唯一正式显示公式在 Appendix F p.58，Equation (1) 是语言模型 DPO objective，Equation (2) 是 diffusion DPO noise-prediction objective；它们服务于下游 preference alignment，并不构成 UFEval 泛化保证。

## 5. 实验设计

### 5.1 研究问题与控制

实验顺序与引言贡献基本对应。

1. **OOD 泛化**：FRA-OOD/FRA-OOD-H 分开测 task generalization 与 aspect generalization；Figure 3 的黑扇区表示 unseen TAs，其余扇区表示 unseen tasks 上的 seen UAs。
2. **MLLM-as-a-Judge**：NLG 用 MT-Bench、SummEval、MANS；IU 用 WildVision、MLLM-as-a-Judge、VLRewardBench；IG 用 GenAI-Bench、Winoground、Pick-a-Pic。
3. **联合学习**：FRA-ID 做 multi-aspect，外部 judge benchmarks 做 multi-task synergy。
4. **Preference alignment**：UFEval 生成 IU/IG preference pairs，再训练 LLaVA-Next-7B 或 SDXL-Turbo。

作者声明训练集与 public benchmark 无 overlapping samples。未给出随机 seed、独立 run 数、完整的 matching/removal log、预注册失败阈值或不确定性估计。Baselines 用同一 prompts 的 prompting models 与若干 fine-tuned evaluators；Auto-J 不能作 specific-aspect judge，Prometheus 2 需要 reference answer，ImageReward/VisionReward 采用不同 evaluation paradigm，因此它们只进入合适的外部 benchmark 对照。

### 5.2 任务、aspect 与标注构造

Table 12 显示 task-specific 与 universal aspects 的分工。例如 NLG 的 Summarization 使用 Coverage/Length Constraint/Layout/Conciseness；IU 的 Robustness-oriented Instructions 使用 Instruction Inconsistency/Context Inconsistency；IG 的 Text-to-Image 使用 Count/Object/Attribute/Spatial/Action/Color/Shape/Texture Alignment 等；ITIG 的 Visual Story Completion 使用 Creativity/Engagingness/Completeness 与多种 image-sequence consistency。FRAUAs-OOD 只保留 UAs；FRA-OOD 增加 Academic VQA、Medical VQA、Embodied Decision-making、GenAI-Bench、ActivityNet、Storytelling 等新 sub-tasks。

人类 UI 为每个 criterion 给 1–5 Likert score，TA 不适用时给 -1。Appendix E 报告 task-grouped Cohen kappa 与 aspect-level Krippendorff alpha。Appendix G 的 templates 强调只依据 criterion，不做 overall assessment，并对 text/image/ITI 分别安排输入顺序。

### 5.3 统计口径

- FRA-ID/OOD：平均 pairwise accuracy，ties 纳入。
- 外部 judge：`tau` 保留 ties，`diff` 排除 ties；表注能独立解释两种分母。
- aspect-level：同一 task 中跨 sub-task 聚合同名 aspect。
- position consistency：交换 response 顺序后检查输出是否一致。
- human reliability：Cohen kappa 按 annotator-pair/task，Krippendorff alpha 按 aspect。
- taxonomy distinctness：within-task Kendall tau；排除 Chart Reasoning（只有两个 aspects）和 FRA-ID text-to-image（每个 sample 只有单 aspect）。

论文没有报告 bootstrap、Bayesian analysis、回归、p 值、多重比较、置信区间或 seed-level error bars。数值大多是单次聚合 accuracy，因而显著性、实质提升和机制证据没有被分开估计。

## 6. 结果、图表与主要解释

### 6.1 OOD 泛化

Table 2 把 task generalization 与 aspect generalization 并列。作者报告 FRA-OOD GPT-4o aggregate 85%、FRA-OOD-H human aggregate 83%；aspect generalization aggregate 为 86.2%/83.2%。UFEval 的 task-generalization per-task values 是 NLG/IU/IG/ITIG 的 81.7/90.4/69.0/83.1（GPT-4o）和 79.0/80.9/62.1/90.6（human）。Aspect rows 是 83.0/86.3/62.9/89.3 和 78.3/80.9/66.1/90.6。

主张是 unseen aspects 不需要训练时直接暴露，也可以借助相近 meaning/standards 迁移。这里的证据对象是 GPT-4o 或人类标注的 pairwise preference；它证明的是与该 label source 的一致性，不等价于开放世界 capability guarantee。

Figure 4 将 aspect 分成 strong、universally poor、weak。IG Harmfulness 的失败被解释为把 shadowy/gloomy imagery 过度关联到 psychological discomfort；Fidelity 对所有 evaluator 都弱，作者归因于当前模型难以识别细粒度 object features，例如 well-formed human facial features。

### 6.2 外部 MLLM-as-a-Judge

- **NLG（Table 3）**：UFEval 的 SummEval average 为 69.0 tau/76.9 diff，MANS diff 为 69.3，MT-Bench 为 74.9 tau/88.3 diff。Claude-3.5 在若干 SummEval/MT-Bench 列占优，UFEval 在 MANS diff 最高。
- **IU（Table 4）**：UFEval Ave 58.4 diff，高于 LLaVA-Critic 的 47.7；WildVision 为 53.9/68.6 tau/diff，VLRewardBench 三列为 46.4、57.7、71.1。作者强调跨 task joint learning 带来相对 domain-specific LLaVA-Critic 的优势，但 GPT-4o/Claude-3.5 在不少列更高。
- **IG（Table 5）**：UFEval 的 GenAI-Bench/Winoground/Pick-a-Pic diff 为 65.5/65.7/57.3；与 VisionReward 的差距在前两项被写成 0.9 和 0.3 个百分点。IG 仍是方法较弱的区段。

外部表格的有用模式是同时报告 ties-included 与 ties-excluded accuracy，读者可以看到分母改变后的稳定性。代价是 headline average 仍缺少 sample count、run variance 和显著性。

### 6.3 Multi-aspect、multi-task 与 DPO

Table 4/5 的训练行从单任务 `w/ IU`、`w/ IG` 增加到跨 task combinations；Figure 5 用 IU、IG、ITIG 三个 radar 显示多数 aspect 的外溢提升。Appendix Tables 50–52 把这种提升拆到每个 aspect。IG 的 Fidelity 始终约 44.0，说明联合 aspect knowledge 没有修复所有视觉判断。

DPO 结果是明确的 downstream utility test。IU 中 LLaVA-Next-7B 的 MMHal/LLaVABench.Wild/LLaVABench 从 2.05/52.9/28.3 升至 2.41/61.4/32.3；IG 中 SDXL-Turbo 的 HPSv2/ImageReward/VisionReward 从 28.1/0.80/3.00 升至 29.9/0.90/3.27。它们验证 UFEval 生成的 pairwise preference 可作为训练数据，但没有人工复核这些 preference 的独立标签。

## 8. 结论、limitations 与闭环

结论 p.10 按 **重述方法 → 回收联合学习/泛化 → 回收 DPO → 价值判断 → limitation → future work** 推进。它没有新数字。明确边界是 IG 相对其他三任务性能较弱，解释为 LMM 缺乏 active visual semantic understanding；未来工作是加入 video understanding/generation 及其 aspects。

|---|---|---|---|
|FRABench 资源|29.3K public + 30.1K generated，112 aspects，325K labels|Figure 2、Tables 8/12|closed|
|四任务统一 evaluator|Qwen2-VL SFT + UA/TA prompts|Table 1、Tables 2–5|closed|

最重要的未闭合部分是 **“synergy” 的因果含义与泛化到任意新标准的范围**。当前结果可支持“在固定 split、label source 与 prompt 下，UFEval 与 GPT-4o/human judgments 的平均一致性提升”，尚不足以支持独立于数据量、模型容量、标注器或 task mixture 的 mechanism guarantee。

## 12. 最终判断

1. **单一主线**：taxonomy → pairwise FRABench → UFEval → held-out task/aspect tests → joint learning → DPO；每步都围绕“标准能否跨任务迁移”服务。
2. **正文决策内容**：问题、资源规模、UA/TA 构念、split、训练入口、OOD/external judge 主结果、joint-learning 方向、DPO 结果和 IG limitation 都保留在 10 页正文。
3. **附录迁移与自足性**：附录承担可复现的 criterion 定义、数据细节、prompt、per-aspect heterogeneity、IAA、correlation、公式和 qualitative error analysis；正文可读但复现和审计不自足。
4. **最有效模式**：固定的 radar/bar/table visual language 把 split、task/aspect distinction 和 aggregate/per-aspect 对齐起来；Appendix D 的 per-aspect rows 让正文的泛化叙事有可追查底稿。
5. **最大读者成本与叙事缺口**：Table 2 的平均值先于分母、标签来源和 variance；“synergy” 与“generalization”仍混合了更多数据、task mixture、GPT-4o label 和模型 capacity。Appendix 规模约为正文 5 倍，读者需要跨 40 页追溯关键边界。
6. **可迁移规则**：每个迁移/协同 claim 必须绑定 held-out unit、标签来源、分母、最弱单元和独立对照，避免 aggregate accuracy 单独承担 mechanism claim。
7. **适用边界**：该规则适合 benchmark/evaluator 论文；若主张开放世界新构念或任意新任务，应增加独立任务、标注协议和外部 judge，不能把低 ROUGE-L 或一次 GPT-4o 对齐当作充分证明。
