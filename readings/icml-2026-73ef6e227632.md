## 5. 方法与理论：从形式对象到可运行管线

### 5.1 理论对象与主张

- **RSR 形式化**：Definition 4.1 定义 `f:X→Y`、query functions `q_i:X×R→X` 和 recovery function `p:X×R×Y^k→Y`；每个 query 的边缘分布必须均匀，但多个 query 可以相关。perfect RSR 要求对所有随机性恢复恒成立；近似 RSR 用 `ρ` 管控随机性失败、用 `ξ` 管控输入例外比例。【p.3，§4 Definition 4.1，explicit，anchor= “must only satisfy marginal uniformity”】【p.3，§4 Eq. (2)，explicit，anchor= “holds with probability 1”】
- **采样访问**：Definition 4.3 列出 independent random samples、correlated random samples、oracle queries；相关样本的每一 `x_j` 边缘均匀，样本间允许相关。这是方法从常规 i.i.d. 学习转到 RSR discovery 的理论接口。【p.4，§4 Definition 4.3，explicit，anchor= “different xj’s may be correlated”】
- **学习定义**：Definition 4.5 中 learner 以带标签样本输出 `q_1,…,q_k,p`，并以 `ρ,ξ,δ` 定义近似 RSR 与成功概率。它明确采用 realizability assumption，agnostic setting 留给 future work。【p.4，§4 Definition 4.5，explicit，anchor= “outputs query functions q1, . . . , qk”】【p.4，footnote 4，explicit，anchor= “leave the agnostic setting”】
- **理论结果的角色**：Fact 4.2 给出有限域多项式的可表达性例；Appendix Claim A.1 给 PAC-to-RSR 的样本复杂度上界，Claim A.2 给 0-sample RSR-learning 与至少 `n` 次 PAC oracle queries 的分离。它们解释学习任务的定义和与 PAC 的关系，而非给 Bitween 的经验覆盖率提供一个 finite-sample performance guarantee。【p.4，§4 Fact 4.2，explicit，anchor= “degree d < ℓ − 1”】【p.14，Appendix A Claim A.1，explicit，anchor= “mRSR(ρ, ξ, δ) ≤ mPAC”】【p.14，Appendix A Claim A.2，explicit，anchor= “efficiently RSR-learnable from 0 samples”】【p.5，§4，explicit，anchor= “open question to obtain an analogous Fundamental Theorem”】【p.5，§4–5，interpretation，anchor= “open question”】

### 5.2 V-B ITWEEN 的最小逻辑单元

1. **设定输入**：输入是被视为未知 `f` 的 alleged implementation `Π`、domain `X`、query class `Q`、recovery degree bound `d` 和 sample complexity `m`。这对应前述相关采样设定。【p.5，§5 Algorithm Overview，explicit，anchor= “alleged implementation of some unknown function f”】
2. **构造候选空间**：为每个 `q∈Q` 建变量 `v_q=Π(q(x,r))`，列举总次数不超过 `d` 的 monomials。该步骤直接解决固定 query 下的可搜索恢复表达式问题。【p.5，Algorithm 1 lines 4–6，explicit，anchor= “all monomials of degree at most d”】
3. **相关抽样与回归**：对随机 `(x_i,r_i)` 查询 `Π(x_i)` 和每个 `Π(q(x_i,r_i))`，以稀疏回归拟合 monomial 系数；文中给出 Lasso/Ridge 形式的 `L_q(C)` 和 iterative elimination。【p.5，Algorithm 1 lines 7–11，explicit，anchor= “sample input xi and randomness ri”】【p.5，§5 Regression Formulation，explicit，anchor= “Sparsification proceeds iteratively”】
4. **可读化和输出**：拟合浮点系数经 rational approximation，非零 monomial 决定保留 query，最后输出 `(q̂_1,…,q̂_k,p̂)` 或 `empty_tuple`。这使候选关系可被后续符号验证。【p.5，Algorithm 1 lines 12–22，explicit，anchor= “Convert to rationals”】【p.5，Algorithm 1，explicit，anchor= “return the randomized self-reduction”】
5. **技术闭环**：appendix 的 Figure 5 画出十步流程，并补充可选的结构相似等价类、Gröbner basis reduction、bounded model checking/property-based testing；主文限制部分说明本评测没有做 Gröbner reduction，原因是作者给出的 NP-complete 代价。【p.17，Appendix D Figure 5，explicit，anchor= “Formal Verification or Property-based Testing”】【p.17，Appendix D，explicit，anchor= “Apply Gröbner Basis Reduction”】【p.9，Limitations，explicit，anchor= “refrained from applying it”】
