## 5. 方法与理论

### 5.1 最小逻辑单元

1. **setup_notation / analogy**：以 natural-language subword tokenization 对照化学 building blocks；形式化词汇为 synthesis-friendly vocabulary `V`。[p.4–5, §2–§2.1, “we propose mCLM ... based on synthesis-friendly building blocks instead of atoms” (`explicit`)]
2. **define_component**：把能承载 function、能由自动化模块合成的 graph substructure 作为 token；三类可断键为 amide、Suzuki–Miyaura、Buchwald–Hartwig coupling。[p.5, §2.1, “These three bonds are amide coupling, Suzuki-Miyaura coupling, and Buchwald-Hartwig coupling” (`explicit`)]
3. **explain_mechanism**：synthesis-guaranteed tokenizer 先按反应/官能团冲突约束断键；coverage check 若不能无损重构，则交给 rule-based tokenizer。rule-based 只保留相同机器友好断键和最小 block 尺寸，文中限定其仅用于 training。[p.5–6, §2.1, “we fall back on a rule-based tokenizer to ensure coverage” (`explicit`)]
4. **connect_to_prediction**：tokenization 把「可制造性」置于生成前，支持 exact reconstruction；新反应经验证后可加入断键规则而无需改架构。[p.5–6, §2.1, “their corresponding disconnection rules can be readily incorporated” (`explicit`)]
5. **instantiate_algorithm / data scale**：约 800 万分子中约 680 万可由 pipeline tokenized；词汇为 80 万 unique blocks，其中 20 万 synthesis-guaranteed。[p.6, §2.1, “800,000 unique building blocks with 200,000 synthesis-guaranteed” (`explicit`)]
6. **define_component / architecture**：每个 block 由 GNN 编码，经 adaptor 投影，与 molecule entity name 位置的 natural-language embedding 拼接；decoder-only Transformer 以先前 token 预测下一个 token，形成 code-switched 序列。[p.6, §2.2, “These representations are then concatenated with natural language embeddings” (`explicit`)]
7. **derive / objective**：以 Qwen2.5 为 backbone，联合 natural-language 与 molecular-token vocabulary 的 categorical cross-entropy；自然词 logit 是 `c_i^T e_v`，molecular block logit 是 `c_i^T f_ψ(GNN_ϕ(v))`。[p.6, §2.2, “we adopt a unified categorical cross-entropy (CCE) loss” (`explicit`)]
8. **connect_to_experiment**：实际预训练采样约 100 万条、1000 个最频繁 blocks；数据集超过 3,600 万条 molecular instructions、1000 tasks、800 万 molecules；作者把 unseen blocks 的 GNN 表征作为 inference 时无需 retraining 的扩展点。[p.6, §2.2, “During inference, new blocks can be directly incorporated without retraining” (`explicit`)]
9. **explain_mechanism / define_component**：critical chemical reasoning 每轮枚举仍待改善的 function，选择最需要改善者，替换/增加/删除约一个 block，并重新评估；循环至目标耗尽或迭代上限。[p.7, §2.3, “mCLM proposes a modification of the molecule targeting this property” (`explicit`)]

方法动作转移序列为：`setup_notation → state_problem → define_component → explain_mechanism → connect_to_prediction → instantiate_algorithm → connect_to_experiment → derive → give_intuition → connect_to_experiment`。方法图（Figure 2/3）对数据流和 tokenizer 分支覆盖较好；正文没有逐行解释 Appendix Algorithm 1，也没有给出推理上限的数值。

### 5.2 形式化对象、假设与理论边界

- 输入为 natural-language prompt、已经 tokenized 的 molecule/block 序列，以及需要改善的 property/function；输出为下一个 natural-language 或 molecular block token，或经迭代得到的 refined molecule。[p.6–7, §2.2–§2.3, “predicts the next token based on previous tokens” (`explicit`)]
- 状态包含当前 molecule `M`、block connection placeholders（如 `[1*]`、`[2*]`、`[3*]`）、contextual representation `c_i` 和 GNN/adaptor 参数；目标是 property-directed generation/optimization。[p.6, §2.2, “c_i is produced by the Transformer given the previous tokens” (`explicit`)；p.27, Appendix F.1, “placeholder atoms ... encode connection points” (`explicit`)]
- 假设包括预定义 automated reactions 可用且选择性足够；blocks 通过 placeholders 可无损重构；oracle ADMET 预测足够可靠用于数字评估；A.1 进一步假设所有 mCLM starting blocks 可获得。[p.5–6, §2.1, “guaranteed to work under defined synthesis protocols” (`explicit`)；p.20, A.1, “we assume that all the building blocks required ... are available” (`explicit`)]
- **公式总数**：1 个 displayed equation（p.6 的联合 CCE/logit piecewise 公式），0 个编号公式，0 个 theorem/lemma/proposition/corollary，0 个 proof。`2n − 3` synthetic steps 与 `Makeability = Valid × Synth.` 是正文/附录中的行内关系，不是另一个 displayed equation。[p.6, §2.2；p.20–21, A.1]
- 理论角色：联合损失属于核心因果链；placeholder/反应规则提供可逆性与条件式 synthesis guarantee；`2n − 3` 是合成步骤的 accounting，而非复杂度定理。没有渐近复杂度、误差界、最优性保证或概率校准。[p.20, A.1, “Scaling this formula to n building blocks gives a requirement of 2n − 3 reactions” (`explicit`)]

### 5.3 Algorithm 1 的粒度

Appendix Algorithm 1（p.21）输入 `Initial molecule M0`，输出 `Refined molecule M*`；初始化 `M ← M0`，循环枚举 metabolism、DILI、BBBP 等 function，若无清晰改善目标则返回，否则选最需改善属性、生成 `M′`（replace/add/remove blocks）、评估后继续。循环层级为单层 `while True`，关键不变量是当前 `M` 经评估后再进入下一轮；算法没有给出 numeric iteration cap、候选数量、评分阈值或并行策略。[p.21, Appendix B, “Select property which requires most improvement” (`explicit`)]

### 7.2 统计口径

- 主要 property 表是按 FDA-drug 集合的算术平均，方向由 `(↓)` 或 `(↑)` 标记；`Avg. Improv.` 是汇总后的方向化改进量，论文没有给出其逐项归一化公式。[p.7, Table 1；p.21, Table 4]
- `Validity` 是 RDKit syntactic correctness；`Synthesizability` 是 valid molecules 中 Allchemy 找到 retrosynthetic path 的比例；`Makeability` 是二者乘积。Allchemy 采样 200 个/模型且每个 molecule 30 分钟，但正文没有报告每个 property 的 route count 原始分子表。[p.8, §3.2；p.20, A.1]
- Oracle 的 classification threshold 在 validation set 上最大化 F1；模型选择使用 TDC scaffold split。表格给 AUC 和 aggregate scores，但未报告区间、假设检验、多重比较或参与者级数据。[p.25–26, D.2.3]
- Figure 4 是逐步案例轨迹，Figure 5/8–13 是结构/频数或 nearest-neighbor 图；图注提供任务与相似度定义，但不能独立重建所有生成提示、随机样本或 oracle 误差。[p.9, Figure 5；p.28–30, Figures 8–13]
- 论文把 statistical significance 写入摘要的 “significantly improving”，但没有相应检验对象；因此这里按作者用词记录，不将其转译为可复核的 inferential result。[p.1, Abstract；p.7, Table 1]

## 9. 结论、局限与闭环

### 9.1 结论段落编码

- **重述问题/方法**：mCLM 被称为第一个把 natural-language sequences 与 modular chemical language 联合建模的 function- and synthesis-aware model。[p.10, §5, “We have developed a function- and synthesis-aware modular Chemical-Language Model” (`explicit`)]
- **回收保证/结果**：强调按设计只生成可在 robotic small-molecule synthesis platforms 上迭代组装的 blocks，连接 desired functions 与 non-specialist accessibility；没有在结论中新报数字。[p.10, §5, “only generates chemical building blocks that can be iteratively assembled” (`explicit`)]
- **未来工作**：更大 backbone；2D/3D、protein–ligand、cell lines、nucleic-acid、genetic profiles；更长 System 2/counterfactual chains；simulation/reaction knowledge bases；multi-agent human-in-the-loop autonomous lab。[p.10, §5, “We plan to extend chemical reasoning” (`explicit`)]
- **Reproducibility**：逐项指向 §3.1、D.2.3、F、C、D、G、E、§3.2；full data/resources `upon publication`，不是当前 artifact 的已验证可得性。[p.10, Reproducibility Statement, “The full data and resources will be released upon publication” (`explicit`)]

## 12. 最终判断

1. **单一主线**：把小分子的 tokenization 单位从 atom/SMILES 字符提升为带功能语义且遵守 automated block chemistry 的 graph building blocks，再用 GNN–adaptor–Qwen bilingual decoder 与 iterative property editing，把「功能预测」和「可制造性」放入同一生成路径。[p.3–7, §1–§2]
2. **正文保留的决策关键内容**：Figure 1–3 说明表示与 tokenizer 分支；§3.1–§3.3 给六项 ADMET、122-drug/OOD 设计、Table 1–2 数值、Allchemy 口径和两个 fallen-angels 轨迹；这些内容足以让读者判断主张的方向、分母和核心 trade-off。[p.2、p.5、p.7–9]
3. **移入附录的细节及其代价**：oracle ensemble/scaffold split、训练 lr/GPU/epochs、模板与数据计数、placeholder exact reconstruction、额外 baseline 和消融均放入 A–I。迁移保持正文叙事紧凑，却使「oracle 是否可靠」「tokenizer 是否真正可逆」「baseline 是否公平」「OOD 如何构造」不能只读正文判断。[p.20–33]
4. **最有效模式**：Figure 3 将 guarantee 分支与 coverage fallback 画成可检查的 pipeline；Table 1/2 将 property 与 makeability 并置；Figure 4 每一步标出优化目标和数值轨迹；Appendix F 用 imatinib 的 placeholder sequence 做 exact reconstruction。这些对象分别承担机制、决策、案例和可逆性，每个对象都有具体任务。[p.5、p.7–9、p.27]
5. **最大叙事缺口**：摘要/结论把 `guarantee` 和 physical-world link 说得很强，但证据主要是 predefined reaction compatibility、Allchemy route search 和假设 starting blocks available；没有本论文实际 wet-lab synthesis，也没有 property uncertainty 或独立 human/clinical endpoint。另一个读者成本是 Table 2 的 summary 与正文四舍五入口径、TNG348/TNG248 名称错误和简单 FDA 分布的 Allchemy dynamic range 需要读者自己对齐。[p.8、p.20、p.32；见第 13 节]
6. **可迁移规则**：当论文把“功能、生成、制造”作为同一能力时，正文应同时给出表示约束的可逆对象、主要任务的分母与 baseline、独立的失败/消融证据，并把数字评估与 physical validation 分开命名。[p.5–9, §2–§3]
7. **适用边界**：该规则适用于存在明确结构化 action space 和真实执行约束的生成研究；若任务只有离线预测或没有可验证的物理/系统执行环节，不能把“约束 token”自动等同于 end-to-end capability。[p.5–6, §2.1；p.8, §3.2]
