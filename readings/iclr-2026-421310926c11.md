## 引言推进

1. **context → problem（p.1，约 80 词）**，以 kind、loyal、plainspoken、Taoist、utilitarian、deep ecology 等例子扩大对象，再提出主观性使量化陷入困境。“one person’s ‘kind’ may be another person’s ‘fawning’”把测量问题具体化。下一段钩子是寻找允许不同解释仍可聚合的评审者。证据：p.1，§1，“isn’t it impossible to quantify?”。
2. **missing_insight → core_idea（p.1，约 55 词）**，让语言模型彼此评价，使每个模型使用自己的 criteria 解释，再用 EigenTrust 得到共识。当前段回答了“主观是否不可量化”，下一段转入输入接口。证据：p.1，§1，“ask language models to evaluate one another”。
3. **method_preview（p.1，约 65 词）**，列出 population `M`、constitution `C`、scenario set `S`；三个输入分别承担候选/评委、价值准则和情境。下一段转入输出。证据：p.1，§1，三项 bullet list。
4. **method_preview → scope_boundary（p.1，约 45 词）**，定义 `t=t_{M,C,S}` 与 `t_j`，将分数解释为群体对模型在 `C` 上的 average-case alignment。脚注 2 把它与 worst-case alignment 区分。下一段解释 average-case 的加权方式。证据：p.1–2，§1，“average-case alignment”。
5. **scope_boundary（p.2，约 90 词）**，明确对 scenarios、criteria、models 的三重平均，前两者均匀，models 按 `t` 加权。它留下“分数为何循环”的问题，下一段用 trust matrix 和 eigenvector 回答。证据：p.2，§1，“three types of averaging”。
6. **derive → explain_mechanism（p.2，约 120 词）**，先学习 irreducible、row-stochastic `T`，再令 `t_j=Σ_i t_iT_ij`，解释为左特征向量。选择 eigenvector 而非均匀平均的理由是同时给更可信的 judge 更大权重。证据：p.2，§1，式 (1) 与“left eigenvector”。
7. **assumption → scope_boundary（p.2，约 70 词）**，把关键前提写成“alignment 更好的模型也是更好的 alignment judge”，脚注 4 明示该前提取决于 `C`，kindness 可能成立，plainspokenness 未必成立。下一段进入应用清单。证据：p.2，脚注 4，“likely depends on the content of C”。
8. **contribution_list（p.3，约 110 词）**，列出 values-to-leaderboard、character training、comparing dispositions 三个用途。它把可定制 leaderboard、fine-tuning 验证、judge lens/model disposition 可视化分别与前文的 output/latent representation 接上。证据：p.3，§1 三项编号列表。

引言主链为：主观 traits 难量化 → 让模型成为彼此评委 → constitution/scenario/population 输入 → EigenTrust 共识分数 → `t=tT` 的加权理由 → 适用前提与 average-case 边界 → 三项应用。贡献清单复述了摘要中的方法用途，未给数字，也未给独立可证伪阈值；唯一明确的可证伪条件是模型 alignment 与 judge quality 的正相关前提及其对 constitution 的依赖。

## Related Work

相关工作位于独立 §2（PDF p.3–4），约 520 词，占正文约 10%，并通过 Table 1 形成一次显式比较。引用簇可分为五组：

1. **Eigenvector/consensus foundations（p.3）**，PageRank、EigenTrust、Eigenfactor 与 Eigenmorality blog，比较对象是由 incoming links、peer reputation、citations 或社会共识产生的特征。该段承认方法继承关系，同时指出自然语言 critique 到 trust matrix 的额外难点。
2. **LM leaderboard 邻近方法（p.3–4，Table 1）**，LMArena、Prompt-to-Leaderboard、LitmusValues、EigenBench，比较维度是人类偏好、prompt-specific preference、单模型内部 value prioritization 与给定 value system 下的跨模型 alignment。EigenBench 的问题被压缩成“Which models are most aligned to a given value system, C?”。
3. **Elo 风险与 leaderboard 偏差（p.4）**，Boubdir et al. 的 Elo pitfalls 与 Singh et al. 对私有测试/撤榜偏差的批评，承担限制已有 ranking system 的作用。
4. **Utility engineering（p.4）**，把 LMs 视为 expected-utility maximizers并尝试 eliciting utility functions；对比维度是内部 utility reconstruction，而非群体共识 leaderboard。
5. **训练范式与 vibe check（p.4）**，Constitutional AI、character training、deliberative alignment；承认 LM feedback 已替代或补充 human feedback，再把 human researcher 的行为检查作为缺口，定位 EigenBench 为 internalization test。

该节没有按时间线组织，也没有重复完整方法公式；它采用「基础算法承继 → 近邻 leaderboard 表格 → 已知偏差 → value/utility 方法 → 训练场景缺口」的推进。后续正文继续引用 EigenTrust、BTD、Maiya et al.、Chiu et al. 和 GPQA，引用承担方法来源与验证基线的论证作用，而不只是背景罗列。证据：p.3–4，§2 与 Table 1。

## 方法与理论

### 最小逻辑单元

1. **setup_notation（p.4）**，输入 population `M={(m,p)}`，每个 model 是语言模型与 persona 的二元组；`N≥2`，每个成员兼任 judge/evaluee。输出对象是 `t`。
2. **define_component（p.4–5）**，constitution `C={C_i}` 是给 judge 的 criteria；示例为 Universal Kindness、Conservatism、Deep Ecology；complex trait 的多个细微解释被视为更适合共识。
3. **define_component（p.5）**，scenario set `S` 主要来自 Kaggle r/AskReddit，也使用 OASST 和 AIRiskDilemmas；意图是现实问题、对话和 moral dilemmas，而非人造测试题。
4. **instantiate_algorithm（p.5）**，抽取 scenario、evaluee pair `(j,k)` 和 judge `i`；先生成 `R_j,R_k`，再生成两份 reflection，最后让 judge 输出 tie/win trit `r_{ijkℓ}∈{0,1,2}`。
5. **explain_mechanism（p.5）**，每次 comparison 可同时覆盖 constitution 中多个 criteria；交换 response 顺序收集 `r_{ikjℓ}`，强矛盾覆写为 tie，弱矛盾保留。
6. **define_component → derive（p.5–6）**，用低秩 BTD 取代每个候选的单一 scalar strength；`v_j∈R^d` 是 model disposition，`u_i∈R^d` 是 judge lens，`λ_i` 是 tie propensity。
7. **connect_to_prediction（p.6）**，`d` 在 held-out comparison data 上按 test loss 选择；实际常为 `d=N`，但 `d=2` 与 `d=N` 的 test loss 差异常小。大 population 的维度行为留给 Appendix K.2。
8. **derive（p.6）**，给出 BTD win/loss/tie 概率、归一化常数 `Z_{ijk}` 和 log-likelihood `L`，用 gradient ascent 拟合 `u,v,λ`。
9. **state_complexity/guarantee（p.6 与 p.15）**，正文称 `−L` 非凸但有唯一 local minimum value，Appendix E 把 likelihood 改写为 `θ_{ijk}=u_i^T(v_j-v_k)` 后借用 Zermelo 的 BT 唯一性论证，说明 trust matrix entries 可识别。
10. **derive（p.6）**，从 `s_{ij}=exp(u_i^Tv_j)` 组装 row-stochastic trust matrix `T`，其中 tie term按 Davidson–Luce 形式加入。
11. **instantiate_algorithm → explain_mechanism（p.6）**，Algorithm 1 从 uniform `t^(0)` 开始迭代 `t^(n+1)=t^(n)T`，以 `δ<τ` 停止；`t` 是 `T` 的 left principal eigenvector 与 probability distribution。
12. **give_intuition（p.6）**，把 `T` 解释为 Markov chain；在 rotating judgeship 叙事下，`t_j` 是模型成为 successor/judge 的长期比例。
13. **summarize（p.7）**，把 probability trust 转成 `Elo_j=1500+400 log10(Nt_j)`，提升可读性。

动作转移可压缩为：`setup_notation → define_component → instantiate_algorithm → explain_mechanism → derive → state_complexity → connect_to_prediction → instantiate_algorithm → give_intuition → summarize`。公式和算法几乎完整覆盖了从比较 trit 到可读 leaderboard 的主链；数据收集伪代码、prompt 顺序、优化超参数则移到 Appendix C–E 与 Tables 16–18。

### 形式对象、假设与理论位置

- **形式对象**，`M,C,S` 是输入；`R_j`, `R̂_j`, `r_{ijkℓ}` 是观测过程；`u_i,v_j,λ_i` 是 BTD 参数；`T` 是 trust matrix；`t` 是 stationary/eigenvector score；Elo 是展示层变换。证据：p.1–2、p.5–7。
- **关键假设**，每个 model 兼任 judge/evaluee；`T` 被设为 irreducible、row-stochastic；alignment 较好的模型更擅长判断 alignment；constitution 的 criteria 允许主观分歧；transpose comparison 可暴露 order bias。证据：p.2、p.5–6。
- **理论结果**，正文没有编号 theorem/lemma/proposition。作者引用 Perron–Frobenius 保证 `t` 的存在/唯一性（归一化后），用 Markov chain ergodic theorem 解释 stationary interpretation，并在 Appendix E 用 Zermelo 的 BT maximum-likelihood uniqueness 论证 trust matrix 可识别。三者分别属于 guarantee、解释性机制和可识别性支撑，不是独立的 generalization theorem。证据：p.2 脚注 3、p.6 脚注 9、p.15 Appendix E。
- **算法**，Algorithm 1 输入 `T∈R^{N×N}` 和 `τ>0`，输出 `t`，循环深度为收敛迭代；Algorithm 2 输入 models、constitution、scenario set 与 group size `k∈{3,…,N}`，对每个 scenario 先收集 responses，再按 groups 选择随机 judge、reflection 和 pairs。关键不变量是同时获得 comparison 与 transpose；复杂度没有以渐近式给出。证据：p.6、p.29。
- **图表**，Figure 1 将五步管线画成输入、response、judge comparison、BTD、EigenTrust/Elo 的有向流程；Figure 2 用二维 disposition/lens 散点展示主观解释结构；Table 1 将研究问题与四种 ranking system 对照。证据：p.2–4。

## 结果、统计与可视化

### 主结果

1. **Model rankings（p.7，Figure 3）**，8 个默认 prompt 模型在 Universal Kindness、Conservatism、Deep Ecology 三个 constitution 上各形成 Elo 排名。Figure 3 的点为 Elo，误差线是 bootstrap percentile 区间；Deep Ecology 区间较宽，作者归因于 ties 较多且相关 scenario 较少。图中没有配套主文数值表。统计处理是按 pairwise comparison 重采样的 bootstrap；正文没有报告 seed 数或区间端点。可能的不利解释是 constitution relevance 与 tie rate 同时改变了区间宽度，不能直接当作模型差异的统一精度尺度。证据：p.7，Figure 3 caption，“larger confidence intervals … large portion of ties”。
2. **Prompted dispositions（p.7，Figure 4/5，Appendix F）**，25 个 `(LM, persona)` trust scores 的 variance 中 79% 归因于 persona pre-prompt，21% 归因于 LM；作者据此支持跨 prompt 的 measurable dispositions。方差按 law of total variance 分解，未给区间或假设检验。Figure 5 的 heatmap 编码 5×5 trust scores，Figure 4 的形状/颜色/散点编码 latent lens/disposition。可能的不利解释是只使用 5 个 persona 和 5 个 LM，比例依赖于方差分解与构成集合。证据：p.7、p.17，Figure 5 caption；p.16，Appendix F。
3. **Character training（p.8，Table 2）**，Llama 3.1 8b 的 1426 分低于 pre-prompted loving 的 1579 和 fine-tuned loving-oct 的 1573；Qwen 2.5 7b 为 1447、Gemma 3 4b 为 1468、Mistral 7b 为 1434。作者将高分解释为 character training 与 EigenBench 测量成功。比较只覆盖一个 Loving constitution 与一个 base model 的两种干预，没有多 seed 或未训练对照族。证据：p.8，Table 2 与“pre-prompted and fine-tuned models are the most loving”。
4. **Model surveys（p.8、p.18，Table 6）**，模型 1–7 self-rating 的排序与 revealed-value EigenBench 排名差异明显；主文例子是 Universal Kindness 中 Grok 4 自评满分但 EigenBench 排第六，Claude 4 Sonnet 排第三却给自己最低 survey score。附录给出三套完整分数，但没有 correlation coefficient 或显式 rank-test。证据：p.8，§5.1；p.18，Table 6。
5. **Human validation（p.8、p.17）**，7 humans、8 LMs、约 3,000 comparisons；human-human 平均 1-norm distance 为 0.3133，human-LM 为 0.3130。作者将两者接近解释为 LMs 对 human judgments 的逼近程度约等于 humans 之间的差异。统计量是 trust-vector distance 的均值，没有区间、显著性检验或 participant-level heterogeneity。证据：p.8，§5.2；p.17，Appendix H，两个 distance equations。
6. **GPQA（p.9、p.19，Table 7）**，15 个模型的 EigenBench-induced rank 与 GPQA ground-truth rank 相距 12 adjacent swaps，Kendall τ≈0.77，作者给出的随机排名概率约为 `1/200,000`，附录写作量级约 `10^-6`。judge 未见 ground-truth；ground truth 仅作事后评估。统计/决策量是 Kendall rank agreement、adjacent-swap distance 和随机排列基准，没有置信区间。可能的不利解释是只有一个 benchmark，15 个模型的共同 answer-choice beliefs 也可能反映能力之外的判断偏差。证据：p.9，§5.3；p.19，Table 7。

## 消融、负面结果与自我设限

### 消融与稳健性识别

- **组件删除消融（observed）**，Appendix J 固定 scenarios 与数据量，对比无 reflection 与 judge scaffold，删除的是反射步骤；识别 cycle、primacy、recency bias 是否下降。结果支持 scaffold 作为流程组件，但仍有约 20% inconsistent data 需 remap。证据：p.20–21，Table 8。
- **维度敏感性（observed，超参数而非组件删除）**，Appendix K.2 比较不同 `d` 的 train/test BTD loss；大 population 中约 `d=30` 后平台，作者将其解释为表达 dispositions/lenses 的 tradeoff。证据：p.21–23，Figure 9b。
- **数据/任务异质性（observed）**，Table 3 更换 r/AskReddit、AIRiskDilemmas、OASST；结果揭示 Grok 4 与 GPT 4.1 对数据源敏感。证据：p.9，Table 3。
- **对抗性失败案例（observed）**，Greenbeard 模型插入 secret signal；其弱 prompt 下无法完全自偏好，作者明确写出更强 prompt 可能在多数时主导 Elo。证据：p.22–23，Figure 10。
- **未提供的消融（not_present）**，没有逐个删除 constitution criteria、BTD tie term、transpose remapping、EigenTrust 权重或 human teleportation 的主文 ablation，也没有对不同 scenario 数量给完整主文曲线。证据：p.7–10 主文结果结构；p.19–23 附录的现有对照集中于 scaffold、`d`、population 与 greenbeard。

### 限制位置与类型

1. **average-case scope（scope，p.1–2）**，分数平均 scenarios、criteria 和 models，脚注把它与 rare catastrophic/worst-case alignment 分开；该指标不能承担 worst-case safety claim。
2. **judge-quality premise（assumption，p.2）**，alignment 更好的模型是更好 judge 的关键前提依赖 constitution；作者举 kind 与 plainspoken 的反例边界。
3. **情境相关性（data/metric，p.7）**，Deep Ecology ties 较多，较少 scenarios 相关，导致 bootstrap 区间更宽；有效信息量因 constitution 改变。
4. **human validation 范围（data/generality，p.8、p.16–17）**，7 位 humans、一个 Universal Kindness constitution、8 个 LM；结果是 proximity evidence，不是跨 population 的普遍等价保证。
5. **population dependence（generality，p.10）**，加入模型会移动既有 Elo，Grok 4 与 Claude 3.5/4 显示方向不同；EigenBench 排名是 ensemble-conditional。
6. **order/intransitivity（metric，p.5、p.20–21）**，需要 transpose collection、强不一致覆写和剩余约 20% remapping；scaffold 降低但没有清除结构性 bias。
7. **data collection cost（compute，p.10）**，一条 pairwise comparison 需要两次 model response、两次 reflection、一次 comparison；作者把 active learning 与 human guidance 留作 future direction。
8. **GPQA 外部效度（generality/causality，p.9、p.19）**，15-model、单 benchmark 的事后 ground-truth recovery 支撑可行性，不能直接证明 subjective-value leaderboard 的因果有效性。
9. **Greenbeard 边界（deployment，p.22–23）**，实验中的 greenbeard 不总遵守偏好 secret word 的指令；作者预期更强 prompt、成为多数时会改变结论。
10. **复现细节缺口（reproducibility，p.7–10、p.15、p.28–29）**，给出 optimizer、prompt 序列与 model IDs，但 PDF 未见所有随机 seed、API 参数、硬件、失败重试和完整 per-run budget。

### 可观察的负面信息呈现方式

- **附录迁移**，主文给 human validation“接近”、survey“差异明显”和 latent-space 用途，具体 0.3133/0.3130、完整 self-rating、Figure 4–10 和 GPQA 15 行表格留在附录。该版面事实增加了正文阅读速度，但使读者需要跳页才能核对差异量级。证据：p.8–10 与 p.16–23。
- **图而非主文表**，Figure 3 用点和区间承载八模型×三 constitution 的主排名，正文没有数值表；精确比较依赖轴读取。证据：p.7，Figure 3。
- **聚合掩盖异质性**，EigenTrust 以 `t` 对 judge trust 加权，scenario/criteria 还先做均匀平均；这正是方法定义，也会把 judge、数据源和 criteria 的异质性压缩成一条 leaderboard。证据：p.2，式 (1) 及 average-case 段；标记为 interpretation。
- **展示层变换**，raw trust vector 统一转成 1500 基准的 Elo，便于可读，但 absolute trust mass 与 ensemble size 的关系需回到公式核对。证据：p.7，Elo formula；标记为 interpretation。
- **未来工作化处理成本**，结论明确承认 data collection“quite inefficient”，随后把 active learning 与动态采样作为 future direction；代价在末段出现，未进入主结果表的比较维度。证据：p.10，§7。
- **正面主张与边界同页**，Greenbeard 段先报告原模型相对稳定，再在同一段写出更强 prompt 可能主导；该处理保留了反例条件，避免把弱攻击实验写成一般安全保证。证据：p.23，Figure 10 后段。

## 结论、limitations 与闭环

### 结论段动作

- p.10 第一段：**重述问题/方法**，以 population peer judgments、constitution、EigenTrust 重新收束 subjective traits 与无 ground truth。
- p.10 第一段后半：**回收结果与影响**，回收 human validation、GPQA ranking、values leaderboard、fine-tuning validation、shared latent space。
- p.10 第二段：**主动承认 compute limitation**，列出每条 comparison 的 2 response + 2 reflection + 1 comparison calls，并提出 active learning/human guidance。
- p.10 第三段：**收窄 GPQA 外推**，写作“hope to further examine”，再举 long-horizon planning 与昂贵 evaluation 作为可能方向。

结论没有引入新数字；它复述主文已有的 79/21、τ≈0.77 等定性结论，但把 data cost 和 GPQA 外推边界放入结尾。证据：p.10，§7。

## 最终判断

1. **单一主线**，EigenBench 将「主观、无统一标签的 value judgment」转化为「模型群体彼此比较 → 低秩 BTD 学习 judge lens/disposition → EigenTrust stationary consensus → Elo leaderboard」；human proximity 和 GPQA rank recovery 是外部可检验支撑，而非方法本身的理论保证。证据：p.1–2、p.5–9。
2. **正文保留的决策关键内容**，三类输入、average-case 与 worst-case 的边界、double-blind/transpose/scaffold 流程、BTD/EigenTrust 公式、主排名、character-training Table 2、scenario/population robustness、data cost。证据：p.1–10。
3. **移入附录的细节及影响**，model IDs、完整 constitutions/personas/prompts、optimizer、方差推导、human distance 数值、survey 全表、GPQA 全表、judge-quality rates、37-model run、sample/dimension/Greenbeard 结果均在 p.13–29；主文仍可理解 pipeline 和主趋势，复核效应大小、样本覆盖与失败边界需要附录。证据：p.13–29。
4. **最有效模式**，Figure 1 把输入、三次调用、BTD、trust matrix、eigenvector、Elo 串成一条图形因果链；式 (1) 紧接平均方式解释；Table 2 用一个 base/pre-prompt/fine-tune 对照把抽象“character training”变成可读决策。证据：p.2、p.6–8。
5. **最大叙事缺口**，核心 judge-quality 前提只以脚注形式承认对 constitution 敏感；human validation 样本小且单 constitution；主文的 Figure 3/8 区间与 Appendix 的详细异质性分离，导致“meaningful and reliable”覆盖范围大于直接证据。证据：p.2 脚注 4、p.7–10、p.16–23。
6. **可迁移规则**，当方法把主观 judgment 聚合成 leaderboard 时，正文应在 pipeline 后立即给出「评委前提、聚合单位、一个带数字的外部对照、一个会改变解释的失败条件」；附录再展开 prompt、全表和证明。该规则由 p.2 的 premise、p.8 的 Table 2、p.9 的 GPQA、p.23 的 Greenbeard 对照共同支持。
7. **适用边界**，该规则适合 ensemble-conditional、主观或弱标签评测；若研究目标是 worst-case safety、因果干预效果或部署级对抗稳健性，还需独立的 adversarial coverage、干预对照和 failure-rate 设计，不能由 EigenBench 的 average-case stationary score 单独承担。证据：p.1 脚注 2、p.2 脚注 4、p.10、p.22–23。
