## 6. 方法与理论（单一因果主线）

### 6.1 形式对象与等价关系

OTLP（Eq. (1)）以 `C` 为 `V × V^n` 耦合变量，在 token-incidence 允许的位置最大化 acceptance mass，同时精确满足目标 `p` 与 draft `p_draft` 边缘。relaxed OTLP（Eq. (2)）把两组边缘等式改为上界，并用 Eq. (3) 的 residual coupling 补回等式。Theorem 3.1 的 Eq. (4) 把最优 acceptance 写成 `1 + min_H ψ(H)`，其中 `ψ(H)=p(H)−p_draft(H^n)`；这一步只解决目标值。

Canonical decomposition 通过 `β(i|i)` 进行 importance sampling，再接 single-draft speculative sampling。Theorem 4.1 / Eq. (5) 证明 `β` 可由 `S*` 列归一化得到，退化列用 uniform split。由此，canonical decomposition 与 relaxed LP 共享计算负担，无法单独恢复 OT。

### 6.2 Max-flow 与 complementary slackness

§5.2 把 relaxed OTLP 写成二部网络：`s→i` 容量为 `p(i)`，`i→tuple` 在 incidence 位置为无穷容量，`tuple→t` 容量为 `p_draft(tuple)`。§5.3 的 Theorem 5.1 用 `H*` 的互补松弛将网络切成 outer 与 inner 两个独立系统，Eq. (7) 消去两类 residual，Eq. (8) 只需按已采样 tuple 求 OT slice。关键不变量包括非 incidence 变量恒为零，outer/inner 的边缘条件分别由相应流系统承载。

### 6.3 Global resolution 三步

1. **恢复 `H*`**：在 iid `q` 下按递减 `q(i)/p(i)` 排序并扫描 prefix，前端成本 `O(V log V)`。
2. **恢复 outer residuals**：Theorem 6.1 给出 subset inequalities；Theorem 6.2 用 polymatroid greedy 的 consecutive differences 求 `p_i`；Lemma 6.3 将每次 `ψ` 最小化限制到 `q/p` 排序 prefix，cumulative minima 保持 `O(V log V)`。
3. **截断凸优化**：outer 用 `Φ_T`（Eq. (12)），其尾部质量误差 `ε_T`（Eq. (13)）由 `q` 在 `H*∪T` 外的质量决定；inner 用带 slack 的 `Θ_T`（Eq. (15)），误差 `γ_T`（Eq. (16)）由 `q(H*^n)−q(T^n)` 决定。Eq. (14)/(17) 的 softmax 行流分别满足 tuple 等式或不等式。

Algorithm 1 在采样 tuple 全落入 `H*` 时走 inner 分支，否则走 outer 分支。它选择最小 `T` 使 `γ_T≤τ` 或 `ε_T≤τ`，L-BFGS-B 梯度停止阈值为 `5τ`，最后依据 Lemma 6.6 归一化 `C_{·,ω}`。Eq. (18) 的 residual fill 将截断 `S` 还原成近似 `C`。Lemma 6.6 将 outer/inner 偏差 `α,β` 组合为 target-marginal `α+2β` 与 acceptance `α+β`；因此得到 target L1 `≤15τ`、acceptance `≤10τ`。证据见p.7–8, Theorems 6.4–6.5, Lemma 6.6。

## 10. 结论、限制与闭环

### 10.1 结论回收

结论段（p.10）依次回收：complementary-slackness system → global resolution 加速 max-flow → 高 acceptance/低 overhead 实证 → future work（multi-step 与 non-iid）。它没有新增数字。Reproducibility Statement 把 proof（B–J）、convex minimization（K）、机器/数据集/solver（M）与 Section 7 互相索引。证据见p.10, `Building on previous theoretical work` 与 `all necessary information to reproduce`。

## 13. 最终判断

1. **单一主线**：把“只知道最优 acceptance 的 subset objective”转成“可恢复 OT 见证解”的 complementary-slackness/max-flow，再借 iid 的 submodularity/polymatroid 与 convex truncation 获得带误差预算的单步 solver。证据见p.3–8。
2. **正文保留的决策关键内容**：OTLP/relaxed LP 定义、H*、outer/inner flow、Algorithm 1、15τ/10τ guarantee、Figure 1 与 Tables 1–2。
3. **移入附录的细节**：14 个 proof blocks、coefficient grouping、L-BFGS-B 25-iteration cap、`|T|` hard limits、硬件/数据集、Gemma-2 表、temperature/greedy/SpecTr/non-iid 结果。迁移让正文可读，但实验失败率与复现路径需要附录。
4. **最有效模式**：先给 acceptance 的 subset objective，再给 flow witness，再给 convex witness 和可组合误差；Algorithm 1 对应这条理论接口。
5. **最大缺口**：理论任意精度与实际可用之间隔着 `T`、早停、温度、成功率和 CPU 环境；实验缺少 seed、区间、逐任务结果、代码 URL，non-iid n≥3 也未闭合。
6. **可迁移规则**：优化论文应把“目标值”和“见证解”拆成可验证的连续接口，每个近似接口都提供独立且可相加的误差预算。
7. **适用边界**：需要结构化集合函数/可行运输和可组合误差；不能把 iid 前端复杂度、单步 L1 保证或 CPU solver 速度外推到任意 draft 分布和端到端 GPU 服务。
