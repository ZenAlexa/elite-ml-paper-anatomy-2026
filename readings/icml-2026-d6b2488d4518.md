## 3. 引言的论证推进

### 段落动作链

1. **`context`**：LRM 通过长 chain-of-thought 解决复杂数学和逻辑问题，并依赖 inference-time scaling。〔p. 1，§1，explicit，`“complex multi-step mathematical and logical problems”`〕
2. **`problem`**：现代 serving 需要同时承受 repeated weight loading、FLOPs 与随序列长度线性增长的 KV cache，长推理常超过 16K tokens。〔p. 1，§1，explicit，`“three critical axes”`〕
3. **`core_idea`**：microscaled FP4 以 E2M1 表示和硬件原生加速连接压缩与部署，B200 宣称最高 9 PFLOPS FP4、约为 FP16 的 4 倍。〔pp. 1–2，§1，explicit，`“up to 9 PFLOPS”`〕
4. **`failure_of_prior_work`**：W4A4KV4 的 aggressive quantization 带来 reasoning degradation；PTQ、QAT、QAD 仍低于 BF16 FT，RoPE 和 KV outlier 使固定 smoothing/shifting 失效。〔p. 2，§1，explicit，`“leaving a persistent performance gap”`〕
5. **`missing_insight`**：论文把失败定位到低熵 token 的精确数字/操作符；高熵连接短语没有被列为主要故障点，并提出需要围绕这些 decision 更新。〔p. 2，§1，explicit，`“precise symbolic commitments”`〕
6. **`method_preview`**：TAQ 重访相同 reasoning traces，SEM 选择性降低低熵位置 entropy，Q-FIT 联合校准 pre-RoPE scaling 与 post-RoPE shifting。〔p. 2，§1，explicit，`“three key innovations”`〕
7. **`result_preview`**：预告 AIME-120、MATH-500、GSM8K；给出 NVFP4 W4A4KV4 的 65.94% 对 BF16 baseline 56.83% 和 BF16 FT 65.46%，以及 B200/DGX Spark speedup。〔p. 2，§1，explicit，`“65.94% AIME accuracy”`〕
8. **`contribution_list`**：引言末段把 ReQAT、低熵 failure analysis、三个组件和多模型/多 benchmark 评测合成贡献链。〔p. 2，§1，explicit，`“In this work, we propose”`〕

引言完整推进为：**LRM scaling 的部署成本 → FP4 的硬件机会 → W4A4KV4 的精度失败 → 低熵 token 机制 → TAQ/SEM/Q-FIT → benchmark 与硬件结果**。贡献列表重复摘要的三组件和结果，但把 failure analysis 与三类 FP4 deployment regime 加入可证伪范围；没有在引言显式列出 seed、误差、DGX Spark 的 FP8-KV 例外或 SFT 依赖。〔pp. 1–2，§1，interpretation，`“reasoning-centric training framework”`〕

## 5. 方法与理论

### 方法最小逻辑单元与叙事

1. **`state_problem`**：FP4 noise 在低熵 token 上增加 non-top-1 sampling probability，已有 PTQ/QAT 不能恢复 reasoning accuracy。〔pp. 3–4，§3.3，explicit，`“may struggle to fully recover”`〕
2. **`setup_notation`**：Stage-1 在 `D_FT` 上得到 BF16 checkpoint，Stage-2 在子集 `D_TAQ ⊆ D_FT` 上做 QAT；输出为 FP4 ReQAT LRM。〔p. 5，Fig. 3，explicit，`“D_TAQ ⊆ D_FT”`〕
3. **`define_component`**：TAQ 由 BF16 FT 与同 trace 的 QAT 两阶段组成，不把第二阶段换成新的 reasoning traces。〔p. 5，§4.1，explicit，`“same reasoning traces”`〕
4. **`derive`**：比较 FT、QAT、FT+QAT 的 entropy dynamics；单阶段主要改变高熵 bin，aligned FT+QAT 才向低熵 bin 分配变化。〔p. 5，Fig. 4，explicit，`“entropy changes increasingly appear in low-entropy bins”`〕
5. **`connect_to_prediction`**：对齐 trace 使 Stage-2 反复看到同一批 symbolic commitments，论文据此预测低熵位置会得到更多有效更新。〔p. 5，§4.1，interpretation，`“repeatedly act on the same”`〕
6. **`define_component`**：SEM 只在预计近确定的 token 位置最小化 predictive entropy，不对所有 token 施加相同正则。〔p. 5，§4.2，explicit，`“rather than uniformly across all tokens”`〕
7. **`derive`**：Eq. (1) 把标准 `L_SFT` 与加权 entropy 项相加；`w_t` 由阈值 `τ` 和 minibatch 内 `H_min` 生成。〔p. 6，§4.2，explicit，`“L_SEM = L_SFT + λ”`〕
8. **`give_intuition`**：软权重避免接近阈值的 token 被 binary mask 过度惩罚；默认 `τ` 为每个 minibatch entropy 的 75th percentile，`λ=0.1`。〔p. 6，§4.2；p. 20，Appendix D.1，explicit，`“soft weighting”`、`“λ = 0.1”`〕
9. **`state_problem`**：TAQ 在 W4A4KV4 下仍受 KV cache 的 RoPE-pair outlier 与 token-wise oscillation 影响；SEM 只能提供约 1.3% 的额外增益。〔p. 6，§4.3，explicit，`“a substantial gap remains”`〕
10. **`define_component`**：Q-FIT 用 pre-RoPE paired scaling 和 post-RoPE channel shift 联合减少 KV4 attention-output error。〔p. 6，Eq. (2)，explicit，`“jointly calibrates”`〕
11. **`instantiate_algorithm`**：`α_s, α_m ∈ [0,1]` 控制 scaling/shift；Q-FIT 在 calibration set 上以 BF16 attention output 与 KV4 output 的 MSE 网格搜索这两个参数。〔p. 6，§4.3；p. 18，Algorithm 1，explicit，`“minimizing the distance”`〕
12. **`explain_mechanism`**：RoPE-pair asymmetric outlier 且 token variation 小时选择 shift；token-wise oscillation 强时抑制 shift、采用 paired scaling。〔p. 6，Fig. 5，explicit，`“layer-specific Key cache characteristics”`〕
13. **`contrast_alternative`**：MXFP4 使用 block-wise rotation 处理 activation outlier；NVFP4 不需要该步骤，KV cache 训练采用 E1M2 以获得更低 loss。〔p. 6，§4.3；p. 19，Appendix C.2，explicit，`“For NVFP4, this step is unnecessary”`〕
14. **`summarize`**：Fig. 3 把 BF16 FT → Q-FIT calibration → trace-aligned QAT+SEM → FP4 output 串成单一训练管线。〔p. 5，Fig. 3，layout_observation，`“ReQAT overview”`〕

方法动作转移序列为：`state_problem → setup_notation → define_component → derive → connect_to_prediction → define_component → derive → state_problem → define_component → instantiate_algorithm → explain_mechanism → contrast_alternative → summarize`。叙事有效处在于每个组件都回应前文一个具体 failure；TAQ 回应更新位置，SEM 回应 sampling confidence，Q-FIT 回应 KV/RoPE distortion。理论层由经验机制与工程 calibration 的解释组成，不含独立证明。

## 11. 最终判断

1. **单一主线**：论文的主线是把 FP4 reasoning degradation 从“全序列均匀量化误差”重新定位为低熵 symbolic token 的 sampling-risk，再用 **TAQ 重访同一 reasoning trace、SEM 锐化低熵 confidence、Q-FIT 校准 RoPE/KV cache** 形成同预算 FP4 QAT 闭环。〔pp. 3–6，interpretation，`“low-entropy token predictions”`、`“three complementary components”`〕
2. **正文保留的决策关键内容**：低熵诊断 Fig. 2、三组件训练图 Fig. 3–5、Table 1–3 的 accuracy、Fig. 6 的 throughput、Table 4–5 的核心消融和 Fig. 7 的 gradient 机制都在正文；读者可据此判断“为什么更新位置和 KV 初始化重要”。〔pp. 3–9，layout_observation，`“Table 4”`、`“Figure 7”`〕
3. **附录迁移及其影响**：协议、Eq. (3)、Q-FIT Algorithm 1、8-seed/四年 AIME 聚合、超参、FP8-KV hardware caveat 和 Tables 8–17 在附录。正文仍可理解机制和主结果，但若要复现或限定 throughput/泛化主张，必须读取 Appendix B–D。〔pp. 15–22，interpretation，`“All results are averaged over 8 random seeds”`〕
4. **最有效的写作/图表模式**：Fig. 2 先把抽象的 entropy 机制分解为 token semantics、probability redistribution、controlled routing 和 noise sensitivity；Fig. 3 再把机制映射到训练阶段；Table 1 用同一 token budget 横向展示 component accumulation。这个顺序把“诊断 → 组件 → decision metric”连成可核对因果链。〔pp. 3、5、7，interpretation，`“Accuracy increases”`〕
5. **最明显的叙事规避或读者成本**：`up to`/`best across budgets` 的选择规则、aggregate accuracy/no uncertainty、Table 1 中 TQ 与完整 TQS 的非单调关系，以及 DGX Spark 实际为 W4A4KV8 的 caveat 需要读者跨页拼接；此外，logit-noise proxy、gradient ratio 与最终 accuracy 之间没有独立中介或因果识别。〔pp. 7–8、20–22，interpretation，`“best accuracy”`、`“FP8 KV cache”`〕
6. **可迁移写作规则**：当量化或系统优化声称“恢复能力”时，先用一个受控干预把 failure 定位到具体 token/state，再让每个组件只修复一个可观测 failure，并用同预算的组件累加表、机制图和独立 deployment metric 同时验证。〔pp. 3–8，interpretation，`“controlled intervention isolates”`、`“same training budget”`〕
7. **规则的适用边界**：该规则需要可定义的 token/state entropy、可复用的 supervision trace、独立于训练目标的 evaluation 或至少清晰区分 proxy 与 outcome；如果 hardware path、KV precision、seed-level dispersion 或跨域数据不同，不能把“up to speedup”或单一 benchmark accuracy 外推成一般保证。〔pp. 15–22，interpretation，`“proxy for relative logit distortions”`、`“does not support the native NVFP4 KV cache path”`〕
