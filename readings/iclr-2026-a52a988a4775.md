## 5. 方法与理论

### 5.1 问题、相似性假设与 cost model

目标是 `f(x)=1/n Σ_i f_i(x)`，每个 `f_i` 只由 client i 直接访问。核心相似性由三项条件刻画，分别是 delegate 差异 `h_1=f-f_1` 的 gradient Lipschitz 常数 Δ₁（Assumption 2.1）、平均差异的二阶界 δ（Assumption 2.2），以及 delegate 函数 `f_1` 的 L₁-smoothness（Assumption 2.3）。若各 f_i 都有 Lmax-Lipschitz gradient，则 Δ₁≤2Lmax、δ≤Lmax；因此通信项只需 Δ₁/δ，local 项额外含 L₁。[p.2–3 §2; equations (1)–(4), `explicit`]

完整 algorithm definition 被有意留在 Appendix C。A-CSS 可任意挑至多 m 个 client，成本 C_A；R-CSS 均匀随机挑 m 个，成本 C_R；D-CSS 固定 delegate set（本文为 client 1），成本 1，且 `1≤C_R≤C_A`。用 `N_f=E[C_A N_A+C_R N_R+N_D]` 衡量通信，用 `K_f=E[Σ_r K_r]` 衡量 local oracle queries；accuracy 是 `E[||∇f(x̂_R)||²]`，复杂度再对问题类取 supremum。[p.16–17 Appendix C, `explicit`]

### 5.2 I-CGM 主干与 inexact subproblem

把 `f=f_1+h_1` 写成 composite form，在每个 outer iteration 用 `g_t≈∇f(x_t)` 构造
`F_t(x)=f_1(x)+h_1(x_t)+⟨g_t−∇f_1(x_t),x−x_t⟩+(λ/2)||x−x_t||²`，并以近似 minimizer 作为 x_{t+1}。两类误差是 `e_t=||∇F_t(x_{t+1})||` 与 `Σ̂_t²=||g_t−∇f(x_t)||²`，同时要求 `F_t(x_{t+1})≤F_t(x_t)`。[p.4 §3; equation (5), `explicit`]

Theorem 3.1 的证明桥梁是 Appendix Lemma F.1，利用 h₁ 的 Δ₁-smoothness，把 `||∇f(x_{t+1})||` 上界成 `(λ+Δ₁)||x_{t+1}−x_t||+Σ̂_t+e_t`，再把函数值下降项 telescope。Corollary 3.2 把两个误差条件改成期望形式，`Σ E[e_t²]` 受 F⁰ 与 `ΣΣ_t²` 控制，且 estimator error 需被 `ΣG_t²+(λ+Δ₁)²Σχ_t²` 吸收；于是均匀抽取的 x̄_T 满足 `E||∇f(x̄_T)||²≤32(λ+Δ₁)²F⁰/((λ−Δ₁)T)`。[p.4 §3; p.23 F.1; equation (6)–(7), `explicit`]

固定 K 的 local CGM 取 K 个迭代中最小 `||∇F_t||`，Lemma 3.3 给出 `K=ceil(8L₁T/(λ−Δ₁))`，local complexity 带 T。几何随机版本令 `K_t=K̂_t+1`、`K̂_t∼Geom(p)`，利用 Lemma E.3 的 last-iterate recurrence 恢复 `f(x_t)−f(x_{t+1})` telescope；Lemma 3.4 取 `p=(λ−Δ₁)/(8(L₁+λ))`，把每轮期望 local queries 降为约 `1/p`，不再乘 T。[p.5–6 §3; p.22 E.3; p.24–25 F.2, `explicit`]

### 5.3 SAGA、SVRG 与 RG

SAGA 在 t=0,1 做两次 full gradient 初始化；随后 R-CSS 选 St，client 维护单个 b_i^t，server 维护 b^t 与 x_t，使用 `G_t=(1/m)Σ_{i∈S_t}(∇f_i(x_t)−b_i^{t−1})+b^{t−1}`。Lemma 4.1 证明其条件无偏，并给出只含 δ_m 的移动项，但 G₁² 的系数可能大于 1，因而不能直接满足 (7)。[p.6–7 §4; equations (9)–(10); p.7 Lemma 4.1, `explicit`]

SVRG 用 loopless refresh：`G_t=∇f_{S_t}(x_t)+∇f(w_t)−∇f_{S_t}(w_t)`，以 Bernoulli(p_B) 决定 w_t 是否刷新。Lemma 4.3 给出 `Σσ_t²≤(4δ_m²/p_B)Σχ_t²`；直接令 g_t=G_t 仍需 `p_B≈1/n_m`、`λ≈Δ₁+n_mδ_m`，因此通信项保留线性 n_m。[p.7 §4; p.28 F.3.2; `explicit`]

RG 把一个满足 Assumption 5.1 的条件无偏 G_t 接到递归：`g_{t+1}=(1−β)g_t+βG_t+∇f_{S_t}(x_{t+1})−∇f_{S_t}(x_t)`。由于 S_t 在生成 x_{t+1} 前才抽样，能让交叉项在条件期望下消失。β=0 对应 SARAH 更新；与 SAGA 结合给 RG-SAGA，与 SVRG 结合给 RG-SVRG。Lemma 5.2 把原 estimator variance 乘以约 β，同时加上 δ_m²/(β) 的 movement 项；Corollary 5.3 取 β≈1/n_m，Corollary 5.4 取 β≈p_B，分别得到 n_m 与 1/p_B 的 improvement。[p.8–9 §5; p.28–30 F.4, `explicit`]

### 5.4 最终复杂度与因果主线

Theorem 6.1 对 I-CGM-RG-SAGA 取 `λ=3Δ₁+113√n_mδ_m`、`β=1/(112n_m)`、`p=(λ−Δ₁)/(8(L₁+λ))`，迭代次数至多 `ceil(256(Δ₁+38√n_mδ_m)F⁰/ε²)`；通信至多 `2C_A ceil(n/m)+(C_R+1)T`，local complexity 为 `n_m` 初始化项加上 `(Δ₁+√n_mδ_m+L₁)F⁰/ε²` 量级。RG-SVRG 的 full-gradient refresh 仍让 C_A 进入 ε-dependent term；这正是 RG-SAGA 的 cost-aware 优势。[p.9 §6; p.30–32 F.5–F.6; Table 1, `explicit`]

1. **单一主线**：把 A-CSS、R-CSS、D-CSS 的不同 client-selection cost 显式纳入 federated optimization complexity；用 I-CGM 的 delegate composite step 承担 Δ₁，用 RG-SAGA/RG-SVRG 的 partial-participation estimator 承担 δ，从而得到 `C_A n_m + C_R(Δ₁+√n_mδ_m)F⁰/ε²` 型权衡。[p.3 Table 1; p.9 Theorem 6.1]
2. **正文保留的决策关键内容**：目标与三项假设、I-CGM 误差条件、SAGA/SVRG/RG 定义、Lemma 4.1/Corollary 5.3、Theorem 6.1、Table 1、Figure 1–2，以及“full synchronization costly”这一应用边界。[p.3–10]
3. **迁移到附录的细节及损失**：C 把 server/client information 与 termination 移出正文；F 把常数与 independence proofs 移出；G/H 把初始化与 stochastic local solver 移出；J 把 cost-ratio、超参、神经网络和所有数值表移出。正文因而适合读主线，但需要附录才能核查定义、证明、复现和 cost-aware 预测。[p.3; p.14–43]
4. **最有效的模式**：用一张 Table 1 把方法、假设、通信/local complexity、VR type 放在同一坐标系；再用 Figure J.5 直接改变 C_A/C_R，完成理论中的成本机制检验；RG 的误差递推把 SAGA 与 SVRG 放入同一抽象接口。[p.3 Table 1; p.8 Lemma 5.2; p.41 Figure J.5]
5. **最大叙事缺口/读者成本**，摘要与 Table 1 的“best-known”没有 lower-bound 证据；主实验默认 C_A=C_R=1，真正的成本差异依赖附录；没有 seed、重复数或不确定性。另有版面/记号需人工留意。p.42 Figure J.9 标题印作 α=10，而 J.4 段落把 CIFAR10 client split 写作 α=0.1；p.43 无 delegate limitation 写出 `Δmax≲Δ₁`，与前文 delegate-specific Δ₁ 和 uniform Δmax 的关系语义不完全一致；p.24 Lemma F.2 的一个分母显示 `λ_ϕ`，而 setup 使用 `λ_ψ`。[p.24; p.19; p.42–43, `layout_observation`]
6. **可迁移规则**：当论文声称“更高效”时，先把选择策略、聚合单位和每种操作的真实 cost 写进同一 complexity ledger，再用一个只改变 cost 的消融（如 C_A/C_R）识别机制；不要让 communication rounds 代替成本加权的 estimand。[p.16–17 Appendix C; p.40–41 Figure J.5, `interpretation`]
7. **规则边界**：该规则适用于操作成本可枚举、selection strategy 是主要机制且能保持其他训练条件一致的分布式优化实验；若通信 payload、压缩、异步延迟、stochastic oracle 或 client availability 本身是主要变量，需要扩展 cost model 和重复/不确定性报告，本文 p.43 已将这些列为未来方向。[p.16–17 C; p.43 Limitations, `explicit`]
