### 形式对象、假设与理论地位

- 目标是从满足高概率 coverage 的 `Aθ` 中选择低 worst-case objective 的几何；`w` 是决策，`θ` 是 transport-cost 参数，`S(θ)` 聚合 primal/dual/slack 解。〔p.4–5，§4；explicit；`solution map`〕
- 关键假设：下层 minimizer 对所有 `θ` 唯一（Assumption 4.1）；`c`、`x⋆`、distance 对 `θ` local Lipschitz 且 definable（Assumption 5.1）。〔p.5，§4.2；explicit；`minimizer ... is unique`〕〔p.6，§5；explicit；`locally Lipschitz and definable`〕
- 主文唯一正式定理是 Theorem 5.1：在 Assumption 5.1、平方可和但不可和步长与有界迭代下，收敛到 `crit φ`；常步长只保证到临界集的可调小邻域。它是**保证**，不是全局最优或 coverage validity 的保证。〔p.7，§5.1；explicit；`converge to a critical point`〕
- 附录补齐 finite-dimensional conic reformulation、solution-map conservative Jacobian 与 OT-distance differentiation。Proposition C.1 和 Lemma C.1 支撑求导条件；Fact D.1/D.2 给离散 Mahalanobis distance 及其导数，Definition D.1 给 Gelbrich distance。〔p.23–26，Appendix C–D；explicit；`sufficient conditions`〕

理论在因果链上的角色是：`(5)–(17)` 构成核心链，Theorem 5.1 为条件性收敛保证，Appendix D 的非凸反例是诊断，Fig.1 是解释。理论与实验的对应只到「迭代下降、coverage 经验图」；实验不直接检验临界性，也无法把 bootstrap coverage 升格为理论下界。〔p.7，§5.1；interpretation；`critical point`〕〔p.10，§7；explicit；`remains an open challenge`〕

### 算法与实现粒度

Algorithm 1 有一个外层迭代循环，未声明形式不变量；从步骤可读出的操作性不变量是下一轮的 `A(θi+1), b(θi+1), c(θi+1)` 必须与已更新 `θi+1` 对应。主文解释覆盖至解、求导、penalty、更新四步。实验实际使用的 Algorithm 2 追加 gradient clipping 与 `θθᵀ` eigenvalue clipping，再作 Cholesky factorization；这一稳定化细节只在 Appendix E，造成主算法与实验算法之间需要读者自行连接的实现层差异。〔p.7，§5；explicit；`Algorithm 1`〕〔p.28–29，Appendix E；explicit；`enhances numerical stability`〕

## L. 最终判断

1. **单一主线**：把 OT transport cost 的几何从独立 calibration 的输入改成由 downstream loss 通过 bilevel hypergradient 学到的变量，再以 bootstrap coverage penalty 限制过度乐观的 set 缩小。〔p.4–6，§4–5；interpretation；`loss function informs the shape`〕
2. **正文保留的决策关键**：问题、coverage surrogate、penalty、主算法、条件性收敛和两类主任务都在正文；这让读者能判断主机制和核心经验现象。
3. **迁往附录的细节与影响**：推导、稳定化、参数、synthetic generation、额外 settings、复杂度和 sensitivity 在附录。此安排不破坏概念自足性，但复现与「一般 conic ambiguity set」外推无法只凭正文完成。
4. **最有效模式**：Fig.1 用一个几何反例讲清保守性；随后每个任务按 `single geometric case → aggregate curve → coverage/robustness check` 推进。Algorithm 1 紧跟公式，避免方法先叙后算脱节。〔p.4，Figure 1；layout_observation；`Simplified problem`〕〔p.8–9，Figures 2–4；layout_observation；`Results of the bilevel optimization`〕
5. **最明显缺口/读者成本**：coverage 是论文最关键的 reliability 接口，却缺少理论 lower bound；主实验缺跨方法 baseline，main error bars 没有定义；实验 Algorithm 2 的 clipping 需到附录才出现。以上是证据边界，不归因作者动机。
6. **可迁移规则**：若创新在于改变一个稳健优化对象的几何，正文应同时给出可视化机制、可执行更新、覆盖约束与任务级结果；把全套推导移到附录前，应让正文能说明每个约束为何存在。
7. **规则边界**：当 guarantee 本身尚未闭合，不能用经验 coverage 图把它表述成理论证书；应像本文 p.10 一样显式标明缺口，并将主张限定在已测任务与假设内。
