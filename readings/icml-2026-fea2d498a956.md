## 相关工作：比较结构

1. **Non-monotonic generation** — masked diffusion、AO-ARM 与 LO-ARM；比较维度是 fixed canvas、conditional-independence approximation 与是否学习 state-dependent unmasking order。对 LO-ARM 给出最近邻差异，后者仍是 fixed-size sequence，未直接建模 insertion-and-termination。[PDF p.6, §3; anchor "does not directly model variable-length generation"]

## 方法与理论：逻辑单元

### 形式对象与转移

- **生成状态与输出**：初始 `y_0=()`；每步 decoder 从 `p_φ(z|y_{i-1})` 选 slot 或 `TERM`，再由 `p_φ(x|y_{i-1},z_i)` 选 token。输出是在 `TERM` 时的 `y_{i-1}`。这把 variable length 放入显式终止决定。[PDF p.2, §2.1, Eqs. (1)–(2); anchor "The process terminates when zi = TERM"]
- **训练对象**：观察到固定目标 `y_L` 后，直接边缘化 trajectory 不可行；把 global permutation `σ∈S_L` 作为 latent order，令 `z_i=f(σ_{≤i})`。输入给 encoder 的是完整 `y_L`，输出每个全局索引的 PL score；decoder 在采样时只看 partial sequence，不看 `y_L` 或 `L`。[PDF pp.3,5–6, §§2.2,2.4; anchors "global permutation" / "conditioned only on the partial sequence"]
- **目标函数**：policy termination 使用 termination log-probability 与 permutation ELBO；classifier termination 以 final-slot EOS 形成等价的 augmented ELBO。主文给出 policy 版本，classifier 的完整推导移至 Appendix C。[PDF pp.4–5, §2.3; anchor "Permutation ELBO"；PDF pp.12–13, Appendix C; anchor "augmented ELBO"]

### 公式、理论与算法

- 人工按版面计数为 **25 个带编号公式**（Eqs. (1)–(25)）和约 **38 个展示数学块**。后一个数把一块多行推导计为一个块，包含 Appendix A–C 的无编号推导；`uncertain`：PDF 未定义「displayed equation」口径，若把 boxed classifier definition 内的三行分别计数会改变该近似值。[PDF pp.2–5,11–13; layout observation; anchors "(1)" / "(25)"]
- **Lemma 2.1**：假设固定 `y_L` 与一条有效 insertion trajectory，结论是唯一 `σ∈S_L`，并且 `z_i` 是 `σ_{≤i}` 中的 rank。证明在 Appendix A.1；它是核心因果链的坐标变化，不是实验保证。[PDF p.3, §2.2; anchor "there exists a unique permutation"；PDF p.11, Appendix A.1; anchor "completes the proof"]
- **Theorem 2.2**：对任意长度 `L` 的 sequence，`p(y_L)=Σ_σ p(y_L,σ)`，且 joint 按 token 与 slot probability 分解。证明在 Appendix A.2；后续对应 ELBO 的构造，论文未为该等式报告独立实验检验。[PDF p.4, §2.2, Eqs. (7)–(8); anchor "Permutation-marginalized likelihood"；PDF p.11, Appendix A.2; anchor "which completes the proof"]
- **随机优化陈述**：Appendix B 以随机 `i`、两条 permutation samples (`M=2`) 和 `stopgrad` 给出 stochastic unbiased objective；Appendix C 将 EOS 约束改写为 augmented ELBO。它们是训练估计器的推导与实现说明，未被命名为新的 theorem/lemma。[PDF p.12, Appendix B, Eqs. (19)–(20); anchor "unbiased gradient"；PDF pp.12–13, Appendix C, Eqs. (21)–(25); anchor "equivalent to an augmented ELBO"]
- **Algorithm 1**：输入数据集 `D`、decoder `p_φ`、inference `q_θ`、样本数 `M`；循环为 training while-loop、每数据样本抽 `M` 个 permutations、再对 `m=1…M` 计算 `F^m`；输出是更新后的 `(φ,θ)`。关键不变量是 partial sequence 始终由 sampled permutation prefix 决定。论文没有给出 asymptotic time/memory complexity；只说精确内层期望和单个随机 time step 用于效率。[PDF p.5, Algorithm 1; anchor "Sample M permutations"；PDF p.5, §2.3; anchor "For efficiency, we subsample a single time step"]

## 实验设计与统计边界

### 研究问题、任务与对照

§4 预先以三个问题组织：insertion 是否优于标准 AR、学习 instance-specific policy 是否优于 order-agnostic、优势是否迁移到 planning 与 flexible-length conditional generation。[PDF p.6, §4; anchor "Our experiments are designed to answer"]

- **Planning**：maze paths 与 star graphs。maze 以部分 ordered subgoals 为条件；星图输入是随机排序的 edge list、source、goal 与 graph-BOS，输出 directed path。maze splits 为 80/10/10；hard star-graph 设 degree 5、arm length `[6,12]`、node vocabulary 56。[PDF p.7, §4.1; anchor "two synthetic planning benchmarks"；PDF p.14, Appendix D.1–D.2; anchors "Data splits are 80/10/10" / "degree 5"]
- **Molecular SMILES**：GuacaMol unconditional generation 和四种 slot-constrained conditional tasks。conditional task 各生成 1,024 samples；unconditional grammar pattern 在 100,000 samples 上报告。[PDF p.8, §4.2; anchors "GuacaMol" / "generate 1024 samples" / "Across 100,000 unconditional samples"]
- **Baselines**：FO-ARM、AO-ARM、MDM、LO-ARM；molecule 另设随机 insertion policy 的 AO-IP。planning 中作者称 all baselines 使用同一 architecture，molecule sequence baselines 使用 comparable Transformer backbones，并重实现并调 FO-ARM 对齐已有 distributional performance。[PDF pp.6–8, §4; anchors "following baselines" / "comparable Transformer backbones"；PDF p.15, Appendix D.3; anchor "all baselines use the same architecture"]
- **训练披露**：planning 为 100 epochs、batch 64、AdamW、`1e-4`、cosine schedule、1,000 warmup、EMA 0.999、12-layer decoder、6-layer policy network、RLOO `M=2`；GuacaMol 给 `p_φ` 18 layers、VI encoder 3 layers 与 Table 5 的优化参数。代码只指向依赖/改编源 `llama2.c`；本文未给出自有 implementation repository、硬件、wall-clock、随机种子、每项样本数或多次训练次数。后三类为 `unavailable`，不是零值。[PDF p.15, Appendix D.3/D.5; anchors "100 epochs" / "all experiments are run to convergence"]

### 不利结果与消融

AO-IP 是正文唯一明确的随机 order 消融：unconditional validity 从 classifier-based IP 的 97.4 降至 88.2，同时 AO-IP 保有 87.7 novelty；conditional 四任务中的 AO-IP validity 也显著较低。这个对照检验 learned order 的必要性，但没有逐个删除 encoder、decoder、termination、RLOO 或 permutation mapping 的 component ablation。[PDF p.8, Table 3; anchor "AO-IP"；PDF p.8, Table 4; anchor "AO-IP"]

作者主动呈现 fidelity–exploration trade-off：FO-ARM/LSTM 的 KL/FCD 高于 IP，IP 在 distributional metrics 上略落后；其解释是 IP 的 novelty 与 validity 组合更适合探索。该解释与结果一致，但「internalizes structural rules」属于作者解释；目前设计没有独立的机制干预来区分这项解释与其他训练/architecture 原因。[PDF p.8, §4.2; anchors "trails FO-ARM/LSTM slightly" / "internalizes the structural rules"]

## 最终判断

1. **单一主线**：将相对 insertion trajectory 改写为 global permutation，使可变长度 insertion process 能以 permutation-based VI 学习 instance-specific order，再以 planning/SMILES 表测试该 order 的价值。[PDF pp.2–5, §§2.1–2.4; anchors "bijection" / "Permutation ELBO"]
2. **正文保留的决策关键内容**：问题差距、生成/推断的核心分解、两条命名理论结果、RLOO 算法、baseline 逻辑、四张主表和一个可解释生成过程。证明与超参数迁到附录。[PDF pp.3–8, §§2–4; anchors "Lemma 2.1" / "Table 4"]
3. **最有效模式**：先用 Fig. 2 将 decoder、posterior 与 estimator 并置；随后以 Lemma/Theorem 将直觉压缩为可检查的固定 latent-space 事实；最后用 AO-IP 把「learned order」与随机顺序作接近的对照。[PDF pp.3–5, §§2.2–2.4; anchors "Figure 2" / "RLOO"；PDF p.8, Table 3; anchor "AO-IP"]
4. **最大读者成本与未闭合处**：术语和公式密度高，关键 RLOO/classifier 推导被移至附录；主结果没有 seeds、dispersion、test denominators、hardware 或独立 mechanism intervention。该判断针对披露与识别范围，未推断未披露实验的结果。[PDF pp.11–15, Appendix B–D; anchors "M = 2" / "Hyperparameter setup"]
5. **可迁移规则**：若生成动作的局部坐标随历史演化，优先寻找能把每条有效轨迹映成固定全局 latent object 的双射；把该映射、likelihood factorization 和其近邻实验对照放在同一主线中。适用边界是存在可证明的一一映射且目标的不同生成 order 可明确枚举/采样；论文没有证明该规则适用于任意 structured generation。[PDF pp.3–4, §2.2; anchors "unique permutation" / "sum over permutations"]
