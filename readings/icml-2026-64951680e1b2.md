## 5. 方法、理论与公式

### 5.1 方法叙事与组件对应

方法分为两层，先构造 TEDBench，再以 MiAE 作为 reference approach。动作序列如下。

`state_problem -> define_component -> explain_mechanism -> give_intuition -> instantiate_algorithm -> connect_to_experiment -> summarize`

其中 `state_problem` 是冗余、long-tail 与 predicted-to-experimental shift；`define_component` 是 Foldseek-cluster、largest-domain label、residue frame、mask/encoder/decoder；`explain_mechanism` 是高 masking 强迫模型从稀疏 frame 重建全 backbone；`connect_to_experiment` 是 Table 2/3、Figure 4-6 和 Appendix C。论文没有自有伪代码或算法框，算法接口通过自然语言和 Figure 3 传达。〔pp. 3-9，`interpretation`，`“non-redundant”`、`“up to 90%”`、`“Figure 3”`〕

| 序号 | 方法动作 | 解决的前文问题或组件 | 页码与证据 |
|---:|---|---|---|
| 1 | `state_problem` | 需要一个大规模、non-redundant、domain-level target。 | p. 3，§3，`“large-scale, non-redundant benchmark”`。 |
| 2 | `define_component` | TED 提供 domain annotations；Merizo、Chainsaw、UniDoc + consensus filtering 处理 domain boundary。 | p. 3，§3.1，`“consensus filtering”`。 |
| 3 | `explain_mechanism` | 全 AFDB 约 365M domains 含大量 redundancy，因此限制到 Foldseek-clustered AFDB 约 2.27M proteins。 | p. 3，§3.1，`“substantially reduces redundancy”`。 |
| 4 | `define_component` | 保留 mean pLDDT > 80，得到 462,175 structures；每个蛋白以 largest domain 的 CATH label 形成单一 target；749,679 unannotated structures 用于 pretraining。 | p. 3，§3.1，`“single, unambiguous target”`。 |
| 5 | `derive`、`contrast_alternative` | 对 long-tail T-level 类别设置最小样本规则；同一 A-level 下稀有 T-level 合并成 `.x`。 | p. 4，§3.2，`“fewer than 10 samples”`、`“965 classes”`。 |

- **显示公式。** 全文 6 个显示公式，其中 1 个编号公式；正文页 4 有 3 个 frame/坐标变换显示式，Appendix 页 14-15 有 3 个 loss 显示式。没有 theorem、lemma、proposition、corollary 或 proof。〔pp. 4、14-15，`layout_observation`，`“Ti”`、`“(1)”`、`“Ldist”`、`“Ldir”`〕
- **算法。** 没有作者自有伪代码或 `Algorithm` 环境，计数为 0。Appendix B.1/B.2 只引用 ESM3 的外部 Algorithm 6/9；Appendix A 的 Python 代码框是 label-processing implementation detail，不作为本文算法计数。〔pp. 13-14，`explicit`，`“def process_cath_labels”`、`“Algorithm 6”`、`“Algorithm 9”`〕
- **方法图与方法表。** Figure 1 是 benchmark overview，Figure 2 是 reconstruction examples，Figure 3 是 architecture；Table 1 是 dataset statistics。它们共同把 benchmark target、输入结构、架构和数据规模连接起来。〔pp. 3-5，`layout_observation`，`“Figure 1”`、`“Figure 2”`、`“Figure 3”`、`“Table 1”`〕

## 8. 结论、Impact 与闭环

### 8.1 Conclusion 与 Impact

Conclusion 先重述 TEDBench 的 benchmark 价值，再回收 MiAE 的 SE(3)-invariance、high optimal masking 和 asymmetric encoder-decoder，最后将 masked autoencoding 外推为 structural biology 的 self-supervised 方向。没有新表格、新公式或新数字。〔p. 9，§6，`explicit`，`“We introduced TEDBench”`、`“MiAE is SE(3)-invariant”`〕

Impact Statement 明确列出 drug discovery、enzyme design、synthetic biology 的潜在正面用途，同时承认 dual-use 风险；又限定本文只做 representation learning、backbone structures、不做 generative design/sequence synthesis。它声明无 human subjects、personal data 或 sensitive biological datasets，并建议 controlled access、careful downstream evaluation 和 community guidelines。〔pp. 9-10，`explicit`，`“dual-use risks”`、`“does not involve human subjects”`〕

## 12. 最终判断

1. **单一主线。** 论文先把 protein fold classification 变成一个大规模、去重、单一 target、带 external experimental test 的 benchmark，再用 MiAE 的 residue frames、高 masking 和 asymmetric encoder-decoder 学 structure-centric representation；同一个 benchmark 同时承担 baseline、transfer、scale 和 component diagnosis。〔pp. 1-9，`interpretation`，`“single, unambiguous target”`、`“which design choices are critical”`〕
2. **正文保留的决策关键内容。** 正文保留 TEDBench 的数据/标签/split、MiAE 的 frame-mask-encoder-decoder 机制、Table 2/3 的 scratch/linear/fine-tune 主结果、Figure 4-6 的关键趋势以及明确 Limitations；读者可以判断任务难度、F1 方向和适用边界。〔pp. 3-9，`explicit`，`“Macro F1 ... primary metric”`、`“This work has several limitations”`〕
3. **移入附录的细节及代价。** label-processing code、精确 loss/clipping/binning、model dimensions、optimizer/batch/iterations、baseline checkpoints、GPU-hour 口径、完整 ablation 和 additional visualizations 放在 A-C。迁移保持了正文的可扫读性，但 label threshold mismatch 和 absent seed reporting 使复现与稳定性判断不能只靠正文。〔pp. 13-19，`layout_observation`/`explicit`，`“Table 7”`、`“Table 9”`、`“cts_cutoff=20”`〕
4. **最有效的图表/方法模式。** Figure 1 先把输入、CATH hierarchy、long-tail、数据分母画在一个 benchmark overview；Figure 3 再把 masked frames 和 asymmetric decoder 画成 pipeline；Table 2/3 以 acc/F1、parameter size、protocol 和 external test 并列，之后 Table 4/5 做组件对照。这种「任务先可判定，方法后可拆验，结果再回收」结构减少了读者在多种 input modality 间跳转的成本。〔pp. 3-9，`interpretation`，`“Overview of the TEDBench”`、`“Benchmark results”`〕
5. **最大缺口。** MiAE+seq 的 F1 优势和外部 transfer 有直接点估计，但没有跨 seed uncertainty、matched compute/architecture 的完整控制，t-SNE/attention 仍是 qualitative；更关键的是正文 10-threshold 与 Appendix 20-default 的 label pipeline 不一致。〔pp. 4、6-9、13-14、17，`layout_observation`/`explicit`〕
6. **可迁移规则。** 先冻结 benchmark 的去重、标签分母、split 与独立外部 test，再让每个模型组件对应一个可删除对照；主文报告改变选择的 macro F1/accuracy 和参数量，附录给出可复现的训练与 loss 定义，同时显式保留未报告的 seed/uncertainty。〔pp. 3-9、13-18，`interpretation`，`“random stratified split”`、`“complete ablation results”`〕
7. **规则边界。** 只有当数据阈值、label map、模型规模、pretraining corpus 和 external test 的身份固定且可追溯时，单点 benchmark 比较才可支撑 recipe-level 结论；对于跨任务 transfer、domain-level detection、低资源 deployment 和 dual-use impact，本文的设计没有可检验对象，应保留为 future work 或 impact boundary。〔pp. 4、6、9、13-17，`explicit`，`“have not explored”`、`“may limit accessibility”`〕
