## 4. 相关工作

相关工作是独立第 2 节，分成三个主题簇，合计约 502 词，占估计正文主区段约 10%。

1. **SfM & SLAM（p.2，约 180 词）**：以 Structure-from-Motion、global bundle adjustment、ORB-SLAM、DROID-SLAM 和 DPVO 建立经典/学习式基线簇，比较维度是重建精度、incremental pose estimation、dense correspondence 与 calibration 假设。段末以 “often assume known camera calibration” 制造本方法的校准自由缺口。
2. **3D Foundation Models（p.2–3，约 160 词）**：按 DUSt3R → MASt3R → FAST3R → VGGT 的能力推进组织，比较 dense geometry、camera parameters、3D-grounded matching、batch inference 和 Transformer 结构；段末把 local consistency 与 short-sequence quadratic cost 并置。
3. **Scalable Foundation-Based SLAM（p.3，约 162 词）**：按 streaming/causal attention 与 submap registration 两条路线组织，具体对照 Stream3R、Streaming 4D、TTT3R、VGGT-Long 和 VGGT-SLAM，指出 catastrophic forgetting、static redundancy、rapid turns 和 fixed-overlap contextual asymmetry。最后用 “motion-aware calibration-free framework” 直接承接方法。

相关工作主要承担 taxonomy、credit、nearest-neighbor contrast 和 gap creation，没有把方法公式提前重复。后文再次使用 VGGT-Long、VGGT-SLAM、MASt3R-SLAM、Fast3R、CUT3R 作为实验基线；其余引用主要留在背景与方法选择说明。

## 5. 方法与理论

### 5.1 逻辑链

方法正文的动作序列为：

`setup_notation → state_problem → derive → define_component → explain_mechanism → give_intuition → instantiate_algorithm → connect_to_prediction → connect_to_experiment → summarize`

1. **问题与总流程（p.3，§3）**：输入是 monocular image sequence，输出是 globally consistent trajectory 和 dense geometry。Figure 2 把方法画成三阶段，分别为 Motion-Aware Submap Construction、Anchor-Driven Direct Sim(3) Registration、Lightweight Pose Graph Optimization。
2. **运动状态估计（p.3–4，§3.1）**：对相邻帧计算 dense optical flow，使用 static ratio 与 turning score，再做 temporal Gaussian smoothing 和 hierarchical classifier，状态为 Static、Turning、Linear。式 (1)–(3) 先把相机动态转成可操作阈值。
3. **冗余过滤（p.4，§3.1）**：Static Redundancy Pruning 只留静态区边界帧；Parallax-Based Keyframe Selection 只接纳相对前一 keyframe 的 parallax 超过 `τpalx` 的帧。两者分别针对 stop-and-go hallucination 与窄基线。
4. **拓扑感知切分（p.4，§3.1）**：Turning Segment Encapsulation 把连续转弯作为不可分割 submap；Adaptive Linear Slicing 用 `Nmax` 控制线性段长度。这里的关键机制是保留转弯 parallax 连续性，并保持高曲率区完整。
5. **anchor 增广与 VGGT 推断（p.4，§3.1）**：式 (4) 定义 `Mk = Rk ∪ Ok ∪ Lk`；`Ok` 是相邻 submap overlap keyframes，`Lk` 是通过 SALAD 检索并注入当前 queue 的历史 loop frames。式 (5) 将 `Mk` 送入 VGGT，输出 point maps、camera poses 和 confidence maps。
6. **对齐问题与 anchor 选择（p.4–5，§3.2）**：作者把固定 overlap 的边界上下文偏差作为 alignment failure。相邻 submap 选择 overlap 中点附近的 context-balanced anchor `Iovlp`；loop closure 重用最高相似历史 keyframe `Iloop`，且不重新推断。
7. **pixel-indexed correspondence（p.5，§3.2）**：同一 anchor 下的点图在同一 image lattice 上，式 (6)–(8) 将两个坐标系的像素位置直接组成 dense correspondence，并用 Sim(3) 加噪声项建模。
8. **可靠性过滤与 robust registration（p.5，§3.2）**：式 (9) 用 confidence 和 semantic non-sky mask 构成 `Ωvalid`；式 (10) 以 Huber loss 最小化 Sim(3) alignment residual，再以 inlier ratio `ηij` 和 `τin` 决定是否把约束写入 pose graph。
9. **稀疏 pose graph（p.5–6，§3.3）**：节点为 submap pose `Xk ∈ Sim(3)`，边来自相邻 overlap 与 loop closure，权重为 `ηij`。式 (11) 在 Lie algebra 中构造 residual，式 (12) 以 Huber loss 和 `Ωij = wij I` 优化，固定 `X1 = I`，用 Levenberg–Marquardt 求解。
10. **轨迹组合与闭环（p.6，§3.3）**：式 (13) 以 `T(n)w = Xk T(n)k` 组合局部 pose，得到全局 trajectory 和 reconstruction；作者将 backend 总结为对少量 submaps 的 sparse Sim(3) optimization。

## 8. 消融、负面结果与自我设限

### 8.1 消融识别目标

1. **Redundancy Filtering（Table 4，p.8）**：组件删除/添加目标是分离 Parallax-Based Selection 与 Static Pruning；作者用整体 ATE 和 stop-and-go 专用 ATE* 识别静态冗余机制。
2. **Submap Partitioning（Table 5，p.8）**：替换 construction strategy，识别 Turning Encapsulation 是否比 temporal slicing 或 parallax trigger 保持拓扑。
3. **Submap Alignment（Figure 6，p.8）**：替换 Dense registration 与 ADSR，并改变 overlap size，识别 contextual anchor 与 filtering 的精度/计算代价。
4. **Loop Keyframe Reuse（Table 6，p.13）**：比较 bidirectional 和 unidirectional reuse，识别历史 context 污染；ATE 18.31→18.26 m，Drift 0.930→0.928%。

消融采用“incremental protocol”，每一步从前一步最佳配置初始化（p.7，`explicit`）。消融占正文约 645 词，约 13% 的估计主文本，含 2 个表和 1 个图。没有 seed、重复运行、统计检验或组件交互的 factorial design。

## 12. 最终判断

1. **单一主线**：论文把长程 SLAM 的根因从单纯 backend optimization 转到输入组织与上下文保持。先用 optical flow 按 motion state 组织 submaps，再用共享 anchor 把局部 point maps 变成直接 dense Sim(3) constraints，最后用 sparse pose graph 汇聚全局轨迹（p.3–6，§3–3.3，Figure 2）。
2. **正文保留的决策关键内容**：三种失败机制、三阶段 pipeline、式 (1)–(13)、设备/阈值、KITTI/Waymo/zero-shot 主结果、runtime 结果和 MASP/ADSR 消融均留在 p.1–9；这些内容足以理解主要系统决定（p.2–9）。
3. **附录迁移及自足性**：Algorithm 1、loop reuse、model swap/SE(3)、TUM-Mono、全量轨迹、点云和限制移到 p.12–22。核心方法仍自足；若要复核 handheld 泛化、模型耦合、点云质量或限制边界，必须读取 Appendix（p.12–22）。
4. **最有效模式**：引言按三个 failure mode 排列，方法组件逐一回应；Table 4–5 与 Figure 6 采用增量/替代消融，Figures 1、4、5 把误差、长度和运行代价放在同一视觉叙事中（p.2、7–9）。
5. **最大缺口**：复杂度只被陈述，没有定理或规模曲线；聚合结果没有不确定性。表值还显示引言的 85–95% 区间未覆盖 A2D2 的约 83.7% 降幅，Table 7 的“consistently”也被逐段反例削弱；B.3 承认 loop 间不能保证 bounded global error（p.7、14–15）。
6. **可迁移规则**：把每个系统组件绑定到一个可观测失败机制，并让主表或主图与消融分别回答效果和机制，同时把失败分母、异质性和适用边界留在同一证据链中（p.2、7–9、15）。
7. **规则边界**：该规则适用于有清晰输入组织、对齐和运行指标的长序列感知论文；单次平均 ATE/runtime、概念性的模型替换或定性点云不能单独升级为普遍 guarantee，尤其在缺少重复运行、规模曲线和动态场景实验时（p.6–9、14–15）。
