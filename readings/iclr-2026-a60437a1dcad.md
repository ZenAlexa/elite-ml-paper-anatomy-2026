## 5. 方法与理论

### 5.1 形式化对象与组件对应

- **已知数据/模型**（p.4 §3.1）：old modality 有带标签 `D(old)` 和冻结 encoder `fθ(old)` 加 task head `gω(old)`；new modality 有无标签 `D(new)`；另有不参与前两者训练的 paired、unlabelled `D(pair)`。目标是在 new modality 上得到可预测模型。
- **桥接输入/输出**（p.4–5 §3.2）：new encoder 前 `m` 层输出 `h_m(new)`；bridge `bψ` 将其投到 old encoder 第 `l` 层的空间，得到 `h̃_l(old)`；后续 old encoder 从 `l+1` 层继续到 task head。
- **位置选择**（p.5–6 §3.3）：先以 old 模型输出的 pseudo labels 做线性 probing 选 `m`，再以 linear CKA 选与 new 表示最相似的 old 层 `l`。这把“新模态表示是否有任务信息”和“两个空间是否容易连接”拆成两个诊断。
- **bridge architecture**（p.6 §3.4）：prototype set `P` 提供 old-space 原型；`A`、`B` 是 low-rank factorization，先对 new tokens 做 pooling，再生成原型聚合权重并 reshape 到 old 表示维度。作者给出的 LaBraM→HuBERT-ECG full-rank 投影规模是约 1.7 billion parameters，而 prototype/low-rank bridge 避免这一直接矩阵。
- **训练**（p.7 §3.5）：冻结两侧模型，只优化 bridge 参数 `ψ`；以 old paired 输入得到的最终层表示和 bridged 路径最终层表示做 `Lalign`，示例是 cosine loss 或 mean absolute error loss。

### 5.2 段落动作序列

`setup_notation → state_problem → define_component (h_m) → define_component (bψ) → derive (prediction) → state_problem (L×M search) → derive (linear probe m) → derive (CKA l) → instantiate_algorithm → contrast_alternative (full-rank) → define_component (prototype/low-rank) → derive (bridge output) → give_intuition (exact alignment) → connect_to_experiment (cosine/MAE and Algorithm 1)`。

Algorithm 1（p.6）把上述顺序固定为：输入 old/new models、old task head、`D(pair)`；初始化 `{A,B,P}`；按 Eq. (4)/(5) 选 `m/l`；每个 epoch/step 采样 paired minibatch、计算 old/bridged final representations、算 `Lalign` 并更新 `ψ`；推理阶段仅输入 `D(new)`，通过 `gω(old) ∘ fθ>l(old) ∘ bψ ∘ fϕ≤m(new)` 得到预测。伪代码给出 epoch、step 和梯度更新，但没有给出渐近时间/空间复杂度公式或循环次数的具体数值。

|对象|页/节|内容与作用|理论角色|证据|
|---|---|---|---|---|

## 9. 结论、限制与闭环

### 9.1 结论段落动作

- **重述问题/方法**（p.10 §5）：将 BioX-Bridge 定义为 biosignal unsupervised cross-modal transfer 框架，以 prototype-based architecture 对齐高维表示。
- **回收核心机制**（p.10）：两阶段 bridge-position selection 被描述为更有效的连接点选择。
- **回收结果**（p.10）：跨数据集和任务达到 comparable/superior performance，并大幅减少 trainable parameters；没有新增数字。
- **影响语言**（p.10）：将方法延伸到 accessible、adaptable、modality-agnostic、resource-efficient 应用，但这些是潜在方向，不是部署实测。

### 9.3 明示限制

1. 依赖每个 biosignal modality 的预训练模型；新兴/欠研究模态可能没有此条件（p.15 Appendix B，`scope/data`）。
2. bridge 位置可能使 inference time 更长（p.15，`compute/deployment`）。
3. 当前方法是否应 task-agnostic 尚未解决；task-agnostic 可能牺牲 task-specific performance（p.15，`generality/metric`）。
4. paired data 比 unimodal data 难收集；unpaired transfer 只是 future work（p.15，`data`）。
5. 多于两种模态、同模态跨数据集泛化和 dataset-specific adaptation 尚未实证（p.15，`generality`）。
6. 正文没有单独 limitations 段；第 10 页 Conclusion 后直接进入 Ethical and Reproducibility Statement，限制依赖 Appendix B 才可完整读取（p.10、p.15，`layout_observation`）。
7. Appendix D.1.1 的 ISRUC 预处理段落称“PPG signals are also sampled at 200Hz”，而正文实验选择 ISRUC EEG/ECG；论文没有解释该 PPG 句子是否是未使用通道或笔误（p.7 §4.1、p.16 D.1.1，`implementation_detail`）。这属于复现阅读成本，不把它推断成实验错误。

## 12. 高频用词与修辞

以下是对正文叙述的语境化观察；已排除 References、公式碎片和图表模板词，领域名词仍保留，词形合并存在连字符/复数误切分风险。

- **领域/方法词** — `layer`、`modality`、`bridge`、`model`、`knowledge`、`transfer`、`biosignal`、`foundation`、`position`、`representation`、`prototype`、`parameters`。最高频概念簇围绕“层、模态、桥、表示”，文章的真实论证动作聚焦表示空间连接，数据生成仅作为对照。
- **高频二元词组**：`knowledge transfer`、`foundation models`、`knowledge distillation`、`cross-modal knowledge transfer`、`position selection`、`intermediate representations`、`prototype network`、`trainable parameters`。这些短语同时出现在标题、方法和结果，属于主线词而非单纯模板词。
- **高频三元词组**：`cross-modal knowledge transfer`、`biosignal foundation models`、`bridge position selection`、`intermediate representation(s)` 与 `low-rank approximation module`。`et al.` 的高频来自引用格式，应从修辞统计中剔除。
- **主张动词**：正文可见 `propose` 约 5 次、`introduce` 约 4 次、`select` 约 5 次、`observe` 约 3 次、`demonstrate` 约 1 次、`present` 约 1 次、`provide` 约 2 次；`show/find` 不是作者主要自称结构。`propose/introduce` 集中在引言和方法，`observe` 集中在结果/附录，形成“设计—测量”的动词分工。
- **限定/对比词**：`however`、`although`、`because`、`despite`、`while` 用来承接 modality gap、BAcc/F1 分歧和 teacher 上限；`notably` 连接 ECG-FM 消融。强主张（`novel`、`superior`、`powerful`、`exceptional`、`drastically`）主要出现在摘要、引言和结论；实验段落更多使用 `comparable`、`possible`、`likely`、`reasonable`。强/弱语气比例没有被作者量化，且强主张有一部分由“efficiency”而非任务效能承担。
- **误切分与解释风险**：`old/new` 既是模态时间角色又是输入输出方向；`oracle` 是 supervised old-modality 参照，不应读成 new-modality 上限；`BAcc` 与 F1 的不同聚合会制造“超过 Oracle”的局部表象；`PaPaGei`/`HuBERT-ECG`/`LaBraM` 的层数不同，不能直接比较 layer 编号的深浅。

3. **指标替代风险被正文主动解释**：BioX/ KD-C 在个别方向的 BAcc 高于 Oracle，但作者补充说明 BAcc 是 recall 平均、F1 还反映 precision（p.9），没有把局部 BAcc 直接写成所有指标更优。
4. **基线范围受限**：CardioGAN 只用于单导联 WESAD ECG→PPG；Appendix C.3 明确多通道 EEG/EMG/ECG 扩展非平凡（p.16）。这是有文字证据的适用范围限制，不据此推断作者回避结果。
5. **弱化比较粒度**：§4.2 以“around 1–2% across all metrics”概括 WESAD PPG→ECG，而原始 Table 1 的三项提升分别为约 1.17、3.31、1.40 个百分点；表格仍保留原始均值，读者可自行恢复差异（p.8）。
6. **结论概括大于证据覆盖**：Conclusion 的“modality-agnostic”与引言脚注的“compatible with any deep learning-based biosignal models”超出已测四种模态、两个 ECG 替换模型的直接范围；Appendix B 的 future work 没有把这一范围收窄为已证明的定理（p.10、p.15）。

## 14. 最终判断

1. **单一主线**：在 paired、unlabelled biosignal data 下，不重新训练 old/new foundation model，而是在两者 intermediate representation 之间学习一个 prototype + low-rank bridge；先用 pseudo-label probing 找到有任务信息的 new 层，再用 CKA 找到可连接的 old 层，最后用 final-representation alignment 继承 old task head。参数效率是主卖点，位置选择是识别机制。
2. **正文保留的决策关键内容**：Figure 2/3、Eq. (1)–(7)、Algorithm 1 交代信息路径和训练边界；Table 1 交代六方向性能与参数；Figure 4、Table 2–3 交代低数据、位置策略和 foundation-model 替换。读者不用附录也能理解方法和主要相对比较。
3. **移入附录的细节及其代价**：preprocessing、split ratios、learning rates、loss、grid、标准差、层曲线、九位置热图、传统 backbone、模型规模、FC-Bridge、reshuffled subjects 全部移入 D。这样正文紧凑，但没有附录就无法判断离散程度、FOG 低数据失败、subject 异质性或复现路径；Appendix B 才给出明确 limitations。
4. **最有效的模式**：Figure 3 将两个 selection criterion 画成可诊断的层级搜索；Table 1 用统一的方向/输入/指标/参数列同时呈现 efficacy 与 efficiency；Table A8 用结构化 bridge 对比 FC-Bridge，直接把 architecture claim 变成可检验反事实。
5. **最大叙事缺口**：一是“comparable or superior”在六方向和三个指标上并非一致成立，二是“exact alignment ⇒ identical prediction”没有近似误差或收敛分析，三是“any model/modality”和“modality-agnostic”由有限 backbone/数据覆盖支撑不足；另有 ISRUC 预处理中的 PPG 句子增加复现歧义。
6. **可迁移规则**。若论文声称轻量 bridge 同时带来性能与效率，应把“连接点选择的诊断量、桥结构、主结果、结构替代消融”放在同一因果链，并在附录给出完整离散量和失败切片，同时以项目特定证据补足聚合指标对 superiority 的支持。
7. **适用边界**：该规则适用于有 paired/unlabelled 数据、两侧 backbone 可冻结且存在可定义中间表示的跨模态迁移；当没有 paired data、没有每模态预训练模型、任务需 task-agnostic、多模态超过两种或目标是跨数据集泛化时，本文证据只能标为 open/future work。
