## 4. Related work：分类与近邻差异

- **Scaling laws**：kernel/random features/NTK 属于 lazy regime；Bordelon 等与 Worschech–Rosenow 延伸到 trained linear networks。本文把缺口定义为 nonlinear/genuine feature learning。[证据 p3–4 §1.2]
- **近邻 contrast**：Ren et al. 与 Ben Arous et al. 的 sublinear width、orthogonal first layer、power-law second layer 与本文不同；本文使用 ERM、`λ>0`、`∆≥0`，而被比较工作采用 noiseless/unregularized 或特定 SGD dynamics。[证据 p4 §1.2]
- **Spectral properties**：已有工作观察 weight/activation heavy tails，或分析 single/few gradient steps、mean-field limits；本文声称给出 trained weights 的 analytic characterization。[证据 p4 §1.2]
- **AMP/SE**：既有 formal guarantees 通常固定 `n/d` 与 `λ`；本文超出该范围使用 SE，并把 numerical agreement 作为支持。[证据 p4 §1.2；p9 §2.4]
- **Compressed sensing**：LASSO 与 matrix compressed sensing 的 quasi-sparse/minimax 结果是基础；本文主张补全各 regularization/data scale 的 phase diagram，同时覆盖多个 rate。[证据 p4 §1.2]

相关工作随后没有逐项重复方法，而是承担“lazy→feature learning、empirical spectrum→analytic spectrum、rigorous SE→heuristic extension”的定位功能；其引用在 p5、p9、p17、p41 的 rate/SE/对照论证中继续发挥作用。

## 5. 方法与理论链

### 5.1 两个 exact reductions

- **ERM/teacher–student**：式 (1) 以 `W∈R^{p×d}`、`a∈R^p` 为优化变量；式 (2) 以同架构 teacher 加 Gaussian noise 生成 labels；式 (3) 在 `x∼N(0,I_d)` 上定义 excess risk。[证据 p1–2]
- **Diagonal network**：`p=d`、`W=diag(w)`、linear/no bias；`θ_i=a_iw_i/√d` 将表达能力仍为线性，但 ℓ2 decay 的 factorization 诱导 ℓ1 sparsity，得到式 (5) LASSO。[证据 p2]
- **Quadratic network**：centered square activation 写成 `Tr[SZ]`，`S=WᵀW/√(pd)⪰0`，`Z=(xxᵀ−I_d)/√d`；weight decay 对应 trace/nuclear penalty，式 (7) 是 PSD matrix sensing。[证据 p2]
- **Power-law target**：diagonal `θ_i*∼N(0,d i^{-2γ})`；quadratic `S*` rotationally invariant，eigenvalues `{√d i^{-γ}}`，`γ>1/2`。[证据 p3]

### 5.2 Appendix A 的等价性证明

A.1 先逐坐标用 AM–GM：`u_i²+w_i²≥2|u_iw_i|=2|θ_i|`，再取 `u_i=sign(θ_i)|θ_i|^{1/2}`、`w_i=|θ_i|^{1/2}` 达到 equality，完成网络目标与 LASSO loss 的 exact equivalence。A.2 把 centered quadratic network 写成 PSD matrix model；centering 只移除 constant offset，Frobenius decay 变为 `tr(S)`，再以 matching-covariance Gaussian/GOE measurements 作为 AMP 分析的 universality replacement。[证据 p15–17 §A]

### 5.3 AMP/SE 到 risk/spectrum

GAMP 的 generic update（式 (30)–(32)）包含 Onsager terms；proximal denoisers（式 (33)–(36)）在 fixed point 给出凸 ERM minimizer。Theorem 1（p20，informal）把 iterates 弱收敛到高斯变量，给出 overlap 和 risk `Q*−2m+q`。LASSO 的 denoiser 是 soft threshold，式 (46)–(49) 将风险收缩为 `ν` 的 self-consistency；式 (51)–(53) 解释 signal/noise bulk 与 cutoff。quadratic 则以 GOE spectral measure、Hilbert-transform/BBP expansion 和式 (20) 的 `J(δ,λε)` 处理。[证据 p20–23、p31–39]

## 6. Main results：风险、谱与相图

### 6.1 Noisy phase diagram（Result 1）

定义 `n_eff=n`（diagonal），`n_eff=n/d`（quadratic）。对 `∆>0`、`n_eff≫1`，式 (11) 的关键分支为：

|阶段/条件|风险阶|机制|
|---|---|---|
|Ia/Ib 或 otherwise|`Θ(1)`|数据稀缺或强正则使 estimator 近零|
|`1≪n_eff≪d`、`λ≪√(n_eff/d)`|`Θ(n_eff^{-1+1/(2γ)}+ρ(n_eff/d))`|feature learning rate 与 noise-overfit correction|
|`n_eff≈d`、`λ≪1`|`Θ(λ^{-2/3})`|interpolation peak|
|`n_eff≫d`、`λ≪√(n_eff/d)`|`Θ(d/n_eff)`|大样本快速衰减|
|`max(√(n_eff/d),n_eff/d^{γ+1/2})≪λ≪n_eff/d^{1/2}`|`Θ((λd^{1/2}/n_eff)^{2−1/γ})`|强 thresholding/未学到尾部|
|`√(n_eff/d)≪λ≪n_eff/d^{γ+1/2}`|`Θ(λ²d²/n_eff²)`|更强 regularization 的 shift|

`ρ(t)=-1/log(t)`（diagonal）或 `t^{2/5}`（quadratic）；对角首个分支带 Appendix C.2 的 log factor。`n_eff^cross=(log d)^{(4γ−1)/(2γ−1)}`（diagonal）或 `d^{4γ/(14γ−5)}`（quadratic）。弱正则下风险随 `n_eff` 先降、在 `n_eff≈d` 因学噪声升、随后再降；红线边界处阶可不连续。[证据 p5–6 Result 1、Figure 1]

**Optimal regularization（Corollary 1）**：适当调 `λ` 可避开 Phase V；在 `1≪n_eff≪d^{2γ}`，最优风险为 `Θ(n_eff^{-1+1/(2γ)})`，在 `n_eff≫d^{2γ}` 为 `Θ(d/n_eff)`，其余为 `Θ(1)`。这把 LASSO 的 minimax rate 推到 quadratic matrix case，并说明“风险下降最快”与“Bayes-optimal”是不同层次的判断。[证据 p5–6]

### 6.2 Learned spectrum（Result 2）

Diagonal 的 estimator 是 `θ̂_i∼σ_{ε_d}(θ_i*+δ_dz_i)`；quadratic 的 empirical spectral measure 是 `F_{μ_δ}(λε)δ_0+μ_δ(x+λε)1_{x>0}`。因此 `δ` 表示 label noise/finite-sample effective noise，`λε` 是正则 cutoff；每一 phase 可读为 zero atom、near-zero bulk、aligned outliers 的组合。[证据 p6 式 (15)–(16)]

Figure 2 把 quadratic simulation histograms 与理论 bulk/spike overlay 置于 Ib/II/III 与 Ia/IV/VIa；Figure 6/7 在 Appendix C.2.1 对 LASSO components 做同类验证。图是机制读出，不只是展示 risk：零点/ bulk/ outlier 的出现顺序直接对应 phase transitions。[证据 p7 Figure 2；p28 Figures 6–7]

### 6.3 Universal error decomposition（Result 3）

对 quadratic `S*` eigenvalues `s_i`：

- under-regularization（`λε<2δ`）的式 (17) = overfitting bulk second moment + underfitting unlearned spikes + learned-spike approximation error；
- over-regularization（`λε≥2δ`）的式 (18) 去掉 bulk overfitting，只剩 unlearned features 与 learned-feature approximation。

作者将三项映射为：bulk = learned noise；被 bulk 隐藏的 spikes = unlearned features；outliers = learned features。强正则会压低 bulk，却可能增大 approximation error；弱正则学习更多 spikes，却在 near interpolation 学到 noise。[证据 p7–9 Result 3]

八个 phase 的结构性读法：

|phase|谱形状|风险含义|
|---|---|---|
|Ib|全零（rank collapse）|`R=Tr[(S*)²]/d`，数据不足+强正则|
|II|零点 + `N_out=(4n/(λd^{3/2}))^{1/γ}` outliers|风险由未学 spikes 与 shift，`Θ((λd^{3/2}/n)^{2−1/γ})`|
|III|目标 heavy-tail 的扰动版，bulk 左移 `≈λd²/(4n)`|`Θ((λd²/n)²)`|
|Ia|小段 semicircle + 很多零点|bulk 贡献可忽略，风险仍为 target power|
|IV|bulk + outliers，`N_out=(∆d/(4n))^{-1/(2γ)}`|bulk 次领先，`Θ((d/n)^{1−1/(2γ)})`，benign overfit|
|V|同样 bulk/outliers，但 bulk second moment 主导|接近 interpolation，开始 fit noise，风险回升|
|interpolation peak|大 semicircle bulk，scale `Θ(∆^{2/3}λ^{-1/3})`|`R=Θ(λ^{-2/3})`，noise 压倒 feature learning|
|VIa|小 bulk + bleed-out + outliers|风险 `Θ(d²/n)`，spike perturbation 主导|
|VIb|目标 heavy-tail 的扰动 bulk|同阶 `Θ(d²/n)`，但只有 VIb 达 Bayes-optimal rate|

这张表把“heavy-tailed spectrum associated with generalization”收紧为条件性机制：只有当 bulk noise 被抑制且 outlier/target tail 的信号结构保留时，heavy tail 与更好风险同时出现。[证据 p8–9]

## 7. Non-asymptotic state evolution：证据与边界

作者明示 formal AMP/SE guarantee 只覆盖 `n_eff,d→∞`、固定 `n_eff/d`（或 matrix case 的比例）和固定 `λ`；本文把方程启发式延伸到 arbitrary scaling。Conjecture 1 给出 quadratic ERM/Bayes 的 fixed-point expressions（式 (19)–(20)）与 `|R−R_n,d|=R_n,d·o_{n,d}(1)`，并把 LASSO 对应 Conjecture 2 放入 Appendix C。[证据 p9 §2.4；p21 §C.1.2]

- **数值支持**：Figure 3 的 `d=100,200,400,800`、`∆=.5`、`λ=1/d,1,√d`，dots 与 solid SE lines 在三个 λ 列上对齐；Figure 5 对 ∆=0 做同样复核。
- **统计边界**：曲线比较没有 error bars、seed 数、显著性检验或不确定性区间；“excellent agreement”是 visual agreement，不是 finite-size theorem。

## 11. Limitations 与不利信息呈现

### 11.1 明示限制

1. **Rigor**：SE 超出 proportional limit 是 heuristic/conjecture；non-asymptotic multiplicative bounds 留给未来（p9）。
2. **Architecture/optimization**：仅 global minimum 的 diagonal/quadratic two-layer ERM，GD/SGD compute scaling 与 implicit bias 未分析（p10）。
3. **Data/target**：isotropic Gaussian 与 power-law target；non-trivial covariance 等结构留作 future work（p2–3、p10）。
4. **Quadratic derivation**：BBP simplification 暂用 sub-extensive-rank `S*`，再后验令 `c→1`（p31）。

## 14. Final judgment

1. **单一主线**：用 sparse estimation 的 exact bridge 解释 feature-learning scaling，再用 spectrum 解释 risk。
2. **正文保留**：模型、target、统一样本轴、Result 1–3、主图与 SE caveat；足以做 phase/regularization/mechanism 判断。
3. **附录迁移**：证明、fixed points、逐 phase 计算、Bayes/ridge、数值实现；自足性只在定性层面成立。
4. **最有效模式**：exact reduction → shared `n_eff` → phase diagram → spectral decomposition → simulation overlay。
5. **最大缺口**：非渐近 SE 仍 conjectural；BBP rank simplification、无 seed/uncertainty、无 component ablation 增加复核成本。
6. **可迁移规则**：每个 scaling claim 同时绑定一个结构性、可观测的 error decomposition，并让图表复用相同 phase boundaries。
7. **适用边界**：仅可迁移到有 exact reduction/SE/可控谱的 convex/global-ERM 设定；不外推到一般 deep nonconvex SGD。
