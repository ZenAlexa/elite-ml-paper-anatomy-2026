## E. 方法与理论

### E.1 形式化对象与逻辑单元

- **对象／输入／输出**：目标表面 (M\subset\mathbb{R}^3) 及其点分布 (Phi_T)；SMPL 模板分布 (Phi_S)；每个 `(S,T)` 对应 latent `z_{T|S}`。生成输出是从流中采样的表面点／feature map，条件可包括 SMPL pose，novel-pose 任务再加入 frontal normal image（p. 4–6，锚点 “The dataset for our task consists of a set of pairs”）。
- **状态与目标**：Flow Matching 在 source (p) 与 target (q) 之间学习 velocity (u_\theta(x_t,t))；方法把 Gaussian source 换成 SMPL，并在配对后以位移 (Delta x=x_1-x'_0) 训练；第二阶段在 feature-map latent space 中生成分布（p. 3–5，锚点 “the source distribution closer to the target geometry distribution”）。
- **假设／前置条件**：论文明示 SMPL 顶点可提供 UV 坐标、法向与 canonical coordinates；目标几何能以表面点采样；flow matching 的 source/target 配对和 ODE 采样成立。没有单独的 theorem-style regularity assumption、误差界或复杂度假设，记为 `not_present`。

|---:|---|---|---|---|
| 1 | Flow Matching 定义（Eq. 1） | `setup_notation` | 需要把 source distribution 推到 target | p. 3，锚点 “transforms samples from a source distribution p to a target distribution q” |

### F.2 可复现实现粒度

附录补充了关键但不完整的训练粒度：每个几何 (2^{18}) 个 surface points，SMPL (2^{17}) 点，KNN 配对，每迭代随机 30,000 pairs；latent map 为 (mathbb{R}^{8\times24\times24})，层宽 256；AdamW、learning rate (8\times10^{-3})、cosine schedule、feature-map L2 权重 (10^{-4})（p. 15，锚点 “During training, we randomly sample 30,000 pairs per iteration”）。

Pose-conditioned 任务的 auto-decoder 训练两天、generation model 一天，使用两张 A100；随机丢弃 pose condition 的概率为 0.5。4DDress 任务的 auto-decoder 两天、generation model 一天，使用四张 A100，未使用该 condition dropping（p. 15，锚点 “randomly drops the pose condition with a probability of 0.5”）。模型参数 56.02M；解压一次 81 ms；1M points 每个 denoising step 529 ms、峰值 9522 MB；10,000 points 为 71 ms、1420 MB（p. 15–16，锚点 “The auto-decoder model has 56.02M parameters”）。

渲染时从 1M points 做 Gaussian Splatting，先生成 depth maps 再提取 normal maps；所有点使用由平均最小点间距确定的同一 scaling（p. 16，锚点 “We visualize our results by sampling 1 million points”）。代码仓库、确切数据 split、seed、denoising step 数、参与者招募与随机化、评级聚合规则均为 `not_present`。

## I. 结论、limitations 与闭环

### I.1 结论逐段编码

`7 CONCLUSIONS` 只有一个段落（p. 9，约 152 词）：

1. `重述问题／方法`：提出 generative human geometry distribution、distribution-over-distribution、SMPL→target flow、compact feature maps。
2. `回收结果`：state-of-the-art quantitative performance、fine-grained clothing details、pose conformity。
3. `回收边界与 robustness`：mismatched pose feature map 仍能生成 plausible result。
4. `impact`：强调 3D human modeling/synthesis 潜力。

该段未新增数字；“only one capable”“novel, unique”属于加强版新颖性措辞，需按范围主张读取（p. 9，锚点 “the only one capable of producing fine-grained geometry”）。

### I.2 作者明示 limitations

1. **非均匀 target sampling**：每个 `x′0` 关联的 `x1` 数目不同；足够采样和移除过近点可缓解，作者建议更先进 pair construction（p. 9，锚点 “the number of target points x1 associated with each SMPL point”）。
2. **数据集覆盖**：body types 的合理多样性带来泛化，但训练集中完全没有的 clothing styles 无法生成（p. 9，锚点 “cannot generate clothing styles that are entirely absent”）。
3. **UV seam artifacts**：UV maps 的 discontinuity segmentation 会在部分 random results 产生 seam；作者建议与真实 garment patches 对齐（p. 9，锚点 “UV maps can cause seam artifacts”）。
4. **极端局部稀疏**：附录 Figure 15 明示极端 loose clothing/hair 可能有 small local sparsity，但总体几何质量维持较高（p. 17，锚点 “may exhibit small local sparsity in extreme cases”）。
5. **mismatched feature 的自然度**：附录说明 wrinkle details 可能不完全自然（p. 17，锚点 “wrinkle details may not be entirely natural”）。

- **对比／因果词**：`however`、`in contrast`、`rather than`、`instead of`、`while`、`although`、`therefore`、`to address`、`because`、`to alleviate`、`leading to`、`stems from`、`enabling`。其中 `leading to` 常把设计动机连接到质量结果，需与实证检验区分。
- **叙事包装**：引言将“single geometry → dataset → feature-map latent → two-stage generation”作为单向升级链；方法中的两个设计改变分别对应 scalability 与 flow efficiency；实验顺序沿该链展开。结论再次使用 `first/only/unique`，形成强新颖性回收。
- **切分风险**：`w/o Pairs`、`w/o DistNorm`、`x′0`、`zT|S`、`uθ`、`4DDress`、`high-fidelity`、`pose-conditioned`、`state-of-the-art` 和 `distribution-over-distribution` 不应拆成普通词；作者名引文（`et al.`）、公式变量、表格行名会污染机械二元／三元词频。

## L. 最终判断

1. **单一主线。** 论文把“高保真人体几何的 dataset-scale 分布学习”作为单一瓶颈：以 SMPL template 作接近目标的 source，借 sparse-KNN 配对和中心化 displacement 形成易学 flow，再把每个几何分布编码成 UV 对齐的 2D latent feature map，最后在 latent space 进行两阶段生成。这个主线由 Eq. 2–6、Table 2–4 和两项任务共同回收（p. 4–9，锚点 “By building flow between regularized dense spaces”）。
2. **正文保留的决策内容。** 正文保留 source/target 选择、pair construction、normalization、feature-map decoder、两项条件、Chamfer／Surface Distance／FID、user study 和三项 limitations；读者可据此判断表示选择与任务结果。
3. **迁移到附录的细节及代价。** 点数、KNN、latent 尺寸、optimizer、训练时长、GPU、内存、Chamfer 曲线和大量姿态／体型案例移入附录。正文仍能理解算法，但复现预算、split/seed 和用户研究程序并未补齐；附录扩大定性覆盖，却没有补足不确定性统计。
4. **最有效的写作、图、表、公式模式。** Eq. 2→3→4 把“source 对齐、短配对、中心化”拆成可消融的连续机制。Table 2 同时给 single/dataset 行，直接暴露 w/o DistNorm 的局部优点与 dataset 退化。Figure 4 将 decoder 与生成条件并列，降低分布编码到下游任务的理解成本（p. 4–7）。
5. **最明显的规避、未闭合主张与读者成本。** “significantly”没有检验；57% 端点算术需复核；FID raw/enhanced 混列、用户 study 聚合细节和数据 split 缺失，令跨方法与跨样本外推成本上升；结论的 “only/unique” 没有穷尽性证据。附录虽公开很多工程数字，却未公开 seed、参与者信息或失败分母（p. 8–20）。
6. **可迁移规则。** 当一个表示同时宣称细节、规模和姿态一致性时，按“表示对象 → 可学习路径 → 条件编码 → 任务指标 → 反例／边界”的顺序安排公式、消融和结果，并在同一表中保留局部与数据集尺度的反例。
7. **适用边界。** 该规则适用于有明确中间表示、连续优化路径和多尺度实验的生成论文；若任务只有离散预测、理论证明或无可比的 dataset-scale 训练，则应改为“定义对象 → 证明条件 → 识别实验”链，不能机械套用 flow／Chamfer／FID 模板。
