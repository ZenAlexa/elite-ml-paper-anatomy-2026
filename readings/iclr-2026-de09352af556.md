## 5. 方法、理论、公式与算法

### 5.1 形式化对象与主线

- **任务与状态。** 单 advertiser 在 sealed-bid second-price auction 中受预算 `B` 约束；impression `i` 的 bid 为 `a v_i`，当 `a v_i ≥ p_i` 时获胜并支付 `p_i`，`ROI=v_i/p_i`，`R_m=max_i v_i/p_i`。Scaling factor `a` 每 `T` 个时间步重新校准。MDP 状态为 `s_t=[t, c̄_{t−1}, x]`，动作是 calibrated scaling factor `a_t`，奖励 `r_t` 是下一时间段赢得 impression 的 value，目标是 Eq. (1) 的累计 reward 与预算约束。【p.2 §2.1，Eq. (1)】
- **离线与 AIGB。** Offline dataset `D` 保存 historical states/actions/rewards。Offline RL 用 TD error（Eq. (2)）学习 Q；AIGB 用条件 generative model 拟合 `p_θ(τ|y(τ))`（Eq. (3)），令 `y*=(1+ε)y_m` 进行 planner–controller 推理；controller 是 off-the-shelf inverse dynamics model。AIGB 的外推条件超出 `y_m`，但没有显式 reward feedback。【p.3 §2.2–2.3，Eq. (2)–(3)】
- **AIGB-Pearl。** Evaluator `ŷ_ϕ(τ)` 在 `D` 上用 supervised loss 学习 trajectory quality，固定 `y*` 后让 planner 最大化 `L(θ)=E[ŷ_ϕ(τ)]`（Eq. (4)）。真实性能 `J(θ)=E[y(τ)]` 与 score 的差距从 Eq. (5) 开始分析。【p.4 §3，Eq. (4)–(5)】
- **约束链。** Theorem 1 给出真实 quality 的 `√T R_m`-Lipschitz 性；Theorem 2 把 evaluator bias 分解为 training bias `δ_D`、condition sensitivity 的 Wasserstein 距离和 offline imitation error。Eq. (6) 以 planner Lipschitz 常数控制第一项，Eq. (7) 以 KL 约束控制第二项，Eq. (8) 将 score maximization 转成 KL-Lipschitz-constrained optimization。【p.4–5 §3.1，Theorem 1–2，Eq. (5)–(8)】
- **性能保证与实现。** Theorem 3 的 Eq. (9) 给出 `J(θ*)−J(θ̂)` 上界；Eq. (10) 给出 planner `L_p` 至少应覆盖 offline conditional trajectory distribution 的 Lipschitz constant。Evaluator 用 Eq. (11) 的 point-wise MSE + Lipschitz penalty，planner 用 Eq. (12) 的 score、conditional behavior cloning、Lipschitz penalty，并以 Eq. (13) 的 synchronous shared-noise coupling 估计 Wasserstein upper bound。【p.6–7 §3.1.1–3.2.2，Eq. (9)–(13)】

段落动作序列是 `setup_notation → state_problem → derive → define_component → explain_mechanism → connect_to_prediction → instantiate_algorithm → connect_to_experiment`。核心因果链是「离线 AIGB 无 feedback → evaluator 提供 score → bias bound 暴露 sensitivity/imitation 两项 → KL + Lipschitz 约束 → synchronous coupling 可训练 → 安全外推」。

## 12. 最终判断

1. **单一主线。** 论文把 AIGB 的 offline conditional generation 接上一个 learned trajectory evaluator，再以 evaluator bias 的 Wasserstein 分解导出 KL behavior cloning 与 Lipschitz sensitivity 约束；synchronous shared-noise coupling 将约束转成可训练的 planner loss，从而在 `y* > y_m` 的外推条件下进行受限 score maximization。【p.3–7 §3，Eq. (4)–(13)】
2. **正文保留的决策内容。** 正文保留任务形式化、AIGB 缺口、核心 evaluator/planner 结构、Theorem 1–3 的陈述、Eq. (8) 目标、4 个 RQ、主性能表、约束消融、Lipschitz sample 检查和 evaluator train/OOD accuracy。这些对象足以判断方法是否回答了“如何安全地把 reward feedback 引入 AIGB”。
3. **附录迁移及影响。** 附录承载 AIGB diffusion details、完整 proof、Algorithm 1、硬件／dataset／hyperparameters、TargetROAS、10-seed stability、multi-modal distribution、LLM/pairwise loss、`δ_K` tuning、first-price/online scope。方法骨架仍自足；理论常数、训练可复现性和机制因果归因需要附录，迁移使正文的安全与稳定主张保持部分闭合。
4. **最有效的模式。** Eq. (5) 的 bias 差距 → Eq. (6)/(7) 两个可控 Wasserstein 项 → Eq. (8) 约束目标 → Eq. (9)/(10) bound/tuning → Eq. (11)–(13) 实现 loss，形成从风险到约束再到算法的连续链。Figure 1 提供几何解释，Figure 2 提供组件流程，Table 4 把两项约束分别删除，三者共同支撑读者从机制到行为的阅读。
5. **最大缺口与读者成本。** Theorem 3 是显式 upper bound，但主文与附录没有直接测量 bound tightness 或 `δ_D,δ_M,k,δ_K,L_p` 的联合影响；random coupling 与 synchronous coupling 没有 matched ablation；真实 A/B 主表多数是单点 aggregate，traffic split、随机化、per-advertiser variance、成本和污染控制缺失。AIGB-Pearl、TargetROAS、first-price、online 的范围在不同附录段落中分散，读者需要拼接适用边界。
6. **可迁移规则。** 对需要在 offline data 外探索的生成式决策方法，正文应按「反馈／误差来源 → 可证书的分布距离或正则约束 → 可训练 surrogate → matched mechanism ablation → 失败判据」排列；每一个安全或稳定性主张都应有对应的过程量或重复性统计，而非只由最终业务分数代理。
7. **规则边界。** 该规则适用于存在可定义 trajectory quality、分布距离和可操作约束的 offline sequential decision-making。若任务没有可观测 reward、只能做一次线上 A/B 或约束本身不可估计，应把 theorem/安全语言降到展示出的数据范围，并把 online、外部策略和失败分母明确列为未闭合项。
