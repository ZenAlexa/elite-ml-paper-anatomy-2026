## 一页结论

论文的单一主线是：把 GRPO 风格 RLVR 简化为固定 prompt 下、由「正确／错误 reasoning modes」组成的多臂 bandit；在 z-score group normalization 的小步长 mean-field 极限，错误模式总质量 `p(t)` 的漂移符号只由 `J = TPR − FPR` 决定。`J > 0` 时 `p` 向零收敛，`J = 0` 时确定性漂移消失，`J < 0` 时 `p` 向一收敛；于是 verifier 噪声在符号正确时改变收敛速率，在符号翻转时改变终局。[PDF pp. 6–9, §§2.1–3.2, `explicit`, anchors= `Law of Motion`; Eq. (6); `Rate, Not Fate`]

最强的理论闭环由三层组成。Eq. (5) 将 good–bad normalized-advantage gap 写为 `J/σ(p)`；Eq. (6) 给出二类 bad-mass ODE；Theorem 6.1 把结论推广到多 good／multi-bad blocks、PPO ratio clipping 与 fresh on-policy groups 的一阶 mean-field 情形。Appendix E 的 Lyapunov 结果再用全局稳定性补足「符号决定相面」的主张。[PDF pp. 6–7, 15, 33–35, §§2.2, 3, 6, Appendix E, `explicit`, anchors= Eq. (5); Theorem 6.1; `Dichotomy by the sign of J`]

实证只覆盖一个受控、合成噪声的 Python code-generation 配方：Qwen2.5-3B、10,239 training prompts、594 validation prompts、`G=8`、1,410 steps、每个配置五个 seed。Figure 1 与 Table 1 显示 `J<0` 的验证 `pass@1` 下降、`J=0` 接近基线、`J>0` 的有限训练轨迹上升；作者同时明确两 epoch 不能判定精确渐近终局。因此 H1 的边界有直接受控证据，H2 的「同一最终 basin」由 ODE 闭合，实验仅提供有限时域一致性证据。[PDF pp. 2, 17–18, §§7.2–7.3, `explicit`, anchors= `five independent runs`; `remain agnostic`; Table 1]

正文把可读决策链留在 20 个物理页中：早期题图和 Figure 1–3 先提出 phase-transition 叙事，随后给出 binary reduction、mode coarse-graining、simplex geometry、Theorem 6.1 与一组 coding 实验。40 页 appendix 承担 bandit formalization、推导、Lyapunov／geometry proof、good/bad inner dynamics、超参数、noise wrapper 和一个数据样例。正文足以审查主张的前提和方向；要复核模型化、`O(η²)` 保留项、KL equilibrium、完整训练细节或 test-harness 样例，必须进入 Appendix A–N。[PDF pp. 1–20, 23–62, `layout_observation`, anchors= `Appendix A`; `Hyperparameters and Training Details`; Algorithm 1]

## 方法、理论与算法闭环

### 最小逻辑单元与转移

1. **GRPO sequence loop**：§2 先给 rollout、scoring、group normalization、policy-gradient update 四步。对象是 prompt `x`、`G` completions、raw reward `rᵍ`、normalized advantage `Âᵍ` 与 parameters `θ`；输出是 update `Δθ`。[PDF pp. 4–5, §2, `explicit`, anchors= `Sampling`; Eq. (3)]
2. **binary reduction**：以 `p=Pr(bad)`、logit `z` 和 class-conditional expected advantage，把 update 化为 Eq. (4) 的 replicator skeleton。此步解决「噪声如何进入学习方向」的问题。[PDF p. 6, §2.1, `explicit`, anchors= `two-class reduction`; Eq. (4)]
3. **noise mechanism**：Eq. (1)–(2) 定义 flip rates 与 `J`；Eq. (5) 给 `E[Â|good]−E[Â|bad]=J/σ(p)`。这里 `J` 是 good/bad advantage gap 的符号来源。[PDF pp. 4, 6, §§1, 2.2, `explicit`, anchors= `purely geometric form`; Eq. (5)]
4. **phase law、tails与支持条件**：Eq. (6) 推出三相；Eq. (8) 给 clean case 轨迹；p. 8 明确 `p₀=1` 是 absorbing support barrier；p. 9 用 Eq. (9) 讲 rate rescaling。[PDF pp. 7–9, §§3–3.2, `explicit`, anchors= `THREE LEARNING REGIMES`; `support barrier`; Eq. (9)]
5. **mode coarse-graining**：§4 把 finite-length sequence support 经 `ϕ:Y≤Lmax→H` 映到 modes，拆成 good family `y`、bad family `z`、outer bad mass `p`。该步把 LLM completion abstraction 接到 multi-arm dynamics。[PDF pp. 9–10, §4, `explicit`, anchors= `coarse-graining map`; `total probability mass on incorrect modes`]
6. **simplex geometry与decoupling**：softmax Jacobian `J(p)=Diag(p)−ppᵀ` 规定 tangent flow；Eq. (12a–c) 把 within-good polarization、within-bad smoothing、outer bad mass 拆开。Figure 4 是此图像化解释。[PDF pp. 11–12, §5.1, `explicit`, anchors= `Decoupling the Dynamics`; Eq. (12a–c)]
7. **finite sampling**：§5.3 把 finite `G` 与 reward noise 分开，采用 Wright–Fisher-shaped diffusion 作为 `O(G⁻¹/²)` fluctuation explanation；没有把它接成有限-`G` 的 phase-boundary proof。[PDF pp. 13–14, §5.3, `explicit`, anchors= `Finite Sampling Cause Genetic Drift Noise`]
8. **practical GRPO theorem**：§6 先限定 `η≪ε,ε′`、fresh on-policy groups；Theorem 6.1 给 Eq. (14) 的 multi-block ODE、internal-time logit form 和 small-heterogeneity correction。Appendix F 将 clipping/IS 的影响限于 `O(η²)`。[PDF pp. 14–15, 36–37, §6, Appendix F, `explicit`, anchors= `Theorem 6.1`; `O(η2)`]
9. **KL intervention**：Eq. (18) 把 reward drift 加到 KL restoring drift；Eq. (19)、Theorem G.6 给 fixed `y,z` 下 unique stable interior equilibrium。实验设定取 `β=0`，因而这个 intervention 没有 training comparison。[PDF pp. 15–17, 38–42, §6.1, Appendix G, `explicit`, anchors= `unique globally stable fixed point`; `β = 0`]

## 实验设计、统计与结果

### 设计与复现粒度

- **预先列出假设**：§7.1 显式给 H1 `Phase Transition at J=0` 与 H2 `Rate, not Fate`。H1 是 finite-horizon observed direction 的预测；H2 同时包含 ODE basin claim 与「more steps/rollouts」的叙述。[PDF p. 16, §7.1, `explicit`, anchor= `Our analysis makes two sharp predictions`]
- **任务与资料**：filtered OpenR1 subset，`Ntrain=10,239`、`Nval=594`；每题有 natural-language spec、I/O examples 和 public/hidden tests。Appendix N 给 `kMarsh` 的一个完整 prompt/test sample，而非完整 dataset manifest。[PDF pp. 17, 61–62, §7.2, Appendix N, `explicit`, anchors= `Ntrain = 10,239`; `Data Sample`]
- **模型与训练**：Qwen2.5-3B；standard GRPO、VeRL、`G=8`、group returns z-scored、`β=0`。Appendix L 给 batch 16、1,410 steps、2 epochs、temperature 1.0、PPO clip 0.2、Adam `10⁻⁶`、weight decay 0.1、max prompt/response 4,000；evaluation greedy temperature 0.0。[PDF pp. 17, 60, §7.2, Appendix L, `explicit`, anchors= `Each group contains G = 8`; Table 4]
- **噪声操纵**：oracle correctness `z` 经 Bernoulli wrapper 产生 `r`；扫描 `J∈[-0.1,1]`，每个 target `J` 可有多个 `(TPR,FPR)` factorization。Algorithm 1 把对应 wrapper 写成可执行伪代码。[PDF pp. 17, 61, §7.2, Appendix M, `explicit`, anchors= `multiple (TPR, FPR) factorizations`; Algorithm 1]
- **控制与顺序**：每个 `J` 两 epoch、1,410 steps、每五步记录、五个不同 seeds，其余 hyperparameters 固定。baseline 是 `J=1` noise-free GRPO；`β=0` 有意隔离 reward-driven drift。没有跨模型、跨任务、different `G`、different clipping 或 KL 的主结果设计。[PDF pp. 17–18, §7.2, `explicit`, anchors= `All other hyperparameters remain fixed`; `performance ceiling`]
- **统计单位与不确定性**：`E[pass@1]` 是 validation problems 的 fraction，再跨五个 independent runs 聚合。Figure 1 caption 明示 solid line 为 run-averaged `E[pass@1]`，shaded band 为 across-runs 95% confidence intervals；§7.2 文字称报告 mean and standard deviation，但 Table 1 只显示 point values/improvement，未列出 SD、interval construction、hypothesis test 或 multiple-comparison procedure。[PDF pp. 2, 17–18, Figure 1, §7.2, Table 1, `explicit`, anchors= `five independent runs`; `shaded bands indicate 95% confidence intervals`; `mean and standard deviation`]

### 消融、负面结果与自我设限

- **噪声强度／符号 sensitivity**：`J=-0.1,0,0.3,0.7,1` 直接扫 H1；它是 mechanism/sensitivity test，不是 method component deletion。[PDF pp. 17–18, §7.2–7.3, `explicit`, anchor= `We explore a grid J`]
- **同一 `J` 的 error-type 对照**：Table 1 的两组 `J=0.3` conditions 识别 FPR/FNR composition 对 finite-time performance 的影响，是唯一明确的 within-`J` ablation-like comparison。[PDF p. 18, §7.3, `explicit`, anchor= `(FPR=0.00, FNR=0.70)`]
- **KL isolation**：`β=0` 的选择是设计控制，用来隔离 unregularized drift；它不提供 β-ablation 的 comparative result。[PDF pp. 17, 60, §7.2, Appendix L, `explicit`, anchors= `to isolate the pure reward-driven dynamics`; `KL coefficient (β) 0.0`]
- **没有 dedicated component-removal、rollout-count、model-scale、task-heterogeneity 或 real noisy-verifier ablation**：主结果页只有 fixed recipe 的 noise conditions；其他因素保留在理论或 future directions 中。[PDF pp. 16–19, §§7.1–7.4, `layout_observation`, anchor= `All other hyperparameters remain fixed`]
- **作者主动限制**：finite test suite 使 `(TPR,FPR)` estimates 有 bias；truncated responses 被置零会造成 systematic FNs；task/model narrowness 限制 generalization；time-dependent noise 被理论允许但没实验；`p₀=1` 支持边界使 RLVR 不会凭空创造 correct mode。[PDF pp. 8, 18–19, §§3.1, 7.4, `explicit`, anchors= `support barrier`; `finite test suite`; `fixed noise rates`]

## 可迁移规则与边界

**规则。**当论文声称一个复杂训练系统存在 sharp qualitative boundary 时，正文宜将主张压缩为可观测 scalar，先写出该 scalar 如何进入 update 的方向项，再写出可检验的 phase prediction，最后用一个主动操纵该 scalar 的受控设计呈现正、零、负条件。RLVεR 的 `J → advantage gap → ṗ → H1/Table 1` 链条清楚；KL、clipping 与 multi-mode details 留到后面再扩展，不阻断第一条阅读路径。[PDF pp. 4–7, 15–18, `interpretation`, anchors= Eq. (5); Eq. (6); `Phase transition confirmed (H1)`]

**适用边界。**这条规则适用于 reward corruption 可被可解释地参数化、主要结果可通过 controlled intervention 观测的工作。它不自动支持真实 LLM verifier、time-varying noise、mode-clustering validity、finite-step PPO dynamics 或 H2 的渐近终局；这些情形需要单独测量 verifier、expose initialization/support、报告 finite-sampling uncertainty，并用足够长的训练或可验证的 stopping criterion 连接 ODE 到训练轨迹。[PDF pp. 8, 14–19, `explicit`/`interpretation`, anchors= `support barrier`; `small-step regime`; `fixed noise rates`]
