## E. 方法与理论

§2 定义每层函数 `f_i`、程序 `π=(i_1,…,i_K)` 与组合函数 `F_π`；正确输出即 valid program。核心 conjecture 是同一输入可有多个超出 standard forward pass 的正确执行。MCTS 仅用于验证存在性和分析结构，非部署算法（p.2–3）。Appendix B 将 skip/repeat block size 与 repetition count 限为 `k,r≤4`，根节点为 standard path，奖励为正确性，UCB 加入长度惩罚；Algorithm 1 以 selection、expansion、simulation、backpropagation 收集程序。`N_sim` 的具体值未提供（p.14–15）。

POLAR 将 D 层划为连续 segment，`K_max=4`。每段选择 `skip`、`keep` 或 `repeat`；repeat 只执行一次额外 pass。边界 mask `z_seg` 与操作向量 `z_op` 构成程序表示。预测器用冻结 `Qwen3-Embedding-0.6B` 编码输入，以 layer embeddings 做 cross-attention，再在 layer dimension 上用轻量 transformer encoder，两个 linear heads 预测 boundary 和 operation logits。推理先 threshold boundary、强制切分过长 segment，再用 segment-level beam search 得到候选程序（p.5–6 §3.1–3.2）。

监督来自 offline MCTS valid programs。若存在比 full-depth 更短的 valid program，full-depth loss 被降权；论文未给权重。训练目标是 boundary BCE 与 segment-start masked operation CE 之和。方法动作序列为：`setup_notation → define_component → give_intuition → explain_mechanism → instantiate_algorithm → derive → connect_to_prediction → connect_to_experiment`。

公式计数：约 20 个独立 displayed blocks（正文 §2 约 3，§3 约 12，Appendix B 5），编号公式 0；无 theorem、lemma、proposition、corollary 或 proof。公式承担程序定义、表示、损失和 MCTS 诊断的核心链。

## F. 实验设计

- 模型：LLaMA-3.2-3B-Instruct、Qwen1.5-MoE-A2.7B-Chat、Qwen2.5-3B-Instruct、Qwen3-8B；基础模型完全 frozen（p.7）。
- ID 数据：DART-Math DM-1–DM-5；Appendix D.1 去重后样本数 565、1,349、1,579、1,537、1,577，train/validation/test 约 62.5%/12.5%/25%，总计 4,130/826/1,651（p.21）。
- OOD：ASDiv、MAWPS、MMLU-Pro 的数学、自然科学、社会科学和人文学科子集；DART-Math 全难度训练后 zero-shot（p.7–8）。
- 指标：`pass@k` 为 top-k 候选至少一个正确的概率；POLAR 用 beam programs，Base sampling 用温度 0.3、0.7、1.0 的采样；OOD 默认 pass@1（p.7）。
- 训练：AdamW；learning-rate grid `{1e-4,3e-4,5e-4,8e-4,1e-3,3e-3}`，batch `{32,128,256}`，epoch `{3,10}`，cosine schedule、linear warmup（p.21）。
- 提示：direct prompting，禁止 chain-of-thought，要求只输出 `\boxed{ANSWER}`（p.21–22）。
- 基线：Base greedy/sampling、ShortGPT、MindSkip、FlexiDepth、DR.LLM（p.7）。
- 控制：ID 难度内划分、OOD zero-shot、统一 frozen setting；未报告 seed、重复次数、题目级失败计数、置信区间、显著性检验、数据泄漏审计或 beam width/threshold。
- 复现：p.1 给出 GitHub 项目 URL；MCTS 的 `N_sim`、搜索时长和训练／推理随机性仍缺失。

## L. 最终判断

1. 单一主线是“用受限 MCTS 发现多种 layer execution，再把连续 segment 和少量 recurrence 编码为 input-conditioned predictor”，从逐输入搜索转为一次预测。
2. 正文保留 conjecture、四个 Finding、表示与损失、主表、OOD 代表性结果、pass@k scaling 和 latency，足以理解设计选择与主效果。
3. 搜索算法、完整模型结果、去重与训练网格、prompt 移入附录；迁移提高叙事密度，却使 `N_sim`、seed、beam width、threshold 和成本判断不完整。
4. 最有效模式是“现象 → 结构统计 → 表示约束 → 部署测量”：Figure 4–7 直接把更短程序、难度、连续 segment 和 single-repeat 连接到 §3。
5. 最大缺口是 predictor 对 MCTS supervision 的依赖及其成本、随机性没有量化；OOD 与效率也只覆盖选定 benchmark 和单一 latency case。
6. 可迁移规则：先报告搜索空间中有效解的结构，再把高频结构转成表示约束，并分别用 scaling、短程序和端到端 latency 证据回收能力、效率和可部署性。
7. 适用边界是存在可靠 correctness signal、离散控制动作和可冻结基础模型的 test-time adaptation；无逐题 validity 或需要复杂长程重排的任务不应直接采用 `K_max=4`、single-repeat 假设。
