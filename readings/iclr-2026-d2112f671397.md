## 6. 方法与理论

### 6.1 形式对象、组件与数据流

- 输入是场景图像 (I) 与 fixation locations；DINOv2-Base with registers 将 448×448 图像划成 14×14 patches，得到 32×32 的 1,024 patch tokens，每 token 768 维，另有 CLS 与 4 个 register tokens（p.3，§3.1）。
- foveal stream 在 original image 的 DINOv2 patch tokens 上施加 binary `M_fixation` mask，仅保留 fixation 对应 patch；peripheral stream 将图像下采样后再上采样回 448×448，并保留全部 patch tokens（p.4，§3.1）。
- 两个 stream 各自经过 Perceiver-based resampler，将 1,024 个 DINOv2 embeddings 压到 32 个 conditioning tokens，再分别进入 Stable Diffusion UNet 的 cross-attention（p.4，§3.2）。
- text conditioning 保持为空字符串；foveal 与 peripheral 通过独立 key/value projections 和加权 cross-attention 相加。训练时只更新两个 resampler 及其 key-value projection matrices，Stable Diffusion 1.5 主体保持预训练状态（p.5，§3.2–3.3）。

### 6.2 方法动作序列

`setup_notation → define_component → explain_mechanism → define_component → instantiate_algorithm → derive → derive → contrast_alternative → instantiate_algorithm → state_complexity → connect_to_prediction → connect_to_experiment`。

其中 binary mask 解决稀疏 fixation 与全场景重建之间的信息缺口；peripheral tokens 提供全局 layout/context；两个独立 resampler 解决 variable-length/dual-source 输入与固定 cross-attention token 接口之间的维度问题；lambda scaling 让 detail 与 plausibility 共同进入去噪。

### 6.3 训练、推理与质量评测

训练使用完整 MS-COCO training set，约 118,000 张图；foveal mask 随机保留 `{1, 2, 3, 5, 10}` 个 patch tokens，peripheral blur 使用 `{0.0625×, 0.125×, 0.25×, 0.5×, 1×}` 下采样尺度。condition dropout 为 `p_foveal=0.05`、`p_peripheral=0.10`；推理采用 DDIM 50 timesteps、CFG++，`λ_foveal=1.2`、`λ_peripheral=0.7`（p.5，§3.3）。Appendix A.2 补充 200K steps、batch size 32、4 张 NVIDIA H100、AdamW、learning rate `10^-4`、weight decay 0.01、512×512 RGB 输出。

Figure 2 用 COCO-10k-test 与 FID10K 评估生成质量：固定 blur level 为 0.25× 时改变 peripheral scale；也扫 blur level，并与使用 COCO training captions 的 SD-1.5 text-to-image baseline 比较。图中绿色曲线随 peripheral scale 增大而下降，红色 blur 曲线维持较低 FID，蓝色 baseline 较高；正文没有给出各点数字表。

论文主动解释生成不是 input image 的逐像素复现，依据是 DINOv2 embedding 的 lossiness 与 sampling stochasticity，并将进一步证据指向 Appendix A.7–A.8（p.5）。

## 7. 实验设计

### 7.1 主行为范式

- **研究问题**：稀疏 fixation 与 peripheral gist 生成的图像能否达到 human scene understanding 的 perceptual equivalence；fixation count 与 feature hierarchy 如何影响 metamer judgment（p.6，§4.2）。没有单列 preregistered hypotheses。
- **参与者与试次**：`n=45`；每个 behavioral trial 使用相同结构，共 300 个 experimental trials（p.6，§4.2）。随机条件另有 12 名 other participants（p.6）。
- **刺激**：300 张 Visual Genome images，属于 YFCC100M 子集；用 DreamSim 在 semantic representational space 聚类后每簇选一张，刻意避免与 COCO training overlap（p.6）。
- **排除规则**：过滤 humans、printed text、clocks 等现有 diffusion model 难以生成的元素（p.6、p.10）。该限制在结果之后才形成单独 Limitations 段。
- **信息操纵**：参与者自由观看原图，达到 `{1, 2, 3, 5, 10}` 个 fixation 后图像消失；fixation locations 由参与者自己选择（p.6）。
- **条件与因变量**：5 秒空屏期间实时生成；随后第二张图呈现 200 ms，参与者报告 “same” 或 “different”；scene metamer 被定义为被试判断生成图与首张真实图相同（p.2、p.6）。
- **Own/random 对照**：主条件以 participant’s own fixations 生成；random condition 以图中 random fixation sampling 生成，由 12 名其他参与者执行相同判断（p.6）。
- **眼动与设备**：EyeLink 1000 tower-mount；13-point calibration；27-inch 2560×1440 240 Hz OLED，观看距离 24 inches，约 55°×30° visual angle；chin rest/head restraint 固定头部（p.16，A.1）。
- **生成与训练复现粒度**：Stable Diffusion 1.5、COCO 约 118K、mask token 数、blur scales、dropout、DDIM/CFG++/lambda 在正文；200K steps、batch、GPU、optimizer、output size 在 A.2（p.5、p.16）。
- **随机种子**：`not_present`。A.2 列出训练预算、硬件和优化器，但没有 seed 数量、seed 值或跨 seed 聚合规则（p.16，A.2，版面核对）。
- **匹配、泄漏与失败判定**：COCO 训练与 Visual Genome 行为刺激明确分开；生成与原图的 behavioral equivalence 由 same/different response 判定。正文没有报告独立 image-level train/test split、预先注册的失败阈值或校准后的 psychometric criterion。

### 7.2 分析顺序

引言提出从 same-different 判断出发；正文先给 Figure 2 的 FID quality，再给 Figure 3 的行为样例，然后依次做 neurally-grounded AlexNet 的 early/mid/late cosine similarity、可解释的 low/mid/high features，最后用新招募的 10 名 viewers 做 foveal/peripheral ablation（p.7–10）。这使主实验、机制分析和组件删除按「生成是否 plausible → 哪些层级解释 judgment → 哪个输入 stream 贡献最大」推进，但 feature analyses 明确是 post-hoc。

## 8. 结果、统计与可视化

### 8.1 统计口径

- 主行为结果以 same/different trial response 的 “same” proportion 表达；29.4% 与 27.7% 的分母和聚合层级没有在正文说明。
- Feature analysis 将原图/生成图送入 neurally-grounded blur-robust AlexNet，计算 early、middle、late layers 的 cosine similarity；Figure 4/5 用按相似度变化的 proportion-“same” 曲线表达关系。
- 解释性分析使用 forward stepwise linear regression；正文报告 `R²=0.039`，A.4 说明模型含 8 variables，并按省略变量后的 `ΔR²` 排序。Appendix A.4 的 random-fixation 模型 `R²=0.031`，只有 DreamSim distance 与 135° Gabor intensity 两个 significant regressors。
- Figure 14 直接标出 `r` 与 `p`，显示 full/peripheral/foveal 三种 stream 条件的相关性；p 值方法、multiple-comparison correction、效应区间和 error-bar 定义均未说明。
- 图 4、5、14 有误差棒或点线离散表达，图注没有说明其为 SD、SEM、bootstrap interval 或 participant-level interval；因此区间类型记为 `not_present`，不能把它解释为 conventional confidence interval。

### 8.2 主要结果清单

1. **FID image quality（§3.4，Fig. 2，p.5–6）**：peripheral scale 增大时 FID 改善；多种 blur level 都能生成 plausible scenes；MetamerGen 曲线低于 SD-1.5 text-to-image baseline。精确点值没有表格，图中也没有不确定性说明。比较单位是 COCO-10k-test 的 FID10K。
2. **Own vs random metamer rate（§5.1，p.7）**：own-fixation generation 的 metamer rate 为 29.4%，random-fixation 为 27.7%，差异 `p=0.24`。作者据此在 Discussion 认为 eye-data collection 对大规模数据集并非必要；具体检验名称和 trial/participant 分母未报告。
3. **跨视觉层级（§5.1，Fig. 4，p.7–8）**：own-fixation 条件下，early、mid、late AlexNet feature cosine similarity 越高，“same” 比例越高；random condition 在高 similarity 处出现下降。作者将其解释为非 fixation 区域的 realistic details 可能暴露与内部表征不一致的细节。
4. **低层特征（§5.2.1，p.8）**：生成图较强的 Gabor response 与更多 “same” judgment 相关；Sobel edge density 也呈正向关系，但被 Gabor effect 视为 redundant。A.5 具体显示 0°、45°、135° Gabor effect，90° horizontal filter 不显著。
5. **中层 depth（§5.2.2，Fig. 5，p.9）**：Depth Anything 的 SiLog discrepancy 越大，metameric “same” 比例系统性下降；作者认为 scene depth relationships 对 layout 很关键。
6. **中层 proto-object（§5.2.2，Fig. 5，p.9）**：blur-trained AlexNet conv3 的 proto-object segmentation mIoU 越高，“same” 比例越高，但效果弱于 depth。
7. **高层语义（§5.2.3，Fig. 5，p.9–10）**：DreamSim distance 较小对应更多 “same”；CLIP similarity 在 own-fixation generation 中也呈正向关系，random-fixation 下该关系消失。作者将 DreamSim 的清晰关系归因于其 human visual similarity 训练目标。
8. **综合回归（§5.2，p.8；A.4，p.17）**：8-variable forward stepwise model 的 `R²=0.039`；A.4 排序为 DreamSim distance、vertical Gabor、predicted-depth RMSE、D3、mid-level CNN similarity、CLIP last-hidden、CLIP CLS、D0.25。该回归把低、中、高层量放在同一可解释性框架，但效应量较小且未报告交叉验证或独立复现。
9. **对象级附加结果（A.5，Fig. 8，p.18–19）**：YOLOv8 object inventory 的 precision、recall、F1 与 mAP localization 越接近原图，metamer judgment 越多；更高 IoU threshold 下 own/random gap 变宽。该结果未进入正文主图。
10. **物理距离与语义距离（A.8，Fig. 12，p.21–22）**：PSNR 分布不能区分 same/different；DreamSim distance 在图中形成分离。作者建议用 DreamSim 选择 stimulus similarity，而非 PSNR。
11. **视觉 encoder 对照（A.10，Fig. 15–16，p.25–26）**：DINOv2 peripheral generation 的 FID 优于 CLIP；DINOv2 随 blur scale 改变而显示信息差异，CLIP patch tokens 的 FID 对 blur 改变不敏感。增加 foveal tokens 会降低两种 encoder 的 DreamSim distance，但低 token 数时 DINOv2 语义相似性更高。

### 8.3 结果与主张边界

作者区分了「same-rate 的 own/random 差异」与「feature similarity 对 same proportion 的关系」：前者没有显著差异，后者在 own fixation 条件显示更强且方向稳定的关联。该结构支持「语义相似性在 own-fixation metamers 中最有解释力」的限定式结论，尚不足以证明语义特征对人类判断的因果优先级。Figure 4/5/14 的误差表达没有定义，限制了对不确定性的独立复核。

## 9. 消融、负面结果与自我设限

### 9.1 主文 ablation（p.10，§5.3）

作者新招募 10 名 viewers，设置四种 second-image condition：identical original（true “same” control）、foveal+peripheral full model、peripheral-only、foveal-only。结果为 full model 54.5%，peripheral-only 45.8%，foveal-only 8.4%。作者解释 foveal-only 捕获 fixation details，却在 non-fixated regions 与原图差异较大；peripheral-only 更能恢复 global scene structure/layout；foveal 输入在与 peripheral 合并后提供额外视觉/语义信息。

### 9.2 Appendix ablations

### 9.3 限制

- **生成器能力边界**（p.10，§6）：Stable Diffusion 难以生成 fine-grained facial details、准确 limb articulations。
- **文本边界**（p.10，§6）：即使 text 被直接 fixation，生成文本常不可读。
- **刺激选择边界**（p.10，§6）：为避免上述 artifact 被误判为 “different”，实验排除包含 humans、printed text、clocks 等元素的图像；因此结论主要覆盖无这些困难元素的 Visual Genome 场景。
- **识别边界**（p.2、p.8）：feature analysis 是 post-hoc，且主要以相关/回归关系解释 same judgment；设计没有提供因果操纵来单独锁定 semantic priority。
- **复现信息缺口**（p.16–17）：A.2/A.4 没有报告随机种子、误差棒定义、multiple-comparison correction 或 regression validation protocol。

## 14. 最终判断

1. **单一主线**：把人类场景理解操作化为 same-different metamer judgment，用 DINOv2 dual-stream 将 peripheral gist 与 sparse fixation 送入 latent diffusion，再以层级 feature analysis 和 stream ablation 解释何种表示使生成图被视为「same」。
2. **正文保留的决策关键内容**：MetamerGen 架构与三个 conditioning equations、训练/推理关键 knobs、Visual Genome 与 COCO 分离、own/random behavioral design、29.4%/27.7% rate、multi-level feature 方向，以及 54.5%/45.8%/8.4% stream ablation rate。
3. **附录迁移及其代价**：训练硬件、Perceiver 结构、逐变量回归、object metrics、PSNR 对照、完整 stream correlations、DINOv2/CLIP 对照和所有生成样例放入 Appendix。正文仍能理解主流程，但 semantic superiority、metric choice 与复现细节依赖附录才能独立核查。
4. **最有效模式**：同一行为判据贯穿模型输出与人类判断；Figure 4/5 以 low/mid/high hierarchy 排列可视变量，Figure 13/14 再用 component deletion 将输入 stream 与行为率对齐，形成「生成 → 判断 → 机制 → 消融」的视觉证据链。
5. **最大缺口**：feature analysis 主要是 post-hoc correlation/stepwise regression，`R²=0.039` 且未交代分母、误差棒和检验细节；own/random rate 没有显著差异，却仍被扩展为减少 eye-data collection 的 practical implication。被排除的 faces、limbs、text 也限制了 scene understanding 的范围。
6. **可迁移规则**：若论文主张生成结果对齐 latent human representation，应在正文让同一 human decision criterion 同时承担效能判定和机制检验，并把每个 representation level 映射到可证伪的 matched feature contrast 或 component ablation。
7. **适用边界**：该规则适合有清晰 behavioral equivalence criterion、生成器能实时输出、且可建立多层 representation proxies 的视觉生成研究；当任务没有短时 same/different judgment、刺激含大量未建模元素，或人类表征无法由可观测 proxy 近似时，不能直接把相关关系包装成 latent alignment 结论。
