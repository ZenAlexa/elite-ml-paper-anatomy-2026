# Hubble：LLM memorization 研究模型套件

## 读取范围与结论摘要

- **论文**：Johnny Tian-Zheng Wei 等，*Hubble, a Model Suite to Advance the Study of LLM Memorization*；ICLR 2026，oral。
- **版本**：`corpus/pdfs/iclr-2026-0c8eb54755cf.pdf`，官方 ICLR proceedings PDF，62 个物理页；逐页读取 p.1–62，包含致谢、references、Appendix A–I。没有单独 supplementary 文件。
- **单一主线**：用标准模型与受控插入模型的配对训练，把版权、隐私和 test-set contamination 的敏感文本随机化并按已知 duplicate count 插入同一 DCLM 基础语料，再用跨 corpus size、插入时段、模型规模和数据类型的评测观察 memorization。论文将套件发布、两条缓解规律（dilution、ordering）和 MIA/unlearning 基准放在同一条 artifact-to-evidence 链上。
- **最强可辩护结论**：在 Hubble 的 Llama-3-derived 1B/8B、100B/500B token 和 DCLM 设置中，增大 corpus 可降低相同重复量下的风险，早期插入且缺少后续 exposure 时信息会遗忘；已知 duplicate count 的随机插入能构造 MIA 和 unlearning 的受控任务。文中结果支持这些范围内的经验结论，未建立跨架构、闭源模型或自然 PII 的普遍保证。

### E.2 对象、输入、输出、状态、目标与假设

- **训练对象**：Llama 3 architecture 的 1B/8B dense decoder-only Transformer；sequence length 2048，global batch 1024（约 2M tokens），OLMo tokenizer 50K vocabulary，untied input/output embeddings（p.5、p.29）。
- **输入**：DCLM baseline corpus（去污染后超过 500B tokens）；敏感文本按数据域、duplicate count 和 timing interval 插入。每个训练序列最多一个 perturbation，perturbation 作为带 EOS 的完整文档，不跨 sequence 切开（p.5）。
- **输出**：标准/受扰 checkpoint 与公开数据、配置、evaluation code；模型输出通过 normalized log-likelihood、choice accuracy、exact match、ROUGE-L、word recall、MIA ROC AUC 或 unlearning scatter 被测量（p.6、p.9–10、p.34–36）。
- **状态变量**：`model_size ∈ {1B,8B}`、`corpus_size ∈ {100B,500B}`、`data_condition ∈ {standard,perturbed}`、`duplication ∈ {0,1,4,16,64,256}`、`insert_range`、risk domain、prompt/evaluation format。
- **目标**：在可控训练条件下估计 duplicate frequency 相对于 corpus size 的 memorization 变化，观察 timing/scale/domain/format 的异质性，并提供 MIA 与 unlearning benchmark。
- **关键假设/控制**：基础 corpus 与插入 data 去污染；standard/perturbed 共享架构与大部分训练过程；插入总量很小（79.9M tokens，100B corpus 的 0.08%，500B 的 0.016%）；随机分 bin 避免 member label 被文本特征直接泄漏（p.5、p.9、Appendix A.3）。

论文没有 theorem、lemma、proposition、corollary、proof 或正式 numbered equation；正文和附录也没有 displayed mathematical equation。总公式数为 0，编号公式数为 0，算法环境/算法 caption 为 0。核心“理论”角色由经验可检验预测承担：相同 duplicate count 下 corpus 越大，relative exposure 越低；敏感文本若只在早期出现，后续训练可能使其遗忘；模型规模增大可能降低达到可测 memorization 所需的 duplicates。它们属于**解释/预测链**，不是 theorem guarantee。

### G.2 统计与可视化边界

论文的聚合单位主要是 **perturbation example × duplicate bin × model/checkpoint × prompt format**；分母由数据集样本数、10/15-way candidate choices 或 test examples 决定。中心量是 normalized log-likelihood、accuracy、exact match、word recall、ROUGE-L、F1、ROC AUC 和 TPR@1%FPR。MIA 明确使用 ROC AUC，unlearning 使用网格搜索后的 scatter/reference-point，通用能力表报告单一 benchmark score。正文没有 conventional confidence intervals、bootstrap、Bayesian posterior 或回归模型；图中通常不画 error bars。§D.1 对“statistically significant”有文字判断，却未给 test family 或阈值。因而这里把“点估计”“近 random”“接近 100%”“>96%”与统计显著性分开记录，避免把可视趋势包装成保证。

## H. 消融、负面结果与自我设限

正文没有 `Ablation` 标题。语义上的消融/异质性检查由 §3.2 的 Interference、Timing、Paraphrased、Architecture runs 和 §4–§5 的 domain/format 对照组成；完整曲线迁移到 Appendix E、D、I。

| 消融或边界 | 识别目标 | 结果与位置 | 呈现状态 |
|---|---|---|---|
| Domain-only interference | 联合训练是否让不同风险域互相污染 | 3 个单域 1B/100B 模型与 core 逐域曲线相符（Appendix Fig.23，p.62） | 作为“minimal interference”支持，未给数值差或形式检验。 |
| Timing/forgetting | exposure 位置与 continued exposure | InsertRange 与 checkpoint 曲线显示 early-only 后遗忘、late-only 更强（Appendix Figs13–14，p.48–49） | 关键证据延后到附录，正文只保留结论。 |
| Architecture depth | 深度与宽度在近似等参数下的影响 | 32-layer 窄模型略多记忆，8-layer 宽模型略少（Fig.16，p.52） | 作为补充扩展，未成为主线结论。 |
| Paraphrase | literal repetition 与 semantic memory 的差别 | paraphrased YAGO 可重建 PII；paraphrased MMLU 不迁移原题（Fig.15，p.50–51） | 同时报告正面语义检索与负面 task transfer。 |
| PII type | 单文档不同字段是否同样容易记忆 | occupation/email/UUID 形成三种 outlier（Figs8，p.37、40） | 异质性被明确命名，避免只报总体平均。 |
| Prompt strength | auxiliary information 对泄漏率的影响 | full prefix/full suffix、full prefix、intro prefix、name-only 逐级变弱（Figs6–8，p.36–40） | 设计清楚，详细 prompt 表放 Appendix。 |
| Format/minimal pair | memorization 是否迁移到另一表达格式或 paired example | WinoGrande cross-format 和 paired accuracy 可下降；ELLie minimal-pair overlap 使 0 dup 也高（p.44–47） | 负面/失效结果明确呈现。 |
| Model scale | 参数规模是否改变达到可测记忆的重复量 | 8B 高于 1B（Fig.22，p.61） | 与 general capability 同时变化，因果范围限于配对模型。 |
| MIA method | 不同 attack 的敏感性 | MinK%++ 通常最有效；Loss/MinK% 在 Gutenberg 高重复可达 1.0（Table1、Figs17–19） | 结果保留方法差异，没有单一冠军结论。 |
| Unlearning method/retain set | 方法精度与 retain 分布的影响 | SatImp 最接近 desired；Keep 与 WikiText retain 的总体图形一致（p.10、Figs20–21） | 只比较 3 方法与网格，不能推出全面方法排名。 |

作者自我设限出现在摘要（经验 best practices）、§3.3（evaluations 是 lower bounds）、§4（interference 只做 check）、§5（metric 依赖、格式与 generalization）、§6（unlearning 未达 target）、Appendix D.3（ELLie 失效）和 Appendix H（dilution 不能消除所有 legal/privacy concern）。没有独立 `Limitations` section。负面信息的实际呈现包括：附录迁移、聚合曲线不展示完整分布、用“nearly all”“minimal interference”“ideal testbed”等范围较宽的语气，但论文同时公开了 ELLie invalidation、Keep/Test degradation、MIA 单次重复近 random 和 unlearning precision gap，因此不能将所有延后都解释为隐匿意图。

## L. 最终判断

1. **单一主线**：受控、随机化、可公开重放的 pretraining data intervention，把“是否记住”从自然语料观察问题改造成 duplicate frequency、corpus size、timing、format 和数据类型可分层的实验问题；同一 intervention metadata 再支撑 MIA 与 unlearning。
2. **正文保留的决策关键内容**：三域风险动机、standard/perturbed 定义、8-model core、6 个 timing models、三种 elicitation、Figure1–3、Table1、dilution/ordering 摘要、MIA/unlearning setup 与 failure-level 结论。
3. **附录迁移及自足性**：数据统计、decontamination、训练配置、通用能力、PII prompt、全部域图、timing/forgetting、MIA 全表/ROC、unlearning grid/full plots均移入附录。主文足以理解产品化主张与核心方向；ordering、PII 异质性、ELLie 失效、完整 benchmark 范围依赖附录，读者需要额外跳转才能审查识别边界。
4. **最有效模式**：Figure1 的 before/after 机制图、Figure2 的统一 duplicate 横轴 small multiples、Figure3 的 desired/standard/perturbed reference points、Table1 的逐 duplicate AUC 表格。它们分别回答“怎么插入”“规律是否跨域”“unlearning 离目标多远”“攻击随重复量怎样变化”。论文没有公式或 theorem，因果链靠对照设计、曲线与任务拆分承载。
5. **最大叙事缺口**：`causal quantities`、`minimal interference`、`ideal testbed` 和 broad policy relevance 的措辞超过了本文明确的统计设计。每个模型条件的 seed/replicate、error bars、显著性检验和 interference effect size 未报告；部分关键结果只在附录，影响正文自足性。ELLie 的污染被诚实揭示，说明 benchmark validity 仍需逐数据集审计。
6. **可迁移规则**：每个敏感数据干预都应有 matched clean reference、可审计的随机 exposure metadata、明确 duplicate/timing bins、与主张一一对应的 metric，以及专门的 cross-format、minimal-pair、decontamination 和 failure check；主图应把 intervention intensity 与风险/能力指标放在同一坐标系。
7. **适用边界**：该规则适用于有能力控制 pretraining corpus、可发布 checkpoint 和可枚举插入记录的研究套件；它不能单凭 Hubble 结果推出闭源/商业模型、fine-tuning 场景、自然个人数据、法律 fair-use 结论或完全隐私/版权消除保证。
