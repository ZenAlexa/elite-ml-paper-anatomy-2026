## Related Work：分类与近邻对照

Related Work 是独立 §2，跨 p. 2–3 两个小标题段落，共约 321 词，约占主文 9.2%。

- **World models for policy evaluation（p. 2）**。先按真实 rollout/physics simulator 与 data-driven world model 做问题分类，引用簇包括 `[19,50]`、`[7,8,22,26–30,35,38,43,46]` 和 `[1,10,11,13,15,20,33,37,39]`。随后按具体注入机制做近邻对照：WorldGym 用 AdaLN，Ctrl-World/WorldEval 用 cross-attention；dWorldEval 把 action 作为 primary tokens，经 self-attention 驱动未来状态（p. 2，§2）。动作是 `taxonomy → nearest_neighbor_contrast → gap_creation`，不是按年份排列。
- **Discrete diffusion in robotics（p. 3）**。先从 DLM 相对 autoregressive LLM 的采样/控制优势，扩展到 LaViDa/MMaDA 的多模态生成，再到 dVLA 与 `[21,40,42]` 的 action token inpainting。最近邻差异是本文把 discrete diffusion 用于 world model，而非 policy learning；统一 token 同时预测 observation 与 progress，省去 prior evaluator 依赖的外部 VLM/reward function（p. 3，§2）。动作是 `chronology → credit_or_foundation → nearest_neighbor_contrast → gap_creation`。

## 方法与理论边界

### 形式化对象与方法单元

1. **World model formulation（p. 3，§3.1）**：输入为 language instruction `l`、current observation `o_t`、history `h_t`、future action sequence `a_t`；输出为 horizon `∆` 的 `ô_{t+∆}` 与 `v̂_{t+∆} ∈ [0,1]`。目标分布写成 `(ô_{t+∆}, v̂_{t+∆}) ∼ Wθ(· | o_t, a_t, h_t, l)`。三项可靠性属性为 action controllability、spatiotemporal consistency、discriminative task completion（p. 3，§3.1）。
2. **Policy evaluation via imagination（p. 3，§3.1）**：将 policy `π` 与 `Wθ` 闭环交互，得到 `τ = {ô_0,ô_∆,…,ô_T}`，以 `J = 1/N Σ_i S(τ_i)` 计算 imagined success rate；`S(·)` 是二元 success indicator（p. 3，§3.1）。
3. **Unified token sequence（p. 4，§3.2.1）**：MAGVIT-v2 编码 RGB，LLaDA 编码 language，FAST 编码 continuous action chunks；序列化为单一 flattened sequence，令 visual token 通过 self-attention 直接读取 action token（p. 4，§3.2.1）。原文 `FAST ... for continuous action chunks at .` 的动作维度在 PDF 文本中缺失，无法补全。
4. **Sparse keyframe memory（p. 4，§3.2.2）**：sliding window 取最近 `K` 帧，stride 为 `∆` 并与 action chunk 对齐；历史帧加绝对 frame-index text token，历史只编码低分辨率 global view，当前 observation 保留全视角 full resolution（p. 4，§3.2.2）。
5. **Discrete progress token（p. 4，§3.2.3）**：训练时由 task-specific milestones 和 SEED-1.5VL few-shot ICL 估计进度，将分数离散化后追加到 target sequence；推理时解码为数值，终端分数等于 `1` 才判为成功（pp. 4、7，§3.2.3、§4.2.3）。
6. **Joint Visual-and-Progress Denoising（pp. 4–5，§3.3）**：MDD 学习 `p(y_{t+∆}|c_t)`，context 保持 unmasked，target suffix 按 `λ ∼ U(0,1)` mask；在 masked index `Ω_λ` 上用 modality-specific weight 优化 Eq. (1)，推理采用 16-step iterative parallel decoding（p. 5，§3.3、§4.1）。

方法动作序列为 `setup_notation → state_problem → instantiate_algorithm → define_component → explain_mechanism → give_intuition → derive → connect_to_prediction → connect_to_experiment`。这里的「理论」主要是建模目标和诊断指标的形式化，属于 core chain/diagnostic；论文没有独立保证、复杂度定理或证明（pp. 3–6，§§3.1–3.3、§4.2.1）。

- **Displayed equation（p. 3，§3.1）**：`(ô_{t+∆},v̂_{t+∆}) ∼ Wθ(·|o_t,a_t,h_t,l)`，定义条件联合分布，角色为 `core_chain`。

## 实验设计

### 研究问题与实验顺序

p. 5 明列五个研究问题：

- **RQ1**：对 suboptimal/OOD action 是否严格遵循 control signal，并呈现 failure，而非 hallucinated success？
- **RQ2**：sparse keyframe memory 是否抑制 long-horizon spatiotemporal drift？
- **RQ3**：Progress-as-text 是否可在无 external oracle 下作为 intrinsic success metric？
- **RQ4**：闭环 imagined performance 是否与 real execution 强相关，并能跨 architecture/training stage 排名 policy？
- **RQ5**：∆-LPIPS 是否能度量 action controllability，并作为评测诊断指标？

实验顺序是 `RQ1/action controllability → RQ2/memory consistency → RQ3/progress grading → RQ4/policy ranking → RQ5/diagnostic validation`，但 RQ5 的 action-shuffling 验证移入 Appendix B（pp. 5–9、14–15，§§4.1–4.4、Appendix B）。

### 数据、任务、模型与基线

- **LIBERO**：LIBERO-Object、Spatial、Goal、100 四个 suite；5.5k official expert demonstrations 加 1k suboptimal failed rollouts；使用 synchronized third-person 与 wrist views（p. 5，§4.1）。
- **RoboTwin**：ARX arm configuration，5.5k trajectories，10 个 contact-rich tableware tasks（p. 5，§4.1；p. 13，Appendix A.1）。
- **Real-world**：双臂 AgileX、两个 6-DoF arms、三台同步 RealSense 457 cameras；5.2k trajectories，其中 1k human-collected failures，五个任务 Bussing Table、Place Cup、Handover Block、Strike Block、Place Bottles（p. 5，§4.1；p. 13，Appendix A.1）。
- **基线**：WorldEval、WorldGym、Ctrl-World；作者声明使用 identical training-data splits（p. 5，§4.1）。目标 policy 包含 LIBERO 上的 π0 多训练 checkpoint，以及 RoboTwin/real-world 的 π0、DexVLA、Diffusion Policy（p. 5，§4.1；p. 8，Figure 7）。
- **模型与训练**：主文给出 256² multi-view outcomes、`K=4` sparse history（历史分辨率写作 128²）、loss weights `w_j=2`（progress）与 `1`（visual）、`∆` 与 action-chunk length 对齐并从 `[2,8]` 选取、16-step parallel decoding（p. 5，§4.1）。Appendix A.2 补充 MMaDAVLA-8B initialization、32 layers/heads、hidden dimension 4096、15 epochs、8 H800、AdamW、learning rate `5e-5`、global batch 128 with gradient accumulation（p. 14，Appendix A.2）。
- **统计和分母**：success rate 在 simulation 每 task 20 episodes、real-world 每 task 30 episodes 上取平均（p. 14，Appendix A.2）；Table 2/4 的 round-trip LPIPS 跨 synchronized views 平均（p. 6，Tables 1–2；p. 9，Table 4）。论文没有报告随机种子、训练/测试划分的样本 ID、标准差/标准误、置信区间、显著性检验或多重比较处理（pp. 5–9、14）。
- **硬件与成本**：完整 trajectory 约 30–90 秒，约 1.5 秒/frame，单张 H800 GPU（p. 14，Appendix A.2）。

### 控制变量、泄漏与失败判定

- action controllability 使用相同 ground-truth action sequence 条件生成，并在 shared third-person view 比较；`D_succ` 与 `D_fail` 分开（p. 6，§4.2.1）。
- round-trip 使用前向 action 到 `H∆`、再接 inverse actions 至 `2H∆`，`H∈{5,10,15,20}`；memory ablation 单独比较（p. 7，§4.2.2）。
- action-shuffle 在保持 history/language/marginal distribution 时以 batch permutation 替换 action，强制 `π(i) ≠ i`；另用 swap probability `p∈[0,1]` 做连续扰动（p. 14，Appendix B）。
- success 判定为 progress terminal token 等于 `1`；memory ablation 产生严重 drift 时，§4.3 改用 generated image 人工判定，以避免不可靠 progress token 影响比较（p. 7–8，§§4.2.3、4.3）。
- 未见显式随机种子、数据泄漏审计、预注册失败阈值、跨任务配对方案或 formal failure criterion；这些信息保持缺失（pp. 5–9、14）。

### 统计、误差与图表独立性

论文使用 LPIPS、∆-LPIPS、终端 success rate、Pearson correlation `r` 和 MMRV rank-violation。中心量主要是跨同步 view 或 episodes 的均值；论文没有 error bars、标准差/标准误、bootstrap、Bayesian model、回归不确定性或假设检验。`r` 和 MMRV 是决策量，∆-LPIPS 是动作条件动态保真度诊断，progress token 是成功分类器；论文将这些实质指标区分开，但未报告不确定性（pp. 6–9、14–15）。

Figure 6 把 Real、Human (imag.) 和 Auto (imag.) 放在同一 checkpoint 曲线上，Figure 7 用 scatter plots 同时显示线性 correlation 与 rank violation；这两种图最接近独立可读的决策证据。Table 1/2/3/4/5 的表注说明了比较对象和下降方向，但不包含分母、样本数或误差表达（pp. 6、9、15，Tables 1–5；p. 8，Figures 6–7）。

## 消融、负面结果与自我设限

### 消融与识别目标

1. **Memory removal**：Table 2/Figure 5(b) 比较 Full 与 w/o Memory 的 round-trip error，识别 long-horizon drift 的 memory 组件贡献；`H` 从 5 延伸到 20 时差距扩大（pp. 6–7，Table 2/Figure 5(b)）。
2. **w/o-history policy ranking**：Figure 7(b–d) 在 multi-view LIBERO、RoboTwin heterogeneous policies 和 real-world 对比 full/w/o-history，识别 spatiotemporal memory 对排名 correlation 的影响；multi-view `r` 从 0.910 降到 0.786（p. 8，Figure 7）。
3. **Action shuffling**：Appendix B/Table 5 置换 action chunk，保持 history/language 固定，检验 model 是否依赖动作条件；∆LPIPS 从 0.324 到 0.697（pp. 14–15，Appendix B/Table 5）。
4. **Probabilistic corruption**：Figure 9 改变 swap probability `p`，识别 ∆-LPIPS 与 policy-ranking correlation 的联动（p. 14，Figure 9）。

消融占主文约 9.3%（以 §4.2.2 与 §4.4 计），主文 1 个图、2 张表；Appendix B 再放 1 张表和 1 个图。论文未做 tokenizer 替换、progress-token 删除、不同 `K`/resolution/decoding steps 的系统消融，也未报告按 task 或 robot morphology 的独立误差分布（pp. 6–9、14–15）。

### 负面结果与失败案例

- `D_fail` 上三个 video baselines 的 ∆-LPIPS 均高于 Expert，WorldEval 由 0.423 升到 0.701、WorldGym 由 0.347 升到 0.650；Ours 由 0.315 到 0.352，失败退化较小（p. 6，Table 1）。
- Figure 5(a) 直接给出 missed grasp 被“修正”为成功、non-existent object hallucination 和 action misalignment；dWorldEval 复现 failure（p. 7，Figure 5(a)）。
- w/o memory 的 round-trip error 随 horizon 上升，progress token 在严重 drift 时被判为不可靠；§4.3 因此改用 generated image 评判该消融（pp. 7–8，§§4.2.2–4.3）。
- Figure 11 给出一个 generated failure trajectory，分数停在低值；这是定性案例，不是失败率估计（p. 17，Figure 11）。

### 限制与范围

- **范围/data**：实证覆盖 LIBERO、RoboTwin 和 AgileX 五项 real-world tasks；1k failure rollouts 用于 failure-aware scoring，但未证明覆盖完整 OOD action space（p. 5，§4.1；p. 13，Appendix A.1）。
- **监督依赖**：progress ground truth 来自 SEED-1.5VL few-shot ICL、task-specific milestones；这使 intrinsic metric 仍依赖外部 VLM 生成的训练标签（pp. 4、14–16，§3.2.3、Appendix C）。
- **统计边界**：success rate 只有每 simulation task 20 episodes、每 real task 30 episodes 的平均；没有 seed、误差量或校准分析（p. 14，Appendix A.2）。
- **计算代价**：完整 trajectory 约 30–90 秒、1.5 秒/frame、单张 H800；论文没有与基线报告同口径吞吐或总训练成本（p. 14，Appendix A.2）。
- **规格缺失**：正文 action-chunk 行尾出现 `at .`，action 维度没有给出；正文与 appendix 对 history resolution 也不一致（p. 4，§3.2.1；p. 5，§4.1；p. 14，Appendix A.2）。
- **结构性缺口**：没有独立 limitations 段落、理论 guarantee、confidence/calibration analysis、formal complexity 或跨更多 unseen morphology 的测试（pp. 3–9、14）。这是版面和实验内容的缺失描述，不是对作者意图的推断。

- 领域高频实词围绕 `action`、`visual`、`world model`、`policy`、`progress`、`memory`、`consistency`、`evaluation`、`success`、`token`、`trajectory`；它们分别对应控制、生成、评测和闭环判定，而非通用模板词（pp. 2–9）。
- 高频二元/三元组合包括 `action controllability`、`spatiotemporal consistency`、`sparse keyframe memory`、`unified token space`、`progress token`、`real execution`、`policy ranking`、`long-horizon drift`、`action-conditioned dynamic fidelity`（pp. 2–9）。

- `we propose` 在摘要和引言重复出现；`we employ`、`we introduce` 负责方法动作；`we find` 出现在 action-shuffle 结果；`confirm`/`demonstrate` 用于把相关性提升为可靠性叙述（pp. 1–2、6、14–15）。

## 最终判断

1. **单一主线**：现有 video-diffusion evaluator 把 action 当作弱条件，导致 OOD failure hallucination 与 long-horizon drift；dWorldEval 用从 robotic data 训练的 unified discrete token sequence，使 action 直接进入 self-attention，再以 sparse keyframe memory 稳定轨迹、以 progress token 统一生成和 success scoring。action fidelity → temporal consistency → intrinsic grading → policy ranking 是唯一连续因果线（pp. 2–9）。
2. **正文保留的决策关键内容**：三项可靠性属性、五个 RQ、统一 token/memory/progress 组件、∆-LPIPS Eq. (2)、Table 1/2/3/4、Figures 5/6/7，以及 LIBERO/RoboTwin/real-world 的核心对照。它们让读者能从机制看到 ranking 结果（pp. 3–9）。
3. **移入附录的细节及影响**：任务 instruction、MMaDAVLA-8B 规格、训练硬件/episodes/runtime、action-shuffle protocol、VLM scoring rubric 和定性 failure/real-world 图移入 pp. 13–20。正文通过引用保持叙事流畅，但缺少这些细节时，progress 标签来源、诊断扰动与复现成本无法独立判断（pp. 4–5、9、13–20）。
4. **最有效模式**：Table 1 把 expert/failure 两个分布并列，Table 2 把 horizon 与 memory ablation 并列，Figure 7 同时给 scatter correlation 和 rank violation；这些结构让机制变量、识别对象和决策量在同一视线内（pp. 6、8–9）。
5. **最大叙事缺口**：论文把「可靠 policy ranking」和「scalable」说得比可检验范围更大；`r≈0.9` 来自有限任务/策略的聚合曲线，未给样本数、误差、seed、per-task breakdown 或 OOD coverage。另有 Table 2 的 0.243 与正文 “LPIPS 0.21”、主文/附录 history resolution、正文 four suites/图注 three suites 的内部不一致（pp. 6–9、14）。
6. **可迁移规则**：若论文把生成质量提升解释为评测能力，必须把 action-conditioned mechanism、long-horizon stress test、真实执行对照和 ranking decision 放在同一证据链，并同步公开聚合分母与不确定性。
7. **适用边界**：该规则适用于以生成模型作为 simulator/evaluator、并把相关性或排名作为终点的机器人论文；纯视觉生成、无闭环决策目标或理论型论文需改用其自身的因果中介和决策量。
