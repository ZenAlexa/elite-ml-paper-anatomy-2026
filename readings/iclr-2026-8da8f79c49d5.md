## 1. 一句话主线

论文用 `10 main categories × 5 subcategories × 7 scenarios × 3 prompt variations = 1,050 prompts` 建立分层物理评测空间，再为每个 prompt 配置对象、事件与关键物理现象的二元标准，以人评和 Context-Aware Prompt（CAP）评估 12 个 text-to-video models。主要经验结论集中在三类困难：Anti-Physics、abrupt state changes、多对象／多约束场景。[PDF p.1, Fig.1, “10 main physics categories”; PDF p.6, §3.1, “Basic Standards and Key Standards”; PDF p.9, §§4.5–4.6, “20 paired prompts”]

这一主线的识别边界很清楚：benchmark能观测生成行为，训练数据模仿、内部物理表征与“真正理解”仍未被直接观测。4.4和4.6把失败率解释为训练分布模仿或缺乏理解，证据仍是输出行为比例。[PDF p.8, §4.4, “prioritize mimicking training data”; PDF p.9, §4.6, “do not really understand”]

## 6. 方法、形式化程度与实验设计

### 6.1 方法动作链

方法段落的动作序列是：`state_problem → define_component → instantiate_pipeline → define_standards → connect_to_experiment → contrast_prior_metrics → explain_CAP_mechanism → ablate`。[PDF pp.4–7, §3, Fig.3, “three-stage pipeline”; PDF p.7, §3.3, “Context-Aware Prompt (CAP)”]

四个最小逻辑单元分别解决四个问题：层级category处理覆盖；三种prompt variation处理提示细节；Basic/Key Standards分开semantic presence与physical correctness；generated-video context加two-step prompting减少MLLM对异常视频的合理化。[PDF p.5, §3.1, “three prompt variations”; PDF pp.5–6, Fig.5, “Basic Standards and Key Standards”; PDF p.7, §3.3, “tend to rationalize unrealistic content”]

输入是text prompt及其object/event/key standards，输出是video-level `SA, PC, Both`。SA要求对象数量和事件均满足，PC要求全部Key Standards满足，Both要求SA=1且PC=1。论文没有objective function、trainable state或formal assumption list；核心隐含假设是关键物理现象能从视频中被Yes/No可靠观察。[PDF p.6, §3.1, “SA = 1, PC = 1”; PDF p.13, Appendix B, “SA, PC ∈ {0, 1}”]

### 6.2 理论与算法清点

- displayed equations：0。
- numbered equations：0。
- theorem／lemma／proposition／corollary／proof：均为0。
- pseudocode／algorithm：0。
- `SA, PC ∈ {0,1}` 是行内指标定义；Fig.5中的 `(1)/(2)` 是standard条目编号。自动测量将其中一个编号误判为numbered equation。[PDF p.6, Fig.5, “(1) The contact point”; PDF p.13, Appendix B, “SA, PC ∈ {0, 1}”]

因此，本论文的“方法”属于benchmark construction与evaluator protocol，理论在因果链、保证、解释、诊断、装饰五类中均不适用。

### 7.2 统计边界

聚合单位首先是video-level binary outcome，随后按prompt／category／physics level／model聚合成功比例；Overall被正文描述为10个physics categories的平均。人类标签由每video三名annotators majority vote决定。自动评估用ROC-AUC、precision、recall；leaderboard使用rank；两项paired study给Pass/Total。[PDF p.8, §4.1, “averaged across 10 physics categories”; PDF p.13, Appendix C, “majority vote”; PDF p.33, Tables 16–17, “Pass / Total”]

核心表格没有报告不确定性、bootstrap、hypothesis test或multiple-comparison处理。Appendix G写“generation time correlates with physics accuracy”，却没有相关系数、拟合模型、样本量或控制变量。文中的“significantly”应读作点差的修辞描述，未对应统计检验。[PDF p.7, §3.3, “significantly outperforms”; PDF p.16, Appendix G, “generation time correlates”]

## 15. 最终判断

1. **单一主线**：分层prompt空间加逐prompt可观察标准，把physical realism转成video-level判定，再用12模型揭示anti-physics、突变和复杂交互失败。[PDF pp.1,5–9]
2. **正文保留的决策关键内容**：hierarchy、creation pipeline、SA/PC/Both、CAP机制、Table 3主结果、Table 4 prompt study、两组paired headline rates。[PDF pp.4–9]
3. **附录迁移及代价**：annotation details、precision/recall、category detail、失败图、static rationalization、paired denominators与limitations均后移；主线仍可读，严谨核查成本升高。[PDF pp.13–19,32–33]
4. **最有效模式**：`结构图 → 判定标准图 → 主结果表 → 成对操控`。Fig.1、Fig.5、Table 3、Tables 16–17分别回答覆盖、成功定义、总体状态与局部困难。[PDF pp.1,6,8,33]
5. **最明显缺口／读者成本**：行为比例无法闭合训练分布模仿或“真正理解”的机制主张；摘要和Table 3又出现5+5／10／12模型数不一致。[PDF pp.1,8–9]
6. **可迁移规则**：benchmark主结果前先公开每个样本的对象、事件、机制判定，并在关键表中给出Pass/Total与聚合层级。[PDF pp.5–6,33]
7. **规则边界**：Yes/No与8-frame sampling适合离散可观察事件；连续动力学、长时序守恒或短暂碰撞需要轨迹／物理量级估计和显式不确定性。[PDF p.7, “evenly sample 8 frames”]
