## 单一主线

论文把高维比例极限 `p ∼ n` 中的 certified unlearning 写成条件于训练数据的二元假设检验问题。核心对象是删除后理想 RERM 解与一步 Newton 近似之间的向量差；向其加入标准差 `R/ε` 的各向同性 Gaussian noise 后，Gaussian trade-off function 将隐私判据压缩成一个无维度的 `ℓ2` 位移比噪声尺度。由外部引用的高概率 Newton 误差界，论文得到 `(ϕ_n, ε)`-Gaussian certifiability；再用 fresh-feature 的 sub-Gaussian 尾界和 loss 的 polynomial-growth 条件，将预测层面的 GED 控制为随 `m^2 polylog(n)/√n` 衰减的量（p.4–8，§3.1–§4.3，式(4)、(9)–(17)）。因此，论文的最强因果链是「高维下旧的逐样本 optimization assumptions 失效 → trade-off/Gaussian certifiability 与加噪机制匹配 → 一步 Newton + calibrated Gaussian noise 同时给出隐私和预测准确性」。

这条链条的关键边界也很清楚：定理只覆盖 convex、三阶可微、可分离且强凸正则化的 GLM/RERM，特征为 mean-zero sub-Gaussian、协方差最大特征值按 `C_X/p` 缩放，响应满足 sub-polylogarithmic tail；完整 Hessian 求逆的工程代价、非凸深网、`p ≫ n` 和更复杂 unlearning 仍是未来问题（p.7–8，p.10，§4.2–§6）。

## E. 方法与理论

### E.1 问题、状态和算法组件

1. **训练状态**。GLM 数据为 `dP_{β*}(x,y)=dp(x)dq(y|xᵀβ*)`，学习器是带一次性正则项的 RERM `L(β)=λr(β)+Σ_iℓ(y_i|x_iᵀβ)`，输出 `β̂`（p.4，式(1)）。
2. **删除状态**。删除集合 `M` 大小为 `m`，理想输出 `β̂_{\M}` 是在 `D_n\D_M` 上重新优化的 RERM（p.4，式(2)）。
3. **可见接口**。unlearning 机制得到原模型、删除数据和训练时可保存的梯度/Hessian 辅助信息，随机性只有 `b`（p.4，式(3)及其后说明）。
4. **隐私接口**。条件于数据定义 `P_re` 与 `P_un`，让 adversary 测试「来自删除后运行」还是「来自完整模型带删除集运行」的输出（p.4，式(4)）。
5. **准确性接口**。GED 比较新样本上 retrained model 与 unlearned model 的 error，条件于 `D_n` 并对测试点及 unlearning noise 平均（p.6，式(11)）。附录以 UED 检查删除集上的 prediction error，但正文没有给出独立的正式 UED 定义式（p.17、p.33–38）。

### E.2 Gaussian trade-off / hypothesis testing

- `T(P,Q)(α)` 返回 Type I error 不超过 `α` 时可达到的最小 Type II error（p.5，Definition 1，式(5)）。
- `f`-certifiability 要求对所有 `α` 的 trade-off 下界以数据概率至少 `1−ϕ` 成立，并对所有 `|M|≤m`、两个方向取最小值（p.5，Definition 2，式(6)–(7)）。
- ε-δ 版本用 `f_{ε,δ}`（式(8)）示意旧 notion；本文选择 `f_{G,ε}(α)=Φ(Φ^{-1}(1−α)−ε)`（式(9)）。
- Lemma 1 给出 shifted isotropic Gaussian 的 dimension freeness：只需 `ε=||μ_1−μ_2||_2/σ`，trade-off 与一维 `N(0,1)`、`N(ε,1)` 相同（式(10)）。因此高维输出比较被化成位移范数与噪声标准差的比值，privacy curve 不再显式引入维度（p.5–6）。

### E.3 一步 Newton + noise

Definition 4 先写一般 Newton-Raphson 迭代 `β^(t)=β^(t−1)−G^{-1}(β^(t−1))h(β^(t−1))`（式(12)）。对删除损失 `L_{\M}` 从 `β̂` 做一步得到 `β̂_{\M}^{(1)}`（式(13））；加入 `b∼N(0,σ²I_p)` 得到 `β̃_{\M}=β̂_{\M}^{(1)}+b`（式(14)）。机制要控制的是 `β̂_{\M}^{(1)}−β̂_{\M}`，因为它是删除信息的残差（p.6–7，§4.1）。

### E.4 Assumptions

- **(A1)** `r(β)=Σ_k r_k(β_k)` 可分离。
- **(A2)** `ℓ` 与 `r` 三阶可微。
- **(A3)** `ℓ`、`r` proper convex，`r` 为 `ν=Θ(1)>0` 强凸。
- **(A4)** `ℓ`、`ℓ̇`、`ℓ̈` 只需 polynomial growth；`∇²r(β)=diag[r̈_k(β_k)]` 且在 Frobenius norm 下以 `C_rr(n)=O(polylog(n))` Lipschitz。
- **(B1)** `x_i` 是 mean-zero sub-Gaussian，协方差 `Σ` 满足 `λ_max(Σ)≤C_X/p`；比例极限保持 `n/p→γ`。
- **(B2)** 响应满足 `P(|y_i|>C_y(n))≤q_n^(y)`、`E|y_i|^{2s}≤C_{y,s}`，其中 `C_y(n)=O(polylog(n))`、`q_n^(y)=o(n^{-1})`。

这些 assumptions 放宽了 per-example loss 的 worst-case `Ω(1)` strong convexity 和 `O(1)` smoothness，但仍保留唯一 RERM 解与 Newton 分析所需的 convexity/regularizer strong convexity/smoothness；作者以 ridge quadratic loss 作为可覆盖的具体例子（p.7，§4.2，式(15)）。

### E.5 主定理、证明职责和可证伪预测

**Theorem 2（隐私）**。在 A1–A4、B1–B2 下，存在 polylog `C_1(n),C_2(n)`。若 `b∼N(0,(R/ε)^2I_p)`，其中

`R=C_1(n) sqrt(C_2(n)m^3/(2λνn))`, `ϕ_n=nq_n^(y)+8n^{-3}+ne^{-p/2}+2e^{-p}→0`,

则式(14) 满足 `(ϕ_n,ε)`-GPAR（p.8，Theorem 2，式(16)）。这里的 sufficient noise 由 Newton residual 的 high-probability `ℓ2` 上界给出。

**Theorem 3（准确性）**。使用 Theorem 2 的 noise，至少以

`1−(n+1)q_n^(y)−14n^{-3}−ne^{-p/2}−2e^{-p}−e^{-(1−log(2))p}`

的概率，有

`GED(β̃_{\M},β̂_{\M}) ≤ C_1(n)√C_2(n)(1/ε+1/√p)√(m^3(m+2)/(λνn))·polylog(n)`。

组合后式(17)给出 `GED=O_p(m^2 polylog(n)/√n)`，条件为 `m^2 polylog(n)/√n→0`；作者进一步写成 `m=o(n^{1/4−α})`（任意 `α>0`），摘要/引言的简写是 `m=o(n^{1/4}/polylog(n))`（p.8，Theorem 3、式(17)；p.3 贡献列表）。

**Proof map**：附录 G.1 的 Lemma 6 提供 Gaussian trade-off 的 monotonicity、closure under suprema、symmetry 和 dimension freeness；Theorem 7（明确标为 Zou et al. 2025 的结果）控制一步 Newton residual 事件 `F`；G.2 通过式(58)–(62)把残差上界转换为 GPAR；G.3 用 fresh-feature events `E_5–E_8`、均值定理和 polynomial-growth 导数把输出位移转为 GED；H 说明同一尾界链可从 Gaussian features 扩展到 sub-Gaussian features（p.29–33）。

**可证伪预测**：

1. 固定 `m,ε`，Gaussian one-step 的 GED 应随 `p` 以约 `p^{-1/2}` 下降，而 Laplace one-step 的 GED 不应消失（p.8–9，Figure 1）。
2. 固定 `p,n,m`，增大 `ε` 会减小 Gaussian noise 并使 GED 接近 retrained model；Laplace 仍高于 Gaussian（p.9，Figure 2）。
3. 增大 `m` 会让两种方法 GED 上升；Gaussian 的实测幂律约 `m^{1.4–1.5}`，与理论的 `m^2` 上界存在实践—上界差距（p.9，Figure 3）。
4. 将 Gaussian trade-off 换成 ε-δ certifiability，在相同 ε 和 certifiability level 下会带来更差 GED，尤其在大维度（p.9–10，Figure 4）。

## L. 最终判断

1. **单一主线**：以 conditional hypothesis testing 和 Gaussian trade-off 替换不适合高维加噪的 certifiability 表达，再把一步 Newton residual 控制转成 privacy 与 GED 两个定理；实验验证 Gaussian 相对 Laplace/ε-δ 的高维趋势（p.4–10，式(4)–(17)、Figure 1–5）。
2. **正文保留的决策关键内容**：RERM/删除接口、trade-off/GPAR/GED 定义、A/B assumptions、一步 Newton 式(13)–(14)、Theorem 2/3、`m` scaling、主模拟和真实数据 Figure 1–5（p.4–10）。
3. **附录迁移与自足性**：proof、常数、calibration、旧工作 blow-up 分析、sub-Gaussian extension 和 UED/n=p/2 图移入附录；正文可支持方向性决策，但 sharp 常数、校准可行性和 extension 的可复核性依赖附录（p.15–38）。
4. **最有效的写作/图表/公式模式**：式(5)–(10)先把任意 hypothesis test 压成一维 Gaussian trade-off，再用式(59)–(62)逐步回收定理；Figure 1–3 采用 log–log axes 和同一 `m/ε` 控制条件，使 `p`、`ε`、`m` 三个预测与理论顺序一致（p.5–9）。
5. **最大叙事缺口**：`Gaussian notion` 与 `one-step sufficiency` 的因果归因没有独立 factorial control；Figure 4 同时更换 noise/certifiability，且 Laplace 与 Gaussian 的校准细节没有表格化。Theorem 2/3 的核心 residual bound 借自 Zou et al. 的 Theorem 3.4，H 的 sub-Gaussian 迁移是文字论证，因而「本文证明了普适 Gaussian optimality」的语气超出本文独立 proof 的范围（p.8、p.29–33）。
6. **可迁移规则**：当算法隐私由加噪输出实现时，先明确 adversary 的 hypothesis-testing target，再选择与噪声机制 Blackwell ordering 对齐的 trade-off；同时把 residual bound、noise calibration 和 prediction metric 写成可逐项验证的闭环。
7. **适用边界**：该规则适合输出近似连续、具有可比较 trade-off 的高维参数估计与 approximate unlearning；对离散/结构化输出、非凸深网、分布级删除和 `p≫n`，需要重新选 baseline trade-off、证明 residual control 和设计独立识别实验（p.16、p.19、p.33、p.10）。
