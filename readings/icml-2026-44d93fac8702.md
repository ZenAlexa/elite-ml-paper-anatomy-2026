## Related Work

Related Work 是独立的第 5 节，位于 p.9，约 340 词、正文约 5–6%。两个段落承担不同比较维度：

1. **`gap_creation`（p.9）**；把 reasoning evaluation 分成 task dependence/structure、instance-level proxies（agreement、length/review、forking、linguistic/information-theoretic scores），承认其用途后指出它们主要预测 instance-level correctness，缺少 strategy-level learnability 的量化解释。证据锚点：“many of these explanations are not quantifiable measures”。
2. **`nearest_neighbor_contrast` + `credit_or_foundation`（p.9）**；回顾 Li et al. 与 Aghajanyan et al. 的 neural-network intrinsic dimension、LoRA 继承关系，并明确本工作反转常见设置，固定 model、改变 LoRA rank 以比较 reasoning strategies；同时区分 task-learning objective 的 ID 与 data-manifold intrinsic dimension。证据锚点：“rather than varying the model to study pre-training quality, we vary the LoRA rank”。

相关工作没有重复完整方法推导；引用在后文仍承担解释和基线选择作用（MDL、LoRA、LongPPL、Reasoning Gym）。时间线组织较弱，主要采用问题类别与最近邻差异。

## 方法与理论

### 最小逻辑单元与动作序列

| 序 | 动作 | 内容与前文问题的对应 | 证据 |
|---:|---|---|---|
| 1 | `setup_notation` | 用 `θ = θ0 + P(θd)` 定义 pretrained 参数、总维度 `D`、低维向量 `d` 与 projection `P`；把“任务需要多少自由度”形式化 | p.2，§2.1：“θ ∈ R^D … θ = θ0 + P(θd)” |
| 2 | `contrast_alternative` | 说明全参数 random projection 对大模型优化困难，选择 LoRA 作为结构化 PEFT 投影 | p.2，§2.2：“randomly projected spaces can be challenging and sub-optimal” |
| 3 | `define_component` | 对冻结 `W0` 使用 `W = W0 + BA`，以 rank `r` 与目标矩阵组限制更新子空间 | p.2，§2.2：“LoRA represents the weight update as” |
| 4 | `state_complexity` | 给出 `params(r,LLoRA) = 2 × LLoRA × dmodel × r`，将 trainable capacity 映射为可扫的维度 | p.2，§2.2：“total number of trainable parameters” |
| 5 | `derive` | 定义 `dint = min{d : A(d) ≥ τ}`，其中 `A(d)` 是训练 accuracy，`τ` 为共同目标 | p.2，§2.3：“minimum number of trainable parameters” |
| 6 | `instantiate_algorithm` | 取 `k` 个 log-uniform 参数目标，组合 rank 与四组 target modules；训练每个配置并记录完成时 training accuracy | p.3，§2.3：“sweep of k LoRA configurations” |
| 7 | `connect_to_prediction` | 解释 percentage-of-validation threshold 在不同 CoT 数据集间不可比，因此跨策略使用 common absolute threshold | p.3，§2.3：“use a common threshold τ across all strategies” |
| 8 | `connect_to_experiment` | 采用任一策略 full-capacity、epoch-1 training accuracy 的最大值（默认其 90%）作为阈值；Figure 1/2 展示 crossing | p.3、p.7，§2.3/§4.4：“maximum training accuracy achieved by any strategy at full capacity after one epoch” |

动作转移序列为：`setup_notation → contrast_alternative → define_component → state_complexity → derive → instantiate_algorithm → connect_to_prediction → connect_to_experiment`。方法没有伪代码框或编号算法；Appendix A.1 用文字列表给出配置选择过程。

## 最终判断

1. **单一主线**：固定学生模型与任务问题来源，仅改变 reasoning-chain supervision；用 LoRA trainable parameter sweep 找到达到共同 accuracy threshold 所需的最小 `dint`，再检验 ID 是否预测 held-out generalization。论文把“有效链条”解释为更容易被模型压缩的 task mapping。
2. **正文保留的决策关键内容**：`dint` 定义、LoRA 参数公式、common threshold 理由、14-strategy 4B/1B 主表、Figure 2、threshold robustness、correctness mix、Reasoning Gym transfer，以及 PPL/KL/length 对照。读者可以在正文重建比较逻辑和主要数字。
3. **移入附录的细节及自足性**：greedy LoRA configuration、收敛/学习率 sweep、GSM8K 与 Reasoning Gym split size/decontamination、LongPPL、策略样例、逐 split Tables 8–9。主结论保持自足；若要判断样本量、错误链或 OOD 异质性是否构成替代解释，附录成为必要证据。
4. **最有效的写作/图表模式**：Figure 1 把 strategy→adapter sweep→ID/OOD 的因果阅读路径画在一张图里；Figure 2/3 用共同阈值与 Pareto frontier 把抽象 ID 定义映射为 crossing；Tables 1/2 同时放效果和 baseline metrics，使相关性比较直接。
5. **最大叙事缺口**：strategy-level correlation 被用作“压缩机制”的主要证据，因果识别、直接 compression measure、seed/hardware 波动和跨 PEFT 一致性仍缺失。实践 guidance 只停留在 implication；绝对 ID 的跨模型比较还受到 1B/4B 阈值不同的限制。
6. **可迁移规则**：比较多种输出/推理策略时，固定模型和问题源，预先规定跨策略共同 capability threshold；同时报告 capacity sweep、held-out generalization 和容易混淆的 length/likelihood 基线。
7. **适用边界**：该规则适用于同一任务、模型家族和 fine-tuning/PEFT 框架内的相对 strategy comparison。LoRA ID 是上界式 operational proxy，不能直接等同于 Kolmogorov complexity；有限的 GSM8K/Reasoning Gym、两种 Gemma 规模与未报告训练硬件/seed 也限制外推。
