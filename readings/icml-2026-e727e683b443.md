## 4. 方法与理论链

### 最小逻辑单元

- **设置**（pp. 2–3）：定义带上下文的 attention/residual 输出 `v_C=A(C,x)`，以及 reduced context 的 `v=A(C\setminus Y,x)`；经 `RMSNorm` 得 `z_C,z`。
- **Gemma 单块构造**（p. 3）：对 `W_gate`、`W_up` 作 rank-1 更新，使无上下文的规范化输入再现 `Wz_C`；对 output scale `m` 作逐元素更新，补偿 residual 差。Theorem 1 的条件是目标 MLP activation 每个元素非零。
- **多层推广**（p. 4）：Theorem 2 用层索引归纳，在每层保持隐藏状态一致；Algorithm 1 先记录 full-context target activations，再逐层计算 patch，以当前 patched 输出送入下一层。
- **统一抽象**（pp. 6–8）：将 inner function 的输入校正称作 `input controllability`，把 residual 差移交 outer function 称作 `output controllability`。Theorem 3 以两步 proof 连接两者。
- **架构边界与解释**（p. 9）：固定尺度的 post-RMSNorm 无法保证 output controllability；trace-loss 连接说明更新可写成一个 pseudo-loss 的 gradient step，作者同时说明这不等于模型在 inference 时真的执行该学习算法。

动作序列为：`setup_notation → derive → explain_mechanism → derive → instantiate_algorithm → connect_to_experiment → define_component → derive → contrast_alternative → scope_boundary`。

|项目|位置|角色与边界|

### Algorithm 1

Algorithm 1 位于 p. 6，输入为 `Θ,x,C,C\setminus Y`，输出为 `Θ′`。它有两个顺序循环：先用 full context 记录 `L` 层 target activation，再从 reduced context 开始逐层以 Eq. 2–4 或 Appendix B 计算 `Δθ_l`。关键不变量是每层 patched output 重新成为下一层输入，并因而吸收数值误差。算法给出层数循环，未给 Big-O；正文把层级含义解释到 activation recording / update / feedback 这一粒度。

## 5. 实验设计、统计与结果

### 设计事实

- **对象与任务**：instruction-tuned Gemma 3 1B 与 4B（p. 5），文本 prompt 的自回归生成；Gemma 3 4B 的 image context（p. 7）；Falcon-7B 的扩展验证（pp. 17–18）。没有命名 dataset，也没有说明 image 来源。
- **处理与对照**：baseline 用 full prompt `C`；updated model 不输入显式 context，而对每个新 token 重算 `Θ′`（p. 5）。两者在相同 generation history 上比较。若 top token 分叉，作者记录差异后强制 updated model 使用 baseline token，继续比较后续分布。
- **指标**：argmax token matching、`L_∞` logit difference、Total Variation Distance（p. 6）；appendix 增加 Hellinger distance、rank distance、top-1 difference、matrix Frobenius norm 和 vector L2 norm（pp. 16–17）。
- **精度与条件**：`float32`、`bfloat16` 和 `bfloat16 (Stable)`；stable 版本使用 Appendix B 的 RMSNorm inversion（p. 6）。
- **报告缺口**：随机 seed、样本/生成 token 分母、hardware、inference runtime、超参数、训练预算与实现仓库均未在 PDF 中给出。论文运行已训练模型的推理评估，因此 training budget 对本文实验不适用；推理计算成本仍未报告。

统计单位是每个生成 token 的 paired next-token distribution；正文没有检验、confidence interval、bootstrap、Bayesian analysis 或多重比较说明。Figure 4、8、9、11–13 用 boxplot、散点或柱形汇总分布，caption 未交代样本数、whisker 定义或跨 seed 聚合。图注通常说明比较对象和指标，统计分母不足以独立复现。

## 9. 用词、修辞与最终判断

主文中高频实词围绕 `context`、`update`、`implicit`、`weight`、`controllability`、`transformer`、`output`、`input`、`equivalence`。高频短语为 `implicit weight updates`、`input controllability`、`output controllability`、`full context`、`reduced context`、`numerically stable update`。这些词由推导对象和组件名驱动，不主要来自模板性贡献语。

以 pp. 1–10、references 前文本作机械短语检查：`we show` 5 次、`we find` 1 次、`we demonstrate` 1 次、`we prove` 1 次、`we introduce` 3 次、`we provide` 3 次、`we test` 1 次、`we hypothesize` 1 次。强主张词 `perfect` 8 次、`exact` 6 次；`provided` 3 次、`assuming` 1 次和 `however` 5 次将核心结论收束到可控性与非零条件。`near-perfect`、`near-identical`、`almost exact` 等弱化词出现在实证段，形成「定理 exact、低精度经验近似」的分层。

**单一主线**：把上下文造成的 attention/residual 差分分成内部输入校正和外部输出补偿；当 inner/outer controllability 条件满足时，可用 token-dependent parameter update 复现 full-context block 的当前 token 输出（pp. 3、8）。

**最可迁移规则**：先为单一可验证对象写出精确等式与条件，再以 constructive update、层间归纳和相同-history 的配对实验形成闭环；每个「现代架构」总称都要在 component-level table 或 theorem assumption 中落地（pp. 4–8）。

**规则边界**：这套写法适合能清楚给出运算图、参数自由度和配对输出的理论/机制工作。它不能把 per-token、recomputed patch 扩写成持久训练、全 prompt 缓存或任意自由 rollout 的证明；经验图也需要明确 token 分母、seed、计算代价和实现条件才可支持更广泛的性能结论（pp. 5、9、20）。
