## 5. 方法与理论：从对象到可部署模型

### 最小逻辑单元与转移

方法的主要推进为：

`setup_notation → state_problem → define_component → explain_mechanism → instantiate_algorithm → derive → connect_to_experiment → state_complexity`。

- **形式化对象**：数据分布 `D`、预算集合 `B`、模型 `(f, θ)`、变换 `Tβ`、性能 `R` 和成本 `C` 首次在 §2.1 定义；理想目标是预算约束下的最优 `Tβ*`。[p. 2, §2.1, Eq. (1)]
- **理想与可训练目标**：Definition 2.1 把每个预算配置在 Pareto front 上定义为 optimal elasticity；Eq. (2) 用带权 KD／任务损失近似该不可直接求解的双层问题。[p. 3, §2.1–2.2, *Pareto Elastic Model*]
- **Layer Decomposition**：DataSVD 以 activation-weighted reconstruction error 产生 `U_l,V_l` 和每层有序 rank components；它回答“低秩候选如何初始化”。[p. 4, §3.1, Eq. (3)]
- **Nested Submodel Search**：Eq. (4) 选择跨层 rank 向量并加入 `m_{k-1} ⪯ m_k`；DP 依赖 per-layer additive probe 与 ranking preservation，回答“全局预算如何选择 nested profiles”。[p. 4, §3.2, *the search space contains K^L submodels*]
- **Knowledge Consolidation**：固定 profile 后，Eq. (5)–(6) 随机抽预算进行 base-model distillation，回答“独立 layer 分解忽略 cross-layer dependency”造成的性能问题。[p. 4, §3.3, *refine all configurations through knowledge distillation*]
- **GAR**：Eq. (7) 将已选 rank 的 factorization 重参数化，声称从常规 dense `O(mn)` 转向 `O((m+n-r)r)`，回答“rank savings 如何转成 inference savings”。[p. 5, §3.5, *strictly less than the O(mn) FLOPs*]

### 算法、图和公式

- **Algorithm 1**（p. 3，method）有三段循环：逐层收集 `Z` 的 activations 并 DataSVD；逐层构造 rank drop candidates 后 `DPRankSelection`；在训练中从候选 profiles 采样并用 KD 更新共享参数。部署时再为给定 `β` 选 profile 并对每层应用 GAR。输入为预训练模型、calibration data、training data 和 budget set；输出是 elastic `θ` 与 ordered Pareto front `M*`。关键不变量是 profile 在训练前固定且 componentwise nested。[p. 3, Algorithm 1, *sample m*_t from M_c*]
- **Algorithm 2**（p. 22，appendix）把 layer candidates 扩展为 DP frontier，保留同 saving 下最小 error、Pareto-prune、backtrack，再通过 `NestedChain` 筛 componentwise-nested chain。正文给出层级 DP 的 `O(L·K)`；附录给出总 probing `O(L·K·C_eval)` 对比 brute force `O(K^L·C_eval)`。这两项复杂度都依赖预计算 sensitivity 与可加 probe 的设计。[p. 22, §C.2, *error probe is to make ... tractable*]
- **Algorithm 3**（p. 23，appendix）展开 `ExpandLayer`、`KeepMinErrorPerSaving`、`ParetoPrune`、`Backtrack`、`ParetoFilter` 与 `NestedChain`，使 Algorithm 2 的选择规则可复现到数据结构操作层。[p. 23, Algorithm 3, *return P'*]
- **Figure 1**（p. 2）是方法总览：左到右的 Layer Decomposition、Nested Submodel Selection、Knowledge Consolidation；中间用包含关系标出 nested models，右侧以 teacher/base model 供 consolidation。它把 §3 的三阶段压缩为一条 pipeline。[p. 2, Figure 1, *three stages*]
- **Figure 3**（p. 5）放在 §3.4，显示从 random weights 或 DataSVD 初始化训练的 nested submodels；正文把它用作“在该受控设置中 recovery true Pareto front”的可视化证据，不能外推为任意架构上的精确保证。[p. 5, §3.4/Figure 3, *recovers the Pareto front*]

## 12. 最终判断

1. **单一主线**：先用 DataSVD 给各层 rank component 建立局部顺序，再用可加 probe 的 DP 选择 nested profiles，最后以随机 profile KD consolidation，让一组 factorized weights 服务多个 deployment budgets。该主线从 Figure 1、Eqs. (3)–(6)、Algorithm 1 到 Figures 4 与 8 形成闭环。[p. 2, Figure 1, *Layer Decomposition*] [p. 4, §3.3, Eq. (6)]
2. **正文保留的决策内容**。问题、核心定义、三阶段算法、线性 theorem statements、主要 task curves、后适配表和三个 ablation 都留在 p. 1–9。正文对“为何 nested”给出了图和 theorem statement，也给出了最终性能。[p. 6, §4, *Nested Subspace Learning*]
3. **附录迁移的后果**：B 放证明，C 放 DP 达成率与机制细节，D 放可复现参数和效率条件。迁移没有破坏方法理解；它削弱了正文对理论证明、ranking-assumption 诊断和可复现训练细节的自足性。[p. 22, §C.3, *not an exact theorem/solution*]
4. **最有效的模式**。Figure 1 的三阶段总图先建立读者心智模型。Section 4 再以 PTS → ASL → NSL 三个反例／正例组织理论，Figure 2 让定理的差异可见，Figure 8 在大模型设置重测同一机制。这种由机制、受控证据和实规模消融组成的链条最清楚。[p. 5, Figure 2, *zero only for NSL*] [p. 8, Figure 8, *Joint submodel training is essential*]
5. **最大未闭合处**。DP 的 ranking-preservation 只在受控 exhaustive setting 中有诊断证据。PDF 对该 setting 给出互相不一致的描述。正文说 four-layer、two CNNs、two MLPs 和 MNIST。C.3 也说 MNIST。D.1 则说 two fully connected linear layers 和 Gaussian synthetic data。这个事实使该验证的准确实验身份为 **uncertain**，不能自行合并解释。[p. 4, §3.4, *two CNNs and two MLPs trained on MNIST*] [p. 23, §D.1, *two fully connected linear layers*]
6. **可迁移规则**。当论文同时主张共享模型、配置选择和部署收益时，将每个环节放到一个可见对象上。算法给固定 invariant。受控实验检验该 invariant。真实任务图测部署曲线，并单列 runtime 条件。这样可避免把一个总曲线误写为三个机制均已证实。
7. **规则的边界**：该规则适合能枚举或诊断核心选择机制、并能用受控问题解释共享干扰的工作。若目标是纯经验系统且没有可辨识的内部选择机制，应改为清楚报告操作条件与任务级结果，不能虚构理论闭环。
