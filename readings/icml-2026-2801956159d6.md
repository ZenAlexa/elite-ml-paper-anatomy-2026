### 4.1 最小逻辑单元与动作转移

主方法的段落动作序列是：

`setup_notation (Eq. 1–3) → state_problem (Eq. 4–5) → contrast_alternative (Eq. 6–10) → derive (Theorem 3.1 / Eq. 11) → define_component (Definition 3.2 / Eq. 12) → explain_mechanism (Eq. 13–14) → instantiate_algorithm (Algorithms 1–2, Eq. 15–18) → state_complexity → guarantee (Theorems 3.4–3.5) → connect_to_experiment (Table 2)`。

|---|---|---|---|
| 扩散设定 | p.2, §2.1, Eq. (1)–(3) | `x0` 经 forward kernel 到 `xt`；`sθ(xt,t,c)` 反向采样。 | 给出能把 sample state 与 score 联系起来的 base process。 |

### 4.2 算法、图与复杂度边界

- **Algorithm 1**（p.4）：输入 `sθ, c, δ, n, r`；对 `n` 个先验噪声用 `δ` 步 solver 生成 `x̂i0`，再注释 `ri = r(x̂i0,c)`；输出固定的 `{x̂i0, ri}` 集。其关键不变量是 lookahead set 在 target sampling 之前完成，不在每个 `xt` 上重新 rollout。
- **Algorithm 2**（p.4）：输入 `sθ, {x̂i0,ri}, s, τ`；从 `xT` 开始，在 `k=τ,…,1` 的 target loop 中以 Eq. (16) 计算 guidance，再用修正 score 解 Eq. (3)；输出 `x0`。算法明确了一个时间循环，没有嵌套的 neural rollout loop。
- **方法图**：Figure 1（p.2）用两阶段示意图呈现预生成和带 reward attraction/repulsion 的 target sampling。Table 1（p.1）是 prior-method 属性矩阵，不是方法表。
- **复杂度**：没有 Big-O 或 memory theorem。作者将 efficiency 设为经验性的 time / memory 比较，并在 Appendix Table 9 将 13.41 s 拆为 5.69 s lookahead、0.65 s annotation、7.07 s target sampling（p.25）。

主文 p.1–9 的固定 authorial structures：`we show` 1 次（Abstract，p.1），`we propose` 2 次（引言 p.2、Conclusion p.9），`we introduce` 1 次（Abstract，p.1）；未见 `we find`、`we demonstrate`、`we observe`。`we refer to` 2 次用于命名 LiDAR（p.1–2）。这些计数按可见主文字符串计，不把附录、references 或图 caption 单独扩展。

最常见的主张动词是 `show`、`propose`、`introduce`、`achieve`、`outperform`、`improve`；限定词和边界词包括 `under mild conditions`、`approximately`、`nearly identical`、`may`、`potential`、`slightly`。对比词为 `however`、`in contrast`、`while`；因果连接依赖 `therefore`、`consequently`、`as a result`。摘要和结论偏强断言，附录在 theorem 条件、D.3 diversity 和 Impact Statement 使用较弱语气。全文的强/弱主张精确比例因 sentence-level rhetorical coding 存在边界，标记为 `uncertain`，不以自动词频代替判断。

## 9. 最终判断

1. **单一主线**：以 forward marginal samples 重写 intermediate EFR，借 few-step lookahead 标注 reward，再用 Eq. (16) 的 softmax-weighted、derivative-free guidance 推动 target sampler；`δ` 和 `n` 是可用于 test-time scaling 的两条控制轴（p.4–6，§3）。
2. **主文保留的决策内容**：问题、现有路线的结构性失败、公式与两个算法、四个 theorem statement、Table 2 / Figure 4 的核心效率比较、extension 端点和 discrete token-independence limitation（p.1–9）。
3. **附录迁移是否伤害自足性**：不会妨碍读者理解因果机制或读取主 benchmark；会阻碍对 theorem assumptions、baseline tuning、EFR oracle 和 diversity cost 的独立审计，因此主文的经验可复现闭环是部分自足（主文 p.4–9；附录 p.17、p.21–25）。
4. **最有效的模式**：先把 EFR 的神经依赖改写为 Eq. (11)，立即把可计算后果落为 Eq. (16) 和两段算法，然后用 Table 2 / Figure 4 对齐「效果、时间、显存」这一主张。这条链在 p.4–7 连续可见。
5. **最大读者成本 / 未闭合处**：报告缺少 seeds、离散量、human evaluation 与 pointwise curve values；`s` 以 IR 选择；部分关键边界在附录。它们限制统计确定性和泛化范围，而不否定已展示的 benchmark 点估计（p.6、p.21、p.23–25）。
6. **可迁移规则**：主文应把「新的可计算对象 → 产生的算法动作 → 一个直接的决策性比较」紧邻排布；证明和 parameter grid 可放附录，但正文必须用明确 section call 保留审计路径（本例 p.4–7 与 p.14–25）。
7. **规则边界**：当关键主张依赖隐含的 evaluation protocol、tuning split 或不可重建的 oracle 时，不能仅靠主文 headline 与曲线完成闭环；至少应在主文提供足以复核比较单位和选择准则的最小信息（本例 Table 2 p.6 与 B.1–B.4 p.21–24）。
