## E. 方法与理论

### E.1 逻辑结构与对象

方法第 3 节从形式化数据对象开始。`θ` 为 VLM，`D={(v_i,q_i,a_i)}_{i=1}^N` 为 VQA 三元组。模型先生成 rationale `r_i`，形成 `R`；每个目标样本与 counterpart 构成 contrastive pair `P`；contrasting 与 rethinking 产生 `\tilde R`，最后用 VisCoR-55K 对 `θ` 做 supervised finetuning。作者明确提出两个挑战，包括如何 curating meaningful pairs，以及如何把 dual-image contrasting 的 discriminative ability 转移到 single-image reasoning。[p.4, §3] “VC-STaR is designed to address two key challenges”

## L. 最终判断

1. **单一主线**：VLM 单图 reasoning path 中的 visual hallucination 难以由 text-centric self-improving 纠正；将同义问题配到视觉相似但细节不同的 counterpart，利用 VLM 的 dual-image comparison 产生 contrastive analysis，再用 rethinking LLM 修正 coarse rationale，筛成 VisCoR-55K 并 SFT，从而把「对比时更会看」转成单图 reasoning 的训练数据。
2. **正文保留的决策关键内容**：pair 的三个条件、GTE/visual embedding 与 cosine thresholds、easy/median/hard 定义、Think/Contrast/Rethink 三步及四个公式、SFT 主配置、六 benchmark Table 1、Fig.5 qualitative grounding、Fig.6 pair construction、Tables 2–4 的模型/难度/正负 pair 分析。它们共同支撑方法可运行和主要相对分数结论。
3. **移入附录的细节及影响**：完整 prompts、greedy first-match-exit 与 240K→86K→55K 数据流程、21 数据集分布图、更多 rationale 案例在 A.2–A.4。主文能读懂方法，但 prompt 级复现、pair 搜索复杂度、过滤结果与 rationale 风格核验依赖附录；附录没有补上 seed、硬件、误差或 filter 误删率。
4. **最有效模式**：Fig.1 先用同一批初始失败样本把 H/C/C&H 的纠正差异可视化；Fig.4 把 Think→Contrast→Rethink 与实际 rationale 对齐；Table 1 同时保留六个 benchmark 列和统一 Avg.；Table 4 用 positive/negative/combined 的受控组合展示机制方向。图、公式、表都服务于「对比→更忠实 rationale→跨任务 SFT」链条。
5. **最明显的叙事规避或读者成本**：正文把机制质量、数据筛选和 prompt 细节分散到附录，缺少全体 rationale fidelity、seed 方差和硬件成本；Table 1 的单个平均值压缩了 benchmark 异质性，且正文 “2.4% average improvement” 与表格差分 2.6 不一致；easy-sample 趋势也并非所有列严格单调。off-the-shelf baselines 的数据生成机制不同，跨数据集比较仍有 confounding。
6. **可迁移规则**：若训练目标是视觉/多模态 reasoning，先构造能锁定语义问题、迫使模型区分细粒度视觉差异的 paired counterfactual，再把比较产出的证据链用于 rationale refinement；主结果表同时保留逐任务分数与统一汇总，消融至少覆盖数据构造、难度、模型迁移和机制替代。
7. **适用边界**：该规则依赖可获得的视觉相似度检索、可靠的同义问题和可验证答案；本文只在 21 个既有 VQA 数据集、三种 VLM 型号、六个 benchmark、固定阈值和单次分数口径内验证，不能据此保证 hard samples、未覆盖任务或部署场景的效果，也不能把 benchmark 提升单独归因于 “inherent contrastive ability”。
