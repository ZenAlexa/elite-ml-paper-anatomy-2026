## 方法与理论

### 3.1 Problem Setup

- **形式化对象**；`Dfull := {(x^(i), y^(i))}_{i=1}^N ~ p(x,y)`；features 为 `x_1,…,x_D`，把 `x_{D+1}:={y^(i)}_{i=1}^N` 并入变量集合 `X`；`Dref` 为 train split，`Dtest` 为 test data，generator 由 `Dref` 生成 `Dsyn`。[p.4，§3.1，anchor； “We refer to any dataset being assessed as evaluation dataset D”，basis=explicit]
- **SCM**；在 causal sufficiency、Markov property、faithfulness 假设下，`M:=⟨X,G,F,E⟩`；`G` 是 causal graph，`E` 是 exogenous noise，`F` 是 structural functions，`x_j=f_j(pa(x_j),ε_j)`。[p.4，§3.1，anchor； “Under the assumptions of causal sufficiency, the Markov property, and faithfulness”，basis=explicit]
- **结构保真定义**；synthetic data 的 SCM 与 GT causal structure 的 alignment；作者把 SCM 作为 empirically effective structural prior，而非宣称其对所有 tabular data 有理论保证。[p.4、p.28，§3.1/C.1，anchor； “define the structural fidelity … as the alignment”，basis=explicit]

### 3.2 CI-based structural fidelity

- **对象层级**；评估 Markov equivalence class 的 CPDAG，而非 skeleton 或完全定向 DAG；目标是让 `Dref` 与 `Dsyn` 具有相同的 CI statements。[p.5，§3.2，anchor； “represented as completed partially directed acyclic graphs”，basis=explicit]
- **全局 CI 集**；对每个变量对 `(x_j,x_k)`，枚举所有 conditioning subsets；把 d-separation 的集合 `S_{j,k}` 和选择性删除元素后得到的 d-connection 集合 `Ŝ_{j,k}` 都放进 `C_global`，因此既测独立也测依赖。[p.5、p.25–26，§3.2/B.1，anchor； “we enumerate all subsets S ⊆ X \ {xj, xk}”，basis=explicit]
- **CI test**；在 `α=0.01` 下，若 CI statement 未被拒绝则指标为 1，否则为 0；`CI(C,D)` 是所选 statement 的 indicator 平均值，范围 `[0,1]`。[p.5，§3.2，anchor； “the significance level α = 0.01”，basis=explicit]
- **局部与全局**；`C_local` 只保留直接涉及 prediction target `y=x_{D+1}` 的 CI/依赖关系，服务 `p(y|x)`；`C_global` 覆盖全部变量对，减少对单一 target 的偏向。[p.5，§3.2，anchor； “Global CI provides a comprehensive assessment of the entire causal structure”，basis=explicit]
- **CPDAG 取舍**；skeleton 删除方向会把物理-law 解释混淆；DAG level 需要在 reference/synthetic 上可靠做 causal discovery，当前方法在高维 tabular data 上不稳定且昂贵。因此 CPDAG 被写成 semantic richness 与 computational feasibility 的折中。[p.5–6、p.28–29，§3.2/C.2，anchor； “strikes a good balance between evaluation efficiency and validity”，basis=explicit]

### 3.3 Global Utility

- **SCM-free 动机**；真实数据通常没有可识别 GT SCM，无法直接枚举 `C_global`；作者采用 “SCM-inspired and real-data-validated” heuristic。[p.6，§3.3，anchor； “ground-truth SCM … typically unavailable or even non-identifiable”，basis=explicit]
- **逐变量 utility**；把每个 `x_j` 当作 prediction target，用其余变量预测；categorical 用 balanced accuracy，numerical 用 RMSE。`Utility_j(D)` 对 categorical 取 `Perf_j(D)/Perf_j(Dref)`，对 numerical 取 `Perf_j(Dref)/Perf_j(D)`，故 utility ≥1 表示不低于 reference。[p.6，§3.3，anchor； “Utilityj ≥ 1 indicates … on par with or better”，basis=explicit]
- **ensemble**；使用 AutoGluon-full 的 8 个 predictors 加 TabPFN，合计 9 个，以削弱单一 downstream predictor 的 inductive bias；full-tuned 对每个 feature 给 1 小时 tuning budget。[p.6、p.25–26，§3.3/B.2，anchor； “we ensemble nine different predictors with AutoGluon”，basis=explicit]
- **local/global utility**；`Utility_{D+1}(D)` 是 local utility；`Global Utility(D)=(1/(D+1))∑_{j=1}^{D+1}Utility_j(D)`，让所有 variables 平均进入评价。[p.6，§3.3，anchor； “aggregating the utility across all features”，basis=explicit]
- **可识别性边界**；global utility 与 global CI 的强相关是 empirical finding，不是 formal proof；它是 likely SCM 的 empirical lens，而非真实因果结构的识别定理。[p.8、p.10、p.48，§4.2/4.4/E.6，anchor； “an empirical finding rather than a formal proof”，basis=explicit]

### 公式、理论结果和算法

- **主要公式库存**；
  1. `x_j=f_j(pa(x_j), ε_j)`；SCM structural function；不是编号公式，但连接 graph、noise 与 data generation。[p.4，§3.1，anchor； “xj = fj (pa(xj ), ϵj )”，basis=explicit]
  2. `C_global` 的 separation/connection 集合定义（Eq. 1）；生成完整 CI statements。[p.5，§3.2，anchor； “The full set of CI statements … is defined as”，basis=explicit]
  3. `I_α(…;D)`（Eq. 2）；α-level CI test 的二值结果。[p.5，§3.2，anchor； “if the CI statement is not rejected on D”，basis=explicit]
  4. `CI(C,D)=|C|^{-1}∑ 1[I_α=1]`（Eq. 3）；选定 CI 子集的平均 fidelity。[p.5，§3.2，anchor； “CI (C, D) ∈ [0, 1] measures the fidelity”，basis=explicit]
  5. `Utility_j(D)`（Eq. 4）；按 categorical/numerical 方向归一化 utility。[p.6，§3.3，anchor； “measured using balanced accuracy … and RMSE”，basis=explicit]
  6. `Global Utility(D)=(D+1)^{-1}∑ Utility_j(D)`；全变量平均的 SCM-free metric。[p.6，§3.3，anchor； “Global Utility(D)”，basis=explicit]
  7. `p(X)=∏_{j=1}^{D+1}p(x_j|pa(x_j))`；CPDAG rationale 中的 joint factorisation。[p.29，Appendix C.2，anchor； “joint distribution factorisation p(X)”，basis=explicit]
  8. latent-confounder variant 的 `x_j=f_j(pa(x_j),ε_j)+∑_{k:j∈S_k}λ_{kj}U_k`；E.4 的 proof-of-concept 数据生成式。[p.44，Appendix E.4，anchor； “modify its structural function via xj = fj”，basis=explicit]
- **理论结果**；没有 theorem、lemma、proposition 或 corollary；没有 formal proof。CPDAG 作为 Markov equivalence/minimal I-MAP 的说明属于 `explanation`，global utility–global CI 关系属于经验预测而非 guarantee。[p.8、p.29、p.48，§4.2/C.2/E.6，anchor； “not a formal proof of a connection”，basis=explicit]
- **Algorithm 1**；输入 DAG `G`，对 unordered variable pairs 枚举所有 conditioning subsets，通过 d-separation 写入 CI，再删除 separator element 检验 d-connection，输出 `C_global`。循环层级为 pair → subset → separator element；关键不变量是每个 pair 的 separation/connection statements 完整，正文没有给出显式 Big-O 复杂度。[p.26，Appendix B.1.1，anchor； “Algorithm 1 Derive complete CI statements”，basis=explicit]

## 实验设计

### 研究问题与对象

- **四个 RQ**；Q1 benchmark framework validity；Q2 global utility validity；Q3 generator structural fidelity；Q4 global utility practicability。[p.7，§4，anchor； “We evaluate 13 tabular generators on 29 datasets”，basis=explicit]
- **SCM 数据**；核心结果使用 6 个 bnlearn expert-validated SCM datasets；Hailfinder、Insurance、Sangiovese（classification）以及 Healthcare、MAGIC-IRRI、MEHRA（regression），7–64 features，均为 100,000 samples。[p.7、p.30，§4/D.1.1，anchor； “six expert-validated SCM datasets with 7-64 features”，basis=explicit]
- **扩展 SCM**；Appendix E.2 再加入 ANDES、Diabetes、Link、Pathfinder、PIGS 五个大 SCM；Appendix D 总列 11 个 SCM 数据集，主 benchmark 仍称 6 个。[p.30、p.39，D.1.1/E.2，anchor； “five additional datasets … with large-scale SCMs”，basis=explicit]
- **真实数据**；14 个 TabZilla/OpenML classification 数据集，846–98,050 samples、6–145 features；9 个 regression 数据集，345–22,784 samples、6–82 features，合计 23 个、覆盖 OpenML/UCI 和多领域。[p.7、p.30–31，§4/D.1.2，anchor； “23 challenging real-world datasets”，basis=explicit]
- **生成器**；13 个现有方法、9 个 category；SMOTE、BN、TVAE、GOGGLE、CTGAN、NFlow、ARF、TabDDPM、TabSyn、TabDiff、TabEBM、NRGBoost、GReaT；另有 `Dref` 作为 reference evaluator。[p.7、p.32，§4/D.3，anchor； “13 existing tabular data generation methods of nine different categories”，basis=explicit]

### 切分、控制和测量

- **切分**；`Dfull` 先 80% train/20% test，再将 train 按 90%/10% 分为 `Dref`/validation；classification 保持 stratification；重复 shuffle 10 次；generator 输出 `Nsyn=Nref`。[p.7、p.32，§4/D.2，anchor； “80% train and 20% test”，basis=explicit]
- **调参**；generator 用 Optuna 最小化自身 validation loss 的 10-repeat average；每个 generator 每个 repeat 最多 2 小时，避免用外部评估指标调参。[p.7、p.32–33，§4/D.3，anchor； “tune each generator based on its own objective function”，basis=explicit]
- **下游预测器**；Full-tuned 9 个 predictors；Light-tuned 8 个；Tiny-tuned 3 个；Tiny-default 为 3 个未调参 predictors。每个 feature 的 full ensemble 每 repeat 1 小时，TabPFN 用默认超参数。[p.25–27、p.37，Appendix B.2/D.4，anchor； “Full-tuned … nine predictors”，basis=explicit]
- **四个维度**；density estimation（Shape、Trend、α-precision、β-recall）、privacy preservation（DCR、δ-Presence）、ML efficacy（local utility）、structural fidelity（local CI、global CI、global utility）。[p.4、p.8，Table 1/Table 2，anchor； “four complementary evaluation dimensions”，basis=explicit]
- **预处理**；数值缺失用 mean、类别缺失用 mode；categorical one-hot（TabDiff 用 ordinal）；numerical Z-score；统计量只从 training split 计算，再变换 validation/test；送入 downstream predictor 前 inverse-transform 回原空间。[p.32，D.2，anchor； “compute each feature’s mean and standard deviation in the training data”，basis=explicit]
- **公平性/污染控制**；数据为公开、contamination-free benchmark；选择的 real-world data 不在 TabPFN meta-validation stage；排除 proprietary/undisclosed LLM。作者没有提供独立外部 test set 作为主流程的一部分。[p.21、p.31，A.3/D.1.2，anchor； “reducing the likelihood that their causal structures were implicitly leaked”，basis=explicit]
- **随机性与硬件**；固定 data loading/evaluation random seeds；统一 PyTorch Lightning pipeline；NVIDIA A100 80GB、Intel Xeon 2.20GHz 64 cores、Ubuntu 20.04.5 LTS。[p.37，D.6，anchor； “fixed the random seeds for data loading and evaluation”，basis=explicit]
- **聚合**；先对每个 dataset 的 10 repeats 取默认报告结果，再在 SCM 或 real-world datasets 内用 ADTM（top/worst affine renormalisation）聚合；Table 2 报告 normalized mean ± std。[p.7、p.37，§4/D.5，anchor； “average distance to the minimum (ADTM)”，basis=explicit]
- **失败判定/实现粒度**；正文没有预注册失败阈值；附录提供 generator hyperparameter spaces、软件库、raw per-dataset tables。GOGGLE/official TabDDPM 的不收敛、GReaT 的高维不收敛是观察到的运行问题，不是预注册 exclusion rule。[p.33、p.35、p.42，D.3/E.3，anchor； “may fail to converge”，basis=explicit]

## 结果、统计与可视化

### 统计协议

- **聚合单位与分母**；10 个 repeated shuffles 是 run 层级；主表在 6 个 SCM 或 23 个 real-world datasets 上聚合，均值的离散量为跨 dataset 的 std。`Dref` 作为参考行并不自动达到所有 metric 的理想值。[p.7–8、p.29，§4/D.5/C.2，anchor； “reported results are averaged by default over 10 repeats”，basis=explicit]
- **CI tests**；categorical 用 chi-square test；numerical 用 Pearson partial correlation；mixed 用 residualisation-based test；默认 `α=0.01`，pgmpy 实现。[p.5、p.25，§3.2/B.1.2，anchor； “we implement all conditional independence tests using pgmpy”，basis=explicit]
- **效应与排序**；主要关系用 Spearman rank correlation `r_s`；报告 p 值（多数 `p<0.001`），未报告 multiple-comparison correction、bootstrap、Bayesian posterior、回归拟合或传统区间。[p.8–10、p.38–47，§4/E，anchor； “Spearman’s rank correlation”，basis=explicit]
- **误差表达**；Table 2、Table 23 及 raw tables 使用 `mean ± std`；Figure 7 也说明每 feature utility 配标准差；图注能说明对象和方向，但不能独立给出所有下游 predictor/seed 细节。[p.8、p.39、p.43，Table 2/23/Figure 7，anchor； “normalised mean ± std metric values”，basis=explicit]

### 主结果清单

1. **Q1；指标能区分参考与低质量数据。** Table 2 中 `Dref` 在 density、ML、CI/utility 等指标基本为最高，privacy 指标为 0；作者据此认为 metrics 能辨别 high/low quality。关键不利信息是 privacy 的方向与其他指标相反，而且 `Dref` 的 local utility/global utility 也有 0.99/0.96–0.99 的波动。[p.7–8，§4.1/Table 2，anchor； “except for privacy-related metrics, the reference data consistently achieves the highest scores”，basis=explicit]
2. **Q1；structural fidelity 与 conventional dimensions 互补。** 六个 SCM 上 Figure 3 左图显示 conventional metrics 与 global CI 没有 strong correlation；SMOTE/BN density 高但 global CI 低（Table 2 中 SMOTE 0.30、BN 0.35），支持“density/ML 不能替代结构评估”。[p.7–9，§4.1/Figure 3/Table 2，anchor； “none of the existing evaluation metrics exhibits a strong correlation with global CI”，basis=explicit]
3. **Q2；global utility 与 global CI 对齐。** 六个 SCM 上 metric-value Spearman `r_s=0.84, p<0.001`；扩展到 11 个 SCM、不同 metrics 和 predictors 后仍由 global utility 取得最高或近最高对齐。[p.8、p.40，§4.2/Table 26，anchor； “rs = 0.84, p < 0.001”，basis=explicit]
4. **Q2；local utility 只对局部 target 结构敏感。** local utility–local CI `r_s=0.78`，但 local utility–global CI 仅 `r_s=0.14`，两者均 `p<0.001`；global utility 用全变量平均减轻 target bias。[p.8–9，§4.2/Figure 3，anchor； “a much weaker correlation with global CI (rs = 0.14)”，basis=explicit]
5. **Q2；ranking 对齐更强。** 13 generators 在六个 SCM 上按 global CI 与 global utility 的 rank correlation 为 `r_s=0.95, p<0.001`；只看 global-CI top-5 仍为 `r_s=0.92`。[p.38–40，Appendix E.2/Table 24–25，anchor； “generator rankings … exhibit a strong correlation (rs = 0.95)”，basis=explicit]
6. **Q3；diffusion top-3。** Table 2 报告 SCM 的 global CI Top-3 为 TabSyn 0.70、TabDDPM 0.69、TabDiff 0.57（global utility 分别 0.76、0.80、0.75）；real-world 的 global utility Top-3 为 TabSyn 0.73、TabDiff 0.73、TabDDPM 0.72。[p.8，Table 2，anchor； “Top-3 methods are TabDDPM, TabSyn, and TabDiff”，basis=explicit]
7. **Q3；BN/GOGGLE 的 structure-learning inductive bias 没有兑现为高 fidelity。** 作者把 BN/GOGGLE 低 global scores 与高维 causal discovery 困难、GOGGLE 缺少 prior knowledge 时的 degradation 联系起来；这是机制解释，非单独因果识别实验。[p.9，§4.3，anchor； “BN and GOGGLE do not demonstrate strong performance”，basis=explicit]
8. **Q3；GReaT 的 ordering bias。** autoregressive factorisation 依赖 feature order `π`；randomising `π` 不消除 permutation mismatch。E.3 的 GReaT-sort 只改成 GT topological order，在六个 SCM 上每个 dataset 的 global utility 都更高；Hailfinder 0.29→0.43、Insurance 0.32→0.49、Sangiovese 0.31→0.40、Healthcare 0.19→0.43、MAGIC-IRRI 0.41→0.49、MEHRA 0.26→0.31。[p.9、p.42，§4.3/Table 31，anchor； “GReaT-sort consistently outperforms GReaT”，basis=explicit]
9. **Q4；global utility 对 predictor 配置稳健。** Full-tuned、Light-tuned、Tiny-tuned、Tiny-default 的 generator relative rankings 基本一致；local utility 从 9→3 predictors 会显著换位，CTGAN 由 Full-tuned 第 2 降至 Tiny-default 第 10。[p.9、p.26、p.44，§4.4/B.2.2/E.4，anchor； “relative rankings … remain consistent”，basis=explicit]
10. **Q4；global utility 更便宜。** Figure 4 的 evaluation time 为 global utility Tiny-default 0.64 s/1,000 samples，local utility Full-tuned 1.21 s/1,000 samples；图中也给出 training/generation time 对 utility 的关系，TabEBM/GReaT generation time >30 s 的 outlier 被排除在中图。[p.10，Figure 4，anchor； “Tiny-default takes only 0.64s per 1000 samples”，basis=explicit]
11. **归一化有效。** SCM 上 global utility 的 relative/normalised performance 与 global CI 的 Spearman 从 absolute 的 0.57 提升到 0.84；absolute scores 在 Full-tuned 与 Light-tuned 的 Top-5 仅共享一个 generator。[p.40–41，Table 27，anchor； “normalisation helps global utility to provide balanced evaluation”，basis=explicit]
12. **Causal-discovery 依赖的指标较弱。** global CI correlation；C2ST 0.50 vs global utility 0.83；CauTabBench skeleton-F1 0.42、direction-ACC 0.44、direction-F1 0.44 vs global utility 0.84；multi-table MLE-R2/MLE-F1 为 0.40/0.44。[p.38、p.41，Tables 22/28/29，anchor； “Global utility exhibits a substantially stronger correlation”，basis=explicit]
13. **样本数稳健性。** `Nref:Nsyn` 从 5；1、3；1 到 1；1/1；3/1；5 时，TabDDPM global utility 0.64、0.74、0.80、0.79、0.81；作者据此选择 equal-sized synthetic/reference。[p.41–42，Table 30，anchor； “tends to saturate when the synthetic sample size reaches or exceeds”，basis=explicit]
14. **低数据可用性。** subsampled `Nfull` 为 100、500、1,000、5,000、10,000、100,000 时，global utility 与 global CI 的 correlation 为 0.82、0.83、0.87、0.83、0.89、0.84，始终高于其他 metric。[p.45–46，Table 36，anchor； “even in very low-data scenarios”，basis=explicit]
15. **latent confounder proof-of-concept。** 注入 1–5 个 unobserved confounders 后，global utility 均值 0.79、0.77、0.79、0.75、0.77；与 Global CI (MAG) correlation 为 0.76、0.72、0.76、0.75、0.72。[p.44–45，Tables 32–33，anchor； “potential to evaluate global structural fidelity … latent confounding”，basis=explicit]
16. **causal inference 外部对应。** 六个 SCM 的 interventional/counterfactual errors 由 TabSyn、TabDDPM、TabDiff 等 diffusion/ARF 较低；global utility 与 I-MSE/C-MSE 的 correlation 分别为 -0.90/-0.83，global CI 为 -0.80/-0.82。[p.45–46，Tables 34–35，anchor； “Global utility exhibits a strong correlation with causal inference metrics”，basis=explicit]
17. **连续/离散变体。** Global utility continuous/discrete 与 global CI discrete/continuous 的 rank correlations 为 0.80–0.86；作者允许用户按成本或用途选择变体。[p.47，Table 37，anchor； “all variants … exhibit strong mutual correlations”，basis=explicit]
18. **主表之外的 per-dataset 异质性。** Table 23 给出每个 dataset 的 local/global Top-3；SMOTE 在 29 个 dataset 中 28 个 local utility 第一，global Top-3 在 SCM/real-world 多数为 diffusion，但 Healthcare、H16、Space、Superconductivity 等 dataset 的第一名可为 BN/ARF，说明平均 Top-3 不是每个单位一致。[p.39、p.47，Table 23/E.5，anchor； “SMOTE achieves the highest local utility on 28 out of 29 datasets”，basis=explicit]

### 主体结果与机制的关系

结果顺序严格对应 Q1→Q2→Q3→Q4；先证实 benchmark 有区分度，再验证 global utility 与 global CI 的经验对齐，随后按 generator family 解释结构表现，最后报告 ranking stability 与成本。Diffusion 的“每个 feature 同时去噪、无固定 feature order”是理论/架构解释；GReaT-sort、normalisation、predictor pruning 和 latent-confounder/causal-inference 结果提供机制对应，但没有对所有候选机制做独立随机化或 feature-level causal intervention。[p.7–10、p.42–46，§4/E，anchor； “four research questions”，basis=interpretation]

## 消融、敏感性与负面结果

论文没有名为 “Ablation” 的正文小节，也没有系统删除 global utility 的组件来测量 component contribution；`ablation` 语义模块因此标为 `not_present`。但 Appendix E 把以下 controlled variants/sensitivity 作为机制识别或稳健性证据；

1. **GReaT vs GReaT-sort（E.3，p.42）**；只更换 finetuning column order，其余配置相同；六个 SCM 全部改善，用于识别 directional/order bias。[p.42，Table 31，anchor； “only difference lies in the column order”，basis=explicit]
2. **Full/Light/Tiny predictor ensemble（B.2/E.4，p.26、44）**；改变 predictor 数量与 tuning，global ranking 稳定、local ranking 不稳定；这是 predictor-bias sensitivity，不是 generator component deletion。[p.26、p.44，Figure 8，anchor； “global utility is stable regardless of hyperparameter tuning”，basis=explicit]
3. **absolute vs relative utility（E.2，p.40–41）**；相同 generator/SCM，改 utility normalisation；`r_s` 0.57→0.84，用于识别跨列任务难度的 scale bias。[p.40–41，Table 27，anchor； “absolute performance versus relative (i.e., normalised) scores”，basis=explicit]
4. **continuous vs discrete metrics（E.2，p.47）**；替换 CI outcome 或 utility outcome 的计算方式，相关性仍在 0.80–0.86；用于检验 metric formulation sensitivity。[p.47，Table 37，anchor； “continuous and discrete”，basis=explicit]
5. **`Nref:Nsyn`（E.2，p.41–42）**；固定 reference、改变 synthetic sample size，utility 在 `Nsyn≥Nref` 后趋于饱和；支持 equal-size design。[p.41–42，Table 30，anchor； “synthetic sample size reaches or exceeds that of the reference data”，basis=explicit]
6. **data availability（E.2，p.45–46）**；`Nfull=100…100,000`，global utility correlation 0.82–0.89；用于低数据条件稳健性。[p.45–46，Table 36，anchor； “different degrees of data availability”，basis=explicit]
7. **latent confounder injection（E.4，p.44–45）**；3 个 SCM、1–5 个 latent confounders、MAG m-separation；global utility 与 Global CI (MAG) 仍相关，但作者称 proof-of-concept。[p.44–45，Tables 32–33，anchor； “proof-of-concept experiment”，basis=explicit]
8. **independent set split（E.6，p.47–48）**；改为 `Dtrain:Dtest:Dindep:Dvalid=3:3:3:1`；SMOTE 的 Trend 高于 `Dindep` 但 DCR 较差，TabDiff 对较少训练样本更敏感。[p.47–48，Figure 9，anchor； “Dindep acts as an independent benchmark”，basis=explicit]
9. **causal inference check（E.4，p.45–46）**；以 interventional/counterfactual MSE 作为外部结果，扩展“global utility 是结构代理”的证据，但仍限于 six SCM。[p.45–46，Table 34–35，anchor； “interventional and counterfactual tasks”，basis=explicit]

**负面与失败信息**；GReaT 常在 >50 features 不收敛；GOGGLE official implementation 在 >10,000 samples 可能不稳定；TabDDPM mixed-type fitting 可能不收敛；δ-Presence 的 Synthcity 实现有数值不稳定；CauTabBench/causal discovery 在高维时可能需要数小时到数天；主流程没有把这些问题转为预注册失败阈值。[p.22、p.20、p.33、p.35、p.42，A.1/A.4/D.3/E.3，anchor； “can exhibit instability due to inherent numerical issues”，basis=explicit]

## Limitations 与自我设限

- **metric epistemic boundary**；global utility 是 empirical measurement of likely SCM，不具备 real-world GT SCM 的 formal guarantee；作者在 §4.2 明确把高相关限定为 empirical finding。[p.8，§4.2，anchor； “rather than a formal proof”，basis=explicit]
- **causal identifiability**；真实数据通常没有 GT SCM；state-of-the-art causal discovery 在 real-world data 上可能表现差并误导使用者；DAG-level 还需在两套数据上运行昂贵 discovery。[p.10、p.29，§4.4/C.2，anchor； “ground-truth causal structures are rarely available”，basis=explicit]
- **CPDAG scope**；CPDAG 保留 Markov equivalence 的可解释方向，但不能提供 full DAG-level orientation；skeleton 被作者认为信息不足。[p.5–6、p.28–29，§3.2/C.2，anchor； “does not require the orientation of all edges”，basis=explicit]
- **benchmark scope**；当前实现是 13 generators、9 categories、29 datasets，静态 tabular；作者将更多 models/datasets/metrics、temporal/event data 留作未来工作。[p.10、p.48，§4.4/E.6，anchor； “extend the framework to support temporal and event-based data”，basis=explicit]
- **implementation failures**；GReaT、GOGGLE、TabDDPM 的收敛/高维行为受数据和实现影响；这些问题会改变实际可用的 generator 集合。[p.33、p.35、p.42，D.3/E.3，anchor； “often fail to converge on datasets with more than 50 features”，basis=explicit]
- **metric instability**；δ-Presence 的数值不稳定、privacy 的高分方向和 utility/structure 相反，导致跨维度比较需要谨慎。[p.20、p.7–8，A.1/§4.1，anchor； “larger values correspond to improved privacy preservation”，basis=explicit]
- **data splitting sensitivity**；E.6 的独立集配置显示训练样本减少可改变 TabDiff 的 Trend 表现；因此主流程 80/20→90/10 的结果不是所有 split policy 的不变量。[p.47–48，E.6，anchor； “varying the data splitting strategy can have notable impacts”，basis=explicit]
- **latent-confounder evidence**；latent confounding 只在 3 个 SCM 上注入，属于 proof-of-concept，不能替代真实隐藏变量数据。[p.44–45，E.4，anchor； “potential … in the presence of latent confounders”，basis=explicit]

## 最终判断

1. **单一主线**；论文把“传统 density/ML/privacy 指标可能把局部任务成功误当作 tabular data authenticity”推进为可测量问题；先用 CPDAG-level CI 在 expert-validated SCM 上定义 local/global structural fidelity，再提出对每个 variable 做 normalized downstream prediction 的 `global utility`，最后以 6 core SCM + 23 real-world、13 generators 的 Q1–Q4 实验验证相关、排序、稳健性和计算成本。[p.2–10，§1–4，anchor； “global utility provides a task-independent, domain-agnostic lens”，basis=interpretation]
2. **正文保留的决策内容**；保留 Figure 1 的物理-law 反例、SCM/CPDAG/CI 定义、Eq.1–4、global/local distinction、四个 RQ、Table 2、Figure 3–4、diffusion/GReaT 机制和 empirical-proof limitation；这些内容足以判断“是否应增加 structural dimension”和“global utility 是否值得作为筛选器”。[p.2、p.5–10，§3–5，anchor； “The strong correlation and consistent generator ranking”，basis=interpretation]
3. **移入附录的细节及代价**；移入了 Algorithm 1/2、CI test implementation、dataset rows、13 个 generator hyperparameters、split/preprocessing、predictor tuning、ADTM、large-SCM/latent-confounder/causal-inference/independent-set checks 和 Tables 38–66；代价是正文无法独立复现实验或检查 per-dataset failure，但 headline 结论没有失去直接证据。[p.7–10、p.25–63，§4/Appendix，anchor； “Full implementation details are available in Appendix D”，basis=interpretation]
4. **最有效模式**；Figure 1 把 physical system→causal graph→CI→metric failure 放入同一视觉因果链；Table 2 用同一 generator 行横向并置四个 evaluation dimensions；Figure 3/4 分别把“互补性”和“实用性”转为 rank/efficiency 证据。它们的有效性来自同一对象和同一方向的连续回收。[p.2、p.8–10，Figures 1/3/4/Table 2，anchor； “conventional metrics are insufficient”，basis=interpretation]
5. **最大缺口**；`global utility` 只被证明与 global CI 经验相关，且其解释依赖“高 fidelity generator 应能用其他变量预测每个变量”的 heuristic；没有 real-world GT SCM、formal proof、完整 causal-identification test，也没有把 predictor/model/data heterogeneity 完全拆开。[p.8、p.10、p.29、p.48，§4.2/4.4/C.2/E.6，anchor； “ground-truth causal structures are rarely available”，basis=explicit]
6. **可迁移规则**；任何声称“结构保真”的生成评估，都应先定义跨变量的 observable surrogate，再在带 expert/known structure 的校准集上同时检查 metric values、induced rankings、失败案例和外部机制任务；同时保留 target-local decomposition，避免单一 downstream task 代替全局结构。[p.5–6、p.38–47，§3/E，anchor； “global utility provides similar generator rankings as global CI”，basis=interpretation]
7. **适用边界**；该规则要求存在可验证的结构校准集和稳定的下游预测 protocol；它不能把 global utility 变成真实因果图，也不能直接覆盖 latent confounding 的全部情形、动态/temporal data 或不同 split policy 下的部署表现。[p.29、p.44–48，C.2/E.4/E.6，anchor； “extend … to temporal and event-based data”，basis=explicit]
