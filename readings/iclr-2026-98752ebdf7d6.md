## 5. 方法与理论

### 5.1 形式化对象

动作集为有限 `A`，每轮策略为 `π^(t)`，utility vector `u^(t)∈[-1,1]^A`；external regret 是 hindsight best fixed mixed action 与实际累计 utility 的差。[p.3 §2.1，公式 (2.1)] 通过逐轮平移 utility，作者令最后动作 `a_|A|` 的 utility 恒为 0，作为 estimator 的 reference。[p.3 §2.1]

每轮提出可重复的 multiset `o^(t)`，观察其 PL permutation `σ^(t)`。full-information 提出全动作集；bandit 从 `π^(t)` with replacement 采样 K 个动作，因而 proposal average 是 expected utility 的 unbiased estimator。[p.4 §3，`sampled from π^(t) independently (with replacement)`]

PL 的温度 `τ` 控制 ranking noise。τ→0 时 utility 更大的动作几乎确定性排前，τ→∞ 时 ranking 接近 uniform。[p.4 §3,p.7 §5.1] 两个 feedback model 只改变 PL 中的 `r^(t)`。InstUtil 用当前 `u^(t)`；AvgUtil full-information 用 `u_avg^(t)=t^−1Σ_su^(s)`，bandit 用每个动作在实际 proposals 中的 empirical average `u_empirical^(t)`。[p.4–5 §3]

### 5.2 负结果与适用边界

- **Theorem 4.1**：InstUtil Rank 对任意 `0<τ≤0.1` 存在 utility sequence，使 full-information 与 bandit 的 expected regret 至少有一个为 `Ω(T)`。Appendix D.1 用两个动作与两个随机 utility instances，让观察到的 ranking distribution 相同，但 action `a` 的 expected utility 分别为 −0.05 与 0.03；一个实例上的低 regret 会在另一个实例产生线性 regret。[p.5 §4,p.18–21 Appendix D.1]
- **Theorem 4.3**。AvgUtil full-information 在 `0<τ≤O(1/(T log T))` 时，存在 `T′≥T` 与 sequence，使 `E[R_ext(T′)]≥Ω̃(T′)`。Appendix D.2 用 K+1 个 doubling-block sequences；action-a construction 与 action-b construction 都让前段 ranking 相同，Lemma D.1 保证至少一个序列的平均 utility 低于 `0.5−1/(2(K+1))`；累积 action gap 保持 0.5，再用 union bound 降到小正 τ。[p.6,p.21–22]
- **Theorem 4.4**。AvgUtil bandit 在 `0<τ≤O(1/log T)` 时 `E[R(4T)]≥Ω(T)`。Appendix D.3 的两个实例分成三阶段；前两阶段迫使 learner 探索 a/b，第三阶段要求少提议 a 才能在 instance 1 低 regret，却会让 instance 2 的 empirical average 失去区分度。[p.6,p.23]

这些 hardness 构成后续 estimator 的必要性：当 τ 过小，ranking 只暴露顺序；当 utility sequence 快速变化，滑窗 pairwise average 对当前 utility 有 temporal bias。[p.5–7 §4–§5，解释性判断基于上述定理与 Theorem 5.1]

### 5.3 Algorithm 1：pairwise utility estimation

Algorithm 1 在最近 `m′` 个 permutations 中，把每个非-reference action `a_j` 与 `a_|A|` 配对。`n_{j,1}` 统计 `a_j` 排在 reference 前的 pair，`n_{j,2}` 统计相反方向；只在两者同现的时间步集合 `T_j` 上取 fraction，再对平均 fraction 应用 `τ sig^{-1}` 并投影到 `[-1,1]`，最后一维设为 0。[p.24 Appendix E.1]

Lemma E.1 的关键 identity 是：在 PL multiset 中，任意两 distinct actions 的 expected pair fraction 等于 `sig((u(a)−u(b))/τ)`，所以 K-wise permutation 可还原成 K=2 的 pairwise marginal；重复 action 也被计入 multiplicity。[p.24,p.27–30] Lemma E.2 说明 inverse logistic of average 位于窗口内 utility 的 min/max 之间；这一步把 sampling error 与 temporal variation 分开。[p.26–27,p.30]

Theorem 5.1 的高概率 bound 为

`||ũ^(t)−u^(t)||∞ ≤ [τ(e^(1/τ)+1)^2/p]√(log(4|A|/δ)/m′) + Σ_{s=t−m′+1}^{t−1}||u^(s+1)−u^(s)||∞`,

条件为 `m′p^4≥2 log(2/δ)`，概率至少 `1−δ`。[p.6,p.25–27] τ→0 与 τ→∞ 都让 sampling term 发散：前者 ranking 过于 deterministic，后者近似 uniform。[p.7 §5.1]

### 5.4 Algorithm 2：InstUtil Rank

full-information 每轮提出全体动作，因此 `p=1`；bandit 从 `π^(t)` with replacement 采样 K 个动作，并把 oracle 输出与 uniform distribution 混合：`π^(t+1)=(1−γ)Alg(ũ^(1:t))+γ1(A)/|A|`，保证每个 action 有正 proposal probability。[p.7 §5.2,p.31 Algorithm 2]

Theorem 5.2（τ 为 constant）将 regret 分解为 numeric-feedback oracle regret 加 estimator/exploration cost：full-information 为 `O(P(T)^(1/3)T^(2/3)(log(T/δ))^(1/3))`，bandit 为 `O(P(T)^(1/5)T^(4/5)log(T/δ))`。[p.7 §5.2；formal constants 在 p.32–36 Appendix G/H] 因此 `P(T)=o(T)` 时正向结果成立，前提仍包含 oracle 的 numeric-feedback no-regret 性质。[p.7]

### 5.5 Algorithm 3：AvgUtil Rank

AvgUtil full-information 仍用 Algorithm 1，但估计 `u_avg^(t)`。相邻 average utility 的差至多 `2/t`，所以 estimator 的 temporal term 可由 harmonic sum 控制，与原始 utility 的 `P(T)` 无关。[p.7 §6.1]

AvgUtil 的难点是 oracle 依赖累计 utility；仅把估计 average 当作逐轮 utility 会放大 perturbation。因此 Assumption 6.1 要求 oracle 对累计 utility sequence 稳定：`||Alg(u^(1:t))−Alg(u′^(1:t))||≤L||Σ_su^(s)−Σ_su′^(s)||`，其中 `L=Θ(T^(−c))`。[p.8 §6.2] FTRL with strongly convex regularizer 的 `L=λ/c0` 由 Lemma L.3 证明。[p.45–46 Appendix L]

full-information Algorithm 3 将当前 estimate 复制为前 t 个 utility vectors 再交给 oracle。[p.32–33 Figure 11/Algorithm 3] Theorem 6.2 给出 `R_ext(T)≤R_ext(Alg,u)+O(LT^(5/3)log(T/δ))`；`c>2/3` 时该附加项 sublinear，且不要求 Assumption 4.2。[p.8 §6.2]

bandit 端先得到 `u_empirical`，再以 block size M 计算每个 action 的累计 empirical utility differences；用 blocks 平均降低 variance，同时引入 conditional-on-selection bias。M 增大时 variance 降低，块内 utility variation 累积导致 bias 增大。[p.8 §6.3,p.33 Algorithm 3]

Theorem 6.3 要求 `P(T)≤O(T^q), q<1/3` 与 `L=Θ(T^(−c)), c∈(5/6+q/2,1)`，给出 `Õ((log(1/δ))²L^(1/3)T^(23/18)P(T)^(1/6))` additive term。[p.9 §6.3,p.38–43 Appendix J] 这条带条件的 bandit upper bound 与 Theorem 4.4 的 small-τ hardness 共同留下了 constant-τ、无 variation 假设的 gap。[p.9,p.46]

### 5.6 Equilibrium computation

Appendix B 定义 ε-CCE 为最大 unilateral coarse deviation gain；主文用每位玩家的 external regret 除以 T 作为 exploitability 上界。[p.16 Appendix B.1,p.9 §7] Lemma K.1 将每位玩家 utility variation 上界为各玩家 strategy variation 的总和；Lemma K.2 给出 Algorithm 2 的 variation ≤ηT，以及 Algorithm 3 bandit 的 variation ≤ηT+2√|A|LT。[p.43–45 Appendix K]

Assumption 7.1 规定 oracle 每一轮 output 的变化不超过 `η=Θ(T^(−w))`；mirror descent 与 FTRL 满足该性质的论据也放在 Lemma L.3。[p.9 §7,p.45–46] Theorems 7.2/7.3 随即把 InstUtil/AvgUtil regret transfer 成 ε-CCE bounds。[p.9–10]

Remark K.3 很重要：τ→0 虽会破坏 online no-regret guarantee，某些 game 中仍可通过 fictitious play 计算 equilibrium。这区分了 “在线环境中的 external regret” 与 “固定 game 中的 equilibrium convergence”。[p.45 Appendix K.1]

## 6. 实验设计

- **LLM routing**：固定一位 user；每轮 query 触发 K 个模型 response；ranking 只提供相对 preference；目标是与 hindsight best fixed model 比较 external regret。[p.10 §8]
- **模型与 reward**：Qwen3-32B、Phi-4、GPT-4o、Llama-3.1-70B；reward model 为 `OpenAssistant/reward-model-deberta-v3-large-v2`。[p.10 §8]
- **合成实验**：`T=10^7`；每个 game player 10 actions；`τ∈{0.5,1,2}`、`K∈{3,5,10}`、`P(T)=T^q`，q∈{0.3,0.5,0.7}；AvgUtil full-information 另用 q=1.0。[p.17 Appendix C]
- **超参数与 oracle**：m、γ、M 使用独立 grid search；InstUtil 以 PGD 为 oracle，AvgUtil 以 L2-FTRL 为 oracle；每个配置 10 seeds；学习率除 AvgUtil bandit 外为 `1/√T`，后者为 `10^−6`。[p.17]
- **噪声 ablation**：full-information AvgUtil 以初始 utility 加 independent coordinate shift，比较 Uniform、Gaussian、Gamma，σ=0.3。[p.18–19]
- **统计与复现**：Appendix C 说 Figures 7–9 有 95% CIs，未报告显著性检验、多重比较、bootstrap、Bayesian analysis 或 effect size；硬件、软件版本、代码链接与 prompt split 未给出。[p.17,p.10–11]

实验顺序大体跟随理论：先 regret curves（Figures 3–6），再 two-player CCE（Figures 7–9），LLM routing 作为单一应用（Figure 2）。但它没有 component deletion、numeric-feedback baseline 或真实 human ranking control，因此机制证据主要来自 proofs，曲线承担可行性展示。[p.17–20]

## 9. 结论、limitations 与闭环

论文的单一主线是：**ranking feedback 只有 ordinal information；PL 的 pairwise marginal 提供可逆的 noisy cardinal signal；temporal averaging 改变 estimator 的 drift；稳定 numeric-feedback oracle 把估计误差传入 regret，再把 no-regret 传入 CCE。** Small τ 的 indistinguishability 先定义信息边界，positive theorems 则精确列出 τ、P(T)、q、L、η 的可行区域。[p.4–10]

正文保留了决策关键内容：feedback taxonomy、external-regret metric、Table 1、hardness/upper-bound theorem statements、Algorithm 1–3 的高层数据流、CCE 结论和 Figure 2。证明常数、multiset induction、Azuma-Hoeffding、block-count lower bound、FTRL stability 及完整 synthetic design 都移入附录；实现 Algorithm 3 的读者必须继续读 Appendix F/J，正文对此自足性不足。[p.24–46]

结论 M 没有引入新的数字主张。它重申 ranking-feedback online learning、hardness、variation-based algorithms 与 CCE，并提出两条 future work：缩小 AvgUtil bandit lower/upper gap；把算法用于真实 ride-sharing/match-dating ranking 数据。[p.46 Appendix M]
