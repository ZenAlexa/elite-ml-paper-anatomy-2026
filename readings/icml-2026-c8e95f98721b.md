## 5. 方法、理论与证明链

### 5.1 最小逻辑单元与转移

正文没有传统「Method」节；§1 的 MPNN formalism 和 §2–3 的 theorem-driven exposition 共同承担方法。主转移为：

`setup_notation → define MPNN invariant task → define finite Lipschitz class/certificate/loss → state cover-plus-regularization theorem → construct MPNN pseudometrics → instantiate PageRank/Bellman–Ford/dynamic programming → derive explicit SSSP training set → contrast expressivity/covering obstructions → connect to Q1–Q3`。

- **形式化对象**：graphs、node/graph/tuple invariants（p. 2–3，§1）；input 为 `(G,u)` 或 graph invariant，output 为标量/向量算法值。
- **目标函数与假设**：Definition 1 把 hypothesis class、pseudo-metric、finite covering number 与 computable Lipschitz certificate 连在一起；Theorem 2 还要求 target 具有受控 certificate 的 uniform approximability（p. 4–5）。
- **可训练量**：`L_emp + L_reg`；一般定理使用 certificate penalty，SSSP 使用 layer-weighted differentiable `ℓ1` penalty（p. 4、p. 25–27）。
- **显式构造**：Theorem 16 的训练集由 `K+1` 个 scaled basis-vector path graphs 组成，输入路径长度为 `K`，而非由随机样本近似 cover（p. 26–27，Figure 3）。
- **没有伪代码**：Bellman–Ford recursion、path graph 和 proof objects 取代 algorithm listing；读者需在 §2.2.1、Appendix E/F 在数学定义间往返。

## 6. 实验设计与可复现粒度

- **研究问题**：Q1 问 gradient descent 是否到达可 size-generalize 的参数；Q2 问更 expressive MPNN 是否改善预测；Q3 问 proposed differentiable regularization 是否优于 p-norm regularization。（p. 8，§5）
- **任务与数据**：全部主实验是 K-step Bellman–Ford/SSSP。训练从理论最小的 3 个 path graphs（K=2）出发，并在 MPNN setup 增加 0.5x、2x 和 multi-path path graph；`x=50`、unvisited value `1000`、每节点 self-loop。（p. 70–71，§N）测试含 ER-constdeg、ER、star、complete、SBM 与 General；nodes 为 64–1024，edge weights 为 `Uniform(1,100)`，General 每组给出 50 graphs。（p. 71，Table 3）

## 7. 结果、表图与统计解释

### 主结果

1. **Q1：size generalization**。主文称随着 node count 从 64 增至 1024，test error 不升高，且 ER-constdeg 与 unbounded-degree ER 没有显示平均 degree 导致的失效。（p. 9，§5）证据锚点为 `does not increase with node count`。Appendix Table 6 给出 General 为 `0.0032±0.0002`（64）到 `0.0033±0.0002`（1024），ER-constdeg 为 `0.0035±0.0002` 到 `0.0030±0.0001`。证据单位是 node-averaged test score，再跨 seeds 聚合；Figure 2/7 是平滑轨迹，不能单独识别训练随机性的全部形状。（p. 73，Table 6；p. 9、75–76）
2. **Q2：expressivity contrast**。Table 1 中 1-WL 在 General 的 score 为 `0.8393±0.0001`（64）、`0.8217±0.0010`（1024），而 1-iWL 分别为 `0.0032±0.0002`、`0.0033±0.0002`；同表也给出 ER/ER-constdeg。作者解释为 source individualization 的必要性，和 Proposition 5 的方向一致。（p. 9，Table 1；p. 7，§3.1）这是 architecture comparison，不是对所有 more-expressive GNN 的普遍排名。
3. **Q3：regularization contrast**。Table 2 的 General score 中，`ℓreg` 从 64 到 1024 nodes 为约 `0.0032–0.0033`，`ℓ1` 为约 `0.0053–0.0061`，`ℓ2` 的均值更高且 `±` 值也较大。作者将其解释为 proposed differentiable loss 的更佳 size generalization。论文没有报告显著性检验。（p. 9，Table 2）证据锚点为 `improves with the proposed regularization`。
4. **深度边界与真实图补充**。two-layer MPNN 直接预测 three Bellman–Ford steps 的 General score 从 `1.5381±0.0057`（64）降至 `0.5721±0.0039`（1024），而 Appendix Table 7 的 three-layer/three-step 与 repeated application 是额外探索；Cora/Citeseer 的 two-step score 分别为 `0.0083±0.0035`、`0.0080±0.0040`。（p. 73–74，Table 7–9）这些结果表明实验只覆盖有限 configurations，不构成所有 K 的系统检查。

## 8. 消融、负面结果与自我设限

- **设计性消融**：Q3 用 `ℓ1`、`ℓ2` 替代 weighted `ℓ1` regularization，识别目标是 loss design；Table 2 是唯一直接 component/regularizer removal。（p. 9）

## 12. 最终判断

1. **单一主线**：把「能否从有限样本学到 graph algorithm 并外推到任意规模」转换为一个由 pseudo-metric、finite cover 和 computable Lipschitz certificate 控制的 learning problem；再用 Bellman–Ford 将存在性框架压缩为可构造 `K+1` path-training set。
2. **正文保留的决策内容**：问题缺口、Definition 1/Theorem 2–4 的 informal form、expressivity/finite-cover 双重负边界、Q1–Q3、两张主表和一个 limitations section。
3. **迁入附录的细节**：所有 formal proof、Theorem 16 训练集和 loss、counterexamples、topological machinery、hyperparameters、runtime、更多 sizes、deeper-step failure。迁移使正文流畅，却使 theorem audit 与 experiment reproduction 不能止于正文。
4. **最有效的模式**：Figure 1 将抽象 theorem 接到 MPNN representation；Figure 3 将 `K+1` 构造具体化；Table 1/2 让 Q2/Q3 各以一个可比较对象回应一个理论命题。这个「general theorem → constructive special case → matched empirical question」链条最清楚。
5. **最大读者成本/未闭合点**：标题暗示完整算法分类，实际结论是 conditional sufficient conditions 与有限的 obstructions；general cover 可能不可构造，gradient descent 没有理论收敛保证，关键 SSSP theorem 的 assumptions 与 proof 藏在 24 页 Appendix F。
6. **可迁移规则**：若论文宣称从小实例到任意规模的 algorithmic generalization，应把 general sufficient condition、一个可构造 training-set 特例、一个 expressivity negative result 和对应的 controlled experiment 连成显式闭环。
7. **适用边界**：该规则适于能够定义 stable representation/pseudometric、目标可被受控-certificate class 近似且训练任务可写成监督 loss 的问题；不自动适用于没有 compactness/finite-cover structure、需要优化收敛保证、混合 aggregation 或未标记关键初始状态的任务。
