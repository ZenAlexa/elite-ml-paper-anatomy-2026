## 5. 方法与理论

### 5.1 分析对象、假设与理论角色

作者以 Q-Insight 为 case study，把 Qwen-VL 的 LLM 部分视为 reasoning process，把 Qwen Visual Encoder 作为受控的视觉输入端。Q-Insight 在每个图像／任务问题上生成带 `<think>` 和 `<answer>` 的候选，score regression 与 degradation perception 共同构成 rule-based rewards，GRPO 更新并用 KL regularizer 保持接近固定参考策略。[p. 3, §3.1, “a multi task GRPO update … while a KL regularizer keeps the policy close”]。本文将其作为被解释的既有 RL-based IQA 机制，并未列为新提出算法。

Section 3 的机制链是：

1. **Reasoning mechanism**：Figure 2 比较 Q-Insight 与通用 Qwen-VL 的 reasoning 长度及 CLIP feature；Figure 3 用生成 score token 时的 attention heatmap 检查依赖位置。
2. **Compact representation**：作者把 512×384 图像的视觉表示近似为约 1,000 tokens，把文本表示约束为少于 100 tokens，作为“超过 10 倍”压缩的直觉来源。[p. 4, §3.3, “A 512×384 image requires approximately 1,000 tokens”]
3. **Domain bridge**：KonIQ 与 SPAQ 的 visual-token t-SNE 分布差异明显，而 reasoning-text-token 分布差异较小；这是跨域表示的观察性证据，未形成 invariant 的形式证明。[p. 4, Figure 4]
4. **Reasoning transfer**：分别在 KonIQ、KADID 上训练 LLM，换回同一个预训练 Qwen Visual Encoder 做跨数据集测试。CSIQ 与 LiveW 的 PLCC 差异在 0.01 内，作者据此认为 reasoning process 比数据集特定的视觉编码更稳定。[pp. 4–5, §3.3, Table 1]

**理论角色**：Section 3 的“理论”属于核心因果叙事中的机制解释与诊断，未构成 guarantee。论文没有 theorem、lemma、proposition、corollary 或 proof，也没有给出泛化界、复杂度定理或显式统计检验。作者使用 “source”“precisely”“prove” 等强措辞，但实验证据主要是 attention、t-SNE、替换组件和跨域相关性比较。

### 5.2 RACT：Reasoning-Aligned Cross-Domain Training

RACT 针对混合 IQA 数据集的 reward／label 分布差异，按三步组织：

1. 在每个 IQA 数据集上独立进行 single-domain RL。
2. 用各自 reasoning module 生成 image quality reasoning text，形成跨数据集统一的 image–text labels。
3. 用跨域 SFT 训练 single-domain RL model；该阶段主要调节 Visual Encoder，使图像映射到已经对齐的 reasoning text，数值 score 只从一个数据集引入以稳定收敛。

这一设计把“图像到描述”与“描述到分数”拆开。作者的解释是，text 保留较客观的 quality information，而 score 还携带 annotator-group bias；Table 5 和 Appendix Table A.3 支持这一方向，但没有直接观测 annotator bias 的独立测量。[p. 5, §3.4, “we only introduce score information from a single dataset”]；[p. 16, Appendix C, “dual-component nature of dataset annotations”]。

### 5.3 RALI：Reasoning-Aligned Lightweight IQA

RALI 保留 RL 模型学到的 quality reasoning text space，但把运行时的多步推理替换为视觉编码器到文本空间的直接对齐。Figure 5 的四个面板分别表示 RL-based IQA、contrastive alignment、feature compression 与 scoring definition；图例区分 training／frozen、visual token、text token、basis score、basis vector 和 quality-aligned token。[p. 6, Figure 5]

**组件 1：Contrastive Alignment。** 用预训练 Q-Insight 在训练集 `C` 上生成 `(I, T, s)` image–text–score triplets；同一图像使用不同 seeds 增加 reasoning text 多样性。冻结 CLIP text encoder，只微调 CLIP vision encoder，使图像进入质量 reasoning text space。[p. 5, §4, “we freeze the text encoder and only train the image encoder”]

**组件 2：Feature Compression。** 微调后的视觉编码器产生 `E ∈ R^D`，`D=768`；PCA 投影到 `M=512` 维，得到压缩特征 `Ê` 与投影矩阵 `U`。作者把降维解释为过滤 quality-irrelevant information，并以 score range `[1,5]` 划分 `N=240` 个 buckets。每个 bucket 内做 `k_n`-means，得到 centroid `μ_nj` 和代表分数 `f_nj`；展平后保留 `K=250` 个 basis vectors／scores。[p. 6, Feature Compression, “K = 250, N = 240”]

**组件 3：Scoring Definition。** 输入图像经 `E_align` 和 PCA 投影后，与 K 个 basis vectors 计算 cosine similarity，以 softmax 变成 `w_i`，最终用 basis scores 的加权和得到 `f̂`。训练从 PCA／bucketed k-means 初始化，再用 image–score pairs 端到端拟合；推理时只保存 `μ_i` 与 `f_i`，执行 dot products。[pp. 6–7, Scoring Definition, “inference reduces to simple dot products”]

`setup_notation → state_problem → derive → define_component → explain_mechanism → give_intuition → connect_to_prediction → connect_to_experiment → instantiate_algorithm → contrast_alternative → define_component → derive → explain_mechanism → state_complexity → summarize`。

### 7.3 主要结果

1. **Reasoning 依赖位置**。Figure 2 的示例把 Q-Insight reasoning 标为 62 words、Qwen-VL 为 128 words；作者称前者更简洁且与 quality 更相关。Figure 3 的 score-token attention 中，1,020 image tokens 得 5%，78 reasoning tokens 得 95%。这是“score 主要读取文本 reasoning”的直接观察，但 attention 不是因果干预。[p. 3, Figure 2；p. 4, Figure 3]
2. **LLM reasoning 的跨域一致性**。Table 1 中，KonIQ-trained 与 KADID-trained LLM 组合在 OOD CSIQ 的 PLCC/SRCC 为 0.832/0.789 与 0.839/0.790，在 LiveW 为 0.837/0.789 与 0.832/0.791，PLCC 差异均小于 0.01；in-domain 则分别偏向自己的训练集（KonIQ 0.876/0.844、KADID 0.841/0.841）。作者把它解释为 reasoning process 的跨域一致性与 score preference 的域内偏置。[pp. 4–5, Table 1]
3. 单域 RALI。Table 2 的 AVG 为 0.798/0.779，Q-Insight 为 0.806/0.783，因此 RALI 在该设置下接近 Q-Insight；RALI 的 PIPAL 为 0.527/0.528，高于 Q-Insight 的 0.486/0.474，LiveW 为 0.896/0.876，高于 Q-Insight 的 0.893/0.865，但 KADID、AGIQA、CSIQ 等域并非全面领先。[p. 8, Table 2]
4. **RALI 与 CLIP-IQA+**。Table 2 实际 AVG 为 CLIP-IQA+ 0.742/0.658、RALI 0.798/0.779；按表中数字相减，差值是 **+0.056 PLCC、+0.121 SRCC**。正文 p. 7 写成 “surpasses it by 0.056 and 0.059”，其中 SRCC 的 0.059 与表中 AVG 不一致，见第 12 节的 measurement disagreement。[p. 7, §5.2；p. 8, Table 2]
5. 跨域 RACT。Table 3 的 RACT in-domain AVG 为 0.853/0.842，低于 DeQA 的 0.894/0.882；OOD AVG 为 0.858/0.816，高于 Q-Align 0.817/0.788、DeQA 0.835/0.799、VisualQuality-R1 0.831/0.781、Q-Insight 0.796/0.740。按表中四个 OOD 域，RACT 的 PLCC 0.881、0.813、0.892、0.844 均为该表最高，SRCC 0.846、0.763、0.838、0.817 也均为最高。[p. 8, Table 3]
6. **效率**。Figure 6 显示 batch 1、4、16、64 的 Q-Insight inference time 约为 3.2、4.0、8.6、23 s，RALI 约为 0.02、0.07、0.29、1.0 s；memory 柱约为 Q-Insight 15、16、19、28 GB，RALI 0.2、0.7、2.8、4.8 GB。正文明确给出 batch 16 时 RALI 是 Q-Insight 的 **14.7% memory 与 3.4% inference time**。[p. 9, Figure 6；p. 9, §5.4]
7. **reasoning removal 的附录验证**。Table A.1 的 AVG 从 Qwen-SFT 0.732/0.709，上升到 Qwen-GRPO w/o Reasoning 的 0.768/0.744，再到 Qwen-GRPO w/ Reasoning（Q-Insight）的 0.806/0.783；作者据此把完整 reasoning 与 OOD 改善联系起来。该比较仍是训练策略的整体对照，并非只改变 reasoning 的单一变量。[p. 15, Table A.1]
8. **RACT 的混合域增益**。Table A.2 中，KonIQ+SPAQ 时 Q-Insight AVG 为 0.789/0.754，RACT 为 0.802/0.768；四域混合时 Q-Insight 为 0.791/0.757，RACT 为 0.855/0.829。随着混合数据集增多，RACT 相对 Q-Insight 的 AVG 差距从 0.013/0.014 增至 0.064/0.072。[p. 16, Table A.2]
9. **numeric-score 来源**。Table A.3 中，使用 KonIQ scores 的 RACT AVG 为 0.858/0.816，使用 SPAQ scores 为 0.852/0.826；作者据此称 RACT 对 numeric-score 来源不敏感，但该结论只覆盖两种来源。[p. 17, Table A.3]
10. **超参数与轻量化对照**。Table A.5 的最终 case 8（score definition、512-D、250 vectors、240 bins）为 0.798/0.779；700-D case 10 为 0.787/0.767。Table A.6 中 3B Q-Insight AVG 为 0.776/0.753，RALI 为 0.798/0.779；表格支持该测试设置下 RALI 的点估计更高，但未报告参数缩减的训练成本或方差。[p. 18, Tables A.5–A.6]
11. **质性样例**。Figure A.2 中 RACT 的 3.92 比 VisualQuality-R1 的 4.70 更接近 GT 3.95；Figure A.3 中 RACT 的 3.50 与 VisualQuality-R1 的 3.80 均低于 GT 3.59，RACT 绝对误差为 0.09、VisualQuality-R1 为 0.21。两例可以展示 reasoning 文本风格和 score 差异，不能单独证明“consistently more accurate”。[p. 19, Figures A.2–A.3]

### 8.2 负面结果与自我设限

- **域内与域外张力**：Table 3 明确显示 SFT-based 方法在 in-domain AVG 更高，而 RACT 在 OOD AVG 更高；作者没有把 OOD 优势改写成所有域全面优越。[p. 8, Table 3]

- **数据范围**：作者明示实验主要针对 natural-image IQA；video 与 AIGC 是未来可扩展方向，而非本文已验证范围。[p. 15, Appendix B]
- **reasoning 长度**：Appendix A 说过短 reasoning 会降低性能，但没有给出长度 sweep、阈值或逐长度曲线；“移除 reasoning”是极端对照，不等同于长度机制的完整识别。[p. 15, Appendix A]
- **呈现位置**：限制、broader impacts、超参数、轻量化和质性样例主要延后到 Appendix B、D–G；正文结论仍以“efficient high-performance solutions”收束。[pp. 9, 15–19]。这是可验证的 **position delay**，不推断作者动机。

| `significantly` | 5 | 泛化增强、差异、下降，p. 1–9 |

| `suggest` | 2 | 代表性或未来解释，主要在机制／附录语境 |

| `limitation`／`limitations` | 1 次主体词形 | 明确 limitations 只在 Appendix B；正文以部署代价和性能词弱化边界 |

强主张包括 `precisely the source`、`fully demonstrates`、`highest performance`、`prove`、`SOTA`、`equivalent level`；弱化或限定词包括 `likely`、`potentially`、`modest`、`roughly`、`we believe`、`can be readily extended`。修辞重心是先把 reasoning 重新命名为 representation，再以 RACT 和 RALI 两个方案收束；限定语境明显少于机制／效率主张。

## 13. 最终判断

1. **单一主线**：论文把 RL 的 IQA 泛化重解释为一种视觉到质量 reasoning text 的压缩与跨域对齐；RACT 把该文本当作统一跨域 label，RALI 再用 CLIP contrastive alignment、PCA、bucketed k-means 和 softmax score mapping 直接复现该表示路径，删除多步 reasoning 与 LLM 推理。
2. **正文保留的决策关键内容**：问题与两项部署／机制问题、Figure 2–4 的表示观察、Table 1 的跨域替换、RALI 三组件与公式 (1)–(3)、Table 2–5 的主结果／消融，以及 Figure 6 的 A100 效率。它让读者能沿“机制 → RACT → RALI → 结果”主线阅读。
3. **移入附录的细节及其代价**：reasoning removal 的 Table A.1、RACT 流程和混合域补充、prompts、超参数扫描、3B 对照、质性案例与 limitations 都在附录。算法主结构没有因迁移而断裂，但适用域、复现粒度、统计稳定性和部分关键消融被推迟，削弱了正文自足性。
4. **最有效的模式**：Figure 3 的 attention 分配、Figure 4 的双 t-SNE、Table 1 的“换 LLM、固定 Visual Encoder”组合，把抽象表示主张变成可读的机制证据；Figure 5 再把同一表示链翻译成四阶段工程流程。最有效的是让方法命名直接复用机制命名（Reasoning-Aligned）。
5. **最大缺口**：核心因果措辞强于识别设计。attention 与 t-SNE 主要是相关性／布局证据，Table A.1 是整体训练策略对照，Table 4 还存在 confounded case；同时 broad memory claim 与 Figure 6 不一致，Table 2 的 SRCC 差值也不一致。
6. **可迁移规则**：若要把昂贵 reasoning 替换为轻量 representation，应同时给出依赖位置的直接测量、跨域表示差异、最小正交干预（删除／替代／长度控制）、逐域结果和成本曲线；“representation is the source”应与可证伪的 intervention 绑定。
7. **规则边界**：该规则适用于小规模、标签主观性强且跨域分布差异明显的视觉质量任务；它不能把 natural-image IQA 上的 t-SNE、PLCC／SRCC 和两种 score source 结果直接外推到 video、AIGC 或其他 MLLM，除非新增任务级实验和同等的效率／因果识别证据。

**证据覆盖**：本篇的实质判断均附物理页、章节和短证据锚点；共登记 20 项需要页码的主张，20 项均有页码证据，状态为 `complete`。
