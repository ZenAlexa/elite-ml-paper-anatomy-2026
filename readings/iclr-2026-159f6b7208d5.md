## 7. 方法与理论：从观测分布到局部图操作

### 7.1 形式化对象

§2 先给出 digraph、latent/observed partition、weighted adjacency B、mixing matrix A 和 observed-row mixing set A(G, X)。Definition 1 把 distributional equivalence 定义为 P(G, X)=P(H, X)。Definition 2 和 Proposition 1–2 用 irreducibility 去除无 observed descendants 的 latents 以及 proportional columns 对应的平凡冗余；作者明确说明这是 canonicalization，而非 structural assumption。【p.3–4】

### 7.2 Path ranks 是第一层桥梁

Lemma 1 先将分布集相等改写为 mixing matrices 在 column scaling/permutation 下的闭包相等。Lemma 2 说明 generic mixing submatrix 的 usual rank 等于 graph path rank。Lemma 3 再给出等价的全量 path-rank preservation criterion。其代价也被明确指出：要遍历 vertex permutations、Z/Y 子集并逐次做 graph traversal，组合复杂度高。【p.5】

### 7.3 Edge ranks 把全局路径压到局部边

Definition 4 把 edge rank 定义为 Y 到 Z 的 maximum bipartite matching，并允许 self-match；Definition 5–6 将图邻接编码为 support matrix Q，并用 matching rank 读取边约束。Lemma 4 是直接由定义得到的 support-matrix rank 对应关系。Theorem 1 给出 path-rank 与 complementary edge-rank 的 duality，解释二者共享 bottleneck 结构。Lemma 5 将等价条件改写成 source set 包含所有 latents 时的 edge-rank preservation。【p.6–7】

Figure 2 的作用是把 path bottleneck 和 edge matching 并置，减少从 matrix rank 到 matching rank 的认知跳跃。作者随后用 Example 1 说明 path ranks 的全球性：同一 rank pattern 下，添加 cycles、删除 edges、改变 latent placement 都能生成大量候选；当 m=n=4 时，示例给出 17、872、1,024 个等价图。【p.6】

### 7.4 Theorem 2：singleton children bases

Theorem 2 定义 `bases_G(Y)` 为从 Y 出发的 perfect edge matchings 所到达的 vertex sets，并把 Lemma 5 的所有 `Y ⊇ L` 检查压缩成 `L` 本身和每个 `L ∪ {X_i}`。这一步是全局 rank constraint 到局部 singleton test 的关键，直接支撑 Phase 2 的列独立重建。【p.8；Appendix B.3.3 p.31–32】

### 7.5 Theorem 3：等价类 traversal

Lemma 6 处理 vertex-disjoint cycle reversals；Lemma 7 用 coloop 条件判断 absent edge 是否可加入，且 deletion 是反向可加入。Theorem 3 证明这两类操作在 up-to-L-relabeling 意义下既充分又必要，并且整个 sequence 至多需要一次 cycle reversal。Figure 3 用 6 个 digraph 展示操作关系。CP(G) 的 maximal presentation 被留到 Appendix C.3 的 Theorem 4。【p.8–9】

### 7.6 glvLiNG 算法

glvLiNG 的输入是 OICA 得到的 observed-row mixing matrix 估计，输出是满足 rank oracle 的 support matrix/digraph 与其完整 equivalence class。Phase 1 对 latent columns 求一个 realization of a transversal matroid；Phase 2 根据 Lemma 9 将 all-subset augmentation 分解为 observed singleton columns，再用 Lemma 10 的 circuit-based deterministic construction 填列，最后做 row permutation 使 diagonal 非零并用 Theorem 3 BFS/DFS traversal。【p.9–10；Appendix A.2–A.4 p.21–24】

Appendix B 的逻辑依赖是：

`Lemma 8`（块拼接独立集）→ `Lemma 10`（单列 particular solution）→ `Corollary 1/2`（maximal/minimal solutions）→ `Lemma 12`（Hasse connectivity）→ `Lemma 13`（单边 alteration）→ `Corollary 3/4`（matroid tower traversal）→ `Theorem 3`。

## 10. 实验设计

### 10.1 研究问题和假设

实验分成五项：等价类规模、运行时间、oracle inputs 下既有方法、finite-sample simulation、Hong Kong stock returns。方法保证依赖 oracle OICA 和 faithfulness；Appendix D 的真实运行改用 SDP-ICA 与 noisy-rank confidence heuristic。【p.9–10；p.21；p.46】

### 10.2 数据、模型、基线和指标

- **枚举**：weakly connected digraphs，n≤6，多种 latent configurations；计数区分 L-isomorphic variants 和 unique up to L-relabeling。
- **runtime**：Erdős–Rényi、n=5/7/9/11/13、average in-degree 1 或 3、ℓ=1/3/5；每个完成设置 50 个模型，Apple M4，10 分钟超时。
- **oracle benchmark**：LaHiCaSl、PO-LiNGAM，oracle GIN tests，n=10/15/20，ℓ=1–4，average degree 3/5/7/9，SHD 到 equivalence-class closest truth。
- **simulation**：n=5–13，ℓ=1–5，d∈{1,3}，N=1,000–200,000；causal weights 从 [-2.5,-0.5]∪[0.5,2.5] 均匀采样，noise 从 [-0.5,0.5] 均匀采样；Figure 7 每格 25 个 random irreducible models。
- **stock**：14 stocks、1,331 日样本，2000-01-04 至 2005-06-17，四个行业；指标是 recovered class、edge-count range、solid/dashed edges 和 qualitative sector patterns。

没有统一 seed protocol、hypothesis test、multiple-comparison procedure、bootstrap、Bayesian analysis 或 confidence interval。Table 4/5 和 Figure 7 的均值配 SD；枚举与 stock graph 采用确定性/描述性数量。【p.44–48】

## 16. 最终判断

1. **单一主线**：先定义 observed distribution set 与 irreducibility，再用 mixing closure/path ranks 建立等价性，借 path/edge duality 将全局条件局部化为 children bases，最后以 matroid reconstruction 和 admissible transformations 实现完整 class recovery。【p.3–10；p.19–35】
2. **正文保留的决策内容**：20 个主文公式、Theorem 2–3、Figure 1–3、glvLiNG 三阶段和五项 evaluation question；oracle OICA/faithfulness 与 OICA efficiency boundary 也被保留。【p.3–10】
3. **附录迁移**：71 个 lettered equations、matroid definitions、10 个 proof blocks、Theorem 4、完整 figures/tables、rank-noise handling 和 stock interpretation 全在附录；迁移使正文概念链可读，但使可复现和可审计性依赖 p.19–48。
4. **最有效模式**：`mixing closure → path ranks → edge ranks → singleton bases → admissible transformations` 形成逐层回答可操作性问题的链；Figure 2 负责直觉，Figure 3 负责 traversal witness。
5. **最大缺口**：oracle theory、finite-sample heuristic 和 dense-graph empirical advantage 之间没有 matched mechanism measurement；没有组件消融，也没有 rank-error/class-coverage/traversal-failure reporting。
6. **可迁移规则**：等价类论文应让「观测对象、等价不变量、局部判定、类遍历」四层形成可追踪闭环，并把实验指标绑定到每层不变量。
7. **规则边界**：模型缺少可观测不变量或实验不能区分机制时，只能报告任务范围内的描述性结果，不能将局部性能外推为普遍识别或因果保证。
