## E. 方法与理论

### E.1 形式化对象和因果链

- **输入状态**：静态场景的视频帧序列 `I={I₁,…,Iₙ}`，拆为 context `I_C` 与 target `I_T`；选 reference `I_R∈I_C` 表达相对 pose（p.3, `Given a sequence of images...`）。
- **三个模块**：`POSE_ENC` 从 context/target 产生 `Z_C,Z_T`；`SCENE_ENC` 将 context 与对应 latent 变成场景表示 `S`；`RENDER` 由 `S,Z_T` 产生预测图像（p.3, Eqs. 1–3）。
- **训练基线**：autoencoding objective `d_I(I_T, RENDER[S,Z_T])` 只要求同一序列的 scene/pose 表示重建 target；这留下 context interpolation 的捷径（p.3–4, Eq. 3）。
- **评测 oracle**：论文训练不依赖 oracle；benchmark 用 VGGT，理由是 robustness 和 ease of use。COLMAP 仅作为 canonical choice 与附录鲁棒性对照（p.3–4, Eq. 4；p.16, Table 8）。
- **转移定义**：若两段序列的 target 共享 camera motion，第一段的 `Z_T^A` 与第二段的 `S^B` 应合成第二段 target；这把 controllability 落在跨场景 input-output 行为上（p.4, Eqs. 5–7）。
- **测量**：TPS 用 oracle pose 轨迹的 `RRA`、`RTA` 或组合 `AUC` 比较真实／生成轨迹；作者明确它只测几何一致性，还需 perceptual measure 检查场景忠实度（p.4, Eqs. 8–9）。
- **训练机制**：two-view stereo-monocular 去掉多 context 插值路径；transferability objective 从同一视频的两种 pose-preserving augmentation 形成低像素重叠 pair，再跨 pair 重建（p.5–6, Eqs. 10–12）。
- **系统扩展**：stereo-monocular XFactor 训练完成后，fine-tune 成 multi-view；reference 选取最大 baseline 最小的 “middlest” frame，POSE_ENC 对 reference 与其他帧逐 pair 预测 latent（p.6, `Multi-View XFactor.`）。

### F.1 研究问题与安排

论文没有预先编号的 hypothesis 列表；第 4 节以三项任务组织研究问题：

1. **Transferability**：XFactor 的 pose latent 是否能跨场景复用？与 RayZer、RUST 比较，使用表 1 的 TPS/RRA/RTA/AUC/FID（p.8, `Our principal evaluation concerns transferability.`）。
2. **Pose probe**：latent 是否编码 oracle 的真实世界 SE(3) pose？冻结 `POSE_ENC`，用三层 MLP 反推，并与表 2 的 trajectory accuracy 对照（p.8–9）。
3. **Ablations**：stereo-monocular 与 transferability objective 是否分别承担 transfer 能力？加入额外 context、瓶颈、SE(3)+Plücker、其他 SSL objective 和 temporal corruption（p.9、p.15）。

实验顺序与引言贡献一致：先判定行为上的 transfer，再测 latent 的可探测几何信息，最后隔离设计组件；附录再提供 autoencoding、inference augmentation、objective robustness、oracle robustness 和 artifact 检查。

## G. 结果、统计与可视化

### G.1 统计方法与分母

- **聚合单位／分母**：主 transfer 结果对每个数据集的 4,000 对序列，报告“averaged over all sequences per dataset”；表内数值以百分比样式的 accuracy／AUC 与 FID 汇总，论文没有提供每个样本的分布或方差（p.8）。
- **中心量**：RRA、RTA、AUC 在 10°、20°、30°阈值的 accuracy；FID 越低越好；PSNR/SSIM 越高越好，LPIPS/FID 越低越好。
- **轨迹 probe**：冻结 `POSE_ENC`，MLP 预测 VGGT 的 SE(3)；比较实验的 scale-invariant trajectory loss 与 relative-pose ablation loss 见 p.14。
- **不确定性**：没有标准差、置信区间、bootstrap、Bayesian posterior 或显著性检验；作者使用“significantly”作自然语言判断，但没有给出检验量或阈值。
- **机制证据与效果量**：TPS 是行为证据，pose probe 是 representation evidence，FID/PSNR/SSIM/LPIPS 是视觉效果证据。论文把这些通道分开报告，没有将 probe 的好坏当作 transfer 的充分条件；p.9 明确指出 RayZer/RUST probe 尚可但 transfer 失败。

表 3 的主结论是：增加 context 会逐步削弱 transfer；16-d bottleneck 可以部分替代 objective；显式 SE(3)+Plücker 没有成为有效的 anti-leakage 方案。作者将 probe 与 transfer 分开，因此允许“pose 可探测但不可迁移”的结果存在（p.9）。

### H.2 附录消融与负面结果

- **SimCLR/VICReg（Table 6, p.15）**：不用 `RENDER`，只以两种 augmentation 产生 positive pose latent。AUC@20° 的 XFactor 为 54.8／61.2／71.5／50.3，SimCLR 为 3.8／2.3／0.5／0.8，VICReg 为 0.8／0／0／3.4。作者据此提出 rendering 可能是 geometric reasoning 的 facilitator；该因果解释仍缺少更细的 loss-matched control。
- **Temporal Shift +1/+2（Table 7, p.15–16）**：把正确 augmentation pair 替换为相邻时间偏移 pair。transfer AUC@20° 从 XFactor 的 47.2／44.8／49.3／14.6 降到 shift +1 的 41.6／36.2／36.1／11.1，再到 shift +2 的 41.1／32.7／29.2／9.38；probe 下降更明显。作者据此区分“transfer objective 的数值鲁棒性”和“几何 correspondence 的形成”，但没有给出 pair-level error 分布。
- **Inference augmentation（Table 5, p.14）**：XFactor 加遮罩后仍有 PSNR 26.1／22.7／24.2／25.5、FID 2.55／22.1／3.43／4.84；结果接近表 4。作者同时承认 RayZer/RUST 未训练 masked input，此设置无法公平比较，避免将其作为跨模型胜负依据。
- **TPS oracle robustness（Figure 2/Table 8, p.16）**：VGGT 在 weak/heavy distortion 下维持稳定，COLMAP 逐渐发散或拒绝注册；20° AUC 为 VGGT 80.8／89.4／86.7／74.4，COLMAP 33.9／63.4／51.7／39.8；Success Rate 分别为 VGGT 四个 100%，COLMAP 28.9／52.3／21.4／32.0。该附录把“评测器本身的脆弱性”从模型能力中分离出来。
- **Reconstruction Artifacts（Figure 3, p.17）**：XFactor 在 wide-baseline、out-of-sight、distribution-shift viewpoints 上可能 blur/warp；LVSM 在困难 extrapolation target 上也出现类似 artifact。作者以此把问题归因到 deterministic model 对不确定性的处理，并提出 camera-controllable generative model 作为后续方向。

### H.3 负面信息的呈现位置

可直接观察到的呈现策略如下：

1. **附录迁移**：autoencoding 基准、masked inference、SSL 对照、temporal corruption、oracle robustness 和 reconstruction artifacts 均放在 Appendix B（p.13–17），正文只在第 4 节预告或在 Limitations 简要回收。
2. **指标分层**：作者把 TPS 定为主判据，同时补充 FID、PSNR/SSIM/LPIPS 和 pose probe；这样可见“视觉重建好”与“pose transfer 好”是不同通道。TPS 可被源帧重放 hack 的 caveat 留在定义段（p.4）。
3. **比较公平性限定**：表 5 只评估 XFactor，并明确 RayZer/RUST 没见过 masked inputs，故不以该设置比较它们（p.14–15）。
4. **oracle 选择限定**：主评测用 VGGT，附录报告 COLMAP 在 distortion 和 transferred videos 上的 rejection；这使主模型结果避免被脆弱 oracle 的拒绝样本主导，但也把 oracle 依赖移出主表。
5. **语气弱化的位置**：作者用 “likely due to”“we attribute”“we posit”“outstanding problems”表达 interpolation、RUST 略优和 artifact 原因；这些均是解释性句子，未标成定理。上述描述记录呈现位置，不推断作者意图。

## I. 结论、limitations 与闭环

### I.1 Limitations（p.9–10）

1. **超宽 baseline**：`POSE_ENC` 被限制为 stereo，一次前向不能估计 ultra-wide baseline。多视图 encoder 理论上可沿重叠帧链路估计，但 self-supervised 版本如何避免 interpolative bias 仍开放（p.9–10, `the restriction of POSE_ENC to a stereo model...`）。类型为 `generality` 与 `assumption`。
2. **生成质量**：当 target pose 偏离 context，转移帧的 blur/warp 增多；作者将其与 deterministic、缺少生成式不确定性处理联系起来，并以 LVSM 图示作旁证。类型为 `metric` 与 `deployment`。
3. **评测持续性**：附录称继续改善 TPS、全面评估 transferability 仍是 outstanding problem（p.15）；这限制了“true NVS”主张的测量覆盖。类型为 `metric` 与 `generality`。
4. **训练／实现可复现性边界**：PDF 给出硬件、优化器、层数和采样 baseline，但没有 seed、训练拆分、公开 code 或逐数据集训练曲线；这些属于文中缺失项，并非作者在 Limitations 段明确承认。类型为 `reproducibility`，证据见 p.7、p.13–14。

### K.3 修辞结构判断

强主张集中在 `first geometry-free self-supervised model`、`dramatically/significantly outperforms`、`highly correlated`、`SE(3) harmful`；弱主张集中在 `likely`、`we attribute`、`we posit`、`could effectively address`。论文的有效做法是把 behavior metric（TPS）、representation probe 和 perceptual metrics 分离，使“能预测 pose”与“能跨场景 transfer”不互相替代。最明显的文本层风险是 small caps 拆词（如 `POSE_ENC` 变成 `P`、`OSE`、`E`、`NC`），以及表格标题／作者引用进入 n-gram；因此词频只能说明论证动作的重心，不能当作精确语料学统计。

## L. 最终判断

1. **单一主线**：论文把 NVS 的可控性重写为跨场景 pose transfer；先用 `stereo-monocular` 去除多 context interpolation，再用 pose-preserving、低像素重叠 augmentation 把 transferability 写进训练 loss，最后 fine-tune 成 multi-view XFactor。证据链为 p.4 Eqs. 5–9 → p.5–6 Eqs. 10–12 → p.7–9 Tables 1–3。
2. **正文保留的决策关键内容**：transferability 定义、TPS caveat、two-view bootstrap、Eq. 11 objective、Eq. 12 augmentation、主数据集／基线、transfer/probe/ablation 三项主结果。它们足以让读者理解“为什么设计改变了行为”。
3. **移入附录的细节及其影响**：ViT/token 实现、optimizer、采样 baseline、GPU 时长、autoencoding 和 masked inference、SSL/temporal/oracle robustness、artifact 案例移入 p.13–17；这保留了正文叙事速度，却让实现复现和负面证据依赖附录。迁移没有破坏判据和主结论的可读性，但降低了正文对 oracle fragility、artifact 与公平性限制的即时暴露。
4. **最有效的模式**：用一个可迁移的 input-output criterion 统领方法与评测；用跨 pair 训练图（Fig. 1）和三层对照表（Tables 1–3）把“行为、表示、组件”逐级拆开；Eq. 10–12 将直觉压缩为可执行训练机制。
5. **最明显的叙事规避、未闭合主张或读者成本**：`first` 优先性没有本文内穷尽证据；“interpolation 导致 failure”“rendering facilitates geometric reasoning”“deterministic model 导致 artifact”主要靠结果后的解释，缺少独立 intervention；主结果依赖 VGGT oracle，而 oracle robustness 和 COLMAP rejection 延后至附录；没有 seed、拆分样本量和统计检验。读者需在正文、Appendix B 和多个表格之间往返，才能评估复现与测量边界。
6. **可迁移规则**：对任何无显式状态表示的生成任务，先定义跨实例可复用的 input-output 行为，再把该行为写成跨样本训练 objective；同时把行为指标、表示 probe 和内容 fidelity 分开报告。
7. **规则适用边界**：该规则适用于存在“同一控制量应在不同内容实例中保持语义”的任务，例如视角、动作或轨迹转移；它要求能构造保持控制量、削弱内容重叠的 paired observations。若控制量无法保持、场景随时间变化、目标本身允许多模态，或 proxy oracle 对 corruption 脆弱，则行为指标需补充生成式、多样性或任务特定验证，不能仅凭 transfer score 推出完整能力。
