## 5. 方法与理论

### 5.1 形式化对象与训练主线

- **RF 目标**：式 (1) 在条件 `c`、时间 `t`、干净样本 `x^0` 上最小化预测 velocity `u(x^t|t,c;θ)` 与目标 velocity `v(x)` 的平方误差（p.3，§2.1，公式 (1)）。
- **统一条件**：T2I 和 T2V 将 `c` 设为 text prompt，`x` 为 image 或 video；I2V 将 first frame 和 text prompt 作为条件，并把 first frame 的 noise 设为零，无需修改模型（p.3，§2.1，“setting the noise of the first frame to zero”）。这支持单模型三任务，但 T2I 的定量结果未在主文单独给出。
- **block AR**：对 `x_{1:N}` 按 block chain rule 分解 `p(x_{1:N})=∏_i p(x_i|x_{j<i})`，每个 block 的条件分布由 diffusion 过程建模（p.3，§2.2，公式行）。
- **三阶段训练**：Stage 1 用约 5--10K steps 做 VAE adaptation；Stage 2 从 SANA-1.6B 继续预训练，新增层 zero-initialized + skip connection，并从 192p/2.5 s 粗到 480p/5 s 细；Stage 3 先 autoregressive block training，再用 self-forcing 处理 exposure bias（pp.3--4，§3.1）。

### 5.2 Linear Video DiT

1. **RoPE 位置**：在 ReLU kernel `φ` 后应用 RoPE，即 `RoPE(φ(x))`，而非先 RoPE 再 ReLU。作者把前者与更稀疏、更局部的 attention map 联系起来；后者可能使非负 ReLU 输出失效并令线性 attention 分母为零（pp.4--5，§3.2、Figure 3）。
2. **稳定分母**：式 (2) 的 numerator 同时保留 RoPE(Q) 与 RoPE(K)，denominator 去除 RoPE，使用 `φ(Q_i)∑φ(K_j)^T`，以保持正值并保留位置编码的 numerator 作用（p.5，§3.2，公式 (2)）。这是一个训练稳定性保证式，而非泛化定理。
3. **Spatial-Temporal Mix-FFN**：在既有 Mix-FFN 的空间卷积后加 temporal convolution shortcut，聚合相邻帧并保留初始化。正文称 temporal 1D convolution，Figure 2 图内标注为 `3×1×1 ConvLayer`；Figure 5 caption 又写作 “temporal 2D Convolution”，构成术语不一致（pp.4--5、p.9）。
4. **预训练兼容性**：新 temporal 层 zero-initialized，使早期训练近似保持预训练 image model；Figure 3 与 Figure 5(a)--(b) 给出局部性和 loss 证据（pp.4--5、p.9）。

### 5.3 Block Linear Attention 与长期生成

- **复杂度对照**：Table 1 以 `N` tokens、token width `D` 和 local window `W` 对比三种 attention。causal full 是 memory `O(ND)`、每新 token `O(ND)`、全序列 `O(N²D)`；causal local 是 `O(WD)`、`O(WD)`、`O(NWD)`；causal linear 是 `O(D²)`、`O(D²)`、`O(ND²)`。作者在 `N>W>>D` 下主张 causal linear 同时保留 global memory（p.5，Table 1）。
- **累计状态**：式 (3) 写出 causal linear attention，令 `S_j=φ(K_j)^T V_j`；缓存过去 `S_j` 的累计和及 `φ(K_j)^T` 的累计和，新 token 只需当前 `S_i`。缓存空间和每 token 计算均为 `O(D²)`，与历史 token 数无关（p.6，§3.3.1，公式 (3)）。
- **因果 Mix-FFN**：训练时每个 block 末尾追加全零 token `R^{1×HW×D}`，阻止后续 block 信息泄露；推理时缓存前一 block 的最后 frame/token 并 prepend 到下一 block。最终 KV cache 由 attention 的累计 state、key sum 和 Mix-FFN 的 last frame 组成（p.6，§3.3.1，Figure 4）。
- **单调 SNR sampler**：随机选一个 block 用 SNR sampler 采 timestep，其余 block 用 propagated probability 生成单调递增 timestep，后面的 block 噪声更大。作者给出的机制解释是采样空间更小、收敛更快，并让每个 block 获得充分训练（p.7，§3.4）。
- **Exposure bias 与 self-forcing**：训练条件是 ground-truth block，推理条件是模型生成 block，误差会累积。LongSANA 用 global constant-memory cache 把 self-rollout 从 5 s 延伸到约 1 min，目标是让训练／推理条件更接近并保持时序一致（p.7，§3.4）。
- **推理算法**：Algorithm 1 初始化 `X_θ=[]`、`KV=[None,None,None]`；外层遍历 `M` 个 block，内层按 `T→1` 去噪。每个 block 完成后 append clean latent，并以 `G_θ^{KV}` 更新累计 state、key sum、conv cache；非末步通过 scheduler 加噪进入下一 timestep（p.18，Appendix C.3，Algorithm 1）。循环不变量是 cache 大小固定；正文没有单独给出 wall-clock 复杂度式。

### 5.4 DCAE-V

DCAE-V 从 DCAE fine-tune，空间下采样 `F=32`、时间因子 `T=4`、latent channels `C=32`，与预训练 T2I latent channels 对齐（p.7，§3.5）。相同空间压缩下，Wan2.2-VAE 需要 192 latent dimensions，而 DCAE-V 只需 32；作者据此解释小 diffusion model 更容易适配 DCAE-V。Table 3 显示其干净样本重建 PSNR/SSIM/LPIPS 为 33.25/0.94/0.03，原始 Wan2.2-VAE 的 PSNR/SSIM 更高，但 DCAE-V 压缩比为 128。

### 5.5 方法动作转移

`setup_notation → state_problem → define_component → derive → give_intuition → instantiate_algorithm → state_complexity → connect_to_prediction → connect_to_experiment → summarize`。核心因果链是 token explosion → linear attention → RoPE／temporal locality → cumulative state → autoregressive training → DCAE-V／data filtering → short and long video efficiency。理论在这里承担复杂度和数值稳定性保证，未形成独立定理体系。

## 9. 结论、限制与闭环

### 9.1 结论段

p.10 的结论按 `重述问题 → 重述方法 → 回收结果／影响` 推进：先称 SANA-Video 以低硬件需求生成高分辨率、高质量、长视频；再回收 linear attention、constant-memory KV cache、数据过滤和 64 H100×12 days；最后回收 16× latency 与 small diffusion models 的竞争性（p.10，§7）。没有新数字，只有对摘要主张的压缩重述。

## 12. 最终判断

1. **单一主线**：面对视频 token 数、quadratic attention 和长序列 KV cache 的共同瓶颈，论文把预训练 SANA-1.6B 改造成 Linear Video DiT，用 RoPE 和 temporal Mix-FFN 追回局部时空建模，再用累计状态的 Block Linear Attention 获得固定内存的 global context，配合单调 SNR／self-forcing、DCAE-V 和数据筛选完成从 5 s 到 minute-length 的低成本生成。
2. **正文保留的决策关键内容**：问题规模、三阶段训练概览、RoPE denominator 修正、式 (3) 的累计 cache、Table 1 复杂度、Table 2／4 主效率与 VBench、Table 5 组件消融、Table 6 AR 对比、Figure 6 NVFP4 速度，以及结论回收。它们足以让读者理解主设计和主要 trade-off。
3. **移入附录的细节及影响**：完整 related work、architecture／optimizer／batch／steps、Algorithm 1、VAE 扰动、定性 I2V／T2V、长视频 30 s 评测、过滤阈值和 world-model 数据来源均在附录。附录使工程叙述更完整，但 internal data、source-specific thresholds、seed、评测分布和失败案例仍缺失，正文对可复现性不自足。
4. **最有效模式**：Figure 2 将数据到 Linear DiT 的系统边界画清；式 (2)--(3) 把数值稳定和固定 cache 机制写成可检查的代数；Table 1 给复杂度；Table 4 同时放 latency、params 和 VBench；Table 5 对三个结构／训练选择做直接成对比较。这一组“机制图 → 复杂度 → 主结果 → 组件消融”推进最有说服力。
5. **最大叙事缺口**：speedup 口径跨分辨率、长度、steps、硬件和基线，摘要的 16× 与正文的 8×、13×、53× 未统一；没有 variance、seeds 或 inferential statistics；LongSANA 的 1-minute 主要是单例可视化；world-model 只有 potential；量化质量和 code/model release 仍是未闭合承诺。
6. **可迁移规则**：当论文以状态压缩替换全局 attention 时，必须让状态不变量、复杂度表、统一 latency protocol 和组件消融共享同一输入长度／分辨率／steps，并把质量、速度和内存分别报告。
7. **规则边界**：这条规则适用于效率型生成模型、状态缓存和可控推理实验；若任务的全局依赖无法由固定状态充分汇总，或质量需要人类／任务级评测，复杂度不变量不能代替能力证据，仍需专门的 coverage、失败案例和人类评测。
