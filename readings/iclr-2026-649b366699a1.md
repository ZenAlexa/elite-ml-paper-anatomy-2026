## 4. 相关工作

相关工作是独立第 2 节，位于引言后、方法前（p.2–3），占正文约 470 词。三个主题簇及其比较维度如下：

1. **Multimodal Embedding（p.2–3）**：先承认 CLIP、MetaCLIP、BLIP、SigLIP 等共享空间和 contrastive training 的基础，再按 VLM backbone（VLM2Vec、GME、LLaVE）与数据／训练策略（MegaPairs、mmE5、UniME、B3、MoCa）分类；最后把单向量扩展瓶颈指向本文。
2. **Multi-Vector Retrieval（p.3）**：以 ColBERT 的 late interaction 为最近邻参照，沿 approximation、compression 和 ColPali/ColQwen 等 text-image 方法对比；具体差异是既有方法在 query 侧引入数百图像 token 后，multimodal-to-multimodal 训练和推理成本过高。该段承担 `nearest_neighbor_contrast + limitation_of_prior + gap_creation`。
3. **Matryoshka Representation Learning（p.3）**：承认 MRL 在单向量多粒度表示和 VLM generation token budgeting 中的 foundation，再明确本文的定位，“first work” 将 nested structure 用于 multi-vector retrieval 并实现 test-time scaling。该段承担 `credit_or_foundation + gap_creation`。

没有独立的 chronology 段落；引用簇数量按上述三个主题簇计为 3。相关工作没有逐一复述本文组件，方法介绍从第 3 节重新定义 retrieval、late interaction 和 Meta Tokens；后续正文继续用 ColBERT/Matryoshka 的引用承担复杂度与设计动机，但没有进一步回到 baseline 的引用链进行机制解释。

### 8.2 限制与自我设限位置

- **compute／deployment（p.9, Discussion；p.17, A.1）**：index memory 随 budget 增长，full `(16,64)` 为 42.72 GiB；效率实现是 native PyTorch `einsum`，latency 被作者描述为 conservative upper bound。
- **compute（p.9）**：query encoding（1024-token image query，42.72 TFLOPs、788 ms）远高于中小预算 scoring；优化重点因而转向 encoder。
- **generality／assumption（p.7）**：Llama-3.2-Vision-11B 的 VQA 42.1 显著低于 Qwen2.5-VL-7B 的 74.2；作者把 base generative weakness 作为 embedding weakness 的来源。

- **data／causality（p.18）**：ObjectNet/ImageNet 113 类重叠未修正；A.3 直接呼吁更 principled evaluation protocol。
- **ethics（p.10）**：现有 multimodal datasets 可能含 cultural、demographic、linguistic biases，部署需要考虑 downstream fairness impacts。
- **metric／statistical（p.6–9）**：宏平均 Precision@1/NDCG@5 把 task 异质性压缩成单一数值；seed、区间、检验身份和样本分母均未在主表给出。

## 9. 结论与主张闭环

### 9.1 结论段落

p.9 的 Conclusion 为一个段落，动作序列为 `restate_problem → restate_method → restate_result → boundary/impact`：先重述大规模 embedding construction/interaction 问题，再回收 Meta Tokens 与 MMR 的 coarse-to-fine 机制，随后回收 accuracy/index size/latency 的平衡和 test-time scalability，最后提出 general、efficient、controllable retrieval 的影响。该段没有新数字、新实验或新的理论主张；`“bridging the gap between fine-grained expressiveness and large-scale deployability”` 是解释性收束（`interpretation`，p.9）。

## 12. 最终判断

1. **单一主线**：论文把“单向量的细粒度损失”与“token-level multi-vector 的索引／交互成本”收束为一个可调旋钮，learnable Meta Tokens 产生紧凑多向量，MMR 用 prefix-nested contrastive groups 让同一表示在 test-time 按 \((r_q,r_c)\) 伸缩（p.1–5，Eq. (3–7)，Figure 1–3）。最强可辩护因果链是 **nested training → monotone budget curve → accuracy/index/latency trade-off**，而非无条件的“通用 SOTA”。
