## 5. 方法与理论

### 5.1 形式化对象与闭环

§3.1（p.3–4）将问题写为带两条超参数分支的 bi-level optimization。输入为带单点标注的红外图像 `x_i`，检测器为 `N`、参数为 `ω`，样本权重为 `α_i`，扩散参数为 `θ`，伪标签为 `ŷ_i(θ)`。内层以加权训练损失更新 `ω`；外层以 validation loss 同时更新 `α` 与 `θ`。验证集使用 physics-induced pseudo-label，而非真实密集标签。作者把这描述为从训练到监督生成的动态闭环（p.4, §3.1，锚点 “the proposed bi-level dual-update framework establishes a dynamic closed-loop”）。

核心形式为：

\[
\min_{\alpha,\theta} \; \mathcal L_{val}(\omega^*(\alpha,\theta),\alpha,\theta),
\qquad
\omega^*(\alpha,\theta)=\arg\min_\omega\sum_i \alpha_i\mathcal L_{tr}(\mathcal N(x_i;\omega),\hat y_i).
\]

它表达了三条因果链：`θ` 改变监督场，`α` 改变样本贡献，`ω` 改变检测响应，validation loss 反向约束前两者。论文没有给出收敛定理、误差界、复杂度定理或独立 proof。

### 5.2 Physics-Induced Diffusion Annotation

§3.2（p.4）把单点 `p_i` 视为局部热源，以各向异性扩散场 `u(a,b,t)` 生成伪标签。连续动力学是：

\[
\frac{\partial u(a,b,t)}{\partial t}=\nabla\cdot\left(D_\theta(a,b)\nabla u(a,b,t)\right),
\quad u(a,b,0)=\delta(a-p_i,b-p_i).
\]

`D_θ(a,b)` 是可学习、随空间变化的 diffusion tensor；作者解释它在均匀区域加快传播以填补缺失，在边缘和高梯度结构附近减慢传播以抑制边界扩散。离散化后：

\[
u^{(k+1)}=(I-\tau L_{D_\theta})u^{(k)},\qquad u^{(0)}=\delta_{p_i},
\]

迭代 `K` 次得到 quasi-steady thermal field。随后加入包含点 `p_i` 的 superpixel 二值区域 `C_{p_i}(a,b)`，用可学习 `ρ∈[0,1]` 聚合：

\[
\hat y_i(\theta)=\rho u^{(K)}(a,b)+(1-\rho)C_{p_i}(a,b),
\]

并归一化到 `[0,1]`。这个组件将物理连续性与局部结构边界合并为可微监督信号。作者没有说明 `D_θ` 的具体网络参数化、`K`、`τ`、superpixel 算法/参数或 `ρ` 初始化；这些实现粒度在主文中缺失，且没有 appendix 补充。

### 5.3 Dynamic Aggregated Solution

§3.3（p.4–5）指出精确 bi-level 求解需要高阶 unrolling 或 implicit differentiation，交替更新又可能因频率错配而不稳定。作者采用 first-order dynamic aggregation，在 inner loop 的 detector 更新中加入训练梯度和 `β` 缩放的 validation 梯度；随后对 `α` 做一步 validation 梯度更新；最后用 differentiable diffusion surrogate `M(y_i;θ)` 对齐 offline pseudo-label `ŷ_i`，并用当前 detector response `y_i` 作正则。三条更新式均嵌在段落中，未另编号为 display equation。

- `ω`：`∇ω L_tr + β∇ω L_val` 的联合更新，`β` 控制 validation feedback 强度；
- `α`：在最新 `ω^{t+1}` 上沿 `L_val` 更新 sample weights；
- `θ`：最小化 `L_val(M(y_i;θ), ŷ_i) + L_val(M(y_i;θ), y_i)`，第一项拟合离线物理伪标签，第二项约束当前响应，减轻噪声监督过拟合。

方法动作转移为：`setup_notation → state_problem → derive → define_component → explain_mechanism → give_intuition → instantiate_algorithm → connect_to_prediction → connect_to_experiment → summarize`。正文没有伪代码、算法框或复杂度说明；Figure 2 是一张框架图，展示 `Sample Rebalance`、`Label Refinement`、`Weighted Data`、可选 detector 及 generated labels 的交互。

## 12. 最终判断

1. **单一主线** — point supervision 有两个耦合失败（伪标签在低对比度 clutter 中不稳，样本分布严重不平衡）。论文把它们合并为一个闭环，由物理 diffusion + superpixel 产生可微 pseudo-mask，再由 bi-level dynamic update 同时调节 detector、sample weight 与 diffusion 参数。
2. **正文保留的决策关键内容**：Eq. (1)–(4)、Figure 2 框架、数据与训练设置、Tables 1–3 的主比较/消融、Figures 5–7 的机制/数据效率、Tables 4–5 的 annotation 质量与时间，以及 Figure 8 的定性对照。读者可据此理解方法和主要决策。
3. **被移入附录的细节**：本版本没有 appendix；实现参数、硬件、软件版本、完整 seed 聚合和额外失败案例均未提供，复现边界比“附录承载细节”的论文更窄。
4. **最有效的模式**：Table 3 将监督质量（A1–A4）和训练策略（B1–B4）分组，形成从伪标签到优化的因果诊断；Tables 4–5 同时报告 IoU 与 per-target time，把精度/效率主张放在同一决策面。
5. **最大缺口**：`significantly`、`consistently` 等强措辞没有统计检验或跨 seed 汇总；30% 数据与代表性图例主要依赖曲线/案例；没有独立验证 physics field、validation pseudo-label 偏差和部署代价。
6. **可迁移规则**：当方法同时改变监督生成和样本贡献时，应把“监督组件”和“优化组件”分组消融，并用同一评测对象报告质量、效果、成本三类证据。
7. **适用边界**：该规则适合具有可分离监督生成/训练权重路径的视觉学习方法；若模块高度耦合、缺少可控替代或任务没有明确成本指标，则需改用机制对照与失败分层，不能仅凭单一消融表宣称因果闭环。
