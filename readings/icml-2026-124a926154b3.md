## 5. 方法、理论与可执行对象

### 5.1 单一机制链

VALUEFLOW 的机制链是：将开放文本映射到包含方向标签的层级空间（HiVES）→ 对每个 macro-value 收集 value-conditional 排序并以 Plackett–Luce 估计分数（VIDB）→ 将模型 response 与固定 VIDB anchors 作 windowed ranking，并把 response utility 映射到 [−10,10] → 以 `(value, intensity)` 或 user-text profile 条件生成，再测 default-to-steered gain。Figure 1 是该闭环的唯一端到端解释图；Figure 3 将 DB construction 与 response evaluation 的局部流程分开。[p.2 Figure 1; p.5 §5.1, “PL optimization”; p.6 §5.2, “ranking against fixed DB anchors”]

### 5.2 最小逻辑单元

- **形式化对象**：第 3.1 节定义 `A`（value set）、`Λ`（intensity space）、query `x`、生成模型 `M`、response `y`、intensity evaluator `I`，并将目标写为对每个目标 value 有 `I(y | x, ai) ≈ λi`。[p.3 §3.1, “Definition (Steerability with intensity)”]
- **层级标注**：四个理论被建成 1—3 层 hierarchy。七个 LLM 对每层 child 投票；≥5 票或领先 ≥2 票接受，含 Neutral 的重问与 human adjudication 处理未决项。最终 label 是 root 到最后固定 node 的 path。[p.4 §4.1, “panel of seven LLMs votes”; p.20 §B.2, “Consensus and neutrality check”]
- **跨理论连接**：所有 corpora 经 qwen3-embedding-8B、k-means（约 500 clusters）、GPT-4.1 neutral summary、support filtering、human review，得到 274 cross-theory anchors；另有人审的 158 duties、142 values、107 rights friendly instances 供直接 steering。[p.4 §4.2, “This yields 274 anchors”; p.23 §B.3; p.4 §4.2, “158 duties, 142 values, and 107 rights”]
- **HiVES 训练**：Stage 1 的 hierarchical contrastive loss 以 shared hierarchy prefix 与 direction 定义 positives；Stage 2 用 individual 与 theory anchors 的 InfoNCE 对齐，合成损失为 `Lhier + λind Lind + λtheory Ltheory`。这解决了仅在 theory 内聚类会留下跨 theory misalignment 的问题。[p.5 §4.3, “Stage 1. Intra-Theory Alignment”; p.5 “Stage 2. Inter-Theory & Anchor Alignment”]
- **VIDB 建库**：每个 value 最多 10K 去重 texts，目标标签优先且正负平衡；binary ranking 是默认，m=30，PL 按 value 独立估计 latent utility，再进行 per-value bounded calibration 与 flag/human correction。[p.31 §C.2, “up to N = 10,000”; p.33 §C.3, “k = 2”; p.32 §C.2, “equal-weight convex blend”]
- **response evaluator**：k−1 anchors 与 response 组成窗口，judge 给 total order，anchor utility 固定，response utility 为唯一自由变量。所有窗口都排在 anchors 之下时，分数设在最小 anchor 之下；其余情形 clamp 到观察到的 anchor range，再 clip 到 [−10,10]。[p.6 §5.2, “Protocol”; p.36 Algorithm 4]

## 6. 实验设计与复现粒度

论文把设计分为四组：表示质量、rating-vs-ranking 稳定性、single/multi-value steering、profile-based demographic alignment；附录再补 alternatives、safety、context、ablation、multi-turn、multilingual、Buddhist ethics 和 human evaluation。

- **rating instability**：每个 SVT value 抽 10K texts，跨 LLM 比 direct scalar rating 与 ranking，查看 per-item variance、maximum range、sign flip、prompt change、ValueNet sign accuracy 和 pairwise accuracy。[p.3 §3.2, “sample 10K texts”; p.4 Table 1]
- **HiVES**：backbone 是 Qwen3-embedding-0.6B，Stage 1 450K、Stage 2 50K；baseline 是同一 base embedding 和 UniVar。三个指标是 hierarchy ranking accuracy、similarity correlation、value-vector orthogonality。[p.6 §6.1, “450K steps”; p.6 “Baselines include”; p.25 §B.6]
- **VIDB**：32 values，每 value up to 10K de-duplicated texts；ranking judge 包括 Mistral-3.1-24B、Phi-4、Qwen3-32B、Gemma3-27b、gpt-oss-20b。binary k=2、m=30 用于建库，七模型 plausibility panel 加 human review 处理 flags。[p.31 §C.2; p.32 §C.2; p.33 §C.3]
- **steering**：500 queries，来自 GPV、ValueBench、OpinionQA、Moral Stories、Moral Choice，各 100 个 cluster-centroid samples；10 个 models、SVT/MFT/Rights/Duty 四框架、32 values。两种 intervention 为 intensity anchor 与 VIDB user texts，target 是 −2、−1、+1、+2；主评价为 `Δ=ssteered−sdefault`，k=6、m=3，Gemma-3-27B-it 做默认 judge。[p.6 §6.2; p.7 §6.2; p.35 §D.1]
- **demographic profile**：OpinionQA 的 22 demographic groups 用 5% split 建 profile，候选答案以 empirical probability 加权、再乘 HiVES relevance，再在 question/group 级聚合；剩余 held-out data 用于 downstream analysis。baseline 是 attribute-only default 与 Modular Pluralism。[p.8 §6.3; p.57 §E.1]
- **human study**：25 evaluators 产出 2K scalar ratings 和 1.5K pairwise/windowed judgments；正文给出 sample totals、mean absolute deviation、win rate、pairwise consistency、window exact / ±1 accuracy 和 positional deviation，没有报告招募来源、报酬、IRB、标注者人口统计、随机种子或置信区间计算。[p.9 §7.2; p.60—61 §G]

控制与边界也有明确位置：hierarchy mapping 使用 seven-model consensus、Neutral 与 human adjudication；VIDB 在 load time 去 exact duplicate、平衡正负方向、随机交换 pair position；intensity evaluator 使用 fixed/bucketed/random anchor sampling。训练 hardware、全部 decoding parameters、query clustering seed、human-adjudication 规模和 code revision 则没有在已读 PDF 中给出。[p.20 §B.2; p.31 §C.2; p.34 §C.3; p.35 §D.1]

## 7. 结果、统计和可视化

### 7.1 主要结果与统计处理

1. **ranking 取代 direct rating 后更稳定且更接近 ValueNet**。Table 1 报告 mean variance 12.6→2.1、maximum range 7.1→2.8、sign-flip 48%→29%、prompt change 3.6→2.3、sign accuracy 82.5%→86.8%、pairwise accuracy 77.4%→84.2%。聚合单位是 item/value 下的 LLM judging outputs；表中没有 error bar、interval 或 test。[p.3 §3.2; p.4 Table 1]
2. **HiVES 对两个 embedding baselines 改善层级排序、similarity correlation 和 orthogonality**。正文只给 “over 20%” 与 “over 50%” 的概括；Figure 5 承担具体柱状比较，误差表达没有在图注中出现。[p.6 §6.1, “over 20%”; p.7 Figure 5]
3. **model steerability 呈三类 regime**。Figure 4 的每个颜色 bar 是 model×value×target 的 mean steered intensity，white dot 是 default；Phi-4/Claude-4 对负向尤其弱，Qwen3/GPT-4.1/gpt-oss/Mistral 中等，Grok-4/Gemma-3/Gemini-2.5/GLM-4 强。图未展示 seed-level dispersion，因而这是 aggregate pattern。[p.7 §6.2, “three qualitative steerability regimes”; p.7 Figure 4]
4. **value 的 response shape 分三种**：Conformity 等 hard-to-steer（`|Δ|≈0`）、Hedonism/rights 的 polarity-asymmetric、许多 SVT/duty 的 bidirectional；Security 的高默认值造成 positive headroom 限制。[p.8 §6.2, “three recurring patterns”; p.8 Figure 6]
5. **profile steering 改善 OpinionQA prediction**。Table 3 的 micro-average 是 Qwen3 56.6→59.1、Phi-4 51.2→55.7、GLM-4 56.8→59.1；作者报告 across temperatures T∈[0.0,0.8] 的 gains，以及 paired t≈16—20、p<10−60。分母是 group-response examples 的 micro-average，组别粒度是 Reg/Edu/Inc/Ideo/Par/Race/Relig/Sex。[p.7 Table 3; p.8 §6.3]
6. **two-value 与 five-value composition 存在结构性非对称**。相近 pairs 大致 additive，opposed pairs 发生 trade-off；five-value 中 +2 target 往往主导并把 negative targets 拉向 neutral。Figure 8/附录 Figures 24—28 展示 vector arrows 与 heatmap，主文未用 hypothesis test 区分不同 pair。[p.8 §7.1; p.9 Figure 8]
7. **human evaluation 支持 evaluator fidelity**。本文方法的 scalar mean absolute deviation 为 1.4，对四个 rating baselines 的 win rate 为 60.4%—78.7%；pairwise consistency 85.3%，6-window exact 60.8%、±1 86.7%、mean deviation 0.46。Table 14—15 给出每个量，没有 cross-annotator agreement 或 interval。[p.9 Table 4; p.60 Table 14; p.61 Table 15]
8. **扩展与边界结果**：persona-vector 和 lightweight kernel 的控制弱；negative target 的 refusal 较高；related/irrelevant query 的 steerability magnitude 相近；多轮注入随 turn 向 neutral 衰减；三种额外语言与 Buddhist ethics 图显示 direction-consistent shifts。这些多数是 figure-supported qualitative claims，缺少图外的 per-run uncertainty 报告。[p.50 §D.5—D.6; p.53 §D.7; p.55—56 §D.10; p.59—60 §F]

## 12. 最终判断

**单一主线。** 论文把“价值是否可作为多元、可测且可操控的 alignment interface”拆成层级表示、ranking-calibrated intensity database、fixed-anchor evaluator 和 steering protocol 四个连续环节。它的因果主张是：如果 intensity 的 measurement 比 scalar rating 稳定，VALUEFLOW 就能把 value profile 或 intensity target 转成可比较的 response shift，并据此研究 model / value / multi-value 的可控边界。[p.2 Figure 1; p.4 Table 1; p.6 §5.2]

**正文保留的关键内容。** 主文保留了对象定义、three-gap diagnosis、端到端图、核心损失与 PL 直觉、主实验范围、model/value/multi-value 的代表性结果、人类 fidelity 的压缩表和结论中的两个成本边界。这个选择让读者能判断论文的框架价值和主要 failure pattern。[p.3 §3.1; p.5 §4.3—5.2; p.7—9]

**最有效的写作与图形模式。** Figure 1 先给 extraction–steering–evaluation 的对象流，Table 1 立刻为 ranking choice 建立需要，Figure 4/6/8 依次把差异放在 model、value、composition 三个层次。结构上每一层回答一个更细的可控性问题，读者可以把结论的 “pluralistic” 具体化为组合时的 trade-off 与 +2 dominance。[p.2 Figure 1; p.4 Table 1; p.7 Figure 4; p.8 Figure 6; p.9 Figure 8]

**最大读者成本。** “composition laws”“scalable infrastructure”“cross-cultural deployment” 的措辞强于其形式保证：没有 theorem，没有 per-seed uncertainty，也未提供全部 hardware/seeds。主文把 per-value curves、judge sensitivity、refusal 和 long-horizon decay 移到附录，读者需要跨 50 页恢复不同 conclusion 的适用边界。[p.9 §8; p.54—56 §D.8—D.10; p.63 §H]

**可迁移规则。** 先让一个可审计的 measurement interface 证明自己比临时评分稳定，再把同一 interface 用于控制效果评价；主体正文应保留选择 measurement 的直接证据和控制失败的代表性图，完整 hyperparameter / per-unit 曲线进入附录。该规则适用于能定义稳定 reference anchors、且 intervention 和 evaluator 都围绕同一语义轴的研究；当对象没有可信 anchors、value 之间缺少可解释坐标或对风险后果要求因果保证时，ranking-based descriptive evidence 不能单独承担 deployment claim。[p.4 Table 1; p.6 §5.2; p.63 §H]
