## 5. 方法与理论

### 5.1 方法逻辑

方法的动作序列为：`setup_notation → state_problem → define_component → derive → define_component → derive → connect_to_prediction → formulate_optimization → derive_closed_form → instantiate_algorithm → connect_to_experiment`。先用 SFE 量化 reset 前后权重距离，再用 DfI 作为可优化的 isotropy proxy。式 (4) 把目标写成最小 SFE 的正交约束问题，式 (5) 用 polar decomposition 给出唯一的 closest column-orthogonal point；Algorithm 1 则用 NS 迭代近似该点。贡献点在于把经典 Orthogonal Procrustes operation 重解释为 reset mechanism，经典优化本身并非新定理。

- SFE 在式 (1) 中定义为 `||W − W̃||²_F`；附录把网络级 SFE 展开成各层距离之和。Theorem 1 把它连接到 normalized feature covariance 的上界，连接条件包含输入范数、activation Lipschitz 常数、每层 spectral norm 和输出特征范数下界。
- DfI 在式 (2) 中定义为 `||WᵀW − I||²_F`。作者选择它的理由是可微、与 orthonormal weight geometry 直接相连；Theorem 2–4 分别给出 Hessian curvature、effective rank 和 activity score 的理论联系。
- 约束求解在式 (4) 中固定列正交性 `W̃ᵀW̃=I`，式 (5) 为 `W̃* = W(WᵀW)^{-1/2}`。它维持低 SFE 的含义依赖正交可行集和权重形状；论文没有讨论宽矩阵、秩亏矩阵或 scale 恢复对式 (4) 可行性的完整条件。
- Algorithm 1 接收二维矩阵 `X` 与迭代数 `N`，先做 Frobenius normalization，再以 `a=1.5,b=-0.5` 重复 `A=X.T @ X; X=a*X+b*(X@A)`。卷积层按 spatial slice 独立处理。这里的主文 recurrence 与 Appendix B.3 的系数说明存在未解决的不一致，见「测量与版本分歧」。

### 5.2 理论结果与证明核对

逐页核对到 14 个编号公式 `(1)`–`(14)`。理论 inventory 以 14 个编号公式、4 个 Theorem statement、6 个 Lemma statement、2 个 Corollary statement、10 个 Proof block 和 1 个「Derivation of Equation 5」block 组成 37 个可定位单元；自动文本计数也给出 37 个 theorem/lemma/corollary 词法命中，但其中包含交叉引用，不能把它直接当成 37 个独立定理。

1. **Theorem 1（p.4；proof p.16–17）**：对两个深度为 `L` 的 feedforward networks，activation 为 Lipschitz，`m_ℓ>0`，以 `B_ℓ` 和 `B_Π` 控制 spectral norm，证明 normalized output-feature covariance 差异受 SFE 上界控制。证明依次使用归一化矩阵差异不等式、hybrid outputs、backend Lipschitz 常数、三角不等式和 Cauchy–Schwarz；式 (6)–(12) 闭合到主文定理。它是稳定性 proxy 的核心链，但上界对 spectral scale 和 `m_ℓ` 敏感。
2. **Theorem 2（p.5；proof p.19）**：在 whitened input、per-sample output Hessian norm `≤β`、gradient norm `≤γ`、固定 ReLU activation pattern 与 gating operator norm `≤1` 的条件下，Hessian spectral norm 被 `ν_k=1+√DfI(W_k)` 的 layerwise product 和二阶 remainder 控制。Lemma 1–5 分别控制 spectral norm、covariance growth、block Jacobian、Gauss–Newton part 和 remainder；Corollary 1 在 `γ≈0` 时去掉 remainder 主导项。
3. **Theorem 3（p.5；proof p.20–21）**：对 `Φ=ZW` 的线性 feature map，`W=QS` 为 right polar decomposition，`ε=√DfI(W)<1`，通过 `Σ_Z` 在 `Q` 子空间的正特征值 `η_1,…,η_d` 控制 singular-value condition ratio，再给出 `srank_δ(Φ)` 下界。白化时输入谱项变为 1；非白化时 achievable flattening 受 `M=QᵀΣ_ZQ` 限制。证明用 Rayleigh quotient、条件数最坏分配和 cumulative singular-value ratio 式 (13)–(14)。
4. **Theorem 4（p.5；proof p.21）**：在 `z~N(0,I_a)`、activation positive-homogeneous、`ε=√DfI(W)<1` 条件下，按层平均 activation 归一化的 neuron activity score `s_j` 被 `sqrt((1−ε)/(1+ε))` 与 `sqrt((1+ε)/(1−ε))` 夹住。Corollary 2 给出若 `DfI(W)≤((1−τ²)/(1+τ²))²` 则无 `τ`-dormant neuron；以文中引用的 `τ=0.025` 得到约 `DfI<0.9975` 的阈值。该结论解释的是分数离散度收缩，不是所有 activation 同时增大。

附录证明逐行给出了 Theorem 1 的 hybrid decomposition、Theorem 2 的五个中间 Lemma、Theorem 3 的 polar/singular-value argument、Theorem 4 的 Gaussian homogeneity argument，以及式 (5) 的 Procrustes 推导。理论结果在形式假设下有证明；实验只测了 DfI、normalized SFE 与 curvature，没有直接测 feature covariance、effective rank 或 dormant ratio，因此这些机制与行为结果之间仍有 proxy gap。

### 5.4 实现边界

Appendix C 具体说明了 scale 恢复。Linear layer 使用 `sqrt(d_out/d_in)`；convolutional layer 对每个 `[C_out,C_in]` spatial slice 独立 orthogonalize，并使用 `sqrt(C_out/C_in)/(k_h k_w)`；ViT 只处理 query/key projection，value、output、MLP 不变。作者给出的理由是 dot-product `QKᵀ` 对 conditioning 最敏感，而 MLP/output 的处理没有稳定收益，甚至可能降低性能（p.25 §C）。这些实现细节使方法可以跨 ResNet、VGG、ViT 使用，但没有给出宽矩阵/秩亏和所有 bias/normalization 参数的统一处理规则。

## 6. 实验设计

实验与引言中的三域顺序一致：视觉 → LLM continual pretraining → RL。视觉和语言在新数据到达时 reset；RL 在训练中点做一次 intervention。核心控制逻辑是对比同一数据/模型训练过程中的 base/no intervention、full reset、S&P、DASH 或其他专门方法，并在 RL 中复用相同 checkpoint 与 replay buffer 以减少 reset 前随机性差异。

### 视觉 continual learning

- 数据集/模型为 CIFAR-10/ResNet-18、CIFAR-100/ViT-Tiny、Tiny ImageNet/VGG-16。
- Warm-start 先用 10% 数据训练，再接入全量数据；continual setting 分 10 个阶段，从 10% 到 100% 每次增加 10%；class-incremental setting 以 20 个 phase 等量加入新类别，因 CIFAR-10 类别数不足而排除，只保留 CIFAR-100 与 Tiny ImageNet（p.6–8 §4.1）。
- Baseline 含 full reset、S&P、DASH、Parseval regularization、L2 Init、CBP、SNR、ReDo、Muon 和 base。视觉结果用 test accuracy；Appendix E.1 报告 3 seeds、Adam、`lr=1e−3`、warmup、gradient clipping `0.5`、batch size `256`、每 chunk 100 epochs、无 data augmentation。Warm-start 在新数据前训练 1000 epochs，之后训练 100 epochs（p.28 §E.1）。
- 搜索空间与每个数据集/方法的最优值见 Table 6–9（p.30–32）；FIRE 视觉默认 `iter=10`，其他 reset/regularization baseline 多数按给定网格选择。

### LLM continual pretraining

GPT-0.1B 先在 WikiText-103 预训练，再在 OpenWebText 与 WikiText-103 混合数据上继续训练；第二阶段分别从 best、30k、60k pretraining checkpoints 初始化，以检验更长预训练是否加重 plasticity loss。Appendix E.2 报告 3 seeds、nanoGPT 实现、AdamW、weight decay `1e−1`、`lr=6e−4`、minimum lr `6e−5`、warmup + linear decay、gradient clipping `1.0`、batch size `480`。第一阶段 warmup 为 2,000 steps，第二阶段 warmup 为该阶段迭代数的 10%。FIRE 固定 5 次迭代；S&P 针对三个 checkpoint 使用不同 λ（p.8 §4.2；p.28、p.33 §E.2/E.4）。

### Reinforcement learning

DQN 使用 standard Nature CNN，在 Atari 2600 的 Asterix、BeamRider、DemonAttack 上以 high Replay Ratio 设置测试；连续控制使用 SimBa + SAC，在 HumanoidBench 的 balance、walk、run 上测试。Baseline 为 full reset、S&P、Plasticity Injection。RL 报告 5 seeds，单次 intervention 位于训练中点。ALE Table 4 给出 Adam、`lr=6.25e−5`、replay buffer `10^6`、batch `32`、initial collect `20,000`、RR `1`、Huber Loss 等；HumanoidBench Table 5 给出 AdamW、`lr=1e−4`、weight decay `.01`、actor/critic hidden sizes `128/512`、RR `2`、replay buffer `10^6` 和 soft target `τ=.005`（p.9 §4.3；p.28–29 §E.3）。论文正文把 HumanoidBench 的一个引用写成 Mnih et al. (2015)，与前文采用的 Sferrazza et al. (2024) 不一致，本文按实验对象而非该处引用推断。

## 14. 最终判断

- **单一主线**：在假定可访问 past data 的 continual regime 中，把 reset 的稳定性—plasticity 两难写成「最小 SFE、DfI=0」的 Orthogonal Procrustes 投影，再用 NS 以低 reset 开销实现；Theorem 1 支持表征稳定性，上述 Theorem 2–4 为 DfI 提供 curvature/rank/activity 的理论联系，Figure 2–5 检验任务收益和 proxy。
- **正文保留的决策关键内容**：SFE/DfI 的定义、式 (4)–(5) 的核心优化、Algorithm 1、三领域任务覆盖、Figure 2–4 的主结果和 Figure 5 的机制/迭代消融。它足以判断方法的操作形态和适用实验范围。
- **移入 appendix 的细节及影响**：证明链、模块 scale、ViT Q/K 选择、baseline 应用部位、seed/优化器/超参/搜索空间、reset 开销与 train accuracy 全部在 appendix。对于理解主线影响有限，但对于复现、检查正交化可行性和判断计算主张，正文不够自足。
- **最有效的模式**：式 (4) 把模糊的 tradeoff 变成一个可解的几何目标；Figure 5(b) 以同一 reset 状态并列 curvature、DfI、normalized SFE，使机制叙述与性能曲线相邻；Figure 2 用三种 data-arrival protocol 检查 reset 后轨迹，而非只报单个终点。
- **最大叙事缺口**：理论假设很窄，实验只测 DfI/curvature/SFE proxy，未测 Theorem 3–4 直接涉及的 rank 和 dormant neurons；NS 系数在主文与附录不一致；“less than 1%”没有训练时间分母；结果主要依赖曲线和未定义误差带，缺少 seed-level numerical table 与统计检验。
- **可迁移规则**：当方法主张同时改变稳定性与 plasticity，应把一个可操作的 joint objective、一个能拆开两种效应的机制图、以及与理论 proxy 对齐的消融放在正文同一证据链中。
- **规则边界**：该规则适合有明确 reset/geometry intervention、可测 proxy 和多协议数据到达过程的 continual-learning 论文；若数据不可回访、模型含大量非矩阵状态或理论假设不满足，SFE/DfI 投影和对应闭环不能直接外推。
