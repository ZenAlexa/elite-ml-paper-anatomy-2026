## 方法与理论

### 最小逻辑单元

1. p.2 用 Generalized Functional ANOVA 的加性式 (1) 和 hierarchical orthogonality (2) 定义目标，再用 independent case 的 Möbius formula (3) 与 dividend Shapley formula (4)--(5) 规定需要回收的边界。
2. p.3 将 categorical support 放入 hypergrid `E`，以 truncated grids 和 index space `I` 完成计数；Definition 3.1 定义带 `p_A(X_A)` 分母的 inverse-likelihood basis。
3. p.4 的 Theorem 3.2 给出 Fourier expansion (8)、component aggregation (9) 和 hierarchical orthogonality。Corollary 3.4 把 uniqueness 限到 full support，Corollary 3.5 回收 independent ANOVA，Remark 3.6 回收 uniform Boolean parity。
4. p.4--5 用 Gram matrix `Γ`、moment vector `μ(f)` 和线性系统 `Γc(f)=μ(f)` 把系数计算化。Theorem 4.1 将 sparse support 的空间维数改写为 `r=|X|`，再选择一个 `r` 元 basis；因此稀疏时的表示依赖选定 support，而非全局唯一。
5. p.5--6 的 Algorithm 1 按 canonical order 做 rank check，优先 main effects 和低阶 interaction。低 rank 截断以 `r_low<r` 停止，并给出最坏 `O(|E| r²)` 与截断后的 `O(|E| r_low²)`。

方法段落的动作序列为：`setup_notation → state_problem → define_component → derive → explain_mechanism → state_complexity → instantiate_algorithm → contrast_alternative → connect_to_experiment`。主文有 23 个带编号公式 `(1)`--`(23)`，Definition 3.1 另有一个未编号 basis 公式；附录有 `(24)`--`(56)` 共 33 个带编号公式。主文的形式结果为 Theorem 3.2、Theorem 4.1、Proposition 3.10、Corollaries 3.4--3.5 和 4.2；Appendix A 提供 Lemmas A.1--A.3 及其余证明。理论承担核心因果链功能，串联 basis construction、orthogonality / spanning、coefficient solve 与 rank-selected sparse computation。

### 算法与可视化承担的工作

- Algorithm 1（p.6）输入 distribution `D`，输出 size-`r` functional basis `B`。循环逐个 test candidate vector 是否提高 rank；关键不变量是已选 `B` 的 rank 单调增加且不超过 `r`。主文解释到 candidate order、低 rank 截断和复杂度层级，没有列出数值线性代数容差或实现伪代码细节。
- Figure 1（p.3）为 Binarized MNIST 的局部解释示例，原图、带符号 attribution、绝对 attribution 并置。它提前展示最终解释产物，定量性能与模型配置则留在第 9 页和 Appendix B。

## 用词与修辞

高频实词由领域名词驱动：`decomposition`、`functional`、`ANOVA`、`support`、`basis`、`categorical`、`Shapley`、`rank`、`sparse`。核心二元组合包括 `functional ANOVA`、`closed-form formulation`、`hierarchical orthogonality`、`full support`、`main effects`、`low-rank approximation`。三元组合包括 `Generalized Functional ANOVA`、`arbitrary dependence structures`、`categorical input setting`。

主张动词主要是 `introduce`、`derive`、`recover`、`compute`、`demonstrate`、`confirm`，限定词包括 `exact`、`generalized`、`arbitrary`、`full`、`sparse`、`low-rank`。对比词多由 `however`、`while`、`consequently`、`furthermore` 连接。`We introduce` 位于 p.2 contribution list 和 p.3 Definition 3.1 前的段落；`We demonstrate` 位于 p.2 contribution list；`we show` 主要用于 theorem/proof 段落；`we observe` 出现在 Figure 1 caption。强主张集中在 abstract、contribution list、theorem statements 和 conclusion，弱化语气集中在低 rank 实验与 limitations。高频不是模板堆叠，主力来自一个持续反复的机制链：support、basis、rank 与 decomposition。

## 最终判断

**单一主线。** 为 categorical support 构造 inverse-likelihood Fourier family，使其满足 hierarchical orthogonality；以 Gram system 求系数，并在 sparse support 选择低阶优先的满秩 basis，从而把 generalized functional ANOVA 与可计算的 SHAP-style attribution 接起来（pp.3--6）。

**正文保留的决策内容。** 主文保留定义、Theorem 3.2、uniqueness 条件、Algorithm 1、复杂度、独立 SHAP 对照、高维 rank trade-off 和两种限制。这个顺序使读者在看数据前已知道每个实验需要验证哪一个理论边界。

**附录迁移是否损害自足性。** 证明、architecture、hardware 和 TreeHFD validation 都在附录。主文足以理解方法、最重要结果和限制；要审计 formal proof、实现参数或 TreeHFD 条件时必须读附录。supplementary code 缺失使可运行复现无法在这份输入中闭合。

**最有效的模式。** 先用最近邻方法的假设失败建立需求，再让一个 basis definition 同时解释 orthogonality、independent recovery、sparse rank selection 和实验指标。Table 6--7 将同一 `rank` 参数同时显示为解释容量、误差和运行时，因而把性能边界放进主论证。

**最大缺口与读者成本。** sparse regime 的 representation non-uniqueness 被诚实说明，却没有定义何为最有意义的 `S_r`；rank search 又是高维成本瓶颈。实验缺少 seeds、不确定性和 code artifact，读者很难判断数字对训练与样本扰动的稳定性。

**可迁移规则。** 理论型解释论文应让每个实验对应一个形式化承诺：构造先定义对象，定理给出可验证性质，实验再在独立、依赖、稀疏和计算边界上分别测试。

**适用边界。** 这条规则适用于有清晰 mathematical object、可写出假设与可观测后果的工作。若任务的核心是用户偏好、开放式生成或无法定义 ground truth 的部署效果，实验需要另设识别设计，不能只依靠 reconstruction 与内部 consistency 指标。
