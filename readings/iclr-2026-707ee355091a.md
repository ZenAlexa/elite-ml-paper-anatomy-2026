## 1. 单一主线

论文的核心断点位于 data-sized dual optimization。作者从 exact penalized least-squares objective 出发，用 stationarity 与 Mercer expansion 得到 data-dependent equivalent kernels；每个 triggering-kernel estimator 的 dual coefficients 全部解析固定为 1。随后，degenerate/random feature map 把 simultaneous Fredholm equations 化为一个 `MU × MU` linear solve，计算状态由 event-count-sized coefficients 转为 feature/dimension-sized matrix。〔p.3｜§2.2, Theorem 1｜“dual coefficients are equal to unity”｜explicit；p.5｜Proposition 4｜“obtained in closed form”｜explicit〕

这条主线同时承担理论与工程两项承诺：Theorem 1 解释 dual optimization 为什么可以消失；Propositions 2–4 给出可执行 closed form；Section 2.4 再把状态空间变化翻译成 `O(N²M²U² + M³U³)` time 与 `O(M²U²)` memory。主实验最终用 accuracy 与 CPU time 的并列表格验证该变化的实际后果。〔p.3｜Theorem 1｜Eq. (5)–(6)｜explicit；p.6｜§2.4｜“O(N 2 M 2 U 2 + M 3 U 3)”｜explicit；p.8｜Table 1｜layout_observation〕

## 6. 方法与理论

### 6.1 形式化对象与输入输出

- 对象：`U`-dimensional linear Hawkes process，`λ_i(t)=μ_i+Σ_j∫g_ij(t-s)dN_j(s)`；`g_ij∈H_k`。〔p.2｜§2.1｜Eq. (1)｜explicit〕
- 输入：typed event sequence `{(t_n,u_n)}`、support `A`、kernel `k`、regularizer `γ`，实现阶段再给 `M` 与 Fourier feature parameters。〔pp.2–5｜§2.1–2.3｜Eq. (1), (13), (18)｜explicit〕
- 输出：closed-form `μ̂_i` 与 function-valued `ĝ_ij(s)`。〔p.5｜Proposition 4｜Eq. (17)｜explicit〕
- Objective：exact `L_LS(g,μ) + γ^{-1}Σ||g_ij||²_Hk`；finite support window `A` 限制历史贡献。〔p.3｜§2.2｜Eq. (3)–(4)｜explicit〕
- 核心假设：PSD kernel on compact one-dimensional `T`、`γ>0`；analytic implementation 进一步要求 shift-invariant kernel。〔p.3｜§2.2｜“positive semi-definite kernel”｜explicit；p.5｜§2.3｜“assume that RKHS kernels are shift-invariant”｜explicit〕

### 7.2 指标、选参与匹配条件

Synthetic 以 integrated squared error `Δ²` 衡量 `g_ij` estimation，以 `cpu` 衡量 fitting time。Gau/Ber/Bonnet 在 `[0.8T,T]` 用 nll 选参；Ours 用 `L_LS`；训练在 `[0,0.8T]`。common synthetic grid 为 `γ∈{0.1,0.5,1.0}`、`β∈{0.5,1.0,1.5}`。〔p.7｜§4.1｜Eq. (23)；“fitted with the events in [0, 0.8T]”｜explicit〕

## 13. 最终判断

1. **单一主线**：exact `L_LS` 的一阶条件诱导 equivalent-kernel representation，unit dual coefficients 删除 data-sized optimization，random features 将其落为 feature-sized linear solve。〔p.3｜Thm.1｜explicit；p.5｜Prop.4｜explicit〕
2. **正文保留的决策关键内容**：objective、theorem statement/proof sketch、closed form、complexity、accuracy/runtime tables、clipping 与 learning-guarantee boundary。〔pp.3–10｜Eq. (3)–(20), Tables 1–4, Limitations｜layout_observation〕
3. **附录迁移与自足性**：完整 proofs、existence、高 N/U evidence 与 negative solver result 入附录；正文足以理解与实现主 estimator，无法独立审计 theorem rigor 或高维适用边界。〔pp.15–23｜Appendix B–H｜layout_observation〕
4. **最有效模式**：`Theorem 1 unit coefficients → Proposition 4 MU×MU solve → Tables 1–2 accuracy/runtime tradeoff`。机制、复杂度与 evidence 对齐。〔p.3｜Thm.1｜explicit；p.5｜Prop.4｜explicit；pp.8–9｜Tables 1–2｜explicit〕
5. **最大 gap**：learning guarantees 明确开放；实证范围还受单一 financial dataset、固定 `M=100`、缺 seeds、Ber outlier denominator 不明限制。H.4 的 T confounding 使 mechanism relation 只能部分闭合。〔p.10｜Limitations｜explicit；p.9｜§4.1.2｜explicit；p.23｜§H.4｜interpretation〕
6. **可迁移规则**：表示定理若改变 optimization dimension，正文应连续交代被消除的状态、可执行 closed form、复杂度依赖与同一 baselines 下的 accuracy–runtime tradeoff；proof 与 scaling extensions再入附录。〔pp.3–8｜Thm.1 → Prop.4 → Table 1｜interpretation〕
7. **规则边界**：该模式适合 theorem 直接改变算法状态空间的论文。若核心主张是 finite-sample efficacy、robustness 或 deployment safety，algebraic closure 与 runtime tables 无法替代相应 evidence。〔p.10｜Limitations｜“learning guarantees … beyond the scope”｜interpretation〕
