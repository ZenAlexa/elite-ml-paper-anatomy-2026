## 方法、理论与公式链

### 单一因果链

论文把 RoPE 的 `mθ_j` 视为以 `β=b^(1/D_r)` 为基数的、带偏差的位值编码。训练长度内未满一个旋转周期的高维对应高位未完成进位。对每个维度设置 `λ_j` 后，混合进制展开延长旋转周期。YaRN 被写成中间维的 regressive 转换；MrRoPE-Uni 固定中间维转换率；MrRoPE-Pro 令中间维转换率逐步上升。论文预期 progressive 策略保留低维高频细节，并用 PPL、检索、bound root 和中间维 attention 图回收该预期。

输入是 RoPE 模型的 token 位置 `m`、隐藏维度集合 `D`、原 base `b`、目标扩窗倍数 `S` 与维度边界 `d_l,d_h`。输出是经 `λ` 修改的旋转角 `mθ'_j`，再得到 query/key 旋转。论文没有训练目标函数、伪代码、算法框、循环层级或显式时间／空间复杂度陈述。实现只说沿用 YaRN 的 `d_l,d_h` 与 rescaling trick，细节见 Appendix B。

### 理论命题与证据边界

1. **RoPE 是 biased `β`-radix encoding。** Eq. (4)–(7) 给出相似项与 `m̂`，Fig. 2 展示不同 base 下的近线性趋势。前提包含暂时忽略 floor 与 modulo period 后再重引入，结论是解释性映射，缺少形式定理标签。证据在 p. 3, §2.2, `“biased β-radix encoding”`。
2. **Eq. (10) 统一符合该式的 RoPE extension。** `λ={λ_1,…,λ_Dr}` 是统一对象，Eq. (11)–(12) 映射 NTK、YaRN。Appendix A.1 同时指出 PI 无法写成 Eq. (16) 的 base-conversion 形式，因此“various” 的统一范围需要读作 Eq. (10) 适用类加上 PI 的解释性位置归一化。证据在 p. 4, §3.1, `“conforming to Eq. 10”` 与 p. 12, A.1, `“cannot be expressed”`。
3. **YaRN 的中间维转换是 regressive。** A.2.1 由 Eq. (21)–(25) 得出 `λ_j/λ_{j-1}≤1`，p. 14 在 `b≠1` 条件下给出严格 `λ_{j-1}>λ_j`。这是文中最接近证明的对象，证明位置完整，依赖 YaRN 的计算式与 base 条件。证据在 p. 13–14, A.2.1, `“λ_{j-1}>λ_j”`。
4. **MrRoPE-Pro 提高 RoPE Bound Theory 预测的上界。** p. 9 以 `B_θ(m)=Σ cos(mθ_j)` 的 root 计算，报告 base 10,000 时 1K 到 28K，对照 YaRN 6K。它是固定设置下的数值诊断，不是把 bound 转成 retrieval 能力的证明。证据在 p. 9, §4.4, `“from 1K to 28K”`。
5. **中间维 attention 更稳定。** Fig. 6 每个相对位置随机选 50 对 token，展示两种模型下的点云与趋势。图没有误差带、分布汇总或检验，机制解释因此由可视化支持，识别力度有限。证据在 p. 9, §4.4, `“randomly selected 50 token pairs”`。

方法段的动作转移为 `state_problem → derive → define_component → contrast_alternative → state_problem → define_component → define_component → summarize → instantiate_algorithm → connect_to_experiment`。Fig. 3 以维度索引为横轴、cumulative scaling `s_d` 为纵轴，把 YaRN、Uni、Pro 和 NTK 的 `λ` 行为置于两个基模型的同一视觉坐标，承担从式到可比较设计的连接。

## 实验设计、结果与统计表达

### 设计与复现粒度

- 全部比较设为 inference-only、no fine-tuning；基线是 YaRN 与 NTK。需要训练的方法被排除，p. 6, §4.1, `“no comparisons were conducted”`。
- 基模型为 LLaMA2-7B、LLaMA3-8B、Qwen2.5-3B；评测序列是 Proofpile PPL、NIAH、RULER、Infinite-Bench、LongBench-V2，外加 bound 与 attention 分析。证据在 p. 6, §4.1, `“three aspects”`。
- PPL 使用 Proofpile 中 10 条随机抽取且超过 128K tokens 的序列，float32；Table 1 的 LLaMA2 补充结果转移到 Appendix C.1。证据在 p. 6–7, §4.2, `“ten randomly sampled sequences”`。
- NIAH 只比较 LLaMA3-8B 的 Pro 与 YaRN，改变 context length 和 insertion depth，以 ROUGE-1 测 retrieval recall。RULER 汇报 13 个 subtask；Infinite-Bench 每 subset 随机选 100 个、长度 100K–128K 的样本。证据在 p. 8, §4.3, `“100 samples per subset”`。
- LongBench-V2 将测试样本限制在 128K 以下；表格放入 Appendix C.2。证据在 p. 15, C.2, `“less than 128K”`。
- PDF 中未报告 random seed 数、重复次数、硬件、运行时间、训练预算或误差计算。p. 10 说配置与 hyperparameters 在 Appendix，实际 Appendix B 只展开 `α,β,d_l,d_h,t` 与敏感性图；匿名 supplementary 代码未随本地语料提供。这是读取版本的可复现边界，不能从 PDF 补写缺失细节。

实验顺序与 §4.1 的承诺一致：PPL → retrieval stress → 实际任务 → mechanism diagnostics。它也回收了引言的三层逻辑，但 MrRoPE-Uni 在 Table 1 后不再进入后续 benchmark，覆盖范围随之缩小。

## 消融、负面信息与局限

`MrRoPE-Uni` 对 `MrRoPE-Pro` 的 PPL 对照是策略级消融：两者共享分段思路，区别在中间维 `λ` 的常数或 progressive 安排。Appendix B.1 是超参数／尺度敏感性检验，考察 `d_l,d_h` 和对应 `α,β`。论文没有组件删除消融、失败案例清单或计算成本测量。

后续 benchmark 只保留 Pro 与 YaRN，p. 7 明说 `“mainly focus on MrRoPE-Pro and YaRN”`，并将原因归于 Uni 的较弱长上下文表现。这是透明的模型选择，同时意味着 NIAH、RULER、Infinite-Bench 与 attention 分析不能比较三种转换策略。训练型 extension 也因 inference-only 设计被排除，p. 6, §4.1, `“no comparisons were conducted”`。

自我设限出现在 Appendix E 的最后一页，摘要、引言和结论均未单列此段。第一段编码为 `scope`／`baseline`，内容是未做 fine-tuning，因而无法直接对比 xPOS、LongRoPE 等训练设定方法。第二段编码为 `generality`，内容是 radix-transformation 与 RoPE 绑定，对 T5 relative bias、ALiBi 的迁移仍是开放问题。版面位置是可核对事实，不推断作者把限制后置的意图。

## 用词与修辞

正文 p. 1–9 的原始文本上下文审计显示，`MrRoPE`、`RoPE`、`radix`、`context`、`dimension`、`method` 是高频领域名词，驱动对象、机制和实验三条线。`progressive`、`training-free`、`unified` 将产品名与贡献动作绑定。`based on` 多用于由理论导入方法或由实验导入解释，`however` 用于 PI／YaRN 的不足和结果段反差。

精确短语检索共找到 `we propose` 2 次，位于摘要与结论；`we identify` 2 次，均在引言的问题设定；`we find` 1 次，在 §3.2 的 YaRN 回归观察；`we demonstrate` 1 次，在 §4.4 的分析承诺；`we show` 在主文没有精确出现。强断言主要落在结果小标题与结论，机制段保留 `conjecture`、`may`、`should` 等限定。按 24 句人工编码的主张句计，16 句使用能力或比较性断言，8 句保留条件或推测，约为两比一。计数用于语境分析，聚合器的标准 token 统计应以其统一脚本为准。

修辞的有效部分是反复回收同一对象：`λ` 在 Fig. 1、Eq. (10)、Eq. (13)–(16) 与 Fig. 3 之间连续出现。读者成本来自符号重载、证明放入附录、理论上界与任务表现之间的未量化桥接，以及后续实验放弃 Uni 后的比较范围收窄。

最强的单一主线是：用混合进制将 RoPE 位置频率的未完整循环问题转化为维度级 radix allocation，再以 progressive `λ` 配置恢复高频细节与增加可编码范围。最有效的写作模式是用 Fig. 1 建立统一视觉语言，再用 Eq. (10)、Eq. (13)–(16)、Fig. 3 将语言落实为可比较的三类策略，最后以任务表和机制图回收。

最大的缺口有三层。第一，PI 被附录承认为不符合该 base-conversion 形式，统一主张需要限定。第二，bound root 与 attention 图是机制诊断，未给出从该诊断到 end-task 结果的形式桥梁。第三，Table 1 的 Qwen2.5 32K 数值和 Table 5 的模型标注分别与附近文本冲突，削弱了“全长度一致最优”及追加结果的可读性。

可迁移规则是：让每一个新参数化同时具有机制图、简洁定义、最近邻基线的可审计推导与覆盖相同任务条件的对照。该规则适用于可把差异压缩到一个共享参数对象的论文；当方法差异跨训练数据、架构、优化和评测协议时，单一参数图不足以承担因果解释。
