## 4. 相关工作如何定位

- §5 是独立章节，占正文约 7%，由四个按**方法族**命名的段落组成，属于 taxonomy 而非 chronology。 [p. 9, §5; `layout_observation`; “Wasserstein Gradient Flows”]
- **Wasserstein Lagrangian and Hamiltonian Flows**：承认 Ambrosio & Gangbo、Chow 的数学基础及 Neklyudov et al. 的 observational inference；最近邻差异是既有 Lagrangian/action minimization 要 reference process，而 WLM 从 damped Lagrangian 导出 mechanics，进而 forecast。 [p. 9, §5; `explicit`; “requires a reference process”]
- **Wasserstein Gradient Flows**：把自身放在同一 Wasserstein space 的更丰富 second-order 类中，并以 §4 的 gradient-flow benchmark 连接性能比较。 [p. 9, §5; `explicit`; “richer class of second-order dynamics”]
- **Reference-based Population Dynamics**：按有 single/family reference process 的方法群分组，比较维度为对 model misspecification 的暴露；文本称 WLM 不属于 reference-based。 [p. 9, §5; `explicit`; “less susceptible to model misspecification”]
- **Flow and Action Matching**：按 finite marginals 上 continuous interpolation 的目标分组，最近邻差异是作者称这些模型只能在 observation period 内 interpolate。 [p. 9, §5; `explicit`; “unable to forecast”]

相关工作避免复述 §3 的网络与训练细节，主要使用「任务/先验/forecast ability」三维短对比。引用随后在 §3 作为 action-minimization 前置工作、在 §4 作为 baselines 和复现实验来源再次承担论证作用。 [p. 5, §3; `explicit`; “Neklyudov et al., 2023b”; pp. 6–7, §4; `explicit`; “previous works”]

## 5. 方法与理论闭环

### 5.1 形式对象、推导与逻辑单元

1. **canonical coordinates**：在绝对连续 `P_2(R^d)` 曲线假设下，Proposition 2.1 用 `ρ̇_t=-∇·(ρ_t∇s_t)` 表示 marginal dynamics，令 `ρ_t` 为 position、`∇s_t` 为 tangent vector。这个假设把路径律的不唯一性暂时压缩为 canonical representation。 [pp. 2–3, §2.1 / Prop. 2.1; `explicit`; “absolutely continuous in P2”]
2. **least action setup**：将 `L[ρ_t,s_t]=K[ρ_t,s_t]-U[ρ_t]`，并在观测 marginals 约束下最小化 `S=∫Ldt`；`U` 可为 entropy、interaction kernels、expectations 等 density functional。 [p. 3, §2.2 / eqs. (2)–(4); `explicit`; “potential energy U[ρt]”]
3. **damped Hamiltonian mechanics**：Theorem 2.2 对 `e^{γt}` 加权的 Lagrangian 推得 `ṡ_t` 方程与 particle 的 second-order equations (7)–(8)，其中 acceleration 由 `δU/δρ_t` 和 `-γv_t` 决定；完整变分推导移至 Appendix A。 [p. 3, §2.3 / Theorem 2.2; `explicit`; “damped Wasserstein Lagrangian”]
4. scope test。Proposition 2.3 以线性 density expectation 恢复 Newtonian mechanics；文本把 Fisher-information 项指向 Schrödinger equation。Proposition 2.4 给 gradient flow 两种 WLM 描述，包括 overdamped `γ→∞` 的稳定极限，以及要求精确初速的 conservative inverted-potential 表示。 [p. 4, §2.4 / Props. 2.3–2.4; `explicit`; “stable characterization”, “unstable characterization”]
5. **可学习的 particle energy**：§3 不拟合未知 functional derivative；Proposition 3.1 将 empirical measure 的 potential energy `Ψ(x^(1),…,x^(N))` 对单粒子的梯度等同于 `1/N` 倍 functional derivative 的空间梯度。 [p. 5, §3 / Prop. 3.1; `explicit`; “tractable characterization”]
6. 训练闭环。用 deep network `Ψ_θ∈R^(N×d)→R` 和 autodiff 构造 acceleration (10)，从 `p̂_0,v̂_0` 用 Leapfrog rollout，用 observed/simulated marginals 的 divergence（例：Sinkhorn）作为损失，并穿过离散轨迹反向传播。 [p. 5, §3 / eq. (10); `explicit`; “Discretize-Then-Optimize approach”]

**段落动作转移**：`setup_notation → define_component → derive → explain_mechanism → contrast_alternative → state_problem → define_component → instantiate_algorithm → connect_to_experiment`。§2 解决「何种机制可表达」；§3 对应引言第二问，给出「未知 Lagrangian 时如何从 snapshots 学」的可计算替代。 [pp. 2–5, §§2–3; `interpretation`; “we therefore consider the Hamiltonian perspective”]

## 12. 最终判断

1. **单一主线**：从 snapshots 推断 dynamics 时，作者将核心对象从指定的 reference process 或 first-order free-energy descent 改为可学习的 population-level mechanics；damped least action 导出参数化 energy 的 second-order rollout，随后以 GF、ocean、cell、Boids 依次验证覆盖和预测能力。 [pp. 1–9, Abstract / §§1–4; `interpretation`; “learning the population mechanics”]
2. **正文保留的决策内容**：读者在正文即可得到问题、(1)–(10)、Theorem 2.2/Propositions、训练伪代码、`W_1` protocol、四个 headline tables 与 Figure 4–5；这些对象足以判断方法接口和主要 empirical trade-off。 [pp. 3–8, §§2–4; `layout_observation`; “Algorithm 1”, “Table 4”]
3. **向附录迁移的细节及影响**：proofs、exact potentials、architecture/hyperparameters、hardware/runtime、per-SDE numbers、DICE implementation exception、batch-size 与 initial-velocity sensitivity、unseen-population qualitative results 均在 Appendix。迁移没有切断正文的结论读法，却使理论有效性和复现判断必须跨页读取。 [pp. 13–22, Appendices A–C; `interpretation`; “Additional Proofs”, “Additional Experiment Details”]
4. **最有效的模式**：用 Figure 1–2 将抽象 functional 语言转换为 visible geometry，再用 Theorem 2.2 → Proposition 3.1 → Algorithm 1 串成可训练方法，最后以由简单到难的四组 benchmark 让 forecast 能力有专门表格。这个模式把概念、mechanism 与 observable `W_1` 接在同一链上。 [pp. 1–8, Figs. 1–5 / §§2–4; `interpretation`; “Hamiltonian equations of motion”]
