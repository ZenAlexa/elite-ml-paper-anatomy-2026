## 5. 方法、组合机制与理论

### 5.1 逻辑单元与动作序列

动作序列为：

`setup_notation → state_problem → define_component → derive → define_component → explain_mechanism → derive → connect_to_experiment`。

1. **CIL 与 Slot Attention setup**（p. 4，§3）：输入为顺序且标签互斥的 (D_1,\ldots,D_T)，backbone `f(·|θf)` 产生 `[CLS]` feature 和 patch feature `E`；slot module 把 `E` 分解为 `K` 个 slot `S` 和 mask `A`。这是以后续 plugin 共用 ViT semantic patch feature 的接口。
2. **全局共享约束**（pp. 4–5，§4）：slot attention 和 primitive selection 在首任务初始化、跨任务微调；架构大小固定。作者把这与避免 parameter explosion 和长任务序列相连。
3. **Concept learning**（p. 5，§4.1）：位置增强后的 slot 经 MLP decoder 重构 patch feature，Equation (1) 定义 `Lre`。它对应「不依赖分割/语言概念标签而提取 slot」。
4. **Primitive selection**（p. 5，§4.1）：`LN → Linear → tanh` 映射 slot，以对 learnable key `Kp` 的 softmax 权重 `wp` 聚合成 `sp`，见 Equation (2)。它解决背景 slot 会稀释类相关概念的问题。
5. **Primitive consistency**（p. 6，§4.1）：由 one-hot label 相似度与 `sp` 相似度构造 KL 型 `Lp`，见 Equation (3)，并与 `Lre` 合成 `Lslot`。它的机制目标是同类 primitive 接近、异类远离。
6. **Method-agnostic distillation**（p. 7，§4.2）：对 batch 内 `sp` 相似度和当前任务 logits 相似度做 `La`，Equation (4)；训练损失为 `Ltr=Lce+βLa`。它只假定 learner 有 FM backbone 和 logits，因此能放进文中列出的多类 CL 方法。
7. **可执行化**（Appendix F，pp. 21–22）：Algorithm 1 将每个任务拆成 `E` epoch 的 concept learning 再 `E` epoch 的 distillation；Algorithm 2 明确 `E`、slot、重构、`wp`、`Lp` 的数据流。两阶段顺序也构成后文限制。

### 5.4 Algorithm、复杂度与机制边界

- Algorithm 1/2 给出输入、输出、双层循环和两个短事务：每个任务先更新 slot/selection，再冻结该阶段的 primitive 梯度去训练 CL learner。关键不变量是 primitive statistics 在 concept-learning 阶段产生，在 distillation 阶段只提供监督；算法没有给出大 O 复杂度。
- Appendix D 的 Remark 5（p. 20）说明 Hungarian matching 用于评价/可视化，但不纳入 distillation，理由是计算开销；attention 聚合被声称满足 slot-order permutation invariance。
- 计算证据在 Appendix H.8（p. 33）：slot-only 训练 5.5 h，FOSTER 为 9.1 h，FOSTER† 为 10.1 h。它支持一个 FOSTER/CGQA 实例的增量时间，不能推出任意 baseline 的统一成本。

### 主要结果、统计与不利解释

1. **CGQA 主结果**（p. 8，Table 1）。ADAM+adapter 的 `AA` 从 `41.930±1.141` 到 `49.480±1.201`，作者标为最大绝对增益 `+7.550`。所有方法的 `AA` 变高；但 CPrompt 的 `FF` 从 `15.670±0.950` 到 `18.315±1.111`、EASE 的 `FF` 从 `18.215±0.107` 到 `22.470±2.472`、FOSTER 的 `FF` 从 `2.441±0.122` 到 `6.470±5.770`，并非每个指标都改善。作者在 p. 8 解释 CPrompt/FOSTER 的例外为原方法在已完成任务上表现差、因而「forget less」；表中没有对这个解释的单独检验。
2. **机制与长任务**（pp. 9–10，Figures 3–4）。Figure 3 以 5-5 task 柱状对照支撑全局共享 slot 的长序列说法；Figure 4 对 30 个 T0 图像的 sample similarity 作了可视化。两者不报告图内不确定性，后者只显示一个代表性 sample set。
3. **COBJ**（p. 30，Table 7）。ADAM+adapter `AA=45.750±0.346 → 50.150±0.249`、`Hn=57.793±1.388 → 61.581±1.399`；CoFiMA 的 `AA` 仅 `+0.105`、`CA` 和 `Hn` 下降，说明「全部指标均提高」不成立。
4. **ImageNet-R**（p. 31，Table 8）。5 个 baseline 的 `AA` 都高于对应 vanilla，例如 FOSTER `76.001±0.243 → 78.950±0.201`；CPrompt 的 `CA` 从 `81.460±0.930` 降到 `79.964±1.078`，RanPAC/FOSTER/MEMO 的 `FF` 有恶化。表中没有正式 hypothesis test。
5. **模型与概念方法扩展**（p. 31，Tables 9–10）。RanPAC + CompSLOT 在 ViT-B16-SAM† 的 `AA/Hn` 为 `67.30/81.22`；CUB200/CIFAR100 上 CompSLOT 的 `AA` 为 `88.38/89.57`，高于表列 SACK/CLG-CBM。p. 18 明示后一个比较不能做到完美公平：CLG-CBM 用外部 LLM，CompSLOT 为 slot extraction 改用 CLIP ViT-B/16。

### 明示限制与信息呈现

- **两阶段边界**（p. 10 §6）。论文明确要求 concept learning 先于向 CL task 提供 conceptual self-supervision；end-to-end integration 仍是未来工作。限定编码为 `deployment` / `compute`。
- **交互边界**（p. 10 §6）。同其他操纵 logits 的 regularization 联合使用的效果尚待研究。限定编码为 `causality` / `generality`。
- **属性变换边界**（p. 26 §H.1）。substitutivity 没有显著改进，论文将其联系到 ViT feature extractor 对 color 等 attribute shifting 的限制。限定编码为 `generality`。
- **概念共享条件**（pp. 18、23–25）。真实复杂图像与细粒度类被用来说明 concept sharing；CIFAR 类别间的 sharing 被描述为视觉上罕见。限定编码为 `data` / `scope`。
- **公平性**（p. 18）。Table 10 的 external LLM 与 CLIP extraction backbone 使完美公平无法达成。限定编码为 `baseline`。
- **复现与统计缺口**（pp. 8、20）。论文报告 3 trials 和 confidence intervals，但全文未给 random seeds、CI construction、code revision、正式检验、多重比较或 failure criterion。缺失项均标为 `not_present`，不推断作者是否执行。限定编码为 `reproducibility` / `metric`。

可核实的呈现策略有两项。第一，p. 9 以 “Due to page limit” 将六个 concept/slot 指标及其实验移到 H.2；这属于 `appendix_migration`，主文 Figure 4 因而只承载代表性视觉机制。第二，p. 10 将唯一直接限制紧接结论并表述为未来 end-to-end 工作；这是 `future_work` 化，但限制本身被明确陈述。与其相反，p. 8 对 CPrompt/FOSTER 的 forgetting 例外进行了正面文字说明，不能据现有版面认定为隐藏不利结果。

## 12. 最终判断

1. **单一主线**：用 ViT patch feature 的 Slot Attention 抽取并选择 primitive，把 batch 内的低维 concept similarity 蒸馏到 CL logits；作者将这种关系约束视为减少错误/不完整概念依赖，从而同时改善组合泛化与 continual accuracy 的原因。
2. **主文保留的决策关键内容**：Figure 1、Equation (1)–(4)、Table 1、Table 2、Figure 4，以及两阶段限制。它们足以让读者判断提案、主 benchmark 和一个主要替代解释。
3. **附录迁移的后果**：proof、algorithm、hyperparameters、六个对齐/稳定性指标、扩展 benchmark 与 efficiency 全部后移。主文因而紧凑；概念对齐的量化和跨设置稳健性无法仅靠主文独立核验。
4. **最有效的组织模式**：流程图先固定接口，再以编号损失连接设计；主结果表给出多 baseline paired rows，随后以 component table 和 similarity visualization 回到机制。这条 `diagram → formulation → paired result → ablation → mechanism image` 链条可扫读。
5. **最大缺口**：从 `primitive/logit` 相似度图和 `Hn/R` 的改善推到「概念机制造成 accuracy 增益」仍是部分闭环。理论结果是定义前提下的集合陈述；它没有给出训练收敛、slot 真正 disentangle 或跨任务提升的保证。部分 `FF/Hn/CA` 也出现反向变化。
6. **可迁移规则**：若论文把 plugin 的机制作为性能原因，主文至少应并列给出成对 outcome、组件对照、直接机制观测，并明确观测样本范围；附录再放完整参数和扩展证据。
7. **规则边界**：在缺少可观测 concept sharing、只有代表性可视化、或理论前提无法测量时，机制结论应保持为解释性证据，不能写成普遍保证。
