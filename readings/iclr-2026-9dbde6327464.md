## 5. 方法、理论与逻辑单元

## 6. 实验设计

### 6.1 研究问题与变量

§4 明示三个 RQ。RQ1 是 PRISM 在 image reconstruction 上的表现，RQ2 是 latent-space choice 的影响，RQ3 是每个组件的贡献（p.6, §4）。实验顺序与 RQ 对齐：Table 2/3 回应 RQ1，Table 4 与 Table 7 回应 RQ2，Table 5 与 Table 8/9 回应 RQ3/机制稳健性。§4 没有预注册 hypothesis，也没有明确 failure threshold。

### 8.2 设限位置与限定方式

- `scope`：实验只在 NSD、BOLD5000、GOD 三个公开数据集上验证，且 m=2 是默认对象数（p.6、p.18、p.21）。
- `assumption`：位置标签来自预定义 `left/right` 或 `top/bottom` 集合；prompt 明确禁止混用水平/垂直标签（p.21、p.23）。
- `data`：keyword search 为效率从 NSD training 随机抽 667 张，而非全量训练集（p.22）。
- `metric`：主结果以 PixCorr、SSIM、LPIPS、CLIP、Inception V3 与 Qwen2.5 QA 为代理；没有 human perceptual study（p.6–8）。
- `baseline`：SDXL 只与 PRISM/Mindeye2 比较，其他基线使用 SD2.1 适配版（p.6–7）。
- `generality`：正文称趋势可泛化到其他数据集，但仅附录 Table 7 给出 BOLD5000/GOD latent-space 数值，未把所有组件消融扩展到三集（p.8、p.20）。
- `causality`：ROI 解释用 token gradients 和 mean voxel intensity，作者自己写明还需 neuroscience validation；该分析关联而非因果干预（p.9）。
- `compute`：没有独立计算成本/推理时延表；只给出两张 L40、epoch 和 denoising-step 参数（p.19）。
- `deployment`：代码 URL 出现在摘要，但 §8 写“Upon acceptance, we will release our code”，可获得性时点没有统一说明（p.1、p.11）。
- `ethics`：伦理声明称不涉及 human/animal subjects、PII 或 sensitive information，数据公开并遵循 license，未见可预见 misuse/discrimination/harm（p.11）。

## 12. 最终判断

1. **单一主线。** 论文把 fMRI-to-image 的第一个瓶颈定义为 latent alignment、第二个瓶颈定义为 object/attribute binding；先用 CKA/CCA/Generalization Gap 选择 LM text，再用 object-centric descriptions、位置拼接和 keyword search 使 text bridge 具有 compositional structure（p.3–6）。
2. **正文保留的决策关键内容。** 正文给出 RQ1–RQ3、三数据集/五指标、Table 1–5、Table 6、Eq. (1)–(7)、negative-prompt 公平性说明和组件消融，因此主要选择可以沿着“alignment→modules→performance”复核（p.4–10）。
3. **附录迁移及其影响。** 附录补全 latent diffusion 基础、dataset counts、baseline adaptation、training schedules、Algorithm 1、跨数据集 latent ablation、object-count/failure cases、prompt templates 和 LLM declaration；方法概念仍可读，但复现与 generality 依赖附录，且 seeds/participants/完整 optimizer 未补足（p.17–25）。
4. **最有效模式。** Figure 1 把“生成结构化描述、fMRI-to-text、object-wise cross-attention、空间拼接”画成一条可追踪链；Table 1 的三指标一致方向与 Table 5 的删除对照分别支持空间选择和机制必要性（p.3–5、p.8）。
5. **最大叙事缺口。** “significantly” 的 QA 主张没有检验细节；text alone 捕获 high/low-level 的解释没有分解实验；Spatial Layout 的 ROI 解释明确需要外部神经科学验证；m=2、667-image search、SDXL 覆盖范围和 Table 2/5/8 的 LPIPS 离散量差异限制了闭环强度（p.7–9、p.21–22）。
6. **可迁移规则。** 若核心贡献是“中间表示选择 + 结构化生成”，正文应把表示选择的可比性、模块删除、跨数据集复核和不利案例安排在同一因果链上，并在主结果表旁明确聚合单位与不确定性来源；附录可以放实现细节，但不能把关键 RQ 的唯一数值证据全部移走（p.4、p.7–8、p.20）。
7. **适用边界。** 该规则适用于有中间表示和多模块生成管线的解码/生成论文；若任务本身没有可分解的表示或实验资源不足，仍需保留最小可证伪对照，而不能机械复制 CKA、object count 或 prompt-search 结构（p.2–6）。
