## 5. 方法与理论

### 5.1 形式对象、状态和假设

本文的形式对象是视频 latent `Xvid`、参考图像 latent `Ximg`、噪声 `Xnoi`、flow-matching 中间状态 `Xt`、timestep `t`、模型 velocity `V̂t`、误差注入状态 `X̃vid/X̃noi/X̃img`、条件 `C={Cvis,Cemb}`、误差 memory banks `Bvid/Bnoi` 与 error-recycled velocity `Vtrcy`。训练输入假设 clean video、clean image、Gaussian noise 和可选多模态 condition；测试将前一 clip 的生成帧作为下一 clip 的 reference image，从而引入 predictive error 和 cross-clip conditional error（p.3–4）。

### 5.2 公式与理论对象（PDF 物理核对）

PDF 明确显示 Eq. (1)–(6) 六个编号公式：

1. **Eq. (1)，p.3，error-free flow matching training objective**：以 clean `Xvid`、`Xnoi∼N(0,I)`、`Ximg`、`C` 和 `t∈[0,1]` 最小化模型 velocity `u(Xt,Ximg,C,t;θ)` 与 ground-truth `Vt=dXt/dt=Xvid−Xnoi` 的平方误差；`Xt=t·Xvid+(1−t)·Xnoi`。这是 clean training hypothesis 的形式起点（`core_chain`）。
2. **Eq. (2)，p.3，test-time numerical ODE step**：在 `0=t0<…<tNtest=1` 上用 `Xtk+1=Xtk+(tk+1−tk)·u(Xtk,Ximg,tk;θ)` 从 noise 积分到视频 latent；它明确了误差如何在每步重用（`core_chain`）。
3. **Eq. (3)，p.4，error injection**：`X̃vid=Xvid+Ivid·Evid`、`X̃noi=Xnoi+Inoi·Enoi`、`X̃img=Ximg+Iimg·Eimg`，`I*` 按概率 `p*` 决定是否注入；作者另设 `p=0.5` 的 clean input probability（`core_chain`）。
4. **Eq. (4)，p.5，unified bidirectional error calculation**：`Evid=X̂vid−Xvid^rcy`、`Enoi=X̂noi^img−Xnoi^rcy`、`Eimg=Unif_T(Evid)`；其中 `Unif` 沿 latent temporal axis 采样。它把三类 injection case 统一到 residual errors（`core_chain`）。
5. **Eq. (5)，p.6，timestep-aligned replay sampling**：`Evid=Unif(Bvid,n)`、`Enoi=Unif(Bnoi,n)`、`Eimg=Unif_T(Bvid)`；video/noise error 按 test timestep bank 采样，image error 跨 timestep 和 temporal axis 采样（`core_chain`）。
6. **Eq. (6)，p.7，ERFT optimization loss**：从 `X̃vid/X̃noi/X̃img` 构造 noisy latent `X̃t`，训练 `u(X̃t,X̃img,C,t;θ)` 指向 clean `Xvid−X̃noi=Vtrcy` 的平方误差；只训练 LoRA（`core_chain`）。

Eq. (1)–(2) 是 `theory` 模块，Eq. (3)–(6) 是 `method` 模块。§3.2 的两类 error、§3.3 的 error-recycled velocity 和三种 curation case 是形式化解释，不是 theorem、lemma、proposition、corollary 或 proof。本文没有 Algorithm／伪代码环境；闭环步骤由 Fig. 3、文字和公式共同给出。p.4 的 boxed ERFT 目标说明与 Eq. (6) 语义一致，但不是额外编号公式。

方法动作序列为：`setup_notation → state_problem → derive(Eq.1–2) → explain_mechanism → state_problem → define_component(ERFT) → instantiate_algorithm(closed loop) → define_component(injection) → define_component(controls) → derive(one-step curation) → derive(Eq.4) → define_component(replay memory) → derive(Eq.5) → instantiate_algorithm/derive(Eq.6)`。它把 error 的形式化、训练输入的破坏、replay 的选择和最终 loss 串成单一因果链。

### 5.4 组件、复杂度和实现边界

- **Error types**：`Evid` 是视频 latent 误差，`Enoi` 是 noise 方向的 dual error，`Eimg` 从 video bank 沿 temporal axis 采样，用于 cross-clip reference image。p.4 footnote 说明双向使用 noise/video error 是 theoretical completeness，不构成额外模型。
- **Replay memory**：训练 grid 通常 `Ntra=1000`，测试 grid `Ntest=50`；每个 bank grid 上限 `Z=500`。满时按 L2 相似度替换最相似条目，论文将其作为保留 diversity 的 memory policy，没有给出时间或空间复杂度公式（p.6）。
- **Control path**：`Cvis`（skeleton）在 tokenized input element-wise addition，`Cemb`（text/audio）进入特定 cross-attention；因此 ERFT 不绑定单一 condition modality（p.5）。
- **Training/inference**：训练只调 LoRA；Table 12 给 `Wan2.1-I2V-14B-480P`、rank/alpha=128、learning rate `2.0e-5`、10 epochs、81 frames、480×832、deepspeed stage 2、GH200 cluster 和 injection probabilities `pvid=0.9,pimg=0.9,pnoi=0.01`。作者声称 zero additional inference cost，但没有单独的 wall-clock 或 peak-memory 对照（p.7、p.18–19）。

### 7.2 统计方法与可视化审计

- **聚合单位与分母**：Table 1 的 VBench++ 百分比是各 track／方法的聚合分数；Appendix A.2 给 generic 50 s `n=152`、250 s `n=14`，conditional `n=10`，但没有按 metric 明示有效帧、clip 或样本分母。Table 11 另从 VBench 随机取 50 test cases、50-clip length（p.19）。

- **决策量**：Table 1 用 bold／underline 标注第一、第二；Dynamic Degree 需要反向解释，作者明确指出 consistent setting 中异常大值代表 uncontrollable motion degradation（p.8）。条件表使用方向箭头区分越高／越低。

- **统计、实质意义和机制**：一致性降幅、conditional FVD 等是实质量；误差可视化和 Eimg removal 是机制证据；未报告相应检验，不能将点值差异表达为 sampling uncertainty 下的确定提升。

## 9. 结论、limitations 与闭环

### 9.1 结论段落

p.10 的 §6 先重述 train–test hypothesis gap 及两类 accumulated error，再重述 SVI／ERFT 的 inject、bidirectional one-step、replay memory 和 selective resampling，最后以三 benchmark 概括 long、ultra-long、conditional 的结果。Discussion 段落把 Self-Forcing、Rolling Forcing、LongLive、RoPE/attention-sink 作为并发差异，强调 SVI 直接校正 inference errors、轻量 fine-tuning。结论没有新数字，但把「break the time limit」和「surpasses state-of-the-art」作为回收性强主张（p.10）。

## 12. 最终判断

1. **单一主线**：论文把长视频的 train–test hypothesis gap 从「clean flow-matching trajectory」与「error-included autoregressive history」的错配中诊断为两类可积累误差，再用 ERFT 注入、双向单步估计、按 timestep replay 和 LoRA loss 训练 DiT 主动校正 self-error；Table 1–3、Table 4、Fig.5–9 将机制连接到 generic、creative 和 conditional generation（p.3–10）。
2. **正文保留的决策关键内容**：gap 的定义、两类 error、Eq. (1)–(6)、Fig.3/4 闭环、三 track 的时长／条件、Table 1–3、Fig.5/6、Eimg 主消融和 15-minute／identity qualitative claims。正文足以理解方法因果链和主要数值对照。
3. **移入附录的细节及自足性**：prompt-engine 实现、sample composition、training data／10 epochs／GH200、Table 12 超参数、metric attacks、online injection、额外定性视频、real-time／identity／style 限制和伦理讨论移入 p.14–27。正文能读懂主张，但复现 benchmark 和判断无限／部署边界必须读取附录。
4. **最有效的模式**：Fig.2 先画 clean/error-included hypothesis gap，Fig.3 再把 inject→curate→bank→resample 闭环物化，Fig.4 用三种 case 对应 Eq. (4)，Table 4 以 Eimg removal 把机制定位到可检验组件，Table 1–3 将同一方法在 duration、prompt-stream 和 condition 维度展开。这种“机制图→统一公式→主结果→组件消融”顺序最能支撑单一故事。
5. **最大缺口**：`infinite`／`no additional inference cost`／`state-of-the-art` 的证据边界比措辞弱，最长明确案例是 15 分钟，Fig.5 没有失败率或不确定性，主表没有 seed／CI／逐任务分母／compute parity；creative prompt stream 的 L 在 A.1 与 A.2 也不一致。身份、style robustness 和 metric validity 依靠单案例或附录讨论，尚未形成广泛统计闭环。
6. **可迁移规则**：面对 autoregressive drift，先把训练／测试输入假设写成可计算的状态转移，区分 model-induced error 与 handcrafted corruption，再用同一误差对象完成注入、估计、replay、组件删除和实证评价；若宣称“无限”，必须同时给出可失败的 horizon protocol 与长期统计，而不能只给代表性视频。
7. **适用边界**：该规则适合以 autoregressive feedback 为根因的 latent/video 或类似生成系统；本文实现仅验证 Wan2.1 I2V、有限 training datasets、特定 VBench++/VBench metrics 和 15-minute qualitative horizon，不能直接外推到 real-time streaming、跨主体身份保证、LLM/MLLM 或无界时长性能。
