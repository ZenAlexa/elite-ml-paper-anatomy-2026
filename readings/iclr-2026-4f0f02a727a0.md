## 4. Related Work

相关工作位于独立 §2（p2–3），分成三个小主题，约 565 词、占正文估计 10.5%。

1. **Rule-Based and Heuristic Control（p2–3）**：先按方法类别 `taxonomy`，再以手工规则依赖专家、问题相关、不能适应未见动态为 `limitation_of_prior`。Figure 1 与此段并置，展示 AutoEP 的问题输入、metaheuristic、动态超参和结果循环。
2. **Meta-Black-Box Optimization（p3）**：以 `taxonomy → chronology → limitation_of_prior → gap_creation` 推进。Meta-BBO 在 algorithm space 搜索；GLEET/NeuroCrossover 的 DRL operator selection 受 sample complexity 限制；Neural ELA/DesignX 扩展 landscape 与联合设计，但仍依赖昂贵 meta-training；作者因此提出保留 adaptivity、去除训练成本的 zero-shot 缺口。
3. **LLMs for Algorithm Design—From Offline Generation to Online Control（p3）**：先做 `chronology`（EoH/ReEvo 离线生成、EvoLLM 在线解生成），再做 `nearest_neighbor_contrast` 与 `gap_creation`。EvoLLM 受浮点表示和 context window 限制；作者提出 LLM 不应模仿 solver，而应作 high-level supervisor，将语义推理接到实时 search dynamics。

相关工作没有把方法组件重新完整介绍一遍，而是把比较维度集中在适应性、训练成本、数值精度/context window 和监督层级。引用主要承担定位与缺口建立；后续实验并未逐项回收所有被引方法的机制，仅以 PT、GLEET、BEA、EoH、ReEvo 等作为基线类别（p6–7）。

### 5.2 ELA 组件、公式与假设

- **Skewness (S)，式 (1)，p3 §3.1.1**：由当前 population fitness 的三阶中心矩标准化得到。作者明示 minimization 中 (S>0)（低质量长尾）提示 exploitation，(S<0)（高质量解趋同/早熟风险）提示 exploration。
- **Kurtosis (K)，式 (2)，p4 §3.1.1**：四阶中心矩标准化后减 3；(K>0) 被解释为集中/低 diversity，需要 exploration，(K<0) 为平坦分散，适合 exploitation。
- **Meta-Model coefficient of determination (R^2)，式 (3)，p4 §3.1.2**：简单（例如 quadratic）模型对样本 fitness 的拟合优度；高 (R^2)≈1 指向 funnel/exploitation，低 (R^2)≈0 指向 rugged/multi-modal/exploration。
- **Dispersion Ratio (D_{ratio})，式 (4)，p4 §3.1.2**：(D(Q_{best})/D(Q_{worst}))，top/bottom 10% 由 fitness quantile 选取，(D) 是解空间平均 pairwise distance；(ll1)（示例 <0.2）指单 funnel，≈1 指精英分散的多模态。
- **Variability (V)，式 (5)，p4 §3.1.3**：当前第 (g) 代平均 fitness 与此前 (m) 代均值的比值；minimization 中 (V>1) 表示足够进展、加强 local search，(V≤1) 表示停滞、加强 exploration。

公式只给出定义和启发式阈值，没有定理、引理、命题、推论或证明；5 个编号公式均服务于 `core_chain`（状态 sensing→策略方向），不是独立 guarantee。论文未形式化全局目标函数、LLM 决策正确性、稳定性或收敛界；ELA 指标到具体超参的映射由 Strategist/Actuator prompt 承担。

### 5.3 Closed-loop 与 CoR

Figure 2（p5）把输入分为 task scenarios、algorithm name、hyperparameter、Experience Pool（iteration number、hyperparameter、target value、ELA features、history information）；Multiple LLMs 生成 hyperparameter，metaheuristic 运行并回传结果。正文将三步写成：

1. **State-Sensing and Context Formulation**：计算 ELA，将当前 state 与经验池中的过去 state/action/fitness improvement 合并为结构化 prompt（p5，anchor=“State-Sensing and Context Formulation”）。
2. **Reasoning via Multi-LLM Chain**：CoR 判定 exploration/exploitation，再转为具体值（p5）。
3. **Action and Feedback**：配置作用于后续 search；结果写回 Experience Pool，作者称其在运行中实现 in-context learning（p5）。

CoR 的角色边界是：Strategist **一次性**读取问题/算法并生成 qualitative control map；Analyst **每次决策**用 ELA+历史判断方向，并显式处理指标共识/冲突；Actuator 根据 control map 选参数、从经验池推断幅度并生成值（p5–6）。Figure 3 用 GA 问题展示「crossover/mutation 影响」→「经验池诊断 exploration」→「增加 mutation、降低 crossover」的三级链。

### 8.2 负面信息和边界

- **计算成本**：正文将 CoR 延迟写为每 decision 30 ms、长运行新增 2–5 min（p7）；附录写 AutoEP 调整平均 0.3 s per run（p18）。Table 1/5/6/7 显示质量增益伴随 runtime 上升（例如 TSP GA-2opt+AutoEP 312.8m vs 309.8m；FSSP N500 181.5m vs 178.0m）。这是 `compute` 边界。
- **统计不确定性**：实验只给 30-run mean；无 std、CI、hypothesis test 或 multiple comparison。对「significantly outperforms」的统计含义，正文没有对应检验。标记为 `metric`/`causality` 限制。
- **范围/泛化**：方法声称 plug-and-play/any metaheuristic，但直接实验是 GA、PSO、ACO，且任务为 TSP/CVRP/FSSP/UAV；没有新算法类型或连续优化验证。标记为 `generality`/`scope`。
- **比较可比性**：AutoEP 使用 Qwen3-30B；EoH/ReEvo 使用 GPT-3.5-turbo；更大模型只在 Table 3 的 CoR comparison 出现。公开 API、硬件、原论文配置不形成完全匹配的 compute/model budget。标记为 `baseline`/`compute`。
- **窗口/频率外推**：L=20 仅在 TSP-100/GA-2opt；frequency 仅在 UAV-300；未证明默认窗口和频率跨任务最优。标记为 `data`/`generality`。
- **状态特征命名缺口**：§3.1 正式定义 `Variability (V)`，而 Appendix C prompt 用 “Diversity value >1” 的规则，另有 `Dratio`；正文没有明确把 prompt 的 `Diversity` 对应到 V 或其他定义。标记为 `assumption`/`reproducibility`，事实位置 p4、p16–18。
- **专门 limitations**：没有标题为 Limitations 的章节；约束分散于实验范围、运行时间、附录和统计呈现中。`

### 8.3 不利呈现策略（中性描述，不推断意图）

1. **附录迁移（observed）**：主文 §4.2.2 仅写「A detailed analysis ... can be found in Appendix B」，CVRP/FSSP/UAV 的完整表格和多数数字在 p14–15；正文的 SOTA 判断因此依赖跨页阅读。

## 9. Conclusion、Limitations 与闭环

### 9.1 结论段落动作

- **p10 §5 首段**：`重述问题 → 重述方法 → 回收结果`；把 AutoEP 定义为 ELA+LLM reasoning 的 zero-shot/training-free 控制，声称超越 tuner 并使 classical heuristic 接近 neural optimization。
- **p10 “Broader Implications—A Shift from Learning to Reasoning”**：`回收方法 → 影响`；以 sense–reason–act 对应 ELA–CoR–hyperparameter action，提出从 sample-intensive learning 到 in-context reasoning 的 generalizable blueprint。
- **p10 “Practical Advantages for Real-World Optimization”**：`回收消融/结果 → 影响`；强调 plug-and-play、30B–32B open-source 模型、local deployment/privacy/latency/reliability。
- **p10 Ethical/Reproducibility Statement**：`scope/可复现性声明`；称无利益冲突、遵守伦理、有可复现代码/匿名链接。无新数字。

## 12. 最终判断

1. **单一主线**：将 metaheuristic 的动态超参控制重构为「ELA 感知搜索状态 → CoR 多 LLM 诊断方向与调整幅度 → 执行并把结果写回 Experience Pool」的 zero-shot sense–reason–act 闭环（p3–6）。性能增益、模型可及性和解释性分别作为这条链的验证面，整体论证围绕同一闭环。
2. **正文保留的决策关键内容**：ELA 五个指标及阈值、State-Sensing/Reasoning/Action 三步、Strategist/Analyst/Actuator 分工、TSP Table 1、ELA/CoR Table 2–3、窗口 Table 4、基础模型/频率/轨迹图（p3–10）。这些内容让读者能复述机制并判断主要 trade-off。
3. **移入附录的细节及损害**：CVRP/FSSP/UAV 完整表、全部 prompts、硬件/API/初始参数移入 B–D（p14–19）。迁移节省正文空间，但让“四任务 SOTA”、17.16% 与复现输入必须跨页查找；prompt 的 `Diversity` 命名还与正文 `V`/`Dratio` 存在待澄清连接。
4. **最有效模式**：Figure 2 的闭环架构 + Figure 3 的具体问答链 + Table 2 的“without ELA/CoR/both”对照，把抽象 LLM 能力拆成可审计组件；Table 4 再把上下文窗口转成质量/延迟决策。其效果来自机制图、反事实式删除和决策量并置；单一最终分数不足以表达这些机制（p5–9）。
5. **最大缺口/读者成本**：无 dedicated limitations、无方差/检验/seed/预算；“significantly/consistently/SOTA/any”超出可直接由均值和三算法四任务支撑的范围；运行时间与质量 trade-off 需要读者自行从多张表重建（p7–10、p14–15）。
6. **可迁移规则**：当 LLM 被用作控制器时，把其输出拆成「可观测状态、方向诊断、数值动作、反馈记忆」四个可单独删除/替换的边界，并让组件消融和决策量（质量+延迟）共同回收每条主张（p5–9）。
7. **规则边界**：该规则适用于有可计算 trajectory/state 和可重复 action 的在线优化；若任务没有可靠的状态指标、动作幅度不可比或反馈成本高，ELA→LLM 的 grounding 与 CoR 消融不能直接迁移；AutoEP 本文也没有在连续优化或三种以外算法上验证（p3–4、p7、p14–15）。
