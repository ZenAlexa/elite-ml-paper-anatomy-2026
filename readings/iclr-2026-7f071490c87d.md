## 5. 方法与理论：从 COT 到可采样的 HTI surrogate

### 5.1 形式对象、输入、输出与假设

- **任务对象**：将单个连续 hyperparameter `λ` 视作 time；希望从 anchors `{pθλ(y|x)}λ∈Λobs` 恢复 conditional paths，并以 `p̂(y|x, λ)` 在中间 setting 采样。【p. 2, §2.1, “λ ∈ Λ (acting as ‘time’)”；`explicit`】
- **训练输入**：`Dobs = {(yi, xi, ti)}Ni=1`，`yi` 是 ambient observation，`xi` 是 condition，`ti` 是 observed time；`hy`、`hx`、`α` 进入 Algorithm 1。【p. 4, Eq. (9) 前；p. 6, Algorithm 1；`explicit`】
- **训练输出**：interval-specific maps `{TθT,k}`、spline geodesic generator `SθS` 和通过 `GθG`/`Û` 定义的 cost；Algorithm 1 的 return 少写 `GθG` 与 potentials，但它们在优化中明确出现。【p. 5, Eqs. (12)–(14)；p. 6, Algorithm 1；`interpretation`】
- **inference 输出**：从相邻 lower anchor 抽样，先 map 再用 `qφ(s*)` 得到 `ŷt*`；无需 inference-time optimization。【p. 6, §4.4, “avoiding the need for any optimisation”；`explicit`】
- **显式假设/归纳偏置**：observed data 在 underlying manifold 上呈现 efficient dynamics；`Û` 使 dense regions 的 path 更有利，`Kθ` 编码 least action；当前设计只直接适用单一连续 hyperparameter。【p. 5, “observed data display dynamics”；p. 10, “single, continuous hyperparameter”；`explicit`】

### 5.2 方程、推导与理论角色

|方程组|页|作用|理论角色|
|---|---:|---|---|

|Eqs. (6)–(8)|3|action、least-action cost、`L = K − U` 的 Lagrangian 分解。|`core_chain`：把 path-dependent cost 接到 COT。|

### 5.3 组件与段落动作

1. `setup_notation`：§2.1 把 HTI 写为 conditional TI 的一个实例。
2. `derive`：§2.2 从 COT primal 转 semi-dual 并以 `c`-transform 得 map。
3. `derive`：§2.3 用 least action 定义 path-dependent Lagrangian cost。
4. `state_problem`：§4 开头要求同时学习 Lagrangian、maps、geodesics。
5. `define_component → explain_mechanism`：§4.1 以高 density 对应高 `Û`，促使 geodesic 偏向 dense region。
6. `derive → instantiate_algorithm`：§4.2 的 min–max、L-BFGS warm start、map/path amortisation 进入 Algorithm 1。
7. `contrast_alternative → define_component`：§4.3 用 Givens rotations 与 eigenvalue budget 避开 `GθG → 0` 的 degenerate minimum。
8. `connect_to_prediction`：§4.4 以 adjacent anchor map 加 spline evaluation 产生 target sample。

动作转移可压缩为：`setup_notation → derive → derive → state_problem → define_component → explain_mechanism → instantiate_algorithm → contrast_alternative → connect_to_prediction`。【p. 2–6, §§2、4；`interpretation`】

### 5.4 算法与复杂度信息

- **Algorithm 1（p. 6）**：输入 `Dobs`、bandwidth、`α`、outer/inner iteration 和四组 learning rates；四层控制结构为 outer iteration → inner iteration → time interval → observed pair。关键不变量是 `Û` 在随后 `K`/maps/path 学习期间固定；每对样本以 learned map warm-start 后用有限 L-BFGS refinement 得到 `c`-transform target。给出迭代结构和 L-BFGS steps，未给 Big-O complexity。【p. 5, “fixed throughout”；p. 6, Algorithm 1；`explicit`】
- **Algorithm 2（p. 18）**：输入 true anchor distributions、maps、path generator、target and condition；找到包住 `t*` 的区间，sample → map → spline → normalise time → evaluate。没有循环和 complexity statement；它是 §4.4 的可执行展开。【p. 18, Algorithm 2；`explicit`】

## 13. 最终判断

1. **单一主线**：将 hyperparameter-induced conditional output paths 视为 conditional trajectory inference，利用 conditional Lagrangian cost 将 dense traversal 与 least action 编码，再以 maps/spline surrogate 在未训练的连续 `λ` 采样。
2. **正文保留的决策内容**：HTI 的定义、COT/CLOT 公式链、`Û`/`GθG`/map/spline 的训练和采样逻辑、五个应用/消融比较及 single-continuous-`λ` 限制。
3. **迁入附录的细节**：full dataset/reward/hyperparameter settings、baseline implementation、hardware/run-time details、sparsity plot 和 multi-hyperparameter extension。该迁移不妨碍理解主结论；复现与 sparsity 闭环依赖 Appendix C/E。
4. **最有效模式**：将一个能区分机制的 synthetic geometry（Figure 1 + Table 1）放在跨领域 benchmark 之前，并在相同 variant vocabulary 下复用到后续表格。
5. **最大缺口/读者成本**：理论没有 formal guarantee；主表只给 20-run means/SE，不给 seeds、pairwise tests 或 setting-level breakdown；Figure 2/Figure 5 的 bands 未定义；full model 在 dropout 的反向格需要读者主动整合。
6. **可迁移规则**：当核心贡献是一个 inductive bias，先构造能让该 bias 的几何或机制差异可视化的可控实验，再用真实任务比较扩展结论。
7. **规则边界**：可控机制实验只能支持其所覆盖的 path geometry/observation sparsity；跨任务、multi-hyperparameter、chaotic dynamics 和部署成本需要各自的直接证据。
