## 相关工作的定位方式

相关工作集中在 Section 6 的三个短段，未散落于引言，约占正文散文 7.75%。它避免重复方法细节，采用「类别 → 与 PGM 的差异」的写法。

1. `Discrete Diffusion` 用 taxonomy 和 gap_creation：列举 discrete diffusion/flow matching，再把 PGM 定位为「无需处理 `[MASK]` 但兼容 MGM 方法」的框架。[PDF p. 8–9, Section 6, “Discrete Diffusion”]
2. `Variable Length Masked Diffusion` 用 nearest_neighbor_contrast：Block Diffusion 的 partial KV-cache 以 any-order 为代价；Eso-LMs 保留 `[MASK]` 并新增 AR/MGM 份额超参数。[PDF p. 9, Section 6, “sacrifices the any-order generation capability”]
3. `Non-Autoregressive Language Models` 用 nearest_neighbor_contrast：any-order AR 仍用 causal attention 且 one-by-one，而 PGM 基于 bidirectional MGM、并行生成多个 token。[PDF p. 9, Section 6, “generate tokens one by one”]

这些引用在正文还承担具体功能：MDLM、MaskGIT、Halton、SDTT 分别作为基线、采样器和 distillation 接口，而非只出现在 related work。[PDF pp. 3–4, Section 2; PDF pp. 7–8, Section 5]

## 方法、符号与推导

### 单一机制链

PGM 的因果链是：MGM 的 `[MASK]` 在推理时占算力但无信息 → 每次把 token 随机分进两个 complementary groups → group-wise attention 阻断跨组内容流 → GroupSwap 把 clean group 的表示路由到待预测位置 → decoder 只对本步待解码位置计算 query → 每步避开未解码的 `[MASK]`，但仍可并行、任意位置解码。Figure 2 给训练与采样两栏，Figure 3 把该链落实为 Encoder、GroupSwap、Decoder 三层结构。[PDF pp. 3, 5–6, Figures 2–3]

### 形式对象、公式与符号

- Section 2.1 用长度 (L) 的序列 (x=(x_1,ldots,x_L))、词表 (V)、数据集 (D)、未知 (p_{data}) 建立对象；ARM 的未编号分解 (p_\theta(x)=\prod_i p_\theta(x_i\mid x_{<i})) 是「只计算已生成 prefix」的对照，而非 PGM 的理论结果。[PDF p. 2, Section 2.1, “factorize the distribution”]
- MGM 以 masked sequence (z_t)、masking probability (p_t)、denoiser (x_\theta)、权重 (w(t)) 给出训练目标 (1)。MDLM 的 (q_t)、noise schedule (\alpha_t)、mask one-hot (\pi=m)、posterior (p_{s\mid t}) 和 step schedule (\tau) 构成 (2)–(4)。CFG 的 (\omega) 是 (5) 的 guidance strength，SDTT 以 teacher/student denoiser、(m/k) 和 divergence (\delta) 写成 (6)。这些是 PGM 声称可直接继承的 MGM 接口。[PDF pp. 3–4, Section 2, Eqs. (1)–(6)]
- PGM 引入 membership vector (g\in\{0,1\}^L)，用 (p_t=1-\alpha_t) 分组；把 group 0 视作 clean、group 1 视作 masked 的类比引出 (L_{PGM}) (7) 与逐 token 权重 (w_i^{PGM}(g,t)) (8)。论文的关键推导是「一轮 forward pass 同时评估两个 complementary masking rates」，不是新的 likelihood theorem。[PDF p. 4, Section 3.1, “two complementary masking rates”; Eqs. (7)–(8)]
- 采样状态是 clean index set (C_\tau)、其大小 (n_\tau)、剩余 (m_\tau) 与每步 (k_\tau)。文本语言模型采用 fixed (k_\tau=k)，Appendix Algorithm 2 逐步 append/reorder；MDLM-equivalent 版本要按 binomial sampling 进行 padding，代价更高。[PDF p. 5, Section 3.2, “fixed schedule”; PDF pp. 19–21, Algorithms 2–5]
- GroupSwap 先说明 encoder 内表示不能跨组，再以 data-independent (u\in\mathbb{R}^H)、位置编码 (pos_i)、(V_i=W[\mathrm{LN}(u+pos_i)+b]) 给 query (9)；sinusoidal encoding 是 (10)。data-dependent 版本从 encoder output (X) 对两组聚合为 (Y_0,Y_1)，并在 (11) 把 opposite-group aggregate 加回 (V_i)。正文没有证明 leakage impossibility，依赖注意力掩码和结构解释。[PDF p. 6, Section 4.1, “cannot depend on tokens in the other group”; Eqs. (9)–(11)]
- Appendix 的 (12) 把 joint 与 marginals product 的 KL 写为 conditional MI，解释 Halton 减少空间聚集；(13) 定义 radical inverse。评测层的 (14) 定义 GPT-2 Large Generative Perplexity，(15) 是平均 unigram entropy，(16) 用 Bayes 等价把 multiple-choice continuation ranking 化为 complete-sequence NELBO ranking。[PDF pp. 14, 16–18, Appendices B–D, Eqs. (12)–(16)]

整篇有 17 个 displayed formula blocks，其中 16 个带编号，编号连续为 (1)–(16)。正文含 12 个 displayed blocks（一个未编号 ARM factorization 与 (1)–(11)），appendix 含 5 个（(12)–(16)）。未出现 theorem、lemma、proposition、corollary 或正式 proof；公式角色是定义、现有目标的连接、机制解释和评测诊断。[PDF pp. 2–6, 14, 16–18]

### 方法动作转移与算法覆盖

正文动作序列为 `state_problem → setup_notation → derive → define_component → explain_mechanism → instantiate_algorithm → connect_to_experiment`。Section 3 的 `From Masking to Partitioning` 和 `Connection to the MDLM Variational Bound` 负责前四步；Section 4 与 GroupSwap 负责组件与反泄漏机制；Section 3.2 把采样连接到 Algorithm 2/3；Section 5 将 speed/quality 判断落到测量。[PDF pp. 4–7, Sections 3–5]

五个伪代码对象在 appendix：Algorithm 1 给 Halton grid order；Algorithm 2 是固定 token-budget 的 PGM sampling；Algorithm 3–5 是 MDLM-equivalent 的可变长度、padding 和抽取实现。Algorithm 2 的外循环为 (K) sampling steps，关键不变量是 `decoded_positions` 与 `x` 同步增长，最后 `reorder` 回原位置；Algorithm 3 引入 per-sequence `concrete_lengths`，其 padding 说明正文为什么偏好 fixed schedule。复杂度以实际 latency/throughput 报告，未提供渐近复杂度式。[PDF pp. 14, 19–21, Algorithms 1–5]

## 实验设计与复现粒度

- 文本：LM1B 使用 `bert-base-uncased`、context 128；OpenWebText 使用 GPT-2 tokenizer、context 1024、sentence packing，并把最后 100k documents 留作 validation。MDLM 是 12 layers、dim 768；PGM 使用 12 或 16 layers、dim 768 或 1024，Encoder/Decoder split 变化。正文给 global batch 512、1M steps、dropout 0.1、Adam 3e-4、EMA 0.9999；Appendix C 给 betas、epsilon、warmup、GPU 数、gradient clipping 等。[PDF p. 7, Section 5.1; PDF pp. 15–16, Appendices C.1–C.2]
- 图像：ImageNet256 经 pre-trained VQGAN 变成 1024-token sequences；MaskGIT 与 PGM 都有 24 Transformer blocks、class-conditioning 与 CFG。训练 500k steps、batch 256、AdamW，图片中心裁剪为 256×256。PGM 有两 registers，sampling 时用一枚；图像评测包括 confidence 和 Halton samplers。[PDF p. 8, Section 5.2; PDF p. 16, Appendix C.3]
- 匹配与对照：Table 1 同时报参数、batch 32 的 latency 与 throughput。LM1B 的 MDLM 170M 对 PGM 6/6 171M，OWT 的更优 PGM 有 203M 或 268M，因而 OWT 的 quality 比较不是严格的 parameter-matched claim。互补 masking 控制组使用 standard bidirectional Transformer 和 2× batch，作者明确称它测得的是潜在收益上界。[PDF pp. 6, 8, Table 1; Section 5.3]
- 测量单位：language quality 使用 validation PPL 与 GPT-2 Large Gen. PPL，另加 unigram entropy；downstream 是 multiple-choice accuracy。图像是 FID 与 IS，对 50,000 generated images 对 validation set 计算。生成评测使用 1,024 sequences；Table 6 的 latency/throughput 为 20 batches、2 warmup 后的 mean ± standard deviation，Table 8/9 为 10 batches，Table 3 为 100 batches、2 warmup。[PDF pp. 7–8, 16–17, 19, 22, 24–25]
- 精度控制：所有 sampling logits cast 到 FP64，以避免低精度 underflow 使 Gen. PPL 偏低但 diversity 变差；distillation 的结果据称因而统一使用 FP32 loss 版本。[PDF pp. 16, 18, Appendix C.4 and D.2]
- 缺失：论文未报告 random seeds、quality/FID/accuracy 的置信区间、显著性检验、多重比较处理或预先定义的失败阈值。时间与 throughput 有离散度，quality 主要是单点表格值。[PDF pp. 6, 9, 22–25, Tables 1–2 and 6–9; layout observation]

实验顺序与引言贡献基本对应：文本 speed/quality → downstream 与 distillation → 图像 speed/quality → 互补 masking isolation。唯一没有直接实验回收的是「gradient variance」本身，实验只测 PPL 与 training-loss spikes。[PDF pp. 7–8, Section 5; PDF p. 17, Figure 6]

## 结果、统计与可视化

### 主要结果与不利解释

1. LM1B 上 Table 1 报 MDLM 27.67 PPL、PGM 6/6 26.80 PPL，且 latency 3.78 s 对 2.12 s、throughput 1,081.57 对 1,930.93 tok/s。质量优势为 0.87 PPL，不是 1.95；后者属于 complementary-masking MDLM 25.72 的差值。该内部不一致见后文核对。[PDF p. 6, Table 1]
2. OWT 上，MDLM 为 23.07 PPL、1,043.22 tok/s；PGM 8/8 为 22.61、5,585.57 tok/s，PGM 6/6 dim 1024 为 21.43、5,518.09 tok/s。前者约 5.35×、后者约 5.29× throughput，但参数分别为 203M 和 268M，对照是 170M MDLM。[PDF p. 6, Table 1]
3. Table 2 的 8 个 downstream tasks 没有总体平均值或不确定性。PGM 8/8 在 distillation 前胜 MDLM 6/8 tasks，之后胜 7/8 tasks；这一组逐任务数字支持「多数 task 略高」，未单独证明整体能力提升。[PDF p. 9, Table 2]
4. 未 distilled 的 OWT Table 6 在 128 steps 时，PGM 6/6 dim 1024 的 Gen. PPL 为 116.95、entropy 5.67、latency 5.93 ms、throughput 5,518.09 tok/s；MDLM 对应 122.89、5.67、31.41 ms、1,043.22 tok/s。这里 throughput 优势约 5.29×，而 entropy 相同。[PDF p. 22, Table 6]
5. distilled 结果需要区分 ancestral 与 nucleus：在 128 steps、FP32 loss 下，PGM 6/6 的 Gen. PPL 为 60.06，高于 MDLM 的 45.06；加 nucleus (p=0.9) 后为 43.84，entropy 5.39 对 5.40，throughput 5,375.20 对 1,043.22 tok/s。主文的「可比」只对应后一个 sampler，不涵盖所有 distilled setting。[PDF p. 23, Table 7; PDF pp. 7–8, Section 5.1]
6. ImageNet 的主图使用各模型最低 FID 的 CFG weight：MaskGIT 32 steps (w=1) 的 FID 5.35、1.05 img/s；PGM 12/12 32 steps (w=3) 的 FID 5.54、7.93 img/s，约 7.55×。PGM 64 steps (w=2) 为 FID 4.56、4.12 img/s，约 3.92×。完整 guidance sweep 在 Table 9，故「comparable」限定在最优 selected weights 与 Halton sampler。[PDF p. 1, Figure 1; PDF pp. 8, 25, Section 5.2 and Table 9]
7. 训练成本反向结果在 Appendix C/E：OWT PGM 6/6 dim 1024 的 forward+backward throughput 为 62.85 seq/s，MDLM 为 80.86 seq/s；作者把它概括为约 75% training throughput。训练 1M steps 约为 LM1B 22 hours、OWT 4.5 days、ImageNet 3.8 days。[PDF pp. 16, 19, Table 3 and Appendix E.1]

## 消融、负面结果与自我设限

正文唯一显式的 `5.3 Isolating the Effect of Complementary Masking` 约 238 词、约占正文散文 5.19%，却通过 Table 1/5 和 Appendix D.1、D.4 延展。它把每个 input 变成两个 complementary masked copies，使用 2× batch 的 standard Transformer，识别目标是「互补监督本身」而非 Partition Transformer；作者也明确将它称为潜在收益的 upper bound。[PDF p. 8, Section 5.3; PDF p. 21, Table 5]

- 组件与 allocation：LM1B 200k 的 PGM 6/6 为 32.69 PPL，8/4 为 32.83、10/2 为 33.55、4/8 为 32.84；data-independent query 为 32.69，logsumexp 为 32.70，mean 为 33.89。它支持 balanced depth 与 simpler query 的选择，未给重复 run 统计。[PDF p. 21, Table 5]

## 最终判断

- 单一主线：用 partition 替代 mask，使 MGM 在每步只计算 clean tokens；GroupSwap 使被预测位置只接收 opposite-group 信息，从而把结构改变转成实际 throughput 条件。[PDF pp. 2, 4–6]
- 正文保留的决策内容：核心 loss、architecture 图、text/image 两项 headline trade-off、downstream 表和互补 masking 的短消融。Figure 1 在第一面预置问题的决策证据，是全篇最有效的视觉安排。[PDF pp. 1, 3–9]
- 迁移到附录的细节：精确 hyperparameters、metric definitions、precision、training cost、algorithm、full sweeps、long-context、stability 和 extra downstream；迁移不妨碍理解方法，但限制复现和主张边界的独立判断。[PDF pp. 14–26]
- 最有效模式：先用 MGM/ARM 的「算力浪费」对比定义问题，接着以互补 groups 的 loss 与 GroupSwap 解释机制，再让每个 benchmark 的 quality–throughput 共图或共表。这个模式的适用边界是新结构必须真能减少所计算的 token 数，不能只把同样的 full-length computation 改名。[PDF pp. 1–6]
- 最大缺口：本文没有直接量化 gradient variance，却把它连到 PPL；更严重的是 1.95 PPL 的 PGM 说法与 Table 1/Table 5 的 26.80 对 27.67 不符。质量、accuracy 与 FID 缺少跨 run 离散度，也使部分「comparable」只能解释为已选设置的点估计。[PDF pp. 2, 6, 21–25]
- 可迁移规则：把效率论文的 headline 数据固定为「任务、模型容量、sampler、steps、batch、quality metric、throughput」的同一行或同一图；同时把任何 cost reversal 与参数差异放在主文的同一决策面。
- 规则边界：当结果依赖广泛 configuration sweep、未 matched capacity 或未报告不确定性时，主图只能作条件性摘要，不能替代完整表格和重复试验。
