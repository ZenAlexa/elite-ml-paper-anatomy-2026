## 5. 方法与理论

### 5.1 UniPercept-Bench 的方法链

方法的第一条链位于 p.4-p.6。作者先定义三个感知域，再给出三层标签和双任务协议，最后给出 QA 生成、拒绝采样和人工修订。关键组件与前文问题的对应关系如下。

| 单元 | 前文问题 | 输入与输出 | 方法推进与证据 |
|---|---|---|---|
| 三域定义 | 语义任务漏掉外观、质量和局部结构 | 图像；IAA、IQA、ISTA 解释 | IAA 侧重 composition/style/emotion/appeal；IQA 侧重 fidelity/degradation；ISTA 侧重 geometry/material/local detail。（p.4，`targets perceptual-level image understanding across`） |
| Domain–Category–Criterion | 感知属性缺少统一操作层级 | 域、类别、criterion；QA 模板 | IAA/IQA 整合 prior expert definitions，ISTA 来自 practitioner structured interviews。（p.5，`three-tier taxonomy`） |
| VR 与 ISTA Rating | 需要连续量化感知判断 | [0,100] 评分 | IAA/IQA 使用 Visual Rating，ISTA 用 structure-texture richness 评分；ISTA 分数的详细规则移到 p.18-p.19。（p.5，`higher score indicates a scene with more complex geometry`） |
| VQA | 连续评分难以表达解释一致性 | question、options、answer | 在三层 taxonomy 上生成 perceptual reasoning QA，与 VR 一起评估判断和解释。（p.5，`jointly measures quantitative judgment and explanatory consistency`） |
| Initial QA Generation | 需要大规模细粒度样本 | 图像、专业标注、结构标注、template | GPT-4o 组合 image、annotation、template，生成候选 QA 和简短 reasoning rationale。（p.5，`Generator MLLM (GPT-4o)`） |
| Reject Sampling | 自动生成样本存在有效性问题 | 候选 QA | Qwen-2.5-VL-78B-Instruct 按 Question/Answer/Reasoning Validity 和 Criterion Relevance 五点量表筛选；所有维度达到 good 或以上，约删除 40%。（p.5，`removing about 40% of candidates`） |
| Human Refinement | 边界样本需要感知与语言校正 | 保留样本、borderline cases | 受训且有 Image Assessment 专长的 volunteers 手工验证、修改边界样本、删除无效样本。（p.5，`Borderline cases are revised`） |

### 5.2 UniPercept 的训练链

| 阶段 | 训练对象 | 机制 | 证据 |
|---|---|---|---|
| Domain-Adaptive Pre-Training | 基于 InternVL3-8B 的模型 | 约 800K 样本。IAA/IQA/ISTA 均有 text-based QA，ISTA 另有 structured-output QA；VR pairs 直接关联连续评分。（p.5-p.6，`dataset ... approximately 800K samples`） |
| Task-Aligned RL 的 VQA 分支 | VQA answer | Eq.1 的 binary reward，正确为 1，否则为 0 | 目标是离散 correctness。（p.6，Eq.1，`1, if the predicted answer is correct`） |
| Task-Aligned RL 的 VR 分支 | predicted score 与 ground truth | Eq.2 Adaptive Gaussian Soft Reward；误差越大 reward 越低，且 `σdyn = σ0(1 + α|pi − gi|/100)` | `pi`、`gi` 映射到 [0,100]；Token As Score 从 token distribution 取得评分。（p.6，`Adaptive Gaussian Soft Reward`） |
| 联合优化 | VR 与 VQA responses | Eq.3 GRPO objective，以 task-specific reward 进入 clipped policy ratio 和 estimated advantage | 统一目标连接离散答案与连续评分。（p.6，`align model behavior with both discrete correctness ... and continuous perceptual consistency`） |
| 资源与超参数 | 两阶段训练 | 16 NVIDIA A100；每阶段 2 epochs；batch size 128；GRPO 每 query 采样 n=8，β=0.001，ε=0.2，σ=0.8 | 复现信息集中在 p.7 的 `Training Details`。（p.7，`16 NVIDIA A100 GPUs`） |

方法推进动作序列为 `setup_notation → state_problem → define_component → give_intuition → instantiate_algorithm → connect_to_prediction → connect_to_experiment → summarize`。具体映射为 `3.1 definition → 3.2 taxonomy/tasks → QA pipeline → 4.1 DAPT → 4.2 reward equations → 5.1 training details`。文中没有伪代码；GRPO 只以公式和文字描述出现，循环层级、不变量和每步 token budget 均未给出。

### 5.3 理论边界

正文没有独立的 theory section，也没有 Theorem、Lemma、Proposition、Corollary 或 Proof。13 个编号公式均为 reward、GRPO 目标或 ISTA 的操作性计分定义，承担可实现性和诊断解释，未给出收敛、泛化、无偏性、复杂度或人类一致性的理论保证。ISTA 公式的详细解释在 supplement p.18-p.19；阈值 reward 的对照公式在 p.23。

- Eq.1-Eq.3（p.6）构成训练目标的核心链，但不构成理论保证。
- Eq.4-Eq.12（p.18-p.19）把 morphology 权重、component score 和 image score 组合成可解释的确定性 ISTA rating。
- Eq.13（p.23）是 threshold reward 的替代设计，用来作消融对照。

理论对论文的角色属于 `explanation` 与 `diagnostic`。论文将“aligns with human perception”和“robust generalization”作为经验主张，未用理论结果单独闭合。

## 7. 结果、统计与可视化

### 7.1 统计口径

- VR 的聚合单位是每个 benchmark dataset 的图像评分，报告 Spearman rank correlation（SRCC）与 Pearson linear correlation（PLCC）；Table 1 和 Table 16 以 `SRCC/PLCC` 展示。论文没有说明每个数据集的精确样本分母、缺失响应如何进入平均值，或是否对不同数据集等权。
- VQA 的聚合单位是 QA 样本或类别，报告 accuracy 百分比。Table 2-4 给出 category、template 和 overall 列，random guess 作为参考。
- Figure 7 用 VQA accuracy 与 VR 的 `(SRCC + PLCC)/2` 作模型概览。没有误差条、bootstrap、假设检验、多重比较校正、Bayesian 分析或回归拟合。
- Table 1 的 `-/-` 代表拒答或功能失败，且没有统一的失败率分母；这使模型间可比性依赖有效回答集合。作者没有把拒答处理作为敏感性分析。

## 14. 最终判断

### 单一主线

论文的单一主线是把 MLLM 的语义视觉能力扩展到可操作的 perceptual layer。作者以 IAA、IQA、ISTA 三域和 Domain–Category–Criterion taxonomy 定义对象，再用 VR 与 VQA 形成双通道 benchmark，接着用约 800K DAPT 与 task-aligned GRPO 训练 UniPercept，最后以跨域 benchmark、T2I reward 和 image/model/dataset profiles 展示用途。（证据 p.2 `To bridge this gap`；p.4-p.6 `three-tier taxonomy`、`Task-Aligned RL`；p.9-p.10 Tables 5-8。）

### 正文保留的决策关键内容

正文保留了三域边界、VR/VQA 任务、QA 三阶段管线的概括、DAPT/RL 两阶段训练、Eq.1-Eq.3 reward 目标、主要 baseline 结果和 T2I/application 结果。Table 1-8 给出大量点估计，使读者能判断 UniPercept 在作者选定 benchmark 上的相对位置。（证据 p.4-p.10。）

### 附录迁移及其代价

附录迁移了 ISTA 的结构化 JSON、形态词典、material/shape/style lexicons、Eq.4-Eq.13、IAA/IQA/ISTA criterion 表、数据组成、消融和 profiles。这样的布局让主文叙事保持紧凑，但 ISTA score 如何产生、QA 覆盖什么 criterion、训练集如何凑成约 800K、联合训练为何有效，都需要读者跳到 p.16-p.23 才能复核。主文对 reward 与 benchmark 的结果可读，方法细节的自足性不足。（证据 p.5 `as detailed in the Appendix`；p.18-p.23。）

### 最有效的写作、图、表和公式模式

最有效的模式是将三层 taxonomy、Figure 1 的结构图、Figure 3 的 QA 实例和 Figure 4 的生产管线连成一个操作闭环，再用 Tables 1-4 逐域比较 VR/VQA。Figure 6 将 structured annotation、continuous reward 和 binary answer reward 放在同一训练图，Eq.2 把 VR 的数值误差变为连续 reward。该组合把抽象的“perceptual-level”转为可标注、可训练、可测量的接口。（证据 p.1、p.3-p.6。）

### 最大叙事缺口

最大缺口是经验闭环强于识别闭环。结果表显示 point-estimate 优势，但没有 seed、重复运行、置信区间、显著性、标注者一致性、数据泄漏控制或 composite reward utility。Table 16 的 IAA Avg 和 Table 5 的 per-dimension trade-off 也没有被“consistently”或“best overall”重新解释。因而论文支持“在选定 benchmark 上表现较强并可被试作 reward/metric”，尚不足以支持无条件的 robust generalization、human alignment 或 causal improvement。（证据 p.6-p.10、p.22-p.23。）

### 可迁移规则

先把模糊的视觉能力拆成互斥且可观测的 perceptual dimensions，再为每个 dimension 同时设计连续评分和解释型 QA；训练目标、benchmark 表格和下游应用沿同一 taxonomy 回收。这样可以让读者从定义直接追踪到模型输出。（依据 p.4-p.8 的三域和双任务闭环。）

### 规则适用边界

该规则适用于有图像、感知属性标签、连续评分或可判定 QA 的评测任务。若目标是开放式审美、真实人类偏好或跨模型因果提升，仍需独立的人类协议、重复统计、外部校准和明确的 composite objective；UniPercept 本文没有提供这些验证。（证据 p.6-p.10、p.22-p.23。）
