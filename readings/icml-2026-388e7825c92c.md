## E. 方法与理论

### E.1 形式化对象与核心链

论文将输入问题记为 `X`，可含题干和初始图。text-only trajectory 是 `τcot = [t1,…,tN]`；interleaved trajectory 是 `τint = [(t1,c1),…,(tk,cK)]`（Eq. 1，p. 4）。其中 `tk` 为文本推理块，`ck` 为可执行 GeoGebra code，`vk = Render(ck)`。关键条件是下一文本块使用累积视觉状态：`P(tk+1 | t1:k, v1:k, X)`（Eq. 2，p. 4）。作者把 `V` 置于 `T → V → Y` 的因果中介位置。绘图先把文本意图实例化为可观察状态，再供后续推理读取。

SFT 分析（§3.2）先令 `T={t1,…,tk}`、`V={v1,…,vk}`、`Y` 为最终答案，并以数据分布上的负 log-likelihood 写出 Eq. 3。Eq. 4 把 likelihood 拆成 premise、plotting、deduction 三段；Eq. 5 以 `Idata(V;Y|T1,X) − Iπθ(V;Y|T1,X) ≫ 0` 表示策略低估图与答案的依赖；Eq. 6 以 `Hπθ(Y|T1,V,X) ≥ Hπθ(Y|T1,X)+δ` 表示噪声 scaffold 产生 distraction penalty。两项机制分别对应“表面相关”和“上下文碎片化”。

Faire（§3.3）规定三项条件：

1. **Geometric Consistency (`Cgeo`)**：代码属于 `Ωvalid`，并满足由题目 `X` 导出的硬约束 `KX`；Eq. 7 用可执行性指标和约束乘积表达 node integrity。
2. **Perceptual Admissibility (`Cperc`)**：VLM judge `Jmllm(v)` 超过视觉清晰度阈值 `τperc`；Eq. 8 约束遮挡、极端缩放和标签重叠等 egress channel noise。
3. **Semantic Alignment (`Csem`)**：从文本得到的几何意图 `ψ(T)` 被 code 提取的 primitive 集合 `ϕ(c)` 包含；Eq. 9 约束图形必须对应当前推理意图，而非任意合法图。

Eq. 10 将三项检查放回局部因果图。`Csem` 检查 `T→V`，`Cgeo` 检查节点完整性，`Cperc` 检查 `V→Y`。Eq. 11 给出 gated/dense reward：`R(V,Y)=I(Y=Y*)+β(Cgeo+Cperc+Csem)`；Eq. 12 以 GRPO 的 advantage ratio 和 `−βDKL(πθ||πref)` 更新策略。图 2（p. 3）将 answer correctness `Cans` 与 code executability `Cexe` 画成门控信号，再聚合 `Cperc`、`Csem`、`Cgeo`。文字和公式把可执行性嵌入 `Cgeo`，存在命名层面的映射，见测量分歧记录。

## F. 实验设计

### F.1 研究问题、数据与生成流程

- **主问题/假设**：交错监督是否会造成 SFT paradox；RL 是否能恢复 constructed state 与后续 deduction 的 functional alignment。作者在消融开头明确列出这两个要验证的 claim（p. 11，§5.6，`explicit`）。
- **Faire-Bench**：K12 几何交错推理 benchmark；每个实例把逐步 deduction 与可执行 GeoGebra script 绑定，执行结果重建下一步依赖的 geometric state（p. 6，§4）。
- **规模与分割**：共 7,989 个实例；SFT 4,643、RL 2,321、Eval 1,025。Table 1 的分割比例为 Plane geometry 51.5/51.6/54.7%、Function 29.4/28.3/27.4%、Analytic geometry 19.1/20.1/17.9%、Hard 54.4/54.8/54.1%、至少两张图 39.6/38.4/43.6%（p. 6）。
- **构造**：先用 taxonomy 选择依赖 axes/curves/key points 的 function/analytic geometry 题和依赖 incidence/parallelism/perpendicularity/tangency 的 Euclidean construction 题；Gemini 2.5 生成逐步 solution trace 与 GeoGebra script。提示词约束 syntax、grounding、category-specific drafting（p. 6）。
- **过滤与人工环节**：先丢弃错误候选并执行 GeoGebra，随后依次使用 Alignment Filter、Semantic Filter、Geo Assert Filter；全通过者进入 expert review，最终留下 All-Pass training data（p. 6–7，Figure 3）。过滤目标包括缺失元素、断开的辅助线、off-canvas、标签拥挤、intent shift 以及关键几何关系失败。
- **分布分析**：K6–8 约 69%，K9–12 约 17–20%，K0–5 约 11–14%；技能集中于 triangle congruence/similarity 27.8%、function graphs 25.6%、polygon reasoning 14.7%、line–coordinate 9.1%、conic + linear relations 6.2%（p. 7，Figure 4 和正文）。

### F.2 模型、基线与训练预算

- **基线**：proprietary 为 GPT-4o、GPT-5.1、GPT-5.2、Gemini-2.5-Pro；open-weight 为 GLM-4.1V-9B、Gemma3-12B、InternVL3.5-8B、Kimi-VL-A3B、Qwen2.5-VL-7B、Qwen3-VL-8B（p. 7–8）。
- **SFT 初始化**：从 Qwen3-VL-8B 开始；bfloat16、SDPA attention；单个 8-GPU node；visual token cap 2,048；最大序列长度 10,000；2 epochs；learning rate `5 × 10−6`；warmup ratio 0.05；DeepSpeed ZeRO-2（p. 8，§5.1）。
- **RL**：从 SFT checkpoint 继续，使用 GRPO；vLLM 加速 sampling；每 prompt 生成 7 个 candidate；temperature 0.9（p. 8）。
- **统一条件**：作者写明除非另有说明，模型遵循同一 prompting protocol 与 evaluation budget（p. 8）。论文没有报告随机 seeds、每个 baseline 的完整 prompt、训练 wall-clock、GPU 型号、总 compute 或公开实现地址。

### F.3 指标、控制与评测粒度

- `Acc` 是 final answer 的 binary accuracy，正确或数学等价为 1，否则为 0。Drawing score 在 Appendix A 定义为三个归一化分数的均值：Visual Judge `svis`、Semantic Judge `ssem`、Formal Judge `sform`（Eq. 13，p. 18）。
- Table 2 同时列 code similarity（BLEU、ROUGE-L、chrF）和 image similarity（PSNR、SSIM、LPIPS），以及 Parser、Code、Judge 三个 verification score 和 Avg。Appendix A 明确 surface similarity 只用于 diagnostic；开放式 construction 的正确性由 tri-perspective score 负责（p. 18–19）。
- 主体比较组合为 text-only/interleaved × SFT/RL（Table 5），reward 采用 full 与 leave-one-out（Table 4），并对 proprietary/open-weight 模型以及 GenExam、GGBench 做外部比较。没有 seed-level 配对、数据泄漏检查、matched-compute 消融或失败判定阈值的完整报告。
- Figure 8 把自动 verifier score 与 human rating 放在散点图中，标注 `r = 0.9578`；没有报告参与者人数、抽样方式、评分 rubric 或相关系数类型（p. 12）。不能从图中把 `r` 进一步解释为某种未注明的检验。

### F.4 实验顺序与引言/理论对应

顺序是 `setup → Table 2 主结果 → entropy shift → 两个主文案例 → GenExam structure/relations → reward 与 training-paradigm ablation → human judgment`。它基本对应引言提出的“功能验证优于表面匹配”、理论提出的三条局部因果约束、以及“RL 将绘图变成后续 state”的预测。GGBench、verifier prompt 和五个额外案例放到 appendix，降低了正文的实验密度，也使外部泛化与案例证据依赖附录。

## I. 结论、限制与闭环

### I.1 结论段动作

p. 12 的结论有两段：第一段 `重述问题 + 回收 SFT paradox`，把失败归因于交替分布拟合与 construction–reasoning dependency under-optimization；第二段 `重述方法 + 回收结果 + 影响`，回收 gated reward、visual/semantic/formal verifiers、跨 benchmark/category 的 dependable intermediate state，以及 verifier–human 对齐；末句把未来方向指向 geometry 之外和 stronger assertion synthesis。结论没有新增数字，唯一数值性事实仍是回收 “track human judgments closely”的 Figure 8 结论（p. 12，`explicit`）。

### I.2 独立限制节与可见边界

PDF 没有名为 `Limitations` 的章节，也没有单独的 ethics、broader impact 或 reproducibility section。以下边界可以从正文/附录直接读出：

1. **任务范围**：Faire-Bench 是 K12 几何题，code/render/verifier 依赖 GeoGebra；从本文可直接支持的对象是几何交错推理，不足以证明对一般 multimodal reasoning 的转移（p. 6、18–24）。
2. **指标范围**：surface similarity 对开放式 construction 只作 diagnostic；formal/semantic/visual 分数分别依赖 GeoGebra kernel、parser 与 VLM judge（p. 18–23）。
3. **实验报告缺口**：没有 random seed、参与者人数/抽样/rubric、完整 denominator、GPU 型号/总 compute、数据泄漏控制或公开实现链接（p. 8、12、18–24；均为 PDF 未出现的事实）。
4. **理论边界**：三条件被称为必要且充分，但 PDF 没有 theorem/proof；应把它读作形式化设计假设与行为证据之间的桥梁（p. 5，`explicit` + `interpretation`）。
5. **因果识别边界**：RL 与 SFT 对照同时改变 optimization/reward/sampling，Table 5 是训练范式对比，不是 matched-seed、matched-compute 的单变量因果实验（p. 8、11，`interpretation`）。

## L. 最终判断

1. **单一主线**：几何交错推理要求图形成为可执行、可检查、能供下一步 deduction 读取的中间状态。论文把 SFT 的失败描述为格式分布拟合导致的图文干扰，再用 Faire 的三视角 verifier、gated reward 和 GRPO 把图的几何合法性、可读性、语义意图与后续答案连接起来；Table 2、Table 4–5、Figure 5–8共同把这条线从方法定义推进到行为证据。
2. **正文保留的决策关键内容**：Figure 1 的类别负迁移、Eq. 1–12 的依赖/奖励形式化、Figure 2 的系统边界、Table 2 的 surface/verification 对照、Figure 6–7 的 state-level 机制案例、Table 4–5 的完整性与范式消融、Figure 8 的人评关系。读者可据此判断“答案正确”和“构造可用”之间的差异。
3. **移入附录及其代价**：Appendix A 的评分算法和 Eq. 13–14、C 的三套 prompt、D/E 的类别与 GGBench 数值、F 的五个案例均被移出主文。主线仍可读，但 verifier 如何得到分数、外部 benchmark 是否支持中间过程、类别异质性如何变化，都要跨页查附录；Appendix 长度接近正文，说明正文自足性是有限的。
4. **最有效的写作/图表/公式模式**：Table 5 的 2×2 `SFT/RL × text-only/interleaved` 直接识别“drawing hurts then helps”；Table 4 的 leave-one-out 对应三个 Eq. 7–9 条件；Table 2 把 answer、surface、Parser/Code/Judge 并列；Figure 6–7 把“构造顺序/图形趋势”转成可观察的失败类型。它们共同把机制从口号变成可核对对象。
5. **最明显的叙事规避、未闭合主张或读者成本**：三项条件被称为必要且充分，却没有 theorem/proof；RL 与 SFT 同时改变 reward、optimization、sampling，缺少 matched compute/seed；Figure 8 只有 `r`，缺少 human protocol；Table 2 的 Avg 和 Figure 12 的类别分数可能掩盖分母与异质性；Figure 12 延迟至 p. 24，Figure 9–11 的 prompt 需要跨页读取。上述是报告粒度和识别边界问题，不能据此推断作者动机。
6. **可迁移规则**：只要中间产物被主张为“推理状态”，就应把它的合法性、与当前意图的语义耦合、对后续模型可读性分别定义为可执行检查，并用组件消融把表面相似度与功能证据分开报告。
7. **适用边界**：该规则适用于具有可执行表示和可判定关系的中间产物；本文只在 GeoGebra/K12 几何和相关 benchmark 中验证，VLM judge、parser 与 assertion 的组合不能单独推出对一般多模态任务、开放式视觉状态或不同训练规模的转移。
