## D. 相关工作

相关工作位于独立的 §1.1（p.2），在方法之前。三个引用簇各自承担定位，不在后文重复为方法介绍：

## E. 方法与理论

### E.1 形式化对象与问题边界

- Universe `X` 为 countable；dataset `W={W_i}_{i∈[n]}`，每个 `W_i⊂X` 有限；`N=Σ_i|W_i|`、`M=|∪_iW_i|`、`N(x)=Σ_i1{x∈W_i}`、`N(r)` 为第 r 大频率（p.2，§2.1，`explicit`）。
- Neighboring dataset 是增删一个 user；算法输出 `S⊆X`。Definition 2.1 给出 `(ε,δ)`-DP（p.2，§2.2）。作者只研究 `δ>0`，因为后续要求 soundness（p.2）。
- Definition 2.2 的 missing mass 是未输出项频率之和除以 `N`；定义 `MM_p` 为缺失频率向量的 `ℓ_p` norm，编号公式 (1) 在 p.3（§2.3）。`p=1` 是主目标，`p=∞` 是最大缺失频率，`p=0` 回到 cardinality 目标。
- Assumption 1（p.3，§3）要求 `A(W)⊆∪_iW_i`，即 soundness。单例且每个 user 持有唯一 item 的构造使任一满足该假设的 DP 算法的期望 missing mass 至少 `1−δ`，展示无数据分布假设时的障碍。
- Definition 3.1（p.3）规定 `(C,s)`-Zipfian：`N(r)≤CN/r^s`。作者限制主 ℓ1 上界到 `s>1`；`s≤1` 时上述病态数据仍合法。Lemma 3.1（p.4）把 Zipfian 条件转成 `max_i|W_i|≤(CN)^{1/s}`。

### E.2 WGM 机制与隐私参数

Weighted Gaussian Mechanism（WGM，Algorithm 1，p.4）是三阶段：

1. 对每个 `W_i` 无放回均匀采样 `\widetilde W_i`，大小 `min{Δ₀,|W_i|}`；
2. 对采样后的 item 计算加权 histogram `\widetilde H(x)=Σ_i(1/|\widetilde W_i|)^{1/2}1{x∈\widetilde W_i}`；
3. 加 `Z_x∼N(0,σ²)`，输出 noisy count `\widetilde H'(x)` 至少为阈值 `T` 的 item。

Theorem 3.2（p.4）沿用 Gopi et al. 的 `(ε,δ)`-DP 条件：Gaussian CDF 不等式约束 `σ`，并要求 `T` 大于对 `t≤Δ₀` 的阈值最大值。Appendix C.2.1 的 Lemma C.1（p.12–13）把最小量级化为 `σ=Θ(√log(1/δ)/ε)`、`T=\widetilde Θ_{δ,Δ₀}(max{σ,1})`。隐私是对最坏邻接数据集保证，并未依赖 Zipfian 假设（p.3–5）。

### E.3 Set union 的核心上界、下界与证明机制

- **Theorem 3.3（p.4）：** 对 `(C,s)`-Zipfian、`s>1` 数据，在 WGM 下以 `1−β` 概率给出 ℓ1 missing mass 上界，依赖 `C,s,N,max_i|W_i|,q*:=min{max_i|W_i|,Δ₀},T+σ`；上界随 `N` 增大、`C` 减小、`s` 增大而改善。其证明把损失拆成 subsampling 与 noisy thresholding 两部分。
- 三个 helper lemma 的因果角色（p.13–15，§C.2.2）：Lemma C.2 控制 subsampling missing mass；Lemma C.3 保证高频 item 以至少一半的比例留在 subsample；Lemma C.4 用 Gaussian concentration 控制被 thresholding 漏掉 item 的加权频率。Theorem 3.3 的 proof 在坏事件概率各取 `β/3` 后 union bound。
- **Corollary 3.4（p.5）：** 代入最小 DP 参数后，误差主项显式含 `1/(εNq*)` 的幂次；若 `Δ₀≥max_i|W_i|`，subsampling 误差消失。作者建议把 `Δ₀` 设得接近最大 user set size，并提醒 `Δ₀≫max_i|W_i|` 会引入被省略的对数因子。
- **Theorem 3.5（p.5，Appendix D.1 p.21–22）：** 对任意满足 soundness 的 `(ε,δ)`-DP 算法，存在 Zipfian 数据使 expected ℓ1 missing mass 下界匹配 Corollary 3.4 对 `ε,N` 的依赖。Lemma D.1 先沿 user 邻接链递推，证明低频 item 的输出概率至多 `1/2`；再对 rank tail 积分。
- **Theorem 3.6（p.5，Appendix C.2.3 p.16–17）：** 不要求 Zipfian，WGM 给 distribution-free `MM_∞` 上界；Lemma C.5 控制 subsampling 后的最大遗漏频率，随后用 Gaussian threshold 与 Chernoff 事件限制所有被漏 item 的原始频率。该结果成为未知域 top-k 与 k-hitting 的接口。

### E.4 Meta Algorithm、top-k 与 k-hitting set

**Meta Algorithm（Algorithm 2，p.6）：** 先以一半隐私预算运行 WGM 得到域 `D`，再以另一半预算在 `D` 上运行已知域算法 `B(W,D,k)`；basic composition 给总体 `(ε,δ)`-DP。该结构把“发现哪些 item”与“在发现域上选择/覆盖”分开。

**Private top-k（§4.1，p.6–7）**，Definition 4.1 定义 ordered output `S=(x_1,…,x_q),q≤k` 的 top-k missing mass。Algorithm 3 对已知域 `D` 计算 `N(x)+Gumbel(λ)` 并按 noisy count peeling 输出前 k 项。Lemma 4.1（p.6；精确参数在 Appendix B Lemma B.1）给 `(ε,δ)`-DP；Lemma 4.2（p.6；证明 p.17）用 Gumbel 最大值集中控制 true top-k 与 output 的 count gap。Theorem 4.3（p.7）将两阶段误差相加，WGM 的 `MM_∞` 导致至多 `k·MM_∞` 的域截断误差，peeling 导致 `\widetilde O(k^{3/2}log M/(εN))` 的排序误差；从而无需 Zipfian 假设。Corollary 4.4（p.7，D.2 p.22）给 soundness 下的线性 `k/(εN)` lower bound。

**Private k-hitting set（§4.2，p.7–8）**，目标是最大化 `Hits(W,S)=Σ_i1{S∩W_i≠∅}`，相对于 NP-hard 问题的 `Opt(W,k)` 给近似保证。Algorithm 4（正文仅在 Appendix C.4 p.19 给伪代码）是 User Peeling：每轮在剩余用户/域上加 Gumbel，选择当前命中数最大的 item，删除已命中的用户，最多循环 k 次。Lemma C.7（p.18–20）基于单调非负 submodular greedy 递推给 `1−1/e` 近似及 noise additive error；Lemma C.8（p.20）把高频域 `D={x:N(x)≥τ}` 的最优值与全域最优值差距限为 `kτ`。Theorem 4.5（p.7–8、C.4 p.20–21）再代入 Theorem 3.6，得到 unknown-domain `1−1/e` 近似，误差含 `k·max_i|W_i|/(ε√q*)` 和 `k^{3/2}log(Mk)/ε`。当 `ln(Mk)/ln(M)≤√max_i|W_i|` 时，作者称相对 Mitrovic et al. 的 `log|X|` 保证改善为 `log M`（p.8）。Corollary 4.6（p.8、D.3 p.22–23）给 soundness 下至多 `\widetilde Ω_δ(k/ε)` 的 expected hit loss。

### F.2 编号公式

1. **式 (1)，p.3，§2.3：** `MM_p(W,S)` 是未输出频率向量的 `ℓ_p` norm；主目标由 `p=1`、接口由 `p=∞`。
2. **式 (2)，p.15，§C.2.2：** `MM(W,S)=MM(W,∪_i\widetilde W_i)+(1/N)Σ_{x∈\widetilde M}N(x)`，把损失拆为 subsampling 与 thresholding。
3. **式 (3)，p.18，§C.3：** WGM 产生的 `MM_∞(W,D)` 上界。
4. **式 (4)，p.18，§C.3：** 全域 true top-k 与域内 true top-k 的质量差至多 `k·MM_∞(W,D)`。
5. **式 (5)，p.18，§C.3：** Gumbel peeling 的域内 top-k count-gap 上界。
6. **式 (6)，p.19，§C.4：** monotone submodular greedy 的最大边际增益至少剩余最优 gap 的 `1/k`。
7. **式 (7)，p.19，§C.4：** noisy user peeling 每轮的边际增益下界，误差由两个 Gumbel 噪声差给出。

公式链为：定义可比较目标 (1) → 拆解 WGM 误差 (2) → 用 ℓ∞ 域截断控制 top-k (3–5) → 用 submodular recurrence 控制 k-hitting (6–7)。

### G.2 主结果与不确定性

1. **Set union（Figure 1，p.8，§5.1）：** claim 是 WGM 在六数据集上与 policy 方法的 MM 接近。主图覆盖三个 large datasets；Δ₀ 为 `{1,50,100,150,200,300}`，每点为 5 trials 的平均 MM，lower is better。作者文字报告 WGM 的 MM 在各数据集上处于 policy 机制的 5% 以内，同时 policy 计算明显更重。无置信区间、假设检验或 runtime 数值；“significantly more intensive computation” 是定性比较。潜在不利解释是 5-trial mean 与图形聚合可能掩盖 dataset/trial 异质性，正文没有进一步分解。小数据集 Figure 8 在 appendix 重复“comparable + more efficient”趋势。
2. **Top-k（Figure 2，p.9，§5.2）：** 三个 large datasets 的所有方法 top-k MM 近 0，因此正文只画三 small datasets。WGM-then-top-k 对比 `k̄∈{k,5k,10k,∞}` 的 limited-domain Durfee–Rogers；当 `k̄<∞` baseline 取 `Δ₀=∞`，`k̄=∞` 取 `Δ₀=100`。文字 claim 是 WGM 对所有 k 都有更小 top-k MM，且优势随 k 增长。图没有误差条/原始数值/检验；作者没有声称显著性。
3. **k-hitting set（Figure 3，p.10 图体、p.9 §5.3）：** 5-trial average hit users，standard error，`k∈{5,10,20,50,100,200}`、Δ₀=100。WGM 与 non-private greedy 和假定 `∪_iW_i` public 的 private greedy 相当；Steam Games 与 Amazon Magazine 上超过 known-domain private greedy。作者解释为 WGM 域更小但保留高质量 item，使第二阶段更容易。潜在不利解释是 public-domain baseline 不满足未知域 DP；作者在正文明确披露这一点，因此比较的边界清楚。
4. **低 ε 与严格排序损失（Figures 9–13，p.25–27）：** `(0.1,10⁻⁵)` 下 set-union 大/小数据集趋势与主实验 qualitatively similar；top-k ℓ1 在 ε=1、Δ₀=100 时 WGM（紫色）比所有 baseline 损失更小，ε=.1 下 top-k MM 与 ℓ1 仍跨 k 优于 baseline；k-hitting 的 missed users 与 public-domain 情况相当、部分超过。所有这些是图形/文字的定性或相对结论，没有额外显著性统计。

**统计边界：** 论文采用 trial-level average、standard error、best/relative qualitative comparisons 和 theoretical high-probability bounds；没有报告 confidence interval、p-value、多重比较、bootstrap、Bayesian model 或回归。set union 的分母是总 entries `N`；top-k MM 的分母也是 `N`；k-hitting 的聚合单位是 users hit/missed。正文区分了理论保证、实质效用和机制解释，但“competitive”与“significantly more intensive”仍缺少可复现的 runtime/uncertainty 数值。

## H. 消融、负面结果与自我设限

- **Δ₀ 敏感性（observed）：** Figure 1（p.8）和 Figure 8–10（p.25）扫描 `{1,50,100,150,200,300}`。这不是组件删除；它同时检测 uniform subsampling 的贡献上限和 epsilon 改变后的稳定性。

- **k 敏感性（observed）：** Figures 2、3、11–13 扫描 k；top-k 同时报告更严格的 ordered top-k ℓ1，识别“MM 看起来好但排序错”的可能性。
- **组件删除/替代（not_present）：** 没有 WGM stage ablation、无-weight Gaussian 对照、无 data-dependent subsampling 对照、无 User Peeling 与其他 private submodular mechanism 的同预算替代实验。
- **数据/任务异质性（observed but limited）：** 六个真实数据域、三大/三小分组，Appendix E 给 rank-frequency 与 user set-size 诊断；没有 synthetic stress test 或跨域统计模型。
- **失败案例/计算成本（partial）：** failure case 不存在；作者口头说明 policy mechanisms 计算更 intensive，却未给 runtime、内存或 wall-clock 表。

有证据的自我设限包括：

1. `scope`：ℓ1 Zipfian 上界限定 `s>1`，`s≤1` 的病态 singleton 数据仍困难（p.3）。
2. `assumption`：soundness `A(W)⊆∪W_i` 是上下界共同依赖的输出边界（p.3、p.21–23）。
3. `privacy`：只研究 approximate DP (`δ>0`)，因为 soundness 与 pure DP 冲突（p.2）。
4. `compute`：uniform subsampling 的误差可能主导；应让 Δ₀ 接近最大 user set size，且避免远大于它（p.5）。
5. `generality`：top-k 与 k-hitting 的 upper/lower bounds 不匹配，作者在 §6 把 closing gaps 列为 future direction（p.9）。
6. `data`：主文只展示 large datasets 的 Figure 1、small datasets 的 top-k/k-hitting，另一半分布结果放入 Appendix F（p.8–9）。

这些限制均描述为适用条件、证明缺口或实验范围；没有依据版面推断作者动机。

## L. 最终判断

1. **单一主线：** 将未知域 DP domain discovery 的不可证明 cardinality 目标改写成 frequency-weighted missing mass；证明简单 WGM 的 ℓ1/ℓ∞ 域发现界，再把 WGM 当作域过滤器接入 known-domain top-k 与 submodular k-hitting set。证据链为 p.3 Definition 2.2/式(1) → p.4–5 Theorems 3.3/3.6 → p.6 Algorithm 2 → p.7–8 Theorems 4.3/4.5 → p.8–10 Figures 1–3。
2. **正文保留的决策关键内容：** soundness 与 Zipfian 条件、WGM 的 sampling/weighting/noise/threshold stages、half-budget composition、三组定理/下界、Δ₀/ε/k 的主设置、baseline 身份以及 unknown-domain baseline 的无效性说明。
3. **附录迁移及其影响：** concentration、完整 WGM/peeling/User Peeling algebra、lower bounds、Table 1、分布诊断和低 ε/ℓ1 图后置。定理陈述仍能独立传达结论；验证 tightness、union bound、数据构造与实验异质性时需要附录，复现实验实现仍因 Supplement 缺失而不完整。
4. **最有效模式：** 式(1) 把 cardinality 与 mass 统一为 `MM_p`；式(2) 将 WGM 损失分成可分别控制的 subsampling/thresholding；Theorem 3.6 的 ℓ∞ 接口把同一域发现器复用于两个任务；Figure 2/3 的任务顺序与引言贡献对齐。
5. **最大叙事缺口：** “simple/scalable”只有相对 baseline 的定性计算说法；没有 runtime、seed、完整配置或 Supplement 代码可核验。top-k/k-hitting 上下界明确不匹配，ℓ∞ 理论也没有对应的直接实验指标。5-trial 平均与只画主面板限制了异质性判断。
6. **可迁移规则：** 当未知域是前置瓶颈时，先定义带频率权重、可与下游目标相加的域损失，再证明一个可组合的 `ℓ∞` 或 tail interface；随后用同一域发现器接入多个 known-domain solver，并在正文显式标出每一阶段隐私预算和每一项误差来源。
7. **适用边界：** 该规则要求输出 soundness、下游损失能由遗漏频率控制，且数据或任务允许明确的 domain truncation；若用户集合不满足 Zipfian/高频集中，ℓ1 结论退化，只有 distribution-free ℓ∞ 接口仍可用；若需要 pure DP、非 sound 输出、运行时保证或 matched lower bounds，本文证据不足。
