## 6. 方法与理论

### 6.1 形式对象与单一方法链

系统输入为 reference image、audio clip，以及可选 text prompt；System 2 输出结构化 analysis 与按 shot 划分的 action schedule；System 1 的 MMDiT 接收 text/audio/video 三分支并生成 120-frame video clip。主文在 latent space 使用预训练 3D VAE 和 flow matching；长视频以先前片段的末帧自回归续写。[p.4–p.6，§3.1–§3.3；p.5，`reference image, the audio clip, and an optional text prompt`]

方法动作转移序列为：

`setup_notation → state_problem → define_component → explain_mechanism → give_intuition → instantiate_algorithm → connect_to_prediction → connect_to_experiment → summarize`

论文没有 theorem、lemma、proposition、corollary、proof、复杂度定理或算法框。公式总数为 0，displayed equation 为 0，numbered equation 为 0；GSB 的 `(Wins − Loses)/(Wins + Loses + Ties)` 只作为 Appendix C 的行内定义出现。[p.20，Evaluation Metrics；p.26，Table 5；全篇无 `Algorithm`/定理标题，`layout_observation`]

### 6.2 System 2：MLLM Analyzer–Planner

Analyzer MLLM 读取 reference image、image caption、audio 和 user prompt，按 step-by-step probing 推断语言／转写、情绪、意图与内容分段，并汇总成 structured JSON。Planner MLLM 读取该上下文，输出按 shot 排列的 expressions/actions schedule；每个 shot 对应一次 generation pass。这个 schedule 是从语义和意图到动作的中间接口，也是认知类比真正进入视频模型的唯一显式通道。[p.5，§3.2；`infers the character’s speech content, emotional state, and intent`]

作者还探索 reflective re-planning 和 reasoning-infused audio latents。两者未进入主定量配置：reflection 因增加 inference overhead 被禁用于 quantitative comparisons；reasoning latents 虽让 facial expressions 更细腻，却压制大幅动态动作，因审美权衡被排除。[p.5，§3.2；p.30，Visual Ablations]

### 6.3 System 1：MMDiT、MM warm-up 与 PLF

MMDiT 设 video、text、audio 三个独立 branch；每个 transformer block 把三类 token 拼接后用共享 multi-head self-attention，让模态互相 attend。audio branch 是专门新增的对称分支。作者指出 naive joint training 会被 dense audio signal 主导，洗掉 text guidance 并破坏预训练 video branch，因此采用两阶段 MM warm-up：阶段 1 联合训练三分支；阶段 2 以原始 text/video 权重和阶段 1 的 audio 权重初始化后整体微调。[p.5–p.6，§3.3；`all three modalities are fused within each transformer block`]

PLF 的训练／推理边界分为两步。训练时丢弃 user reference image，改用视频原生 GT first/last frames，二者各以 0.1 dropout；推理时把 user image 放入 last-frame 位置，并把 RoPE index 移到生成序列末端之后的固定时间距离。PLF 被解释为 “carrot on a stick”，为身份提供远端目标而不强制复制静态图；长视频续写时用前片段最后 5 帧，RoPE shift 为 30。[p.5–p.6，§3.3；p.18，Appendix B；`each with a dropout probability of 0.1`]

这两个设计分别对应两类前文问题：MM warm-up 处理 audio/text/video 的模态干扰，PLF 处理参考图的 identity–motion trade-off。Figures 8–9 主要以视觉证据支持 PLF，Table 1–2 以组件替代支持 warm-up 与 reference conditioning；没有单独的 identity distance 或 motion–identity 统计量。[p.6–p.8；p.28–p.30，Appendix E]

## 7. 实验设计

### 7.1 训练与实现

- 输出为 120 frames、24 fps；大多数 ablation 以 480p 生成，再用同架构 super-resolution model 放大到 720p 以匹配比较设定。[p.6，§4.1；`generates 120-frame clips at 24 fps`]
- 训练分三阶段：audio branch warm-up（约 18k A100-equivalent GPU-hours）、main phase（15,000 小时视频，约 43k GPU-hours）、100 小时高质量 subset fine-tuning（约 6k GPU-hours）。优化器为 AdamW，learning rate `5e-5`、global batch size 256、gradient clipping norm 1.0。[p.18，Appendix B；`global batch size of 256`]
- MLLM 实例为 miniCPM-o Analyzer 与 Seed-1.5-VL Planner；audio feature 由 Whisper encoder 提取；每个 visual latent 只与时间上最近的 5 个 audio/text tokens 做 attention。[p.18，Implementation Details]
- 训练数据由 PySceneDetect、PaddleOCR、Q-Align、RAFT、SyncNet 过滤；5–20 秒连续片段、字幕去除、静态或混乱运动过滤、音画同步过滤。约 70% 数据的 lip–audio correlation 较差，论文称丢弃 audio 并以 audio-dropout 使用这些视频。[p.19，Training Data Curation and Composition]
- 数据构成抽样中 upper-body 约 47%、medium 30%、full-body 15%、long shot 8%；indoor 约 45%、静态背景 outdoor 41%、动态背景 outdoor 14%。[p.19，Training Data Curation]

### 7.2 数据、任务、基线与评测

- 自建 Single-Subject Generalization Set 为 150 cases，覆盖真实人像、AIGC figures、anime、animals；音频包括 speech、singing、theatrical performance，并为 text-conditioning 写 150 条描述 prompt。[p.19，Evaluation Datasets]
- Multi-Subject Interaction Set 为 57 cases，配对多角色交互音频；多人物扩展加入 predicted speaker mask，mask 区域独占 audio feature injection，Planner 也读取 speaker mask。[p.18–p.19，Implementation of Multi-Person Scenarios]
- 公平比较采用 CelebV-HQ 100 videos 做 portrait talking-head，CyberHost test set 269 videos、119 identities 做 full-body。[p.19，Evaluation Datasets]
- Objective metrics：FID、FVD、Q-Align 的 IQA/ASE、SyncNet 的 Sync-C/Sync-D、Hand Keypoint Confidence/Variance（HKC/HKV）。作者特别说明多人物场景中 Sync-C 可能给未说话人脸误导性高分，因此增加 Sync-D。[p.20，Evaluation Metrics]
- Human study 有 40 participants；pairwise 的 overall quality 计算 GSB，artifact analysis 记录 LSI、MU、ID；另有 best-choice 计算 Top-1 selection rate。[p.20，Subjective Metrics]
- MLLM evaluation 使用 Gemini-2.5-Pro 对 side-by-side video 做 Overall Quality、Prompt Following、Motion-Context Coherence 三维比较；左右位置随机化，每个 sample pair 评估 5 次。[p.20、p.25–p.27，MLLM Evaluation Prompt and Protocol]

### 7.3 控制与复现粒度

作者给出了输出长度、分辨率、训练阶段、GPU-hour、优化器、数据过滤工具、数据集规模和 metric 定义，并把完整 MLLM prompt、案例分析和扩展实现放入附录。论文没有报告随机种子、每项人类比较的精确 pair 数、participant 分配、训练／测试去重或数据泄漏检查、Q-Align 的数值 threshold、显著性检验、多重比较策略、误差传播或置信区间。[p.18–p.20、p.25–p.27；相关列表未出现 seed/CI/test de-duplication，`layout_observation`]

## 8. 结果、统计与可视化

### 8.1 统计口径

### 8.2 主结果清单

1. **Reasoning ablation（Table 1/2，主文 p.7）**：full model 的 HKV 为 168.912，高于 w/o Multi-Step 157.638、w/o Analyzer 148.381、System-1-only 122.376；full 的 GSB 为 +0.29，w/o reasoning 为 −0.29，MU 为 0.37 对 0.58，ID 为 0.04 对 0.11，LSI 两者同为 0.12。作者据此主张 reasoning 提升动态性、motion naturalness 和 semantic quality。[p.7，Tables 1–2；`Ours (Full Model) ... 168.912`]
2. **Conditioning ablation（Table 1/2，主文 p.7–p.8）**：full 的 HKV 168.912，高于 cross-attention 116.317、w/o MM-Warmup 164.080、w/ reference image 160.889、w/o reference & PLF 160.986；与 OmniHuman-1-style conditioning 比较时，LSI/MU/ID/GSB 为 0.03/0.25/0.07/+0.23，对方为 0.21/0.39/0.17/−0.23。表中 full 并非每个 objective 列都最优。例如 w/o Multi-Step 的 IQA 4.795 高于 4.790，w/o Ref. & Pseudo Frame 的 Sync-C 4.141 高于 4.087。[p.7–p.8，Tables 1–2；`Ours (Full Model)` 与各 ablation 行]
3. **Text-conditioning fidelity（Table 2c，主文 p.8）**：相对 base model，TA 为 −0.02、Motion 为 +0.18、VQ 为 +0.14；作者将其解释为 text alignment 基本持平，同时 motion naturalness 与 visual quality 提高。[p.8，Table 2(c) 与 `Text-Conditioning Fidelity`]

## 10. 结论、限制与证据闭环

### 10.1 结论段动作

### 10.2 Limitations 与自我设限

## 13. 最终判断

1. **单一主线**。纯 audio-reactive avatar 生成被重新表述为 dual-system simulation。Analyzer–Planner 用 MLLM 把音频、图像和 prompt 变成语义 schedule，MMDiT 以 MM warm-up 融合低层节奏，PLF 以远端 identity target 支持大幅动作。[p.2、p.4–p.6]
2. **正文保留的决策关键内容**：问题缺口、System 1/System 2 功能类比、Analyzer/Planner、三分支 MMDiT、PLF、warm-up、基本训练设定、两类主 benchmark、两组 ablation、multi-person 与 SOTA 表格，以及 conclusion 的总体收束。[p.4–p.10]
3. **移入附录的细节及其影响**：实现超参、数据过滤与分布、评测 protocol、逐步 schedule、Gemini prompt/结果、PLF/MM-Warmup/reflection montage、latency、ethics/reproducibility/limitations 被移入 p.18–p.33；因此主文可读性较好，但 semantic 评测的分母、完整 prompt、视觉失败边界和复现细节离开附录后无法独立判断。[p.18–p.33]
4. **最有效的写作／图表模式**：把低层 objective metrics 与 human/MLLM semantic dimensions 并列，以 Table 1/2 的组件删除和 Figure 12 的 speech-matched cases 形成“机制、主观结果、案例”的证据链；PLF 用 Figure 8/9 的长时间序列和 RoPE offset 对照传达 reset 机制。[p.7、p.26、p.29–p.32]
5. **最大叙事缺口**：认知 simulation 是功能类比而非认知有效性论证；semantic coherence 依赖主观或 MLLM proxy，缺少标注 ground truth、participant/pair 分母、误差和检验；“significant/leading”与表格支持之间有强弱不对称。PLF 的 identity 结论也主要是 montage 证据。[p.2 脚注；p.7、p.10、p.20、p.26、p.29–p.30]
6. **可迁移规则**：面向高层语义的生成系统，应把低层保真指标、组件级反事实消融和预先定义的语义评测维度并列报告，并同步公开比较分母、重复层级与不确定性，使“指标捕捉不到的能力”仍能被审计。[p.7、p.20、p.25–p.27]
7. **适用边界**：这条规则适用于语义与感知质量占主导的生成任务；它不能把功能类比升级为认知机制证据，也不能以少量案例、MLLM 偏好或无区间单点值替代 identity、语义 ground truth 和 deployment-level robustness。[p.2 脚注；p.19–p.20；p.33]
