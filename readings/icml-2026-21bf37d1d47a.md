## E. 方法与理论

### E.1 形式对象与最小逻辑链

- **输入与有效观测**：个体 `i=1..N` 的 `x_i in R^P`，疾病结局 `Y_{i,v} in {0,1}`，仅在风险指示 `R_{i,v}=1` 时建模；目标是多结局预测和重建重叠 latent pathways（p.3, 3.1）。
- **观测层**：`y_{i,v} ~ Bernoulli(sigma(eta_tilde_{i,v}))`，`eta_tilde_{i,v}=alpha_v+x_i^T beta_v`（Eq. 1, p.3）。
- **潜在拓扑**：`G=(V,E)`，节点是疾病，超边是风险响应模式，`H_{v,e}=z_e m_{v,e}`，`E` 是最大超边数（p.3–4）。
- **路径到疾病的映射**：`beta_{j,v}=d_v^(-1) sum_e H_{v,e} mu_{j,e}`，`d_v=E^(1/2)`（Eq. 2, p.4）。这一步把因子 `j` 的超边效果聚合成疾病特异系数，同时允许疾病属于多个超边。
- **拓扑先验**：`z_e|r_e ~ Bernoulli(r_e)`、`r_e ~ Beta(a_r,b_r)`；`m_{v,e}|z_e,rho_{v,e}` 在 `z_e=0` 时退化为 0，在 `z_e=1` 时为 Bernoulli；`rho_{v,e} ~ Beta(a_rho,b_rho)`（p.4）。
- **因素—超边效果层**：`mu_{j,e}|gamma_{j,e}` 是 spike-and-slab，`gamma_{j,e}` 受 `z_e` 条件约束；同一风险因素的重叠超边由 `R_rep(gamma_j|H)` 惩罚（p.4）。Repulsion overlap 使用 `O(S_e1,S_e2)=|S_e1∩S_e2|/min(|S_e1|,|S_e2|)`，允许不同因素的超边重叠，但压制同一因素下冗余激活。
- **逻辑不变量**：`z_e=0 => m_{v,e}=gamma_{j,e}=mu_{j,e}=0`，且 `gamma_{j,e}=0 => mu_{j,e}=0`（p.4）；它属于生成先验和条件变分因子的共同约束，后处理阶段没有再定义这一规则。
- **后验近似**：PG augmentation 把 logistic likelihood 变成条件 Gaussian；structured VI 保留 `q(z_e) q(m_{v,e}|z_e) q(gamma_{j,e}|z_e) q(mu_{j,e}|gamma_{j,e})` 的条件层级（p.4–5）。
- **推断器**：CAVI 交替更新 PG 变量、截距、效果、激活概率、成员概率、超边存在概率和 Beta/Inverse-Gamma 超参数；repulsion 的变分期望进入 `nu`、`rho`、`r` 更新（Algorithm 1, p.5；Appendix A.4, pp.15–17）。
- **复杂度**：作者给出每轮约 `O(N E(P+V))`，并称不同超边在每轮内可并行（p.5、p.22）。这是复杂度陈述而非 theorem；没有 asymptotic proof 或运行时间上界。

| Eq. (15) | 16 | `core_chain` | edge existence `r` update；汇总 downstream membership/activation 证据 |
| Algorithm 1 | 5 | `core_chain` | 输入 (Y,E,\lambda)，交替更新至 ELBO convergence，输出 variational posterior |

Appendix A 的 Eq. (9)–(15) 把正文只给出名称的“preserve dependencies”落实成可复算的 conditional updates；但这些式子是 coordinate-wise variational updates，不是对 exact posterior 或 global optimum 的保证。

### G.2 主要结果、统计处理和不利解释

1. **Simulation predictive performance。** Table 1 报告 BHPI 的 AUC 为 (75.00(0.83))（(N=2000)）和 (74.63(0.46))（(N=5000)），optimal logistic 为 (73.86(0.83))、(74.15(0.49))；LGBM 为 (68.50(0.94))、(69.68(0.56))。数值是 50 replicates 的 mean (standard deviation)，AUC 乘 100；比较对象还包括 Binary Relevance、Classifier Chains、RAkELd（p.6, Table 1）。作者解释为在不牺牲 prediction 的情况下获得结构。一个不利解释是 BHPI 的生成机制与 simulation data-generating process 同构，因而这不是对 misspecification 的检验；论文没有加入结构错配模拟（`interpretation`，p.6, 5.1–5.2）。
2. **Simulation structural recovery。** Table 2 给出 (corr(\beta,\hat\beta)=97.85)、H-AUC (=96.96)、γ-AUC (=97.85)（×100）；optimal logistic 的 coefficient correlation 为 95.65，但按构造不定义 H/γ recovery。作者据此声称可恢复真实 block structure，而独立 logistic 无法恢复 latent hypergraph（p.6, Table 2 与 5.2）。统计处理是 replicate-level aggregate，未给区间或 hypothesis test。结构真值来自模拟，因此识别力结论主要是内部恢复检验。
3. **Repulsion prior ablation。** Table 3 在 (N=2000) 下比较 λ=0 与 λ>0：AUC 74.69→75.00，Jaccard 0.542→0.565，overlap 0.800→0.812，effective edges/RF 1.992→1.874，overlap/RF 0.097→0.082。正文解释为 prediction 几乎不变，而 redundancy/stability 改善；Table 7 在 (N=5000) 也显示 AUC 74.51→74.63、Jaccard 0.581→0.619（p.6、p.18）。不利解释是 λ>0 的结构收益没有显著性检验，也可能混合了 model selection/initialization variability；作者通过扩展表和敏感性图补充而未做正式机制分解。
4. **UKB rare-disease stability。** Figure 2 展示相对于 tuned logistic 的 per-disease ΔAUC distributions，并按 prevalence 分层；LGBM 和 Classifier Chains 在 rare diseases 有长 lower tails，BHPI 更稳定。图是分布可视化，没有给每病种数值、聚合分母或区间；作者以“matches or exceeds”描述而非给单一平均改善（p.7, Figure 2）。潜在不利解释是 prevalence bin 内异质性和 100 split 的 per-disease variation 被图形聚合，读者不能从正文恢复每一病种决策。
5. **UKB calibration。** Table 4 报 BHPI ECE 0.005、Brier 0.041；optimal logistic ECE 0.001、Brier 0.041；LGBM 0.021/0.043，Binary Relevance 0.031/0.045，Classifier Chains 0.044/0.052，RAkELd 0.006/0.042。作者说 BHPI ties for best Brier 且 ECE<0.01，并把 logistic 的更低 ECE 归因于 per-disease calibration objective（p.7, Table 4）。统计层级和不确定性没有在表注中展开；ECE/Brier 的 disease/sample aggregation 规则未给出，故“well-calibrated”应限于该 cohort/split aggregate。
6. **Hypergraph-specific advantage。** Table 5 以 per-disease logistic 为参照，按 prevalence 报 mean ΔAUC ×100 与 paired Wilcoxon p-values：BHPI 在 <2% 为 +1.2 (3E−5)、2–5% 为 +0.2 (0.11)、≥5% 为 +0.2 (0.02)；BFR (K=20/30) 和 clique-expanded 仅在部分组改善或下降。作者进一步指出 clique graph 即使 PIP threshold 0.9 仍约 65% dense，learnable clique-GCN AUC≈0.50，因此高阶选择性是主要表示优势（p.7–8, Table 5）。不利解释是只给 prevalence-group aggregate，p 值多重比较处理未说明；clique construction 与 BHPI topology 共享，基线的调参对称性也未完整展示。
7. **PIP structure and masking。** Figure 3 画 disease–hyperedge 与 risk-factor–hyperedge PIPs；初始 E=60，posterior expected active edges 27.2，PIP>0.5 的为 28，多数 hyperedges 覆盖 2–12 diseases。Table 6 中 high-PIP-only AUC 几乎等于 full model（UKB 68.7/69.6/71.6 vs full 68.9/69.7/71.6；simulation 75.6 vs 75.7），low-PIP-only 接近 chance（58.6/55.0/57.4；simulation 51.2），random subset 介于其间（p.8）。作者将此作为 posterior structure carries genuine predictive signal 的机制检验。潜在不利解释是 PIP threshold 由作者选定，masking variant 与 full model 共享已学结构，不能等同于独立预注册 feature selection。
8. **Pathway case studies。** Figure 4 和页 8–9 文字展示 Smoking 分到 respiratory injury 与 ulcer 两条不相同路径，Dementia 同时进入 vascular-cognitive、geriatric frailty、metabolic-neurodegenerative 路径；用 PIP、edge width 和医学文献作定性支持。案例说明 overlapping membership 和 factor-specific activation。它们提供的是定性关联证据，未完成 causal identification，也没有病例级 effect size/validation（p.8–9, Figure 4）。
9. **MCMC structural calibration。** Appendix Table 8 比较 full Gibbs MCMC 与 CAVI：MCMC H overlap (0.885\pm0.068)、ECE_H (0.081\pm0.019)、ECE_z (0.058\pm0.053)、ECE_γ (0.039\pm0.032)、AUC (0.747\pm0.009)；CAVI 为 0.850±0.054、0.087±0.026、0.028±0.081、0.050±0.030、0.741±0.008。作者据此把结论收窄为“well-supported structural posterior uncertainty and competitive predictive calibration”。论文没有给出 exact calibration guarantee（p.18、p.20, Table 8）。
10. **Initialization and runtime。** Appendix B.5 报告 permutation alignment 后 initialization overlap 为 simulation (0.905\pm0.062)、UKB (0.875\pm0.044)，cross-replicate overlap 0.81–0.83，AUC std 0.01；但 exact labeled-edge identifiability 不保证。Appendix D/Table 10 报 UKB E=60 用 27.8 GB、73.7 min training、<0.1 ms inference；simulation runtime 随 E 由 10→15→20 增长 1.6/2.7/3.2 s（N=2000）和 4.1/6.4/9.3 s（N=5000）（p.19、p.22）。这些是特定硬件和实现配置的观测，不是所有 EHR scale 的性能保证。

**统计边界。** 论文真实使用的统计包括 replicate/split aggregation、mean (s.d.)、AUC、correlation、Jaccard/overlap、PIP、ECE、Brier、paired Wilcoxon p-values、ROC 和 Bayesian posterior factors。没有报告 bootstrap、回归、传统置信区间、multiple-comparison correction 或 participant-level human evaluation。表格能独立解释列名与比较，但 ECE/Brier 聚合分母、PIP threshold 选择和完整 p-value correction 规则需要代码或补充说明。

**显著性与实质意义的区分。** Table 5 的 rare-disease +1.2 improvement 同时有 paired Wilcoxon p=3×10−5，2–5% 的 +0.2 p=0.11；这说明作者把实质增益与检验结果并列，但没有在正文给最小重要差异阈值。Table 3/7 的 identifiability metric 变化没有 p 值，Table 8 的 calibration 用 ECE aggregate 而非假设检验。机制证据（PIP mask、repulsion redundancy、MCMC comparison）与预测证据有区分，但 UKB latent pathway 的真值不可观测。

## L. 最终判断

1. **单一主线。** 论文的单一主线是：把 EHR 多病种风险从独立或全局共享表示改写成「风险因素直接调制潜在超边」的问题；repulsion prior 让同一因素下的路径不冗余，structured VI 维持 `existence → membership → effect` 逻辑，借此在 rare-disease setting 同时获得可解释的高阶结构、结构后验不确定性和竞争性预测。证据链由 Eq.1–2、p.4 hierarchy、Algorithm 1、Table 2/3/5/6、Figure 3/4、Appendix Table 8 构成。
2. **正文保留的决策关键内容。** 正文保留表示选择（hypergraph 而非 clique/latent factor）、repulsion 的机制、conditional VI 的必要性、模拟真值恢复、UKB rare-disease/performance/calibration、clique 对照、PIP mask 和 Smoking/Dementia 解释案例。读者可以据此判断核心结构是否影响 prediction 以及 repulsion 是否主要影响 identifiability。
3. **移入附录的细节及其代价。** PG/full posterior/CAVI equations、敏感性曲线、CAVI–MCMC calibration、initialization symmetry、UKB cohort table/ROC、额外案例和 runtime 全部在附录。迁移使正文更易读，但 calibration claim、exact identifiability 边界和 biobank compute cost 需要读者跨页拼接才能完整成立。
4. **最有效的模式。** Figure 1 先用一张 workflow 把数据、latent hypergraph、risk-factor action 和 uncertainty 对齐；Table 3/7 把 prediction 与 structure 的作用拆开；Table 5/6 用 prevalence-stratified paired comparison 和 PIP masking 连接结构到实质预测；Figure 4 将 global graph 与两个可读案例并置。最有效的公式模式是 Eq.2 的短映射加 p.4 的逻辑蕴含，再由 Appendix Eq.13–15 展开算法更新。
5. **最大叙事缺口。** “identifiable”与“calibrated”在摘要和引言中先作为强能力提出，但 exact labeled-edge identifiability 在 p.19 被限定为不保证，CAVI calibration 也只与 MCMC 近似；UKB pathway 结构没有可观测真值，且因果/病因意义只由关联和文献案例支持。正文还缺少结构错配模拟、跨 cohort 验证、完整 seeds/hyperparameters、PIP threshold sensitivity 的统一表述。
6. **可迁移规则。** 当 latent structure 同时承担解释和预测时，必须把「结构识别」与「预测效能」分开消融：至少报告组件删除对预测的影响、对结构稳定/冗余的影响，以及一个独立 posterior/calibration 对照；并把 label symmetry、真值不可得和因果范围写进主文，同时在附录提供细节。
7. **适用边界。** 该规则适用于有层级 latent structure、结构标签可交换或真实数据真值不可得的统计/机器学习论文；若任务没有 latent object、没有可定义的结构诊断，或研究目标仅是预测而非解释，则应改用任务特异的机制检验，不能机械套用 Jaccard/PIP/MCMC 对照。
