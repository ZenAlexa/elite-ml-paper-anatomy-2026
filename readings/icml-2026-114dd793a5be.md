## D. 方法与理论

### D.1 形式对象与组件

§3.1–§3.2 先定义 response token activation `A_{y_i}`、prompt/response 串 `xy_{≤i}`、attribute `attr` 和 intervention `Δ_AS`，再把常见 constant steering 写成 `α z_attr`。Prompt steering 的 steered activation 用 `Δ_PS` 表达，并分为全 forward pass 的累积干预 `Δ_PS_acc` 与单层 local 干预 `Δ_PS_loc`。图 1 用 unsteered／prompt-steered activation 的相减展示监督目标；图注明确 PSR 只在 prompt steering 成功诱导目标属性的案例上近似（p.3）。

### D.2 方程与理论项

PDF 中编号公式为 (1)–(8)，均为 displayed equations；另有 regularization `L_reg` 和 relative-RMSE 定义作为未编号、行内或行断公式。由此记录为：公式出现约 10 次；displayed 8 次；numbered 8 次；theorem/lemma/proposition/corollary/proof 均为 0。理论承担的是把 prompt 干预约化为 rank-1 activation intervention 的**表示假设**与解释链，未形成独立保证。

**假设及其边界。** Assumption 3.1 假定累积 prompt intervention 是单方向；Assumption 3.2（作者标为 prior art）假定所有 token magnitude 相同。实证 Figure 2 直接显示 token strength 显著变化，因此作者提出 Assumption 3.2a：magnitude 是 activation-before-steering 的函数，常数形式因而被替换（p.4）。Attention query/key 的 dot-product 只提供机制动机，不是证明。A-PSR 进一步把局部版本迭代到所有层；作者明确承认假设不一定适用于所有层，靠 end-to-end objective 联合优化来减轻噪声传播风险（p.4–5）。

### D.3 S-PSR、A-PSR 与训练

- **S-PSR**：只在一层应用式 (7)，用于观察某层输出如何表示目标属性；即使假设成立，后续层仍可能继续执行 prompt steering，因此不保证全 forward pass 等价（p.4）。
- **A-PSR**：在每层迭代式 (7)，把上一层已 steering 的 activation 作为下一层输入，试图近似整个 forward pass；联合优化每层 `θ_attr,l` 和 `z_attr,l`（p.4–5）。
- **MSE**：S-PSR 最小化干预层及后续层的 MSE；A-PSR 联合最小化所有层 MSE。后续层损失约束单层错误干预不要破坏后续匹配（p.5）。
- **Loglikelihood**：最大化 steered activation 预测 `y′` 的 loglikelihood；不保证中间 activation faithful，但在 rank-1 假设不佳时可能更有效（p.5）。
- **Regularization**：惩罚所有 token 的 `λ` 输出和小于 1，以防 ReLU dead region；AxBench 调参后关闭，因为它尤其损害 MSE 模型（p.5–6）。
- **训练管线**：使用只在目标属性上不同的 prompt pairs `(x,x′)`，从 steered prompt 生成 `y′`，以 `J_attr` 和 `J_coher` 过滤成功且连贯的三元组。训练时令 `α=J_attr`；二元属性可用 0/1，连续 judge 使 λ 负责「是否适合 steering」、judge 分数负责强度。正例训练足够；若纳入正负例，`b_{m,l}` 初始化为 −0.5，使 `J_attr<0.5` 的负例起始为负 steering coefficient（p.5–6）。

## E. 实验设计

### E.1 研究问题与基准

作者在 §5 开头明确列出两个问题（`(1) Does PSR improve steering performance? (2) Are PSR interventions more faithful to prompt steering?`）（p.7）。设计覆盖三类长文本生成 steering：

1. **Persona Vectors**（p.5–6）：每个 trait 20 个 training questions、20 个 evaluation questions；5 条 positive 与 5 条 negative instructions，形成各 100 个正／负 prompt pairs。每个训练 pair 采样 10 个 response，得到每 trait 1,000 个 positive 与 1,000 个 negative triplets。`J_attr` 判断 trait，`J_coher` 用 `gpt-4.1-mini-2025-04-14` 评 coherence；coherence <0.5、正例 trait <0.5、负例 trait >0.5 被过滤。调参用 apathetic/humorous，评测用 evil/sycophantic/hallucinating。模型是 Llama-3.2-3B-Instruct、Llama-3.1-8B-Instruct、Qwen2.5-7B-Instruct；activation 均在 residual stream，Llama-3.2-3B 未有 Chen 层选择，使用 layer 16。
2. **IFEval augmented format**（p.6）：12 类 format instruction 与 14 种 language instruction；后者是数据中同时有 train/test 的 14 种，作者说明 Stolfo 报告 19 种但此版本只有 14 种完整 split。跟随 Stolfo 的 train/eval setup，`J_attr` 是脚本的 binary score，`J_coher` 是适配非英语 prompt 的 coherence judge；所有 steered responses 使用 greedy decoding。非 prompt 方法按 `J_attr(y′)=0` 与 coherence <0.5 过滤，少于 20 个训练例时保留 trait=1 且 coherence 最高的 20 个。此 benchmark 的 `x′` 不由统一前缀构造，所以只在解码 response token 的 hidden states 上 steering。
3. **AxBench**（p.6）：Gemma-2-2B-L20 与 Gemma-2-9B-L20；每个 split 500 个由 residual-stream layer-20 SAE features 随机抽取的 target concepts，每 concept 有 72 train、5 validation、5 test triplets。`y′` 由 frontier LLM 生成而非 subject LLM；沿用 Wu et al. setup/evaluation script；因调参发现 regularizer 损害性能，AxBench 关闭它。

### E.2 架构、目标、位置与 baseline

- **Intervention architecture**：S-PSR、A-PSR 对比 S-Const、A-Const；所有方法作用于 residual stream（p.6）。
- **Training objective**：PSR/Const 比较 MSE 与 LL；Const 另比较 popular difference-in-means（DiM）（p.6）。
- **Intervention positions**：response-only（`R`）与 question+response（`QR`）（p.7）。
- **其他 baseline**：no steering、prompt；IFEval 复现 Stolfo；AxBench 纳入 LoRA、LoReFT、HyperSteer、SFT 等文献结果（p.7）。
- **层选择**：Persona 单层沿 Chen 最有效层，Llama-3.2-3B 用 16；IFEval 沿 Stolfo 最佳层。完整 trait／instruction type 层索引移入 Appendix C（p.6、p.22）。

### E.3 评测指标、控制与缺失项

- Persona 报 `TA@C80` 与 prompt 平均 coherence `TA@Cp`；用 binary search 找到目标 coherence 附近的 `α`，再在上下相邻 coherence 间 interpolate（p.7；Algorithm 1 在 p.23）。
- IFEval 报脚本计算的 instruction-following accuracy `IF Acc.` 和 `J_coher`；为公平比较将 PSR/Const 的 `α` 固定为 1（p.7）。
- AxBench 报 0–2 steering score，是 concept presence、fluency、answer relevance 三个 LLM judge 分数的 harmonic mean（p.7）。
- 有 train/eval 或 train/validation/test split、judge threshold、固定 temperature/top-p、greedy decoding、指定层选择和成功样本过滤。论文没有报告随机种子、每个模型的训练 epoch/batch size/learning rate/optimizer、硬件、总训练预算、推理吞吐或成本；也没有独立的 data-leakage audit 或预注册失败判定。`J_attr`/`J_coher` 的 judge templates 在 Appendix B（p.21），可复现粒度集中于数据构造和评价公式，而非训练系统细节。
- 实验顺序与引言贡献基本对齐：5.1 先性能，再以 5.2 的 activation RMSE 检查 faithful mechanism；但 rank-1 表达边界只在结果文字与 Appendix E.2 说明，没有单独的预先假设表。

## F. 结果、统计与可视化

### F.1 统计口径

论文使用描述性聚合：Persona 的 trait macro-average，IFEval 的 instruction-type macro-average，AxBench 的每概念 harmonic mean。Faithfulness 使用 prompt-steering predictions 上的 mean relative RMSE，分母为 prompt intervention norm；relative RMSE=1 被解释为与 no-steering forward pass 一样 faithful。目标 coherence 的 `α` 用 binary search（区间 0–10，停止条件 `|α_max−α_min|<0.01`）并 interpolation。论文没有报告 seed-level/task-level 离散量、误差条、bootstrap、Bayesian posterior、回归、p-value 或多重比较；正文却使用 “significantly improves” 描述 Persona PSR，未说明对应显著性检验。表格和图注能够说明主要指标，但不能独立恢复训练随机性或不确定性。

### G.2 局限与负面结果

- **假设的普适性** — 结论明确说 rank-1 PSR 的 assumptions 不普遍成立，IFEval 的复杂 instruction 超出 rank-1 表达能力，prompting 仍更强（p.9, §6）。类型：`generality`、`causality`。
- **任务参数结构** — IFEval 的五类 instruction 需要 arguments，而单属性 steering setup 未建模；过滤后的 Table 8 只能说明条件化边界（p.7、p.26）。类型：`data`、`metric`、`generality`。
- **成功条件筛选** — PSR 训练只从 successful prompt steering 的正例（或 judge 过滤后的 triplets）学习；这有助于超越 prompting，却没有测试失败 prompt 分布上的替换能力（p.3 Figure 1、p.5–6 §3.6/§4.1）。类型：`data`、`causality`。
- **维度权衡** — AxBench 2B split 的 A-PSR_MSE combined score 增益来自 concept alignment，同时 answer relevance 从 prompt 的 1.760 降至 1.427；作者在主文提及并在 Table 9 分解（p.9、p.27）。类型：`metric`。
- **coherence 代价** — IFEval 中 activation steering + prompting 常提高 IF Acc.，但部分模型 coherence 下降；表中给出具体 paired values（p.8、p.9）。类型：`metric`、`deployment`。
- **评测范围** — 正文只覆盖 text generation、指定 open LMs、Persona/IFEval/AxBench；没有人类评测、真实部署、长期交互或 adversarial robustness 结果（p.5–8）。类型：`data`、`deployment`、`generality`。
- **统计与计算可审计性** — 没有 seed、variance/error bar、训练预算和硬件报告；“significantly”没有相应检验细节（p.5–9）。这是版面缺失事实，不应解释为作者动机。类型：`compute`、`metric`。
- **伦理范围** — 作者承认 evil 与 hallucinating traits 可能有害，但称选择它们是因为先前工作使用；Impact Statement 只写没有需要特别强调的社会后果（p.6 footnote 7、p.10）。类型：`ethics`。

### G.3 不利信息的呈现策略

以下是版面与文本上可验证的呈现方式，不把它们升级为作者意图判断：

1. **附录迁移**：response-only `R` 结果因位置差异不大而移至 Appendix E.1；完整 IFEval `ConstMSE` 结果也因篇幅省略，移至 Appendix E.2（p.7–8、p.24–26）。
2. **成功条件筛选**：训练分母只保留 `J_attr`/`J_coher` 达标的 triplets；这使学习目标明确对应 successful prompt steering，同时不代表所有 prompt steering 实例（p.5–6）。
3. **分母与聚合**：Persona 使用 trait macro-average，IFEval 使用 instruction-type macro-average，AxBench 使用 harmonic mean；异质性需查附录逐项表格（p.7–8、p.26–27）。
4. **目标 coherence 调参**：Persona 先在 `α` 上 binary search，再 interpolation 到 C80/Cp；这保证比较在 coherence 条件附近，但不等于单一固定 α 的全局性能（p.7、p.23）。
5. **代表性机制图**：Figure 6–9 是两个 sycophantic examples；作者把它们与跨模型／trait 的 Figure 4–5 和 Figure 14 并列，读者仍需区分案例和聚合证据（p.14–20、p.28）。
6. **主文先给 aggregate SOTA，再给维度代价**：p.9 先报告 A-PSR_MSE 在 AxBench 的 combined score，再指出 2B relevance drop；Table 9 把代价留在附录分解（p.9、p.27）。
7. **结果语气的范围化**：IFEval 结果没有被包装成普遍胜出；结论写成 assumptions“不 hold universally”，并保留 prompting 在复杂 instruction 上更强（p.9）。

## K. 最终判断

1. **单一主线**：论文把 prompting 重新写成「对 activation 的、依赖 token 的 intervention」，再用由 activation 预测 λ 的 rank-1 PSR 蒸馏它；constant steering 的等 magnitude 假设被 Figure 2/4/5 诊断为过强，因此 token-specific λ 成为性能与 faithfulness 的共同桥梁（p.3–5、p.14–16）。
2. **正文保留的决策关键内容**：Eq. (3) 的 prompt/activation bridge、Assumptions 3.1/3.2/3.2a、Eq. (7)–(8) 的 PSR、三 benchmark 的数据与指标、Tables 1–3、Figure 3，以及 IFEval rank-1 failure 与 AxBench relevance trade-off 的范围化结论都在正文承担决策作用（p.3–9）。
3. **附录迁移及自足性**：层索引、coherence binary search、response-only/ConstMSE 全表、argument-free IFEval、judge breakdown、跨模型 RMSE 和 vector cosine 被移到 Appendix C–G；正文能支持核心方向，但要复现单层结果、理解 IFEval 边界或解释 AxBench 增益，读者必须回到附录（p.22–30，正文调用见 p.6–9）。
4. **最有效模式**：先用 Figure 1 把抽象的 prompt intervention 变成可计算的 activation difference，再用 Figure 2 的 token heatmap/强度反例破坏 constant assumption，最后用 Table 1–3 的跨模型指标与 Figure 3 的 activation-level RMSE 双重闭环；这使方法动机和实验结果共享同一个 intervention 对象（p.3、p.8–9）。
5. **最大叙事缺口**：rank-1 PSR 的 generality 依赖未经证明的单方向与 activation-decoded magnitude 假设；IFEval 反例说明其边界，但论文没有低秩扩展、组件删除、随机性／计算成本或 adversarial robustness 的完整实验，所以 “faithful activation steering” 仍是条件性结论，而非通用保证（p.4、p.7、p.9）。
6. **可迁移规则**：如果方法声称模仿一个黑盒行为，先把目标行为写成同一状态空间中的可测 intervention difference，再用针对该 difference 的机制诊断和 output-level 结果分别验证；不要仅凭最终分数宣称机制忠实（p.3 Figure 1、p.9 §5.2）。
7. **规则边界**：该规则适用于可在同一模型、同一 token/状态轨迹上计算 counterfactual activations 的 steering/representation 方法；对只提供最终文本、无法恢复中间状态或依赖多属性组合与 argument binding 的任务，rank-1 activation difference 不能自动构成充分的行为等价证据（p.3 footnote 5、p.7–9 IFEval、p.6 AxBench setup）。
