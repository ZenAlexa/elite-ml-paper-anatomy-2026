## 5. 方法与理论

### 5.1 形式化对象、输入输出与目标

- §2.2 首次定义 latent state `h ∈ R^{d_m}`、invertible linear alignment `A(h)=Wh`、causal subspaces `z_var_i`、extra subspace、source/target vectors 与 intervened vector `h_hat`。Eq. (1) 给分块表示，Eq. (2) 给 interchange intervention，Eq. (3) 用 counterfactual label `c` 训练 `A`，模型权重冻结。〔PDF p. 3；§2.2/Eq. (1)–(3)；锚点 “keeping the model parameters frozen”；basis=`explicit`〕
- §4.1 首次定义 matrix null-space 与更一般的 behavioral null-space `N(ψ,X)`；harmlessness 以向量、指定 function 和 mechanistic claim 的关系为对象，不能由向量孤立决定。〔PDF p. 6；§4.1/Eq. (4)；锚点 “behavioral null-space with respect to X”；basis=`explicit`〕

### 5.2 最小逻辑单元与动作转移

1. `setup_notation → instantiate_algorithm`：DAS 把 causal variables 映射到 orthogonal subspaces，再以 interchange intervention 检验 counterfactual behavior。〔PDF p. 3；§2.2；锚点 “subspaces encoding interpretable variables”；basis=`explicit`〕

### 7.2 主要结果与统计处理

1. **Divergence across methods**：Figure 2 的 intervened EMD 高于对应 natural-natural baseline，PCA 亦显示 separation；comparison 涵盖 MDVP、SAE 与 Boundless DAS。作者把结论限制为 divergence 的 presence，没有由此判定方法失效。〔PDF p. 5；§3.2；锚点 “only meant to show the presence of divergence”；basis=`explicit`〕

## 13. 最终判断

1. **单一主线**：causal intervention 可能把 representation 推离 natural support；这类 divergence 的危害取决于 mechanistic claim，behavioral null-space 可提供有限 harmlessness，而 hidden pathways/dormant changes 给出 pernicious existence cases；CL loss 以缩小几何 divergence 作为初步 mitigation。〔PDF p. 6；§4.1；锚点 “harm is inherently claim dependent”; basis=`interpretation`〕〔PDF p. 8；§5；锚点 “minimizing divergence magnitude”; basis=`interpretation`〕
2. **正文保留的决策关键内容**：Figure 2 让读者接受 divergence 不是单一方法特例；§4 的 constructions 改变对 behavior-only intervention evidence 的解释；Figure 3 说明 CL proxy 与 OOD IIA 可能同向改善。〔PDF p. 5；Figure 2；锚点 “not specific to any one method”; basis=`interpretation`〕〔PDF p. 10；Figure 3；锚点 “higher OOD performance”; basis=`interpretation`〕
3. **Appendix 迁移**：proof、sample/layer selection、metric definitions、training recipes、parameter sweeps 与 regression diagnostics 均后移；主线仍能读懂，但 prevalence 与 statistical robustness 的判断依赖 appendix。〔PDF p. 17；§A.2；锚点 “Patch-closure”; basis=`interpretation`〕〔PDF p. 21；§A.6；锚点 “Covariance Type nonrobust”; basis=`interpretation`〕
4. **最有效模式**：Figure 1 的 claim-dependent functional landscape 与 §4.2 的两个 minimal circuits 构成 “visual intuition → exact construction → practical implication” 链；它把抽象的 off-manifold warning 转为可反驳的 mechanism。〔PDF p. 2；Figure 1；锚点 “functional landscape”; basis=`interpretation`〕〔PDF p. 8；§4.2.2；锚点 “hidden context dependencies”; basis=`interpretation`〕
5. **最大未闭合点**：mitigation 只优化 EMD/IIA，没有测 CL 是否减少 hidden-pathway activation 或 dormant context flips；authors 明示 modified CL 不 specific to pernicious divergence。因此 “lower divergence → less pernicious mechanism” 仍是代理链。〔PDF p. 10；§6；锚点 “not specific to pernicious divergence”; basis=`interpretation`〕
6. **可迁移规则**：提出 representation-level failure 时，应把 harm 定义为相对于具体 downstream function 与 scientific claim 的可观察差异，再用一个存在性 construction 和一个真实模型测量分别回答 “can happen” 与 “does happen”。〔PDF p. 7；§4.1；锚点 “specific mechanistic claims”; basis=`interpretation`〕〔PDF p. 5；§3.2；锚点 “in practice”; basis=`interpretation`〕
