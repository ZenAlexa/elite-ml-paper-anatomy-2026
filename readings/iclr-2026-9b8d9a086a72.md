## L. 最终判断

1. **单一主线**，论文把迭代 optical flow 的全／部分 cost volume 替换为 current-flow 驱动的高分辨率 feature-space warping，再用 transformer recurrent update 隐式提供 long-range dependence；由此同时瞄准 cost-volume memory bottleneck、低分辨率边界误差和 custom flow-specific design。（证据：PDF p1、p3–6、p9。）
2. **正文保留的决策关键内容**，cost-volume 的形式对照与 Table 1 memory profile；Warp 公式；input encoder／DPT updater／MoL loss；T=5、训练 schedule；Tables 2–5 的 benchmark、zero-shot 和 matched direct/iterative、DPT/CNN、warp/no-warp 消融。（证据：PDF p4、p6–9。）
3. **移入附录的细节及影响**，只把 Sintel sequence-wise Table 6 和 Ambush1 分析移入 p14；没有把方法或超参数大块隐藏。若只读正文，能理解方法和主要 aggregate，但会低估 Ambush1 对 full Final average 的不利影响。（证据：PDF p8、p14。）
4. **最有效的写作／图／表／公式模式**，把一个结构替换拆成“资源问题（Table 1）→可视化后果（Figure 3）→形式定义（Warp 公式）→机制消融（Table 5）→跨 benchmark 结果（Tables 2–4）”；其中 Table 5 以同一首行作为参照，读者能逐项定位变化。（证据：PDF p4–9。）
5. **最大叙事缺口**，摘要和引言的宽泛 SOTA/rank 语言没有始终与 metric/split 对齐；结果混用不同预训练 backbone 和 submission protocol；Sintel Final 的 full-average 不利项被放在附录；缺 seed、variance、区间和 formal theory。上述是范围与识别不足，不是仅靠“显著”措辞可补齐的证据。（证据：PDF p1、p7–9、p14。）
6. **可迁移规则**，当论文删除一个被视为必要的表示时，必须把资源 profile、保持 backbone／训练条件的替代对照、组件消融和不利分层结果放在同一可追溯链中，并在主张中显式写出 metric、split 与 checkpoint 边界。（证据：PDF p4、p7、p9、p14。）
7. **适用边界**，该规则适用于“表示替换＋效率／精度”是中心贡献的视觉系统；若要外推到真实部署、鲁棒性或普遍理论保证，还必须补充跨硬件／输入分辨率、seed 重复、失败分层、统一训练和独立数据控制。（证据：PDF p4、p7–9；这些项目在正文未提供。）
