## 方法与理论

### 方法的最小逻辑单元

`state_problem → setup_notation → derive → define_component → explain_mechanism → instantiate_algorithm → contrast_alternative → connect_to_experiment`

1. **共同程序**：Section 2 以 target、proposal、当前 state、auxiliary variable `ω` 和 estimator `R_{θ→θ′}` 定义单变量 transition；Equation (1) 是逐点平衡条件，Proposition 1 由此推出 estimator 无偏且 kernel reversible。[pp.2–3, Section 2, “Then R is unbiased”, explicit]
2. **双变量接口**：Section 3.1 的输入是 target `Π`、initial `θ0`、proposal family `{q_{ω1}}`、两个 simulators `S1` 与 `S2` 和迭代次数 `T`。`ω1` 只依赖当前 `θ` 并决定 proposal；`ω2` 依赖 `(θ, θ′, ω1)` 并帮助估计 target ratio。输出是边际链 `θ_0:T`，目标是 `Π` 的可逆性。[pp.3–4, Section 3.1, “two simulators”, explicit]
3. **Algorithm 1 的机制**：接受率含 `Π(θ′)P_{θ′,θ}(ω1,ω2)q_{ω1}(θ′,θ)` 与对应分母。作者说明昂贵的 `Π(θ′)/Π(θ)` 部分可经 `P` 的比率抵消。Proposition 2 证明此 general framework reversible；证明在 Appendix B.3，不在正文。[pp.3–4, Section 3.1, “offset by … by design”; pp.15–16, Appendix B.3, explicit]
4. **三种实例化**：Case 1 无 `ω1`，回收 exchange/PoissonMH/TunaMH；Case 2 令 `ω1=ω2`，形成 Metropolis-within-Gibbs 解释并用于 Locally Balanced PoissonMH；Case 3 令两个变量独立，把 gradient proposal 与 ratio estimation 分开，生成 Tuna–SGLD。[pp.4–6, Sections 3.1–3.2.2, explicit]
5. **新算法**：Algorithm 2 用 Poisson minibatch 的 proxy gradient 定义 Poisson–MALA 与 Poisson–Barker；Algorithm 3 用独立均匀 minibatch 的 SGLD proposal，加 TunaMH 型 ratio correction。正文把 Algorithm 3 明示为 fixed-step SGLD 的 Metropolized version。[pp.5–6, Sections 3.2.1–3.2.2, “Metropolized version of SGLD”, explicit]

方法图和方法表均未出现。正文有三个算法框：Algorithm 1（p.4）传达 general reversible transition，Algorithm 2（p.5）传达 `ω1=ω2` 的 locally balanced PoissonMH，Algorithm 3（p.6）传达独立 gradient minibatch 与 Tuna ratio minibatch。Appendix A/C/D 再给 Algorithms 4–9 和具体 sampling/implementation。[pp.4–6; pp.12–25, layout_observation]

## 最终判断

单一主线是：把“目标或其梯度昂贵”重写为一个辅助变量的模拟与抵消问题，再让第一个辅助变量指导 proposal、第二个变量校正 target ratio，从而在精确 stationary distribution 的条件下使用 minibatch gradient proposal。

主文最有效地保留了共同程序、Algorithm 1 的接受率、两种新算法、从 `Paux` 到 `PMwG/Pideal` 的理论比较、三组主任务的核心表图和明确限制。附录承载 formal proofs、bounds、Poisson thinning、proposal sampling 推导与大部分 sensitivity results；这种迁移让 9 页主文保持决策链清晰，同时使严格验证要求跨页读取。

最强的写作模式是每次方法扩展都绑定到一个可检验对象：Section 2 的 common procedure 绑定 Proposition 1，Section 3 的双变量框架绑定 Proposition 2，Section 4 的 performance comparison 绑定 Theorem 1/2 与既有算法 propositions，Section 5 绑定相同机制在 three task families 中的 clock-time evidence。

最大读者成本来自两处：Theorem 2 与全部证明不在正文，完整 rate-by-rate 结果与 Figure 3 也在附录；主表的 `Best` aggregation 还压缩了 tuning heterogeneity。论文已经在 Section 6、SGLD plateau、Poisson–MALA 0.25 率表现和 HMC 失败处提供了可见反证信息。

可迁移规则：当一个统一框架承担抽象贡献时，把每个新增自由度映射为一个明确的计算角色、一个保持目标分布的条件性证明和一个与该角色对应的经验比较。

适用边界：该规则要求形式条件、估计器与成本模型可实际检查。本文自身依赖可得且足够紧的 bounds、i.i.d. likelihood、调参策略和受控 benchmarks；不应把现有时钟时间优势外推到 non-i.i.d. 或弱 bounds 的模型。[p.9, Section 6; pp.12–13, Algorithms 5–6 `Promise`, explicit]
