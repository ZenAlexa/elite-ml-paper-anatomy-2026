### E.2 DMS 的核心机制

1. **Archive 与 emitters。** DMS 保留 MAP-Elites 风格的 per-cell elite，不在 archive 中保存 discount 或 threshold；CMA-ES emitters 以 `N(θ*, Σ)` 采样，并按 `Δ_i` 排序更新 `θ*`、`Σ` 和内部参数 `p`。CMA-ES 收敛后，从 archive 随机解重启并恢复 `Σ ← σI`（p.5–6，Sec.5，`explicit`，锚点为 “DMS maintains a MAP-Elites-style archive”）。
2. **Discount model。** `\hat f_A` 是可替换的 neural network：低维 measure 可用 MLP，image/text measure 可换 convolutional network 或 transformer。实际实验除 LSI 外使用三层 `[k,128,128,1]` MLP；LSI 先用 CLIP ViT embedding 到 512 维，再使用 `[512,128,128,1]` MLP（p.5、p.30，Sec.5/C，`explicit`，锚点为 “The primary component of DMS is its discount model”）。
3. **训练目标。** 对 emitter solution 的 measure `s=m(θ)`，模型当前输出低于 objective 时使用线性更新目标；objective 不超过模型输出时保持当前 discount。这样目标复现 CMA-MAE threshold 的“探索过的区域逐渐提高 discount”行为，但用连续模型取代 cell histogram（p.6，Sec.5，`explicit`，锚点为 “this target aims to slowly increase the discount values”）。
4. **Empty points。** 每轮从未占用 cell 中无放回抽样 `n_empty` 个 centroid，目标固定为 `f_min`，把未探索区域压回最低 objective。作者说明没有这些点时，模型会在未观测区域产生任意高值，发射器会误以为那些区域已经探索（p.6、p.34–35，Sec.5/Appendix D，`explicit`，锚点为 “To prevent this issue by ‘clamping down’ the discount model”）。
5. **两阶段循环。** 第一阶段用 emitters 生成并插入 elite；第二阶段收集 `D_A`（emitter samples 加 empty points），在最多 5 个 epoch 内以 MSE 训练模型，默认平均 loss cutoff 为 0.05，实践中通常 1 个 epoch 即达到。Algorithm 1 的循环层级是 `iteration → emitter → batch sample`，并在每轮末尾训练 discount model（p.6–7、p.30，`explicit`，锚点为 “DMS performs two phases”）。

### F.2 Domain 细节

- **LP。** `n=100`；`k∈{2,10}`，另有 Sphere 的 20D/50D；measure 将 contiguous blocks 的 clipped solution values 求和，`r=n/k`。Sphere、Rastrigin 取负值转为 maximization，global optimum 平移到 `θ_i=2.048`，objective 归一化。Flat 恒为 1，用于纯 diversity optimization（p.7、p.35–37，`explicit`）。
- **Arm Repertoire。** 100-joint planar arm，measure 为 forward-kinematics 的二维 end-effector position，objective 为 `−var(θ)+1`（p.7、p.37，`explicit`）。
- **TA。** 30 个 grayscale triangles，每个 8 参数，总 solution 维度 240；rendered measure 为 28×28=784 维图像；从 MNIST 或 Fashion MNIST 抽 1,000 图像作为 CVT centroids；按 Euclidean distance 分配，objective 为对 centroid 的 negative MSE 加 1（p.7、p.37，`explicit`）。
- **LSI (Hiker)。** StyleGAN3 的 pretrained `stylegan3-t-ffhqu-256x256.pkl`，solution 是 512D `w-space` latent；measure 是 256×256×3 RGB image；从 LHQ256 抽 10,000 landscape centroids；以 CLIP ViT-B/32 score 做 assignment。objective 为 prompt CLIP、centroid CLIP 的平均值减去 latent 分布外的 L2 penalty（p.8、p.38，`explicit`）。

## L. 最终判断

1. **单一主线。** 论文的唯一因果主线是：高维 measure distortion 让 CMA-MAE 的离散 histogram 把相近解压到同一 discount；用 smooth neural discount model 加上未占用 cell 的 `f_min` 约束恢复 archive-improvement 方向，从而扩展 QD 到 dataset-defined image measures（p.2、p.5–7、p.9，`interpretation`，锚点为 “a smooth, continuous representation of the discount function will enhance exploration”）。
2. **正文保留的决策关键内容。** 正文保留 problem formulation、CMA-MAE failure mechanism、DMS 的 Eq. (1)/Algorithm 1、QDDM 的两个 domain 定义、Table 1 主结果、Welch/Games-Howell 统计选择、Table 2 计算代价以及主要 limitations；这些对象足以让读者理解为何要换 histogram 和性能结论的范围（p.3–10，`layout_observation`/`explicit`）。
3. **移入附录的细节及其代价。** 超参数、完整曲线/误差、heatmap、pairwise 表、α/empty/restart 消融、domain 公式、nearest-neighbor 实现和硬件细节移到 p.19–39。迁移保留了正文叙事的可读性，但使统计细节、训练设置和 QDDM objective 的完全复现依赖附录；正文仍能做方向性判断，不能独立重建所有运行（p.9、p.29–39，`interpretation`）。
4. **最有效的模式。** Fig.1 把同一 failure mode 画成 CMA-MAE 与 DMS 的并排机制对照；Algorithm 1 将模型训练和 archive 更新放在同一循环；Table 1 先给全 domain 的两项决策指标，Appendix Fig.8/11 再把 discount model 的空间输出与性能变化连接起来（p.2、p.6、p.8、p.26、p.34，`interpretation`）。
