### 5.2 形式对象、公式与理论

- **输入/状态/输出**：输入是 RGB 图像 `I ∈ R^{W×H×3}` 及其 `fx, fy`；resize 后为 `I′ ∈ R^{W′×H′×3}`，其中 `W′ = (f_uni/fx)W`、`H′ = (f_uni/fy)H`；再把 marker 叠加到查询像素，通过文字输出距离（p.6–7 §3.4）。
- **假设**：图像无畸变并遵循 pinhole camera model；f_uni 默认 1000 pixels。该假设是实际方法的输入边界，不是 theorem 前提（p.6 §3.4）。
- **训练目标**：标准 next-token prediction 与 text-token cross-entropy；没有 dense prediction head、regression loss 或 regularization loss（p.6 §3.4）。
- **显示公式**：1 个无编号的 resize 公式组（p.6–7 §3.4）；编号公式、theorem/lemma/proposition/corollary 与 proof 均未出现。理论对象总数为 0，唯一公式归为 `core_chain`，不承担保证。
- **复杂度与不变量**：论文没有给训练/推理复杂度、循环层级或伪代码不变量；Figure 6 只传达「统一焦距 → marker → 文字问答 → 距离」的数据流（p.6 Figure 6）。
- **理论角色**：可证明理论未出现；方法中的 pinhole resize 是机制化实现，Figure 2/4/5 与 Table 1/2/3 承担经验预测检验。Figure 7 传达任务覆盖，理论保证未给出（p.7 Figure 7）。

### 8.2 负面结果与明确限制

- **直接负面比较**：Text coordinates、intrinsics in text、predicted ray、纯视觉错误尺度、基线 VLM 低 δ1 均保留在正文图表；例如 Table 1 的 GPT-5 .370 与 Ours 3B .824 同表呈现（p.8 Table 1）。
- **形态上的不利信息**：Figure 8 承认 DepthLM 在平滑区有稍高噪声，纯视觉模型的 smooth surfaces 在非边界区域有优势（p.9 Figure 8）。
- **显式 scope 限制**：结论称论文聚焦 VLM 的“simplest and most important design”，并把更细粒度策略留作未来工作（p.10 §5）。限定类型为 `scope`、`generality`。
- **数据/泛化限制**：未来方向是 data filtering 后加入更多数据集，以及用 diverse/complementary tasks 增强泛化；训练集与评测集有同名数据集但 scene 声称不重叠（p.10 §5；p.3 §3）。限定类型为 `data`、`generality`。
- **相机模型假设**：最终 resize 依赖 `fx, fy`，并假设无畸变 pinhole camera；论文没有交代缺少 intrinsics 时如何部署（p.6–7 §3.4）。限定类型为 `assumption`、`deployment`。
- **基座/架构边界**：12B Pixtral .771 低于 3B/7B 默认架构，正文明确说 base model performance matters；跨架构有效性是合理精度，未达到统一最佳性能（p.8 Table 1 解释）。限定类型为 `generality`。
- **未报告的边界**：seed 方差、失败样例全集、推理吞吐/逐像素成本、显著性和误差表达均 `not_present`；Figure 8 只有六个可视案例，不能替代失败分布（p.8–9 Tables 1–2/Figure 8，p.3 Analysis Setup）。

## 12. 最终判断

1. **单一主线。** VLM 的 metric-depth 差距被拆成像素定位与跨相机尺度两个可操作瓶颈；把坐标改成图上 marker、把图像按 intrinsics 统一焦距，再用普通 text-SFT 学稀疏数值，即可从 3B VLM 得到 .824–.838 的八集 δ1，并将同一文本接口扩展到六类 3D 任务（p.4–8 §3.1–§4、Table 1）。
2. **正文保留的决策关键内容。** 主文保留四个 Finding、Figure 2–5 的控制曲线、resize 公式、Implementation 预算、Tables 1–3 的平均结果和 Figure 8 的形态解释；这些对象分别回答“像素指向、训练方式、相机尺度、标签密度、能力上限、形态差异”（p.4–10）。
3. **移入附录的细节及自足性。** marker 样例、精确数据分配、cross-dataset SFT/GRPO、GRPO 与模型超参数、相机 prompt、逐数据集多任务表被移入 A.1–A.7；正文仍能做主要决策，但复现 GRPO/相机 prompt 和识别任务异质性需要回看附录（p.14–15）。
4. **最有效的写作/图表/公式模式。** 最有效的是“先把替代解释做成小规模诊断，再把每个 Finding 映射为最终方法部件”：Figure 2/4/5 使用简单、可读的 δ1 曲线，Figure 6 把流程压成一条数据流，Table 1/2/3 统一比较对象；无编号 resize 公式足以说明核心变换（p.4–8）。
5. **最大叙事缺口。** “无需 architecture/loss”与“camera ambiguity 已解决”的因果范围超出直接识别：没有添加 head/loss 的反事实、没有 intrinsics 缺失时的部署实验、没有 seed/误差/失败分布，而且 Table 2 的 UniDepthV2 仍比 Ours 高 9.2%（p.6–8）。
6. **可迁移规则。** 把统一模型的每个强主张拆成可替代因素，并在正文给一张最小控制图、一个机制公式和一个跨基线表；将复现 prompt/超参数/逐单元异质性放附录但用一句正文调用（p.4–8、p.14–15）。
7. **适用边界。** 该规则适用于“模型接口统一但输入坐标/尺度可能混淆”的视觉任务；若关键 intrinsics 不可得、相机不满足无畸变 pinhole、任务需要 dense output 或要证明全面超越最佳专家模型，则需额外部署、失败与共同评测证据，不能从本论文的 δ1 平均和六个可视案例直接外推（p.6–9）。
