### 形式对象、假设与理论边界

- 输入是 image、含部分 object 的自然语言 prompt 和模型隐状态；输出通常是下一个 object 的 color/shape 或 spatial-relation answer。位置 ID 被当作空间索引，目标 features 与 ID 在阶段间分离（pp.3–4，Secs.3.1–3.2，`explicit`）。
- RSA 的 model RSM 由跨 trial activation 的 cosine similarity 构成；position target 使用归一化 Euclidean distance，feature target 是 color/shape equality 的平均。该协议在 Appendix A.2 给出 Eq. (2)–(5)（p.16，`explicit`）。
- CMA 的假设是 patching 某类 head 会让模型输出对应的 counterfactual answer；分数来自 logits 差分，50 samples 做平均。它提供局部因果中介证据，不是全模型的形式保证（p.5，Sec.3.4，`interpretation`）。
- 论文没有 theorem、lemma、proposition、corollary 或 proof，也没有复杂度界。`theory` 模块为 `not_present`；机制解释属于 `core_chain` 与 `diagnostic`，不是独立理论保证。

### 公式、图与表承担的任务

- Eq. (1), p.5：CMA score，连接 clean/modified/patched context 与期望 token logits，承担 head 识别的核心因果量。
- p.8 干预式：`õ_h(x) = o_h(x) + α (d_t − d_o)` 与 ID prototype 平均，定义 position-ID steering；另有 visual-patch key swap 和 cross-task ID injection。它们把“ID 是可操作变量”推进到行为结果。
- Eq. (2)–(5), p.16：分别定义 position、color、shape、combined feature RSM，补足 RSA 可复现细节。
- Figure 1, p.4：同一版面并列架构、PCA、RSA 与 CMA，把表征顺序和因果 head 定位放进一张闭环图。Figure 2–7 继续按相对/绝对编码、PUG、localization、cross-task reuse 和 entropy/error 排列。

### 统计与可视化边界

论文实际使用的中心量是 Pearson RSA、CMA logits score、accuracy/proportion correct 和 mean accuracy；没有报告离散量、区间、假设检验、多重比较、bootstrap、Bayesian analysis、regression 或 correlation beyond RSA。图注通常能说明任务和阶段，但 Figure 5、Figure 7、Figure 46 的具体柱值主要留在图形读取，Table 1 独立可读（pp.4–10、16、30–32，`layout_observation`）。

统计推断、实质意义与机制证据被部分区分：干预的 before/after 行为变化给出实质效果，CMA 与 representation 提供机制支持，作者没有给显著性检验。正文的 `>79% efficacy`、`significantly improved` 和“directly traced”语气强于不确定性呈现；这使机制方向清楚，读者需要回到 Appendix 才能看到模型级曲线和 binding patch 表（pp.8–9、25–32，`interpretation`）。

## 最终判断

1. **单一主线**：论文把 multi-object visual binding 还原为 content-independent spatial indexing。Prompt object 先经 ID retrieval heads 取回位置索引，ID selection heads 选中 target，feature retrieval heads 再从 image patches 取回语义 features；PCA/RSA、CMA、ID steering、key swap 和 entropy patch 依次把表征、局部因果与行为错误串成一条线（pp.3–10，Secs.3–4，`interpretation`）。
2. **正文保留的决策关键内容**：scene description 定义、三阶段架构、Qwen2-VL 的阶段证据、CMA score 和 head layers、PUG `>79%` intervention、relative/absolute 方向、patch localization、spatial-reasoning reuse 与 entropy failure（pp.3–10，`explicit`）。
3. **移入 Appendix 的细节及影响**：数据生成、RSA 数学定义、CMA 条件图、全模型热图、relative/absolute 全量图、entropy 全模型图、α/K sweep、COCO、counting 和 Table 1 均后置。方法可理解性保持完整，模型级广度、数值复核和 error-repair 因果强度依赖 Appendix，正文自足性因此为“机制主线自足、广度与统计边界需回查”（pp.11、14–32，`interpretation`）。
4. **最有效的模式**：Figure 1 将架构、PCA、RSA、CMA 置于同一视觉闭环；随后用 position swap、feature swap、task transfer 和 high→low entropy patch 将抽象 ID 变成可操纵对象。公式数量少且都连接具体干预，减少了理论与实验之间的跳步（pp.4–8，`interpretation`）。
5. **最大缺口**：没有独立 theory/complexity guarantee；emergentness 的架构偏置与训练分布尚未区分；模型级图表缺少不确定性；relative 结论受 family 差异、COCO 的模型派生 order、counting 的单一 best model 和 spatial reasoning ceiling 限制（pp.6、9–10、27–32，`interpretation`）。
6. **可迁移规则**：把每个机制主张绑定到一个可命名的表征预测、一个局部 counterfactual intervention 和一个行为任务，并在同一图或相邻图中显示三者的方向一致性（pp.4–9，`interpretation`）。
7. **规则边界**：该规则适用于具有可 patch 隐状态和明确对象/关系任务的 generative VLM；对不可访问内部 activation、没有独立对象标签或需要开放世界 grounding 的系统，position-ID 对应关系和 intervention 可识别性需要另设验证（pp.7、29–30，`interpretation`）。
