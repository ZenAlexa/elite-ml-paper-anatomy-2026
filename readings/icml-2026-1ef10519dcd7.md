## 3. 引言的论证推进

### 段落动作链

1. **`context → problem`**：用 continuous-distribution sampling 与 gradient access 提出 `polylog(1/δ)` 是否可能。〔p. 1，§1，explicit，`“What is the complexity”`〕

3. **`failure_of_prior_work`**：无 density evaluation 时，SDE discretization bias 阻断 high accuracy；PDMP 是窄例外。〔p. 1，§1，explicit，`“precludes high-accuracy guarantees”`〕
4. **`context → missing_insight`**：把问题落到 diffusion reverse process，现实训练的产物是 score，不包含 density。〔p. 1，§1，explicit，`“only learn the score function”`〕
5. **`state_problem`**：式 (1) 把目标写为 discrepancy、target accuracy、score error 和 approximation factor 的关系。〔p. 1，§1，explicit，`Eq. (1)`〕
6. **`failure_of_prior_work`**：minimal assumptions 下 DDPM 为 `1/δ²`，且 DDPM 有 `Ω(1/δ)` 下界，提示必须换算法。〔p. 2，§1，explicit，`“motivates changing the algorithm”`〕
7. **`failure_of_prior_work`**：higher-order 方法降低幂次却保留 order/parameter 的隐式指数代价，未达到 polylog。〔p. 2，§1，explicit，`“fall well short”`〕

## 5. 方法与理论：最小逻辑单元

### 形式化对象与因果链

1. **目标与接口。** §2 从 DDPM forward process、true backward kernel `ρk` 和 score error `ε²k,score` 开始；输入是 approximate scores 与 schedule，输出是对 early-stopped `p1` 的 sample。〔p. 4，§2，explicit，`Eq. (3)`、`Eq. (4)`、`Definition 2.1`〕
2. **抽象子问题。** §3 将单步问题化为 Gaussian tilt `ν(x) ∝ exp(-f(x)-‖x-x0‖²/(2η))`，只能 query `∇f`。〔p. 5，§3，explicit，`Eq. (7)`〕
3. **关键转换。** §3.1 先用 `f(x)=E[xf′(y)]` 把 function value 转为 unbiased derivative estimate，再用 Poisson/Taylor Bernoulli factory 生成接受随机性；Algorithm 1/FORS 正式执行有界 estimator 的 rejection sampling。〔pp. 5–6，§§3.1–3.2，explicit，`Eq. (8)`；`Algorithm 1`〕
4. **从局部线性化到低维路径。** 用 Gaussian proposal 加 path-integral `Wr,z,x` 重写 tilt correction；sin/cos path 使需要的条件从 `βdη` 改成 `β√dη` 型，并放宽为 Hölder `s∈[0,1]`。〔p. 7，§3.2，explicit，`Eq. (9)`–`Eq. (11)`；`“better dimension dependence”`〕
5. **从子程序到 diffusion。** Algorithm 2 对每个 reverse DDPM transition，以 score-guided Gaussian proposal 加 FORS corrector；`d⋆` 将数据几何压缩进 schedule condition。〔pp. 7–9，§§4–4.2，explicit，`Algorithm 2`；`Definition 4.1`〕
6. **全链条误差。** Theorem 4.3/4.9 以 chain rule 汇总 terminal error、每步 clipping/kernel error 和 `Σηk ε²k,score`；Appendix F 给出对应分解。〔p. 9，Theorem 4.3；p. 11，Theorem 4.9；p. 37，§F.2，explicit，`“chain rule for the KL divergence”`〕
7. **第二应用。** §5 观察 RGO 也是 Gaussian tilt，将 Algorithm 3 的每个 RGO 调用用 FORS 实现，Theorem G.1 给 PI/LSI/log-concave 条件下的 query bounds。〔pp. 11–12，§5；pp. 42–43，§G，explicit，`“RGO is exactly a Gaussian tilt”`〕

**方法动作转移序列**：`setup_notation → state_problem → derive → define_component → explain_mechanism → instantiate_algorithm → state_complexity → connect_to_prediction → connect_to_experiment(not_applicable) → summarize`。其中最后一个 experimental connection 在本文不适用。结论明示没有 implementation/evaluation。〔p. 12，§6，explicit，`“left for future work”`〕

## 11. 最终判断

1. **单一主线。** 论文把「无法做 density-based rejection sampling」转换为「能否以 gradient 查询构造有界、无偏的 tilt correction」：FORS 给出该 correction 的采样器，再逐步校正 diffusion reverse kernel，并把同一 Gaussian-tilt primitive 复用到 RGO。〔pp. 5–8，§§3–4；pp. 11–12，§5，interpretation，`“simulate rejection sampling”`；`“RGO is exactly a Gaussian tilt”`〕
2. **正文保留的决策关键内容。** 正文保留问题的接口约束、三段算法、`d⋆` 定义、Theorems 3.1/3.3/4.3/4.9 的 statements、log-concave representative bounds 与明确的「未实现/未实验」边界；这使读者能判断主张范围，不必先读证明。〔pp. 5–12，explicit，`“FORS guarantee”`；`“left for future work”`〕
3. **被移入附录的细节及代价。** clipping/coverage tails、`d⋆` moment bounds、single-step KL optimality 与全链 proof 进入 B–F；完整 log-concave theorem 在 G，且一段 proof omitted。迁移没有损害 headline 的可读性，却使 theorem verification 和 exact-proximal boundary 不能仅靠正文完成。〔pp. 21–43，layout_observation，`“Proofs”`；p. 43，explicit，`“Proof … omitted”`〕
4. **最有效的表达模式。** 先用一维 Bernoulli-factory toy derivation（p. 5）说明机制，再立即给 Algorithm 1 和 theorem；随后通过「same Gaussian tilt」把 mechanism 接到 diffusion/RGO。这比先列复杂度更容易让读者识别真正的新 primitive。〔pp. 5–7，interpretation，`“We motivate our approach”`；`“General path integral”`〕
5. **最明显的未闭合点/读者成本。** 论文没有经验评估；log-concave formal extension 假设 exact proximal point 且省略 proof；「all previous results」的横向比较没有统一表或共同 metric。它们不否定 theorem，但使部署可行性、prox solve 成本与跨工作可比性仍需读者自行核验。〔p. 12，§6；p. 42，§G；p. 16，§A.1，explicit，`“future work”`；`“assume … zero”`〕
6. **可迁移规则。** 对理论算法论文，若新能力来自一个可复用 primitive，先用最小 toy problem 证明该 primitive 的接口与精确性，再把它作为现有主链的局部替换，并把 end-to-end error 用明确加和项连接起来。〔pp. 5–9，§§3–4，interpretation，`Eq. (8)` → `Algorithm 1` → `Theorem 4.3`〕
7. **规则边界。** 只有当 primitive 的假设和误差能在应用链中可控时，此模式才成立；这里 bounded estimator/clipping、early stopping、score-error norm、non-uniform Lipschitz 条件和 exact/accurate proximal solve 都是不可省略的前提。〔pp. 7、9–11、21–23、42，explicit，`“Assumption 3.2”`；`“Assumption 4.8”`；`“assume … zero”`〕
