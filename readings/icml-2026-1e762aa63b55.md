## 4. 方法、理论与实验设计

### 最小逻辑单元

`setup_notation → define_component → contrast_alternative → state_problem → derive → explain_mechanism → connect_to_experiment`。

- **对象与状态**：训练序列为 `S = {D_i, J_i}`，`θ_i` 由此前阶段初始化；`D_pre → D_mid → D_target` 是工作框架。midtraining 被定义为 pretraining 和 posttraining 间的中间阶段，并保留 general pretraining data 的 mixture。continued pretraining 是 general-data mixture weight 为零的极限。[p. 2，§§2.1–2.2]
- **目标与遗忘量**：`J_P(θ)` 是 pretraining population loss，`J_T(θ)` 是 SFT loss；后训练从 `θ_0(t,w)` 出发，遗忘定义为 `Δ_P(K)=J_P(θ_K)-J_P(θ_0)`。[p. 2，§2.3 / Equation (1)]
- **机制拆分**：Equations (2)–(5) 将 forgetting upper bound 写成 posttraining-path 的 gradient alignment/conflict 项和以 `J_T(θ_0)-J_T*` 表示的 energy/effort 项。本文的“bridge”解释由更低的 target initialization loss 和较少后期工作连接起来。[p. 3，Equations (2)–(5)]
- **实验可观测 proxy**：proximity advantage `PA(M→T)=prox(M,T)-prox(C4,T)` 是 unigram token 统计的 model-agnostic diagnostic；它替代了理论中的梯度量，因而是关联性 proxy，不是 gradient alignment 的直接量测。[p. 4，`Proximity advantage` / Equation (6)；interpretation]

### 实验设计与复现粒度

- **预训练控制**：Pythia 70M、160M、410M、1B 均从 C4 训练 128B tokens（约 61k steps），cosine schedule、max LR `3e-4`、AdamW；C4-only continuation 是相同 token budget 的 control。[p. 3，§3.1]
- **midtraining 处理**：Starcoder、Math、FLAN、KnowledgeQA、DCLM 五个 mixture；Table 1 给出 196B、12B、3.5B、9.6B、51B source-token 量。正文说明 starts 为 Starcoder 6k、Math 20k、其余 40k steps，目的是防止 repetition。[p. 3，Table 1 / §3.1]
- **后训练与结果单位**：GSM8K、SciQ、Pycode（CodeSearchNet-Python）、LIMA；主文用 target validation loss 作为 adaptation，用 held-out C4 cross-entropy loss 作为 forgetting。主文称每个 checkpoint 的结果经过 hyperparameter search 后平均 5 seeds。[p. 4，§§3.1、4；p. 5，Table 2]
- **附录给出的实现细节**：L40S GPUs、LitGPT、batch/rank/precision、四个 SFT dataset 的样本数、4 epochs、warmup、LR grid 与各模型最终 LR 都在 p. 16。GSM8K 只 mask prompt/question；其他 loss 覆盖 full sequence。[p. 16，Tables 4–7 / §§B–C]
- **控制与缺失**：给出了 held-out C4 和防止 data repetition 的描述；没有给出随机 seed 值、run-level losses、data-contamination audit 或 mean 比较的显著性检验。后两项在所读主文和附录页中均未出现。[pp. 4–5，§4 / Table 2；p. 16，§§B–C；layout observation]

## 6. 消融、负面信息与限制

### 消融与负面结果

- **timing/weight sensitivity**：§6 是唯一明确的参数 grid；它测试两者是否独立、后期是否可由更高 mixture 补偿，并把失败描述为 `Compensation through increased mixture fails`。[p. 6，§6]
- **temporal ablation**：Figure 5 随 pretraining checkpoint 追踪同一 20% Starcoder family，区分 immediate in-domain effect 与迟发 C4 retention。[p. 7，Figure 5]
- **domain heterogeneity / mismatch**：所有 midtrain × SFT 组合使 mismatch 作为负例出现；Figure 3/§4 将这些点与 aligned pairs 一并保留。[pp. 4–6，§4 / Figure 3]
- **alternative mechanism condition**：Table 3 将 retained general mixture 与 100% specialized continued pretraining 对照，识别目标是 mixture 的价值；由于 start time 也变化，识别仍不纯粹。[pp. 5–6，§5.2 / Table 3；interpretation]
- **mechanism probe**：§7 以 CKA 检查较少 late-layer change；它是诊断性附加结果，不是删除组件的 ablation。[pp. 7–8，§7]
- **未出现的项目**：没有 component-removal algorithm、没有 compute-cost table、没有 human evaluation、没有 separate failure-case section。[pp. 1–24，full-PDF layout observation]

## 8. 用词、修辞与包装

- **高频论证动作**：摘要使用 `propose`、两次 `find`、两次 `suggests`；主文以五个紫色 `Finding 1`–`Finding 5` 框把经验结论固定在 §4–§7。结论使用 `We demonstrate`，将语气抬升到全篇总结。[p. 1，Abstract；pp. 4–8，Findings 1–5 / §9]
- **强弱主张的分工**：domain-specific loss、continued-pretraining comparison、timing interaction 用 `yields`、`outperforms`、`fails`、`demonstrate` 等强动词；distributional bridge、gradient conflict、plasticity window 与任何 phase transition 的因果解释则多用 `appears`、`suggests`、`consistent with`、`may`。强断言落在比较结果，弱断言留给机制与外推。[pp. 1–2，Abstract / §1；pp. 3、7–8，§2.3 / §§7–9]
- **高频名词不是模板填充**：`midtraining`、`pretraining`、`posttraining`、`distribution`、`mixture`、`forgetting` 和 `initialization` 反复出现，并分别连接定义、理论 bound、控制处理与结果；`bridge/bridging` 是全篇的叙事枢纽。[pp. 1–8，Abstract / §§1–9]
- **包装方式**：标题直接给出唯一因果主线；首页 Figure 1 先提供几何直觉，随后 Table 2/3 和 Figure 3/4 提供决策证据。简洁的 `Finding` 框提升扫读性，但也把复杂识别条件压缩到正文、脚注和附录。[pp. 1、5–7，Figure 1 / Tables 2–3 / Figures 3–5；layout observation]

## 9. 最终判断

1. **单一主线**：midtraining 的价值在于把 general pretraining distribution 与目标 posttraining distribution 之间的跳变改成混合的中间桥；较好的 initialization 关联到更低 target loss、较少 C4 forgetting 和较小 late-layer representational change。[pp. 1–8，Abstract / §§2.3、4–9]
2. **正文保留的决策关键内容**：定义、4 个研究问题、五个 finding、1B 主表、continued-pretraining 对照、proximity scatter、timing grid、CKA exemplars 都留在主文。读者能据此判断现象是否存在及适用的域条件。[pp. 3–8，Tables 1–3 / Figures 2–6]
3. **迁入附录的细节与代价**：proof、hardware、exact LR、完整 similarity matrix、70M–410M 全表与 CKA 扩展图迁入附录。迁移没有阻止理解主结果；它使机制严密性、可复现实验配置和跨规模核验需要跨 12 页读取。[pp. 13–24，Appendices A–I]
4. **最有效的模式**：先用一个可操作的 diagnostic `PA`，再以主表给 domain heterogeneity、以 direct comparator 排除一个替代、以参数 grid 说明设计边界；Table 2 和 Figure 3 的 caption 对 baseline、方向、颜色／形状编码交代得最充分。[pp. 4–6，Equation (6) / Table 2 / Figure 3]
5. **最大缺口／读者成本**：理论核心是 gradient alignment，但实证没有测梯度；`PA` 和 CKA 只提供 proxy。continued-pretraining comparison 的 start-time 差异、70M 相关系数文字与图注不一致、以及缺少 seed dispersion 也限制机制与统计结论的强度。[p. 5，§5.1 / footnote 2；p. 6，Figure 3；pp. 5–6、18，Tables 2–3、8]
6. **可迁移规则**：对跨分布训练论文，把主叙事压缩为“处理改变什么中间状态、该状态预测什么后续结果、哪个对照排除最接近替代、何处失效”，并将每一步放在同一主文证据链里。
7. **规则边界**：当中间状态只由 token overlap、CKA 或其他 proxy 表示时，不能把相关性写成已验证的优化机制；需要直接中介量、匹配的 treatment timing，或把主张降到经验规律的范围。[pp. 3–7，Equations (2)–(6) / Figures 3–6]
