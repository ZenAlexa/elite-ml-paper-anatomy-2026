## E. 方法、理论与算法

### 形式对象和动作链

Preliminary 先定义 vanilla neuron 的 charge/fire/reset（Eqs. 1--3），再区分 non-causal layer-by-layer 与 causal step-by-step propagation；论文将自己明确放在 causal 范式，目标是保持低 physical latency 而不牺牲 accuracy〔p.2, §3.1；p.3, §3.2〕。§4 的动作链为：

`setup_notation → explain_mechanism → state_problem → derive → define_component → connect_to_prediction → state_problem → define_component → instantiate_algorithm → contrast_alternative → derive`。

|组件|首次形式化/机制|解决的前文问题|证据与边界|
|---|---|---|---|
|AMOS neuron|Eqs. (4)--(8)，用 firing mask 保证最多一 spike；训练时最后一步强制 firing〔p.3, §4.1〕|为按时间平均的初始化推导提供 one-spike 假设。|推理时不强制最后一步；可在最后层 spike 后 early stop。|
|ETTFS-init|从 `D(X^l[t][i])` 推到平均方差 `N_l σ_l²/T`（Eqs. 13--15），再设为 1 得 Eq. (16)〔p.4--p.5, §4.2〕|Kaiming 方差随 T 变小，导致 silent neurons / vanishing gradients。|结论依赖层间独立、one-spike 与平均量；不是跨数据集的 theorem。|
|weight normalization + affine|Eq. (18) 固定权重尺度，Eqs. (19)--(20) 加可学习 affine 且推理时融合〔p.5, §4.3〕|梯度下降使 ETTFS-init 后的分布漂移。|论文称无 inference overhead；没有 Big-O 或 wall-clock benchmark。|
|temporal weighting decoder (TWD)|Eqs. (21)--(25)：训练用可微 weighted sum，推理用 earliest output spike〔p.6, §4.4〕|argmin inference rule 不可微；之前 decoder 的时序利用/开销问题。|`γ>1` 强化 early firing，但 γ 需按数据集调参〔p.9, §5.2.4〕。|
|average pooling|Eqs. (26)--(27) 对比 max/average pooling 的序列 spike 总和〔p.6, §4.5〕|max-pooling 可让多个空间输入在不同时间各输出 spike，破坏 one-spike。|证明的是给定 one-spike 输入的代数性质；不等同于整体准确率保证。|

## H. 消融、负面结果与自我设限

主文 ablation 约 482 估计词（9.50%）和 5 个对象（Figures 6--9、Table 4）。它覆盖：

- **机制诊断**：Figure 6 的梯度尺度与 Figure 7 的深度稳定性，测试 ETTFS-init 的信号/梯度机制〔p.8, §5.2.1--5.2.2〕；
- **组件删除/组合**：Table 4 从 max-pooling + TQ-TTFS baseline 的 89.61% 到 ETTFS-init + avg-pooling + norm + affine + TWD 的 92.90%，但无重复或误差表达〔p.9, Table 4〕；
- **超参数敏感性**：γ 的 exponential/linear decay 在三个数据集比较，Fashion-MNIST 与 CIFAR10 的最佳 γ 都报为 3，DVS Gesture 较稳定〔p.9, §5.2.4/Figure 9〕；
- **附录敏感性**：T=2--12 与初始 post-synaptic variance 的扫描移入 Appendix A〔p.12, Tables 5--6〕；
- **外部对照**：rate coding 对照移入 Table 7；相同结构下 Rate 在四个静态集准确率更高，ETTFS 只在 DVS Gesture 更高〔p.13, Table 7〕。

明示限制只在 §6 末尾：工作聚焦 small-scale datasets，未覆盖 ImageNet，未来工作需缩小 performance gap、扩大适用性〔p.9, §6, “only focuses on small-scale datasets”〕。它不在 Abstract 或 Introduction；这是一项位置事实，无法据此断定作者动机。DVS 的难点在 §5.1.1 解释为 motion 所需不同时刻 spikes 与 strict TTFS constraint 冲突；「competing methods typically fail to converge」未附故障分母或统一判据〔p.7, §5.1.1〕。

可验证的呈现模式只有三项：限制后置到结论末尾；T/variance 敏感性后移到 Appendix A；Table 1 将异构模型、pre-training 与作者实现同表呈现并明确标注。没有证据支持「弱基线」「代表性挑选」「聚合掩盖异质性」等更强意图性结论。

## L. 最终判断

1. **单一主线**：将 causal TTFS 的训练不稳解释为「one-spike 时序约束下，Kaiming 的平均 post-synaptic variance 随 T 缩小；训练中权重再漂移；输出 decode 与 pooling 也必须遵守早发/单 spike 条件」，并用 ETTFS-init、normalization、TWD、average pooling 串成从初始化到 early-stop inference 的链条〔p.4--p.6, §§4.2--4.5〕。
2. **主文保留的决策关键内容**：问题总图、32 个公式中的前 29 个、主 benchmark、steps/energy 表、四个机制/组件消融和 γ 曲线都留在 p.1--p.9；读者可以判断论文的因果链与主结果〔p.2--p.9〕。
3. **迁入附录的细节及代价**：T 与 variance sensitivity、rate-coding 对照、模型层结构和硬件设置移入 p.12--p.13。迁移没有破坏理解 ETTFS 的核心推导，却让 T/variance 的稳健性与架构复现无法只靠主文核验〔p.12--p.13〕。
4. **最有效模式**：Figure 1 先把 signal distribution、convergence、latency 的三种证据压成一个贡献地图，随后 §4 以 Eq. (15)→(16) 和 Eq. (26)→(27) 将问题与两个关键设计选择配对；Table 4 将组件组合收束为单一 outcome〔p.2, Figure 1；p.5--p.6；p.9, Table 4〕。
5. **最大缺口/读者成本**：SOTA/energy 主张跨不同架构、pre-training 与实现来源比较，`±`、seed、训练配置和真实硬件测量不足；结论中的 small-scale 限制很短且后置。Table 1 条件标注减轻误读，仍不能替代可比的配对实验〔p.7, Table 1；p.8, §5.1.2；p.9, §6〕。
6. **可迁移规则**：当论文把稳定性诊断、机制推导、组件因果和 deployment metric 串为同一主线时，应让每个设计选择既有清晰的局部不变量/公式，也有对应的可比消融与结果表。
7. **适用边界**：此规则适合可分解、可测的系统/算法论文；当主张依赖 heterogeneous external baselines、真实硬件、数据规模或训练随机性时，局部代数推导与工程估算不能单独闭合整体性能或部署主张。
