## 引言与相关工作

### 引言推进

1. **context**：私有语料上的 foundation-model adaptation 需要 PEFT，并给出 adapters、prefix/prompt tuning、BitFit 和 lightweight reparameterizations 的范围。[PDF p.1，§1，`Foundation models are routinely adapted`]
2. **context**：LoRA 被定位为 drop-in、低精度可用且低秩分解高效的方法，同时承接 non-identifiability。[PDF p.1，§1，`LoRA has emerged as a dominant method`]
3. **problem**：敏感数据下模型会面临 membership、inversion、extraction 风险，DP-SGD 是本文采用的 attack-agnostic 训练机制。[PDF p.1，§1，`clips per-example gradients`]
4. **failure_of_prior_work**：现有 DP-LoRA 对 `(A, B)` 直接做 DP-SGD，部分变体冻结一个因子；作者把其表述为与有效更新 `Z` 失配。[PDF p.1–2，§1，`fundamentally misaligned`]
5. **missing_insight**：有效对象是 `Z = ABᵀ`，因子只是 auxiliary representation；因子空间会带来 gauge-dependent clipping/noise、二阶双线性噪声和自适应不稳定。[PDF p.2，§1，`the effective update Z`]
6. **core_idea**：DP mechanism 在 intrinsic update space 上运行，先投影到 rank-`r` tangent space，再做 global Frobenius clipping 与 isotropic tangent Gaussian noise。[PDF p.2，§1，`operates on the space of intrinsic model updates`]
7. **method_preview**：PRISM 的效率、闭式内在噪声和 Table 1 的三项 desiderata 形成实现预览。[PDF p.2，§1，`Table 1 compares PRISM`]
8. **contribution_list**：三项贡献依次覆盖 failure diagnosis、PRISM update 与 DP-aware adaptive rule，最后以 code URL 结束。[PDF p.2，§1，`Our contributions can be summarized below`]

贡献列表扩写了摘要中的机制与理论主张，而非逐字重述：它给出 global clipping、`O((m+n)r²)` sampler、rank-space floors 与所采用的 accounting。列表含有可证伪主张，例如 gauge invariance、有效噪声的维度表达、`(ε, δ)-DP` 和避免 optimizer-induced amplification；没有在引言列出实验数字，也没有预先列出限制。[PDF p.2，§1，贡献列表]

## 实验设计与复现粒度

- **研究对象与任务。** 主实验是 GLUE8（除 WNLI 的八个 GLUE task）和 Math-10K（GSM8K、AQuA、MAWPS、SVAMP），使用 instruction-format 接口；GLUE8 在官方 validation splits 上依标准 GLUE metrics，Math-10K 用 exact answer accuracy。[PDF p.7–8，§4，`GLUE8`、`exact answer accuracy`]
- **模型与比较。** 主 backbone 为 Gemma-3-4B-pt，比较 FFA、LoRA-RITE、AdamW、LoRA+、LAMB 和 PRISM；额外结果覆盖 Gemma-2-9B 与 Gemma-3-12B-pt。[PDF p.7–8，§4；p.27，Table 8]
- **privacy 与统一控制。** 主文使用 `ε ∈ {3,6}`、`δ=10⁻⁵`；Appendix B 给出 rank 16、LoRA scaling 16、dropout 0.05、五个 target modules、batch 64、seed 42、clip `C=1.0`、Functorch fallback-to-hooks 与 Opacus default PRV accountant。[PDF p.7，§4；p.26，Table 7]
- **预算和实现。** GLUE8 为 500 update steps、Math-10K 为 300；常规训练在单张 NVIDIA A100-PCIE-40GB 上进行。方法专属学习率与 LoRA+ ratio 置于 Table 8。[PDF p.25–27，Appendix B.1、Table 7–8]
- **机制检验。** Issue I 使用五个等价 gauge 和 300 steps；Issue II 固定 `Z` 后对 61 个 `log₁₀ c` 值各抽 64 个 Monte-Carlo samples；Issue III 在多 privacy budget 下执行 sigma sweep，并以 300-step run 作时间序列诊断。[PDF p.26、p.29、p.31，Appendix C.1–C.3]

设计顺序与引言一致：先 Table 2 的私有 utility，再把 backbone、rank、runtime/memory 作为稳健性与成本，再以 Figure 1–4 和 Appendix C 分别对 Issue I–III 的理论预测做机理检查。表格主结果没有列出 repetitions 或 uncertainty interval；Figure 4、14、15 使用 `μ ± σseed`，但 PDF 未说明对应 seed 数量。[PDF p.7–9，§4；p.32，Figure 14–15]

## 结果、统计与消融

1. **私有 utility。** Table 2 的 unweighted 12-task mean 中，PRISM 在 `ε=6` 为 `0.690`，在 `ε=3` 为 `0.680`；作者报告分别赢得 8/12 和 7/12 tasks。比较对象是 FFA、RITE、AdamW、LoRA+、LAMB，表中没有 error bars、interval、hypothesis test 或 seed count。[PDF p.7–8，Table 2、§4，作者明示]
2. **任务异质性。** 作者明确说明 PRISM 不在 SST-2、RTE、AQuA 等每一项都最好，并归因于 suite-level shared hyperparameters 与 task-specific convergence/sensitivity；Table 2 保留所有 task 列，未只给平均分。[PDF p.8，§4，`not best on every task`]
3. **backbone 扩展。** 在 Table 3，PRISM 的 Math-10K Avg 是 Gemma-3-4B-pt `0.590`、Gemma-2-9B `0.7019`、Gemma-3-12B-pt `0.6966`，每个 backbone 内均高于同表的 AdamW 和 LoRA+。统计处理仍是 task average，没有不确定性报告。[PDF p.8，Table 3]
4. **rank sensitivity。** Table 4 显示 `r=8/16/32` 时 PRISM Avg 分别为 `0.684/0.690/0.682`，高于各 rank 的 AdamW 与 LoRA+；它是 scale/hyperparameter sensitivity，不是组件删除式 ablation。[PDF p.8，Table 4]
5. **成本。** Table 5 在单 A100-40GB 的 10 warmup + 30 measured updates 下报告 PRISM step time `18.64 s`，LoRA+ `9.32 s`、AdamW `9.37 s`；peak memory 分别为 `20964.3/20961.1/20961.1 MB`。作者将主要 practical cost 表述为 runtime，而 memory 几乎不变。[PDF p.8–9，Table 5、Limitations]
6. **Issue I。** Figure 2 的 `ρ_t` 是多 gauge 下 `‖ΔZ_t‖F` 的范围；文中说 PRISM warm-up 后趋近零而 factor-space baseline 保持较大。Appendix Figure 5–11 把裁剪系数、实际 update、step 1 与 step 300 的 gauge sweep 分开，且 p.28 明示 late saturation 可能掩盖机制依赖。[PDF p.9，Figure 2；p.27–30，Appendix C.1]
7. **Issue II。** Figure 3 把测得 noise 对 `S_t` 作图，图内拟合注记为 `0.999`；fixed-`Z` 的 Figure 12–13 使用 61 个 gauge 和每个 gauge 64 次 Monte-Carlo samples，baseline 的 linear component 对 gauge 呈数量级变化，PRISM 几乎平坦。[PDF p.9，Figure 3；p.29–31，Appendix C.2]
8. **Issue III。** Figure 4 和 Appendix Figure 14–20 把 raw noise、preconditioned amplification、max scaling、Gram stress 分层呈现。p.32 报告 PRISM 的 amplification 大约 18–50，baseline 大约 90–275；这些数来自 seed-level `μ ± σseed` 图，未给 seed 数或正式检验。[PDF p.9，Figure 4；p.31–34，Appendix C.3]

消融和诊断的主要对象是 representation、noise injection、rank、backbone 与 adaptive preconditioning；没有组件删除对 canonical lift、tangent sampler、retraction、DP-aware floor 分别进行独立的 causal ablation，也没有 human evaluation、attack simulation 或部署研究。[PDF p.8–9、p.26–35，§4、Appendix C；缺失项为版面观察]

## 自我设限与不利信息呈现

- **scope**：PRISM 针对 LoRA-style fixed-rank updates；扩展到其他 PEFT 要重新推导内在几何。[PDF p.9，Limitations，`tailored to LoRA-style fixed-rank updates`]
- **compute**：geometry-aware operations 带来 runtime overhead；memory 在 Table 5 中基本持平。[PDF p.8–9，Table 5、Limitations]
- **metric / heterogeneity**：PRISM 没有逐 task 取胜，正文点出 SST-2、RTE 和 AQuA，并把 shared hyperparameters 与不同收敛率作为范围解释。[PDF p.8，§4]
- **metric**：p.28 说明 factor-space clipping saturation 会使曲线变平，因此晚期 gauge sweep 不能单独证明 invariance。[PDF p.28，Appendix C.1，`saturation can mask`]
- **measurement**：p.31 说明 PRISM 的 raw intrinsic noise 可能大于 factor-space DP-AdamW；解释为两者噪声进入内在空间的方式不同。[PDF p.31，Appendix C.3]

没有证据表明作者用弱 baseline、选择性案例或隐藏任务列回避上述不利信息。相反，Table 2 保留各 task，正文承认非全胜，Appendix C 还把诊断的 saturation caveat 写明。详细 proofs、hyperparameters 和机制诊断被移到 appendix，但主文在每个 theorem 后提供 appendix 指针。[PDF p.2–9、p.26–35，Table 2、§3、Appendix C]

## 用词与修辞观察

正文高频的领域名词由 `gauge`、`intrinsic`、`tangent`、`noise`、`factor-space`、`preconditioning`、`LoRA`、`DP` 驱动；不是模板式贡献词的堆叠。反复出现的论证动作包括 `we propose`、`we show`、`we establish`、`we benchmark`、`we analyze`，分别集中在 Abstract/Introduction、§2–§3 与 §4/Appendix C。[PDF p.1–9，Abstract、§1–§4]

主张动词通常带着机制对象：`show` 对应 Proposition 2.2 与 Corollary 2.3，`establish` 对应 DP and gauge invariance theorems，`benchmark` 对应两个 suite，`analyze` 对应三类 diagnostics。限定表达包括 `under DP`、`for any R`、`for any target δ`、`for fixed-rank`、`roughly`、`up to stochastic variability`。这种写法把强 claim 固定在可检查的假设、公式或图表上；限制语气主要出现在 runtime、other PEFT、single-run stochasticity 和 late clipping saturation。[PDF p.3–9、p.26–34，§2–§4、Appendix C]

## 最终判断

1. **单一主线**：把 DP 的裁剪与噪声从 gauge-redundant LoRA factors 移到 `Z` 的 rank-`r` tangent space，使 private update 的分布由内在对象而非坐标选择决定。[PDF p.2、p.5–6，§1、§3]
2. **正文保留的决策内容**：三类 failure 的数学形式、Algorithm 1、核心定理陈述、两类 benchmark 的主表、rank/backbone/cost 检查、四张机制图和两句限制均留在正文。[PDF p.3–9，§2–§4]
3. **附录迁移及其代价**：完整 proofs、sampler/QR 实现、privacy accounting、数据和优化器细节、16 张诊断图均在附录。正文的主张可读，但想复核 proof obligation、noise sampler 等价性或完整诊断条件必须跳到 Appendix A–C。[PDF p.13–35，Appendix Roadmap]
4. **最有效的模式**：每个 Issue 都采用“失败公式 → PRISM 组件 → theorem → 机制图”的同构链；Table 1 在引言末尾预先给出评判维度，Figure 1–4 紧接主结果把理论差异落到测得噪声。[PDF p.2–9，Table 1、§2–§4]
5. **最大读者成本或未闭合处**：没有独立 Conclusion；细节高度依赖 23 页 appendix；主效用表没有 uncertainty/repetition 信息；组件级 causal ablation、attack evaluation 和非-LoRA PEFT 扩展未提供。[PDF p.8–9、p.13–35，§4、Limitations、Appendix]
6. **可迁移规则**：当模型的训练坐标有非识别冗余时，先定义与模型行为一致的内在更新对象，再在其度量与 sensitivity 上做隐私机制，并让理论、诊断和任务效用检验同一失效模式。[PDF p.2–7，§1–§3]
7. **适用边界**：该规则依赖可计算的内在几何、切空间投影与 retraction；论文自身只验证 LoRA-style fixed-rank updates，且几何操作带来可观 runtime 成本。[PDF p.9、p.20、p.25，Limitations、Appendix A.13、Appendix B]
