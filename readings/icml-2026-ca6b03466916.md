## 一页结论

这篇论文的单一主线是：在**终局、二元、可验证**的生成任务中，把“至少产生一个正确答案”的概率视为隐式似然；传统 expected-reward RL 只保留该对数似然的 `pass@k` Maclaurin 展开的一阶项。MaxRL 以 rollout 数 `T` 截断这一展开，并以“只对成功轨迹取平均”的 on-policy 估计器实现对应的有限算力目标；因此，增加 rollout 数不仅减少噪声，也改变为更接近 maximum likelihood 的目标。[PDF pp. 3–6, §§3–4；“a first-order approximation”；“better approximation of the maximum likelihood gradient”，显式]

论证的最强闭环是三层同向对应：Eq. (4)–(7) 给出 `pass@k` 的调和混合，Theorem 2 将成功条件化估计器精确对应到 `T=N` 的截断目标，ImageNet 受控实验再把高 rollout MaxRL 与可直接优化的 cross-entropy 放在同一图中比较。[PDF pp. 3–5, 8, 34；Eq. (4)–(7), Theorem 2, Figure 2，显式] 实验叙事随后以 maze 的数据充足情形、GSM8K 的数据稀缺情形、Qwen3 推理模型三段递进，并把更高 `pass@k` 转成 perfect verifier 下的 test-time scaling efficiency。[PDF pp. 8–11, §§6.2–6.5；“data-rich”；“data-scarce”；“up to 20×”，显式]

结论的边界也明确：主文只直接覆盖 binary reward、on-policy、有限 rollout 近似；算法对没有成功 rollout 的 task 给出零梯度，实用 baseline 使其无偏对应的截断阶数从 `N` 变为 `N−1`。连续奖励扩展只有一个 maze 初步实验，作者把完整理论和更广实证留作 future work。[PDF pp. 6, 12, 35–36, 59–60；“T = N − 1”；“leave the full theoretical treatment”，显式]

## 方法、理论与算法

### 最小逻辑单元

1. **形式化（pp. 2–3）**：`x∼ρ`、正确输出 `y*(x)`、输出分布 `pθ(·|x)`、latent trajectory `z∼mθ(·|x)`、deterministic decode `f(z)` 和二元 reward 首次出现。Eq. (1) 把 `mθ` push forward 到 `pθ`；`pass rate` 是 `pθ(y*(x)|x)`，`pass@k` 是至少一次成功的概率。[PDF pp. 2–3, §2；Eq. (1)；“deterministic decoding”，显式]
2. **缺口与推导（p. 3）**：Eq. (2) 的 `E log pθ` 与 Eq. (3) 的 `E pθ` 不同；Eq. (4)–(5) 将前者写成 failure/pass@k 的无穷调和混合。此处把“rare success”需要高阶项作为核心机制。[PDF p. 3, §3.1；“higher-order terms encoding rare success”，显式]
3. **计算折中（p. 4）**：Eq. (6)–(7) 定义 `T` 阶 `JMaxRL`；`T=1` 为 RL，`T→∞` 为 ML。`T` 是可解释的 compute knob，不依赖额外、无来源的 heuristic。[PDF p. 4, §3.2；“T = 1 recovers reinforcement learning”，显式]
4. **条件化估计（pp. 4–5）**：Theorem 1 把 ML gradient 表成成功条件下的 score expectation；Eq. (9) 用 `K` 个成功样本平均 score，Theorem 2 证明它对 `T=N` 截断目标无偏。Table 1 用分母 `N` 与 `K` 的对照将 MaxRL 和 REINFORCE 的“近乎一行差异”可视化。[PDF pp. 4–5；Theorems 1–2, Table 1；“normalization (N vs. K)”，显式]
5. **工程实现与保留边界（p. 6）**：Eq. (10) 减去 unconditional average score，Algorithm 1 将 per-task mean reward 放入 advantage。作者同时说明 practical variant 在 `K=0` 时丢弃两项，因而是 `T=N−1` 而非 `N` 的无偏估计器。[PDF p. 6, §§4.2–4.3；“order T = N − 1”，显式]
6. **解释性重述（pp. 6–7）**：Eq. (11)、Figure 1、Table 2 把各目标化为 `w(p)∇p`，其中 RL 为 1，GRPO 为 `1/√(p(1−p))`，MaxRL 为 `[1−(1−p)^T]/p`，ML 为 `1/p`。该段解释各目标如何分配学习信号，不新增算法步骤。[PDF pp. 6–7, §5；“fully characterizes the differences”，显式]

方法动作序列为 `setup_notation → state_problem → derive → define_component → explain_mechanism → instantiate_algorithm → contrast_alternative → connect_to_experiment`。主文有 11 个带编号公式（Eq. (1)–(11)）、约 17 个显示数学块、2 个定理和 1 个算法；Appendix C–E 给 3 个定理/命题和证明。最关键的理论承担 `core_chain` 角色，直接决定 experiment 的 rollout 横轴和 Table 1 的归因。[PDF pp. 2–7, 34–38；Eq. (1)–(11), Theorem 1, Theorem 2, Proposition 6，版面观察]

## 实验设计、统计与结果

### 设计与复现粒度

- **研究问题呈现**：没有编号 RQ 或预注册假设；§6 以“exact ML、infinite data、data-scarce、large-scale LLM”四段安排实验，顺序与引言的 compute/data scaling 主张对应。[PDF pp. 7–10；“We begin”；“Finally”，显式]
- **受控 ImageNet**：ResNet-50、ImageNet、batch 256、20 epochs、SGD momentum 0.9、初始 LR 0.1、cosine schedule；比较 CE、REINFORCE、GRPO、MaxRL。作者报告对 `{0.001,…,1.0}` 做了 LR sweep，但没有给出每个 sweep 的表格或随机种子数；单次训练为 single L40S GPU / 15 hours。[PDF pp. 7–8, 41–43；“batch size of 256”；“single L40S GPU”，显式]
- **Maze（数据充足）**：1,000,000 个 distinct `17×17` training mazes、256 non-overlapping test mazes、约 3M parameter decoder-only Transformer；高预算设计是 batch 256、9,000 steps、每 prompt 4–128 rollouts，另有 batch 32、20,000 steps、128 rollout 的广基线对照；每个 run 用 4 RTX 4090。[PDF pp. 8–9, 44–46；“1 million distinct”；“4 RTX 4090 GPUs”，显式]
- **GSM8K（数据稀缺）**：SmolLM2-360M-Instruct，在 GSM8K train 上 RL finetune，用 non-overlapping GSM8K-Platinum eval；Table 4 给 batch 256、128 generations/prompt、1,500 steps、8 Nvidia GH200 等参数。主文以 50 epochs 描述动态，appendix 以 1,500 RL steps 描述实际设置；二者可同时成立，但没有逐 epoch–step 换算。[PDF pp. 9, 47–49；“up to 50 epochs”；“Training Steps 1500”，显式]
- **Qwen3（大模型）**：Qwen3-1.7B-Base、Qwen3-4B-Base 在约 50k prompt 的 POLARIS-53K 上，batch 256、16 rollouts/prompt、1,000 RL steps，主文用 AIME 2025、BeyondAIME、MATH-500、Minerva；appendix 增加 AIME 2024、HMMT Feb/Nov、JEEBENCH，训练设备为 32 Nvidia H200。[PDF pp. 9–10, 50–52；“16 rollouts per prompt”；“32 × Nvidia H200”，显式]

## 用词与修辞

主文的高频论证词围绕同一个机制反复收束，包括 `maximum likelihood`、`expected reward`、`pass rate`、`pass@k`、`sampling compute`、`objective`、`gradient`、`rollouts`、`hard / low-success inputs`。这些词不能归为单纯模板词。关键主张动词包括 `prove`、`show`、`introduce`、`establish`、`compare`、`demonstrate`，常配 `exactly`、`principled`、`simple`、`consistently`、`up to` 等限定/强化词。[PDF pp. 1–12；“We prove”；“We introduce”；“We establish”，显式]

最常见的修辞结构是 **“理论恒等式 → 一句斜体结论 → Table/Figure → Takeaway”**：p. 3 的 “Reinforcement learning optimizes a first-order approximation…”，p. 5 的 “Increasing compute…”，以及 pp. 8–11 的五个框都把读者重新拉回同一个 compute-indexed storyline。强主张多数带范围限定（如 “all tested”、`up to`、`when direct ML is available`）；最明显的弱化词集中在机制解释和连续奖励扩展，如 `suggest`、`may`、`we conjecture`、`leave ... to future work`。[PDF pp. 3, 5, 7–12, 60；“we conjecture”；“initial results are encouraging”，显式]

## 可迁移规则与边界

**规则。**当一个方法的最大主张可由明确的目标函数差异解释时，正文应先封闭一个小型理论链，依次说明旧目标遗漏的内容、新目标如何以可调算力恢复它，以及估计器究竟对哪个目标无偏。随后以能直接实现理论极限的受控任务作为第一张因果证据图，最后扩展到真实任务与规模结果。MaxRL 的 Eq. (4)–(10)、Theorem 2 与 Figure 2 是该结构的清晰实例。[PDF pp. 3–8；“unbiased for fundamentally different objectives”，显式]

**适用边界。**这条规则适合有可验证事件、可写出 population objective、且可通过可控 benchmark 观察理论极限的研究。它不自动证明现实大模型结果的因果机制，也不替代跨 seed 的不确定性报告；当 reward 连续、多个 turn、离线/off-policy 或 verifier 不完美时，必须重新说明目标、估计器和实证识别边界。[PDF pp. 10, 12, 39, 59–60；“perfect verifier”；“fully on-policy”，显式]
