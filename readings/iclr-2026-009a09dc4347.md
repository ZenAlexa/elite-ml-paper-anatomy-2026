## 3. 引言的论证推进

引言按以下链条推进：现有 RLHF 的 transitivity/scalar-reward 假设 → NLHF 的 two-player 进展 → single-opponent bias 与多源偏好信号 → population competition 的 mean-field 解释和 homogeneous 条件 → MNPO 定义 → 理论、算法、实证三项贡献 → unification/robustness 的收束。核心切换位于 p.2，建模对象由单个对手扩展为整个 policy population。【p.1 §1；p.2 §1】

|---:|---|---|---|

## 5. 方法、符号、公式与证明

### 5.1 形式化对象和方法链

- `x ∈ X` 是从固定未知 `d₀` 抽取的 prompt，`π : X → Δ(Y)` 是 LLM policy，`y ∼ π(·|x)`；`πref` 是 reference policy，`Π` 被限制为与 `πref` 有相同 support 的 policies。【p.3 §2 Notation；p.3 §2 Nash Policy】
- `P` 是 general preference oracle；homogeneous 情形中所有 player 共用 `P : X × Y × {Y}^{n−1} → [0,1]`，heterogeneous 情形中 player `i` 使用 `Pᵢ`/reward model `rᵢ`。【p.3 §2 General Preference Oracle；p.4 §3.1；p.7–8 §3.3】
- 目标从 KL-regularized reward objective（Eq. 1）与 two-player zero-sum-like game（Eq. 2）扩展到 player 对 opponent population 的 `J(πᵢ,{πⱼ})`（Eq. 7）。`DualGap` 负责衡量单方偏离收益（Eq. 4/9）。【p.3 Eq. 1–4；p.4 Eq. 7–8；p.5 Eq. 9】
- Eq. 10 给出 geometric mean of opponents 加 preference advantage 的 multiplicative update；Eq. 11–14 把不可算的 partition function 转为 response-pair log-ratio loss；Eq. 15 以偏好采样与 `1/(2η)` 目标规避难算项。【p.5 Eq. 10–14；p.6 Eq. 15】
- Eq. 16 把代理损失放入 RPO 的 reward-gap 表达，Eq. 17 将历史 policies 以 `{λⱼ}` 混合成 TD-MNPO，Eq. 18 将对手和 reward signal 改成异质 `Pᵢ`/`rᵢ` 的 HT-MNPO。【p.6 Eq. 16–17；p.8 Eq. 18】

段落动作序列是 `setup_notation → state_problem → derive → define_component → explain_mechanism → define_component → derive → instantiate_algorithm → state_complexity → connect_to_prediction → contrast_alternative → connect_to_experiment`。Eq. 10 至 Eq. 15 构成全文的核心因果链。理想 n-player update 的 ratio identity 产生可训练 loss，RPO 与历史 mixture 将该 loss 接到实际 TD-MNPO。【p.5 §3.1；p.6–7 §3.2】

## 12. 最终判断

**单一主线。** 论文把 RLHF 的 single-opponent two-player game 改写为对 opponent population 的 n-player game；先在 homogeneous oracle 条件下导出 ratio-based loss 与 OMD/no-regret 叙述，再将其实现为 TD-MNPO，并把同一形式推广到无正式保证的 HT-MNPO。【p.2 §1；p.5 Eq. 10–15；p.6–8 Eq. 17–18】

**正文保留的决策内容。** 主文保留了符号、Eq. 1–18、一个方法图、Table 1–4、异质 setting 的无保证边界和三项核心结果。它把 pseudo-code、精确训练设置、replication/judge evidence、player-number 消融、证明和外部 opponent extension 放入 appendix。【p.5–10；p.16–21】

**最有效的模式。** Eq. 10 → Eq. 11–13 → Eq. 14–15 形成清晰的「理想 update → 消去不可算 partition function → pairwise trainable loss」链；Figure 1 在引言页先让 two-player、multiplayer 和 heterogeneous reward models 共现；Table 1 以同一组控制旋钮呈现 special cases。【p.2 Figure 1；p.5–6 Eq. 10–15；p.7 Table 1】

**最大缺口与读者成本。** convergence 的正式论证主要是 Appendix F.3 的标准 OMD 归属，缺少定理式完整条件/常数；多玩家带来 gradient-variance、non-transitive coverage、heterogeneous stationary behavior 的机制主张没有相匹配的测量；主表多数只有 point estimates，关键消融移入 appendix。三个边界分别影响理论可审计性、因果归因和实证不确定性。【p.2 §1；p.9–10 Tables 2–4；p.17–20 Tables 5–8/F.3/G】

**可迁移规则。** 当论文依靠复杂的对齐机制时，正文应先把理想目标到可训练代理的等价/近似链闭合，再让主结果、机制消融和限制各自对应该链的一段。该规则适用于能定义明确训练对象和对照的算法论文；在没有可观测机制量、没有稳定对照或主张仅是定位性观点时，应把结论范围限制在展示出的任务和测量上。
