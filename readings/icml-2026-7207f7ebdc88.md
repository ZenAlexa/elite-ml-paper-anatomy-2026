## method

方法主线是 `state_problem → derive → define_component → explain_mechanism → instantiate → connect_to_experiment`。

- p.3 Eq. (1) 把层级重构写为 `min ||W−αT||²₂`，Eq. (2) 定义阈值 Δ 下的 hard ternarization。
- p.3–4 Eq. (3) 定义 LM 的 `Ŵ=(W−μ)/α`、`μ=μ0+δμ α0`、`α=δα α0`，并令 `Δ=δΔΔ0`。Eq. (4) 用 `T_i=Q(Ŵ_i;δΔΔ0)` 产生 ternary weights。LM 以 redistribution proxy 减少分布失配，并保留无 μ 的 `W≈αT` 部署形式。证据为 p.4 “approximating the pre-trained weights as W ≈ αT without µ”。
- p.4 Eq. (5) 定义 tanh transition function `f(W;s,Δ)`。作者陈述其对称、可微、`s→0` 接近 identity、`s→∞` 接近 hard ternarization。p.4–5 Eq. (6) 用 `t=0`、`0<t≤γ`、`γ<t≤1` 构造 differentiable-to-hard 两阶段 relay，默认 `s0=30`、`γ=0.8`、`m=60`。
- p.5 Eq. (7) 最小化滑动层窗口的输出特征误差 `||F(W,X)−F(A·T,X)||²₂`。窗口大小遵循 SliderQuant 默认值，但 PDF 没有给出具体值。

## experimental_design

实验使用 7 个 dense Llama2/Qwen3 模型和 3 个 MoE 模型，范围 1.7B–235B，证据为 p.5 Section 3.1。默认 calibration 为 C4 随机 512 samples，每个 2048 tokens，约 1M tokens；默认 group size 128、Δ0=0.5、s0=30、γ=0.8、batch size 3、AdamW、60 epochs、学习率 0.001 linear decay，证据为 p.14 Table A。主任务是 zero-shot PIQA、ARC-E、ARC-C、HellaSwag 和 Winogrande，指标为 accuracy (%)，证据为 p.5。

QAT 对照为 BitNet v1/v2、TernaryLLM、TriLM、Tequila；PTQ 对照为 AWQ、GPTQ、OmniQuant、EfficientQAT、SliderQuant、BiLLM、PB-LLM、DB-LLM，证据为 p.5–6。部署测试使用 llama.cpp、Intel i9-13900KF、RTX 4090、batch size 1、生成 512 tokens，证据为 p.9 Table 13。PDF 未报告随机种子、重复次数、误差表达、显著性检验、完整 sliding-window size 或失败判定。

## results

结果单位是每模型每任务 accuracy 百分比；Avg 为五任务汇总列，论文未明写聚合公式，也未报告不确定性。Table 1 p.6 覆盖 10 个模型。典型 Avg 为 Qwen3-1.7B FP16/CAT-Q 61.42/51.01、Qwen3-8B 71.57/61.76、Llama2-70B 76.53/72.72、Qwen3-235B-A22B 79.59/69.09。作者指出 Llama2-70B 仅下降 3.81 个百分点，并观察到 MoE 更敏感，后者是带 `likely` 的机制解释。

Tables 2–3 p.6 给出相近规模的 QAT 对照。CAT-Q 用约 1M tokens，对照 BitNet 的 100B、TriLM 的 300B、Tequila 的 10B 和 TernaryLLM+KD 的 1T tokens；Qwen3-1.7B/4B/8B 的 W1.58A16 Avg 为 51.01/57.06/65.43。Table 4 p.6–7 中，CAT-Q 在 Llama2-7B 和 70B 的 Avg 为 57.69 和 72.72，超过表中 W2 或 dual-1-bit PTQ 对照。

Table 13 p.9 显示 CAT-Q 在 Qwen3-4B 上为 1.01/1.17 GB、37.35/320.34 tokens/s，在 Llama2-7B 上为 1.62/1.90 GB、26.30/281.66 tokens/s，分别对应 CPU/GPU。Appendix Table B p.15 是重要负面结果。复杂数学和代码任务上 CAT-Q Avg 仅 3.44，具体 MATH-500、GSM8K、Omni-MATH、HumanEval+、MBPP+ 为 0、14.48、2.71、0、0；表中模型身份未明确列出。CAT-Q+通过新的 calibration data generation strategy 得到 Avg 45.60。

## ablation

Tables 5–12 位于 p.7–8。Table 5 逐步加入 δμ、δα、δΔ 和 ST，Qwen3-4B Avg 从 40.16 升至 57.06，Llama2-7B 从 45.37 升至 57.69。Table 6 的 γ=0.8 最优，γ=1.0 下降，支持保留 hard stage。Table 7 的 s0=30 在两模型上最优；过大 s0 过早接近 hard target。

Table 8 的 LM Avg 为 Qwen3-4B 57.06、Llama2-7B 57.69，超过 static approximation 和 direct learning。Table 9 显示无 μ 的 `W≈αT` 略优于带 μ。Table 10 支持 learnable Δ。Table 11 显示 512 到 1024 samples 仍提升 Avg，但作者选择 512 作为成本折中。Table 12 显示较小 group size 通常更好，默认 128 用于公平对照。

Appendix Figure B p.15 在六个 sliding windows 上显示 ST 最终 loss 更低。Appendix Figures C–K p.16–19 覆盖 Qwen3-4B、Llama2-7B 多层投影和 Qwen3-30B-A3B 的 sampled experts，显示 static approximation 误差最大、direct learning 有 outlier、LM 误差和方差最低。困难任务 Table B 是范围失败证据，而非组件成功证据。
