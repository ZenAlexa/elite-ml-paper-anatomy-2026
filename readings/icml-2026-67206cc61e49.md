### 5.2 算法、复杂度与实现粒度

- **Algorithm 1**：一个升序 `for β ∈ G` 循环。每轮估计 normalizer ψβ、构造 constrained PDF 与过去 policy 的 mixture，计算 calibration weights 和 conservatively bounded test-point weight；当 weighted empirical risk 超过 α 时返回当前 β̂，若从未超过则返回 `max(G)`。输入／输出、循环方向和保守 test point 都在主文可读；grid construction、ψ 的 Monte Carlo 估计、mixture approximation 与 numerical log-space 计算转移到 §D.1。[p.6, Algorithm 1；p.40–43, §D.1]
- **Algorithm 2** 给出四阶段最小闭环：safe-policy data collection、policy improvement、`CALIBRATEBETA`、constrained deployment。它呈现单轮 CPC 的管线伪代码，并复用 Algorithm 1 的 calibration。[p.53, Algorithm 2]
- **复杂度**：主文只给 “fast linear runtime” 的定性说明，针对用 past-policy mixture 近似 permutation weights；未给 Big-O、memory 或 wall-clock 量化，故这些项目为 `not_present`。采样的效率被提为 test-time compute trade-off，附录给 AR envelope 与 IMH，而没有给 benchmark runtime。[p.7, §4.2；p.42–45, §D]

## 13. 最终判断

1. **单一主线**：把 agent 自身造成的 distribution shift 变成可选的 likelihood-ratio-clipped policy family；用 safe-policy data 做 conformal calibration 选择最大的风险可接受 β，再以 rejection sampling 部署。这样将 “我要多大风险” 的 declarative α 直接连到 policy 的概率分布，而非交给未校准的 divergence penalty。[p.1–3, §1–2；p.6–7, §4.2]
2. **正文保留的决策关键内容**：引言的 selection-bias 问题、Figure 1 的完整 pipeline、Eq. (5)–(6)、两条主 guarantee、Algorithm 1、三个任务的主结果图与 Discussion 的 marginal/context/likelihood 边界。这些内容足够判断方法承诺与适用前提。[p.2, Figure 1；p.5–9, §4–6]
3. **附录迁移及影响**：证明、normalizer/weight approximation、采样细节、数据生成与 hyperparameters 均移到 supplement。迁移没有破坏“方法是什么”的主文自足性；它限制了“实验使用的近似实现是否继承 exact-weight theorem”的独立判断，必须查 §D.1.3。[p.7, §4.2；p.40–43, §D.1.3]
4. **最有效模式**：早期全宽流程图先将训练、calibration、用户 α 与 deployment 串成一条可视因果链；随后以 β 插值图、两条 theorem、按贡献顺序排列的任务图把机制、保证和证据依次闭合。[p.2, Figure 1；p.5–9, Figures 3–6]
5. **最大缺口／读者成本**：Theorem 4.6 建立在 exact conformal permutation weights 上，实际叙述又用 mixture approximation 与 empirical (w_{max})；该近似的同级 finite-sample guarantee 未在 PDF 中给出。其次，非 Medical QA 图的 aggregation／seed／ribbon 定义缺失，Figure 5 与 Table 3 的 iteration count 相冲突。[p.7, §4.2；p.41–43, §D.1.3；p.8, Figure 5；p.51, Table 3]
6. **可迁移规则**：将用户可理解的 target risk 映射到一个由系统自身可计算、连续且可校准的 policy family；让 model selection 本身成为 calibration procedure 的输出，而非 calibration 之后的额外选择步骤。
7. **适用边界**：规则需要可信 safe reference、bounded loss、mutual absolute continuity、可计算或可信估计的 likelihood、足够稳定的 calibration procedure 和 context distribution；当权重只能近似或 context shift 继续变化时，主张范围应缩回到已验证的近似／recalibration 条件。[p.6–7, §4；p.9, §6；p.40–43, §D]
