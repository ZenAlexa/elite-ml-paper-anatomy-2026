## 方法、公式与理论边界

### 最小逻辑单元

1. `setup_notation`：将一个环境写为任务 prompt `P_T`、环境描述 `P_E`、动作集合 `A^E` 与接口规范 `I^E={D_i}`；每个 `D_i` 同时含 action name、functional description 与 invocation format。【p.2 §3.1；p.3 §3.1｜`explicit`】
2. `derive`：agent 根据 `P_E,P_T,I^E,O_{≤t}` 产生文本动作，环境解析后返回 observation；轨迹 outcome 聚合为环境 score。【p.3 §3.1，动作与轨迹式｜`explicit`】
3. `explain_mechanism`：trajectory collection 与 evaluation 重用同一 `I^E`，使训练可利用 interface-level regularities。【p.3 §3.1「This similarity creates room」｜`explicit`】
4. `define_component`：PIPE 仅将 `I^E` 重写为 `I^{E'}`，分 synonym 与 symbol 两个扰动家族，保持 executable actions、tasks、observations 和详细功能描述。【p.3 §3.2；p.4 §3.2｜`explicit`】
5. `connect_to_prediction`：语义学习应在重写接口中恢复正确工具使用；接口捷径应出现较大的 `Delta`。Figure 2 将这个反事实比较可视化。【p.3 Fig.2；p.4 §3.3｜`explicit`】
6. `define_component`：IR 令原始别名与 synonym 别名并存，按任务计数，在 log space 聚合并对提示顺序做双次 counterbalance。【p.7 §6；p.17 §F｜`explicit`】
7. `contrast_alternative`：Appendix G 排除算术平均的 `IR_naive`，理由是极端任务、交互长度和 alias stickiness 会支配均值；几何均值保留可解释的乘性偏好。【p.17 §G；p.18 §G｜`explicit`】

动作转移为：`setup_notation → derive → explain_mechanism → define_component → connect_to_prediction → connect_to_experiment → define_component(IR) → contrast_alternative`。方法图只有 Figure 2；没有 pseudocode 或 Algorithm，正文不把实现流程伪装成算法贡献。【p.3 Fig.2；p.1–31 未见 Algorithm 标签｜`layout_observation`】

## 实验设计与统计表达

### 设计

- **研究问题**：Q1 测试 PIPE 是否统一增大任务难度；Q2 测试 trajectory-SFT 是否扩大训练接口下的扰动 gap；Q3 用失败案例解释退化；Q4 用 IR 定量训练接口偏好。【p.4 §4；p.5 §5；p.7 §6｜`explicit`】
- **覆盖**：AgentBench 6 个环境、AgentGym 10 个环境，共 16 个；任务数、交互形态、action interface 和 metric 分别列于 Tables 7–8。AgentBench 的测试任务数为 50–300，AgentGym 为 20–200，因环境而异。【p.4 §4.1；p.14 Table 7；p.15 Table 8｜`explicit`】
- **控制条件**：每个 agent 在 Original、Perturb 1 synonym、Perturb 2 obfuscation 三种条件中评测。严格设置禁止原始 identifier；输出旧 identifier 会得到 `invalid/deprecated action`，因此不能借由后端接受旧名获得成功。【p.4 §4.1；p.19 §I｜`explicit`】
- **语义控制**：作者称 synonym 由多位熟悉 tool-augmented agents 的 reviewers 独立复核，检查等价意图、难易度和环境内一致性；后端通过 display-side rewriting 与 server-side translation 保持不变。【p.19 §I｜`explicit`】
- **对象**：AgentBench 比较 GPT-3.5、GPT-4o-mini、GPT-5-mini 与 AgentLM-7B/14B/70B、AgentFLAN；AgentGym 报告 Qwen3-8B/14B 与 Gemma3-4B/12B training 前后。【p.4 §4.1；p.5 Table 1；p.6 Table 2｜`explicit`】
- **训练细节**：Appendix K 明示 full-parameter SFT、DeepSpeed ZeRO-3、bfloat16、Adam、`1e-5` 学习率、cosine decay、0.1 warmup、per-device batch 2、gradient accumulation 2、16 preprocess workers、4 loader workers；无 held-out validation (`val size=0`)，每 10 steps 记录 loss，未保存中间 checkpoints。【p.20 §K｜`explicit`】
- **报告缺口**：该版本未报告 random seed 数、重复训练次数、硬件型号/数量、误差条、置信区间或假设检验。该判断来自完整表图的版面检查；不能把点估计差异解读为已通过统计显著性检验。【p.5–8 Tables 1–4/Figs. 3–4；p.20 §K｜`layout_observation`】
- **实现范围不确定**：§4.1 明写 fine-tune Qwen3-8B/14B 与 Gemma3-4B/12B，Appendix K 又写「All trajectory-based ... experiments」从 Qwen3-8B 初始化。文中没有消除二者的覆盖关系，故精确训练实现范围标为 `uncertain`。【p.4 §4.1；p.20 §K｜`explicit`】

### 统计与可视化

- 主 performance 是每环境任务 outcome 的平均；p.3 定义环境 score 为 `r(tau)` 对任务的平均。`Delta=(s1+s2)/2-s0` 汇总两类扰动与原始分数的变化。【p.3 §3.1；p.4 §4.1｜`explicit`】

- Table 1–4 可自行说明 model、environment、训练状态和 metric；Figure 3–5 均有完整 caption。它们报告 task/environment 聚合量和曲线，却没有显示 seed-level variation 或 interval。【p.5–8 Tables 1–4/Figs.3–4；p.20 Fig.5｜`layout_observation`】

|---|---|---|

### 消融、负面结果与自我设限

没有组件删除式受控消融。作者在比较 AgentFLAN 时明确写出这只是相关性观察，原因是没有对其 training design 做 controlled ablations。【p.5 §4.2「correlational observation」｜`explicit`】

可视为敏感性/稳健性补充的对象有三类：IR 的 `alpha=0.5,1,2`（Tables 12–17）、naive arithmetic aggregation 的反例（Table 11）、以及 8-epoch checkpoint 轨迹（Figures 4–5）。它们诊断测量与训练长度，不识别单个 SFT 组件的因果贡献。【p.18 §§G–H；p.28 Table 11；p.29–30 Tables 12–17；p.8 Fig.4；p.20 Fig.5｜`interpretation`】

自我设限出现的位置与编码如下：

- `causality`：AgentFLAN 的较强鲁棒性仅是相关性，未做 controlled ablation。【p.5 §4.2｜`explicit`】
- `scope` / `metric`：SQLGym、TextCraft 的扰动区分力较低；Mind2Web、SQLGym 在此 protocol 中近似 single-turn，错误累积和恢复机会少。【p.15 §§C.3–C.4｜`explicit`】
- `generality`：环境特征（工具数、轨迹数、interaction length）支持 loose/high-pressure 的解释，但只是环境统计与 pattern 对照，作者没有在该处给出操作化随机干预。【p.16 §D；p.31 Tables 24–25｜`interpretation`】

## 用词、修辞与可迁移规则

对 p.1–8 的 PDF 文本做粗略检索（含标题、图表标签，未作最终 corpus token normalization）得到：`trajectory-SFT` 约 37 次、`interface shortcut` 约 20 次、`interface reliance` 约 13 次、`semantic learning` 约 12 次；高频领域词为 interface、agent(s)、perturb(ation)、action、environment(s)、training、evaluation。高频二元表达的有效部分是 `interface reliance`、`semantic learning`、`action names`、`interface perturbations`、`trajectory-SFT agents`；title、作者引用、model/table 标签会污染 `what do agents…`、`et al.` 和 `Origin/Perturb` n-grams。【p.1–8，术语反复出现｜`layout_observation`】

主张动词以 `propose`（3）、`introduce`（2）、`demonstrate`（1）、`reveal`（1）为主；限定语包括 `may`（7）、`typically`（5）、`largely`（3）、`primarily`（2）。对比/因果连接词 `however`、`in contrast`、`therefore` 把「同一分数」→「不可识别」→「反事实接口」→「IR」串成单一路径。强主张集中在摘要、贡献 bullet 与结论；p.5 的 correlation caveat、p.15 的 single-turn 限制和 p.20 的 `val size=0` 构成较弱但具体的收束。【p.1–2 Abstract/§1；p.5 §4.2；p.15 §C.4；p.20 §K｜`interpretation`】

### 可迁移规则

当核心科学主张是「某训练增益反映何种机制」时，把潜在机制差异转化为只改一个表面因子的反事实协议，并在主文同时报告 outcome gap 与机制近端行为量。【p.3–4 §§3.1–3.3｜`interpretation`】

### 适用边界

该规则要求后端行为、任务、functional descriptions 和成功标准可保持不变。single-turn 或低工具多样性环境的扰动区分力可能较低，且 score gap 本身仍不是对潜在语义表征的直接测量。【p.3–4 §§3.1–3.3；p.15 §§C.3–C.4｜`interpretation`】
