## 相关工作：三簇定位而非方法复述

§6 只有约 307 个词，位于 p.17。其三段分别采用以下组织方式：

1. **Reasoning collapse and policy degeneracy**：按现象和闭环训练条件归类，区分 rationale/template 层退化与 action-policy 层退化，并用 self-training/model-collapse 文献作基础。证据为 p.17，§6，`reasoning-level degeneration can decouple`。
2. **Diversity, input dependence, faithfulness**：按测量对象区分 lexical／embedding／uncertainty、多种 behavioral tests、retrieval-style matching 和 faithfulness。与 faithfulness 的相邻差异是“decision basis”对比“input sensitivity after RL”。证据为 p.17，§6，`related but not equivalent`。
3. **Stabilizing multi-turn Agent RL**：按干预族群列 KL、entropy、clipping、reward shaping、curriculum、replay、rejection sampling 等，再用“相同 reward 未区分 reasoning quality”制造当前方法的缺口。证据为 p.17，§6，`gradients carry little information`。

该节以 taxonomy、credit_or_foundation、limitation_of_prior 和 gap_creation 为主。它避免重复完整方法：没有重列 `matched`／`marginal`、Top-p 公式或结果表。RAGEN [60]、PPO [42]、GRPO [44]、任务文献等引文随后在 setup、算法比较和环境定义中继续承担论证功能。直接的 nearest-neighbor contrast 主要发生在 faithfulness 段；对其他工作多为簇级归纳。

### 最终判断

1. **单一主线**：多轮 agent RL 的 reasoning 可在 entropy 维持时转向跨输入 template。论文用 MI proxy 让该退化可观测，再将低 reward variance 解释为低 SNR 的条件，并以 per-prompt RV filtering 干预更新。
2. **主文保留的决策关键内容**：四象限定义、cross-scoring、SNR 示意、筛选公式、任务矩阵、主结果、噪声边界和五项限制都留在 p.1–18。读者能够判断问题、操作和经验方向。
3. **迁入附录的内容及自足性**：环境／超参数、替代 proxy 与 filter、全部定理证明、estimator bias 和 GRPO 变体在 p.26–44。正文保持了核心因果故事；严格审查机制、无偏性和精确复现需要附录。
4. **最有效的模式**：Figure 1 先把“entropy 稳定但 input dependence 下降”视觉化；随后 Figure 3、Table 6、Figure 9 依次把梯度观察、RV 干预和失效边界接在同一变量上。该串联使诊断、机制与反例共享可追踪的中间量。
5. **最大的缺口与读者成本**：Table 4 使用 peak/delta 且未报告 seed-level 分母或不确定性，机制证据因而难以估计稳定性。理论保证的假设、filtered-objective bias 和 token-space-bound 的松弛度分散在附录，要求读者在主文与 p.35–43 间往返。
6. **可迁移规则**：当论文提出“一个常用监测量存在盲点”时，先用可区分的二维状态图界定盲点，再让新的观测量、机制中间量、干预和边界条件复用同一坐标或变量。
7. **适用边界**：该规则适用于可定义中间量且可做对照干预的经验论文。中间量本身若受环境噪声、目标偏置或不可观测混杂影响，仍需报告其可靠性条件、失败区域和统计重复信息。
